# ELMo와 ULMFiT: 자연어 처리를 위한 전이 학습

출처: https://mbrenndoerfer.com/writing/elmo-ulmfit-transfer-learning-natural-language-processing

---

2018년에 자연어 처리 전이 학습을 확립한 두 방법, ELMo와 ULMFiT를 종합적으로 설명한다. 문맥화 임베딩과 미세조정 기법이 사전 학습 모델의 지식을 후속 과제로 옮길 수 있게 하면서 언어 AI를 어떻게 바꾸었는지 살펴본다.

## 2018년: ELMo와 ULMFiT

2018년 초, 서로 독립적인 두 연구진은 신경 언어 모델을 후속 과제에 적용하는 방식을 근본적으로 바꾼 방법을 발표했다. Matthew Peters와 Mark Neumann 등이 참여한 Allen Institute for AI 연구진은 ELMo(Embeddings from Language Models)를 발표했다. ELMo는 심층 양방향 언어 모델이 강력한 문맥 의존 단어 표현을 만들 수 있음을 보였다. 같은 시기 fast.ai의 Jeremy Howard와 Sebastian Ruder는 ULMFiT(Universal Language Model Fine-tuning)를 제시했다. 사전 학습 언어 모델을 적은 과제별 자료만으로도 여러 자연어 처리 과제에 효과적으로 미세조정할 수 있다는 결과였다. 동시에, 그러나 독립적으로 개발된 두 접근은 이후 자연어 처리의 중심이 된 전이 학습 패러다임을 확립했다.

2010년대 후반 신경 언어 모델은 빠르게 정교해졌지만 근본 문제가 남아 있었다. 대규모 언어 모델 사전 학습에서 얻은 지식을 특정 후속 과제로 어떻게 효과적으로 옮길 것인가 하는 문제였다. 전통적인 방식은 과제마다 별도 모델을 처음부터 훈련했다. 비표지 텍스트에서 배울 수 있는 언어 구조·구문·의미 지식을 매번 다시 익혀야 했다. Word2Vec과 GloVe 같은 분산 표현은 유용한 언어 규칙성을 포착했지만 정적이고 문맥에 독립적이었다. 금융 문맥의 bank와 강가를 뜻하는 bank가 같은 표현을 받았으므로 미묘한 의미 차이를 이해하는 데 한계가 있었다.

ELMo와 ULMFiT는 서로 다르지만 보완적인 방식으로 이 전이 학습 문제를 다뤘다. ELMo는 깊은 양방향 언어 모델을 훈련해 같은 단어라도 문맥에 따라 다른 표현을 만드는 문맥화 임베딩에 초점을 맞췄다. 주변 단어에 따라 달라지는 표현 안에 구문·의미·담화 수준 정보를 담았다. ULMFiT는 다른 길을 택했다. 판별적 미세조정, 점진적 동결 해제, 기울어진 삼각형 학습률을 사용해 사전 학습 지식을 보존하면서 모델을 특정 과제에 적응시킬 수 있음을 보였다.

두 방법은 대규모 비표지 텍스트 사전 학습의 지식을 옮기면 표지 자료 요구량을 줄이면서 여러 자연어 처리 과제의 성능을 크게 높일 수 있음을 보였다. ELMo의 문맥화 표현은 질의응답, 감성 분석, 개체명 인식, 의미역 결정 등에서 당시 최고 성능을 개선했다. ULMFiT는 하나의 사전 학습 언어 모델을 여러 텍스트 분류 과제에 맞춰 미세조정할 수 있고, 더 많은 표지 자료로 훈련한 과제 전용 구조와 맞먹거나 앞설 수 있음을 보였다. 이 결과는 큰 비표지 말뭉치에서 얻은 언어 지식이 여러 후속 응용의 토대가 될 수 있다는 가설을 뒷받침했다.

의의는 즉각적인 성능 향상보다 넓었다. ELMo와 ULMFiT는 컴퓨터 비전을 바꾼 전이 학습이 자연어 처리에서도 효과가 있다는 실증을 제시했다. 대규모 텍스트로 훈련한 언어 모델이 과제와 영역을 넘어 옮길 수 있는 일반 언어 지식을 포착한다는 사실을 보여 주었다. 이 통찰은 곧 Transformer 기반 BERT와 GPT 및 그 후속 모델에서 훨씬 큰 규모로 확장됐다.

## 문제

ELMo와 ULMFiT 이전의 자연어 처리 시스템은 사전 학습 모델의 지식을 특정 후속 과제로 옮기는 데 근본적인 어려움이 있었다. 전통적인 접근은 무작위 초기화에서 시작해 과제별 신경망을 따로 훈련했다. 계산 비용과 자료 요구량이 컸고, 각 모델이 구문·형태론·의미 관계 같은 공통 언어 지식을 다시 배워야 하므로 비효율적이었다.

단어 임베딩은 일부 해결책을 제공했다. Word2Vec과 GloVe는 큰 말뭉치에서 의미·구문 관계를 담은 벡터를 학습했고, 이를 과제별 모델의 초기값으로 쓸 수 있었다. 그러나 정적 임베딩은 문맥과 관계없이 단어 하나에 같은 벡터를 준다는 결정적 한계가 있었다. river bank와 investment bank의 bank가 같은 임베딩을 받았고, 의미 구분의 부담은 과제별 훈련 자료와 후속 모델에 남았다.

이 문맥 독립성은 여러 자연어 처리 과제에 직접적인 제약을 주었다. 질의응답에서는 bank가 금융 기관인지 지형인지 알아야 했다. 개체명 인식에서는 Washington이 사람·도시·주 가운데 무엇인지 문맥으로 판단해야 했다. 의미역 결정에서는 같은 동사도 구문 문맥에 따라 다른 논항 구조를 취할 수 있었다. 정적 임베딩은 이런 변이를 자체 표현에 담지 못했다.

과제 전용 모델을 처음부터 훈련하려면 응용 영역마다 많은 표지 자료가 필요했다. 전문가가 수천에서 수만 개 예시에 라벨을 붙이는 작업은 비싸고 느렸다. 전문 영역, 저자원 언어, 새 응용처럼 표지 자료가 드문 곳에는 큰 장벽이었다. 자료가 충분해도 모델은 과제 사이에 공통인 언어 기초를 다시 익히느라 용량과 계산을 소비했다.

언어 모델은 잠재적 해결책이었다. 방대한 비표지 말뭉치로 훈련해 일반 언어 지식을 배울 수 있었기 때문이다. 그러나 이 지식을 후속 과제에서 효과적으로 사용하는 법이 분명하지 않았다. 초기 언어 모델 표현을 후속 과제에 쓰려는 시도는 성공이 제한적이었고, 구조와 학습 절차도 전이를 중심으로 설계되지 않았다. 언어 모델이 배운 풍부한 지식을 뽑아 여러 응용으로 옮길 표현이나 미세조정 절차가 필요했다.

과제마다 모델을 따로 훈련하는 계산 비용도 비효율을 낳았다. 여러 자연어 처리 응용을 만드는 조직은 사용 사례마다 신경망을 훈련하고 유지해야 했다. 감성 분석과 개체명 인식은 모두 단어 의미·문장 구조·담화 관계를 알아야 하지만 보통 이 공통 지식을 공유하지 않은 채 독립적으로 훈련됐다.

## 해법

ELMo와 ULMFiT는 모두 대규모 언어 모델 사전 학습을 이용했지만 그 지식을 후속 과제에 적용하는 방식은 달랐다. ELMo는 문맥에 따라 달라지는 풍부한 표현을 만들었고, ULMFiT는 사전 학습 지식을 보존하면서 모델 전체를 특정 과제에 적응시키는 방법을 개발했다.

### ELMo: 심층 문맥화 단어 표현

ELMo의 혁신은 문맥 의존 단어 표현을 만드는 깊은 양방향 언어 모델이었다. 정적 단어 임베딩과 달리 같은 단어에도 주변 문맥에 따라 다른 벡터를 만들었다. 모델은 왼쪽에서 오른쪽으로 읽는 순방향 언어 모델과 오른쪽에서 왼쪽으로 읽는 역방향 언어 모델로 구성됐다. 두 방향은 각각 이전 문맥으로 다음 단위를 예측하도록 훈련됐고, 대응하는 층의 표현을 결합해 사용했다.

이 양방향 구성은 현재 위치의 앞뒤 단어에서 풍부한 문맥 정보를 포착했다. 순방향 언어 모델은 현재 위치 앞의 단어 정보를, 역방향 언어 모델은 뒤의 단어 정보를 부호화했다. 두 표현을 합치면 각 단어를 둘러싼 문장 문맥이 반영된 표현을 얻을 수 있었다.

ELMo는 여러 층의 깊은 LSTM 구조를 사용했고, 층마다 서로 다른 종류의 언어 정보가 나타났다. 하위 층에서는 국소 구문 패턴과 품사 정보가 더 잘 드러났고, 상위 층에서는 의미처럼 더 추상적인 정보가 더 잘 나타나는 경향이 있었다. 최종 표현은 모든 층의 표현을 과제별로 학습한 가중치로 합해 만들었다. 따라서 후속 모델은 필요에 따라 서로 다른 추상화 수준을 활용할 수 있었다.

#### 양방향 문맥 부호화

ELMo의 핵심 통찰은 단어 의미가 앞뒤 문맥 모두에 의존한다는 것이다. 순방향·역방향 언어 모델의 표현을 합치면 financial 뒤, account 앞의 bank는 강둑보다 금융 기관을 뜻할 가능성이 높다는 식의 정보를 담을 수 있다. 이는 정적 임베딩이나 한 방향 언어 모델보다 풍부한 단어 표현을 제공했다.

사전 학습 ELMo는 입력 텍스트를 처리해 각 단어의 문맥화 임베딩을 만들었다. 후속 모델은 이를 기존 단어 임베딩과 이어 붙이거나 입력 표현의 일부로 사용할 수 있었다. 원래 ELMo 활용 방식에서는 사전 학습 양방향 언어 모델을 대체로 고정하고, 과제별 층 혼합 가중치와 후속 모델을 학습했다. 이 설계는 기존 자연어 처리 구조를 완전히 바꾸지 않고도 통합하기 쉽게 했다.

### ULMFiT: 언어 모델의 효과적인 미세조정

ULMFiT는 사전 학습 언어 모델을 후속 과제에 효과적으로 미세조정하는 데 초점을 맞췄다. 절차는 일반 영역 언어 모델 사전 학습, 목표 영역 언어 모델 미세조정, 목표 과제 분류기 미세조정의 세 단계로 이루어졌다. 이때 판별적 미세조정, 점진적 동결 해제, 기울어진 삼각형 학습률이 사전 학습 지식을 잃지 않으면서 새 과제에 적응하는 데 중요한 역할을 했다.

판별적 미세조정은 사전 학습 언어 모델의 층마다 담긴 정보가 다르므로 서로 다른 학습률을 써야 한다는 생각이다. 아래층의 일반 언어 패턴은 적게 바꾸고, 위층은 새 영역과 과제에 더 크게 적응시킨다. ULMFiT는 층별로 다른 학습률을 적용해 아래층에는 더 작은 학습률, 위층에는 더 큰 학습률을 사용했다.

점진적 동결 해제는 모든 층을 한꺼번에 미세조정할 때 생기는 불안정을 줄였다. 모든 매개변수를 동시에 크게 갱신하면 일반 언어 지식을 잊을 수 있다. 따라서 먼저 마지막 층만 풀어 학습하고, 이후 더 아래층을 차례로 풀어 각 층이 점진적으로 새 과제에 적응하게 했다.

기울어진 삼각형 학습률은 초기에 빠르게 적응하고 뒤에는 세밀하게 조정하는 일정이다. 학습률을 짧은 구간 동안 빠르게 높인 다음 더 긴 구간에 걸쳐 서서히 낮춘다. 이 방식은 과제에 충분히 적응하면서도 최적점을 지나치거나 이미 배운 표현을 크게 훼손하는 위험을 줄였다.

#### 사전 학습 지식 보존

미세조정은 정교한 기계를 다시 조율하는 일과 비슷하다. 너무 많은 부품을 너무 빨리 바꾸면 이전에 잘 작동하던 조정 상태가 무너진다. 점진적 동결 해제와 판별적 미세조정은 변화가 더 필요한 위층부터 작은 단계로 조정하면서 여러 과제에 유용한 아래층 지식을 보존하려는 방법이다.

ULMFiT는 하나의 사전 학습 AWD-LSTM 언어 모델을 감성 분석, 뉴스·리뷰 분류, 질문 유형 분류 같은 여러 텍스트 분류 자료에 맞춰 미세조정할 수 있음을 보였다. 사전 학습 모델이 이미 많은 언어 지식을 갖고 있었기 때문에 적은 표지 자료에서도 강한 성능을 냈다. 이는 전문 영역이나 자료가 부족한 분류 응용에 특히 유용했다.

### 상호 보완적인 접근

ELMo와 ULMFiT의 메커니즘은 달랐지만 대규모 언어 모델 사전 학습을 후속 과제에 재사용한다는 원리는 같았다. ELMo는 후속 모델이 특징으로 사용할 문맥화 표현을 제공했고, ULMFiT는 사전 학습 모델 전체를 조심스럽게 적응시키는 법을 보여 주었다. 두 방법은 비표지 텍스트에서 얻은 지식이 과제 성능을 높이고 표지 자료 요구량을 줄인다는 사실을 입증했다.

두 접근의 성공은 전이 학습이 자연어 처리에서도 실행 가능한 패러다임임을 확인했다. 이후 Transformer 기반 모델은 이 원리를 확장하고 규모를 키웠지만, ELMo와 ULMFiT는 각각 특징 추출과 모델 미세조정이라는 중요한 경로를 선명하게 보여 주었다.

## 응용과 영향

ELMo와 ULMFiT는 여러 응용에서 빠르게 효과를 보이며 전이 학습을 자연어 처리의 중심 패러다임으로 끌어올렸다. ELMo의 문맥화 표현은 질의응답, 감성 분석, 개체명 인식, 의미역 결정, 상호참조 해소 등에서 당시 최고 성능을 개선했다. ULMFiT는 적은 표지 자료로도 텍스트 분류에서 강한 결과를 얻을 수 있음을 보였다.

질의응답은 문맥에 따라 단어 의미가 달라지는 것을 이해해야 하므로 ELMo의 표현에서 특히 이득을 얻었다. SQuAD 같은 자료에서 질문에 답하려면 지문 문맥을 정확히 읽어야 했다. 문맥화 표현은 중의적인 단어의 의미를 구분하고, 상호참조 해소에서는 문장과 언급 사이의 관계를 포착하는 데 도움을 주었다.

감성 분석과 텍스트 분류에서는 ULMFiT가 유용했다. 수만 개의 표지 예시가 없어도 수백 또는 수천 개 예시로 효과적인 분류기를 만들 가능성을 보였다. 영역·언어·용도마다 큰 자료를 새로 구축하기 어려운 환경에서 하나의 사전 학습 모델을 여러 분류 과제에 적응시킬 수 있었다.

개체명 인식은 ELMo의 문맥화 표현을 사용해 Washington 같은 단어가 사람·지역·조직 가운데 무엇인지 더 정확히 구분할 수 있었다. 앞뒤 문맥을 함께 반영하는 표현은 개체 경계와 문장 안 관계를 판단하는 데도 도움을 주었다.

후속 연구에서는 의학·법률 등 특정 영역의 말뭉치로 ELMo를 사전 학습했고, ULMFiT의 절차를 다언어·저자원 언어·전문 영역 분류로 확장했다. 성공적인 결과는 전이 학습 연구를 촉진했고 곧 Transformer 기반 방법으로 이어졌다.

계산 효율과 배포상의 이점도 있었다. ELMo 표현은 미리 계산해 저장할 수 있었고, ULMFiT의 미세조정은 언어 모델을 처음부터 다시 훈련하는 것보다 훨씬 적은 시간과 자원으로 새 분류 과제에 적응할 수 있었다. 다만 문맥에 따라 표현이 바뀌므로 ELMo를 모든 상황에서 문맥과 무관하게 한 번만 계산할 수 있는 것은 아니다.

두 방법은 문서 수준 패턴을 다루는 연구에도 쓰였다. ELMo 표현은 상호참조 해소처럼 문장 사이 언급 관계가 중요한 과제에 도움을 주었고, ULMFiT 분류기는 문서 전체 패턴을 학습했다. 그러나 이것이 ELMo가 임의 길이 담화를 완전하게 부호화했다거나 ULMFiT가 일반 요약·질의응답 구조를 직접 해결했다는 뜻은 아니다.

사전 학습 모델과 코드의 공개도 채택을 빠르게 했다. 자체 언어 모델을 훈련하기 어려운 연구자와 조직도 공개 ELMo와 ULMFiT 모델을 사용해 전이 학습의 이점을 얻을 수 있었다. 이는 연구와 응용의 진입 장벽을 낮췄다.

## 한계

큰 영향에도 ELMo와 ULMFiT에는 뒤이은 연구가 다룬 여러 한계가 있었다. ELMo의 양방향 LSTM은 텍스트를 두 방향으로 순차 처리하므로 한 방향 모델보다 계산량이 컸다. 큰 문서나 실시간 응용에서 문맥화 표현을 만드는 속도는 확장성의 제약이 될 수 있었다.

깊은 LSTM 구조를 훈련하는 일도 어렵고 비쌌다. 여러 순환 층을 지나는 그래디언트 흐름은 세심한 초기화와 학습 절차를 요구했다. 층 표현의 가중합은 유연하지만 후속 모델에 통합할 요소도 늘렸다.

ELMo는 정적 임베딩보다 풍부했지만 LSTM의 순차 구조 때문에 매우 긴 의존성과 복잡한 문서 관계를 다루는 데 한계가 있었다. 양방향 문맥이 도움을 주어도 먼 위치 사이 상호작용을 항상 효과적으로 보존하는 것은 아니었다.

ULMFiT는 원 논문에서 텍스트 분류를 중심으로 검증됐다. 질의응답·구조화 예측·생성처럼 출력 형식과 구조가 다른 과제에는 분류기 미세조정 절차를 그대로 적용할 수 없고 과제별 구조가 더 필요했다. 따라서 모든 자연어 처리 과제에 같은 효과가 입증됐다고 일반화하면 안 된다.

두 방법 모두 큰 언어 모델의 사전 학습에 상당한 계산과 말뭉치가 필요했다. 자체 모델을 만들기 어려운 조직은 공개 모델에 의존해야 했고, 공개 모델의 언어나 영역이 목표 응용과 맞지 않을 수 있었다.

전이 학습은 표지 자료 요구를 줄였지만 없애지는 못했다. ELMo를 넣은 후속 모델이나 ULMFiT 분류기를 훈련하려면 과제 라벨이 필요했다. 라벨이 전혀 없거나 극히 적은 과제는 여전히 어려웠다.

언어와 영역의 편중도 문제였다. 대부분의 공개 사전 학습 모델은 영어 중심이었고, 다른 언어에서는 사전 학습 자료량에 따라 전이 품질이 달랐다. 의학·법률·기술 영역은 별도 영역 사전 학습이나 미세조정이 필요할 수 있었다.

두 방법은 모두 LSTM을 사용했으므로 병렬 처리와 계산 효율에 구조적 한계가 있었다. 위치를 차례로 처리해야 해 전체 시퀀스를 병렬로 다루는 Transformer보다 훈련과 추론이 느렸다.

문맥화 표현도 복잡한 의미 관계를 무한히 담지는 못했다. 미세한 화용 차이, 복잡한 추론, 훈련 분포에서 드문 표현은 여전히 어려웠다. 통계적 패턴을 강하게 포착했지만 사람과 같은 언어 이해가 보장되는 것은 아니었다.

## 유산

ELMo와 ULMFiT는 대규모 언어 모델 사전 학습의 지식을 옮기면 후속 과제 성능을 크게 높일 수 있음을 보이며 전이 학습을 현대 자연어 처리의 핵심 패러다임으로 확립했다. 그 성공은 BERT·GPT를 비롯한 Transformer 기반 모델이 확장한 접근의 실행 가능성을 입증했다. 사전 학습 언어 모델을 지식의 원천으로 삼고 후속 과제에 적응시킨다는 원리가 분야의 표준이 됐다.

ELMo는 단어 표현이 문맥에 따라 달라져야 한다는 점을 분명히 보여 주었다. 이후 모델은 LSTM 대신 self-attention을 사용해 더 풍부한 문맥 표현을 만들었지만, 정적 단어 벡터가 아닌 위치별 문맥 의존 은닉 상태라는 생각은 현대 언어 AI의 기본이 됐다.

ULMFiT의 미세조정 방법은 사전 학습 모델을 적응시키는 실무 원칙을 정립했다. 층별 학습률, 점진적 동결 해제, 신중한 학습률 일정은 큰 사전 학습 모델의 지식을 훼손하지 않고 과제에 맞추려는 후속 연구와 계속 연결됐다. 다만 오늘날 Transformer 미세조정의 모든 기법이 ULMFiT에서 직접 유래했다고 단정할 수는 없다.

### 전이 학습 혁명

ELMo와 ULMFiT는 자연어 처리도 과제 전용 모델을 처음부터 훈련하는 방식에서 대규모 비표지 텍스트의 지식을 재사용하는 방식으로 전환할 수 있음을 보였다. 이는 ImageNet 사전 학습이 표준이 된 컴퓨터 비전의 변화와 닮았다. 언어에도 비표지 자료에서 학습해 응용 사이에 옮길 수 있는 일반 패턴이 있다는 실증이었다.

두 방법은 후속 과제의 자료 요구량을 줄였다. 큰 표지 데이터셋을 만들기 어려운 전문 영역과 저자원 환경에서도 고급 자연어 처리 응용을 시도할 수 있게 했다. 다만 감소 폭은 과제·영역·자료에 따라 달랐고 표지 자료 자체가 불필요해진 것은 아니었다.

성공은 더 나은 구조와 학습 절차를 찾는 연구를 촉진했다. BERT는 양방향 문맥 표현을 Transformer와 마스크드 언어 모델링으로 확장했고, GPT 계열은 자기회귀 생성 사전 학습과 과제 적응을 확대했다. 이들은 ELMo나 ULMFiT의 단순한 확대판이 아니라 서로 다른 구조와 목적함수를 사용했지만, 사전 학습 지식을 재사용한다는 문제의식을 공유했다.

현대 언어 모델도 더 큰 자료와 매개변수 규모에서 문맥 표현을 만들고, 여러 방식으로 특정 응용에 적응한다. 규모는 크게 달라졌지만 비표지 또는 자기지도 사전 학습에서 얻은 지식을 후속 과제로 옮긴다는 중심 원리는 남아 있다.

하나의 사전 학습 모델을 여러 과제에 적응시킨다는 생각은 학습과 배포 방식도 바꾸었다. 조직은 과제마다 모든 지식을 처음부터 다시 학습하기보다 공개 또는 자체 사전 학습 모델을 미세조정해 개발 시간과 계산 비용을 줄일 수 있었다.

ELMo와 ULMFiT의 영향은 개별 기법을 넘어 연구 생태계에도 미쳤다. 큰 사전 학습에 투자한 결과물을 공유하면 다양한 연구자와 응용이 이를 재사용할 수 있음을 보여 주었다. 공개 사전 학습 모델을 중심으로 한 생태계가 성장하는 데 중요한 선례가 됐다.

언어 AI가 더 큰 시스템으로 발전한 뒤에도 두 방법이 제시한 질문은 중심에 남아 있다. 일반 말뭉치에서 무엇을 사전 학습할 것인가, 내부 표현을 고정된 특징으로 쓸 것인가 모델 전체를 적응시킬 것인가, 새 과제의 적은 자료로 지식을 훼손하지 않고 어떻게 옮길 것인가 하는 질문이다. ELMo와 ULMFiT는 이 전환이 가능함을 서로 다른 경로로 보여 주었다.

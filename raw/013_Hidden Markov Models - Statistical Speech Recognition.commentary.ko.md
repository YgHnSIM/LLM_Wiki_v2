# 은닉 마르코프 모델과 통계적 음성 인식 해설

## 1. 한눈에 보기

- 핵심 주제: 직접 보이지 않는 상태열과 관측열의 관계를 확률로 표현하는 은닉 마르코프 모델(HMM)
- 등장 배경: 잡음과 화자 변이가 있는 연속 음성을 유한상태 확률 모델과 동적 계획법으로 다루려는 연구
- 가장 중요한 아이디어: 평가, 디코딩, 학습을 서로 구분하고 각각 순방향 계산, 최고 경로 탐색, 매개변수 재추정으로 푼다.
- 이후 LLM/NLP에 남긴 영향: 확률적 수열 모델링과 효율적인 추론이라는 문제 설정은 이어졌지만, HMM에서 RNN·Transformer·LLM으로 곧장 이어지는 단일 계보로 보면 안 된다.

> 이 문서는 `013_Hidden Markov Models - Statistical Speech Recognition.md`의 번역문을 이해하기 위한 해설이다. 원문의 설명을 되풀이하기보다 HMM의 정확한 계산 문제, 음성 인식 도입 시기, 후대 신경망과 비교할 때 필요한 한계를 정리한다.

## 2. 핵심 요약

HMM은 관측할 수 없는 상태가 시간에 따라 전이하고, 각 상태가 관측값을 확률적으로 방출한다고 가정하는 생성 확률 모델이다. 표준적인 설명은 모델이 관측열에 부여하는 가능도를 계산하는 평가, 가장 좋은 상태 경로를 찾는 디코딩, 관측 자료에서 매개변수를 재추정하는 학습의 세 문제를 구분한다. 각각 순방향 알고리즘, 비터비 알고리즘, Baum–Welch 알고리즘과 연결된다. HMM의 수학적 기반은 1960년대 중반의 Baum–Petrie 연구와 1970년 전후의 후속 논문에 놓여 있으며, 음성 인식 적용이 뚜렷해진 것은 1970년대 중반이다. 따라서 “1970년대에 HMM이 발명되어 곧바로 음성 인식을 혁명화했다”는 한 문장으로 기원과 적용을 합치지 않는 편이 정확하다. HMM 음성 인식은 데이터에서 확률을 추정했지만, 음향 특징·상태 토폴로지·발음 사전·언어 모델 같은 설계 요소를 여전히 필요로 했다. 현대 신경망과 LLM도 확률 분포를 다루지만 표현, 목적 함수, 추론 구조가 다르므로 HMM의 직접 후손이라고 단정할 수 없다.

- 무엇을 모델링하는가: 은닉 상태열과 관측열의 결합 확률
- 어떤 문제를 해결하려 했는가: 잡음과 변이가 있는 순차 관측에서 가능도와 상태 경로를 계산하고 매개변수를 학습하는 문제
- 어떤 방식이 새로웠는가: 모든 상태 경로를 열거하지 않고 동적 계획법과 확률 재추정으로 계산을 공유하는 방식
- 결과적으로 무엇이 바뀌었는가: 특히 음성 인식에서 통계적 모델링과 데이터 기반 매개변수 추정이 중심 도구로 자리 잡았다.

## 3. 역사적 배경

마르코프 연쇄는 HMM보다 앞선 수학적 전통이다. 은닉된 유한상태 마르코프 과정의 통계적 성질과 매개변수 추정은 Leonard E. Baum과 Ted Petrie가 1966년에 다루었고, Baum과 동료들은 1970년에 확률 함수의 최대화와 재추정 공식을 제시했다. Andrew Viterbi의 1967년 알고리즘은 길쌈 부호 복호를 위해 제안되었으며 처음부터 음성 인식용으로 개발된 것은 아니다. 이 동적 계획법이 후에 유한상태 마르코프 모델의 최고 경로 계산으로 해석되고 음성 인식에 널리 쓰였다.

1970년대 중반의 음성 인식 연구에서는 확률 음향 모델, 언어 모델, 가설 탐색이 결합되었다. 이 시기를 “규칙이 통계로 단번에 교체된 때”라고 부르기보다는, 템플릿 정합·음향 처리·어휘 지식·확률 추정·탐색이 서로 다른 속도로 재구성된 시기로 보는 편이 낫다. HMM 기반 시스템도 음소나 단어를 완전히 자동으로 발견한 것이 아니라 사람이 정한 단위와 구조, 전사 자료, 특징 표현을 사용했다.

- 이전 접근법: 템플릿 정합, 동적 시간 정합, 유한상태 모델, 음향·언어 지식의 수작업 설계
- 당시의 한계: 화자와 발음의 변이, 연속 음성의 분절, 큰 탐색 공간, 제한된 학습 자료와 계산 자원
- HMM이 필요했던 이유: 잡음이 있는 시간 관측과 잠재 상태 사이의 불확실성을 하나의 확률 모형 안에서 계산하기 위해서다.

## 4. 핵심 개념 해설

### 4.1 상태, 관측, 두 가지 조건부 독립 가정

HMM은 초기 상태 확률, 상태 전이 확률, 상태별 관측 방출 확률로 표현된다. 1차 HMM의 상태 전이는 현재 상태가 직전 상태에만 의존한다고 가정한다. 여기에 더해 현재 관측은 현재 상태가 주어지면 다른 상태와 관측으로부터 조건부 독립이라고 가정한다. 원문은 주로 첫 번째 가정만 강조하지만, 두 번째 가정도 표준 HMM의 구조와 한계를 이해하는 데 중요하다. 음성 인식의 상태는 흔히 문맥 의존 음소나 그보다 작은 음향 단위에 대응하도록 설계된 모델 변수이며, 성도나 뇌에 존재하는 소리를 문자 그대로 가리키는 것은 아니다.

### 4.2 평가, 디코딩, 학습

평가는 관측열의 확률을 모든 상태 경로에 걸쳐 합산하는 문제이며 순방향 알고리즘으로 계산할 수 있다. 디코딩은 관측열에 가장 높은 확률을 부여하는 단일 상태 경로를 찾는 문제이며 비터비 알고리즘이 대표적이다. 학습은 관측 자료에서 전이와 방출 매개변수를 조정하는 문제이며, 순방향-역방향 계산을 사용하는 Baum–Welch 재추정이 대표적이다. 세 계산은 모두 동적 계획법으로 부분 문제를 재사용하지만 결과의 의미는 서로 다르다.

### 4.3 최고 경로, 주변 확률, 학습의 한계

비터비 결과는 가장 좋은 경로 하나이지 가능한 경로 전체의 사후분포가 아니다. 각 시점 상태의 주변 사후확률이나 충분통계량이 필요하면 순방향-역방향 계산을 사용한다. 따라서 날씨 예에서 “비터비 알고리즘이 전체 날씨 상태열 분포를 계산한다”고 표현하면 두 계산을 섞는 셈이다. 또한 어떤 경로가 최고인지는 전이·방출 확률뿐 아니라 초기 상태 확률에도 달려 있다. Baum–Welch는 반복할 때 관측 가능도를 감소시키지 않지만, 전역 최적해를 보장하지 않고 정지점이나 국소해에 도달할 수 있다.

## 5. 원문의 논리 구조

원문은 대체로 다음 흐름으로 전개된다.

1. 관측 가능한 출력과 보이지 않는 상태를 구분하는 문제를 제시한다.
2. 상태 전이와 방출 확률로 이루어진 HMM 구조를 설명한다.
3. 평가·디코딩·학습이라는 세 계산 문제와 대표 알고리즘을 소개한다.
4. 날씨와 옷차림 예로 추론 과정을 직관적으로 설명한다.
5. HMM이 음성 인식과 NLP에서 규칙 중심 접근을 통계 중심 접근으로 바꾸었다고 주장한다.
6. 마르코프 가정, 특징 공학, 국소 최적점, 생성 모델의 한계를 제시한다.
7. HMM에서 RNN과 Transformer로 이어지는 개념적 연속성을 강조한다.

이 흐름은 입문 설명으로 이해하기 쉽지만, 기원과 음성 응용의 연대를 합치고 비터비와 순방향-역방향의 역할을 섞으며, HMM과 현대 신경망 사이의 유사성을 직접 계보처럼 제시하는 부분은 비판적으로 읽어야 한다.

## 6. 왜 중요한가

HMM의 중요성은 “확률을 처음 사용했다”는 데 있지 않다. 더 정확히는 잠재 상태가 있는 순차 모형에서 가능도 계산, 최고 경로 탐색, 매개변수 재추정을 계산 가능한 절차로 조직했고, 이 절차가 음성 인식 같은 실제 시스템에 들어갔다는 데 있다. HMM은 불확실한 관측을 하나의 결정적 규칙으로 환원하지 않고 후보와 경로에 확률을 부여할 수 있게 했다.

특히 중요한 점은 다음과 같다.

- 순차 확률 모델의 추론과 학습을 명시적인 계산 문제로 분리했다.
- 동적 계획법으로 지수적으로 많은 상태 경로의 합이나 최댓값을 다항 시간에 계산할 수 있게 했다.
- 음향 모델, 발음 사전, 언어 모델, 탐색을 결합한 통계적 음성 인식 구조의 핵심 구성 요소가 되었다.

## 7. 현대 LLM과의 연결

HMM과 LLM은 둘 다 순차 자료에 확률을 부여하고 불확실성을 수치화한다는 넓은 공통점이 있다. 하지만 HMM은 유한한 잠재 상태와 조건부 독립 가정을 둔 생성 모형인 반면, Transformer 언어 모델은 자기어텐션과 고차원 연속 표현으로 문맥에 따른 다음 토큰 분포를 학습한다. 따라서 두 모델의 관계는 “확률적 언어 처리라는 넓은 전통에서 비교할 수 있다”는 수준으로 설명하는 것이 안전하다.

- 확률적 예측: HMM은 상태 전이와 방출 분포를, LLM은 문맥에 따른 토큰 분포를 계산한다.
- 잠재 표현: HMM의 이산 상태와 신경망의 연속 은닉 표현은 모두 직접 관측되지 않지만, 수학적 역할과 학습 방식은 다르다.
- 효율적 계산: HMM의 순방향·비터비 계산과 Transformer의 행렬 연산은 모두 구조를 이용해 계산을 줄이지만 같은 알고리즘의 연장선은 아니다.

RNN의 시간 역전파(backpropagation through time)는 미분 가능한 순환 계산 그래프에 기울기를 전파하는 훈련법이다. HMM의 순방향-역방향 알고리즘은 상태열의 확률과 기대 통계를 계산한다. 둘 다 앞뒤 방향의 계산을 사용한다는 표면적 유사성은 있지만 “직접 대응한다”고 말할 정도로 같은 절차는 아니다.

## 8. 한계와 비판적 관점

- 기술적 한계: 1차 상태 전이와 관측 조건부 독립 가정은 실제 음향·언어의 장거리 의존성과 상관을 충분히 담지 못할 수 있다.
- 이론적 한계: 상태의 의미와 수는 모델 밖에서 설계하는 경우가 많고, 학습 결과가 언어학적 실체를 자동으로 발견했다는 보장은 없다.
- 실용적 한계: 특징, 상태 토폴로지, 발음 사전, 학습 자료, 초기화와 탐색 폭이 성능에 큰 영향을 준다.
- 오늘날의 관점에서 다시 볼 점: 표준 HMM도 연속 관측값에 대한 밀도 모형을 둘 수 있다. 가우시안·가우시안 혼합 방출은 연속 신호를 다루는 대표 구현이지, HMM 이론과 본질적으로 맞지 않는 임시방편은 아니다.

원문의 계보 서술도 조정할 필요가 있다. HMM은 1970년대에 발명된 것이 아니라 1960년대부터 수학적으로 발전했고, 음성 인식 적용이 1970년대 중반에 확산했다. 초기 음성 인식이 모두 수작업 언어 규칙이었던 것도 아니며, HMM 시스템도 데이터만 바꾸면 자동으로 새 억양·도메인에 적응한 것이 아니다. MFCC, 문맥 의존 상태, GMM, 신경망-HMM 하이브리드는 서로 다른 시기의 후속 기술이다. 품사 태깅은 분명한 HMM 응용이지만, 개체명 인식과 기계 번역은 특정 모델과 시기를 밝혀야 하며 기계 번역에서는 HMM 계열 단어 정렬 같은 제한된 용례로 표현하는 편이 정확하다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 은닉 상태(hidden state) | 관측되지 않으며 시간에 따라 전이한다고 모델이 가정하는 이산 변수 |
| 방출 확률(emission probability) | 현재 은닉 상태에서 특정 관측값이 나올 확률 또는 확률 밀도 |
| 순방향 알고리즘(forward algorithm) | 가능한 상태 경로를 합산하여 관측열의 가능도를 계산하는 동적 계획법 |
| 비터비 알고리즘(Viterbi algorithm) | 관측열에 대해 점수가 가장 높은 단일 상태 경로를 찾는 동적 계획법 |
| Baum–Welch 알고리즘 | 순방향-역방향 기대 통계를 이용해 HMM 매개변수를 반복 재추정하는 EM 계열 방법 |
| 관측 조건부 독립 | 현재 상태가 주어지면 현재 관측이 다른 상태·관측과 독립이라는 표준 HMM의 가정 |

## 12. 짧은 결론

HMM은 은닉 상태가 있는 수열에서 확률, 경로, 매개변수를 효율적으로 계산하는 방법을 정립했고 통계적 음성 인식의 핵심 도구가 되었다. 그 역사적 의미는 규칙을 한순간에 없앴거나 현대 LLM을 직접 낳았다는 데 있지 않다. 확률 모델, 데이터 추정, 동적 계획법, 사람이 설계한 표현을 실제 시스템 안에서 결합한 중요한 단계였다는 데 있다.

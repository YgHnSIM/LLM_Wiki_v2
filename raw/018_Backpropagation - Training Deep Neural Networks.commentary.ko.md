# 역전파와 심층 신경망 훈련 해설

## 1. 한눈에 보기

- 핵심 주제: 신경망의 손실을 각 매개변수로 미분한 그래디언트를 출력에서 입력 방향으로 효율적으로 계산하는 역전파
- 등장 배경: 다층 구조 자체는 존재했지만, 은닉층의 가중치가 최종 오류에 얼마나 기여했는지 계산하고 조정하는 일반적 절차가 널리 쓰이지 못하던 시기
- 가장 중요한 아이디어: 계산 그래프에 연쇄 법칙을 역방향으로 적용하면 중간 결과를 재사용하면서 모든 가중치의 그래디언트를 구할 수 있다.
- 이후 LLM/NLP에 남긴 영향: 현대 신경 언어 모델의 사전 학습과 미세조정에도 역전파가 쓰이지만, Transformer와 LLM의 성립은 구조·목표 함수·최적화·데이터·하드웨어가 함께 만든 결과다.

> 이 문서는 018_Backpropagation - Training Deep Neural Networks.md의 번역문을 이해하기 위한 해설이다. 번역문은 원문의 강한 역사적·인과적 표현까지 충실히 보존한다. 해설에서는 1986년 논문의 실제 위치, 역전파와 경사 하강법의 차이, 현대 LLM과의 연결 범위를 사실과 해석으로 나눠 살펴본다.

## 2. 핵심 요약

역전파는 신경망의 각 가중치가 손실에 미치는 민감도, 즉 그래디언트를 효율적으로 계산하는 절차다. 순전파에서 저장한 중간 활성화 값을 이용하고, 출력 쪽 미분값에서 시작해 연쇄 법칙을 역방향으로 적용한다. 계산된 그래디언트를 실제 가중치 변경으로 바꾸는 일은 경사 하강법·SGD·Adam 같은 최적화기가 맡으므로 역전파와 최적화는 같은 말이 아니다. Rumelhart·Hinton·Williams의 1986년 논문은 은닉 유닛이 과제에 유용한 내부 표상을 학습하는 모습을 간결하게 보여 주고 이 절차를 널리 알린 중요한 논문이다. 그러나 역방향 자동 미분과 신경망 학습에 관한 선행 연구가 있었으므로 1986년을 단일 발명 시점으로 두지 않는다. 다층 신경망도 1986년에 처음 등장한 것이 아니며, 중요한 변화는 다층 구조의 모든 미분 가능한 매개변수에 오류 정보를 체계적으로 전달할 수 있게 된 데 있다. 역전파는 이후 신경망 훈련의 핵심 도구가 됐지만 그래디언트 소실·폭주, 메모리와 계산 비용, 일반화, 목표 함수 설계까지 자동으로 해결하지는 않는다.

- 무엇을 다루는가: 연쇄 법칙, 순전파, 역방향 자동 미분, 그래디언트, 손실 함수, 가중치 갱신
- 어떤 문제를 해결하려 했는가: 출력 오류를 은닉층과 개별 가중치에 효율적으로 배분하는 신용 할당 문제
- 어떤 방식이 새로웠는가: 중간 계산을 재사용해 많은 매개변수의 미분을 한 번의 역방향 순회로 계산하고, 내부 표상 학습을 실용적인 절차로 제시했다.
- 결과적으로 무엇을 바꾸었는가: 다양한 미분 가능 신경망을 하나의 목적 함수에 맞춰 종단 간 훈련할 수 있는 공통 계산 기반을 제공했다.

## 3. 역사적 배경

사실: 퍼셉트론의 오차 수정 규칙과 Widrow–Hoff 계열의 학습은 1986년보다 앞섰고, MADALINE처럼 여러 적응 선형 요소를 결합한 구조도 이미 존재했다. 다만 초기 다층 시스템의 모든 층을 오늘날과 같은 단일 역전파 절차로 공동 훈련한 것은 아니었다. 원문도 Seppo Linnainmaa의 1970년대 자동 미분 연구와 Paul Werbos의 선행 작업을 언급한다. Rumelhart·Hinton·Williams가 1986년 Nature에 발표한 「Learning representations by back-propagating errors」는 은닉 유닛을 포함한 네트워크의 가중치를 반복 갱신해 내부 표상을 학습하는 절차를 널리 알렸다.

사실: 이 연구와 연결된 1985년 기술 보고서와 1986년 장의 실험은 XOR·패리티·부호화·대칭성·이진 덧셈·문자 판별 같은 소규모 합성 과제가 중심이었다. 은닉 표상 학습의 가능성을 보여 준 중요한 시연이지만, 그 자체가 대규모 음성·비전·NLP 응용의 즉각적인 실용성을 입증한 것은 아니다. 역전파를 이용한 실제 손글씨 우편번호 인식 같은 더 뚜렷한 응용 사례는 1989년 LeCun 등의 후속 연구에서 확인된다.

해석: 따라서 “1986년에 역전파가 처음 발명됐다”보다 “1986년 논문이 다층 신경망 학습의 강력한 시연과 대중화를 이끌었다”가 더 안전하다. 또한 이 논문 하나로 심층 학습의 모든 실용 문제가 해결된 것도 아니다. 이후의 활성화 함수, 초기화, 확률적 최적화, 합성곱·순환·잔차·어텐션 구조, 정규화, 대규모 데이터와 병렬 하드웨어가 서로 다른 시기에 결합됐다.

- 이전 접근법: 퍼셉트론 학습, 델타 규칙, 층별 또는 제한된 구조의 학습, 수치 미분과 탐색
- 당시의 한계: 은닉층의 각 매개변수와 최종 손실 사이의 기여도를 효율적으로 계산하기 어려웠다.
- 이 주제가 필요했던 이유: 다층 구조의 표현 능력을 실제 학습 가능한 시스템으로 바꾸려면 전체 네트워크에 오류 정보를 전달할 방법이 필요했다.

## 4. 핵심 개념 해설

### 4.1 연쇄 법칙과 역방향 자동 미분

신경망의 순전파는 입력에서 출력으로 이어지는 합성 함수다. 연쇄 법칙은 합성 함수의 미분을 각 연산의 국소 미분을 곱한 형태로 분해한다. 역전파는 출력의 손실에서 시작해 이 국소 미분을 거꾸로 결합한다. 여러 매개변수가 같은 중간 계산을 공유할 때 그 값을 다시 계산하지 않고 저장한 결과를 재사용하므로, 매개변수마다 순전파를 새로 수행하는 방식보다 효율적이다. 오늘날의 자동 미분 프레임워크는 이 원리를 일반 계산 그래프에 적용한다.

원문의 “선형 시간”은 무엇에 대해 선형인지 정의하지 않아 그대로 일반화하면 부정확하다. 고정된 순방향 계산 그래프에서 각 연산의 국소 미분을 한 번씩 처리한다는 조건에서는 역방향 패스의 계산량이 순전파와 같은 점근적 차수이며 보통 비슷한 상수배 규모다. 이는 모든 모델의 훈련 시간이 층 수·매개변수 수·데이터 크기 가운데 어느 하나에 보편적으로 선형이라는 뜻이 아니며, 중간 활성화를 저장하는 메모리 비용도 함께 든다.

### 4.2 신용 할당과 최적화의 구분

신용 할당은 어느 내부 변수와 가중치가 최종 오류에 얼마나 영향을 주었는지 묻는 문제다. 역전파는 각 가중치에 대한 손실의 편미분으로 이 질문에 국소적인 답을 준다. 그러나 그래디언트를 계산했다고 훈련 전략이 모두 정해지는 것은 아니다. 학습률, 모멘텀, 미니배치, Adam, 가중치 감쇠 같은 규칙은 그래디언트를 이용해 실제 매개변수 이동을 결정한다. 역전파는 미분 계산이고 경사 하강법은 그 미분을 사용하는 최적화 절차라는 구분이 중요하다.

### 4.3 내부 표상과 원문 수식

은닉층은 정답 특징 목록을 직접 받기보다 목적 함수에 유리한 중간 표상을 학습할 수 있다. 이것이 1986년 논문이 강조한 중요한 결과다. 다만 원문의 감정 분석, 0과 1 사이의 확률, 제곱 오차는 학습 과정을 설명하기 위한 단순화된 예다. 실제 분류에서는 출력 함수와 손실 함수의 선택이 달라질 수 있다. 또한 번역문 수식에 wijw_{ij}wij​처럼 같은 기호가 여러 형식으로 겹쳐 보이는 부분은 웹 원문의 렌더링 문자열이 중복된 결과다. 번역에서는 원문 보존 원칙에 따라 고치지 않았으며, 의미상으로는 가중치 w_{ij}, 활성화 a_j, 가중 입력 z_j에 대한 연쇄 법칙을 나타낸다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개된다.

1. 1986년 논문을 심층 신경망 훈련의 결정적 전환점으로 제시한다.
2. 출력 오류를 내부 연결에 배분하는 신용 할당 문제를 설명한다.
3. 순전파·손실 계산·역방향 패스·가중치 갱신의 네 단계와 연쇄 법칙을 소개한다.
4. 감정 분석 예시와 수식을 통해 그래디언트 계산 및 경사 하강 갱신을 풀어낸다.
5. 다층 표상 학습의 응용, 한계, 현대 언어 AI와의 계보를 폭넓게 주장한다.

원문 앞부분은 알고리즘 설명이고 뒷부분은 역사적 영향에 관한 해석이 강하다. 특히 “처음”, “모든”, “직접 계보”, “없었다면 존재하지 않는다” 같은 표현은 번역에서는 그대로 두되 사실 검증에서는 별도의 근거가 필요한 주장으로 읽어야 한다.

## 6. 왜 중요한가

역전파의 핵심 가치는 특정 신경망 구조 하나가 아니라 미분 가능한 계산을 학습 가능한 시스템으로 바꾸는 재사용 가능한 방법을 제공했다는 데 있다. 층이 여러 개여도 국소 연산의 미분을 연결해 전체 목적 함수의 그래디언트를 계산할 수 있으므로, 사람이 각 층의 학습 규칙을 따로 설계하지 않고도 공동 최적화가 가능해졌다.

특히 중요한 점:

- 내부 표상 학습: 은닉 유닛이 최종 과제에 유용한 특징을 데이터에서 형성할 수 있게 했다.
- 계산 재사용: 역방향 자동 미분은 모든 매개변수의 그래디언트를 효율적으로 모은다.
- 구조의 범용성: 순방향망뿐 아니라 합성곱망, 순환망, Transformer 등 다양한 미분 가능 구조에 같은 원리를 적용할 수 있다.

다만 “역전파가 어떤 응용을 혼자 가능하게 했다”는 인과 표현은 조심해야 한다. 데이터, 목적 함수, 구조, 최적화 안정성, 계산 장치와 평가 자료가 함께 갖춰져야 실제 성능으로 이어진다.

## 7. 현대 LLM과의 연결

현대 Transformer 언어 모델은 사전 학습 손실을 계산하고, 그 손실의 그래디언트를 역전파해 수많은 매개변수를 갱신한다. 지도 미세조정과 여러 선호 최적화 절차도 미분 가능한 목적 함수를 사용할 때 역전파에 의존한다. 이 의미에서 역전파는 현대 신경 언어 모델 훈련의 핵심 계산 도구다.

- 사전 학습: 다음 토큰 예측이나 마스크드 토큰 예측 손실을 네트워크 전체로 역전파한다.
- 미세조정: 이미 학습한 매개변수를 더 작은 데이터와 학습률로 특정 과제나 지시 형식에 맞춘다.
- 추론: 일반적인 텍스트 생성 시에는 순전파로 출력을 계산하며, 보통 매 토큰마다 가중치를 역전파해 갱신하지 않는다.

이 연결을 직접적인 단일 계보로 과장하지 않는다. 역전파만으로 어텐션, Transformer, 토큰화, 사전 학습 목표, 스케일링 법칙이 도출된 것은 아니다. 1986년 논문은 현대 LLM이 사용하는 핵심 훈련 도구의 중요한 이정표지만, 현대 언어 AI 전체의 유일한 기원은 아니다. 통계 언어 모델과 기호적·지식 기반 NLP도 서로 다른 계열로 발전했다.

## 8. 한계와 비판적 관점

- 기술적 한계: 깊은 계산 경로에서는 그래디언트가 소실되거나 폭주할 수 있고, 역전파를 위해 중간 활성화 값을 저장해야 하므로 메모리 비용도 크다.
- 이론적 한계: 그래디언트는 현재 지점의 국소 변화 방향을 알려 줄 뿐 전역 최적해, 인과적 설명, 의미 이해를 보장하지 않는다.
- 실용적 한계: 데이터 품질, 목표 함수, 초기화, 정규화, 계산 예산에 따라 같은 구조도 크게 다른 결과를 낸다.
- 오늘날 관점에서 다시 봐야 할 점: 고차원 비볼록 최적화에서는 나쁜 국소 최솟값뿐 아니라 안장점, 평평한 영역, 최적화 경로가 중요하다. 원문의 국소 최솟값 설명은 입문용 직관으로 읽는 편이 좋다.

역사 서술에도 한계가 있다. 다층망은 1986년 이전에도 존재했고, 역전파의 수학적·자동 미분 계보 역시 더 오래됐다. 1986년 논문 이후에도 HMM과 통계적 방법은 음성 인식과 NLP에서 오랫동안 중심적이었다. 따라서 “즉시 모든 분야가 신경망으로 전환됐다”거나 “역전파가 문제를 완전히 해결했다”고 요약하지 않는다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 역전파(backpropagation) | 출력 손실에서 시작해 계산 그래프를 거꾸로 순회하며 각 매개변수의 그래디언트를 계산하는 절차 |
| 순전파(forward pass) | 입력으로부터 층별 중간값과 최종 예측·손실을 계산하는 과정 |
| 그래디언트(gradient) | 각 매개변수의 작은 변화에 따라 손실이 어떻게 변하는지를 모은 미분값 |
| 신용 할당(credit assignment) | 최종 결과의 공로와 오류를 내부 구성 요소에 어떻게 배분할지 묻는 문제 |
| 연쇄 법칙(chain rule) | 합성 함수의 미분을 국소 미분의 곱으로 연결하는 미적분 원리 |
| 손실 함수(loss function) | 모델 출력과 목표 사이의 차이를 최적화 가능한 수치로 표현한 함수 |
| 최적화기(optimizer) | 그래디언트와 상태를 사용해 실제 매개변수 갱신량을 정하는 규칙 |
| 그래디언트 소실 | 깊은 경로에서 반복 곱셈으로 그래디언트가 매우 작아지는 현상 |

## 12. 짧은 결론

역전파는 다층 신경망의 손실을 각 매개변수와 연결해 내부 표상을 공동으로 학습하게 한 핵심 계산 절차다. Rumelhart·Hinton·Williams의 1986년 논문은 이 방법의 효용을 선명하게 보여 주고 널리 확산시킨 중요한 이정표다. 그러나 역전파의 수학적 선행 계보와 1986년 이전 다층망을 지우거나, 그 논문 하나가 딥러닝의 모든 난제를 해결하고 현대 LLM을 직접 낳았다고 말해서는 안 된다. 오늘날 LLM은 여전히 역전파로 훈련되지만, 그 성립은 수십 년 동안 축적된 구조·최적화·데이터·하드웨어의 결합으로 이해해야 한다.

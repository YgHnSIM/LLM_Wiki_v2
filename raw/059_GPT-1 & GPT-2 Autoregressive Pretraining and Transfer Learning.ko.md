# GPT-1과 GPT-2: 자기회귀 사전 학습과 전이 학습

출처: https://mbrenndoerfer.com/writing/gpt1-gpt2-autoregressive-pretraining-transfer-learning

---

OpenAI의 GPT-1과 GPT-2를 종합적으로 설명한다. Transformer의 자기회귀 사전 학습이 여러 자연어 처리 과제로 전이된 방식, 규모 증가와 함께 관찰된 zero-shot 수행, 현대 언어 AI의 기반에 미친 영향을 살펴본다.

## 2018년: GPT-1과 GPT-2

OpenAI가 2018년 GPT-1, 2019년 GPT-2를 발표한 일은 자연어 처리의 중요한 전환이었다. 큰 텍스트 말뭉치로 사전 학습한 자기회귀 언어 모델이 과제 전용 구조를 크게 바꾸지 않고도 여러 자연어 처리 과제에 적용될 수 있음을 보여 주었다. GPT는 Generative Pre-trained Transformer의 약자다. 하나의 생성 언어 모델을 비표지 텍스트에서 먼저 학습하고 후속 과제에 적응시키는 접근은 연구자가 자연어 처리 문제를 설계하는 방식에 영향을 주었다.

2018년 무렵 Transformer는 기계 번역에서 효과를 보였지만 다른 응용은 여전히 과제별 구조와 훈련 절차를 많이 사용했다. 질의응답·감성 분석·텍스트 분류마다 별도 표지 자료와 구조 선택이 필요했다. 컴퓨터 비전에서는 ImageNet 사전 학습 모델을 여러 과제에 미세조정하는 방법이 자리 잡았지만 언어에서는 대응하는 일반 방법이 아직 널리 입증되지 않았다.

GPT-1은 Transformer가 가변 길이 sequence와 먼 의존성을 다루는 능력을 일반 언어 표현의 기반으로 사용했다. 앞의 모든 token에서 다음 token을 예측하는 단순한 목적을 BookCorpus에 적용했다. 다음 token을 잘 예측하려면 구문·의미·문맥의 통계적 패턴을 배워야 했고, 내부 표현은 후속 과제에 유용했다.

핵심은 구조나 목적 하나뿐 아니라 비지도 사전 학습 뒤 지도 미세조정이라는 두 단계였다. GPT-1은 다양한 책에서 사전 학습한 모델을 최소한의 과제별 입력 변환과 출력층으로 미세조정해 강한 결과를 얻었다. 과제별 모델을 무작위 초기화에서 훈련하는 것보다 적은 구조 변경으로 지식을 옮겼다.

GPT-2는 2019년에 규모와 자료를 크게 늘렸다. 가장 큰 모델은 15억 개 매개변수를 가졌고 WebText라는 더 크고 다양한 웹 문서 집합에서 훈련됐다. 별도 과제 미세조정 없이도 언어 모델 과제, 독해·번역·요약·질의응답에서 어느 정도 수행이 나타났다. 규모 증가와 다양한 사전 학습 자료에서 과제 형식이 언어 모델링 안에 포함될 수 있다는 관찰은 후대 대규모 언어 모델 연구를 예고했다. 그러나 당시 zero-shot 결과가 모든 과제의 지도 최고 성능에 근접한 것은 아니었다.

## 문제

2018년 자연어 처리 연구에는 과제 전용 모델 설계와 일반 언어 능력 사이의 간극이 있었다. 감성 분석, 기계 번역, 질의응답은 서로 다른 구조와 학습 절차를 사용했고, 각 과제마다 데이터셋·입력 표현·출력층을 따로 설계했다.

이 방식은 여러 문제를 낳았다. 첫째, 과제마다 많은 표지 자료가 필요했다. 감성 분류에는 감성 라벨 문장, 질의응답에는 사람이 만든 질문–답 쌍이 필요했다. 새 과제가 생기면 자료 수집과 구조 설계를 다시 시작해야 했다.

둘째, 한 과제에서 배운 지식을 다른 과제로 쉽게 옮기지 못했다. 감성 분류 모델의 표현을 질의응답이 자동으로 재사용하지 못했고, 개체명 인식 모델이 요약을 직접 돕지 않았다. 공통 언어 지식을 과제마다 다시 학습하는 계산과 자료 낭비가 생겼다.

셋째, 좁은 벤치마크에 최적화한 모델은 입력 형식이나 영역이 조금만 바뀌어도 약해질 수 있었다. 영화 리뷰 감성 분류기가 뉴스나 이메일의 표현에 일반화하지 못하는 것처럼 표지 분포에 강하게 묶였다.

Transformer는 번역에서 가능성을 보였지만 다른 자연어 처리 과제에서는 여전히 과제별 encoder·decoder와 결합 구조를 설계했다. 하나의 사전 학습 Transformer가 여러 과제의 공통 기반이 될 수 있다는 생각은 아직 폭넓게 실증되지 않았다.

자연어 처리의 전이 학습도 제한적이었다. Word2Vec과 GloVe는 단어 수준 지식을 전달했지만 문장·문서의 문맥 표현 전체를 옮기지는 않았다. 큰 비표지 말뭉치에서 어떤 목적과 구조를 학습해야 다양한 후속 과제에 유용한 표현을 얻을지 확인할 필요가 있었다.

## 해법

GPT-1은 Transformer 기반 언어 모델을 큰 비표지 corpus에서 자기회귀 목적으로 사전 학습하고, 같은 모델을 최소한의 과제별 변경으로 지도 미세조정하는 방법을 제안했다. 사전 학습 지식을 여러 자연어 처리 응용으로 옮겨 과제별 자료와 구조 요구를 줄였다.

GPT-1은 Transformer의 masked self-attention stack을 사용했다. 흔히 decoder-only라고 부르지만 원 Transformer decoder의 encoder–decoder cross-attention을 제거한, causal self-attention 중심의 구조다. 각 위치는 앞선 위치만 볼 수 있으므로 다음 token 예측과 왼쪽에서 오른쪽 생성에 맞는다.

여러 층에서 self-attention과 feed-forward network를 반복했다. 각 위치는 앞선 모든 위치에 직접 attention할 수 있어 순환 신경망보다 먼 의존성을 짧은 계산 경로로 연결했다. multi-head attention은 여러 관계를 병렬로 표현했고 layer normalization과 residual connection은 학습을 안정화했다.

사전 학습 목적은 간단했다. token sequence $x_1,\ldots,x_n$에서 각 위치의 다음 token 조건부 확률을 최대화한다.

$$
L_1(\mathcal{U})=\sum_i\log P(x_i\mid x_{i-k},\ldots,x_{i-1};\Theta).
$$

이 자기회귀 목적은 모델이 앞 문맥에서 다음 단위를 예측하도록 한다. 정확한 예측에는 구문·의미·담화와 말뭉치에 나타난 사실적 연관의 통계가 도움이 된다. 그렇다고 다음 token 예측만으로 참·거짓 검증이나 사람과 같은 이해가 자동 보장되는 것은 아니다.

GPT-1은 Toronto BookCorpus의 7천 권이 넘는 미출간 책을 사용했다. 긴 연속 텍스트가 있어 장거리 정보 학습에 적합하다고 보았다. 약 1억 1천7백만 개 매개변수의 12층 Transformer를 사전 학습했다.

핵심은 미세조정이었다. 후속 과제에서는 입력을 하나의 token sequence로 바꾸고 마지막 Transformer block 위에 선형 출력층을 추가했다. 분류 손실과 보조 언어 모델 손실을 함께 사용해 전체 매개변수를 갱신했다. 보조 LM 손실은 지도 과제 적응 중 사전 학습 표현을 유지하고 일반화를 돕는 역할을 했다.

### 과제별 입력 형식

GPT-1은 같은 모델에 구조화된 입력을 연속 token sequence로 제시했다. 문장 쌍 과제는 premise와 hypothesis를 delimiter로 잇고, 유사도 과제는 두 순서를 각각 처리해 표현을 합쳤다. 다지선다형 과제는 context와 각 답 후보를 이어 각 후보 점수를 계산했다. 텍스트 분류는 입력 앞뒤에 start·extract delimiter를 배치했다. 이는 완전히 task-agnostic한 원시 입력이 아니라 과제 구조를 token 형식으로 변환한 것이다.

사전 학습 표현은 강한 초기값을 제공했고, 아래층의 형태·순서·구문 패턴과 위층의 더 추상적 관계가 후속 과제에 적응할 수 있었다. 그러나 층 기능이 고정적으로 분리된다는 뜻은 아니다.

GPT-2는 이 접근의 규모를 크게 늘렸다. 2019년 가장 큰 모델은 48층·15억 매개변수였고, GPT-1의 약 1억 1천7백만에서 크게 증가했다. WebText는 Reddit에서 일정 수준 이상의 반응을 받은 외부 링크를 따라 수집한 약 8백만 문서, 약 40GB text로 구성됐다. Wikipedia 문서는 training set에서 제거하려 했다.

구조는 GPT-1과 비슷했지만 layer normalization을 각 sub-block 입력 쪽으로 옮기고 마지막에 layer normalization을 추가했다. 깊이에 따라 residual 경로의 초기화를 조정했고, context 길이를 512에서 1024 token으로 늘렸다. byte-level BPE를 사용해 큰 Unicode 문자열 공간을 고정 vocabulary로 다뤘다.

GPT-2의 중요한 차이는 zero-shot 평가였다. GPT-1은 주로 표지 자료로 미세조정했지만 GPT-2 논문은 언어 모델링 자체에 여러 과제가 포함돼 있다는 가설을 시험했다. 번역에는 언어 쌍 형식, 요약에는 `TL;DR:`, 질의응답에는 document·question 형식처럼 과제에 맞춘 자연어 cue를 사용하고 매개변수는 갱신하지 않았다.

zero-shot 수행은 사전 학습 corpus에 여러 task 설명과 예시 형식이 자연스럽게 들어 있을 수 있다는 생각에서 나왔다. 모델은 text continuation을 학습하는 동안 번역쌍·질문과 답·요약 표기 같은 패턴도 보았을 가능성이 있다. 다만 GPT-2 논문은 현대의 instruction tuning이나 광범위한 few-shot in-context learning을 확립한 연구는 아니며, 과제별 cue와 평가 절차를 사용한 초기 실험이다.

## 응용과 영향

GPT-1은 자연어 추론, 질의응답, 의미 유사도, 텍스트 분류 등 12개 데이터셋을 평가했고 9개에서 당시 최고 성능을 유의하게 개선했다고 보고했다. 과제별 구조를 깊게 새로 만들지 않고 입력 변환과 작은 출력층으로 여러 과제를 처리했다. 이는 자기회귀 사전 학습 표현의 지도 전이가 효과적임을 보여 주었다.

GPT-1의 영향은 연구 방법에 있었다. 과제별 모델을 처음부터 만들기보다 사전 학습 checkpoint를 출발점으로 삼아 특정 과제에 미세조정하는 방식이 강한 기준이 됐다. 하지만 ELMo와 ULMFiT도 같은 시기 전이 학습을 실증했으므로 GPT-1 하나가 이 패러다임을 단독 창시했다고 쓰면 안 된다.

GPT-2의 zero-shot 결과는 더 큰 관심을 끌었다. 별도 미세조정 없이 language modeling benchmark, LAMBADA, Children’s Book Test, Winograd Schema에서 강한 결과를 냈고 일부 언어 모델링 자료에서 당시 기록을 개선했다. 번역·요약·질의응답·독해에서도 과제에 맞춘 cue만으로 정답 형식의 출력을 만들 수 있었다.

그러나 이 결과의 강도는 과제별로 크게 달랐다. 번역은 일부 방향에서 단순 기준선을 넘었지만 지도 최고 성능보다 낮았고, 요약은 `TL;DR:` cue로 관련 text를 생성했지만 반복과 새 사실 생성 문제가 있었다. Natural Questions의 정확한 일치율은 낮았고, CoQA 독해도 지도 모델에 크게 못 미쳤다. ‘과제를 수행했다’와 ‘당시 최고 수준으로 해결했다’를 구분해야 한다.

이런 결과는 모델이 무엇을 배우는지에 대한 질문을 만들었다. 다음 token 예측은 표면 유창성만이 아니라 corpus 안의 과제 형식·장르·연관을 학습할 수 있었다. 그러나 이를 설계되지 않은 일반 추론 능력의 단계적 출현으로 확정하려면 모델 크기별 곡선과 통제 실험이 더 필요하다. GPT-2 논문의 scale 결과를 오늘날의 ‘창발 능력’ 개념과 그대로 동일시하지 않는다.

GPT-2 공개 방식은 AI 안전과 책임 있는 공개 논의를 촉발했다. OpenAI는 2019년 2월 처음에는 117M 모델과 sampling code만 공개하고 1.5B 모델을 보류했다. 이후 345M, 774M을 단계적으로 공개했고 2019년 11월 1.5B 모델과 code를 공개했다. 초기 결정은 영구 비공개가 아니라 staged release 실험이었다.

기술적으로 GPT-2는 규모 확대의 효과를 보여 주었다. 큰 모델과 더 다양한 자료가 language modeling과 일부 zero-shot 과제의 성능을 높였다. 이 관찰은 GPT-3처럼 더 큰 모델을 개발할 동기가 됐다. 하지만 매개변수 수 하나만으로 성과 원인을 분리할 수 없고 자료량·품질·context·학습 계산도 함께 변했다.

BERT의 MLM과 GPT의 자기회귀 목적은 서로 다른 장점이 있었다. BERT는 전체 입력 표현과 분류·span 예측에 강했고, GPT는 자연스러운 왼쪽→오른쪽 생성 인터페이스를 가졌다. 둘 다 큰 비표지 사전 학습과 전이를 사용하지만 같은 모델의 양방향·단방향 버전이라고만 축약하지 않는다.

## 한계

GPT-1·GPT-2는 causal 구조 때문에 현재 위치가 뒤 token을 볼 수 없다. 전체 입력의 각 token에 좌우 문맥을 함께 반영해야 하는 token-level 이해 과제에서는 BERT식 encoder가 유리할 수 있다. 다만 생성 시점에는 뒤 token이 아직 존재하지 않으므로 causal 제약이 자연스러운 확률 분해를 제공한다.

다음 token 예측은 유창한 text를 선호하지만 사실성 검증 목적은 아니다. GPT-2는 문법적으로 자연스럽지만 사실과 맞지 않는 문장을 만들 수 있었다. 말뭉치의 연관을 모방하는 것과 신뢰할 수 있는 근거를 확인하는 것은 다르다.

zero-shot 성능은 불안정하고 과제 cue·형식·domain에 민감했다. GPT-2 논문에서도 다수 후속 과제 성능은 지도 모델보다 낮았다. 오늘날 의미의 prompt engineering이라는 실무가 이미 완성됐다고 소급하지 않는다.

계산 비용도 컸다. 15억 매개변수의 학습과 추론은 많은 GPU 자원을 요구했고, 긴 출력을 생성할 때 token마다 순차적으로 모델을 실행해야 했다. Transformer 훈련 위치의 병렬성과 자기회귀 sampling의 순차성을 구분해야 한다.

명시적 추론·계획 장치도 없었다. 여러 단계 문제에서 자연스러운 문장을 생성해도 일관된 논리 절차를 따르지 않을 수 있었다. 통계적 sequence prediction이 모든 기호 추론을 자동 대체했다고 볼 수 없다.

자기회귀 생성은 앞에서 고른 token을 다음 조건으로 사용한다. 초기 오류나 우연한 표본이 뒤 출력에 누적되고, 이미 생성한 부분을 같은 pass 안에서 되돌려 수정하지 않는다. decoding 전략에 따라 반복·주제 이탈·다양성이 달라졌다.

WebText는 웹의 편향·오정보·유해 표현을 포함할 수 있었다. Reddit 반응을 수집 필터로 쓴 방식도 대표성·언어 coverage를 보장하지 않는다. 모델은 이런 패턴을 재생산하거나 증폭할 수 있었다.

## 유산과 전망

GPT 모델은 자기회귀 사전 학습을 대규모 생성 언어 모델의 핵심 경로로 확립했다. 다음 token 예측이라는 단순한 목적이 여러 과제에 쓸 수 있는 표현과 생성 능력을 만들 수 있음을 보였다. 이 길은 GPT-3와 후속 생성 모델로 이어졌다.

GPT-1의 사전 학습 뒤 지도 미세조정은 자연어 처리의 공통 관행이 됐다. 다만 현대 모델은 instruction tuning·선호 학습·도구 사용 등 여러 후속 단계를 더하며, 모두 GPT-1과 동일한 두 단계는 아니다.

GPT-2의 zero-shot 실험은 GPT-3의 few-shot·in-context learning을 예고했다. task description이나 입력 예시만으로 매개변수 갱신 없이 행동을 바꾸는 연구 방향에 근거를 보탰다. 그러나 GPT-2의 제한된 cue 기반 결과와 GPT-3의 체계적 few-shot 평가를 구분한다.

과제 표현 방식이 성능에 미치는 영향도 부각됐다. 같은 모델도 cue·delimiter·보기 순서·decoding에 따라 결과가 달랐다. 이는 prompt 설계 연구로 이어졌지만, GPT-2 당시에는 현재의 체계적 prompt optimization이 정립되지 않았다.

GPT-2의 staged release는 모델 공개와 오용 위험을 함께 평가하는 사례가 됐다. 생성 text의 기만·spam·사칭 가능성이 논의됐고 model card, 위험 평가, 단계적 접근과 governance 논의에 영향을 주었다. 실제 오용 규모와 정책 효과는 별도 실증이 필요하다.

현대 언어 모델은 초기 GPT의 강점을 유지하면서 자료·훈련·정렬을 확장했다. 그러나 GPT-4가 명시적 추론과 사실성을 완전히 해결했다는 원문의 후대 평가는 공개된 근거와 시스템별 평가 없이는 채택할 수 없다. 더 큰 모델도 환각·편향·계산 비용·검증 문제를 남긴다.

GPT의 영향은 자연어 처리를 넘어 foundation model이라는 개발 방식에도 닿았다. 하나의 큰 모델을 여러 응용에 적응시키는 방식이 시각·음성·멀티모달 연구로 확장됐다. 그렇다고 모든 분야의 전이 학습이 GPT에서 시작됐다는 뜻은 아니다.

GPT-1과 GPT-2는 언어 AI 진화의 서로 다른 이정표다. GPT-1은 자기회귀 Transformer 사전 학습 표현을 표지 과제에 미세조정하는 전이를 입증했고, GPT-2는 규모와 WebText를 늘려 별도 과제 학습 없는 text continuation이 어디까지 갈 수 있는지 시험했다. 두 단계를 구분하면 현대 생성 LLM의 기원을 과장 없이 이해할 수 있다.

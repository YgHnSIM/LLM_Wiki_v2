# 메모리 네트워크: 신경 질의응답을 위한 외부 메모리

출처: https://mbrenndoerfer.com/writing/memory-networks

---

2014년 등장한 메모리 네트워크를 소개한다. 제이슨 웨스턴과 동료들이 신경 모델에 외부 지식 저장소 접근 능력을 부여한 방식과, 이 발상이 현대 검색 증강 생성(RAG)을 어떻게 예고했는지 살펴본다.

## 2014년: 메모리 네트워크 — 신경망에게 기억하는 법 가르치기

2014년 Facebook AI Research의 제이슨 웨스턴 팀은 신경망에 도서관을 줄 수 없을까라는 질문을 던졌다. 가중치 속에 압축된 지식만이 아니라 사실을 넣고 필요할 때 꺼내 질문에 답하는 실제 외부 저장 공간을 붙이는 생각이었다.

RAG 시스템이 언어 모델과 외부 데이터베이스를 결합하는 오늘날에는 당연해 보이지만 당시에는 급진적이었다. 신경망이 문서 집합을 다루려면 모든 내용을 훈련 중 매개변수에 압축해야 한다고 여겨졌다. 새 정보를 더하려면 다시 훈련해야 하고, 수백만 사실로 늘어나면 한정된 용량 때문에 중요한 정보가 사라질 수 있었다.

메모리 네트워크는 추론 구성 요소와 분리된 외부 메모리를 읽고 쓸 수 있게 했다. 관련 정보에 초점을 맞추고 나머지를 무시하는 접근 메커니즘을 통해 여러 사실을 결합하고 여러 단계로 질문에 답할 가능성을 보였다. 모든 지식을 가중치에 넣지 않고 바깥에 두어 필요할 때 찾는 원리는 뒤의 독해와 RAG 계열에 영향을 주었다.

## 문제: 서류함이 없는 신경망

세계사 시험을 보는데 미리 외운 사실 1,000개 외에는 메모도 검색도 허용되지 않는다고 하자. 수천 사건과 날짜를 연결해야 하는 질문에는 한계가 분명하다. 2010년대 초 신경 질의응답도 비슷했다.

당시 대표적인 시퀀스 구조인 RNN은 고정 크기 은닉 상태를 계속 갱신했다. 짧은 문장의 문법과 뜻을 추적하는 데는 쓸 수 있지만, 수천 문서의 사실을 저장하고 질문에 맞는 특정 사실을 꺼내기에는 지나치게 압축된 작업 기억이었다.

### 훈련 시점 지식의 함정

표준 신경망이 아는 것은 훈련 중 매개변수에 들어가야 했다. Wikipedia로 훈련한 뒤 “프랑스의 수도는?”을 물으면 관련 정보가 수많은 가중치에 분산돼 있어 특정 근거를 직접 찾기 어렵다. Wikipedia가 갱신될 때 새 글 하나만 읽어 저장하기도 어렵고, 지식을 최신화하려면 값비싼 재훈련이 필요했다.

### 다중 홉 추론의 어려움

“에펠탑이 있는 나라의 수도는?”은 에펠탑이 프랑스에 있다는 사실과 프랑스의 수도가 파리라는 사실을 차례로 찾아야 한다. 표준 RNN은 중간 결과 “프랑스”를 은닉 상태에 유지하면서 다음 사실을 찾아야 한다. 홉 수가 늘면 고정 상태에 여러 중간 결과와 질문, 답 준비 정보를 동시에 담아야 했다.

### 규모의 문제

기업 문서 수백만 쪽을 매개변수에 압축하면 일반 패턴은 배울 수 있어도 특정 분기 보고서의 매출 수치 같은 사실은 잃거나 다른 보고서와 섞일 수 있다. 검색, 장기 대화, 교육용 지식 베이스처럼 많은 정보를 정확히 다뤄야 하는 과제에는 지식 저장과 추론을 분리하는 다른 구조가 필요했다.

## 해법: 신경망에 도서관 이용증 주기

메모리 네트워크는 모든 것을 신경망에 압축하는 대신, 신경망 옆에 구조화된 외부 메모리를 둔다. 모델은 모든 사실을 외우기보다 필요한 사실을 찾는 법을 학습한다. 백과사전을 통째로 외우는 것과 도서관에서 필요한 책을 찾는 법을 아는 것의 차이다.

원문은 구조를 네 구성 요소로 설명한다. 입력 모듈은 질문을 검색 가능한 표현으로 바꾸고, 메모리 모듈은 사실·문서 정보를 저장한다. 출력 모듈은 관련 정보를 모아 답에 필요한 표현을 만들고, 응답 모듈은 이를 과제에 맞는 답 형식으로 바꾼다.

### 네 구성 요소의 협력

**입력 모듈: 질문을 질의로 변환하기**

입력 모듈은 자연어 질문을 의미를 담은 밀집 벡터로 바꾼다. “프랑스의 수도는 무엇인가?”와 “어느 도시가 프랑스의 수도인가?”처럼 표현이 달라도 비슷한 벡터를 만들면 같은 정보를 찾을 수 있다.

**메모리 모듈: 도서관 자체**

메모리는 사실, 문장, 문단 같은 정보 조각을 각각의 슬롯에 저장한다. “파리는 프랑스의 수도다”, “에펠탑은 파리에 있다” 같은 항목을 벡터 행렬의 행으로 표현하면 질문 벡터와 비교할 수 있다. 문서 집합이나 지식 베이스를 메모리로 초기화하고 추론 중 접근하므로 지식 전체를 매개변수로 만들 필요가 없다는 설명이다.

**출력 모듈: 스포트라이트로서의 어텐션**

원문은 출력 모듈이 질문과 각 메모리 슬롯의 관련도를 계산하고, 높은 관련도를 가진 슬롯에 큰 가중치를 주어 메모리 내용의 가중 결합을 만든다고 설명한다. “프랑스의 수도는?”에는 “파리는 프랑스의 수도다”가 높은 가중치를 받고, “도쿄는 일본의 수도다”는 거의 받지 않는다. 이 과정이 미분 가능하므로 역전파로 질문 표현과 접근 패턴을 함께 학습할 수 있다는 것이다.

**응답 모듈: 답 형식 만들기**

응답 모듈은 메모리에서 얻은 정보를 단일 단어, 객관식 선택, 완전한 문장 같은 요구 형식으로 바꾼다. “파리는 프랑스의 수도다”가 선택되면 “파리”를 답으로 추출하고, 복잡한 질문에는 여러 슬롯의 정보를 결합한다.

### 다중 홉 추론: 사실 사슬 따라가기

에펠탑 질문에서는 첫 홉이 에펠탑의 위치를 찾아 프랑스를 중간 결과로 얻고, 둘째 홉이 프랑스의 수도를 찾아 파리를 얻는다. 각 홉은 이전 검색 결과와 원 질문으로 다음 접근 분포를 갱신한다. 외부 메모리는 중간 사실을 다시 참조할 수 있는 추론용 메모장처럼 작동한다.

### 훈련: 메모리 탐색법 가르치기

훈련은 질문 표현, 관련 슬롯 선택, 답 생성을 함께 학습해야 한다. 원문은 질문-정답 쌍과 필요한 메모리 내용을 주고, 최종 오류에서 질문 인코딩과 접근 메커니즘까지 역전파한다고 설명한다. 각 구성 요소는 관련 슬롯을 찾고 그 정보에서 답을 만드는 방향으로 함께 적응한다.

## 메모리 네트워크가 가능하게 한 것

첫째는 규모 확장이다. 매개변수 수보다 외부 저장 공간이 지식 용량을 정하므로 더 많은 사실과 문서를 다룰 수 있다. 둘째는 동적 갱신이다. 추론 구성 요소와 지식 저장이 분리돼 새 문서를 더할 때 모델 전체를 다시 훈련하지 않아도 된다는 장점이 있다. 셋째는 해석 가능성이다. 어떤 메모리 슬롯이 답에 기여했는지 접근 가중치를 살펴볼 수 있다.

### 독해와 질의응답

문서의 각 문장을 슬롯에 넣고 질문에 필요한 문장들을 찾는 구조는 독해에 잘 맞았다. 원문은 여러 추론 능력을 시험하는 합성 bAbI 과제에서 다중 단계·시간·공간 추론을 처리했다고 설명하고, 뉴스·과학 문헌 같은 현실 문서에도 확장됐다고 말한다.

### 정보 검색과 문서 순위화

문서 집합을 가중치로 압축하지 않고 바깥에 유지하면서 신경 유사도로 관련 문서를 찾는 원리는 신경 정보 검색에 영향을 주었다. 신경망의 의미 관련성 학습과 전통 검색의 대규모 문서 저장을 결합하는 혼합 접근이다.

### 대화형 AI

대화의 각 발화를 슬롯에 저장하면 모델은 여러 턴 전의 사실을 다시 참고할 수 있다. 이전 진술에 관한 질문, 사용자 정보의 일관성, 긴 대화 문맥 유지에 도움이 되는 구조로 제시됐다.

## 한계: 완전한 해법은 아니었다

### 감독 신호 문제

원래 메모리 네트워크는 정답만 아니라 어느 메모리 슬롯이 질문을 지지하는지에 관한 추가 감독이 필요한 경우가 있었다. 다중 홉 질문에서 어떤 슬롯을 먼저, 다음에 선택할지 경로를 찾는 일이 어려웠기 때문이다. 뒤의 End-to-End Memory Network는 질문-정답 쌍만으로 더 많은 부분을 학습하도록 감독 요구를 줄였다.

### 접근 계산 비용

각 질문마다 모든 메모리 슬롯의 관련도를 계산하면 비용이 메모리 크기에 따라 늘어난다. 수천 슬롯은 가능해도 수백만 슬롯을 전부 비교하는 것은 비싸다. 따라서 메모리 네트워크는 매개변수 압축보다 큰 지식을 다룰 수 있지만 무제한으로 확장되는 것은 아니다.

### 사실 사이 관계 이해

평평한 슬롯들은 서로의 명시적 관계를 직접 표현하지 않는다. “John은 Mary의 아버지”, “Mary는 Susan의 어머니”를 찾아도 John이 Susan의 할아버지라는 전이를 별도 예시에서 암묵적으로 배워야 할 수 있다. 관계 그래프와 계층·논리 의존을 직접 다루는 장치가 제한적이었다.

### 메모리 부호화의 어려움

문서를 문장, 문단, 개별 사실 가운데 무엇으로 나눌지에 따라 결과가 달라진다. 작은 슬롯은 정밀하지만 문서 문맥을 잃고, 큰 슬롯은 문맥을 담지만 정확한 항목을 찾기 어려울 수 있다. 새 도메인에서는 정보의 분할·표현·입도에 관한 공학이 필요했다.

### 다음 단계

End-to-End Memory Network는 감독을 줄이고, 후속 연구는 더 효율적인 접근과 구조화된 지식·관계 추론을 탐색했다. 외부 메모리를 읽는 신경 구조라는 핵심 생각은 유지됐지만 구체적인 구현은 계속 바뀌었다.

## 유산: 현대 검색 시스템의 DNA

웹 검색을 결합한 챗봇, 사내 문서를 질의하는 AI, RAG 응용은 외부 지식을 찾아 신경 생성과 결합한다는 메모리 네트워크의 원리와 닮았다.

### Transformer로 가는 길

원문은 메모리 접근에 쓰인 어텐션이 2017년 Transformer의 시퀀스 내부 어텐션에 영향을 주었다고 설명한다. 두 구조는 관련도 가중치로 정보를 결합하고 역전파로 학습한다. 또한 메모리의 반복 홉과 Transformer의 multi-head attention 모두 여러 방식으로 정보를 볼 수 있다는 공통점을 가진다고 설명한다.

### RAG: 성장한 메모리 네트워크

RAG는 외부 저장소에 지식을 두고 질문에 맞는 문서를 신경 검색기로 찾은 뒤 생성 모델이 답을 만든다. 현대 RAG는 수백만 문서의 벡터 색인, 대규모 신경 검색기와 언어 생성기를 사용한다. 최신 정보와 사유 지식, 출처가 필요한 응용에서 지식을 다시 훈련하지 않고 갱신할 수 있다는 장점이 있다.

### 모듈식 구조 원리

메모리 네트워크는 저장과 추론을 분리해 각 구성 요소를 따로 확장·교체할 수 있다는 설계 원리를 보였다. 지식 베이스를 바꾸면서 추론기를 유지하고, 검색기를 개선하면서 생성기 전체를 다시 만들지 않을 수 있다. 오늘날 언어 모델, 벡터 데이터베이스, 검색기, 오케스트레이션 층으로 나뉜 응용도 이 모듈성을 활용한다.

### 현대 언어 모델의 명시적 메모리

대형 언어 모델도 많은 지식을 매개변수에 저장하지만 빠른 갱신, 출처 제시, 정확한 사실 접근에는 제약이 있다. 그래서 외부 지식 검색과 읽기·쓰기 가능한 작업 메모리를 붙이는 연구가 계속된다. 신경 학습과 대규모 외부 지식을 어떻게 결합할지는 여전히 중심 과제다.

### 지속되는 영향

메모리 네트워크는 더 큰 신경망만이 아니라 외부 자원과 구조적 귀납 편향을 결합한 설계가 중요하다는 점을 보여 주었다. 학습된 접근으로 정보 사이를 탐색하고, 사용한 슬롯을 어느 정도 확인하며, 저장과 추론을 모듈화하는 생각은 질의응답·대화·문서 검색 등 지식 집약 응용에 남아 있다. 오늘날 구현은 벡터 데이터베이스, Transformer 검색기, 대형 생성기로 달라졌지만 외부 지식을 학습된 검색으로 접근한다는 문제의식은 이어진다.

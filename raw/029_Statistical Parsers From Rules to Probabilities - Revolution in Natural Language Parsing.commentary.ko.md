# 통계적 구문 분석 해설

## 1. 한눈에 보기

- 핵심 주제: 문법이 허용하는 여러 구문 트리 가운데 자료에 비추어 더 그럴듯한 구조를 선택하는 통계적 구성성분 구문 분석
- 등장 배경: 수작업 문법은 후보 구조를 생성할 수 있었지만 광범위한 텍스트의 중의성을 일관된 기준으로 순위화하고 평가하기 어려웠고, [[023_Penn Treebank와 통계적 구문 분석|Penn Treebank]] 같은 주석 말뭉치는 구조와 빈도를 함께 학습할 자료를 제공했다.
- 가장 중요한 아이디어: 확률적 문맥 자유 문법(PCFG)은 규칙 확률의 곱으로 트리 점수를 계산하고, Collins의 1997년 생성적 어휘화 모델은 중심어·수식어·거리·하위범주화·wh-이동을 더 세분된 확률 인자로 나눴다.
- 이후 LLM/NLP에 남긴 영향: 트리뱅크 지도학습과 표준 평가 관행은 신경 구문 분석에도 이어졌지만, BERT·GPT의 대규모 자기지도 사전학습이나 Transformer 구조가 Collins 파서에서 직접 파생된 것은 아니다.

> 이 문서는 `029_Statistical Parsers From Rules to Probabilities - Revolution in Natural Language Parsing.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 1997년 단일 혁명 서사, 규칙과 확률의 잘못된 이분법, PCFG·Collins 모델·CKY식 탐색의 차이, 응용과 현대 LLM으로 이어지는 계보의 범위를 바로잡습니다.

## 2. 핵심 요약

통계적 구문 분석은 문법 규칙을 없앤 접근이 아니다. [[문맥자유문법]]이나 트리뱅크의 구성성분 범주가 후보 공간을 정하고, 말뭉치에서 얻은 확률이나 점수가 후보의 우선순위를 정한다. 따라서 “규칙에서 확률로”라는 표현은 **규칙의 폐기**보다 **허용 가능한 구조만 생성하던 체계에 자료 기반 순위화를 결합한 변화**로 읽어야 한다.

PCFG에서는 같은 좌변을 가진 생성 규칙의 확률을 주석 트리에서 추정하고, 한 트리의 확률을 그 트리에 쓰인 규칙 확률들의 곱으로 계산한다. 기본 PCFG는 현재 비단말 범주에만 조건화하므로 실제 중심 단어, 더 넓은 구조와 부착 거리를 충분히 반영하지 못한다. Collins의 1997년 논문은 각 구성 성분에 중심어를 연결하고, 중심 자식과 좌우 수식어를 생성하는 과정을 분해했다. Model 2는 하위범주화 틀을, Model 3은 wh-이동과 trace를 확률적으로 처리했다.

Collins의 논문은 통계 파싱의 시작점이 아니다. Booth·Thompson의 1973년 확률 문법, 1980년대의 확률적 품사·명사구 처리, 1991년 PARSEVAL, 1992년 부분 괄호 자료를 이용한 PCFG 재추정, Magerman의 1995년 결정 트리 파서와 Collins 자신의 1996년 파서가 앞선다. 1997년 논문의 실제 기여는 이 누적된 흐름 안에서 **생성적 어휘화 문법에 하위범주화와 wh-이동을 포함하고 WSJ Section 23에서 평가한 세 모델**이다.

논문은 WSJ Sections 02–21 약 4만 문장으로 학습하고 Section 23의 2,416문장으로 평가했다. 최종 모델은 구성성분 정밀도 88.1%, 재현율 87.5%를 보고했다. 이는 특정 영어 신문 말뭉치와 당시 PARSEVAL 조건의 결과이지, 모든 언어·도메인·문장 길이에서 규칙 기반 파서를 보편적으로 능가했다는 증거가 아니다.

원문이 말한 CKY 계열 동적 계획법은 핵심 논문과 부합한다. 다만 단순 PCFG가 범주와 구간만 보존하는 표준 CKY 표와 Collins의 어휘화 chart state는 같지 않다. Collins의 기본 상태에는 중심어와 완결 여부가 들어가고, Model 2는 하위범주화 상태를, Model 3은 gap 상태를 추가한다.

## 4. 핵심 개념 해설

### 4.1 PCFG와 트리 확률

PCFG의 규칙을 $A\rightarrow\beta$라고 하고 같은 좌변 $A$에서 선택되는 규칙 확률을 $P(\beta\mid A)$라고 하자. 완전히 주석된 트리뱅크에서 최대가능도 추정은 보통 다음 상대 빈도로 쓸 수 있다.

\[
\hat P(\beta\mid A)
=
\frac{C(A\rightarrow\beta)}{\sum_{\beta'}C(A\rightarrow\beta')}
\]

트리 $T$가 규칙 적용 $r_1,\ldots,r_m$으로 생성되면 기본 PCFG의 트리 확률은 다음처럼 인수분해된다.

\[
P(T)=\prod_{j=1}^{m}P(r_j)
\]

이 계산은 문법이 허용하는 여러 트리에 일관된 점수를 줄 수 있게 한다. 그러나 규칙 선택이 현재 좌변 범주에만 의존한다는 문맥 자유 가정 때문에, 같은 `VP`라도 중심 동사가 무엇인지, 앞서 어떤 수식어가 나왔는지, 부착 거리가 얼마나 되는지 같은 차이를 직접 표현하지 못한다.

기본 PCFG도 품사에서 단어를 생성하는 어휘 규칙을 가질 수 있으므로 “모든 명사를 완전히 같은 단어로 취급한다”고 말하면 지나치다. 부족한 것은 단어 자체의 존재가 아니라 **중심 단어가 더 높은 구 구조와 수식어 선택을 조건화하는 어휘 의존성**이다.

### 4.2 Collins의 생성적 어휘화

Collins 모델은 각 비단말에 중심 단어와 품사 태그를 붙인다. 한 구를 생성할 때 먼저 중심 자식 범주를 고르고, 그 중심을 기준으로 왼쪽·오른쪽 수식어를 생성하며, 더 이상 수식어가 없으면 `STOP`을 생성한다. 수식어의 범주·단어는 부모 범주, 중심 범주·단어와 거리 특징 등에 조건화된다.

어휘화된 전체 규칙을 그대로 세면 조합 수가 너무 커져 [[데이터 희소성]]이 심해진다. 논문은 생성 결정을 작은 확률 인자로 분해하고 여러 조건화 수준의 최대가능도 추정치를 보간한다. 훈련에서 5회 미만 나온 단어와 시험에서 보지 못한 단어는 `UNKNOWN`으로 바꿨다. 따라서 원문의 “더 정교한 [[Smoothing|평활화]]가 가능한 모든 규칙에 0이 아닌 확률을 준다”는 설명은 넓게 일반화돼 있다. 보간과 미지어 처리는 희소성을 줄이지만 문법 밖의 모든 구조를 자동 허용하지 않는다. Model 2에서는 요구된 보어가 하위범주화 집합에 남아 있는 동안 `STOP` 전이를 허용하지 않고, 요구되지 않은 보어의 생성도 배제한다.

Model 2는 중심어가 요구하는 보어 집합을 하위범주화 틀로 먼저 생성하고, 필요한 보어가 모두 나올 때까지 `STOP`을 허용하지 않는다. Model 3은 Penn Treebank의 trace와 공지표 정보를 이용해 gap을 트리 아래로 전달하고 적절한 위치에서 방출하는 결정을 확률화한다. “어휘화”를 단어별 선호 하나로만 설명하면 이 구조적 확장이 사라진다.

### 4.3 학습과 추론의 차이

학습은 주석된 문장–트리 쌍에서 규칙·중심어·수식어·하위범주화·gap 결정의 계수를 세고 매개변수를 추정하는 일이다. 추론은 새 문장에 대해 가능한 트리 가운데 모델 점수가 가장 높은 트리를 찾는 일이다. 지도 자료의 정답을 재현하도록 학습했다는 사실과, 새 도메인의 올바른 의미 구조를 보장한다는 주장은 다르다.

가능한 트리 수는 문장 길이에 따라 급격히 늘지만 동일한 부분 구간의 분석은 여러 전체 트리에서 재사용된다. [[동적 계획법]]은 구간별 부분 해를 chart에 저장해 모든 전체 트리를 하나씩 열거하지 않는다. Collins 논문은 자신의 알고리즘을 `CKY style dynamic programming chart parser`, 즉 CKY(Cocke–Kasami–Younger)식 동적 계획 차트 파서라고 명시한다. 다만 chart item에는 구간·범주·중심어와 완결 여부가 들어가고, Model 2는 하위범주화 상태를, Model 3은 gap 상태를 추가한다. 따라서 표준 CNF PCFG의 단순한 $O(n^3)$ CKY 표와 상태·계산량을 그대로 동일시하지 않는다.

### 4.4 확률, 최고 트리와 평가

$\arg\max_T P(T\mid S)$는 주어진 문장 $S$에서 모델이 가장 높게 평가한 트리를 고른다. 생성 모델에서는 문장마다 $P(S)$가 일정하므로 $P(T,S)$를 최대화해도 같은 최고 트리를 얻는다. 이 최적성은 **주어진 후보 공간과 추정된 모델 안의 최고 점수**라는 뜻이며 실제 독자의 의도나 세계 지식에 맞는 유일한 구조라는 보장은 아니다.

Collins의 1997년 평가는 예측 트리와 Penn Treebank 기준 트리의 레이블 구성성분을 비교하는 정밀도·재현율과 crossing brackets를 사용했다. Section 23 평가에서 논문이 보고한 최종 구성성분 정밀도는 88.1%, 재현율은 87.5%였다. 이 값은 문장 의미 이해, 의존 관계, trace 복원과 하위 과제 성능을 모두 하나로 나타내는 지표가 아니다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. 1997년을 규칙 기반 구문 분석에서 통계적 구문 분석으로 전환한 단일 분기점으로 제시한다.
2. 규칙 기반 파서가 중의성·예외·미지어에서 원리적으로 취약하고 통계 규칙성이 없다고 설명한다.
3. Penn Treebank의 정답 트리, PCFG 규칙 확률과 어휘화를 해결책으로 제시한다.
4. 최대가능도 학습과 평활화, CKY식 동적 계획 추론을 하나의 실용 파싱 절차로 묶는다.
5. 자연어 이해·기계 번역·정보 추출·질의응답·표준 평가 문화로 영향을 확장한다.
6. 도메인 이동·주석 비용·중의성·계산량의 한계를 지적한 뒤 신경 파서·Transformer·BERT·GPT로 이어지는 계보를 제시한다.

이 흐름은 통계 파싱의 직관을 전달하지만, **확률 문법의 선행 연구**, **트리뱅크와 평가의 별도 역사**, **Collins 세 모델의 구체적 기여**, **응용마다 필요한 별도 근거**, **지도 파서와 자기지도 언어 모델의 차이**를 압축한다. 해설에서는 이를 분리해 읽는다.

## 6. 왜 중요한가

통계 파싱의 중요한 변화는 언어 구조를 버린 데 있지 않다. 사람이 정의한 구성성분 구조를 공유 자료로 만들고, 그 구조의 후보 선택을 자료에서 추정하며, 보지 못한 시험 자료에서 정량 평가하는 반복 가능한 연구 절차를 정착시키고 강화하는 데 기여한 점에 있다.

특히 중요한 점:

- 문법적 가능성과 실제 자료에서의 상대적 선호를 구분해 구조적 중의성을 순위화했다.
- 중심어와 수식어 관계를 확률 모델에 넣어 기본 PCFG의 문맥 독립 가정을 완화했다.
- 하위범주화와 wh-이동 같은 언어학적 구분을 확률적 생성 과정 안에 포함했다.
- 트리뱅크 분할과 PARSEVAL을 이용해 모델을 같은 조건에서 비교하는 연구 관행을 강화했다.
- 규칙·주석 스키마·통계 추정·탐색 알고리즘·평가 지표가 서로 다른 설계 층이라는 점을 보여 줬다.

이 성공을 “언어학 지식이 불필요해졌다”는 결론으로 읽으면 핵심이 거꾸로 된다. Penn Treebank의 범주와 trace, 중심어 전파 규칙, 보어 판별에 쓰인 기능 태그, 모델 인수분해와 chart state는 모두 사람이 설계했다. [[말뭉치 기반 학습]]은 설계를 없애기보다 어떤 결정을 자료에서 추정할지 다시 배치했다.

## 7. 현대 LLM과의 연결

### 7.1 직접 이어진 계보: 지도 신경 구문 분석

후대 구성성분 파서는 Penn Treebank 같은 문장–트리 쌍에서 학습하고 Section 23 같은 시험 분할로 평가하는 관행을 이어받았다. 신경망은 사람이 설계한 희소 어휘 특징과 수동 확률 분해의 일부를 연속 표현과 학습된 점수 함수로 바꿨다. 전이 기반 파서, span 점수 파서, recurrent neural network grammar와 self-attentive parser는 구조·탐색·학습 목표가 서로 다르지만 **주석 트리에서 구조를 예측하는 지도 파싱 과제**라는 직접 연결이 있다.

[Klein·Manning의 2003년 비어휘화 파서](https://aclanthology.org/P03-1054/)는 정교한 비단말 상태 분할만으로 강한 성능을 보여, 1990년대식 단어 중심 어휘화가 이후 모든 파서의 필수 원리가 아니었음을 보여 줬다. [Kitaev·Klein의 2018년 self-attentive parser](https://aclanthology.org/P18-1249/)는 문장 표현에 자기어텐션을 사용했지만 Transformer 언어 모델 전체가 Collins식 생성 문법을 계승했다는 뜻은 아니다.

### 7.2 사전학습 Transformer와 파싱

[2019년 다언어 구성성분 파싱 연구](https://aclanthology.org/P19-1340/)는 BERT 같은 사전학습 표현을 파서의 입력에 결합해 여러 언어의 트리뱅크 평가를 개선했다. 이 경우 직접 과제는 여전히 주석 트리 예측이며, 사전학습은 추가 표현을 제공한다. 반대로 일반 BERT·GPT의 사전학습 목표는 Penn Treebank 구문 트리를 정답으로 맞히는 것이 아니다.

신경 표현에서 구문 정보가 선형 probe나 attention 분석으로 어느 정도 복원된다는 결과는 모델이 문법 규칙을 Collins 파서와 같은 방식으로 명시적으로 저장한다는 증거가 아니다. probe의 능력, 자료 편향, 상관과 인과적 사용을 구분해야 한다.

### 7.3 현대 LLM과의 제한된 공통점

[[규칙 기반 AI에서 데이터 기반 학습으로]]가 정리하듯 현대 [[대규모 언어 모델]]도 자료에서 매개변수를 학습하고 확률이나 점수로 중의적 출력을 다룬다. 그러나 이 방법론적 공통점을 직접 구조 계보로 바꾸면 안 되며, 다음 차이가 크다.

- Collins 파서는 지도된 문장–트리 쌍으로 명시적 구성성분 트리를 출력한다.
- GPT 계열은 대규모 비주석 텍스트의 다음 토큰 예측으로 사전학습하며 보통 명시적 트리를 출력하지 않는다.
- BERT 계열의 마스킹 복원과 Transformer self-attention은 PCFG 규칙 확률 곱이나 CKY chart와 다른 계산이다.
- LLM이 문장을 생성하는 확률과 후보 구문 트리를 평가하는 확률은 표본 공간과 의미가 다르다.

따라서 “자료에서 언어 규칙성을 학습한다”는 문제 수준의 공통점은 있지만, 1997년 파서가 Transformer와 LLM의 직접 설계도를 제공했다고 기록하지 않는다.

## 8. 한계와 비판적 관점

### 8.1 원문에서 바로잡아야 할 주장

- **1997년 통계 파싱의 등장**: PCFG는 1973년에 정식화됐고, 1980년대 확률 파싱과 1992–1996년 트리뱅크 기반 파서가 선행했다. 1997년은 Collins의 세 생성적 어휘화 모델이 발표된 시점이다.
- **Collins가 규칙을 데이터로 대체**: 모델은 lexicalized context-free grammar, Penn Treebank 범주, 중심어 전파 규칙과 사람이 정한 확률 분해를 사용했다. 규칙과 구조 위에 자료 기반 추정을 결합했다.
- **규칙 기반 파서는 중의성을 선택할 원리가 전혀 없음**: 수작업 우선순위·제약·의미 정보·가중치·후처리를 사용할 수 있었다. 통계 모델은 대규모 자료에서 일관된 순위 기준을 추정하는 방법을 확장했다.
- **규칙 기반 시스템은 미지어·비문에서 항상 완전 실패**: 견고성은 문법 형식, 사전 처리, fallback과 복구 전략에 따라 달라진다. 절대 명제로 일반화하지 않는다.
- **Penn Treebank는 수만 개 WSJ 문장만으로 이루어짐**: Collins의 학습·시험 자료는 WSJ 부분이지만 Penn Treebank 프로젝트 전체에는 품사·구문 주석 단계와 다른 자료가 있다. 프로젝트 전체와 특정 실험 분할을 구분한다.
- **기본 PCFG는 모든 명사를 동일하게 취급**: 품사–단어 어휘 규칙은 단어별 확률을 가질 수 있다. 기본 PCFG의 핵심 한계는 중심 단어가 상위 구 구조와 부착 결정을 충분히 조건화하지 못한다는 점이다.
- **평활화가 가능한 모든 규칙을 0이 아니게 만듦**: Collins는 조건화 수준을 보간하고 미지어를 묶었지만 문법 밖 구조까지 허용하지 않으며 일부 하위범주화 위반의 확률은 0이다.
- **Collins 파서는 단순 CKY 표**: 논문은 CKY(Cocke–Kasami–Younger)식 동적 계획 chart parser를 사용했다고 명시한다. 다만 중심어·완결 여부를 기본 상태에 담고, Model 2는 하위범주화 상태, Model 3은 gap 상태를 추가한 확장된 탐색이다.
- **통계 파싱이 NLP의 표준 평가 문화를 창안**: PARSEVAL은 1991년에 제안됐고 Penn Treebank 공유 자료도 1997년 전에 구축·배포됐다. Collins 연구는 이 관행을 사용하고 강화했다.
- **NMT·IE·QA 성능 향상은 Collins 파서의 직접 결과**: 통사 정보를 쓰는 과제별 모델은 존재하지만, 구체적 시스템·자료·대조 실험 없이 광범위한 응용 효과를 한 파서에 귀속하지 않는다.
- **통계 파서가 창의적 문장을 원리적으로 처리할 수 없음**: 문법의 재귀 조합은 훈련에 없던 전체 트리를 생성할 수 있다. 문제는 새 어휘·구조·도메인에서 추정 확률과 표현이 얼마나 일반화되는가다.
- **현대 neural parser는 모두 1997 패러다임을 그대로 유지**: 일부는 어휘화 가정을 버리거나 판별 span·전이 점수를 쓰며, 비지도·약지도 파싱도 있다.
- **BERT·GPT가 통계 파싱의 직접 후손**: 주석 트리 지도학습과 자기지도 토큰 사전학습, chart와 self-attention의 계산을 구분한다.

### 8.2 기술적·자료적 한계

- 트리뱅크의 주석 지침과 언어 이론이 정답 구조를 정의하므로 다른 이론의 타당성을 자동 판정하지 않는다.
- WSJ에서 추정한 어휘·부착 선호는 대화, 생의학, 소셜 미디어와 다른 언어에 그대로 적용되지 않을 수 있다.
- 어휘화는 유용한 문맥을 주지만 조건 조합을 늘려 희소성과 메모리·탐색 비용을 키운다.
- 최고 점수 트리 하나만 출력하면 후보 불확실성과 여러 해석을 가릴 수 있다.
- 구성성분 정밀도·재현율은 의미 이해, 실제 과제 효용과 모델의 확률 보정을 직접 측정하지 않는다.
- 전문가 트리 주석은 비용이 크고 주석자·지침·전처리의 선택에 영향을 받는다.

### 8.3 해석의 한계

확률이 높다는 것은 학습 분포와 모델 가정 안에서 상대적으로 선호된다는 뜻이다. 화자의 의도, 사실성, 담화 문맥과 세계 지식을 자동으로 보장하지 않는다. 또한 트리뱅크 구조를 잘 재현한다는 사실만으로 인간이 문장을 처리하는 인지 절차를 그대로 모사한다고 결론 내릴 수 없다.

## 9. 용어 정리

| 용어 | 설명 |
| --- | --- |
| 통계적 구문 분석(statistical parsing) | 후보 구문 구조에 확률이나 학습 점수를 부여해 자료에 비추어 우선순위를 정하는 파싱 접근 |
| 확률적 문맥 자유 문법(PCFG) | 같은 좌변의 문맥 자유 생성 규칙에 정규화된 확률을 부여한 문법 |
| 구성성분(constituent) | 문장에서 하나의 계층적 단위를 이루는 연속 단어 구간과 범주 |
| 트리뱅크(treebank) | 문장에 품사·구문 트리 등을 주석한 말뭉치 |
| 어휘화(lexicalization) | 구의 비단말 범주에 중심 단어·품사 정보를 연결해 구조 확률을 단어에 조건화하는 방식 |
| 중심어(head word) | 한 구의 통사적 성질과 수식 관계를 대표하도록 선택한 핵심 단어 |
| 하위범주화(subcategorization) | 동사 등 중심어가 요구하거나 허용하는 보어의 종류와 수에 관한 정보 |
| wh-이동·gap | 의문사·관계사와 해석 위치 사이의 장거리 관계를 trace와 빈자리 특징으로 나타내는 분석 |
| 최대가능도 추정(MLE) | 관측된 주석 자료의 확률이 커지도록 매개변수를 상대 빈도 등으로 추정하는 방법 |
| chart parser | 동일한 구간의 부분 분석을 저장·재사용해 후보 구조를 효율적으로 탐색하는 파서 |
| CKY식 동적 계획법 | Cocke–Kasami–Younger 계열로, 문장 구간을 작은 구간부터 결합해 최고 점수 구조를 찾는 bottom-up chart 계산 방식 |
| PARSEVAL | 예측 트리와 기준 트리의 구성성분 괄호를 정밀도·재현율 등으로 비교하는 평가 절차 |

## 12. 짧은 결론

통계적 구문 분석의 역사는 1997년에 규칙이 사라지고 확률이 그 자리를 차지한 단일 혁명이 아니다. 1970년대의 확률 문법, 1980년대의 확률적 텍스트 처리, Penn Treebank와 PARSEVAL, 1990년대 전반의 통계 파서 위에서 Collins의 1997년 생성적 어휘화 모델이 중심어·수식어·하위범주화·wh-이동을 하나의 평가 가능한 체계로 결합했다.

그 성과는 사람이 만든 언어 구조를 데이터가 대체했다는 데 있지 않다. **구조 후보를 명시하고, 그 선택 기준을 주석 자료에서 추정하며, 공유 시험 자료에서 검증하는 연구 절차를 강화한 것**이 핵심이다. 이 절차는 후대 지도 신경 파서에 직접 이어졌지만, Transformer·BERT·GPT의 자기지도 학습과 계산 구조는 별도의 발명과 자료 규모를 거쳤다. 그러므로 Collins 파서는 현대 LLM의 단일 기원보다, 상징 구조와 통계적 선택을 결합한 1990년대 구문 분석의 중요한 이정표로 이해하는 편이 정확하다.

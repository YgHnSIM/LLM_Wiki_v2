# PaLM: Pathways 언어 모델 - 대규모 훈련, 추론 및 다국어 역량

원본 출처: https://mbrenndoerfer.com/writing/palm-pathways-language-model-large-scale-training-reasoning

---

복잡한 추론, 다국어 이해, 코드 생성에서 획기적인 역량을 보여준 Google의 5,400억 매개변수 언어 모델 PaLM을 다루는 종합 안내서다. Pathways 시스템과 효율적인 분산 훈련, 그리고 PaLM이 대규모 언어 모델 성능의 새로운 기준을 세운 과정을 살펴본다.

## 2022년: PaLM

2022년에 이르자 갈수록 야심 차게 진행된 규모 확장으로 대규모 언어 모델의 지형은 크게 달라져 있었다. 2020년에 1,750억 개의 매개변수로 공개된 [GPT-3](/writing/gpt3-in-context-learning-emergent-capabilities-from-scale)는 거대 언어 모델이 소수 예시 학습(few-shot learning)과 다양한 과제에서 지닌 잠재력을 보여주었다. 하지만 Google 연구진은 전례 없는 규모로 훈련한 더 큰 모델이라면 추론과 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 이해, [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development)에서 새로운 역량을 끌어낼 수 있다고 보았다. 과제는 단순히 더 큰 모델을 만드는 데 그치지 않고, 분산 훈련 인프라 전반에서 이를 효율적이고 안정적으로 구현하는 것이었다. 여러 TPU Pod에 걸친 효율적인 훈련을 지원하도록 설계된 Google의 Pathways 시스템은 다음 단계의 규모 확장을 위한 인프라 기반을 제공했다.

Pathways 팀이 이끈 Google 연구진은 당시 기술적으로 가능한 한계를 밀어붙일 정도의 규모로 언어 모델을 훈련하고자 했다. 그 결과 2022년에 PaLM(Pathways Language Model)이 공개되었다. PaLM은 5,400억 개의 매개변수를 갖춘 [트랜스포머](/writing/transformer-attention-is-all-you-need)로, 복잡한 추론과 다국어 과제, 코드 생성에서 뛰어난 역량을 보여주었다. [GPT-3](/writing/gpt3-in-context-learning-emergent-capabilities-from-scale)보다 세 배 넘게 큰 PaLM은 당시까지 훈련된 가장 큰 밀집형 언어 모델이었으며, 트랜스포머 아키텍처와 대규모 훈련으로 실현할 수 있는 가능성의 최전선을 넓혔다.

PaLM의 의의는 규모뿐 아니라 그 규모로 보여준 역량에도 있었다. 이 모델은 여러 단계의 문제 풀이가 필요한 수학적 추론 과제에서 뛰어난 성능을 보였고, 규모 확장이 더 정교한 추론 패턴을 가능하게 할 수 있음을 시사했다. 100개가 넘는 언어를 아우르는 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 역량은 대규모 훈련만으로도 특수한 아키텍처 없이 효과적인 언어 간 이해가 가능할 수 있음을 보여주었다. 특히 눈에 띄는 점은 PaLM의 강력한 [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development) 능력이었다. 이는 언어 모델이 여러 프로그래밍 언어의 코드를 이해하고 실제로 작동하는 코드를 생성할 수 있음을 시사했다.

PaLM은 연구자들이 규모 확장으로 모델 역량을 어디까지 끌어올릴 수 있는지 탐색하던 언어 모델 발전의 중대한 시점에 공개되었다. 이 모델의 성공은 수천억 개의 매개변수로 규모를 키우면 복잡한 추론과 전문 과제에서 상당한 성능 향상을 얻을 수 있음을 보여주었고, 이후의 모델 개발에 영향을 미치며 대규모 언어 모델 성능의 새로운 기준을 세웠다. 규모와 역량, 효율성을 함께 갖춘 PaLM은 대규모 언어 모델 진화의 이정표가 되었다.

## 문제

[GPT-3](/writing/gpt3-in-context-learning-emergent-capabilities-from-scale)를 비롯한 대규모 언어 모델이 인상적인 역량을 보여주었지만, 몇 가지 근본적인 과제가 그 효과와 접근성을 제한했다. 가장 중요한 과제 가운데 하나는 복잡한 다단계 추론을 수행하는 능력이었다. 모델은 일관된 글을 생성하고 여러 과제에서 좋은 성능을 낼 수 있었지만, 복잡한 상황을 더 작은 단계로 나누고 추론 과정 내내 맥락을 유지하며 논리적 사고를 일관되게 적용해야 하는 문제에는 어려움을 겪었다. 수학 문장제와 논리 퍼즐을 비롯해 추론이 많이 필요한 과제는 규모가 충분하지 않거나 특화 훈련을 받지 않은 모델에게 여전히 어려웠다.

[다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 이해 역시 중요한 한계였다. 대다수 대규모 언어 모델은 주로 영어에서 뛰어난 성능을 보였고, 다른 언어에서는 역량이 현저히 떨어졌다. 여러 언어의 텍스트를 효과적으로 이해하고 생성하는 모델을 만들려면 일반적으로 특수한 아키텍처나 언어별 훈련이 필요했으므로, 다양한 언어 환경에 대규모 언어 모델을 적용하기가 어려웠다. 하나의 모델로 여러 언어를 처리할 수 있다면 대규모 언어 모델의 잠재적 활용 범위를 크게 넓힐 수 있었다.

[코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development)은 언어 모델이 가능성을 보이면서도 한계에 부딪힌 또 다른 영역이었다. 모델은 구문상 올바른 코드를 생성할 때도 있었지만, 복잡한 프로그래밍 개념과 여러 파일로 이루어진 프로젝트, 소프트웨어 개발 과제의 미묘한 요구 사항을 이해하는 데 어려움을 겪곤 했다. 자연어 설명으로부터 실제로 작동하는 올바른 코드를 생성하는 능력은 소프트웨어 개발에 강력한 응용 가능성을 열어주지만, 이를 위해서는 충분한 규모와 적절한 훈련 데이터를 모두 갖춘 모델이 필요했다.

PaLM 규모의 모델을 훈련하는 일에는 상당한 기술적 과제가 따랐다. 5,400억 매개변수 모델의 훈련에 필요한 연산량은 단일 장치는 물론 단일 TPU Pod로도 감당할 수 있는 범위를 넘어섰다. 여러 TPU Pod에 걸친 분산 훈련에는 훈련을 조율하고 통신 오버헤드를 관리하며 훈련 안정성을 확보할 정교한 인프라가 필요했다. Pathways 시스템은 훈련의 품질과 효율성을 유지하면서 수천 개의 장치에서 효율적인 병렬 훈련을 가능하게 해 이러한 과제를 해결했다.

메모리 제약도 또 다른 어려움을 낳았다. 분산 훈련을 사용하더라도 이 정도 규모의 모델을 저장하고 처리하려면 세심한 메모리 관리 기법이 필요했다. 그래디언트 체크포인팅(gradient checkpointing), 혼합 정밀도 훈련(mixed precision training), [희소 어텐션](/writing/attention-complexity-quadratic-scaling-memory-efficient-transformers) 패턴은 대규모 훈련을 가능하게 하는 핵심 요소가 되었다. 이러한 최적화가 없었다면 PaLM 규모의 모델 훈련은 연산 측면에서 실현할 수 없었을 것이다.

연산 자원을 가장 효과적으로 활용하는 방법도 여전히 풀리지 않은 문제였다. 이전 모델들은 모델이 클수록 더 좋은 성능을 낼 수 있음을 보여주었지만, 모델 크기와 훈련 데이터 양, 훈련 절차 사이의 최적 균형은 충분히 밝혀지지 않았다. 연구진은 전례 없는 규모에서 훈련하는 동시에 연산 자원을 효율적으로 사용하도록 보장할 체계적인 접근법이 필요했다.

## 해결책

Google은 아키텍처 혁신과 효율적인 훈련 인프라, 그리고 모델 크기와 훈련 데이터의 세심한 규모 확장을 결합해 이러한 과제를 해결했다. Pathways 시스템은 분산 훈련을 위한 기반 인프라를 제공하여 여러 TPU Pod를 효율적으로 조율할 수 있게 했다. 연구진은 이 인프라를 통해 개별 훈련 시스템의 용량을 넘어서는 모델을 훈련하면서도 훈련 안정성과 효율성을 유지할 수 있었다.

### Pathways 시스템

Pathways 시스템은 분산 컴퓨팅 인프라에서 효율적인 대규모 훈련을 구현하기 위한 Google의 접근법이었다. 기존 분산 훈련 방식은 상당한 통신 오버헤드나 복잡한 조정을 필요로 할 수 있었지만, Pathways는 모델 품질을 유지하면서 여러 TPU Pod에 걸쳐 효율적인 병렬 훈련을 가능하게 했다. 이 시스템은 그래디언트 동기화, 모델 매개변수 갱신, 내결함성 등 분산 훈련의 복잡한 문제를 처리해, 연구진이 인프라 관리 대신 모델 개발에 집중할 수 있도록 했다.

Pathways 인프라

Pathways 시스템은 여러 TPU Pod에서 PaLM을 훈련할 수 있게 하여, 수천 개의 장치를 조율해 하나의 거대 모델을 훈련했다. 이러한 인프라 추상화는 PaLM 규모의 모델을 실현하는 데 핵심적이었다. 분산 훈련의 복잡성을 처리하면서도 효율성과 신뢰성을 유지했기 때문이다. 이런 인프라가 없었다면 이 규모의 모델을 훈련하는 일은 지나치게 복잡하거나 아예 불가능했을 것이다.

### 아키텍처와 훈련 최적화

PaLM의 아키텍처는 [트랜스포머](/writing/transformer-attention-is-all-you-need)를 기반으로 하면서 규모 확장을 위한 여러 최적화를 통합했다. 이 모델은 표준 밀집 어텐션보다 긴 시퀀스를 더 효율적으로 처리할 수 있는 [희소 어텐션](/writing/attention-complexity-quadratic-scaling-memory-efficient-transformers) 패턴을 사용했다. 이러한 패턴은 시퀀스의 장거리 의존 관계를 포착하는 능력을 유지하면서 연산 요구량을 줄였다.

그래디언트 체크포인팅은 훈련 중 메모리 요구량을 줄이는 데 핵심적인 역할을 했다. 일부 활성값만 저장하고 나머지는 [역전파](/writing/history-backpropagation-deep-learning-training) 과정에서 다시 계산하는 방식으로, 훨씬 적은 메모리만으로 훈련할 수 있게 해 대규모 훈련을 실현했다. 혼합 정밀도 훈련은 수치적 안정성을 위해 필요한 부분에는 더 높은 정밀도를 유지하되, 대부분의 연산에는 더 낮은 정밀도의 부동소수점 연산을 사용함으로써 메모리 사용량을 더 줄이고 훈련 속도를 높였다.

### 훈련 데이터와 절차

이 모델은 텍스트와 코드를 모두 포함하는 방대하고 다양한 데이터셋으로 훈련되었다. 훈련 과정에서는 다음 토큰 예측(next-token prediction)을 주된 목표로 사용하여, 모델이 여러 도메인과 과제에 걸친 패턴을 학습할 수 있게 했다. 데이터셋에는 책과 웹사이트 등 여러 출처에서 수집한 고품질 텍스트뿐 아니라 다양한 프로그래밍 언어와 맥락의 코드도 포함되었다.

데이터 필터링과 품질 관리를 통해 모델이 고품질 사례로부터 학습하도록 하고, 성능을 저하시킬 수 있는 잡음과 저품질 데이터는 배제했다. 훈련 과정에는 유해한 출력을 줄이고 모델이 일반적인 배포 환경에서 유용하고 안전하게 쓰이도록 하기 위한 안전 조치도 포함되었다. 여기에는 훈련 데이터 필터링, 안전 프롬프트 사용, 잠재적 위해 요소를 찾기 위한 모델 출력 평가가 포함되었다.

### 5,400억 매개변수로의 규모 확장

PaLM의 규모로 훈련하려면 모델 크기, 훈련 데이터, 연산 예산 사이의 관계를 세심하게 고려해야 했다. 5,400억 개의 매개변수는 이전 모델보다 크게 늘어난 규모였으며, 이 용량을 효과적으로 활용하려면 그에 비례해 더 많은 훈련 데이터가 필요했다. 훈련 과정에서는 가용 연산 예산 안에서 최적의 성능을 달성하도록 모델 크기와 훈련 데이터의 균형을 맞췄다.

규모 확장을 위한 체계적인 접근은 단순히 모델 크기만 키우는 데 그치지 않고, 늘어난 용량에 충분한 훈련 데이터와 적절한 훈련 절차를 함께 갖추는 것이었다. 이러한 균형 잡힌 접근 덕분에 모델은 연산 자원을 효율적으로 사용하면서 여러 과제에서 뛰어난 성능을 달성할 수 있었다.

## 응용과 영향

PaLM의 역량은 추론과 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 이해, [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development)의 새로운 응용을 가능하게 했다. 수학적 추론 과제에서 뛰어난 성능을 보인 이 모델은 교육용 응용 프로그램, 연구 보조, 문제 해결 도구에 유용했다. 복잡한 문제를 더 작은 단계로 나누고 추론 과정 내내 맥락을 유지하는 능력은 과학 연구와 수학적 탐구, 논리 분석에서 AI의 도움을 활용할 가능성을 열었다.

이 모델의 다국어 역량은 곧바로 실용적인 쓰임새를 제공했다. 여러 언어를 다루는 조직은 언어별 모델 없이도 PaLM을 번역, 언어 간 검색, 콘텐츠 생성과 같은 다국어 과제에 활용할 수 있었다. 이 역량은 특히 국제적인 응용 분야와 다국어 환경의 연구, 다양한 언어 공동체를 지원해야 하는 도구에서 가치가 컸다.

PaLM의 코드 생성 능력은 소프트웨어 개발의 새로운 응용을 가능하게 했다. 이 모델은 코드 완성, 디버깅, 자연어 설명을 바탕으로 한 코드 생성뿐 아니라 개발자가 여러 프로그래밍 언어의 코드를 이해하고 다루는 일도 도울 수 있었다. 이러한 역량은 소프트웨어 개발 도구, 교육 플랫폼, 자동 프로그래밍 연구에 활용될 잠재력이 있었다.

모델의 공개 출시는 전 세계 연구자와 개발자가 PaLM의 역량을 토대로 새로운 작업을 수행할 수 있게 했다. 모델 가중치와 훈련 절차에 관한 정보를 이용할 수 있게 되면서 다른 이들도 특화 응용 프로그램을 개발하고 대규모 언어 모델을 연구하며 새로운 활용 사례를 탐색할 수 있었다. 이러한 개방형 접근은 대규모 언어 모델의 개발과 연구를 촉진해, 역량을 빠르게 혁신하고 탐색할 수 있게 했다.

PaLM의 성능 벤치마크는 이후 대규모 언어 모델을 평가하는 방식에 영향을 미쳤다. PaLM 평가에 사용된 과제와 지표는 모델 역량을 비교하는 표준 참조점이 되었고, 추론과 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 이해, [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development)의 새로운 기준을 세웠다. 이러한 벤치마크는 연구자들이 모델의 역량과 한계를 이해하고 향후 개발 방향을 정하는 데 도움을 주었다.

## 한계

인상적인 역량에도 불구하고 PaLM에는 실제 활용 가능성에 영향을 미치는 중요한 한계가 있었다. 이 규모의 모델을 훈련하고 배포하는 데 필요한 연산 자원은 여전히 막대했고, 이는 접근을 가로막는 장벽이 되었다. PaLM을 훈련하려면 인프라에 상당한 투자를 한 조직만 확보할 수 있는 막대한 연산 자원이 필요했다. 완전한 모델을 사용해 추론하는 데도 상당한 연산 자원이 필요해 여러 응용 분야에서 접근성이 제한되었다.

모델 성능은 과제와 도메인에 따라 달랐다. 많은 영역에서 뛰어난 역량을 보여주었지만, 특정 과제의 성능은 일관되지 않을 수 있었고 매우 전문적인 지식이나 추론 패턴이 필요한 과제에서는 때때로 어려움을 겪었다. 이 같은 편차로 인해 실제 서비스에 모델을 배포하려면 신중한 평가가 필요했고, 특정 활용 사례에 맞춘 미세 조정이 필요할 수도 있었다.

안전성과 [신뢰성](/writing/monitoring-reliability-ai-agents)에 대한 우려도 중요한 한계로 남았다. 훈련과 배포 과정에 안전 조치를 적용했음에도, 모델은 일부 상황에서 유해하거나 편향되거나 잘못된 출력을 생성할 수 있었다. 안전하고 신뢰할 수 있게 배포하려면 면밀한 모니터링과 필터링이 필요했고, 많은 응용 분야에서는 [인간의 감독](/writing/ethical-guidelines-human-oversight-ai-agents)도 필요할 수 있었다. 이러한 안전상의 고려 사항은 모델을 배포할 수 있는 범위와 방식을 제한했다.

모델의 크기와 연산 요구량 때문에 자원이 제한된 환경에는 배포하기 어려웠다. 실시간 응답이 필요하거나 엣지 장치에 배포해야 하거나 제한된 연산 예산으로 작동해야 하는 응용 분야는 상당한 어려움에 직면했다. [희소 어텐션](/writing/attention-complexity-quadratic-scaling-memory-efficient-transformers) 같은 기법이 효율성을 높였지만 이러한 제약을 없애지는 못했다.

포괄적인 평가 방법론도 실제로 중요할 수 있는 모델 품질의 모든 측면을 포착하지는 못했다. 장기 추론, 시간 경과에 따른 사실 정확성, 경계 사례에서의 성능 같은 요소는 표준 벤치마크에서 충분히 다뤄지지 않았다. 모델 행동의 이러한 측면을 이해하려면 추가 평가와 특화된 테스트 절차가 필요할 수 있었다.

## 유산과 미래 전망

PaLM은 대규모 언어 모델 역량의 새로운 기준을 세웠고, 수천억 개 매개변수로 규모를 확장했을 때의 잠재력을 보여주었다. 이 모델의 성공은 세심한 규모 확장과 훈련을 통해 추론과 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 이해, [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development)을 크게 향상할 수 있음을 입증했다. 이러한 성과는 이후 모델 개발에 영향을 주었고, 연구자들은 PaLM의 성취를 토대로 더욱 뛰어난 시스템을 만들었다.

PaLM을 위해 개발된 Pathways 인프라와 훈련 접근법은 이후 대형 모델을 훈련하는 방식에 영향을 미쳤다. 효율적인 분산 훈련 기법과 메모리 최적화 전략, 훈련 절차는 다른 연구자와 조직이 채택하는 본보기가 되었다. 이러한 인프라와 방법론의 기여는 PaLM 자체를 넘어 새로운 세대의 대규모 언어 모델을 가능하게 했다.

추론 과제에서 보인 이 모델의 성능은 복잡한 문제 해결을 언어 모델이 지원할 수 있다는 가능성을 부각했고, 수학적 추론과 논리 분석을 비롯해 추론 중심 응용에 초점을 맞춘 시스템의 개발에 영향을 미쳤다. 이후의 모델들은 이러한 역량을 토대로 더 정교한 추론 패턴이 필요한 영역으로 나아갔다.

PaLM의 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 역량은 대규모 훈련만으로도 특수한 아키텍처 없이 효과적인 언어 간 이해가 가능할 수 있음을 보여주었다. 이 발견은 이후 모델 개발에 영향을 주어, 연구자들이 다국어 훈련을 표준적인 관행에 포함하게 했다. 하나의 모델로 여러 언어를 처리하는 능력은 대규모 언어 모델에 기대되는 역량이 되었다.

이 모델의 [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development) 능력은 소프트웨어 개발과 프로그래밍 지원을 위한 AI 시스템 개발에 영향을 미쳤다. 이후의 모델들은 이러한 역량을 토대로 코드 이해, 생성, 디버깅 분야를 더욱 발전시켰다. 언어 이해와 코드 생성 역량의 결합은 AI 지원 소프트웨어 개발의 새로운 가능성을 열었다.

PaLM이 보여준 원칙과 역량은 대규모 언어 모델 개발에 계속 영향을 미치고 있다. 새로운 아키텍처와 훈련 방법, 역량이 등장하는 가운데서도 [효율적인 규모 확장](/writing/sparse-models-conditional-computation-efficiency), 다양한 역량, 실용적 응용에 대한 강조는 여전히 중요하다. 규모와 역량, 인프라에 관해 PaLM이 제시한 근본적인 통찰은 이 분야가 계속 발전하는 지금도 개발 방향을 안내한다.

PaLM이 다룬 추론 역량과 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 이해, 코드 생성 등의 과제는 여전히 활발한 연구 개발 영역이다. 이후의 모델들은 PaLM의 성취를 토대로 그 한계를 해결하면서 추론, 효율성, 특화 역량 같은 분야를 더욱 발전시켰다. PaLM의 유산은 구체적인 기술적 성과를 넘어, 세심한 규모 확장과 대규모 언어 모델의 체계적인 개발로 무엇이 가능한지를 보여준 데까지 이어진다.

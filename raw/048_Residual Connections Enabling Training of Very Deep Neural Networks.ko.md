# 잔차 연결: 매우 깊은 신경망의 훈련을 가능하게 하다

출처: https://mbrenndoerfer.com/writing/residual-connections-deep-neural-networks-resnet

---

잔차 연결을 종합적으로 소개한다. 스킵 연결이 100층이 넘는 네트워크 훈련을 가능하게 하고 현대 언어 모델과 Transformer의 기본 요소가 된 과정을 설명한다.

## 2015년: 잔차 연결

2015년까지 깊은 합성곱 신경망은 컴퓨터 비전에서 큰 성공을 거두었다. VGG와 GoogLeNet은 ImageNet에서 깊이가 복잡한 시각 표현을 학습하는 데 중요함을 보였다. 하지만 층을 더한다고 언제나 좋아지는 것은 아니었고, 더 깊은 네트워크가 얕은 네트워크보다 나쁜 경우도 있었다.

Microsoft Research Asia의 허카이밍, 장샹위, 런사오칭, 쑨젠은 깊은 네트워크가 유용한 표현을 만들 수 없어서가 아니라 훈련하기 어려워서 생긴 문제라고 보았다. 원문은 순환망에서 알려진 기울기 소실이 매우 깊은 합성곱망에도 영향을 주어 초기 층의 학습 신호를 약하게 만들었다고 설명한다.

이들이 제안한 잔차 연결은 층이 입력에서 출력으로 가는 전체 변환을 배우는 대신 둘의 차이인 잔차를 배우게 했다. 필요할 때 항등 사상을 쉽게 구현해 기여하지 않는 층을 사실상 건너뛸 수 있었다. ResNet은 100층이 넘는 구조를 훈련하고 더 얕은 네트워크보다 높은 정확도를 얻었다.

잔차 연결은 비전을 넘어 자연어 처리와 강화학습으로 퍼졌다. 2017년 Transformer도 각 하위층에 잔차 연결을 사용했고, 현대 언어 모델의 수십·수백 층을 훈련하는 기본 구성 요소가 됐다.

## 문제

AlexNet은 8층, VGG는 19층, GoogLeNet은 22층으로 깊어졌다. 연구자들은 더 깊은 층이 더 추상적인 특징을 잡을 것이라 기대했지만, 실제로는 층을 추가하면 시험 오류뿐 아니라 훈련 오류까지 높아졌다.

이론적으로 더 깊은 네트워크는 추가 층을 항등 사상으로 설정해 얕은 네트워크와 같은 함수를 구현할 수 있다. (n)층 네트워크가 특정 오류를 낸다면 (n+k)층은 추가 (k)층에서 입력을 그대로 통과시켜 적어도 같은 오류를 낼 수 있어야 한다. 그러나 최적화가 그 해를 쉽게 찾지 못했다.

원문은 근본 원인을 기울기 소실로 설명한다. 역전파에서 여러 층의 가중치와 활성화 도함수가 곱해지면 기울기가 지수적으로 작아져 초기 층이 사실상 멈출 수 있다는 것이다. 2015년 Batch Normalization이 활성화와 기울기를 안정화했지만 20층을 넘는 네트워크는 여전히 어렵고, 최적화 지형에 지역 최솟값과 평평한 영역이 많았다고 설명한다.

항등 사상 자체를 학습하기도 어려웠다. 전통 층은 비선형 변환을 적용하므로 입력을 그대로 보존하려면 여러 층이 비선형성을 서로 상쇄하도록 조정돼야 했다. 실패한 깊은 훈련은 많은 계산을 낭비했기 때문에 깊이가 안정적으로 이득이 되는 구조가 필요했다.

## 해법

잔차 연결은 정보가 직접 흐르는 경로를 제공한다. 전통 층이 (y=F(x))를 계산한다면 잔차 블록은 다음을 계산한다.

\[
y=F(x)+x
\]

입력 (x)를 변환 (F(x))의 출력에 직접 더한다. 원하는 사상이 항등이면 (F(x)=0)만 학습하면 된다. 입력과 출력 차원이 다를 때는 선형 투영 (W_s)를 쓸 수 있다.

\[
y=F(x)+W_sx
\]

합성곱망에서는 보통 (1\times1) 합성곱으로 채널 수나 공간 크기를 맞춘다.

이제 층은 전체 목표 표현이 아니라 입력에 더할 조정량을 학습한다. 원하는 출력이 입력과 비슷하면 작은 잔차를, 많이 다르면 큰 잔차를 배운다. 원문은 초기에는 shortcut이 기준 경로를 제공하고, 학습이 진행되며 (F(x))가 세밀한 조정을 보탠다고 설명한다.

ResNet은 여러 잔차 블록을 stage로 쌓는다. 각 블록에는 보통 두세 합성곱층, BatchNorm과 ReLU가 있고 변환 결과에 입력을 더한다. 공간 해상도를 줄이고 채널을 늘리는 전환 지점에서는 stride 2의 (1\times1) 투영으로 차원을 맞춘다.

## 응용과 영향

ResNet은 ILSVRC 2015 분류에서 앙상블 top-5 오류 3.57%를 기록해 우승했다. 50·101·152층을 효과적으로 훈련했고 더 깊은 모델이 얕은 모델보다 좋은 결과를 냈다. 객체 검출·의미 분할에도 쓰였고 ResNeXt와 DenseNet 같은 변형·후속 구조가 나왔다.

자연어 처리의 깊은 encoder·decoder와 언어 모델도 잔차 연결을 채택했다. Transformer는 multi-head self-attention과 position-wise feed-forward 하위층 각각을 잔차 연결로 감싸고, 원 구조에서는 잔차 덧셈 뒤 Layer Normalization을 적용했다.

원문은 GPT, BERT, T5 등 주요 언어 모델이 잔차 연결을 쓰며 GPT-3의 96층, PaLM의 118층 같은 깊이를 가능하게 했다고 설명한다. 강화학습, GAN·VAE, 그래프 신경망에도 스킵 연결 패턴이 확산됐다. 자율주행, 의료 영상, 제조 비전과 번역·요약·질의응답 같은 실제 응용도 이 구조를 사용한다.

## 한계

shortcut 신호가 너무 강해 학습 변환을 충분히 쓰지 않을 가능성이 있다는 우려가 있지만, 실무에서는 변환도 성능에 크게 기여한다.

덧셈에는 입력과 출력의 호환되는 차원이 필요하다. 차원이 다르면 투영층이 추가돼 매개변수와 계산이 늘고 구조가 복잡해진다. 또한 블록 출력과 더하기 위해 입력 활성화를 보관하므로 훈련 메모리 비용이 생길 수 있다.

세심한 초기화와 정규화를 쓰면 일부 설정에서 잔차 연결 없이도 깊은 모델을 훈련할 수 있지만 예외적이며, 잔차 연결은 안정성과 수렴을 위한 표준 선택으로 남았다.

잔차 연결은 과적합, 지속 학습의 파국적 망각, 계산 효율 문제를 직접 해결하지 않는다. 잔차망도 정규화가 없으면 과적합할 수 있고 깊이가 늘면 훈련·추론 계산이 커진다. 원문은 각 층이 완전한 재표현보다 점진적 정제를 할 때 특히 잘 맞는다고 설명한다.

## 유산과 전망

잔차 연결은 깊은 학습의 가장 기본적인 구조 패턴이 됐다. 단순한 덧셈이라는 구조 선택이 최적화 지형과 정보 흐름을 바꿔, 알고리즘 자체를 바꾸지 않고도 이전에 어려웠던 깊이를 훈련 가능하게 했다.

후속 연구는 여러 변형을 만들었다. DenseNet은 각 층이 앞선 모든 층의 출력을 받는 dense connection을 사용했고, Highway Network는 스킵 경로를 학습하는 게이트를 두었다. 여러 scale을 건너뛰거나 attention에 잔차를 결합하는 구조도 등장했다.

Batch Normalization과 Layer Normalization은 잔차 연결과 함께 쓰이며 서로 다른 훈련 문제를 보완한다. 현대 구조는 보통 정규화와 잔차를 동시에 사용한다.

모델이 더 커지고 깊어질수록 잔차 경로의 기울기 흐름은 더 중요해졌다. 원문은 조 단위 매개변수 모델에도 이를 필수 요소로 평가한다. 왜 잘 작동하는지에 대해서는 더 매끄러운 최적화 지형과 더 나은 기울기 전달 등 여러 이론적 설명이 연구되고 있다.

2015년 잔차 연결의 도입은 매우 깊은 네트워크 훈련의 전환점이었다. 단순성과 효과 덕분에 현대 신경망 설계의 초석이 됐고, 비전부터 언어 모델까지 깊은 구조가 만들어지는 방식을 계속 규정하고 있다.

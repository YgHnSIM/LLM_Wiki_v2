# 밀집 구절 검색과 검색 증강 생성: 지식을 언어 모델과 통합하기

Source: https://mbrenndoerfer.com/writing/dense-passage-retrieval-retrieval-augmented-generation-rag

---

언어 모델이 외부 지식 소스에 접근할 수 있게 한 2020년의 혁신, 밀집 구절 검색(Dense Passage Retrieval, DPR)과 검색 증강 생성(Retrieval-Augmented Generation, RAG)을 포괄적으로 다루는 안내서다. 밀집 벡터 검색이 의미 검색을 어떻게 바꾸었는지, RAG가 검색과 생성을 어떻게 통합했는지, 그리고 이 기술들이 지식 인식 AI 시스템에 어떤 지속적인 영향을 미쳤는지 살펴본다.

읽기 수준

자신의 전문 지식 수준을 선택해 설명되는 용어의 수를 조정할 수 있다. 초보자에게는 더 많은 툴팁이 표시되고, 전문가는 읽기 흐름을 유지할 수 있도록 더 적은 툴팁을 보게 된다. 밑줄 친 용어 위에 마우스를 올리면 정의를 바로 확인할 수 있다.

## 2020년: 밀집 구절 검색과 검색 증강 생성

2020년, Facebook AI Research(현재 Meta AI)의 연구자들은 언어 모델이 지식과 상호 작용하는 방식을 근본적으로 바꿀, 서로 밀접하게 연관된 두 가지 혁신을 소개했다. [밀집 구절 검색](/writing/dense-retrieval-semantic-search-bi-encoders)([DPR](/writing/contrastive-learning-retrieval-infonce-dpr))과 검색 증강 생성([RAG](/writing/long-term-knowledge-storage-and-retrieval))이다. 이 기술들은 사전 학습 언어 모델의 중대한 한계, 즉 학습 중 매개변수에 부호화된 범위를 넘어 외부 지식에 접근하고 이를 통합할 수 없다는 문제를 해결하고자 했다. [BERT](/writing/bert-bidirectional-pretraining-revolutionizes-language-understanding)와 [GPT](/writing/gpt1-gpt2-autoregressive-pretraining-transfer-learning) 같은 모델은 언어 이해와 생성 과제에서 뛰어난 성능을 거두었지만, 정적인 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)에 묶여 있었다. 최신 정보나 도메인 특화 지식, 학습 데이터에 없던 구체적인 사실에는 접근할 수 없었다. DPR과 RAG는 밀집 벡터 검색을 신경망 언어 모델과 결합하면 외부 지식 소스를 활용해 질문에 답하고, 더 정확하고 사실적인 텍스트를 생성하며, 재학습 없이 새로운 정보에 적응할 수 있는 시스템을 만들 수 있음을 보여주었다.

2020년에 이르러 정보 검색과 언어 모델링 분야는 모두 크게 발전했지만, 두 분야는 대체로 서로 독립적으로 발전해 왔다. 정보 검색 시스템은 [BM25](/writing/bm25-probabilistic-ranking-information-retrieval) 같은 희소 키워드 기반 방법이나 학습된 질의-문서 표현을 사용하는 신경망 접근법으로 대규모 컬렉션에서 관련 문서를 찾았다. BERT와 GPT 같은 언어 모델은 텍스트를 이해하고 생성하는 강력한 도구가 되었지만, 학습 시점에 지식이 동결된 폐쇄형 시스템으로 작동했다. 이 두 능력을 결합하려는 시도는 제한적으로 이루어졌다. 일부 시스템은 생성 전에 관련 문맥을 찾는 전처리 단계로 검색을 사용했고, 다른 시스템은 검색으로 보강한 학습 데이터로 모델을 미세 조정했다. 그러나 관련 정보를 검색하고 생성 과제에 효과적으로 사용하는 법을 함께 학습할 수 있는 종단 간 학습 가능 프레임워크 안에서 밀집 의미 검색과 신경망 언어 생성을 성공적으로 통합한 접근법은 아직 없었다.

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr)과 [RAG](/writing/long-term-knowledge-storage-and-retrieval)의 중요성은 [질의응답](/writing/ibm-watson-jeopardy-open-domain-question-answering-nlp-information-retrieval)에 곧바로 적용되는 범위를 훨씬 넘어선다. 이 기술들은 지식을 인식하는 언어 시스템을 구축하는 기본 패러다임으로 검색 증강 생성을 확립했다. 또한 [밀집 벡터 검색](/writing/dense-retrieval-semantic-search-bi-encoders)을 신경망 언어 모델과 매끄럽게 통합할 수 있음을 보여주면서, 검색의 확장성과 신경망 생성의 정교함을 결합한 시스템의 가능성을 열었다. 이 논문들에서 소개한 기법은 이후 검색 증강 챗봇, 여러 지식 소스를 결합하는 시스템, 대화 중에 정보를 동적으로 검색하는 접근법을 비롯한 현대 검색 증강 시스템의 발전에 영향을 미쳤다. DPR과 RAG는 지식 집약적 언어 AI의 미래가 더 많은 사실을 암기하도록 점점 더 큰 모델을 학습하는 데 있지 않고, 외부 지식 소스를 효과적으로 검색하고 그 위에서 추론할 수 있는 아키텍처를 만드는 데 있음을 보여주었다.

## 문제: 정적 지식과 정보 검색의 한계

2010년대 후반의 사전 학습 언어 모델에는 근본적인 제약이 있었다. 지식이 학습 시점에 동결된다는 점이다. [BERT](/writing/bert-bidirectional-pretraining-revolutionizes-language-understanding)와 [GPT](/writing/gpt1-gpt2-autoregressive-pretraining-transfer-learning) 같은 모델은 대규모 텍스트 말뭉치로 학습되어, 통계적 패턴과 사실 지식을 수백만 또는 수십억 개의 매개변수에 부호화했다. 이 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)는 방대했지만 정적이었다. 학습이 끝나면 이 모델들은 새로운 정보에 접근할 수 없었고, 학습 데이터에 없는 도메인 특화 지식을 받아들일 수도, 학습 기준일 이후에 일어난 사건에 관한 질문에 답할 수도 없었다. 2019년에 학습된 모델은 그 사건이 아무리 중요하더라도 2020년에 일어난 일을 알 수 없었다.

이러한 정적 지식의 한계는 외부 지식 소스를 이용해 사실 질문에 답해야 하는 오픈 도메인 [질의응답](/writing/ibm-watson-jeopardy-open-domain-question-answering-nlp-information-retrieval) 같은 지식 집약적 과제에서 특히 문제가 되었다. 연구자들은 더 많은 사실을 모델 매개변수에 부호화하려고 점점 더 큰 데이터셋으로 점점 더 큰 모델을 학습하는 방식으로 이 문제를 해결하고자 했다. 하지만 이 접근법에는 근본적인 한계가 있었다. 학습 데이터에 없는 사실은 언제나 존재했고, 전문성이 필요한 도메인 특화 지식도 있었으며, 시간에 따라 바뀌는 정보도 있었다. 사실을 암기하도록 거대 모델을 학습하는 일은 계산 비용과 환경 비용도 많이 들었으므로, 매개변수 증가만으로 모델을 확장하는 방식의 지속 가능성에 관한 의문이 제기되었다.

전통적인 정보 검색 방법은 외부 지식 소스에 접근할 수 있었지만, 신경망 언어 모델과 함께 사용할 때는 상보적인 난관에 부딪혔다. [BM25](/writing/bm25-probabilistic-ranking-information-retrieval) 같은 방법은 정확한 키워드 일치에 의존했기 때문에 질의와 문서 사이의 의미 변형, 바꿔쓰기, 어휘 불일치를 처리하는 데 어려움을 겪었다. 사용자가 "지구 온난화의 원인은 무엇인가?"라고 물어도 관련 문서에는 정확히 "지구 온난화"라는 구절이 없이 "기후 변화", "온실가스", "탄소 배출" 같은 용어만 쓰였을 수 있다. [용어 빈도](/writing/vector-space-model-tfidf-information-retrieval-semantic-search-history)와 [문서 빈도](/writing/inverse-document-frequency-idf-text-weighting)에 기반한 희소 검색 방법은 이러한 의미 간극을 효과적으로 메우지 못했다.

검색과 신경망 언어 모델을 결합하려던 초기 시도들은 상당한 장애물에 부딪혔다. 일부 시스템은 검색을 전처리 단계로 사용해 관련 문서를 찾은 뒤 언어 모델에 전달했다. 그러나 이 2단계 접근법에서는 검색 시스템과 언어 모델을 따로 학습했기 때문에, 언어 모델이 검색된 정보를 효과적으로 활용하는 법을 배울 방법이 없었다. 검색 시스템이 관련 구절을 찾아내더라도 언어 모델은 이를 생성 과정에 적절히 통합하는 법을 모를 수 있었다.

다른 접근법들은 검색으로 보강한 학습 데이터로 언어 모델을 미세 조정하고자 했지만, 어떤 질의에 어떤 문서가 관련되는지를 보여주는 레이블 학습 데이터가 대량으로 필요했다. 이런 학습 데이터셋을 만드는 일은 노동집약적이고 비용이 많이 들어 접근법의 확장성을 제한했다. 더구나 이 시스템들은 정답이 담긴 정확한 구절을 검색하는 일이 성능에 결정적인 [질의응답](/writing/ibm-watson-jeopardy-open-domain-question-answering-nlp-information-retrieval) 과제에 필요한 정밀한 일치에서 종종 어려움을 겪었다.

핵심 과제는 관련 정보를 검색하고 이를 생성 과제에 효과적으로 사용하는 법을 배울 수 있는 종단 간 학습 가능 시스템을 만드는 것이었다. 이런 시스템에는 정확히 같은 단어가 쓰였는지를 넘어 의미를 포착하고 의미적 유사성에 따라 검색할 수 있게 하는 밀집 의미 표현이 필요했다. 또한 검색과 생성을 매끄럽게 통합해 언어 모델이 검색된 문맥을 조건으로 출력을 만들 수 있어야 했다. 무엇보다 제한된 학습 데이터만으로 이 행동을 배워야 했으며, 사전 학습 모델의 밀집 표현을 최소한의 미세 조정만으로 검색에 맞게 적응시킬 수 있음을 입증해야 했다.

## 해법: 밀집 구절 검색과 검색 증강 생성

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr)과 [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 지식 접근 문제에 상호 보완적인 해법을 제시했다. DPR은 검색 문제를 다루면서 사전 학습 언어 모델의 밀집 벡터 표현을 의미 기반 구절 검색에 효과적으로 사용할 수 있음을 보여주었다. RAG는 DPR의 검색 능력을 토대로 검색과 생성을 종단 간 학습 가능 프레임워크 안에 통합한 단일 시스템을 만들었다.

### 밀집 구절 검색: 최소한의 학습으로 구현한 의미 검색

DPR은 전통적인 희소 검색 방법과 초기 신경망 검색 접근법의 한계를 모두 극복하는 새로운 구절 검색 방식을 소개했다. 핵심 혁신은 [BERT](/writing/bert-bidirectional-pretraining-revolutionizes-language-understanding) 같은 사전 학습 언어 모델의 밀집 벡터 표현을 사용해 질의와 구절을 공유 임베딩 공간에 부호화한 것이다. DPR은 질의와 문서에서 정확히 겹치는 키워드를 맞추는 대신, 의미적으로 유사한 질문과 구절이 이 밀집 벡터 공간에서 서로 가까워지도록 학습했다.

키워드에서 의미로

DPR의 근본적인 통찰은 검색을 키워드 일치 문제가 아니라 의미 유사성 문제로 다루는 것이었다. DPR은 "질의와 문서가 같은 단어를 포함하는가?"가 아니라 "질의와 문서가 의미적으로 유사한가?"라고 물었다. 사전 학습 모델의 밀집 표현을 사용함으로써 DPR은 정확히 같은 단어가 전혀 없더라도 "지구 온난화"에 관한 질문이 "온실가스 배출로 인한 기후 변화"를 논하는 구절과 의미적으로 유사하다는 사실을 알아낼 수 있었다.

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr) 아키텍처는 질의와 구절에 별도의 인코더를 두는 이중 인코더(dual-encoder) 접근법을 사용했다. 두 인코더는 모두 사전 학습된 [BERT](/writing/bert-bidirectional-pretraining-revolutionizes-language-understanding) 모델로 초기화해 사전 학습 중에 이미 습득한 의미 이해를 활용했다. 질의 인코더는 질문을 밀집 벡터로 처리하고, 구절 인코더는 텍스트 구절을 같은 차원의 밀집 벡터로 처리했다. 학습 중 시스템은 질문과 그에 관련된 정답 구절을 임베딩 공간에서 가깝게 배치하는 한편, 관련 없는 구절은 더 멀리 밀어내는 법을 배웠다.

학습 과정에서는 [대조 학습](/writing/clip-contrastive-language-image-pretraining-multimodal) 목적 함수를 사용했다. 질문이 주어지면 시스템은 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)에서 여러 구절을 검색했다. 여기에는 정답을 담은 구절(양성 예시)과 정답이 없는 다른 구절(음성 예시)이 포함되었다. 학습 목적 함수는 질의와 관련 구절 사이의 유사도 점수, 즉 두 [임베딩](/writing/long-term-knowledge-storage-and-retrieval)의 내적으로 측정한 점수가 높아지도록 하는 동시에 질의와 관련 없는 구절 사이의 유사도는 낮아지도록 유도했다. 이 대조 접근법은 사전 학습 모델에 이미 부호화된 의미 지식을 활용할 수 있었으므로, 이전의 신경망 검색 방법보다 훨씬 적은 레이블 학습 데이터가 필요했다.

검색 과정은 간단했다. 질의가 주어지면 질의 인코더로 밀집 벡터에 부호화한 다음, [내적 유사도](/writing/vector-similarity-search-metrics-ann-faiss)를 기준으로 [질의 벡터](/writing/query-key-value-attention-mechanism)와 가장 높은 점수를 보이는 임베딩의 구절을 찾았다. FAISS 같은 [근사 최근접 이웃](/writing/dense-retrieval-semantic-search-bi-encoders) 검색 기법을 사용하면 이 작업을 효율적으로 수행할 수 있어, 수백만 또는 수십억 개의 구절에서 수 밀리초 안에 검색할 수 있었다. [DPR](/writing/contrastive-learning-retrieval-infonce-dpr)은 이러한 밀집 검색 접근법이 기존 신경망 검색 방법보다 훨씬 적은 학습 데이터를 사용하면서도 [질의응답](/writing/ibm-watson-jeopardy-open-domain-question-answering-nlp-information-retrieval) 벤치마크에서 당시 최고 수준의 결과를 달성할 수 있음을 보여주었다.

### 검색 증강 생성: 검색과 언어 모델의 통합

RAG는 DPR의 검색 능력을 토대로 지식 집약적 생성 과제를 위한 통합 시스템을 만들었다. 핵심 혁신은 검색을 단순한 전처리 단계가 아니라 생성 과정의 필수 요소로 다룬 데 있었다. [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 사실을 매개변수에 암기하도록 언어 모델을 학습하는 대신, 검색된 문서를 조건으로 생성하도록 모델을 학습함으로써 학습 데이터의 범위를 훨씬 넘어서는 정보에 접근할 수 있게 했다.

[RAG 아키텍처](/writing/rag-architecture-retriever-generator-design-patterns)는 검색기와 생성기라는 두 가지 주요 구성 요소로 이루어졌다. 검색기는 입력 질의나 프롬프트가 주어지면 DPR을 사용해 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)에서 관련 구절을 찾았다. 생성기는 사전 학습 언어 모델, 일반적으로 [GPT-2](/writing/gpt1-gpt2-autoregressive-pretraining-transfer-learning) 또는 그와 비슷한 모델로, 원래 입력과 검색된 구절을 모두 생성 문맥으로 받았다. 학습 중에는 두 구성 요소를 함께 미세 조정해 생성기가 검색된 정보를 효과적으로 사용하는 법을 배울 수 있게 했다.

검색된 문맥에 조건화한 생성

RAG의 힘은 암기한 지식에만 의존하지 않고 검색된 문서를 조건으로 생성하는 데서 나왔다. "지진의 원인은 무엇인가?"라는 질문에 답할 때 RAG는 먼저 지각판과 지질학적 과정에 관한 관련 구절을 검색한 다음, 그 구절을 문맥으로 사용해 답변을 생성했다. 이 방식은 모델의 학습 데이터에서 충분히 다루지 않은 주제에 대해서도 정확하고 사실적인 생성을 가능하게 했다.

학습 과정에는 질문을 정답 및 그 정답을 담은 구절과 짝지은 데이터셋을 만드는 일이 포함되었다. 각 학습 예시에서 [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 [DPR](/writing/contrastive-learning-retrieval-infonce-dpr) 검색기로 후보 구절을 검색한 다음, 질문과 검색된 구절이 모두 주어졌을 때 올바른 답을 생성하도록 생성기를 미세 조정했다. 이러한 공동 학습을 통해 시스템은 어떤 유형의 질문에 어떤 구절이 가장 유용한지, 검색된 여러 구절의 정보를 어떻게 일관된 생성 텍스트로 통합할지를 배울 수 있었다.

RAG는 RAG-Sequence와 RAG-Token이라는 두 가지 작동 방식을 지원했다. RAG-Sequence 방식에서는 하나의 검색 구절을 사용해 생성 시퀀스 전체를 조건화했으며, 이는 답을 한 구절에서 찾을 수 있을 때 적합했다. RAG-Token 방식에서는 생성 시퀀스의 토큰마다 서로 다른 검색 구절을 사용할 수 있어, 여러 소스의 정보를 더 유연하게 통합할 수 있었다. 두 방식 모두 지식 집약적 과제에서 기준 언어 모델보다 크게 향상된 성능을 보였으며, 여러 문서의 정보가 필요한 복잡한 질문에서는 RAG-Token이 추가적인 유연성을 제공했다.

출처를 인용할 수 있다는 점은 이 시스템의 또 다른 중요한 장점이었다. 생성이 검색된 구절을 명시적으로 조건으로 삼았기 때문에 [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 생성된 주장의 근거를 제시하고, [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)의 어느 구절이 생성 텍스트에 정보를 제공했는지 보여줄 수 있었다. 이 기능은 언어 모델 출력의 투명성과 검증 가능성에 관한 중요한 우려에 대응했으며, 사용자가 출처 구절을 찾아 생성된 주장을 확인할 수 있게 했다.

## 응용과 영향

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr)과 [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 [질의응답](/writing/ibm-watson-jeopardy-open-domain-question-answering-nlp-information-retrieval), 지식 집약적 생성, 최신 정보나 도메인 특화 정보에 접근해야 하는 시스템에 곧바로 적용되었다. 검색과 신경망 언어 모델을 결합하는 능력은 모델 매개변수에 부호화된 범위를 넘어 정보에 접근할 수 있는 지식 인식 AI 시스템을 구축할 새로운 가능성을 열었다.

### 오픈 도메인 질의응답

DPR과 RAG가 가장 직접적으로 적용된 분야는 오픈 도메인 질의응답이었다. 이 분야의 시스템은 대규모 지식 베이스에서 관련 정보를 검색해 사실 질문에 답해야 했다. RAG 시스템은 관련 구절을 검색하고 그 구절을 조건으로 답을 생성함으로써 최근 사건, 도메인 특화 지식, 학습 데이터에 없던 사실에 관한 질문에 답할 수 있었다. 이 능력 덕분에 새 정보가 생길 때마다 비용이 많이 드는 모델 재학습을 하지 않아도 최신 상태를 유지하는 질의응답 시스템을 구축할 수 있었다.

연구 시스템은 [RAG](/writing/long-term-knowledge-storage-and-retrieval)가 [질의응답](/writing/ibm-watson-jeopardy-open-domain-question-answering-nlp-information-retrieval) 벤치마크에서 표준 언어 모델을 능가하는 동시에 더 정확하고 사실적인 출력을 생성할 수 있음을 보여주었다. 검색된 근거를 조건으로 생성할 수 있다는 것은 RAG가 만든 답변이 사실일 가능성이 더 높고 정보를 환각할 가능성은 더 낮다는 뜻이었다. 이처럼 사실 정확도가 향상되면서 RAG는 교육 시스템, 연구 보조 도구, 지식 관리 도구처럼 신뢰할 수 있는 정보가 필요한 응용 분야에서 특히 가치가 높았다.

### 지식 집약적 생성 과제

RAG는 질의응답을 넘어 외부 정보 소스를 활용해야 하는 지식 집약적 생성 과제를 가능하게 했다. 시스템은 관련 문맥을 검색해 최근 뉴스 기사를 요약하거나, 교육 자료를 검색해 복잡한 주제를 설명하거나, 학습 데이터에 없는 도메인 특화 지식이 필요한 콘텐츠를 만들 수 있었다. 이러한 능력은 정확성과 사실적 근거가 중요한 콘텐츠 생성 응용 분야에서 RAG를 유용하게 만들었다.

문서 요약은 또 하나의 중요한 응용 분야였다. [RAG](/writing/long-term-knowledge-storage-and-retrieval) 시스템은 여러 소스의 정보를 통합한 요약을 생성할 수 있어 단일 문서 시스템보다 더 포괄적인 요약을 만들 수 있었다. 관련 주제에 관한 구절을 검색함으로써 요약의 유용성과 정확성을 높이는 문맥과 배경 정보를 제공할 수 있었다.

### 도메인 특화 응용 분야

RAG는 도메인 특화 지식 소스에 접근할 수 있어 전문 응용 분야에서 가치가 높았다. 법률 분야에서는 법률 분석이나 법률 질문에 대한 답을 생성할 때 관련 판례와 법적 선례를 검색할 수 있었다. 의료 분야에서는 의학 정보를 제공할 때 관련 연구 논문이나 임상 지침을 검색할 수 있었다. 기술 분야에서는 기술 질문에 답할 때 문서, 코드 예시, 기술 사양을 검색할 수 있었다.

이러한 도메인 특화 능력은 언어 모델에 전문 도메인 지식을 학습하려면 비용이 많이 드는 데이터 수집과 모델 학습이 필요했기 때문에 특히 중요했다. [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 도메인 특화 지식 베이스를 유지하면서 필요할 때 검색으로 그 지식에 접근하는 대안을 제공했다. 이 모듈식 접근법을 사용하면 새 모델을 학습할 때보다 더 빠르고 비용 효율적으로 시스템을 새로운 도메인에 적응시킬 수 있었다.

### 실시간 정보 접근

RAG의 가장 중요한 장점 가운데 하나는 시간에 따라 바뀌거나 모델 학습 뒤에 새로 공개된 정보에 접근할 수 있다는 점이었다. 전통적인 언어 모델에는 고정된 지식 기준일이 있어 재학습 없이는 새 정보를 받아들일 수 없었다. RAG 시스템은 지식 베이스를 새 문서로 갱신할 수 있었으므로, 모델을 다시 학습하지 않고도 최근 사건, 최신 연구 결과, 새로 공개된 정보에 관한 질문에 답할 수 있었다.

이 능력은 빠르게 전개되는 뉴스의 최신 상태를 따라가야 하는 뉴스 요약 같은 응용 분야에서 유용한 것으로 입증되었다. 또한 새로운 정보가 생길 때마다 갱신할 수 있는 전문 지식 베이스를 유지함으로써 사용자별 또는 조직별 지식을 시스템에 통합할 수 있게 했다.

## 한계와 과제

상당한 장점에도 불구하고 [DPR](/writing/contrastive-learning-retrieval-infonce-dpr)과 [RAG](/writing/long-term-knowledge-storage-and-retrieval)에는 이후 연구에서 다루어야 할 몇 가지 중요한 한계가 있었다. 이러한 한계를 이해하면 이 시스템들이 중요한 이정표였던 이유와 연구가 이 초기 접근법을 넘어 계속 발전한 이유를 함께 파악할 수 있다.

### 검색 품질과 포괄 범위

DPR의 효과는 구절을 검색하는 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)의 품질과 포괄 범위에 달려 있었다. 관련 정보가 지식 베이스에 없거나 특정 주제를 제대로 포괄하지 못한다면, 시스템은 그 주제에 관해 정확한 답을 생성할 수 없었다. 이 한계는 포괄적이고 품질이 높은 지식 베이스를 구축하는 일이 효과적인 RAG 시스템의 중요한 요건으로 남아 있음을 뜻했다.

검색 과정 자체도 여러 방식으로 실패할 수 있었다. 질의 인코더가 질문의 의도를 제대로 이해하지 못하면 관련 없는 구절을 검색할 수 있었다. 구절 인코더가 구절의 의미 내용을 정확히 포착하지 못하면 의미적으로 관련된 구절을 놓칠 수 있었다. 이러한 검색 실패는 생성 단계로 전파되어 부정확하거나 관련 없는 텍스트가 생성될 수 있었다.

### 계산 효율성

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr)은 [근사 최근접 이웃](/writing/dense-retrieval-semantic-search-bi-encoders) 검색을 사용해 대규모 지식 베이스에서 효율적으로 검색할 수 있게 했지만, [RAG](/writing/long-term-knowledge-storage-and-retrieval) 시스템 전체는 여전히 계산 비용이 많이 들었다. 구절을 검색하려면 질의를 부호화하고 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)를 검색한 뒤 검색된 구절을 다시 부호화해야 했다. 텍스트를 생성하려면 검색된 구절이 포함된 [확장 문맥](/writing/long-context-models-processing-million-token-sequences-language-ai) 창으로 언어 모델을 실행해야 했다. 지연 시간 요건이 엄격한 실시간 응용 분야에서는 이러한 계산 오버헤드가 문제가 될 수 있었다.

지식 베이스를 유지하고 갱신해야 한다는 점도 지속적인 계산 비용과 저장 비용을 발생시켰다. 대규모 지식 베이스에는 상당한 저장 용량이 필요했고, 이를 갱신할 때는 구절의 색인을 다시 만들어야 했으므로 계산 비용이 많이 들 수 있었다. 이러한 운영 요건은 자원이 제한된 환경에서 RAG를 적용하는 데 제약이 되었다.

### 문맥 창의 한계

언어 모델에는 제한된 문맥 창이 있었으므로, 생성 문맥에 포함할 수 있는 검색 구절의 수에도 제약이 생겼다. 질문에 서로 다른 많은 소스의 정보가 필요하거나 관련 정보가 여러 개의 긴 구절에 흩어져 있다면, 시스템은 필요한 문맥을 모두 포함하지 못할 수 있었다. 질문에 여러 소스의 포괄적인 정보가 필요한 경우, 이 한계 때문에 답이 불완전하거나 단편적이 될 수 있었다.

생성되는 토큰마다 서로 다른 구절을 사용할 수 있는 [RAG](/writing/long-term-knowledge-storage-and-retrieval)-Token 방식의 순차 생성 과정은 계산 복잡성을 더했다. 검색된 여러 구절을 관리하고 각 생성 단계에 어느 것을 사용할지 결정하려면 추가 처리가 필요했으므로, 이 방식은 RAG-Sequence보다 비용이 많이 들면서도 언제나 그에 비례하는 이점을 제공하지는 않았다.

### 학습 데이터 요건

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr)은 이전 신경망 검색 방법보다 적은 학습 데이터가 필요했지만, 효과적으로 학습하려면 여전히 해당 구절과 연결된 질의응답 쌍이 필요했다. 특히 전문 도메인이나 자원이 부족한 언어에서는 이러한 데이터셋을 만드는 일이 여전히 노동집약적이었다. 학습 데이터의 품질도 시스템 성능에 큰 영향을 미쳤으므로 세심한 선별과 주석이 필요했다.

RAG에서 검색기와 생성기를 공동 학습하려면 어떤 질문에 어떤 구절이 관련되고 어떤 답을 생성해야 하는지 보여주는 데이터셋이 필요했다. 다양한 도메인에 걸친 지식 집약적 과제를 위한 포괄적인 학습 데이터셋을 만드는 일은 여전히 어려웠고, 이 때문에 학습 자원이 풍부한 도메인으로 시스템의 적용 범위가 제한되었다.

### 환각과 사실 정확도

[RAG](/writing/long-term-knowledge-storage-and-retrieval)는 검색된 근거를 조건으로 생성함으로써 표준 언어 모델보다 환각을 줄였지만, 여전히 부정확한 정보를 생성할 수 있었다. 생성기가 검색된 구절을 잘못 해석하거나, 여러 구절의 정보를 잘못 결합하거나, 검색된 근거가 뒷받침하는 범위를 넘어서는 텍스트를 만들 수 있었다. 이러한 한계는 시스템이 관련 원자료에 접근할 수 있더라도 생성 텍스트의 사실 정확도를 보장하는 일이 계속 어려운 과제임을 보여주었다.

검색된 구절에 의존한다는 것은 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)에 존재하는 편향이나 부정확성이 생성 출력으로 전파될 수 있다는 뜻이었다. 지식 베이스에 편향된 정보, 오래된 사실, 특정 주제를 불완전하게 다룬 내용이 있다면 이런 문제가 RAG의 출력에 영향을 미쳤다. 지식 베이스의 품질을 보장하는 일은 실제 운영 시스템에 배포할 때 여전히 중요한 고려 사항이었다.

## 유산과 전망

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr)과 [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 지식 인식 언어 시스템을 구축하는 기본 패러다임으로 검색 증강 생성을 확립했고, 검색과 신경망 언어 모델을 결합하는 현대 AI 시스템의 발전에 영향을 주었다. 이 논문들에서 소개한 기법은 외부 지식 소스에 접근하고 최신 정보를 통합하며 생성된 주장에 출처를 제시해야 하는 차세대 언어 AI 시스템에 필수적인 토대가 되었다.

DPR이 소개한 밀집 벡터 검색 접근법은 신경망 언어 시스템의 [의미 검색](/writing/neural-information-retrieval-semantic-search)을 위한 표준 기법이 되었다. 이후 시스템은 이 아이디어를 확장해 더 정교한 검색 방법, 더 나은 학습 목적 함수, 검색과 생성을 결합하는 개선된 아키텍처를 개발했다. 사전 학습 모델의 밀집 표현을 최소한의 미세 조정만으로 검색에 맞게 적응시킬 수 있다는 근본적인 통찰은 다양한 응용 분야의 검색 증강 시스템에 영향을 미쳤다.

연구에서 프로덕션으로

DPR과 RAG의 연구 프로토타입을 프로덕션 시스템으로 전환하려면 확장 가능한 지식 베이스 관리, 대규모 환경의 효율적인 검색, 기존 소프트웨어 인프라와의 통합을 비롯한 수많은 공학적 과제를 해결해야 했다. 이러한 실무적 고려 사항은 이후 프로덕션 수준의 검색 증강 시스템 연구를 촉진했다.

현대의 검색 증강 챗봇과 가상 비서는 [DPR](/writing/contrastive-learning-retrieval-infonce-dpr)과 [RAG](/writing/long-term-knowledge-storage-and-retrieval)가 놓은 토대 위에 직접 세워졌다. 이 시스템들은 [밀집 검색](/writing/dense-retrieval-semantic-search-bi-encoders)과 대규모 언어 모델을 결합해 학습 중에 부호화된 범위를 넘어서는 정보에 접근할 수 있는 유용하고 정확한 답변을 제공한다. 대화 중 관련 정보를 검색하는 능력은 더 많은 정보와 문맥을 반영한 답변을 가능하게 하며, 모델을 재학습하지 않고도 시스템이 최신 정보를 유지할 수 있게 한다.

검색과 언어 모델의 통합은 여러 지식 소스를 결합하고, 여러 차례 이어지는 대화 중에 정보를 동적으로 검색하며, 생성된 주장에 출처를 제시하는 시스템의 발전에도 영향을 미쳤다. 언어 AI 시스템이 정확성, 투명성, 최신 정보 접근이 필요한 응용 분야에 배포되면서 이러한 능력은 점점 더 중요해졌다.

DPR과 RAG 이후의 연구는 학습된 희소-밀집 혼합 표현을 사용하는 더 나은 검색 방법, 검색과 생성을 위한 개선된 학습 목적 함수, 검색된 여러 구절을 더 잘 통합하는 아키텍처, 지식 베이스를 효율적으로 갱신하는 기법 등 수많은 개선책을 탐구했다. 또한 검색된 정보를 추론하고, 여러 소스의 근거를 결합하며, 서로 충돌하는 정보를 적절히 처리할 수 있는 검색 증강 시스템도 연구하게 되었다.

[DPR](/writing/contrastive-learning-retrieval-infonce-dpr)과 [RAG](/writing/long-term-knowledge-storage-and-retrieval)는 지식 집약적 언어 AI의 미래가 오직 더 많은 사실을 암기하도록 점점 더 큰 모델을 학습하는 데만 있지 않고, 외부 지식 소스를 효과적으로 검색하고 그 위에서 추론할 수 있는 아키텍처를 만드는 데 있음을 보여주었다. 이 통찰은 신경망 모델의 의미 이해, 검색 시스템의 지식 접근, 이후 연구에서 출현할 추론 능력을 결합해야 하는 차세대 언어 AI 시스템의 근본적인 토대가 되었다. 검색 증강 생성으로의 패러다임 전환은 효과적인 언어 AI 시스템이 여러 능력을 통합해야 한다는 사실을 인정한 것이었다.

# Raw Artifacts

이 디렉터리는 수집 당시의 원문, 번역, 해설, 클리핑 자료를 보존한다. 파일이 이곳에 있다는 사실은 내용이 검증됐다는 뜻이 아니다.

## 사용법

1. 웹 아티클, 논문, 보고서, 번역, 해설을 역할이 드러나는 파일명으로 저장
2. 이미지·PDF 등 첨부파일은 `assets/` 하위 폴더에 저장
3. `wiki/meta/raw-artifacts.yml`에 역할, 출처 상태, 원문 `source_url`과 SHA-256 해시 등록
4. 외부 문헌은 `wiki/meta/evidence.yml`에 별도 등록
5. LLM에게 "새 소스 처리해줘" 또는 파일명을 지정하여 처리 요청

## 규칙

- ⚠️ **등록된 artifact는 LLM이 수정하거나 덮어쓰지 않습니다.**
- 이 디렉터리는 사실의 source of truth가 아니라 수집 상태의 보존 계층입니다.
- 검증된 설명의 기준은 `wiki/` 문서와 locator가 있는 `evidence`입니다.
- 오류·결손은 raw를 고치지 않고 위키의 `검증 정정` 또는 `원문 상태` 절에 기록합니다.
- 운영 문서인 이 `README.md`는 artifact 해시 대상이 아니며 스키마 변경 시 갱신할 수 있습니다.

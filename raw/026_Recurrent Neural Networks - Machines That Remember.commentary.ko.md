# 순환 신경망과 학습 가능한 상태 해설

## 1. 한눈에 보기

- 핵심 주제: 현재 입력과 이전 은닉 상태를 함께 계산해 순서열의 앞선 정보를 다음 시점으로 전달하는 순환 신경망(Recurrent Neural Network, RNN)
- 등장 배경: 고정 길이 입력만 처리하는 순방향 신경망을 넘어, 길이가 달라지는 음성·문장·시계열에서 같은 매개변수를 반복 사용하려는 연구
- 가장 중요한 아이디어: $h_t=f(W_{xh}x_t+W_{hh}h_{t-1}+b_h)$처럼 **학습 가능한 상태 전이**를 두고, 시간마다 같은 가중치를 공유한다.
- 이후 LLM/NLP에 남긴 영향: 신경 언어 모델과 encoder–decoder 계열의 기반, BPTT를 통한 순서열 학습, 장거리 의존성 문제를 드러내 LSTM·attention 연구를 촉진한 점

> 이 문서는 `026_Recurrent Neural Networks - Machines That Remember.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 RNN의 상태와 학습을 정확히 설명하고, “1995년에 RNN이 실용화됐다”는 연대, 이전 신경망은 문맥을 전혀 다루지 못했다는 서술, 모든 현대 언어 모델이 RNN의 직접 후손이라는 계보를 1차 문헌에 맞춰 교정합니다.

## 2. 핵심 요약

RNN은 한 시점의 입력 $x_t$와 직전 상태 $h_{t-1}$를 결합해 새 상태 $h_t$를 계산하는 신경망 계열이다. 같은 상태 전이 함수를 모든 시점에 반복 적용하므로 입력 길이에 비례해 새 매개변수를 만들지 않고도 가변 길이 순서열을 다룰 수 있다. 이때 은닉 상태는 과거를 그대로 보관하는 저장소가 아니라, 현재 과제의 손실에 맞춰 학습되는 **고정 차원 수치 벡터**다. 따라서 “기억”이라는 표현은 유용한 비유이지만 모든 앞선 입력을 정확히 복원하거나 무한히 유지한다는 뜻은 아니다.

훈련할 때는 순환 연결을 유한한 시간축으로 펼친 뒤 같은 가중치가 여러 시점에서 받은 기여를 합산한다. 이 절차가 시간 역전파(backpropagation through time, BPTT)다. 긴 시간축에서는 연쇄된 야코비안 곱 때문에 그래디언트가 특정 방향에서 작아지거나 커질 수 있어 장거리 의존성을 배우기 어렵다. 1994년 Bengio·Simard·Frasconi의 분석과 1997년 LSTM은 이 문제를 이해하고 완화하려는 중요한 이정표였다.

다만 RNN이 1995년에 갑자기 등장해 순서열 처리를 “혁명”했다는 원문의 중심 연대는 성립하지 않는다. Jordan의 1986년 보고서, Williams·Zipser의 1989년 순환망 학습 연구, Elman의 1990년 단순 순환망, Werbos의 1990년 BPTT 논문이 1995년 전에 핵심 구조와 학습법을 제시했다. 1995년은 Hochreiter·Schmidhuber의 LSTM 원고가 접수된 해로 기록할 수 있지만, 논문 출판은 1997년이다.

RNN은 음성 인식·언어 모델·품사 태깅·필기 인식에 중요한 신경망 방법을 제공했지만, 이런 과제를 처음 가능하게 한 것은 아니다. n-gram, 은닉 마르코프 모델(HMM), 시간 지연 신경망(TDNN), 수작업 특징과 통계 모델이 이미 순서와 제한된 문맥을 다루고 있었다. RNN의 더 정확한 기여는 **고정된 창이나 명시적 상태 목록 대신 학습 가능한 연속 상태 전이로 문맥을 압축**하고, 이를 여러 과제에 재사용한 데 있다.

- 무엇을 다루는가: RNN의 순환 상태, 시간축 가중치 공유, 펼치기, BPTT, 순서열 응용, 기울기 소실·폭주와 후속 구조
- 어떤 문제를 해결하려 했는가: 길이가 달라지는 순서열에서 앞선 입력을 이후 계산에 반영하는 문제
- 어떤 방식이 새로웠는가: 동일한 신경 상태 전이를 시간마다 반복하고 그 상태 자체를 데이터에서 학습한 점
- 결과적으로 무엇을 바꾸었는가: 신경 언어 모델과 순서열 변환 연구의 공통 틀을 제공하고, 장기 기억과 병렬 계산이라는 새로운 설계 문제를 명확히 드러낸 점

## 3. 역사적 배경

순서 정보를 다루는 문제는 RNN 이전에도 존재했다. n-gram 언어 모델은 직전 몇 개 토큰의 빈도로 다음 토큰을 추정했고, HMM은 이산적인 잠재 상태와 확률적 전이로 음성·품사열을 모델링했다. TDNN은 고정된 시간 창에 공유 가중치를 적용해 국소 패턴의 시간 이동을 학습했다. 따라서 “이전 모델은 매 입력을 완전히 고립시켰다”는 원문의 대비는 일반적인 순방향 다층 퍼셉트론에는 해당하지만, 당시의 순서열 처리 전체를 설명하지는 못한다.

RNN의 역사도 1995년 한 해로 묶을 수 없다.

1. **1986년**: Michael I. Jordan은 *Attractor Dynamics and Parallelism in a Connectionist Sequential Machine*에서 이전 상태와 출력을 상태 단위로 되먹임하는 순환 구조를 다뤘다. 오늘날 흔히 말하는 Elman형 RNN과 피드백의 출발점이 다르므로 둘을 같은 구조로 합치지 않는다.
2. **1989년**: Ronald J. Williams와 David Zipser는 순환망의 실시간 학습 알고리즘 RTRL을 발표했고, 목표 출력을 다음 단계의 피드백으로 사용하는 절차에 **teacher forcing**이라는 이름을 붙여 기술했다. 논문도 Jordan과 Pineda의 선행 사용을 인용하므로 이 방법의 유일한 발명 시점으로 부르지 않는다. 같은 논문은 1986년의 펼친 네트워크 학습 접근을 BPTT라고 부르며 RTRL과 계산 방식을 구분했다.
3. **1990년**: Jeffrey L. Elman은 Jordan의 제안을 발전시키되, 은닉층 활성을 한 시점 늦춰 문맥 단위에 복사하는 단순 순환망으로 문자·단어 순서에서 시간적 구조를 학습하는 실험을 보고했다. 같은 해 Paul J. Werbos는 역전파를 동적 시스템의 시간축에 적용하는 방법을 정리했다. 따라서 BPTT를 1990년 한 논문의 단독 발명으로 기록하지 않는다.
4. **1994년**: Yoshua Bengio·Patrice Simard·Paolo Frasconi는 그래디언트 기반 학습이 장기 의존성을 배우기 어려운 이유를 이론과 실험으로 분석했다. 같은 해 Tony Robinson은 음소 확률 RNN을 HMM과 결합해 기존 방식과 경쟁력 있는 음성 인식 결과를, Helmut Schmid는 출력 피드백을 둔 태거로 한 설정에서 trigram·HMM 기준선을 조금 웃도는 품사 태깅 결과를 보고했다. 이는 “1995년 이후에야 실용 연구가 시작됐다”는 서술의 반례이지만 RNN 일반의 보편적 우월성을 입증하지는 않는다.
5. **1997년**: Sepp Hochreiter와 Jürgen Schmidhuber가 LSTM을 출판했다. 원 논문은 입력 게이트·출력 게이트와 constant error carousel을 사용했고, 오늘날 표준 LSTM에 익숙한 망각 게이트(forget gate)는 Gers·Schmidhuber·Cummins가 2000년에 추가했다.
6. **2014–2017년**: GRU, RNN encoder–decoder와 sequence-to-sequence 학습, attention, Transformer가 차례로 RNN의 장기 정보 압축과 순차 계산 제약에 다른 해법을 제시했다. 공통 문제를 다뤘다는 사실과 한 논문에서 모두 직접 파생됐다는 주장은 구분해야 한다.

- 이전 접근법: n-gram, HMM, 고정 창 순방향망, TDNN, 수작업 시계열 특징과 동적 모델
- 당시의 한계: 고정 문맥 창, 사람이 정한 이산 상태, 가변 길이 의존성을 하나의 학습 가능한 신경 상태로 표현하기 어려운 점
- 이 주제가 필요했던 이유: 위치마다 별도 매개변수를 두지 않으면서 과거 정보를 다음 계산으로 전달하고, 표현과 상태 전이를 과제 손실에서 함께 학습할 필요가 있었기 때문

## 4. 핵심 개념 해설

### 4.1 은닉 상태와 시간축 가중치 공유

가장 단순한 RNN은 다음처럼 쓸 수 있다.

\[
h_t=\phi(W_{xh}x_t+W_{hh}h_{t-1}+b_h)
\]

\[
o_t=g(W_{ho}h_t+b_o)
\]

$x_t$는 현재 입력, $h_{t-1}$는 이전 은닉 상태, $h_t$는 새 은닉 상태, $o_t$는 출력이다. $W_{xh}$·$W_{hh}$·$W_{ho}$는 시점 $t$가 바뀌어도 같은 값이 사용된다. 이 공유 덕분에 모델은 10개 토큰과 100개 토큰에 같은 전이 규칙을 적용하고, 한 위치에서 배운 패턴을 다른 위치에도 사용할 수 있다.

은닉 상태는 “지금까지 본 모든 것”의 완전한 기록이 아니다. 이전 상태에서 새 상태로 갈 때 필요한 정보가 손실될 수 있고, 무엇을 보존할지는 모델 용량·활성화 함수·데이터·손실·최적화에 달린다. 상태 차원이 고정됐다는 사실만으로 언제 정보가 사라질지 계산할 수도 없지만, 상태 하나에 긴 이력을 계속 압축해야 하는 것이 vanilla RNN과 초기 encoder–decoder의 중요한 제약인 것은 맞다.

### 4.2 시간축 펼치기와 BPTT

순환망의 정적 그림에는 되먹임 고리가 있지만, 길이 $T$인 관측 순서열에 대해 계산을 **펼치면** $h_0\rightarrow h_1\rightarrow\cdots\rightarrow h_T$인 유한한 비순환 계산 그래프가 된다. 각 시점의 셀은 복사본처럼 그려져도 실제로는 같은 매개변수를 공유한다. 그러므로 원문의 “계산 그래프에 사이클을 만든다”는 말은 접힌 구조에는 맞지만, BPTT가 미분하는 펼친 그래프에도 사이클이 남는다는 뜻으로 읽으면 안 된다.

BPTT는 펼친 그래프에 일반 역전파를 적용한다. 여러 시점에서 같은 $W_{hh}$를 사용했으므로 각 사용 지점의 그래디언트를 합해 하나의 행렬을 갱신한다. 전체 순서열을 모두 펼치면 메모리와 계산 비용이 길이에 따라 증가하기 때문에 실무에서는 일정 구간만 역전파하는 truncated BPTT를 자주 쓴다. 이는 계산을 줄이는 대신 구간보다 먼 학습 신호를 잘라 낼 수 있다.

Williams·Zipser의 RTRL은 시간 순서대로 정확한 그래디언트를 갱신하는 다른 방법이지만 매 시점의 계산·저장 비용이 커서 표준적인 큰 모델 훈련법이 되지 못했다. BPTT도 마지막 시점의 오차에만 제한되지 않으며, 여러 시점에서 정의한 손실을 합해 역전파할 수 있다. “RNN 훈련=BPTT 하나”나 “BPTT=마지막 출력의 오차만 전달”로 단순화하기보다 구조·손실·학습 알고리즘을 분리해야 한다.

### 4.3 기울기 소실과 폭주

먼 시점의 상태가 현재 손실에 미치는 미분에는 대략 다음과 같은 야코비안 곱이 들어간다.

\[
\frac{\partial h_t}{\partial h_k}
=
\prod_{i=k+1}^{t}
\frac{\partial h_i}{\partial h_{i-1} }
\]

각 국소 야코비안이 관련 방향을 반복해서 줄이면 그래디언트가 소실되고, 반복해서 키우면 폭주한다. 원문처럼 “가중치 행렬의 고윳값이 1보다 작거나 크기 때문”이라고만 설명하면 활성화 함수의 도함수, 시점별 상태, 행렬 방향과 비정규성까지 빠진다. 실제 조건은 반복되는 **전체 야코비안의 곱**과 그 방향별 크기를 봐야 한다.

sigmoid와 tanh의 포화 구간은 작은 도함수를 만들 수 있어 소실을 악화하지만, 이 함수만이 원인은 아니다. 그래디언트 클리핑은 폭주한 그래디언트의 노름을 제한해 훈련을 안정시키지만 이미 사라진 장거리 학습 신호를 복원하지는 못한다. Pascanu·Mikolov·Bengio의 2013년 연구는 RNN에서 소실·폭주의 기하를 분석하고 노름 기반 클리핑에 이론적 근거를 제시한 대표 자료다. 저자들 역시 앞선 Mikolov의 변형과 유사하다고 밝혔으므로 클리핑 자체를 이 논문의 단독 발명으로 기록하지 않는다.

### 4.4 상태, 출력, 과제 형태를 구분하기

RNN은 매 시점 출력을 내는 언어 모델·품사 태깅, 마지막 상태로 전체 순서열을 분류하는 모델, 한 순서열을 다른 순서열로 바꾸는 encoder–decoder처럼 여러 입출력 형태로 사용할 수 있다. “I love cats”를 한 단어씩 넣어 다음 단어 분포를 내는 원문의 예시는 **자기회귀 언어 모델** 한 종류를 설명할 뿐 모든 RNN의 동작을 정의하지 않는다.

입력 단어는 그대로 행렬에 들어가는 문자열이 아니라 보통 원-핫 벡터나 학습된 임베딩으로 표현된다. 출력도 항상 softmax일 필요는 없다. 분류에서는 softmax를, 이진 결정에서는 sigmoid를, 회귀에서는 선형 출력을 쓸 수 있다. RNN 구조, 입력 표현, 출력 손실을 나눠야 “순환 연결 하나가 문법과 의미를 자동으로 이해한다”는 과장을 피할 수 있다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개된다.

1. **1995년 전환점 제시**: 이전 순방향망은 과거를 전혀 기억하지 못했고 1995년 RNN이 이를 해결했다고 주장한다.
2. **순환 상태 소개**: 현재 입력과 이전 은닉 상태를 결합해 시간에 따라 변하는 내부 기억을 만든다고 설명한다.
3. **수학적 형식화**: 상태 전이와 출력 식, 시간축 가중치 공유, 순차 계산의 장단점을 제시한다.
4. **펼치기와 학습**: 접힌 순환 구조를 시간축으로 펼치고 BPTT로 그래디언트를 구한다고 설명한다.
5. **예시와 응용**: “I love cats” 다음 단어 예측에서 음성 인식·품사 태깅·필기·시계열 예측으로 범위를 넓힌다.
6. **한계 제시**: 기울기 소실·폭주, 고정 크기 상태의 병목, 직렬 계산을 vanilla RNN의 핵심 문제로 정리한다.
7. **후대 계보 구성**: LSTM·GRU·attention·Transformer·GPT·BERT를 RNN이 세운 순차 처리 패러다임의 연속선에 놓는다.

이 서술은 RNN의 직관과 수식을 연결하는 데는 유용하다. 그러나 **1995년이라는 연대**, **RNN 이전에는 순서 처리가 불가능했다는 대비**, **응용이 즉시 가능해졌다는 성능 주장**, **현대 LLM 전체가 RNN에 직접 빚졌다는 계보**를 한꺼번에 받아들이면 역사가 왜곡된다. 해설에서는 구조와 수학으로 확인되는 사실, 여러 연구를 종합한 역사적 평가, 별도 인용이 필요한 직접 영향 주장을 분리한다.

## 6. 왜 중요한가

RNN의 중요한 공헌은 “기억하는 기계”라는 수사보다 **학습 가능한 상태 전이**를 범용 신경망 부품으로 만든 데 있다. HMM은 사람이 정한 수의 이산 상태와 명시적인 확률 분해를 사용한다. RNN은 연속 벡터 상태와 비선형 전이를 데이터에서 학습해, 과제에 필요한 구분을 상태 공간 안에 형성할 수 있다. 해석 가능성이 자동으로 높아지는 것은 아니지만 표현의 유연성은 커졌다.

둘째, 시간축 매개변수 공유는 입력 길이와 위치에 대한 중요한 귀납 편향이다. 같은 단어나 음향 패턴이 어느 위치에 나타나도 같은 전이 규칙으로 처리할 수 있고, 서로 다른 길이의 순서열을 같은 모델로 학습할 수 있다. 이는 모든 시간 위치에 별도 가중치를 두는 순방향망보다 매개변수를 훨씬 효율적으로 사용한다.

셋째, RNN의 실패 양상은 후속 연구의 질문을 구체화했다. 장거리 그래디언트가 왜 사라지는가, 상태에 무엇을 오래 보존할 것인가, 모든 입력을 한 벡터에 압축해야 하는가, 시간축 계산을 병렬화할 수 있는가라는 질문이 LSTM, attention, Transformer를 이해하는 기준이 됐다. 후속 구조를 RNN의 단순한 “업그레이드”로 부르지 않아도, RNN이 드러낸 병목이 연구 의제를 형성했다는 평가는 가능하다.

특히 중요한 점:

- 고정 창 대신 학습된 연속 상태로 가변 길이의 앞선 문맥을 전달한 점
- 한 상태 전이의 매개변수를 모든 시점에서 공유해 위치 독립성과 데이터 효율을 얻은 점
- 장거리 의존성·고정 상태 병목·직렬 계산을 후속 순서열 모델의 명확한 설계 문제로 만든 점

## 7. 현대 LLM과의 연결

### 7.1 자기회귀 언어 모델의 확률 분해

RNN 언어 모델과 GPT 계열은 다음 토큰 확률을 앞선 토큰에 조건화한다는 점에서 같은 자기회귀 분해를 사용할 수 있다.

\[
p(x_{1:T})=\prod_{t=1}^{T}p(x_t\mid x_{<t})
\]

차이는 문맥을 계산하는 방식이다. RNN은 과거를 상태 $h_t$에 순차적으로 압축한다. Transformer decoder는 위치별 표현 사이의 masked self-attention으로 앞선 위치를 직접 참조하고, 학습 시 여러 위치의 계산을 병렬화할 수 있다. 다만 Transformer도 자기회귀 **생성**에서는 이전에 생성한 토큰을 조건으로 다음 토큰을 내므로 출력 단계 자체는 순차적이다.

### 7.2 encoder–decoder에서 attention으로

Sutskever·Vinyals·Le의 2014년 sequence-to-sequence 모델은 한 RNN이 입력 순서열을 고정 차원 벡터로 읽고 다른 RNN이 출력을 생성하게 했다. 이는 RNN에서 신경 기계 번역으로 이어지는 직접적인 계보다. 그러나 긴 문장을 하나의 벡터로 압축하는 병목이 있었고, Bahdanau·Cho·Bengio의 attention은 출력 시점마다 입력 위치의 은닉 상태를 가중 결합하게 해 이 병목을 완화했다.

2017년 Transformer는 순환을 보존한 채 attention을 더한 모델이 아니라, encoder와 decoder의 중심 순서열 연산에서 recurrence와 convolution을 제거하고 self-attention을 사용한 구조다. RNN이 다루던 문제를 이어받았다는 넓은 역사적 연결은 가능하지만, Transformer의 모든 핵심 연산이 RNN에서 직접 유래했다고 말할 수는 없다.

### 7.3 GPT와 BERT를 같은 “시간적 기억”으로 묶지 않기

GPT의 causal language modeling은 왼쪽 문맥만 사용하므로 RNN 다음 단어 예측과 과제 형식을 직접 비교하기 쉽다. BERT의 masked language modeling은 가려진 위치의 양쪽 문맥을 함께 사용하므로 “언어가 시간순으로 펼쳐지고 이전 상태만 기억한다”는 RNN 서사에 그대로 들어맞지 않는다. 두 모델 모두 고정된 하나의 은닉 상태에 전체 문맥을 압축하지 않고 위치별 표현을 유지한다.

현대적 연결은 다음처럼 제한해 표현하는 편이 정확하다.

- **자기회귀 모델링**: RNN 언어 모델과 GPT는 같은 조건부 확률 분해를 서로 다른 문맥 계산기로 구현한다.
- **순서열 변환**: RNN encoder–decoder는 신경 기계 번역과 sequence-to-sequence 학습의 직접 선행 구조다.
- **attention과 Transformer**: RNN의 고정 벡터 병목과 직렬 계산 제약에 대응한 후속 연구이지만, recurrence를 그대로 계승한 구조는 아니다.
- **도구·에이전트의 상태**: 대화 기록이나 외부 메모리를 유지하는 LLM 시스템은 RNN 은닉 상태와 비슷한 “기억” 비유를 쓸 수 있으나, 저장 위치·갱신 규칙·학습 방식이 다르므로 같은 메커니즘으로 부르지 않는다.

### 8.2 사실, 해석, 직접 계보의 경계

- **확인된 사실**: vanilla RNN은 이전 상태와 현재 입력으로 새 상태를 계산하고 시간마다 매개변수를 공유한다. BPTT는 펼친 시간축에 역전파를 적용한다. 1994년 장기 의존성 분석, 1997년 LSTM, 2000년 forget gate 논문이 각각 존재한다.
- **근거 있는 해석**: 학습 가능한 연속 상태는 신경 순서열 모델링의 범용 틀을 제공했고, RNN의 장거리 학습과 직렬 계산 문제는 후속 구조의 중요한 연구 동기가 됐다.
- **직접 계보가 확인되는 연결**: LSTM과 GRU는 recurrent state를 게이트로 갱신하며, RNN encoder–decoder와 그 병목을 다룬 attention 논문 사이에는 설계·인용 관계가 있다.
- **더 약한 개념적 연결**: Transformer·GPT·BERT가 모두 문맥을 다룬다는 사실만으로 RNN의 직접 후손이 되지는 않는다. 각 모델의 핵심 연산, 학습 목표와 직접 인용을 따로 확인해야 한다.

### 8.3 기술적·실용적 한계

- **장거리 학습**: 상태가 이론적으로 먼 과거에 의존할 수 있어도 BPTT의 학습 신호는 소실하거나 폭주할 수 있다.
- **직렬 계산**: $h_t$가 $h_{t-1}$에 의존하므로 한 순서열 안의 시간 단계 병렬화가 어렵다. 배치·층·행렬 연산 수준의 병렬화까지 불가능하다는 뜻은 아니다.
- **상태 병목**: vanilla RNN과 고정 벡터 encoder는 긴 입력의 모든 과제 관련 정보를 제한된 상태에 압축해야 한다.
- **노출 편향**: teacher forcing으로 학습할 때는 정답 이전 출력을 보지만 생성할 때는 자신의 출력을 보므로 오류가 누적될 수 있다.
- **해석 가능성**: 연속 상태가 HMM보다 유연하다는 사실이 그 상태의 각 차원을 사람이 해석할 수 있다는 뜻은 아니다.
- **응용별 전처리**: 초기 음성·필기 RNN도 음향 특징, 경계, 정렬, 하이브리드 HMM 등 상당한 설계를 사용했다. “특징 공학 없이 원자료에서 직접 학습했다”는 일반화는 피해야 한다.

Jordan의 [1986년 순서 수행 구조](https://escholarship.org/uc/item/1fg2j76h)(pp. 533–536, Fig. 1), Williams·Zipser의 [1989년 순환망 학습 논문](https://doi.org/10.1162/neco.1989.1.2.270)(pp. 270–275), Elman의 [1990년 *Finding Structure in Time*](https://doi.org/10.1207/S15516709COG1402_1)(pp. 182–185, 197–203), Werbos의 [1990년 동적 신경망 역전파 논문](https://doi.org/10.1109/5.58337), Bengio·Simard·Frasconi의 [1994년 장기 의존성 분석](https://doi.org/10.1109/72.279181), Robinson의 [1994년 음소 확률 RNN](https://doi.org/10.1109/72.279192)(pp. 298–305), Schmid의 [1994년 Net-Tagger](https://aclanthology.org/C94-1027/)(pp. 172–175)를 사용했다. LSTM 관련 연대와 구조는 Hochreiter·Schmidhuber의 [1997년 LSTM](https://doi.org/10.1162/neco.1997.9.8.1735)(원고 접수 1995년 8월 28일, pp. 1735–1740)과 Gers·Schmidhuber·Cummins의 [2000년 forget gate 논문](https://doi.org/10.1162/089976600300015015)(pp. 2451–2454)으로 확인했다.

후대 연결은 Cho 등의 [2014년 RNN encoder–decoder](https://doi.org/10.3115/v1/D14-1179)(pp. 1725–1726), Sutskever·Vinyals·Le의 [2014년 sequence-to-sequence 논문](https://papers.nips.cc/paper/5346-sequence-to-sequence-learning-with-neural-networks)(pp. 3104–3108), Bahdanau·Cho·Bengio의 [attention 기반 번역 논문](https://arxiv.org/abs/1409.0473)(초록과 §1), Pascanu·Mikolov·Bengio의 [2013년 기울기 분석](https://proceedings.mlr.press/v28/pascanu13.html)(pp. 1310–1315), Vaswani 등의 [2017년 Transformer 논문](https://proceedings.neurips.cc/paper/7181-attention-is-all-you-need)(pp. 5998–6002)으로 범위를 확인한다. 이 문헌이 지지하는 직선 계보는 LSTM을 사용한 sequence-to-sequence, RNN encoder–decoder의 고정 벡터 병목을 완화한 attention, attention을 유지하면서 recurrence를 제거한 Transformer까지다. GPT와 BERT 전체가 1995년 RNN 한 사건에서 직접 파생됐다는 주장까지 지지하지는 않는다.

## 9. 용어 정리

| 용어 | 설명 |
| --- | --- |
| 순환 신경망(RNN) | 이전 상태를 현재 계산에 다시 입력하는 신경망 계열 |
| recurrent connection | 한 시점의 상태나 출력이 이후 시점의 계산으로 되먹임되는 연결 |
| hidden state | 이전 상태와 현재 입력으로 갱신되는 고정 차원 수치 표현. 과거의 완전한 기록과는 다르다. |
| state transition | $h_{t-1}$와 $x_t$를 $h_t$로 바꾸는 공유 함수 |
| parameter sharing | 같은 가중치를 모든 시간 위치에 반복 적용하는 설계 |
| unrolling / unfolding | 순환 구조를 관측한 시간 단계만큼 복사해 비순환 계산 그래프로 나타내는 방식 |
| BPTT | 펼친 시간축에 역전파를 적용해 공유 매개변수의 그래디언트를 구하는 학습법 |
| truncated BPTT | 제한된 시간 구간만 역전파해 계산·메모리를 줄이는 근사 훈련법 |
| RTRL | 시간 순서대로 순환망의 정확한 그래디언트를 갱신하는 온라인 학습법. 계산 비용이 크다. |
| 장거리 의존성 | 멀리 떨어진 두 시점의 정보가 현재 예측이나 손실에 함께 필요한 관계 |
| 기울기 소실·폭주 | 반복된 야코비안 곱으로 그래디언트가 매우 작아지거나 커지는 현상 |
| gradient clipping | 그래디언트 노름이나 값을 임계 범위로 제한해 폭주를 완화하는 기법 |
| teacher forcing | 훈련 때 모델의 이전 예측 대신 정답 이전 출력을 다음 단계 입력으로 쓰는 절차 |
| LSTM | 장기 오류 흐름과 선택적 상태 갱신을 위해 셀과 게이트를 도입한 순환 구조 |
| attention | 출력 시점마다 입력 위치들의 표현을 가중 결합해 필요한 정보를 직접 참조하는 메커니즘 |

## 12. 짧은 결론

RNN은 1995년에 돌연 등장한 단일 발명이 아니라 1980년대 중반부터 1990년대 초까지 순환 구조와 학습 알고리즘이 누적되며 형성된 연구 계열이다. 그 핵심은 과거를 완벽히 보관하는 장치를 만든 데 있지 않고, 같은 비선형 상태 전이를 시간마다 공유해 가변 길이 문맥을 데이터에서 학습하게 한 데 있다. 이 틀은 신경 언어 모델과 sequence-to-sequence 학습을 가능하게 한 중요한 기반이었지만, 장거리 그래디언트, 고정 상태 압축, 직렬 계산이라는 한계도 분명히 드러냈다. LSTM과 GRU는 순환 상태의 갱신을 개선했고, attention과 Transformer는 입력 위치를 직접 참조하거나 recurrence 자체를 제거하는 다른 해법을 택했다. 따라서 RNN의 역사적 위치는 모든 현대 LLM의 유일한 조상이라기보다, **학습 가능한 문맥 상태의 가능성과 한계를 동시에 입증해 후속 순서열 모델의 질문을 정교하게 만든 전환점**으로 보는 것이 정확하다.

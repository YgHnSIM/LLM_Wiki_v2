# Flamingo의 퓨샷 시각-언어 학습 해설

## 1. 한눈에 보기

- 핵심 주제: 사전학습된 시각 인코더와 인과적 언어 모델을 동결한 채, 그 사이에 학습 가능한 연결 모듈을 삽입해 이미지·동영상·텍스트가 섞인 프롬프트를 처리하는 방법
- 등장 배경: GPT-3는 텍스트 예시만으로 새 과제에 적응하는 인컨텍스트 학습을 보여 주었고, CLIP은 이미지와 텍스트 표현을 대규모로 정렬했지만, 하나의 생성 모델이 여러 시각-언어 과제를 예시 몇 개만 보고 수행하는 문제는 남아 있었다.
- 가장 중요한 아이디어: Perceiver Resampler로 가변 길이의 시각 특징을 고정 개수의 토큰으로 압축하고, 0에서 시작하는 `tanh` 게이트가 붙은 교차 어텐션으로 그 토큰을 동결 언어 모델에 주입한다.
- 이후 LLM/NLP에 남긴 영향: 언어 모델의 생성·인컨텍스트 학습 능력을 유지하면서 별도의 지각 모듈을 연결하는 설계가 실용적인 멀티모달 모델의 한 경로임을 보여 주었다. 다만 특정 후속 모델이 Flamingo에서 직접 계승했다는 주장은 각 모델 논문의 인용과 구조 비교로 따로 확인해야 한다.

> 이 문서는 `084_Flamingo Few-Shot Vision-Language Learning with Gated Cross-Attention.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 모델 안에서 시각 정보가 이동하는 경로, 퓨샷 평가가 뜻하는 바, 그리고 원문 서술에서 구분해야 할 사실과 해석을 정리합니다.

## 2. 핵심 요약

Flamingo는 2022년에 발표된 자기회귀 시각-언어 모델 계열로, 입력 프롬프트 안에 이미지나 동영상과 텍스트를 임의로 번갈아 놓을 수 있고 출력은 텍스트로 생성한다. 연구진은 강한 사전학습 시각 인코더와 언어 모델의 가중치를 고정하고, 두 모달리티를 잇는 Perceiver Resampler와 GATED XATTN-DENSE 블록만 새로 학습했다. Resampler는 해상도나 동영상 프레임 수에 따라 길이가 달라지는 시각 특징을 이미지·동영상마다 고정된 수의 잠재 토큰으로 바꾼다. 교차 어텐션에서는 언어 은닉 상태가 질의가 되고 시각 토큰이 키와 값이 되어, 다음 단어를 예측하는 과정에 시각 문맥을 공급한다. 새 잔차 경로의 게이트를 0으로 초기화했기 때문에 학습 시작점에서는 동결 언어 모델의 기존 계산을 거의 그대로 보존하고, 훈련이 진행되며 필요한 만큼 시각 신호를 열 수 있다. 모델은 웹 문서에서 추출한 이미지-텍스트 교차 배열과 이미지-텍스트·동영상-텍스트 쌍을 함께 학습해, 추론 시에도 시범 예시와 질의가 섞인 동일한 형식의 문맥을 해석한다. 원 논문은 캡셔닝, 시각 질의응답, 객관식 과제 등 16개 벤치마크에서 이 인컨텍스트 적응 능력을 평가했다. 이 성과는 “모든 과제에 최고인 하나의 모델”을 증명했다기보다, 과제별 경사하강 미세조정 없이도 한 모델이 여러 종류의 시각-언어 인터페이스를 사용할 수 있음을 보인 결과로 읽는 편이 정확하다.

- 무엇을 다루는가: 생성형 언어 모델에 시각 입력을 연결하고, 프롬프트 안의 몇 개 예시만으로 새 시각-언어 과제를 지정하는 방법
- 어떤 문제를 해결하려 했는가: 과제마다 별도의 데이터셋과 미세조정 모델을 마련해야 하는 비용, 그리고 기존 언어 모델의 인컨텍스트 학습 능력을 시각 입력과 결합하기 어려운 문제
- 어떤 방식이 새로웠는가: 고정 길이 시각 병목인 Perceiver Resampler, 0 초기화 `tanh` 게이트가 붙은 교차 어텐션, 동결된 단일 모달 사전학습 구성요소, 이미지와 텍스트가 교차 배치된 학습 데이터의 조합
- 결과적으로 무엇을 바꾸었는가: 멀티모달 과제도 “시범 예시들 + 새 질의”라는 프롬프트 인터페이스로 다룰 수 있다는 강한 실험적 사례를 제시했다.

## 3. 역사적 배경

Flamingo가 등장하기 전에는 두 흐름이 빠르게 발전하고 있었다. 첫째, GPT-3 같은 대규모 인과적 언어 모델은 가중치를 갱신하지 않아도 프롬프트에 몇 개의 입력-출력 예시를 넣으면 새로운 텍스트 과제의 형식을 따라 할 수 있었다. 둘째, CLIP 같은 대조학습 모델은 방대한 이미지-텍스트 쌍을 이용해 두 모달리티의 표현을 같은 공간에 정렬했고, 제로샷 이미지 분류와 검색 가능성을 크게 넓혔다. 그러나 CLIP의 유사도 계산 인터페이스는 긴 답변을 생성하거나 여러 이미지 사이의 맥락을 이어 가는 인과적 언어 모델과는 달랐다.

당시의 생성형 시각-언어 시스템도 이미지 캡셔닝이나 시각 질의응답에서는 성과를 냈지만, 흔히 과제마다 출력 헤드·학습 목적·미세조정 절차가 달랐다. 단순히 이미지 특징을 텍스트 임베딩 앞에 이어 붙이면 입력 길이와 해상도가 커질수록 계산량이 늘고, 이미 잘 학습된 언어 모델의 내부 분포를 갑자기 바꾸어 안정성이 떨어질 수 있었다. 반대로 두 거대 모델을 모두 처음부터 다시 학습하면 계산 비용과 데이터 요구량이 매우 커진다.

Flamingo의 문제 설정은 이 틈을 겨냥했다. “언어 모델이 이미 가진 다음 토큰 예측과 인컨텍스트 학습 능력을 최대한 보존하면서, 시각 신호가 필요할 때만 읽게 할 수 있는가?”라는 질문이다. 이 관점에서 동결은 단순한 비용 절감책이 아니라 기존 능력을 보존하기 위한 제약이고, Resampler와 게이트 교차 어텐션은 서로 다른 표현 체계를 잇는 학습 가능한 인터페이스다.

- 이전 접근법: 과제별 시각-언어 미세조정, 이미지·텍스트의 단순 결합, CLIP식 대조 정렬, 텍스트 전용 인컨텍스트 학습
- 당시의 한계: 가변 길이 시각 입력의 계산 비용, 과제별 데이터와 모델 관리 부담, 새 시각 경로가 사전학습 언어 능력을 훼손할 위험
- 이 주제가 필요했던 이유: 이미지·동영상과 텍스트가 섞인 문맥에서 한 모델을 재학습하지 않고도 과제의 형식과 답변 방식을 예시로 지정할 일반 인터페이스가 필요했다.

## 4. 핵심 개념 해설

### 4.1 Perceiver Resampler: 가변 시각 특징을 고정된 병목으로

이미지 인코더는 보통 공간 격자의 각 위치에 특징 벡터를 만들고, 동영상에서는 여기에 시간축까지 더해진다. 이를 그대로 언어 모델의 모든 층과 교차 어텐션하면 입력 해상도와 프레임 수에 따라 키·값의 길이가 크게 변한다. Flamingo는 먼저 동결된 시각 인코더 $E_\mathrm{vision}$로 특징 격자를 얻고, 학습 가능한 Resampler $R$로 고정 길이의 시각 토큰을 만든다.

\[
F = E_\mathrm{vision}(X), \qquad V = R(F), \qquad V \in \mathbb{R}^{m \times d}
\]

여기서 $X$는 이미지 또는 동영상, $F$는 가변 개수의 시공간 특징, $m$은 미리 정한 잠재 질의 수다. 원 논문의 기본 설계에서는 입력 크기와 무관하게 64개의 시각 출력 토큰을 사용했다. 이 숫자는 “이미지에 물체가 64개 있다”는 뜻이 아니라, 뒤쪽 언어 모델에 전달할 통신 대역폭을 64개 벡터로 제한했다는 뜻이다.

Resampler의 학습 가능한 잠재 벡터가 질의 $Q$가 되고, 펼친 시각 특징과 잠재 벡터가 키·값 $K,V$에 함께 들어간다. 따라서 각 잠재 토큰은 전체 시각 격자에서 자신에게 필요한 정보를 모으는 요약 슬롯처럼 작동한다. 고정 길이 덕분에 정지 이미지와 여러 프레임 동영상을 같은 후단 인터페이스로 보낼 수 있지만, 압축 과정에서 작은 글자·정확한 개수·세밀한 공간 관계가 손실될 가능성도 생긴다.

### 4.2 GATED XATTN-DENSE: 동결 언어 모델에 시각 정보를 안전하게 주입하기

언어 모델의 한 시점 은닉 상태를 $H$, Resampler가 만든 시각 토큰을 $V$라 하자. 새 블록에서는 텍스트 상태가 질의이고 시각 토큰이 키와 값이다. 핵심 계산은 다음처럼 요약할 수 있다.

\[
\widetilde{H} = H + \tanh(\alpha_\mathrm{xattn})\,
\operatorname{CrossAttn}(Q=H,K=V,V=V)
\]

\[
H' = \widetilde{H} + \tanh(\alpha_\mathrm{ff})\,
\operatorname{FFN}(\widetilde{H})
\]

두 스칼라 게이트 $\alpha_\mathrm{xattn}$와 $\alpha_\mathrm{ff}$는 0으로 초기화된다. 그러면 학습 시작 시 $\tanh(0)=0$이므로 새 경로의 출력이 잔차 스트림에 거의 더해지지 않고, 전체 모델은 원래 동결 언어 모델에 가까운 동작으로 출발한다. 이후 훈련으로 게이트와 교차 어텐션·FFN 가중치가 갱신되면서 시각 정보의 기여가 열리거나 부호까지 조정된다. 여기서 “게이트”는 과제마다 사람이 여닫는 스위치가 아니며, 신경망 학습으로 정해지는 연속적인 계수다.

이 블록은 기존 언어 모델 층 사이에 끼워 넣는다. 언어 모델의 자기어텐션과 기존 FFN은 동결되어 텍스트 내 인과적 문맥을 계속 처리하고, 새 블록만 시각 토큰을 읽는다. 또한 마스크는 어떤 텍스트 토큰이 시간상 뒤에 놓인 이미지를 미리 보지 못하게 한다. 기본적인 단일-이미지 교차 어텐션에서는 텍스트 토큰이 자신보다 앞에 나온 가장 최근 이미지의 토큰을 직접 읽고, 더 앞선 이미지의 정보는 이미 처리된 텍스트 상태를 통해 간접적으로 이어질 수 있다. 이는 모든 텍스트가 모든 이미지를 무제한으로 보는 방식과 다르다.

### 4.3 동결 구성요소, 교차 배열 학습, 퓨샷 평가의 관계

“동결 모델”이라는 표현은 Flamingo 전체를 학습하지 않았다는 뜻이 아니다. 시각 인코더와 언어 모델 본체의 파라미터를 고정한 대신, Resampler와 GATED XATTN-DENSE 블록은 대규모 멀티모달 데이터로 학습한다. 개념적으로는 다음과 같이 구분할 수 있다.

| 구성요소 | 주된 역할 | Flamingo 훈련 중 상태 |
|---|---|---|
| 사전학습 시각 인코더 | 이미지·동영상 프레임을 특징 격자로 변환 | 동결 |
| Perceiver Resampler | 가변 길이 특징을 고정 길이 시각 토큰으로 압축 | 학습 |
| 사전학습 인과적 언어 모델 | 텍스트 문맥 처리와 다음 토큰 생성 | 동결 |
| GATED XATTN-DENSE 블록 | 시각 토큰을 언어 잔차 스트림에 주입 | 학습 |

학습 데이터 형식도 구조만큼 중요하다. 원 논문은 웹 페이지의 문서 구조에서 이미지와 주변 텍스트가 번갈아 나오는 M3W 자료와, ALIGN·LTIP 이미지-텍스트 쌍 및 VTP 동영상-텍스트 쌍을 혼합했다. 특수 토큰은 이미지의 위치와 한 이미지에 대응하는 텍스트 범위를 표시한다. 그 결과 훈련 때 본 “이미지—설명—이미지—질문—답”과 같은 배열이 추론 때의 “시범 예시들—새 질의” 배열과 닮게 된다. 즉, 퓨샷 능력은 교차 어텐션 한 층만의 효과로 보기 어렵고, 사전학습 언어 모델의 인컨텍스트 학습 성향, 멀티모달 데이터 형식, 연결 모듈의 공동 산물이다.

평가에서 $k$-shot은 대상 과제의 예시 $k$개를 프롬프트에 넣는다는 뜻이다. 모델 가중치는 그대로다. 예를 들어 이미지 캡셔닝이라면 `(예시 이미지, 예시 캡션)` 쌍 몇 개 뒤에 새 이미지를 놓고 캡션을 생성한다. 시각 질의응답이라면 `(이미지, 질문, 정답)` 시범 뒤에 `(새 이미지, 새 질문)`을 제시해 다음 텍스트로 답을 생성한다. 이는 같은 $k$개 예시로 경사하강을 수행하는 퓨샷 미세조정과 구별해야 한다. 객관식 같은 폐쇄형 과제에서는 각 후보 답변의 조건부 로그가능도를 비교하는 방식도 사용할 수 있다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. 문제 제기: 텍스트 LLM은 예시 몇 개로 새 과제에 적응하지만, 기존 시각-언어 모델은 대체로 과제별 라벨과 미세조정을 요구한다.
2. 핵심 아이디어: 강한 시각 모델과 언어 모델은 동결해 보존하고, 학습 가능한 소수의 모달리티 연결부만 사이에 삽입한다.
3. 방법 또는 구조: 시각 특징을 Perceiver Resampler로 압축하고, 게이트 교차 어텐션으로 인과적 언어 모델에 주입하며, 이미지·동영상·텍스트가 교차된 웹 데이터로 훈련한다.
4. 결과 또는 주장: 한 Flamingo 모델이 캡셔닝·시각 질의응답·객관식 등 여러 과제에서 프롬프트 예시만으로 강한 성능을 보였고, 공식 소개에 따르면 연구한 16개 과제에서 4-shot만으로도 당시의 기존 퓨샷 접근보다 우수했다.
5. 의의와 한계: 멀티모달 인컨텍스트 학습의 가능성을 입증했지만, 거대한 훈련·추론 비용, 프롬프트 민감성, 데이터 편향, 세밀한 지각과 신뢰성 문제는 해결하지 못했다.

원문의 서술은 Flamingo의 역사적 영향과 실용 가능성을 넓게 강조한다. 반면 기술적으로 가장 강하게 입증된 것은 특정 모델·데이터·평가 프로토콜에서의 비교 결과다. “여러 후속 시스템의 표준이 되었다”거나 특정 제품에 직접 영향을 주었다는 계보 주장은 원 논문만으로 확정할 수 없으므로, 후속 논문의 명시적 인용과 구조적 차이를 함께 확인해야 한다.

## 6. 왜 중요한가

Flamingo의 핵심 가치는 새로운 모달리티를 언어 모델에 연결하는 문제를 “전체 모델의 재학습”이 아니라 “보존할 능력과 새로 학습할 인터페이스의 분리”로 다시 구성했다는 데 있다. 이는 이미 값비싸게 학습된 단일 모달 모델을 재사용하면서도, 멀티모달 입력을 자연어 생성이라는 공통 출력 인터페이스로 통합하는 설계 원칙을 제공했다.

또한 과제 정의를 모델 파라미터가 아니라 문맥 안으로 옮겼다. 같은 가중치로 캡셔닝과 질의응답을 오갈 수 있는 이유는 과제별 분류 헤드를 바꾸어서가 아니라, 프롬프트의 예시가 “어떤 입력에서 어떤 형식의 텍스트를 내야 하는가”를 보여 주기 때문이다. 이 점은 멀티모달 모델을 고정된 예측기보다 조건부 생성기로 바라보게 한다.

특히 중요한 점:

- 고정 길이 시각 병목을 두어 이미지 해상도나 동영상 프레임 수와 언어 모델의 교차 어텐션 비용을 어느 정도 분리했다.
- 0 초기화 게이트로 새 모달리티 경로를 점진적으로 열어, 사전학습 언어 모델의 동작을 보존하면서 학습 안정성을 확보하는 구체적 방법을 제시했다.
- 훈련 데이터와 추론 프롬프트를 모두 이미지-텍스트 교차 배열로 맞춰, 멀티모달 인컨텍스트 학습이 작동할 조건을 설계 차원에서 보여 주었다.

다만 “동결했으므로 효율적”이라는 말은 제한적으로 이해해야 한다. 전체를 처음부터 학습하는 것보다 재사용성이 높다는 뜻이지, 최대 80B 규모 모델과 대규모 웹 데이터의 훈련·추론 비용이 작다는 뜻은 아니다.

## 7. 현대 LLM과의 연결

Flamingo는 오늘날 시각 입력을 받는 LLM을 이해할 때 유용한 세 가지 축을 제공한다. 첫째는 시각 특징을 어떤 길이와 형식의 토큰으로 바꿀지, 둘째는 그 토큰을 언어 모델의 어디에 연결할지, 셋째는 어떤 데이터 배열과 목적함수로 두 모달리티의 사용법을 가르칠지다. 후속 멀티모달 모델들은 이 세 축에서 서로 다른 선택을 한다. 어떤 모델은 Flamingo처럼 교차 어텐션 어댑터를 쓰고, 어떤 모델은 시각 특징을 언어 토큰 공간에 투영해 접두 토큰처럼 넣으며, 또 다른 모델은 처음부터 여러 모달리티를 함께 학습한다.

- 인컨텍스트 학습: GPT-3의 텍스트 시범 학습을 `(이미지 또는 동영상, 텍스트 응답)` 시범으로 확장했다. 다만 예시를 이해해 추상 규칙을 학습했는지, 표면 패턴과 검색 유사성을 활용했는지는 과제별 분석이 필요하다.
- 멀티모달 어댑터: 동결 백본 사이에 학습 가능한 연결부를 두는 방식은 파라미터 효율적 적응과 닮았지만, Flamingo의 새 모듈 자체가 작거나 훈련이 저비용이라는 뜻은 아니다.
- 시각 토큰 병목: Perceiver Resampler는 길이가 큰 지각 출력을 소수 토큰으로 요약한다. 이는 계산을 제어하지만, OCR·정밀 위치 지정·계수처럼 세부 정보 보존이 중요한 과제에는 병목이 될 수 있다.
- RAG와 도구 사용: 외부 정보를 조건으로 언어를 생성한다는 추상 구조는 비슷하지만, Flamingo의 시각 토큰은 입력 이미지에서 신경망이 계산한 연속 표현이다. 문서를 검색해 출처 단위로 가져오는 RAG나 실행 가능한 도구 호출과 동일한 메커니즘은 아니다.
- 현대 멀티모달 LLM: Flamingo가 보여 준 “언어 생성기를 중심에 두고 지각 입력을 조건으로 공급한다”는 관점은 중요한 선행 사례다. 다만 GPT-4V·GPT-4o 등 개별 비공개 시스템의 내부 구조가 Flamingo와 같다고 추정해서는 안 된다.

관련 흐름을 시간 순서로 보면 [[067_GPT-3 and In-Context Learning Emergent Capabilities from Scale.ko|GPT-3의 인컨텍스트 학습]], [[070_CLIP Contrastive Language-Image Pre-training for Multimodal Understanding.ko|CLIP의 시각-언어 정렬]], [[078_Chinchilla Scaling Laws Compute-Optimal Training and Resource Allocation for Large Language Models.ko|Chinchilla의 계산 최적 언어 모델]]이 Flamingo가 결합하려 한 기반을 서로 다른 각도에서 설명한다.

## 8. 한계와 비판적 관점

- 기술적 한계: 고정 개수 시각 토큰으로 압축하면 작은 물체, 텍스트, 정확한 개수, 복잡한 공간 관계가 희석될 수 있다. 자기회귀 언어 생성기는 그럴듯하지만 영상 근거와 불일치하는 답을 만들 수 있으며, 교차 어텐션이 존재한다는 사실만으로 답의 각 문장이 특정 시각 증거에 충실하다고 보장되지는 않는다.
- 이론적 한계: 퓨샷 성능 향상이 게이트 구조, 교차 배열 데이터, 언어 모델 규모, 예시 검색·순서 중 무엇에서 얼마나 비롯되는지 하나의 원리로 분해하기 어렵다. 원 논문의 절제 실험은 구성요소의 실용적 기여를 보여 주지만, 모델이 문맥에서 과제를 “학습”하는 내부 메커니즘을 완전히 설명하지는 않는다.
- 실용적 한계: 대규모 시각·언어 백본과 새 연결 모듈은 훈련과 추론에 상당한 계산 자원을 요구한다. 성능은 시범 예시의 품질·순서·형식에 민감할 수 있고, 안전이 중요한 환경에서는 과제별 검증과 보정 없이 퓨샷 결과만 신뢰하기 어렵다.
- 데이터와 사회적 한계: 웹에서 수집한 이미지·텍스트에는 문화적·인구학적 편향, 유해 콘텐츠, 부정확한 설명, 저작권·개인정보 문제가 섞일 수 있다. 연구진도 성별·피부색 관련 캡션과 독성 등을 제한적으로 점검했지만, 이는 포괄적 안전성 평가를 대신하지 않는다.
- 오늘날 관점에서 다시 봐야 할 점: 원문은 Flamingo를 “돌파구”와 “표준”으로 묘사하는 경향이 있다. 확실히 말할 수 있는 사실은 2022년 당시의 정의된 평가에서 강한 퓨샷 결과와 유효한 아키텍처 절제 결과를 제시했다는 점이다. 장기적 영향, 실제 배포 성능, 후속 모델과의 직접 계보는 각각 별도의 근거가 필요하다.

원 논문이 보고한 16개 벤치마크 평균이나 “기존 미세조정 모델보다 우수”하다는 표현도 과제별로 읽어야 한다. 지표와 데이터 분할이 서로 다르고, 모든 과제에서 모든 전문 모델을 이긴 것은 아니다. 공개 소개의 “4개 예시만으로 기존 퓨샷 접근을 능가했다”는 비교와, 과제별 완전 미세조정 최고 성능을 넘었다는 주장은 같은 문장이 아니다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 시각-언어 모델(Visual Language Model, VLM) | 이미지·동영상 같은 시각 입력과 자연어를 함께 조건으로 받아 이해·생성 과제를 수행하는 모델 |
| 퓨샷 인컨텍스트 학습 | 소수의 시범 입력-출력 예시를 프롬프트에 넣어 과제를 지정하되 모델 가중치는 갱신하지 않는 적응 방식 |
| 교차 어텐션(cross-attention) | 한 표현의 질의가 다른 표현의 키·값을 조회하는 어텐션. Flamingo에서는 텍스트 상태가 시각 토큰을 읽는다. |
| GATED XATTN-DENSE | 교차 어텐션과 FFN의 잔차 출력을 학습 가능한 `tanh` 게이트로 조절하는 Flamingo의 연결 블록 |
| Perceiver Resampler | 가변 개수의 시공간 특징을 학습 가능한 잠재 질의로 읽어 고정 개수 시각 토큰으로 바꾸는 모듈 |
| 동결(frozen) | 훈련 중 해당 구성요소의 파라미터를 갱신하지 않는 것. 그 구성요소를 계산에서 제외한다는 뜻은 아니다. |
| 인터리브드 이미지-텍스트 | 이미지·동영상과 텍스트 구간이 한 시퀀스 안에서 실제 문서 순서처럼 번갈아 배치된 입력 형식 |
| 인과 마스킹 | 현재 위치가 미래의 텍스트나 아직 등장하지 않은 시각 입력을 보지 못하게 하여 자기회귀 생성을 유지하는 제한 |
| 모달리티 병목 | 많은 시각 특징을 제한된 수의 토큰으로 압축해 계산과 정보 흐름을 제어하는 지점 |

## 12. 짧은 결론

Flamingo는 시각과 언어를 단순히 한 표현 공간에 맞추는 데서 한 걸음 더 나아가, 이미지·동영상과 텍스트 시범을 한 문맥에 넣고 자연어로 과제를 수행하는 멀티모달 인컨텍스트 학습을 구체화했다. Perceiver Resampler는 시각 입력을 고정된 통신 병목으로 만들고, 0 초기화 게이트 교차 어텐션은 동결 언어 모델의 기존 능력을 보존하면서 그 병목을 읽게 했다. 이 구조적 성과와 2022년의 강한 퓨샷 실험 결과는 분명하지만, 계산 비용·세부 지각 손실·환각·편향·프롬프트 민감성까지 해결한 것은 아니다. 따라서 Flamingo의 역사적 위치는 “현대 멀티모달 모델의 완성형”이라기보다, 강한 단일 모달 백본과 학습 가능한 연결부, 교차 배열 데이터가 어떻게 하나의 생성형 퓨샷 인터페이스를 만들 수 있는지 설득력 있게 보여 준 이정표로 보는 것이 적절하다. 기술 수치와 평가 범위는 [Alayrac et al., 2022 원 논문](https://arxiv.org/abs/2204.14198)에서 다시 확인할 수 있다.

# 조건부 무작위장과 구조화 예측 해설

## 1. 한눈에 보기

- 핵심 주제: 조건부 무작위장(Conditional Random Field, CRF)은 관측열 $x$가 주어졌을 때 라벨열 $y$ 전체의 조건부 확률 $P(y\mid x)$를 모델링하는 판별적 구조화 예측 틀이다.
- 등장 배경: HMM은 순서열 의존성을 이미 모델링했지만 관측 생성분포 때문에 강한 독립성 가정을 두었다. MEMM은 풍부한 관측 특징을 조건부 모델에 넣었으나 상태별 국소 정규화에서 label bias가 생길 수 있었다.
- 가장 중요한 아이디어: 선형 사슬 CRF는 상태·전이 특징의 점수를 순서열 전체 후보에 걸쳐 한 번에 정규화해, 각 위치가 아니라 완전한 라벨열 사이에서 확률 질량이 경쟁하게 한다.
- 이후 LLM/NLP에 남긴 영향: 품사 태깅·청킹·개체명 인식 같은 순서열 라벨링에 구조화 예측을 정착시켰고, 이후 BiLSTM-CRF처럼 신경 표현과 전역 라벨 디코딩을 결합한 구조로 이어졌다. Transformer와 LLM 전체가 CRF에서 직접 파생됐다는 뜻은 아니다.

> 이 문서는 `032_Conditional Random Fields - Structured Prediction for Sequences.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 원 논문의 문제 설정, 수학 구조, 실험 범위, 후대 연결과 과장된 계보를 구분합니다.

## 2. 핵심 요약

CRF는 입력 순서열의 확률 $P(x)$를 따로 모델링하지 않고, 입력이 주어졌을 때 구조화된 출력의 확률 $P(y\mid x)$에 직접 집중한다. 2001년 Lafferty, McCallum, Pereira가 제시한 일반 정의는 출력 변수들이 입력 전체에 조건부인 무작위장을 이룬다는 것이며, 원 논문의 주된 계산 예시는 출력 그래프가 사슬인 선형 사슬 CRF다. 각 후보 라벨열의 점수는 관측과 현재 라벨을 연결하는 상태 특징, 인접 라벨을 연결하는 전이 특징의 가중합으로 계산한다. 분배 함수 $Z(x)$는 가능한 라벨열 전체의 점수를 합해 조건부 확률을 정규화한다. 이 전역 정규화는 각 상태에서 나가는 전이만 정규화하는 MEMM의 label bias 문제를 다루는 핵심 차이다. 선형 사슬에서는 forward-backward로 분배 함수와 주변확률을, Viterbi로 최고 점수 라벨열을 동적 계획법으로 계산할 수 있다. 원 논문은 합성 자료와 Penn Treebank 품사 태깅에서 HMM·MEMM·CRF를 비교했으며, 철자 특징을 넣은 CRF+가 그 설정에서 가장 낮은 단어 오류율을 보였다. 그러나 이 제한된 실험이 NER·정보 추출·생의학 처리 전반의 우위나 확률 보정을 자동으로 보장하지는 않는다.

- 무엇을 다루는가: 조건부 구조화 예측, 전역 정규화, 특징 함수, label bias, 동적 계획법 기반 학습·추론을 다룬다.
- 어떤 문제를 해결하려 했는가: 생성 모델의 관측 독립성 제약을 완화하면서도, 국소 조건부 모델이 미래 관측을 충분히 반영하지 못하는 label bias를 줄이려 했다.
- 어떤 방식이 새로웠는가: 풍부하고 중첩되는 관측 특징을 사용하면서 라벨열 전체를 하나의 조건부 확률분포로 정규화했다.
- 결과적으로 무엇을 바꾸었는가: 개별 라벨 분류가 아니라 출력 사이의 의존성을 목적 함수와 추론에 포함하는 구조화 예측을 NLP의 표준 도구로 만들었다.

## 3. 역사적 배경

CRF 이전에도 순서열을 공동으로 모델링하는 방법은 있었다. HMM은 상태 전이와 관측 방출을 결합해 라벨열과 관측열의 결합확률을 정의하고, Viterbi 알고리즘으로 전체 상태열을 디코딩했다. 따라서 원문의 “이전 모델은 단어마다 독립적으로 분류했다”는 서술은 HMM·확률 태거·유한상태 모델의 역사를 지나치게 단순화한다.

문제는 HMM이 출력뿐 아니라 관측의 생성과정까지 모델링해야 한다는 데 있었다. 계산을 가능하게 하려면 현재 상태가 주어졌을 때 관측 특징들이 독립이라는 식의 가정을 두기 쉬웠고, 철자·접사·대문자 여부·앞뒤 단어처럼 서로 겹치는 풍부한 특징을 한꺼번에 넣기 어려웠다. 2000년 McCallum, Freitag, Pereira의 maximum entropy Markov model(MEMM)은 다음 상태의 조건부 분포에 이런 특징을 넣었지만, 각 출발 상태에서 나가는 전이끼리만 정규화했다. 나갈 길이 적은 상태는 관측과 무관하게 확률 질량을 보존해 유리해질 수 있는데, 이것이 label bias다.

2001년 CRF는 MEMM의 조건부 특징 표현을 유지하면서 무방향 무작위장의 전역 정규화를 결합했다. 원 논문은 이 차이를 합성 유한상태 문제, 혼합 차수 자료, Penn Treebank 품사 태깅으로 확인했다. 역사적 핵심은 순서열 의존성 자체의 최초 발견이 아니라 **판별적 특징 표현과 라벨열 전체의 전역 정규화 결합**에 있다.

- 이전 접근법: [[013_Hidden Markov Models - Statistical Speech Recognition]]의 HMM·Viterbi, 최대 엔트로피 분류기, 2000년 MEMM, 변환 기반 태거와 국소 분류기가 있었다.
- 당시의 한계: 생성 모델의 관측 독립성 가정, 국소 조건부 정규화의 label bias, 수작업 특징을 구조 출력 전체의 목적 함수와 함께 학습하는 비용이 문제였다.
- 이 주제가 필요했던 이유: 품사·청크·개체명처럼 한 위치의 결정이 이웃 결정과 맞아야 하는 과제에서 풍부한 입력 특징과 일관된 출력 구조를 동시에 다룰 방법이 필요했다.

## 4. 핵심 개념 해설

### 4.1 조건부 무작위장과 선형 사슬

일반 CRF에서 입력 $X$와 출력 변수 집합 $Y=(Y_v)_{v\in V}$가 있을 때, $X$에 조건부인 출력 변수들이 그래프 $G=(V,E)$의 마르코프 성질을 만족한다. 즉 한 출력 변수는 입력 전체와 그래프의 이웃 출력에 조건부일 때 나머지 출력과 독립이다.

순서열 라벨링에서 가장 널리 쓰인 경우는 라벨 $Y_1,\dots,Y_T$가 사슬을 이루는 선형 사슬 CRF다. 이 구조에서는 인접 라벨 쌍과 현재 라벨-입력 특징을 점수화한다.

$$
P(y\mid x)=\frac{1}{Z(x)}\exp\left(\sum_{t=1}^{T}\sum_k \lambda_k f_k(y_{t-1},y_t,x,t)\right)
$$

입력 $x$ 전체는 고정된 조건이므로 특징은 현재 단어뿐 아니라 앞뒤 단어, 철자, 문서 배치 같은 비독립 관측 정보를 함께 볼 수 있다. 다만 계산 가능한 모든 전역 특징을 공짜로 쓸 수 있는 것은 아니다. 정확한 동적 계획법을 유지하려면 점수가 그래프의 국소 clique로 분해되어야 한다.

### 4.2 전역 정규화와 label bias

MEMM은 각 상태에서 다음 상태로 나가는 확률을 따로 정규화한다. 출구가 하나뿐인 상태는 관측이 무엇이든 그 전이에 확률 1을 줄 수 있고, 그 상태에 도착한 경로의 점수가 이후 관측으로 충분히 낮아지지 않는다. 원 논문은 이를 “score mass conservation”으로 설명했다.

CRF의 $Z(x)$는 시작부터 끝까지 가능한 완전한 라벨 경로 전체를 합한다. 따라서 한 경로의 국소 전이는 같은 상태의 출구뿐 아니라 다른 전체 경로와도 경쟁한다. 미래 관측에서 얻은 특징 점수가 앞선 분기 선택에 반영될 수 있다. 이것이 “CRF는 이웃 라벨을 본다”보다 더 정확한 차이다. HMM도 이웃 상태와 전체 경로를 디코딩하지만, CRF는 관측 생성분포를 모델링하지 않고 중첩 특징을 조건부 점수에 직접 쓸 수 있다.

### 4.3 학습·주변확률·디코딩

학습은 정답 라벨열의 조건부 로그가능도를 높이는 가중치를 찾는다. 고정된 특징을 쓰는 로그선형 선형 사슬 CRF의 음의 로그가능도는 볼록하므로 전역 최적값을 찾을 수 있다. 그러나 규제가 없으면 매개변수 표현이 중복돼 최적 매개변수가 유일하지 않을 수 있고, 신경망으로 특징을 함께 학습하는 neural CRF 전체 목적은 일반적으로 볼록하지 않다.

forward-backward는 $Z(x)$와 각 위치·전이의 주변확률을 구해 기대 특징 빈도와 기울기를 계산한다. Viterbi는 같은 사슬 분해를 사용하되 합 대신 최댓값을 취해 최고 점수 라벨열을 찾는다. 라벨 수를 $K$, 길이를 $T$라 하면 밀집 1차 전이의 대표 비용은 $O(TK^2)$다. 그러므로 “길이에만 비례한다”는 표현은 $K$를 고정한 경우의 설명이며 라벨 수 비용을 생략한 것이다.

## 5. 원문의 논리 구조

원문은 대체로 다음 흐름으로 전개된다.

1. 품사 태깅과 개체명 인식을 서로 의존하는 라벨열 예측 문제로 제시한다.
2. 입력이 주어졌을 때 라벨열 전체의 조건부 확률을 계산하는 CRF를 소개한다.
3. 상태·전이·문맥 특징이 단어 적합도와 라벨 사이의 일관성을 어떻게 점수화하는지 설명한다.
4. 품사 태깅 예시와 NLP 응용을 통해 구조화 예측의 직관을 보여준다.
5. 전역 정규화, 동적 계획법, 볼록 최적화를 이론적 장점으로 설명한다.
6. 수작업 특징, 학습 비용, 낮은 차수 의존성, 선형 점수의 한계를 정리한다.
7. neural CRF와 현대 순서열 모델로 이어지는 영향을 주장한다.

이 흐름은 교육적으로 읽기 쉽지만, “독립 분류 대 CRF”라는 이분법 때문에 HMM과 MEMM의 역할이 희미해진다. 실제 역사와 수학을 이해하려면 생성/판별, 국소/전역 정규화, 입력 특징/출력 구조라는 세 축을 따로 보아야 한다.

## 6. 왜 중요했는가

CRF는 서로 다른 두 장점을 한 모델에 묶었다. 최대 엔트로피 계열의 판별 모델처럼 입력에 관한 중첩 특징을 자유롭게 설계할 수 있었고, HMM처럼 동적 계획법으로 완전한 라벨열을 학습·추론할 수 있었다. 동시에 MEMM의 상태별 정규화가 만드는 label bias를 라벨열 전체의 정규화로 피했다.

원 논문의 Penn Treebank 실험은 이 결합을 작은 규모지만 구체적으로 보여준다. 45개 품사 태그, 110만 단어 말뭉치의 50% 학습 분할에서 단순 CRF 오류율은 5.55%, 철자 특징을 더한 CRF+는 4.27%였다. 같은 표에서 HMM은 5.69%, MEMM은 6.37%, 철자 특징을 더한 MEMM+는 4.81%였다. 이 결과는 관측 특징의 이점과 전역 정규화의 이점을 구분해 볼 수 있게 하지만, 하나의 자료·분할·특징 집합에서 얻은 결과다.

특히 중요한 점:

- CRF는 “문맥을 본다”는 모호한 표현을 입력 전체에 조건부인 특징과 출력 그래프의 명시적 의존성으로 나누어 정식화했다.
- 라벨열 확률을 전역 정규화해 국소 분류기의 label bias를 구조적으로 다뤘다.
- 특징 기대값, forward-backward, Viterbi를 하나의 로그선형 구조화 예측 틀에서 연결했다.
- 후대 신경 모델이 입력 표현을 자동 학습하더라도 CRF 층으로 출력 라벨 제약을 유지할 수 있는 모듈성을 제공했다.

## 7. 현대 LLM과의 연결

CRF와 현대 LLM은 모두 문맥을 사용하지만 예측 대상과 정규화 구조가 다르다. 선형 사슬 CRF는 관측 입력 전체가 주어진 뒤 라벨열 후보를 조건부로 점수화한다. 자기회귀 LLM은 앞선 토큰을 조건으로 다음 토큰의 분포를 위치마다 계산하고, 생성된 접두사를 다시 입력으로 사용한다. Transformer 인코더 기반 태거는 각 입력 위치의 문맥 표현을 만들고 CRF 층으로 라벨열을 디코딩할 수 있지만, Transformer 자체가 CRF의 전역 정규화와 같은 것은 아니다.

- BiLSTM-CRF: 양방향 LSTM이 입력 표현과 긴 문맥 특징을 학습하고, CRF 층이 인접 출력 라벨의 전이 점수와 문장 단위 디코딩을 담당한다.
- Transformer-CRF: 사전학습 인코더의 토큰 표현 위에 선형 사슬 CRF를 붙여 BIO 같은 라벨 전이의 일관성을 명시적으로 점수화할 수 있다.
- 구조화 출력: LLM의 JSON schema 검증, 문법 제약 디코딩, tool calling도 출력 구조를 강제하지만, 보통 CRF의 조건부 무작위장 목적 함수와 동일한 기술은 아니다.
- 확률 해석: CRF와 LLM 모두 정규화된 분포를 만들 수 있지만, 확률분포가 존재한다는 사실만으로 실제 오류 빈도와 confidence가 일치하는 calibration이 보장되지는 않는다.

따라서 CRF의 현대적 유산은 “모든 순서열 모델의 직접 조상”이라기보다, 입력 표현과 구조 출력 층을 분리하고 전체 출력의 일관성을 목적 함수에 넣는 설계 원리로 이해하는 편이 정확하다.

## 8. 한계와 비판적 관점

원문은 CRF의 장점을 잘 설명하지만 역사와 기술 범위를 여러 곳에서 넓혀 쓴다.

- 기술적 한계: 선형 사슬 CRF의 정확 추론은 라벨 수의 제곱과 길이에 비례하고, 고차·조밀 그래프·전역 비분해 특징에서는 비용이 급증하거나 근사 추론이 필요하다.
- 이론적 한계: 고정 로그선형 CRF의 볼록성과 신경 특징 추출기를 함께 학습하는 현대 neural CRF의 비볼록 목적을 구분해야 한다. 볼록하더라도 규제·식별성 조건 없이 “유일한 최적 매개변수”가 항상 보장되지는 않는다.
- 실용적 한계: 수작업 특징은 도메인 지식을 담을 수 있지만 이식 비용이 크고, 긴 거리 출력 의존성을 낮은 차수 전이만으로 표현하기 어렵다.
- 평가의 한계: 원 논문의 자연어 실험은 Penn Treebank 품사 태깅 한 과제다. NER·청킹·정보 추출 전반의 성능은 후속 연구별 자료·기준선·평가 지표를 확인해야 한다.
- 확률의 한계: 정규화된 조건부 확률은 confidence를 제공하지만 자동으로 보정된 확률은 아니다. 보정은 별도 held-out 평가가 필요한 경험적 성질이다.
- 역사 서술의 한계: HMM과 MEMM도 순서열 의존성을 모델링했다. CRF의 새로움은 최초의 공동 순서열 예측이 아니라 조건부 특징과 전역 정규화의 결합이다.
- 계보의 한계: neural CRF는 직접 결합 사례지만 RNN·attention·Transformer·LLM 전체가 CRF의 후손이라는 인과 계보는 원 논문과 구조적 유사성만으로 입증되지 않는다.

오늘의 관점에서 다시 봐야 할 점: 출력의 일관성이 중요하다고 해서 항상 CRF 층이 유리한 것은 아니다. 강한 인코더와 충분한 데이터에서는 위치별 softmax가 비슷하거나 더 나을 수 있고, 복잡한 라벨 구조에서는 semi-Markov CRF, span 분류, 전역 제약 디코딩 같은 다른 선택지가 적합할 수 있다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 조건부 무작위장(CRF) | 입력 전체에 조건부인 출력 변수들이 그래프의 마르코프 성질을 따르는 판별적 확률 모형이다. |
| 선형 사슬 CRF | 출력 라벨이 사슬 구조를 이루어 인접 전이 점수와 상태 점수를 동적 계획법으로 합산하는 CRF다. |
| 분배 함수 $Z(x)$ | 주어진 입력에서 가능한 모든 라벨열의 비정규화 점수를 합해 조건부 확률을 정규화하는 값이다. |
| label bias | 상태별로 나가는 전이를 국소 정규화할 때 출구가 적은 상태가 관측 증거와 무관하게 유리해질 수 있는 문제다. |
| 상태 특징 | 입력의 속성과 현재 라벨의 적합도를 점수화하는 특징이다. |
| 전이 특징 | 이전 라벨과 현재 라벨 조합의 적합도를 점수화하는 특징이다. |
| forward-backward | 분배 함수와 위치·전이 주변확률, 기대 특징 빈도를 계산하는 동적 계획법이다. |
| Viterbi 디코딩 | 가능한 경로 가운데 가장 높은 점수의 라벨열을 찾는 동적 계획법이다. |

## 12. 짧은 결론

CRF의 핵심은 단순히 이웃 라벨을 참고하는 데 있지 않다. HMM이 먼저 보여준 공동 순서열 추론과 최대 엔트로피 모델의 풍부한 판별 특징을 결합하되, MEMM의 상태별 정규화를 라벨열 전체의 전역 정규화로 바꾼 데 있다. 이 구조는 품사 태깅과 정보 추출에서 입력 특징의 유연성과 출력 일관성을 함께 다룰 수 있게 했다. 후대 신경 모델은 수작업 특징을 자동 표현 학습으로 대체했지만, 입력 표현과 구조 출력의 책임을 나누고 완전한 출력 후보를 비교한다는 문제의식은 BiLSTM-CRF 같은 혼합 모델에 명확히 남았다. 다만 원 논문의 제한된 실험, 선형 사슬의 계산 조건, 확률 보정과 직접 계보의 범위를 넘어서 CRF를 모든 현대 순서열 모델의 출발점으로 일반화해서는 안 된다.

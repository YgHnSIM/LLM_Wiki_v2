# V-JEPA 2 해설

원본 출처: https://mbrenndoerfer.com/writing/v-jepa-2-vision-based-world-modeling-embodied-ai

## 1. 한눈에 보기

- 핵심 주제: Meta의 V-JEPA 2가 비디오의 픽셀을 생성하는 대신 가려진 부분의 잠재 표현을 예측해 시각 표현을 학습하고, 별도의 행동 조건부 모델 V-JEPA 2-AC로 짧은 로봇 조작 계획까지 확장한 과정
- 등장 배경: 언어 모델은 물리 세계를 주로 텍스트를 통해 배우고, 픽셀 생성형 비디오 모델은 계획에 불필요한 세부까지 복원하느라 계산량이 커질 수 있었다. Meta는 예측 가능한 장면 구조를 표현 공간에서 학습하는 JEPA 계열을 대안으로 발전시켰다.
- 가장 중요한 아이디어: V-JEPA 2의 기본 사전학습은 대조학습도, 행동을 조건으로 한 미래 프레임 생성도 아니다. 마스킹한 시공간 패치의 목표 표현을 EMA 인코더로 만들고, 문맥 인코더와 예측기가 그 표현을 L1 손실로 맞춘다.
- 이후 LLM/NLP에 남긴 영향: 언어 감독 없이 학습한 비디오 인코더도 언어 모델과 정렬하면 비디오 질의응답에 활용할 수 있음을 보였고, 언어 모델과 잠재 세계 모델을 결합하는 연구 경로를 구체화했다.

> 이 문서는 108_V-JEPA 2 Vision-Based World Modeling for Embodied AI.md의 번역문을 이해하기 위한 해설입니다. 원문의 서사를 반복하기보다 Meta의 공식 논문, 발표문, 코드 저장소를 기준으로 연표·학습 목적·로봇 실험·공개 범위와 한계를 교정합니다.

## 2. 핵심 요약

V-JEPA 2의 공식 발표와 arXiv 논문 v1 공개일은 2025년 6월 11일이다. 따라서 원문의 “2025년 4월 공개”는 공식 기록과 맞지 않는다. 공식 GitHub 저장소의 변경 기록에는 6월 25일을 릴리스 날짜로 적고 있으므로, 발표·논문 공개와 코드 저장소의 릴리스 표기를 구분하는 편이 정확하다. Meta는 V-JEPA 2를 100만 시간이 넘는 비디오와 100만 장의 이미지로 사전학습한 비디오 세계 모델로 소개했다. 논문에서 핵심 인코더는 3억 매개변수 ViT-L부터 10억 매개변수 ViT-g까지 확장되며, Meta 발표문은 전체 모델을 12억 매개변수라고 표현한다.

V-JEPA 2는 비디오를 픽셀 단위로 생성하지 않는다. 비디오를 시공간 튜블릿으로 나누고 일부 토큰을 가린 뒤, 보이는 문맥에서 가려진 부분의 잠재 표현을 예측한다. 목표 표현은 지수 이동 평균(EMA) 인코더가 만들며, 예측값과 목표값을 L1 손실로 맞춘다. 원문이 말한 ‘대조학습’처럼 양성·음성 쌍을 서로 끌어당기고 밀어내는 목적함수는 이 사전학습 절차의 핵심이 아니다. 또한 기본 사전학습은 반드시 다음 프레임만 예측하는 자회귀 과정이 아니라, 같은 클립에서 마스킹된 시공간 영역의 표현을 복원하는 마스크 제거 과제다.

로봇 계획은 별도의 두 번째 단계에서 등장한다. 연구진은 V-JEPA 2 인코더를 고정하고 DROID의 62시간 미만 로봇 비디오와 말단장치 상태를 사용해 약 3억 매개변수의 행동 조건부 예측기 V-JEPA 2-AC를 후학습했다. 이 모델은 과거 영상 표현, 로봇 동작, 말단장치 상태를 조건으로 미래 관측의 표현을 자회귀적으로 예측한다. 두 연구실의 Franka 로봇 팔에서 목표 이미지를 따라 도달·파지·픽앤플레이스를 수행했지만, 이는 제한된 탁상 조작 실험이다. 자율주행·증강현실·범용 로봇에 실제 배포됐다는 증거는 공식 자료에 없다.

- 무엇을 다루는가: 대규모 비디오 자기지도학습, 잠재 표현 예측, 행동 조건부 세계 모델, 모델 예측 제어
- 어떤 문제를 해결하려 했는가: 라벨과 픽셀 생성 없이 물체의 움직임과 장면 변화를 담는 표현을 배우고, 적은 상호작용 데이터로 계획에 활용하는 문제
- 어떤 방식이 새로웠는가: 대규모 마스크 잠재 예측 사전학습과 소규모 행동 조건부 후학습을 분리하고, 표현 공간의 거리를 로봇 계획 비용으로 사용했다.
- 결과적으로 무엇을 바꾸었는가: 비디오 표현학습의 성능을 분류에만 두지 않고 행동 예측·언어 모델 정렬·실물 로봇 폐루프 계획까지 한 연구 안에서 연결했다.

## 3. 역사적 배경

V-JEPA 2는 2022년 Yann LeCun이 제시한 JEPA 구상, 2023년 I-JEPA, 2024년 V-JEPA의 연장선에 있다. JEPA의 출발점은 관측의 모든 세부를 복원하는 대신, 문맥에서 예측 가능한 목표의 표현을 학습하자는 것이다. 이미지와 비디오에는 나뭇잎의 정확한 위치나 압축 노이즈처럼 다음 상태를 계획하는 데 중요하지 않은 변동이 많다. 픽셀 생성 목표는 이런 고엔트로피 세부까지 모델링해야 하지만, 잠재 표현 예측은 과제에 유용한 구조를 선택적으로 남길 가능성이 있다.

이 계보는 CLIP식 대조학습과도 구분된다. CLIP은 이미지와 텍스트의 대응 쌍을 같은 표현 공간에 정렬하고 배치 안의 비대응 쌍을 구별하도록 학습한다. 반면 V-JEPA 2의 사전학습에는 텍스트 정답이나 음성 쌍이 필요하지 않으며, 마스킹된 비디오 부분의 EMA 목표 표현을 직접 회귀한다. 두 방식 모두 표현학습이지만 감독 신호와 목적함수는 다르다.

연표는 다음처럼 정리할 수 있다.

| 날짜 | 확인된 사건 | 해석할 때의 경계 |
|---|---|---|
| 2024년 | Meta가 첫 V-JEPA 연구를 공개했다. | V-JEPA 2와 동일한 규모·데이터·로봇 계획 결과는 아니다. |
| 2025-06-11 | Meta 공식 발표문과 V-JEPA 2 논문 arXiv v1이 공개됐다. | 원문의 2025년 4월 표기는 근거가 없다. |
| 2025-06-25 | 공식 GitHub README가 V-JEPA 2 릴리스 날짜로 기록한 날이다. | 연구 발표일과 저장소 릴리스 표기를 같은 사건으로 뭉개지 않는다. |

- 이전 접근법: 픽셀 단위 비디오 생성, 이미지·텍스트 대조학습, 행동·보상으로만 학습하는 로봇 세계 모델
- 당시의 한계: 픽셀 생성의 높은 계획 비용, 실제 로봇 상호작용 데이터의 희소성, 정적 이미지 표현이 놓치기 쉬운 시간적 움직임
- 이 주제가 필요했던 이유: 대규모 관찰 비디오에서 일반 시각 표현을 먼저 배우고, 적은 로봇 궤적으로 행동의 결과만 추가 학습하는 분업이 상호작용 데이터 병목을 줄일 수 있기 때문이다.

## 4. 핵심 개념 해설

### 4.1 V-JEPA 2의 마스킹된 잠재 표현 예측

V-JEPA 2는 비디오 클립을 시간·높이·너비를 가진 튜블릿 토큰으로 바꾸고 일부 토큰을 제거한다. 문맥 인코더는 남은 토큰을 처리하고, 예측기는 마스크 토큰의 위치 정보를 받아 가려진 부분에 대응하는 잠재 벡터를 만든다. 별도의 목표 인코더는 완전한 입력에서 목표 벡터를 계산한다. 이 목표 인코더는 문맥 인코더 가중치의 지수 이동 평균으로 갱신되고, 목표 쪽에는 기울기를 흘리지 않아 표현 붕괴를 막는다. 손실은 마스킹된 위치의 예측 표현과 목표 표현 사이 L1 거리다.

이 절차는 세 가지 오해와 구분해야 한다.

1. **픽셀 복원과 다르다.** 모델은 원본 영상을 선명하게 재생성하도록 학습되지 않는다.
2. **대조학습과 다르다.** 공식 목적함수에는 오답 비디오를 음성 샘플로 밀어내는 항이 없다.
3. **단순 다음 프레임 예측과 다르다.** 사전학습 목표는 한 클립 안에서 가려진 시공간 부분의 표현이다. 1초 뒤 행동 예측은 별도의 다운스트림 프로브이고, 행동 조건부 미래 표현 예측은 V-JEPA 2-AC 단계다.

인코더와 예측기는 Vision Transformer로 구현된다. V-JEPA 2는 시간·높이·너비 축에 나눠 적용하는 3차원 RoPE를 사용하고, 데이터 2,200만 샘플, 최대 10억 매개변수 인코더, 더 긴 학습, 점진적 공간·시간 해상도 증가를 주요 확장 요소로 삼았다.

### 4.2 관찰 사전학습과 V-JEPA 2-AC의 행동 후학습

관찰만으로 학습한 V-JEPA 2는 비디오 안의 빠진 장면을 예측할 수 있지만, 특정 로봇 명령이 어떤 결과를 만드는지는 직접 조건으로 받지 않는다. V-JEPA 2-AC는 이 빈틈을 메운 별도 행동 조건부 모델이다. 고정한 ViT-g 인코더 위에 블록 인과 어텐션을 쓰는 약 3억 매개변수 Transformer 예측기를 붙이고, 과거 프레임 표현·7차원 말단장치 상태·7차원 동작 변화량을 시간 순서로 입력한다. 예측기는 다음 프레임 표현을 자회귀적으로 예측하며, 교사 강제 손실과 두 단계 롤아웃 손실을 함께 사용한다.

여기서 ‘62시간의 비라벨 로봇 비디오’라는 표현도 세밀하게 읽어야 한다. 연구진은 과제 이름, 보상, 성공·실패 표시는 쓰지 않았지만, 각 프레임에 딸린 말단장치 위치·자세·그리퍼 상태는 사용했다. 인접 상태의 차이로 동작 벡터를 구성했으므로 순수 영상만 본 것은 아니다. 데이터는 DROID의 Franka Panda 원격조작 궤적 약 2만 3천 개에서 왔으며, 4초 미만 클립을 제외한 실제 사용량이 62시간 미만이다.

### 4.3 목표 이미지 기반 모델 예측 제어와 ‘제로샷’의 범위

로봇 계획에서는 현재 프레임과 목표 이미지를 V-JEPA 2 인코더로 각각 표현한다. V-JEPA 2-AC가 후보 동작열의 결과 표현을 상상하면, 시스템은 그 표현이 목표 표현에 가까워지는 동작열을 교차엔트로피 방법(CEM)으로 찾는다. 첫 동작만 실행하고 새 관측을 받은 뒤 다시 계획하는 폐루프 모델 예측 제어(MPC)다. 긴 픽앤플레이스에서는 ‘물체 파지’, ‘목표 근처 이동’, ‘배치 완료’에 해당하는 시각 하위 목표를 사람이 순서대로 제공한다.

논문에서 ‘제로샷’은 두 연구실의 해당 로봇 개체와 장면에서 추가 데이터를 수집하거나 과제별 보상으로 다시 학습하지 않았다는 뜻이다. 세계의 모든 로봇과 과제에 무학습으로 일반화했다는 뜻은 아니다. 평가 장비는 두 대의 Franka 팔, RobotiQ 그리퍼, 저해상도 단안 RGB 카메라였고, 조작 대상과 과제도 컵·상자 중심의 도달·파지·들고 이동·픽앤플레이스로 제한됐다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. **문제 제기**: 텍스트 중심 AI는 공간 관계와 물리적 인과를 직접 경험하지 못하므로 로봇·자율주행·증강현실에 부족하다고 주장한다.
2. **핵심 아이디어**: V-JEPA 2가 시각 예측으로 물리 세계의 직관과 인과를 학습했다고 설명한다.
3. **방법 또는 구조**: 시각 인코더, 미래 시각 표현 예측, 공동 임베딩, 대조학습을 기술 요소로 제시한다.
4. **결과 또는 주장**: 로봇·자율주행·증강현실에서 더 정교한 조작과 예측을 열었다고 확장한다.
5. **의의와 한계**: 통계적 상관과 제한된 데이터라는 한계를 인정하면서도, V-JEPA 2가 범용 물리 지능의 핵심 전환점이라고 평가한다.

큰 방향에서 ‘언어 이외의 관찰로 세계 모델을 학습한다’는 문제의식은 공식 연구와 맞는다. 그러나 세부적으로는 2025년 4월이라는 날짜, 대조학습이라는 설명, 기본 V-JEPA 2와 행동 조건부 V-JEPA 2-AC의 혼합, 로봇 실험을 자율주행·증강현실 배포로 확대하는 서술을 교정해야 한다. ‘물리 법칙과 인과를 이해했다’는 표현도 벤치마크와 제한된 조작 실험이 직접 입증한 범위보다 넓다.

## 6. 왜 중요한가

V-JEPA 2의 연구적 중요성은 비디오 표현의 정확도 하나보다 관찰·예측·행동을 단계적으로 연결한 설계에 있다. 대규모 인터넷 비디오에서는 동작 라벨 없이 일반 표현을 배우고, 상대적으로 작은 로봇 데이터에서는 행동에 따른 상태 전이만 추가 학습한다. 그 뒤 표현 공간의 예측 오차를 실제 제어의 비용 함수로 사용한다. 이는 생성된 영상의 시각적 품질보다 계획에 필요한 상태 정보와 계산 효율을 우선한 선택이다.

특히 중요한 점:

- **목적함수의 전환**: 모든 픽셀을 재구성하지 않고 예측 가능한 잠재 특징을 맞춰, 계획과 인식에 중요한 구조에 계산을 집중한다.
- **데이터 역할의 분리**: 100만 시간 이상 관찰 비디오로 일반 표현을 만들고 62시간 미만의 로봇 궤적으로 행동 조건부 전이를 학습한다.
- **표현에서 제어까지의 연결**: 고정 인코더의 잠재 공간을 분류·행동 예상뿐 아니라 목표 조건부 MPC의 에너지 함수로도 사용했다.
- **언어 모델과의 보완 관계**: 통제 비교에서는 V-JEPA 2를 고정한 채 Qwen2-7B-Instruct와 1,800만 개 정렬 샘플을 공통으로 사용해 시각 인코더의 기여를 비교했다. 최종 80억 매개변수급 결과는 별도의 Llama 3.1 8B Instruct 구성과 8,850만 개 이미지·비디오-텍스트 학습 샘플에서 얻었다. 이는 세계 모델이 LLM을 대체하기보다 감각 표현을 보완할 수 있음을 보여 준다.
- **재현 가능성 확대**: 공식 저장소가 학습·평가 코드, 3억·6억·10억 매개변수 체크포인트, 프로브, V-JEPA 2-AC 체크포인트와 설정을 공개했다.

대표 결과는 평가 단위와 함께 읽어야 한다.

| 평가 | 보고된 결과 | 해석 범위 |
|---|---:|---|
| Something-Something v2 | 77.3% top-1 | 고정한 ViT-g/16 384 인코더 위에 과제별 어텐티브 프로브를 학습한 동작 분류 |
| EPIC-KITCHENS-100 | 39.7 mean-class recall@5 | 폐쇄된 주방 행동 집합에서 1초 뒤 동작을 예상한 결과 |
| PerceptionTest / TempCompass | 84.0 / 76.9 | Llama 3.1 8B Instruct와 V-JEPA 2를 결합하고 8,850만 개 이미지·비디오-텍스트 샘플로 학습한 최종 8B 구성 |
| 로봇 픽앤플레이스 | 컵 80%, 상자 65% | 두 연구실의 Franka 팔에서 목표·하위 목표 이미지를 주고 얻은 평균 성공률; 각 연구실·조건별 10회 시행 |

다만 ‘표현 공간에서 잘 예측한다’는 사실과 ‘명시적인 뉴턴 역학이나 인과 법칙을 안다’는 주장은 다르다. 역사적 의미는 인간과 같은 물리 이해를 완성했다는 데 있지 않고, 관찰로 학습한 잠재 표현을 실제 로봇의 짧은 폐루프 계획에 연결한 실증 경로를 보였다는 데 있다.

## 7. 현대 LLM과의 연결

- **[[055_The Transformer Attention Is All You Need|Transformer]]**: V-JEPA 2의 인코더와 예측기는 Transformer 계열이지만, 다음 텍스트 토큰의 확률을 최대화하는 언어 모델과 달리 마스킹된 비디오의 잠재 벡터를 회귀한다. 같은 기본 연산을 써도 학습 대상과 출력 의미가 다르다.
- **[[070_CLIP Contrastive Language-Image Pre-training for Multimodal Understanding|CLIP]]**: CLIP은 이미지·텍스트 쌍의 대조 정렬이 핵심인 반면 V-JEPA 2는 텍스트 없이 비디오 내부의 마스킹된 목표 표현을 예측한다. 원문이 V-JEPA 2를 대조학습으로 설명한 부분을 바로잡는 데 중요한 비교다.
- **[[105_Multimodal Integration Unified Architectures for Cross-Modal AI Understanding|멀티모달 통합]]**: V-JEPA 2 인코더를 언어 모델에 연결하면 비디오 질의응답이 가능하지만, 이 단계에는 별도의 프로젝터와 대규모 이미지·비디오-텍스트 정렬 및 지시 튜닝 데이터가 필요하다. 시각 사전학습만으로 언어 능력이 자동으로 생긴 것은 아니다.
- **에이전트와 세계 모델**: LLM이 목표를 언어로 분해하고 도구를 선택하는 데 강하다면, 행동 조건부 세계 모델은 후보 행동이 시각 상태를 어떻게 바꿀지 예측하는 데 초점을 둔다. 두 능력의 결합은 유망하지만, V-JEPA 2-AC 자체는 언어 목표를 받지 않고 목표 이미지를 요구한다.
- **생성 모델과 잠재 예측 모델**: 비디오 생성 모델은 사람이 볼 수 있는 픽셀 출력을 만들지만, V-JEPA 2는 계획에 쓸 잠재 표현을 만든다. 논문 실험에서 V-JEPA 2-AC는 한 동작 계획에 약 16초가 걸렸고 Cosmos 기반 비교 시스템은 약 4분이 걸렸다. 이는 잠재 계획의 효율 가능성을 보여 주지만 16초도 실시간 제어라고 부르기 어렵다.

비디오 질의응답 성능도 실험 설정별로 읽어야 한다. 시각 인코더 자체를 비교한 통제 실험에서는 각 인코더를 고정하고 동일한 Qwen2-7B-Instruct 백본, 프로젝터, 1,800만 개 이미지·비디오-텍스트 정렬 샘플을 사용했다. 반면 PerceptionTest 84.0과 TempCompass 76.9를 보고한 최종 V-JEPA 2 8B 실험은 Llama 3.1 8B Instruct 백본과 8,850만 개 이미지·비디오-텍스트 학습 샘플을 사용한 별도 구성이다. 따라서 이 수치는 Qwen2 통제 실험의 결과도, 순수 V-JEPA 2 단독 성능도 아니며 시각 인코더·프로젝터·언어 모델·더 큰 정렬 데이터가 결합된 전체 시스템 성능이다.

## 8. 한계와 비판적 관점

- **기술적 한계**: 기본 V-JEPA 2의 마스크 예측은 행동의 개입 효과를 직접 모델링하지 않는다. 행동 조건부 인과 전이는 별도의 V-JEPA 2-AC 후학습이 있어야 한다. 잠재 표현이 어떤 물리 변수를 명시적으로 담는지도 보장되지 않는다.
- **시간 범위의 한계**: EK100 행동 예상은 기본적으로 1초 앞을 대상으로 하며, 논문은 더 긴 시간 지평에서 정확도가 낮아진다고 보고한다. V-JEPA 2-AC도 자회귀 롤아웃 오차가 누적되고 계획 탐색 공간이 급증한다.
- **평가 범위의 한계**: SSv2의 77.3%는 고정한 인코더 위에 학습한 4층 어텐티브 프로브의 top-1 정확도이고, EK100의 39.7%는 폐쇄된 주방 행동 범주에서 1초 뒤 행동의 mean-class recall@5다. 범용 물리 법칙 이해 점수로 바꿔 읽을 수 없다.
- **비교의 한계**: 논문은 동일한 프로브 절차를 적용해도 비교 모델마다 사전학습 데이터와 학습 방법이 다르므로 시스템 수준 비교만 가능하다고 명시한다. 최고 성능 표가 단일 설계 요소의 인과적 우월성을 증명하지 않는다.
- **로봇 실험의 한계**: 두 연구실의 Franka 팔, 단안 RGB 카메라, 컵과 상자, 짧은 탁상 조작이 중심이며 각 조건의 시행 수가 작다. 연구진은 잘 작동하는 카메라 위치를 수동으로 찾았고, 카메라 각도에 따라 좌표축 추정 오류가 생겼다.
- **계획 속도의 한계**: RTX 4090 한 장에서 V-JEPA 2-AC가 동작 하나를 고르는 데 약 16초가 걸렸다. 원문의 ‘실시간 로봇·자율주행 적용’으로 일반화할 수 없다.
- **목표 지정의 한계**: 픽앤플레이스에는 사람이 제공한 목표 이미지와 시각 하위 목표가 필요하다. 자연어 목표, 장기 과제 자동 분해, 안전 제약은 입증되지 않았다.
- **데이터의 한계**: VM22M은 SSv2, Kinetics, HowTo100M, YT-Temporal-1B, ImageNet을 합친 2,200만 샘플이다. YouTube 중심 데이터의 편향과 장면 분포가 실제 로봇 환경 전체를 대표한다고 볼 수 없다.
- **인과 해석의 한계**: 다음 표현과 행동 결과의 통계적 규칙을 학습한 것이 반사실적 개입과 보편적 인과 구조를 이해했다는 뜻은 아니다. Meta가 함께 공개한 물리 추론 벤치마크에서도 인간과 최신 모델 사이에 큰 격차가 남았다.
- **응용 과장**: 공식 자료가 실증한 실제 배포는 제한된 로봇 팔 실험이다. 자율주행차, 증강현실, 범용 로봇, 산업 현장에서의 성능·안전성·지연은 별도 검증이 필요하다.
- **공개 범위의 경계**: 공식 저장소에는 코드, 설정, 여러 인코더 체크포인트, V-JEPA 2-AC 체크포인트와 평가 프로브가 공개돼 있다. 그러나 원래 사용한 100만 시간 규모 동영상 원본을 하나의 완전한 재배포 데이터셋으로 제공한 것은 아니며, 대규모 사전학습 계산을 재현하는 비용도 높다.

Meta 공식 발표문은 V-JEPA 2가 단일 시간 척도에서 학습·예측한다고 밝히고, 여러 시간·공간 척도를 다루는 계층적 JEPA와 시각·오디오·촉각을 결합한 멀티모달 JEPA를 후속 과제로 제시했다. 이 ‘다음 단계’ 목록 자체가 현재 모델의 범위를 보여 준다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| JEPA | 관측을 직접 생성하기보다 문맥에서 목표의 잠재 표현을 예측하는 Joint Embedding Predictive Architecture |
| V-JEPA 2 | 대규모 이미지·비디오에서 마스킹된 시공간 영역의 표현을 자기지도학습한 Meta의 비디오 인코더·예측기 계열 |
| V-JEPA 2-AC | 고정한 V-JEPA 2 인코더 위에서 로봇 동작과 말단장치 상태를 조건으로 미래 표현을 예측하도록 후학습한 모델 |
| 잠재 표현(latent representation) | 픽셀을 그대로 저장하지 않고 장면의 특징을 벡터로 압축한 내부 표현 |
| EMA 목표 인코더 | 문맥 인코더 가중치의 지수 이동 평균으로 갱신되어 안정적인 학습 목표를 만드는 인코더 |
| 마스크 제거(mask denoising) | 입력 일부를 가린 뒤 보이는 문맥에서 가려진 부분의 표현을 맞히는 자기지도 과제 |
| 대조학습(contrastive learning) | 대응하는 쌍은 가깝게, 비대응 쌍은 멀게 배치하도록 표현을 학습하는 방식. V-JEPA 2의 핵심 사전학습 손실과는 다르다. |
| 행동 조건부 예측 | 현재 상태뿐 아니라 에이전트의 동작을 입력으로 받아 다음 상태를 예측하는 방식 |
| 모델 예측 제어(MPC) | 여러 후보 동작의 결과를 모델로 예측하고, 첫 동작만 실행한 뒤 새 관측에서 반복해서 다시 계획하는 제어 방식 |
| 시각 목표(image goal) | 로봇이 도달해야 할 상태를 자연어가 아니라 이미지로 제시한 목표 |
| 제로샷 로봇 배포 | 논문의 해당 로봇 개체·연구실·과제에서 추가 학습하지 않고 기존 가중치를 적용했다는 뜻. 모든 환경에 대한 무조건적 일반화를 뜻하지 않는다. |

## 12. 짧은 결론

V-JEPA 2는 2025년 비디오 자기지도학습을 대규모로 확장하고, 그 잠재 표현을 행동 예상·비디오 질의응답·실물 로봇 계획으로 이어 본 중요한 연구다. 확인된 핵심은 대조학습이나 픽셀 생성이 아니라 마스킹된 비디오 부분의 EMA 목표 표현을 L1 손실로 예측한다는 점, 그리고 행동의 결과를 다루려면 별도의 V-JEPA 2-AC 후학습과 로봇 상태·동작 데이터가 필요하다는 점이다. 두 연구실의 Franka 팔에서 얻은 픽앤플레이스 결과는 잠재 공간 계획의 가능성을 보여 주지만, 16초 수준의 동작 계획 시간, 카메라 민감도, 이미지 하위 목표, 짧은 시간 지평과 좁은 과제 범위가 남아 있다. 따라서 이 연구의 의의는 인간 같은 물리 인과 이해나 자율주행·증강현실 배포를 완성했다는 데 있지 않고, 대규모 관찰 학습과 소규모 행동 학습을 결합해 세계 모델을 실제 제어로 연결하는 재현 가능한 경로를 제시했다는 데 있다.

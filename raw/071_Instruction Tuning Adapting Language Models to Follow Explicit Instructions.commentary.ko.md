# 지시 튜닝과 FLAN 해설

## 1. 한눈에 보기

- 핵심 주제: 여러 NLP 과제를 자연어 지시 형식으로 바꾸어 미세 조정하고, 학습 때 보지 않은 과제 유형에도 지시만으로 대응하게 하는 지시 튜닝(instruction tuning)
- 등장 배경: GPT-3가 문맥 내 예시로 여러 과제를 수행했지만, 제로샷 성능과 프롬프트 표현 변화에 대한 견고성이 충분하지 않았던 상황
- 가장 중요한 아이디어: 특정 과제의 정답 규칙만 학습하는 대신, 서로 다른 과제에 공통된 “지시를 읽고 요구된 출력을 만든다”는 상위 패턴을 지도 학습으로 익히게 한 것
- 이후 LLM/NLP에 남긴 영향: 범용 사전 학습 모델과 사용자 요청 사이에 다중 과제 지도 미세 조정이라는 후학습 단계를 정착시키고, 뒤이은 대화형 모델·RLHF·합성 지시 데이터 연구의 기반을 넓힌 것

> 이 문서는 `071_Instruction Tuning Adapting Language Models to Follow Explicit Instructions.md`의 번역문을 이해하기 위한 해설입니다. 원문을 되풀이하기보다 2021년 FLAN 실험이 실제로 입증한 범위, 지시 튜닝과 문맥 내 학습·과제별 미세 조정·RLHF의 차이, 원문의 넓은 역사 서술에서 사실과 후대 해석을 구분하는 기준을 정리합니다.

## 2. 핵심 요약

지시 튜닝은 사전 학습 언어 모델을 여러 과제의 자연어 지시와 목표 출력 쌍으로 추가 학습하는 방법이다. 2021년 FLAN 연구는 137B 매개변수의 LaMDA-PT를 62개 공개 NLP 데이터셋과 데이터셋별 자연어 지시 템플릿으로 미세 조정했다. 연구진은 데이터셋을 12개 과제 군집(task cluster)으로 묶고, 평가할 과제 군집 전체를 학습에서 제외하는 방식으로 “보지 않은 과제”를 비교적 엄격하게 정의했다. 논문이 보고한 best-dev template 조건에서 FLAN은 평가한 25개 데이터셋 중 20개에서 175B GPT-3의 제로샷 성능을 앞섰으며, 일부 과제에서는 퓨샷 GPT-3도 능가했다. 그러나 이는 지시 튜닝이 어떤 크기의 모델이나 어떤 과제에도 늘 이롭다는 뜻은 아니다. 같은 논문의 절제 실험에서는 8B 이하 모델의 보류 과제 성능이 오히려 나빠졌고, 언어 모델링 목표와 거의 같은 형식의 일부 과제에서도 이점이 제한적이었다. 또한 지시 튜닝은 모델에 사실 지식·추론 능력·안전성을 자동으로 주입하는 방법이 아니라, 이미 가진 능력을 자연어 요청에 맞춰 끌어내고 출력 형식을 조정하는 지도 후학습 방법으로 이해해야 한다.

- 무엇을 다루는가: FLAN을 중심으로 한 다중 과제 지시 미세 조정과 보지 않은 과제 유형에서의 제로샷 일반화
- 어떤 문제를 해결하려 했는가: 매번 예시를 넣거나 과제별 모델을 따로 학습하지 않고도 자연어 지시로 여러 과제를 수행하게 하는 문제
- 어떤 방식이 새로웠는가: 여러 데이터셋을 자연어 지시 템플릿으로 통일하고, 과제 군집 전체를 보류한 채 일반화를 평가한 방식
- 결과적으로 무엇을 바꾸었는가: “사전 학습 모델을 그대로 프롬프트한다”와 “과제별로 새 모델을 만든다” 사이에 범용 지시 후학습이라는 실용적 경로를 확립했다.

## 3. 역사적 배경

지시 튜닝은 아무 선례 없이 단독으로 등장한 발상이 아니다. BERT 계열의 사전 학습–미세 조정, T5의 모든 과제를 text-to-text 형식으로 통일하는 접근, GPT-3의 제로샷·퓨샷 문맥 내 학습, 다중 과제 학습과 자연어 프롬프트 연구가 이미 과제를 하나의 텍스트 인터페이스로 표현하는 길을 닦고 있었다. FLAN은 이 흐름을 “여러 과제를 자연어 지시로 미세 조정하면 보지 않은 과제 유형의 제로샷 성능도 좋아지는가?”라는 실험 질문으로 명확히 만들었다.

역사적으로는 Google의 FLAN만을 지시 튜닝의 유일한 출발점으로 놓지 않는 편이 정확하다. FLAN은 2021년 9월 처음 공개됐고 정식 논문은 ICLR 2022에 실렸다. 같은 2021년에는 T5 계열을 여러 프롬프트 과제로 학습한 T0 연구, Natural Instructions, CrossFit 같은 교차 과제 일반화 연구도 발표되었다. FLAN은 그중에서도 매우 큰 137B 모델, 자연어 지시 템플릿, 과제 군집 보류 평가를 결합해 규모와 과제 다양성이 제로샷 일반화에 미치는 효과를 강하게 보여 준 대표적 이정표다.

- 이전 접근법: 과제마다 별도 가중치를 만드는 지도 미세 조정, 예시를 프롬프트 안에 넣는 GPT-3식 문맥 내 학습, T5식 통합 text-to-text 인터페이스
- 당시의 한계: 제로샷 프롬프트가 표현에 민감했고, 퓨샷 예시는 문맥을 차지했으며, 과제별 미세 조정은 데이터·가중치·운영 파이프라인을 반복해서 요구했음
- 이 주제가 필요했던 이유: 하나의 사전 학습 모델이 자연어로 설명된 여러 과제 사이에서 전이하고, 새로운 과제 유형에도 지시만으로 대응할 수 있는지를 검증할 필요가 있었음

## 4. 핵심 개념 해설

### 4.1 지시 튜닝과 세 가지 적응 방식

과제별 미세 조정에서는 보통 하나의 과제 데이터로 모델 가중치를 업데이트하고 그 과제 전용 체크포인트를 만든다. 문맥 내 학습에서는 가중치를 바꾸지 않고 추론 시 프롬프트에 설명과 예시를 넣는다. 지시 튜닝은 여러 과제의 지시-입력-출력 예시로 가중치를 업데이트하여, 이후 자연어 지시 자체를 공통 인터페이스로 사용하게 한다.

세 방법은 서로 배타적이지 않다. 지시 튜닝된 모델에 퓨샷 예시를 추가할 수 있고, 지시 튜닝 체크포인트를 특정 과제에 다시 미세 조정할 수도 있다. FLAN 논문에서도 지시와 퓨샷 예시를 함께 사용할 때 모든 평가 과제 군집에서 제로샷 FLAN보다 성능이 좋아졌다. 따라서 지시 튜닝을 “프롬프트가 더는 필요 없는 기술”로 읽기보다, 프롬프트가 모델이 학습한 인터페이스와 더 잘 맞도록 만드는 후학습으로 이해하는 편이 낫다.

### 4.2 FLAN의 데이터 구성과 보류 평가

원 FLAN 논문은 TensorFlow Datasets에 공개된 62개 텍스트 데이터셋을 12개 과제 군집으로 묶었다. 각 데이터셋에는 연구자가 자연어 지시 템플릿 10개를 작성했고, 일부 템플릿은 원래 과제를 뒤집은 형태까지 포함해 표현과 입출력 방향을 다양화했다. 학습 예시는 데이터셋별 템플릿 가운데 하나를 무작위로 적용해 만들었다.

“보지 않은 과제”의 정의가 특히 중요하다. 평가 데이터셋 하나만 빼는 것이 아니라 같은 과제 유형에 속한 군집 전체를 지시 튜닝에서 제외했다. 예컨대 자연어 추론(NLI)을 평가할 때는 어떤 NLI 데이터셋도 학습에 넣지 않았다. 또한 평가할 군집마다 나머지 군집으로 별도의 체크포인트를 학습했으므로, 10개 군집의 결과를 하나의 고정된 FLAN 체크포인트가 모두 낸 것처럼 이해하면 안 된다. 이 설계는 데이터셋 이름만 새로운 경우보다 더 강한 과제 유형 일반화를 시험하지만, 사전 학습 웹 자료에 개별 평가 예시가 들어 있었을 가능성까지 완전히 없애지는 못한다.

### 4.3 조건부 생성 목표와 원문의 수식 흔적

지시를 $I$, 입력을 $x$, 목표 출력을 $y$라고 하면 의도한 학습 목표는 조건부 확률 $P(y\mid I,x)$를 높이는 것이다. 즉 모델은 지시와 입력을 읽은 뒤 목표 출력의 토큰을 순차적으로 예측한다. 분류도 정답 레이블(label)을 텍스트로 생성하게 만들 수 있고, 번역·요약처럼 출력 공간이 큰 과제도 같은 생성 인터페이스로 다룰 수 있다.

번역 원문의 `III`, `xxx`, `yyy`, `P(y∣I,x)P(y | I, x)P(y∣I,x)` 표기는 웹 수식 변환 과정에서 같은 기호와 수식이 중복된 렌더링 흔적이다. 번역문은 보존 자료의 구조를 유지하기 위해 이를 그대로 옮겼지만, 수학적으로 세 확률을 연달아 곱한다는 뜻으로 읽어서는 안 된다. 핵심은 하나의 조건부 생성식 $P(y\mid I,x)$다.

또한 지시 튜닝을 “기존 모델 위에 새 기술 계층을 얹는다”고 말하는 것은 기능적 비유다. 2021년 FLAN은 별도의 작은 모듈만 추가한 것이 아니라 사전 학습 모델의 가중치를 미세 조정했다. 아키텍처를 크게 바꾸지 않는다는 사실과 매개변수를 업데이트하지 않는다는 주장은 서로 다르다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. GPT-3식 퓨샷 문맥 내 학습과 과제별 미세 조정이 지닌 사용성·확장성 문제를 제기한다.
2. 여러 과제를 자연어 지시-응답 쌍으로 바꾸어 지도 미세 조정하는 해결책을 제시한다.
3. FLAN을 대표 사례로 들어 과제 다양성, 지시 표현, 출력 형식과 과제 간 전이를 설명한다.
4. 제로샷·퓨샷 성능, 통합 모델, 데이터셋 구축과 실용적 응용에 미친 영향을 넓게 서술한다.
5. 데이터 품질, 모호성, 기반 모델의 한계와 안전성 문제를 짚고 현대 대화형·멀티모달 모델로 이어지는 유산을 전망한다.

이 흐름에는 2021년 FLAN 논문에서 직접 측정한 **실험 결과**, 이후 여러 연구에서 확장된 **연구 계보**, 현대 제품에 관한 **일반화된 해석**이 함께 들어 있다. 세 층위를 구분하면 지시 튜닝의 역사적 의미를 인정하면서도 단일 논문이 입증한 범위를 과장하지 않을 수 있다.

## 6. 왜 중요한가

지시 튜닝의 핵심 공헌은 수십 개 과제를 한 모델로 처리했다는 사실만이 아니다. 자연어 지시를 단순한 사용 시점의 요령이 아니라 학습 자료의 명시적 구성 요소로 삼아, 사전 학습과 사용자 인터페이스 사이의 불일치를 줄였다는 데 있다. 과제별 레이블 공간과 입력 형식을 텍스트로 통일하면서 다중 과제 학습의 전이를 실제 사용자가 쓰는 요청 형식과 연결했다.

특히 중요한 점:

- 과제 군집 전체를 보류해, 같은 데이터셋의 변형이 아니라 보지 않은 과제 유형에 대한 제로샷 전이를 시험했다.
- 과제 수와 모델 규모, 자연어 지시가 성능 향상의 핵심 조건임을 절제 실험으로 분리해 확인했다.
- 하나의 범용 체크포인트를 여러 자연어 요청에 적응시키는 후학습 패러다임을 확산해, 대화형 모델과 범용 어시스턴트(assistant)의 데이터 설계에 직접적인 질문을 남겼다.

그러나 “실용적으로 만들었다”는 표현은 접근성 향상과 제품 완성도를 구분해야 한다. FLAN 논문은 NLP 벤치마크의 제로샷 성능을 평가했으며, 실제 사용자의 만족도, 장기 대화, 사실성, 안전성, 지연 시간(latency)이나 운영 비용을 종합적으로 측정한 제품 연구는 아니었다.

## 7. 현대 LLM과의 연결

현대 LLM의 후학습은 지시 튜닝 하나로 끝나지 않는다. 보통 사람이 작성하거나 모델이 합성한 지시-응답 자료를 이용한 지도 미세 조정, 선호 비교나 비평 자료를 이용한 정렬, 안전 정책 학습, 도구 사용과 대화 형식 학습 등이 조합된다. 공개된 세부 절차는 모델마다 다르며, 상용 모델의 전체 학습 파이프라인이 모두 알려진 것도 아니다.

- 지도 미세 조정(SFT): 정답 또는 모범 응답을 직접 예측하게 한다는 점에서 FLAN식 지시 튜닝과 가장 가깝다. 다만 현대의 대화 데이터는 단일 NLP 과제보다 다중 턴(multi-turn) 대화, 거절, 형식 준수와 도구 호출까지 포함할 수 있다.
- RLHF와 선호 최적화: 어떤 응답이 더 나은지에 관한 인간 선호를 사용한다. 지시-정답 쌍으로 학습하는 것과 목적·자료·최적화 방식이 다르므로, 지시 튜닝을 곧 RLHF라고 부르면 안 된다.
- 합성 지시 데이터: Self-Instruct 이후 모델이 씨앗 과제를 확장하거나 응답을 생성해 학습 자료를 늘리는 방법이 발전했다. 규모를 키울 수 있지만 오류·편향·중복을 함께 증폭할 위험이 있다.
- 프롬프트와 문맥 내 학습: 지시 튜닝은 프롬프트 공학을 없애지 않았다. 모델이 지시 형식을 더 익숙하게 처리하도록 만들었지만, 예시 선택·문맥 배치·출력 제약은 여전히 결과를 바꾼다.

ChatGPT 같은 대화형 모델이 지시 따르기 후학습과 인간 선호 학습을 결합했다는 점은 FLAN과의 개념적 계보를 보여 준다. 다만 이것이 특정 상용 모델이 FLAN 체크포인트나 FLAN 데이터로 직접 학습되었다는 뜻은 아니다. “영향을 주었다”와 “직접 이어진 동일한 학습 계보”는 근거 수준이 다르다.

## 8. 한계와 비판적 관점

원문은 지시 튜닝의 장기적 영향을 폭넓게 설명하지만, 2021년 FLAN이 보여 준 결과에는 분명한 경계가 있다. 137B 모델에서의 성공이 작은 모델에도 자동으로 적용되지 않았고, 여러 표현을 학습했다고 해서 모든 말바꿈에 견고해진 것도 아니었다. 실제로 논문은 단순한 단어 위치 반환이나 덴마크어 지시 같은 쉬워 보이는 사례에서도 실패를 보고했다.

- 기술적 한계: 원 FLAN 절제 실험에서는 8B 이하 모델의 보류 과제 성능이 지시 튜닝 뒤 오히려 낮아졌고, 문장 완성에 가까운 상식 추론·상호참조 일부 과제에서는 이점이 제한적이었다.
- 이론적 한계: 자연어 지시와 정답의 통계적 대응을 학습하는 것이 지시의 의미를 인간처럼 이해했다는 증거는 아니다. 과제 표현, 레이블 단어, 디코딩(decoding)과 평가 방식이 성능에 영향을 준다.
- 실용적 한계: 다양한 지시 자료를 모으는 비용뿐 아니라 충돌하는 지시, 그릇된 정답, 데이터 오염, 과제 비중과 언어 편향을 관리해야 한다. 137B FLAN은 서비스 비용도 컸다.
- 오늘날 관점에서 다시 봐야 할 점: 지시 튜닝은 안전 정렬이나 사실성 보장의 동의어가 아니다. 악의적 지시를 잘 따르거나 그럴듯한 오류를 형식에 맞게 출력할 수도 있으므로 별도의 정책·검증·선호 학습이 필요하다.

역사 서술에도 주의가 필요하다. FLAN은 대표적인 이정표지만, 2021년 지시 기반 일반화는 T0, Natural Instructions 등 여러 연구 흐름이 함께 만든 분야다. 또한 원문이 현대 GPT-4와 Claude를 “지시 튜닝되었다”고 넓게 묶는 설명은 일반적인 후학습 관행을 가리키는 수준으로 읽어야 한다. 각 모델의 정확한 데이터 구성과 단계는 공개 범위가 달라 하나의 동일한 FLAN식 절차로 단정할 수 없다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 지시 튜닝(instruction tuning) | 여러 과제를 자연어 지시와 목표 출력 형태로 바꾸어 사전 학습 모델을 지도 미세 조정하는 방법 |
| FLAN | 137B LaMDA-PT를 62개 NLP 데이터셋의 자연어 지시 템플릿으로 미세 조정한 2021년 Google 연구의 모델 |
| 과제 군집(task cluster) | 자연어 추론, 번역, 질의응답처럼 같은 유형의 데이터셋을 묶은 평가 단위 |
| 제로샷 일반화 | 평가 과제의 예시를 프롬프트에 제공하거나 해당 과제 유형으로 추가 학습하지 않고 지시만으로 수행하는 능력 |
| 문맥 내 학습(in-context learning) | 모델 가중치를 바꾸지 않고 프롬프트의 설명·예시로 과제를 지정하는 방식 |
| 지도 미세 조정(SFT) | 입력에 대한 목표 출력을 직접 맞히도록 사전 학습 모델의 가중치를 추가 학습하는 과정 |
| RLHF | 모델 응답에 대한 인간의 비교·평가를 보상 신호로 사용해 행동을 조정하는 후학습 방법 |

## 12. 짧은 결론

지시 튜닝은 자연어 지시를 학습과 사용의 공통 인터페이스로 만들어 사전 학습 언어 모델을 범용 어시스턴트로 적응시키는 핵심 경로를 열었다. 2021년 FLAN의 가장 강한 증거는 137B 모델, 62개 데이터셋, 과제 군집 보류라는 구체적인 실험에서 best-dev template 조건으로 25개 중 20개 데이터셋의 제로샷 GPT-3 성능을 앞선 결과다. 동시에 작은 모델과 일부 과제의 부정적 결과, 군집별 별도 체크포인트, 사전 학습 데이터 오염 가능성과 서비스 비용은 “지시를 학습하면 무엇이든 따른다”는 해석을 막는다. 오늘날의 지속적인 교훈은 지시 튜닝을 만능 능력 주입이 아니라, 모델이 가진 능력을 다양한 자연어 요청에 연결하는 강력하지만 데이터·규모·평가·안전 조건에 의존하는 후학습 방법으로 보아야 한다는 데 있다.

# BERT: 양방향 사전 학습이 언어 이해를 바꾸다

출처: https://mbrenndoerfer.com/writing/bert-bidirectional-pretraining-revolutionizes-language-understanding

---

BERT(Bidirectional Encoder Representations from Transformers)를 종합적으로 설명한다. 마스크드 언어 모델링, 양방향 문맥 표현, 사전 학습 뒤 미세조정 패러다임과 자연어 처리에 미친 영향을 살펴본다.

## 2018년: BERT

2018년 10월 Google AI Language 연구진은 자연어 처리를 크게 바꾼 논문 「BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding」를 공개했다. BERT(Bidirectional Encoder Representations from Transformers)는 질의응답부터 감성 분석까지 열한 개 자연어 이해 과제에서 당시 최고 결과를 달성했다. 변화를 만든 것은 성능뿐 아니라 접근 방식이었다. 양방향 Transformer encoder를 마스크드 언어 모델링(masked language modeling, MLM)과 다음 문장 예측(next sentence prediction, NSP)이라는 두 과제로 사전 학습한 뒤, 과제별 구조를 조금만 추가해 다양한 자연어 처리 과제에 전체 모델을 미세조정할 수 있었다.

BERT는 언어 AI 발전의 중요한 시점에 등장했다. 1년 전 발표된 Transformer는 주로 기계 번역에서 가능성을 보였고, 연구자들은 self-attention이 풍부한 문맥 관계를 포착한다는 점에 주목해 이해 과제에 활용하는 방법을 탐구하고 있었다. 그러나 기존 사전 학습 표현에는 한계가 있었다. 전통적인 언어 모델은 왼쪽에서 오른쪽 또는 오른쪽에서 왼쪽 한 방향으로 텍스트를 처리했다. 현재 단어를 부호화할 때 양쪽 문맥을 함께 사용할 수 없으므로 양방향 문맥이 필요한 이해 과제에 제약이 생겼다.

돌파구는 이해 과제의 사전 학습에는 생성과 다른 목적이 유용하다는 인식에서 나왔다. 자기회귀 언어 모델은 다음 단어를 차례로 예측하지만 이해 과제는 양쪽 문맥에서 이득을 얻는다. BERT는 입력 token 일부를 무작위로 가리고 앞뒤 문맥에서 복원하게 하는 마스크드 언어 모델링을 사용했다. 이 변화는 모델이 좌우 문맥을 함께 사용하는 표현을 배우게 했고, 여러 이해 과제에 강하게 전이됐다.

BERT의 영향은 즉각적이었다. GLUE 벤치마크에서 이전 시스템을 크게 앞섰고, 큰 Transformer를 방대한 비표지 텍스트로 사전 학습한 뒤 특정 과제에 미세조정하는 패러다임을 널리 확산했다. 이 접근은 GPT-2, T5와 현대 대규모 언어 모델에 이르기까지 후속 연구의 중요한 기준이 됐다. BERT는 Transformer가 생성뿐 아니라 이해 과제에도 강한 기반이 될 수 있음을 보이고, 양방향 문맥의 가치를 입증했다.

## 문제

BERT 이전의 언어 표현 학습에는 후속 이해 과제에서 사전 학습 모델의 효과를 제한하는 문제가 있었다. 초기 신경 언어 모델은 보통 텍스트를 한 방향으로 처리했다. 왼쪽에서 오른쪽 모델은 앞 문맥에서 다음 단어를, 오른쪽에서 왼쪽 모델은 뒤 문맥에서 이전 단어를 예측했다. 하지만 질의응답, 자연어 추론, 감성 분석처럼 단어 의미를 파악하려면 앞뒤를 모두 봐야 하는 과제가 많았다.

“The bank announced it would increase interest rates.”에서 bank를 이해하려면 announced라는 앞 단서와 interest rates라는 뒤 단서가 모두 도움이 된다. 왼쪽에서 오른쪽으로 읽는 언어 모델은 bank를 부호화할 때 interest rates를 아직 보지 못한다. 반대 방향 모델은 반대쪽 정보를 놓친다. 어느 한 방향만으로는 현재 위치의 전체 양방향 문맥을 동시에 이용할 수 없다.

문제는 단어 의미 중의성에 그치지 않았다. “The cat sat on the mat”이 “The mat is under the cat”과 어떤 관계인지 판단하려면 여러 방향의 통사·의미 관계를 이해해야 한다. 주어–동사–목적어, 수식 관계, 대용 표현은 문장 전체 문맥을 요구한다. 한 방향으로 상태를 누적하는 모델은 뒤의 정보를 반영해 앞 위치의 표현을 다시 만드는 데 구조적 제약이 있었다.

사전 학습 목적과 후속 과제 사이의 불일치도 있었다. 다음 단어 예측은 텍스트 생성과 자연스럽게 맞지만, 분류·질의응답·함의 판단은 중요한 구간을 찾고 문장 쌍을 비교하며 관계를 판단해야 한다. 다음 단어 예측에서 배운 표현도 전이할 수 있으나, 이해 과제에 최적으로 맞춰진 목적은 아니었다.

ELMo 같은 특징 기반 방법은 양방향 LSTM 표현을 결합해 일부 제약을 다뤘다. 그러나 LSTM은 시퀀스를 차례로 처리하고 깊게 쌓는 데 비용이 컸다. 또한 ELMo는 사전 학습 모델의 내부 표현을 기존 과제 모델에 특징으로 공급했으므로 후속 과제의 주 모델은 따로 학습해야 했다.

기존 전이 방식은 과제별 구조 수정과 통합 작업도 많이 요구했다. 새 과제마다 별도 구조를 설계하거나 사전 학습 요소를 어디에 넣을지 결정해야 했고, 다양한 과제에서 같은 모델을 재사용하기 어려웠다.

## 해법

BERT는 양방향 이해에 맞춘 구조와 사전 학습 목적을 결합했다. Transformer encoder는 모든 입력 위치 사이 self-attention을 계산한다. 미래 token을 가리는 자기회귀 causal mask를 사용하지 않으므로 각 위치가 좌우 입력에 접근할 수 있다. 이런 encoder를 마스크드 언어 모델링으로 사전 학습해 양방향 문맥을 실제 학습 신호로 만들었다.

핵심 혁신은 MLM이었다. 사전 학습 입력 token의 약 15%를 예측 대상으로 고르고, 그 위치의 원 token을 주변 문맥에서 맞히게 했다. 다음 token 예측과 달리 가려진 위치의 왼쪽과 오른쪽을 모두 사용할 수 있었다. 모델은 양쪽 문맥의 관계를 이용해 복원하는 표현을 학습했고, 이는 여러 이해 과제에 적합했다.

### 마스크드 언어 모델링 전략

선택된 token 모두를 `[MASK]`로 바꾸지는 않았다. 선택 위치 가운데 80%는 `[MASK]`로, 10%는 임의 token으로 바꾸고, 나머지 10%는 원 token을 그대로 두었다. 미세조정 입력에는 보통 `[MASK]`가 없으므로, 모델이 이 특수 기호에만 의존하는 사전 학습–미세조정 불일치를 줄이려는 전략이었다. 어떤 방식으로 제시되든 선택된 위치의 원 token을 예측하게 했다.

Transformer encoder도 중요한 역할을 했다. self-attention은 각 위치가 같은 층에서 다른 모든 입력 위치와 직접 상호작용하게 한다. LSTM처럼 시점을 차례로 처리하지 않아 큰 말뭉치에서 위치 병렬 훈련이 가능했고, 모든 층에서 양방향 문맥을 유지했다. multi-head attention은 서로 다른 관계를 병렬로 포착할 표현 용량을 제공했다. 다만 각 head가 고정된 통사·의미·화용 역할을 갖는다고 보장하는 것은 아니다.

BERT는 사전 학습 때 다음 문장 예측(NSP)도 사용했다. 입력 문장 A 뒤에 원문에서 실제로 이어지는 B가 오는 경우와 무작위 문장 B가 오는 경우를 절반씩 만들어 이어지는 관계인지 분류했다. 저자들은 이것이 질의응답과 자연어 추론처럼 문장 쌍 관계를 다루는 과제에 도움이 된다고 보았다. MLM과 NSP를 함께 사용해 token 수준과 문장 쌍 수준 신호를 제공했다.

구조에는 후속 Transformer에서 널리 쓰인 특수 token이 포함됐다. `[CLS]`는 입력 맨 앞에 놓이고 최종 hidden state가 문장·문장쌍 분류에 사용됐다. `[SEP]`는 문장 끝과 문장 쌍의 경계를 표시했다. 입력 표현은 token, segment, position embedding의 합이었다. 이 형식은 단일 문장과 문장 쌍을 같은 encoder에서 처리하게 했다.

후속 과제 미세조정은 비교적 단순했다. 분류에서는 `[CLS]` 최종 표현 위에 선형 층을 두었다. 질의응답에서는 각 token이 답의 시작과 끝일 점수를 예측하는 층을 추가했다. 문장 쌍 과제는 두 문장을 `[SEP]`로 이어 입력했다. 작은 과제별 출력 층을 추가한 뒤 사전 학습 BERT 전체를 과제 자료로 공동 미세조정했다. 이 방식은 과제별 구조 공학을 크게 줄였다.

## 응용과 영향

BERT는 발표 당시 열한 개 자연어 처리 과제에서 새 최고 결과를 보고했다. SQuAD 질의응답, MNLI 자연어 추론, SST-2 감성 분류, CoNLL-2003 개체명 인식 등 여러 과제가 포함됐다. 향상 폭은 과제마다 달랐지만 일부에서는 이전 최고 시스템보다 여러 점 높았다.

질의응답에서는 지문의 token마다 답 시작·끝 점수를 예측하도록 미세조정해 SQuAD 1.1과 2.0에서 강한 결과를 냈다. 자연어 추론에서는 문장 쌍의 함의·모순·중립을 분류했고, 감성 분류에서는 문장 표현을 사용했다. 이는 같은 사전 학습 encoder가 서로 다른 출력 형식에 작은 헤드를 붙여 적응할 수 있음을 보여 주었다.

성능보다 더 큰 변화는 연구와 실무의 방법론이었다. 큰 Transformer를 먼저 사전 학습하고 새 과제에는 간단한 출력 층을 추가해 전체 모델을 미세조정하는 방식이 표준이 됐다. 연구자는 과제별 복잡한 구조를 처음부터 만드는 대신 공통 기반 모델을 출발점으로 삼을 수 있었다. 공개된 사전 학습 checkpoint는 자체 대규모 훈련 자원이 없는 조직도 강한 언어 표현을 사용할 수 있게 했다.

BERT는 Transformer encoder가 폭넓은 이해 과제의 기반이 될 수 있음을 확인했다. 번역에서 검증된 self-attention 구조가 분류·질의응답·추론·sequence labeling에도 효과적임을 보이면서 Transformer를 생성과 이해 양쪽의 중심 구조로 만들었다.

상용 응용에서도 검색, 챗봇, 추천, 분류 등에 BERT와 변형 모델이 도입됐다. 특정 영역과 과제에 미세조정할 수 있다는 점이 실제 배포에 유리했다. 그러나 정확한 제품 채택·성능·비용은 시스템별 근거가 필요하며 BERT 한 논문이 모든 산업 효과를 입증한 것은 아니다.

BERT의 성공은 사전 학습 목표와 구조 개선 연구를 촉진했다. RoBERTa는 NSP를 제거하고 자료·batch·학습량을 바꿨고, ALBERT는 매개변수 공유로 크기를 줄였으며, DistilBERT는 지식 증류로 추론 비용을 낮추려 했다. ELECTRA는 가려진 token을 복원하는 대신 교체된 token을 판별하는 목적을 제안했다.

‘이해 과제에는 양방향 문맥이 유용하다’는 통찰도 오래 남았다. 다만 현대 자기회귀 생성 모델이 BERT식 양방향 encoder를 내부에 갖는다고 일반화할 수는 없다. 이들은 prompt 전체의 token이 causal mask 아래 앞쪽 문맥만 보도록 계산하지만, 생성할 때 주어진 전체 prompt를 조건으로 사용할 수 있다. 구조적 양방향성과 입력을 모두 읽었다는 일상적 표현을 구분해야 한다.

## 한계

BERT의 중요한 한계는 계산 비용이었다. BERT-base는 약 1억 1천만 개, BERT-large는 약 3억 4천만 개 매개변수를 가졌다. 사전 학습에는 큰 계산 자원이 필요했고, 미세조정과 추론도 GPU·TPU가 제한된 연구자에게 부담이었다. 실시간·모바일·edge 배포에서는 지연과 메모리 제약이 컸다.

입력 길이도 최대 512 token으로 제한됐다. 많은 문장·짧은 지문에는 충분하지만 긴 문서, 다중 대화, 장문 문맥을 한 번에 처리하지 못했다. 자르거나 여러 조각으로 나누면 문서 전체 관계가 손실될 수 있었다. 이 제약은 긴 sequence 모델 연구를 촉진했다.

MLM은 이해 과제에 효과적이었지만 자연스러운 왼쪽에서 오른쪽 생성 목적은 아니었다. BERT는 입력 전체를 보고 가려진 위치를 복원하므로 다음 token을 차례로 생성하는 자기회귀 모델처럼 직접 텍스트 생성에 쓰기 어렵다. 분류와 표현 학습에는 강하지만 생성이 필요한 과제에는 다른 구조나 decoding 방법이 필요했다.

풍부한 문맥 표현이 명시적 구조 추론을 보장하지도 않았다. 여러 단계 논리, 수학적 조작, 기호 추론은 미세조정 뒤에도 어려울 수 있었다. 벤치마크 정답률을 사람과 같은 이해나 일반 추론의 증거로 동일시하면 안 된다.

NSP의 유용성도 후속 연구에서 재검토됐다. RoBERTa는 NSP 없이 더 많은 자료와 긴 학습, 동적 masking 등을 사용해 강한 결과를 얻었다. 하지만 여러 요소를 함께 바꿨으므로 “NSP는 항상 무용하다”는 단일 원인 결론도 조심해야 한다. BERT 원 논문의 ablation에서는 NSP 제거가 일부 과제에 손해를 주었다고 보고됐다.

모든 후속 과제가 같은 이득을 얻은 것도 아니다. 사전 학습 분포와 크게 다르거나 명시적 순차 생성이 필요한 과제에서는 효과가 달랐다. 전이 성능은 목적함수·자료·출력 구조와 미세조정 조건에 의존했다.

사전 학습 자료의 편향도 물려받았다. BooksCorpus와 영어 Wikipedia에는 사회·문화·언어 편향과 coverage 불균형이 있었다. 이 표현을 후속 응용에 사용하면 불공정한 연관이나 오류가 재현·증폭될 수 있다. 높은 평균 벤치마크 성능은 공정성이나 안전성을 보장하지 않는다.

## 유산

BERT의 유산은 당시 성능 향상보다 넓다. 이해 과제에서 양방향 사전 학습이 효과적이며 MLM이 이를 가능하게 하는 목적이라는 점을 실증했다. 이 생각은 후속 encoder형 언어 모델에 큰 영향을 주었다. 다만 ‘모든 현대 언어 모델이 BERT식 양방향 사전 학습을 쓴다’고 확대해서는 안 된다.

BERT가 널리 알린 사전 학습 뒤 미세조정 패러다임은 후속 과제 적용의 표준이 됐다. 복잡한 과제 전용 구조를 새로 설계하는 대신 공통 기반 모델 위에 작은 출력 층을 추가하고 전체 모델을 학습할 수 있었다. 공개 checkpoint와 도구는 연구와 산업에서 Transformer 기반 표현의 채택을 빠르게 했다.

Transformer encoder가 이해 과제의 강력한 구조라는 점도 확립했다. self-attention은 먼 위치를 직접 연결하고 입력 위치를 병렬 처리하며, 모든 층에서 좌우 문맥을 통합했다. 번역 encoder에서 시작한 구조가 분류·추론·질의응답으로 확장됐다.

RoBERTa·ALBERT·DistilBERT·ELECTRA 등은 BERT의 목표·효율·훈련 절차를 바꾸며 발전했다. 이 변형들은 BERT의 문제 설정을 이어받았지만 각 기법의 성과는 별도 실험과 근거로 평가해야 한다.

BERT의 성공은 더 큰 모델·더 나은 자료·새 사전 학습 목표에 대한 투자를 촉진했다. GPT-3와 T5 및 후대 모델도 큰 말뭉치 사전 학습과 과제 전이라는 넓은 패러다임을 공유한다. 그러나 GPT의 causal 자기회귀 목적과 BERT의 MLM은 서로 다른 조건부 예측 문제이며, 생성과 이해 인터페이스도 다르다.

### 전이 학습 혁명

BERT는 대규모 비표지 말뭉치의 사전 학습 뒤 과제별 미세조정이 적은 표지 자료에서도 처음부터 학습한 과제 전용 모델보다 강할 수 있음을 보였다. 이는 비표지 텍스트의 통계적 규칙성을 여러 표지 과제로 옮기는 자연어 처리 전이 학습을 표준 관행으로 만들었다.

상용 자연어 처리에도 영향이 컸다. 검색·고객 지원·콘텐츠 분류 등에서 BERT와 변형이 사용됐다. 사전 학습 모델을 특정 영역에 맞추는 방식은 처음부터 큰 모델을 훈련하기 어려운 조직에도 강한 출발점을 제공했다. 하지만 공개 checkpoint 사용이 계산·편향·자료 품질 문제까지 자동 해결하는 것은 아니다.

BERT의 여러 과제 성과는 GLUE 같은 종합 평가의 중요성도 부각했다. 빠른 성능 향상은 더 어려운 SuperGLUE와 진단적 평가를 만들 동기가 됐다. 동시에 여러 점수를 하나의 ‘언어 이해’ 수치로 합치는 방식의 한계도 드러났다.

후대 모델은 BERT의 한계를 서로 다른 방식으로 다룬다. T5는 이해와 생성을 text-to-text 형식으로 통합했고, 긴 문맥 모델은 512 token 제약을 완화했으며, 효율적 encoder와 증류 모델은 배포 비용을 줄이려 했다. 자기회귀 대규모 언어 모델은 BERT식 MLM을 쓰지 않더라도 큰 사전 학습과 전이라는 넓은 문제를 공유한다.

언어 AI가 더 일반적인 시스템으로 발전한 뒤에도 BERT가 남긴 핵심 질문은 유효하다. 어떤 사전 학습 목표가 어떤 후속 능력으로 전이되는가, 입력 양쪽 문맥을 어떤 구조로 사용할 것인가, 공통 모델을 최소한의 과제별 수정으로 어떻게 적응시킬 것인가 하는 질문이다. BERT는 이 세 축을 강력한 하나의 실증으로 결합한 역사적 모델이다.

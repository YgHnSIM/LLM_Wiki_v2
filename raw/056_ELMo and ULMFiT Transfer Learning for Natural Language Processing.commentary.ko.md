# ELMo와 ULMFiT의 자연어 처리 전이 학습 해설

## 1. 한눈에 보기

- 핵심 주제: 언어 모델 사전 학습 지식을 후속 과제로 옮기는 두 경로
- 등장 배경: 정적 단어 임베딩의 문맥 독립성과 과제별 모델의 반복 학습 비용
- 가장 중요한 아이디어: ELMo는 고정된 양방향 언어 모델의 층별 표현을 과제 특징으로 쓰고, ULMFiT는 언어 모델 전체를 단계적으로 미세조정한다.
- 이후 LLM/NLP에 남긴 영향: 문맥화 표현과 사전 학습–과제 적응을 자연어 처리의 기본 설계 축으로 만들었다.

> 이 문서는 `057_ELMo and ULMFiT Transfer Learning for Natural Language Processing.md`의 번역문을 이해하기 위한 해설이다. 두 방법의 공통점보다 전이 경로의 차이를 중심으로 읽는다.

## 2. 핵심 요약

ELMo와 ULMFiT는 모두 큰 비표지 텍스트에서 언어 모델을 먼저 학습한 뒤 그 지식을 표지 자료가 있는 후속 과제에 재사용했다. 그러나 ELMo는 사전 학습 양방향 LSTM의 각 층 출력을 과제별 가중합으로 만들어 기존 모델에 특징으로 넣었다. ULMFiT는 AWD-LSTM을 일반 말뭉치에서 사전 학습하고 목표 영역의 언어 모델로 미세조정한 뒤, 분류기를 붙여 모델을 점진적으로 풀어 가며 학습했다. 따라서 둘은 단순히 같은 ‘사전 학습 모델’의 두 이름이 아니라, 표현을 고정해 꺼내 쓰는 방법과 모델을 새 과제에 적응시키는 방법의 대비를 보여 준다.

- 무엇을 다루는가: 2018년 ELMo와 ULMFiT가 만든 NLP 전이 학습의 두 인터페이스
- 어떤 문제를 해결하려 했는가: 정적 임베딩의 다의성 한계와 적은 표지 자료에서의 과제 학습
- 어떤 방식이 새로웠는가: 문맥별 층 표현 혼합과 안정적인 전체 모델 미세조정
- 결과적으로 무엇이 바뀌었는가: 언어 모델을 과제 밖에서 미리 학습해 여러 응용에 재사용하는 관행이 실증적 표준이 됐다.

## 3. 역사적 배경

Word2Vec과 GloVe는 큰 말뭉치에서 학습한 정적 단어 벡터를 여러 과제에 재사용하게 했다. 그러나 단어 유형마다 벡터 하나만 있어 다의어의 문맥별 의미를 직접 표현하지 못했다. 한편 순환 언어 모델은 문맥 의존 은닉 상태를 만들 수 있었지만, 그 전체 지식을 여러 과제에 안정적으로 옮기는 표준 절차는 확립되지 않았다. 컴퓨터 비전에서는 큰 자료의 사전 학습 모델을 새 과제에 미세조정하는 관행이 앞서 자리 잡았다. ELMo와 ULMFiT는 이 문제를 언어 모델에 각각 특징 추출과 전체 모델 적응이라는 방식으로 풀었다.

- 이전 접근법: 정적 임베딩 초기화, 과제별 순환 신경망의 무작위 초기화
- 당시의 한계: 문맥 독립 단어 표현, 표지 자료 비용, 미세조정 때의 파국적 망각
- 이 주제가 필요했던 이유: 큰 비표지 말뭉치에서 이미 배운 언어 패턴을 과제마다 되풀이해 학습하지 않기 위해서였다.

## 4. 핵심 개념 해설

### 4.1 ELMo의 층별 문맥화 표현

ELMo의 양방향 언어 모델은 순방향과 역방향 LSTM으로 각 위치의 앞뒤 문맥을 따로 부호화한다. 후속 과제는 문자 CNN 입력과 각 biLM 층의 표현을 포함한 여러 내부 상태에 과제별 스칼라 가중치를 학습하고, 전체 크기 계수와 함께 합성한다. 원 논문의 대표 설정에서는 사전 학습 biLM 매개변수를 고정한다. 따라서 ELMo의 전이는 ‘표현을 계산해 특징으로 공급하는 전이’다.

### 4.2 ULMFiT의 세 단계

ULMFiT는 WikiText-103에서 AWD-LSTM 언어 모델을 사전 학습하고, 목표 과제의 비표지 텍스트에 언어 모델 목적을 유지한 채 적응시킨 다음, concat pooling 분류기를 붙여 표지 자료로 미세조정한다. 이 세 단계는 일반 언어, 목표 영역 언어, 목표 분류 경계를 차례로 학습한다.

### 4.3 안정적 미세조정

판별적 미세조정은 층마다 다른 학습률을 쓰고, 점진적 동결 해제는 위층부터 차례로 훈련 가능하게 만든다. 기울어진 삼각형 학습률은 학습 초기에 빠르게 상승한 뒤 길게 감소한다. 세 기법은 적은 자료에서 모델 전체를 갑자기 바꿔 사전 학습 지식을 잃는 위험을 줄이는 장치다.

## 5. 원문의 논리 구조

원문은 정적 임베딩과 과제별 처음부터 학습하는 방식의 한계를 제시한다. 이어 ELMo의 문맥화 표현과 ULMFiT의 미세조정 기법을 각각 설명하고, 두 접근을 보완 관계로 묶는다. 후반에는 여러 과제의 성능 향상과 공개 모델 생태계를 영향으로 들고, LSTM의 순차 계산·자료와 계산 비용·언어 편중·표지 자료 의존을 한계로 정리한다. 마지막에는 BERT와 GPT가 이 전이 학습 원리를 확장했다고 평가한다.

1. 정적 표현과 과제별 학습의 병목을 제시한다.
2. ELMo가 문맥별 표현을 어떻게 만드는지 설명한다.
3. ULMFiT가 모델 전체를 어떻게 안정적으로 적응시키는지 설명한다.
4. 응용 성과와 자료 효율을 비교한다.
5. Transformer 시대의 유산과 과장 가능한 계보를 검토한다.

## 6. 왜 중요한가

두 연구는 언어 모델을 완성된 생성기만이 아니라 다른 과제에 지식을 공급하는 공통 기반으로 보게 했다. 특히 ELMo는 입력 단어의 초기 벡터와 문맥을 통과한 은닉 상태를 분리해 생각하게 만들었고, ULMFiT는 사전 학습 모델을 새 자료에 맞추는 과정 자체가 독립적인 최적화 문제임을 보여 주었다. 이 둘을 함께 읽으면 오늘날의 ‘사전 학습 모델 사용’이라는 말 안에 특징 추출, 전체 미세조정, 영역 적응이라는 서로 다른 선택이 들어 있음을 알 수 있다.

핵심적으로 중요한 점:

- 문맥화 표현을 정적 단어 임베딩과 구분했다.
- 일반 사전 학습과 목표 영역 적응, 과제 감독을 단계로 나눴다.
- 적은 표지 자료에서 전이 학습이 실질적인 이점을 줄 수 있음을 여러 벤치마크로 보였다.

## 7. 현대 LLM과의 연결

현대 Transformer 언어 모델은 각 토큰 위치에서 문맥 의존 은닉 상태를 만든다는 점에서 ELMo와 문제의식을 공유한다. 그러나 BERT의 masked language modeling은 ELMo의 두 독립 방향 LSTM을 단순히 attention으로 바꾼 것이 아니다. GPT 계열은 자기회귀 목적을 유지하면서 모델 전체 또는 일부를 여러 방식으로 적응시킨다는 점에서 ULMFiT와 비교할 수 있지만, 입력 변환·규모·생성 능력·후속 학습 절차가 다르다.

오늘날에도 모델을 고정해 임베딩이나 특징을 추출할지, 전 매개변수를 미세조정할지, adapter·LoRA처럼 일부만 학습할지는 핵심 선택이다. 따라서 ELMo–ULMFiT 대비는 과거 기술 비교를 넘어 현대 모델 적응 전략을 읽는 좌표가 된다.

## 8. 한계와 비판적 관점

- 기술적 한계: 두 방법 모두 LSTM의 순차 계산 비용과 긴 의존성 병목을 갖는다.
- 이론적 한계: 층별로 구문과 의미가 완전히 분리된다는 강한 해석은 실험에서 관찰된 경향보다 과하다.
- 실용적 한계: ELMo도 후속 과제 모델과 라벨이 필요하고, ULMFiT 원 논문의 주된 검증 범위는 텍스트 분류다.
- 오늘의 관점에서 다시 봐야 할 점: BERT·GPT를 두 연구의 직접 단일 후계로 쓰기보다 공통 문제, 다른 목적함수, 다른 구조를 구분해야 한다.

원문의 ‘거의 모든 후속 응용’과 ‘담화 수준 정보를 포착한다’는 표현은 과제별 결과와 분석 범위를 넘어 보편화될 수 있다. ELMo 원 논문은 여섯 과제의 개선을 보고했고, ULMFiT는 여섯 텍스트 분류 데이터셋을 중심으로 검증했다. 이 결과를 모든 언어·영역·출력 형식의 보장으로 확대하지 않는다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 문맥화 표현 | 같은 토큰도 주변 시퀀스에 따라 다른 은닉 상태를 갖는 표현 |
| 특징 추출 | 사전 학습 모델을 고정하고 그 출력을 후속 모델의 입력 특징으로 쓰는 방식 |
| 판별적 미세조정 | 층별로 서로 다른 학습률을 적용하는 방법 |
| 점진적 동결 해제 | 위층부터 아래층으로 차례로 훈련 가능 상태를 늘리는 방법 |
| 기울어진 삼각형 학습률 | 짧게 증가한 뒤 길게 감소하는 학습률 일정 |
| 영역 언어 모델 미세조정 | 목표 과제 텍스트에서 언어 모델 목적을 유지해 분포에 적응시키는 단계 |

## 12. 짧은 결론

ELMo와 ULMFiT는 2018년 자연어 처리 전이 학습의 두 상보적 경로를 제시했다. ELMo는 문맥화된 내부 표현을 고정 특징으로 제공했고, ULMFiT는 일반 사전 학습 언어 모델을 영역과 분류 과제에 단계적으로 적응시켰다. 이 차이를 보존해야 이후 BERT·GPT·현대 미세조정의 계보를 정확하게 읽을 수 있다.

# Shannon's N-gram Model 해설

## 1. 한눈에 보기

- 핵심 주제: 언어를 규칙 목록이 아니라 확률적 패턴으로 보고 다음 단어를 예측하는 n-gram 언어 모델
- 등장 배경: 1948년 섀넌의 정보 이론과 통신 공학 문제
- 가장 중요한 아이디어: 짧은 단어열의 빈도와 조건부 확률만으로도 언어의 예측 가능성을 상당 부분 설명할 수 있다는 점
- 이후 LLM/NLP에 끼친 영향: 언어 모델링, perplexity, smoothing, 기준선 평가, 다음 토큰 예측 패러다임의 출발점

## 2. 핵심 요약

섀넌의 n-gram 모델은 언어가 완전히 자유로운 단어 배열이 아니라 강한 통계적 규칙성을 가진다는 사실에서 출발한다. 특정 단어 뒤에는 어떤 단어들이 더 자주 오며, 이 빈도 차이를 이용하면 다음 글자나 단어를 예측할 수 있다. 이 접근은 언어를 명시적 문법 규칙으로 모두 설명하려는 방식과 달리, 실제 텍스트 데이터에서 패턴을 학습한다. n-gram은 단순히 연속된 n개의 언어 단위이지만, 조건부 확률과 결합하면 언어 모델이 된다. 모델은 의미를 이해하지는 못하지만 자동완성, 음성 인식, 기계 번역 같은 실제 시스템에서 오랫동안 핵심 구성 요소로 쓰였다. 동시에 긴 문맥을 보지 못하고 희소한 조합에 약하다는 한계가 있었고, 이 한계는 smoothing, distributed representation, 신경망 언어 모델로 이어지는 연구 흐름을 낳았다.

- 무엇을 다루는가: n-gram, 마르코프 가정, 조건부 확률 기반 언어 예측
- 어떤 문제를 해결하려 했는가: 언어의 예측 가능성과 정보량을 수학적으로 다루는 문제
- 어떤 방식이 새로웠는가: 규칙 기반 문법보다 데이터에서 관찰되는 빈도와 확률을 우선한 점
- 결과적으로 무엇이 바뀌었는가: 자연어 처리가 통계적 학습과 언어 모델링 중심으로 이동하는 길이 열렸다

## 3. 역사적 배경

1940년대의 핵심 문제는 오늘날의 챗봇이나 검색 품질이 아니라, 잡음이 있는 통신 채널에서 메시지를 어떻게 효율적으로 보내고 복원할 것인가였다. 섀넌은 정보량, 엔트로피, 중복성 같은 개념을 통해 통신을 수학적으로 다루는 틀을 만들었다. 이때 영어 텍스트는 정보 이론을 설명하기 좋은 사례였고, 그 분석 과정에서 언어가 예측 가능한 통계 구조를 가진다는 점이 드러났다.

- 이전 접근법: 문법 규칙, 논리, 기호적 설명을 중심으로 언어를 이해하려는 관점
- 당시의 한계: 실제 언어 사용의 빈도, 중복성, 불확실성을 정량적으로 다루기 어려웠다
- 이 주제가 필요했던 이유: 통신 효율과 오류 처리를 설명하려면 메시지의 예측 가능성과 정보량을 측정해야 했다

## 4. 핵심 개념 해설

### 4.1 N-gram

n-gram은 텍스트에서 연속으로 등장하는 n개의 항목이다. 단어 단위로 보면 unigram은 한 단어, bigram은 두 단어, trigram은 세 단어다. 중요한 점은 n-gram이 문장의 전체 의미를 이해하려는 구조가 아니라, 가까이 붙어 있는 단어들의 국소 패턴을 세는 구조라는 것이다.

### 4.2 마르코프 가정과 조건부 확률

마르코프 가정은 다음 단어의 확률을 전체 과거가 아니라 바로 앞의 제한된 문맥으로 근사한다. 예를 들어 trigram 모델은 앞의 두 단어만 보고 다음 단어의 확률을 추정한다. 이 가정은 현실 언어를 단순화하지만, 계산을 가능하게 만들고 실제 데이터에서 확률표를 만들 수 있게 해 준다.

### 4.3 데이터 희소성과 Smoothing

n이 커질수록 가능한 n-gram 수는 폭발적으로 늘어난다. 그래서 학습 데이터에 나타나지 않은 조합이 실제 사용 중 자주 생긴다. smoothing은 이런 미관측 사건에 0이 아닌 확률을 부여하는 기법이며, Katz back-off는 보지 못한 긴 n-gram 대신 더 짧은 문맥으로 물러나는 대표적 방식이다.

## 5. 원문의 논리 구조

원문은 대체로 다음 흐름으로 전개된다.

1. 섀넌의 1948년 정보 이론 연구가 언어의 통계적 성격을 드러냈다는 문제 제기
2. n-gram이 무엇이며 왜 단순한 구조만으로 예측에 쓸 수 있는지 설명
3. n-gram 모델이 마르코프 가정과 조건부 확률로 작동하는 방식 정리
4. 데이터 희소성 문제와 Katz back-off, Good-Turing, Kneser-Ney 같은 smoothing 기법 소개
5. n-gram의 한계가 신경망, 분산 표현, 트랜스포머로 이어지는 연구 흐름을 만들었다는 결론

## 6. 왜 중요한가

n-gram 모델은 현대 LLM에 비하면 매우 단순하지만, 자연어 처리의 중심 질문을 처음으로 실용적인 형태로 제시했다. "앞의 문맥이 주어졌을 때 다음 단어는 무엇일 가능성이 높은가?"라는 질문은 오늘날의 autoregressive language model에서도 그대로 유지된다. 차이는 문맥 표현 방식과 확률 추정 장치가 빈도표에서 거대한 신경망으로 바뀌었다는 데 있다.

특히 중요한 점은 다음과 같다.

- 언어를 데이터 기반 확률 모델로 다룰 수 있음을 보여 주었다
- 언어 모델 평가의 정보 이론적 기반, 특히 entropy와 perplexity의 뿌리를 제공했다
- 데이터 희소성, 문맥 길이, 일반화라는 NLP의 오래된 난제를 선명하게 드러냈다

## 7. 현대 LLM과의 연결

n-gram 모델과 대규모 언어 모델은 규모와 메커니즘이 다르지만, 다음 항목을 예측한다는 문제 설정을 공유한다. n-gram은 짧은 표면 문맥을 기준으로 확률을 추정하고, LLM은 긴 문맥을 신경망 내부 표현과 attention으로 압축해 다음 토큰 분포를 계산한다. 이 때문에 n-gram은 LLM을 이해하기 위한 역사적 출발점이자 대비 기준이 된다.

- 다음 토큰 예측: GPT 계열 모델은 n-gram보다 훨씬 긴 문맥과 풍부한 표현을 쓰지만, 조건부 확률 분포를 예측한다는 틀을 이어받았다
- 표현 학습: n-gram은 단어를 서로 독립적인 표면 토큰으로 보지만, word2vec, GloVe, transformer는 의미적 유사성을 벡터 공간에 반영한다
- 평가와 기준선: perplexity와 n-gram baseline은 새로운 언어 모델이 실제로 얼마나 개선되었는지 비교하는 기준으로 남아 있다

## 8. 한계와 비판적 관점

n-gram은 실용적이고 해석 가능하지만, 언어 이해 모델로 보기에는 한계가 뚜렷하다. 특히 짧은 문맥 안에 들어오지 않는 정보는 사용할 수 없고, 단어 간 의미 관계도 직접 표현하지 못한다. 이 한계는 단순한 구현 문제라기보다 모델의 표현 방식 자체에서 비롯된다.

- 기술적 한계: 가능한 n-gram 수가 지수적으로 증가하고, 미관측 조합에 취약하다
- 이론적 한계: 의미, 지시 관계, 담화 구조, 장거리 의존성을 표면 빈도만으로 충분히 설명하지 못한다
- 실용적 한계: 큰 n-gram 확률표는 저장과 유지 비용이 커지며, 도메인이 바뀌면 성능이 쉽게 흔들릴 수 있다
- 오늘의 관점에서 다시 볼 점: LLM도 더 복잡한 방식으로 같은 예측 문제를 풀지만, 희소성, 일반화, 문맥 활용이라는 긴장은 여전히 남아 있다

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| n-gram | 텍스트에서 연속된 n개의 언어 단위. 단어, 문자, 음절 등이 단위가 될 수 있다. |
| unigram | 하나의 단어 또는 항목만 보는 1-gram. |
| bigram | 연속된 두 단어 또는 항목을 보는 2-gram. |
| trigram | 연속된 세 단어 또는 항목을 보는 3-gram. |
| 마르코프 가정 | 다음 상태 또는 단어가 전체 과거가 아니라 제한된 최근 문맥에만 의존한다고 보는 근사. |
| 조건부 확률 | 어떤 조건이 주어졌을 때 특정 사건이 일어날 확률. 언어 모델에서는 앞 문맥이 주어졌을 때 다음 단어의 확률을 뜻한다. |
| 엔트로피 | 불확실성 또는 평균 정보량을 나타내는 정보 이론의 핵심 개념. |
| 데이터 희소성 | 가능한 조합은 많지만 실제 데이터에서 관찰되는 조합은 적어 확률 추정이 어려워지는 문제. |
| smoothing | 관찰되지 않은 사건에도 합리적인 확률을 부여하도록 확률 추정치를 조정하는 기법. |
| Katz back-off | 긴 n-gram을 보지 못했을 때 더 짧은 n-gram 문맥으로 물러나 확률을 추정하는 smoothing 계열 기법. |
| perplexity | 언어 모델이 다음 토큰을 얼마나 잘 예측하는지 평가하는 지표. 낮을수록 모델의 예측이 더 확신 있다는 뜻이다. |

## 12. 짧은 결론

섀넌의 n-gram 모델은 현대 LLM의 직접적인 기술 형태는 아니지만, 언어를 확률적으로 예측할 수 있는 대상으로 바라보게 만든 출발점이다. 이 모델은 단순한 빈도 계산만으로도 실제 언어 기술을 만들 수 있음을 보여 주었고, 동시에 문맥 길이, 희소성, 의미 표현이라는 한계를 드러냈다. 바로 그 한계가 이후 통계적 NLP, 신경망 언어 모델, 트랜스포머로 이어지는 긴 연구 흐름의 동력이 되었다.

# Google 신경망 기계 번역 해설

## 1. 한눈에 보기

이 글은 2016년 GNMT를 구 기반 통계 번역에서 종단 간 신경 번역으로의 제품 전환으로 설명한다. 큰 방향은 맞지만 실제 시스템은 단순한 LSTM 인코더-디코더가 아니다. 8층 인코더와 8층 디코더, bottom encoder의 양방향 층, 한 어텐션 모듈, 잔차 연결, WordPiece, 모델 병렬화, 저정밀 추론, beam-search 길이 정규화와 coverage penalty를 결합했다. 또한 논문의 “평균 60% 오류 감소”는 일부 언어쌍의 고립된 단순 문장에 대한 인간 side-by-side 평가이며, 모든 언어·문서·사용 상황에서 사람 번역에 근접했다는 보편 결론이 아니다.

## 2. 핵심 요약

- GNMT 기술 보고서는 2016년 9월 공개되었다.
- 기본 모델은 8개 LSTM 인코더 층과 8개 LSTM 디코더 층, 어텐션, 잔차 연결을 사용했다.
- 인코더 첫 층은 양방향이고 위의 층은 단방향으로 쌓였다. 잔차 연결은 깊은 LSTM 스택의 최적화를 도왔다.
- 어텐션은 최상위 인코더 출력과 최하위 디코더 층을 연결해 decoder layer의 병렬 계산을 늘리는 시스템 선택이었다.
- WordPiece는 희귀어를 유한한 subword sequence로 표현했지만 새 용어의 정확한 의미 번역을 보장하지 않는다.
- 동기식 데이터 병렬 훈련과 모델 병렬화를 함께 사용했고, 12 GPU 세대의 replica를 여러 사본으로 운영했다.
- 추론은 8-bit matrix multiplication을 사용해 속도를 높였고, TPU 배포는 당시 공식 제품 설명에 포함되었다.
- beam search에는 length normalization과 coverage penalty가 들어가 짧은 번역 선호와 원문 누락을 완화했다.
- WMT14 영어→프랑스어·영어→독일어에서는 당시 최첨단과 경쟁력 있는 결과를 보고했지 모든 비교에서 압도한 것은 아니다.
- production phrase-based system 대비 평균 약 60% 번역 오류 감소는 사람 평가 점수의 `6-score`를 오류로 바꾼 특정 계산이다.
- 2016년 9월 공식 배포 발표는 중국어→영어 100%, 하루 약 1,800만 번역을 명시했다. 모든 103개 언어의 즉시 전환은 아니었다.
- GNMT는 Transformer의 직접 원인이 하나뿐인 것은 아니며, Transformer는 더 넓은 어텐션·seq2seq 연구를 바탕으로 순환을 제거했다.

## 3. 역사적 배경

GNMT 이전에 신경 번역은 이미 빠르게 발전하고 있었다. 2013년 recurrent continuous translation model, 2014년 Sutskever 등의 4층 LSTM seq2seq, Cho 등의 RNN Encoder–Decoder, 2014년 공개·2015년 발표된 Bahdanau 어텐션, 2015년 Luong 어텐션과 희귀어 복사 연구가 선행했다. 2016년 GNMT의 의의는 신경 번역을 발명한 데 있지 않고, 깊은 구조·서브워드·탐색·분산 훈련·저지연 추론을 하나의 제품 규모 시스템으로 통합한 데 있다.

구 기반 SMT도 “각 구를 완전히 독립 번역한 뒤 수동 규칙으로 재배열”하는 단순 시스템은 아니다. 병렬 자료에서 구 대응과 재배열 점수를 추정하고, 언어 모형·어휘 가중·여러 특징을 로그선형으로 결합하며 beam search를 사용했다. NMT는 이 모듈 상당 부분을 하나의 조건부 신경 모델로 묶었지만 데이터 정제·토큰화·탐색·평가·서빙이라는 공학을 없애지는 않았다.

## 4. 핵심 개념 해설

GNMT는 원문 $x$를 인코더 상태로 바꾸고, 번역문 $y$의 조건부 확률을 자기회귀적으로 분해한다.

$$
p(y\mid x)=\prod_{t=1}^{T}p(y_t\mid y_{<t},x)
$$

각 디코딩 시점에서 어텐션은 최상위 인코더 상태에 점수를 주고 정규화한 가중 합을 문맥 벡터로 만든다. GNMT는 하나의 어텐션 모듈을 사용하고 최하위 디코더 층과 연결했다. “모든 decoder layer마다 독립 어텐션”이나 “문장 전체를 하나의 고정 벡터로만 전달”하는 구조가 아니다.

WordPiece는 단어를 빈번한 subword로 분해한다. 희귀 문자열을 UNK 하나로 잃는 대신 여러 조각으로 부호화할 수 있지만, 조각 sequence가 길어지고 형태소 경계와 일치하지 않을 수 있다.

beam search의 원시 로그 가능도는 짧은 출력을 선호하기 쉽다. GNMT는 길이 정규화 $lp(Y)$와 coverage penalty $cp(X;Y)$를 결합해 후보 점수를 조정했다. coverage는 원문 위치별 어텐션 누적이 부족한 번역에 벌점을 주려는 휴리스틱이지 의미 보존을 증명하는 제약은 아니다.

## 5. 원문의 논리 구조

원문은 다음 순서로 서술한다.

1. 구 기반 SMT가 유창성·장거리 문맥·희귀어·특징 공학에서 한계에 이르렀다고 제시한다.
2. LSTM 인코더-디코더와 어텐션을 종단 간 대안으로 소개한다.
3. 대규모 병렬 자료와 제품 서빙 인프라가 연구 모델을 실제 서비스로 만들었다고 설명한다.
4. 번역의 유창성·문맥성·희귀어 처리와 대규모 배포를 영향으로 든다.
5. 계산비·대량 병렬 자료·유창하지만 틀린 출력·블랙박스·전문 용어를 한계로 든다.
6. GNMT 어텐션에서 Transformer·BERT·GPT와 인공지능 전반으로 이어지는 유산을 주장한다.

이 구조는 제품 전환의 의미를 이해하기 좋지만 GNMT 논문이 실제로 측정한 언어쌍·문장 유형·지표와 가능한 일반 효과를 분리해야 한다.

## 6. 왜 중요한가

GNMT의 핵심 가치는 단일 모델 아이디어보다 시스템 통합에 있다. 깊은 LSTM을 residual path로 훈련하고, 큰 어휘를 WordPiece로 제한하며, 여러 GPU에 모델·자료를 나눠 훈련하고, 저정밀 추론과 보정된 beam search로 제품 latency를 맞췄다. 연구 BLEU 하나가 아니라 품질·속도·메모리·배포를 함께 최적화한 사례다.

또한 GNMT는 “종단 간”의 실제 경계를 보여 준다. 번역 확률은 하나의 신경 목적에서 학습하지만 WordPiece 어휘, layer 수, attention 위치, parallelism, beam-search penalty, human evaluation은 사람이 설계한다. 종단 간 학습은 공학의 제거가 아니라 학습 가능한 부분과 시스템 경계의 재배치다.

## 7. 현대 LLM과의 연결

GNMT와 현대 LLM은 subword token, 자기회귀 조건부 생성, attention, 대규모 분산 훈련, beam 또는 다른 decoding이라는 구성 요소 일부를 공유한다. 그러나 GNMT는 원문과 번역문을 분리한 encoder-decoder 번역 시스템이고, GPT 계열은 주로 decoder-only 사전학습 모델이다. BERT는 번역 decoder가 아니라 masked encoder다.

2017년 Transformer는 NMT를 주된 실험장으로 삼고 attention만으로 encoder-decoder를 구성했다. GNMT가 어텐션의 제품 규모 유용성을 보여 준 것은 역사적으로 중요하지만, Transformer의 attention은 Bahdanau·Luong 등의 더 넓은 연구 계보와 병렬 계산 동기에서 나왔다. “GNMT의 어텐션이 Transformer를 직접 발명했다”는 단일 계보는 과장이다.

현대 번역은 문장 단위 GNMT를 넘어 document context, multilingual transfer, monolingual back-translation, pretrained seq2seq를 활용한다. 따라서 2016년 GNMT 성능을 현재 번역·LLM 품질과 같은 조건으로 비교할 수 없다.

## 8. 한계와 비판적 관점

첫째, raw는 구 기반 SMT가 20년 동안 각 구를 독립 처리해 문법적으로만 맞았다고 단순화한다. 실제 phrase-based decoder는 언어 모형, 재배열, lexical weighting, 여러 특징을 문장 수준 탐색에서 함께 사용했다.

둘째, GNMT가 모든 언어쌍을 즉시 대체했다는 서술은 틀리다. 2016년 9월 제품 발표가 명시한 첫 100% 전환은 중국어→영어였고, 103개 언어로 확장하는 일은 별도 난제였다.

셋째, 평균 약 60% 오류 감소는 고립된 단순 문장을 bilingual human rater가 0–6으로 평가한 결과다. 논문은 긴 문장·희귀어에서 품질이 떨어지고 공통 단어를 생략하는 오류가 남는다고 분석했다.

넷째, WordPiece는 OOV 문자열 부호화를 개선하지만 용어 번역을 자동 해결하지 않는다. `microcytic`을 여러 조각으로 쓸 수 있어도 의학적 번역을 올바르게 아는 것은 별도 문제다.

다섯째, 통계 시스템이 유창하지만 사실과 다른 번역을 거의 만들지 않는다는 raw의 대조도 과도하다. SMT와 NMT 모두 원문 누락·삽입·오역을 만들 수 있으며 오류 유형과 빈도는 데이터와 시스템에 따라 다르다.

여섯째, “고정 크기 표현이 긴 문장의 병목”이라는 한계는 어텐션 없는 초기 seq2seq 설명에는 맞지만 GNMT 자체는 위치별 인코더 상태에 어텐션으로 접근한다. GNMT의 긴 문장 문제를 고정 벡터 하나로 설명하면 구조가 섞인다.

## 9. 용어 정리

- **GNMT**: 2016년 Google이 공개한 8층 attention LSTM 기반 신경 번역 시스템.
- **구 기반 SMT**: 병렬 자료에서 문자열 구 대응을 추출하고 여러 특징을 로그선형 점수와 탐색으로 결합하는 통계 번역.
- **종단 간 NMT**: 원문에서 목표 토큰 가능도까지 하나의 신경 목적을 학습하는 번역 접근.
- **WordPiece**: 유한 subword 어휘로 입력·출력 문자열을 분절하는 방식.
- **잔차 연결**: 깊은 층의 변환 출력에 identity path를 더해 최적화를 돕는 연결.
- **모델 병렬화**: 한 모델의 서로 다른 층·연산을 여러 장치에 나누는 방식.
- **데이터 병렬화**: 모델 replica가 서로 다른 mini-batch를 처리하고 gradient를 결합하는 방식.
- **길이 정규화**: beam-search 후보의 길이 편향을 줄이도록 로그 점수를 조정하는 규칙.
- **coverage penalty**: 원문 위치에 충분한 어텐션이 누적되지 않은 후보를 벌점 주는 탐색 항.
- **side-by-side 평가**: 사람이 같은 원문에 대한 여러 번역을 나란히 비교·평정하는 평가.

## 12. 짧은 결론

GNMT는 신경 번역을 처음 발명한 시스템이 아니라, 어텐션 LSTM·잔차 연결·WordPiece·분산 훈련·저정밀 추론·탐색 보정을 제품 규모에 통합한 이정표다. 그 성과는 특정 언어쌍과 평가 조건에서 통계적 생산 시스템보다 큰 개선을 보였다는 데 있다. 이를 모든 언어의 즉시 전환이나 사람 번역에 가까운 보편적 이해로 넓히지 않을 때, GNMT는 연구 구조와 서빙 공학이 함께 만들어 낸 전환으로 더 정확히 읽힌다.

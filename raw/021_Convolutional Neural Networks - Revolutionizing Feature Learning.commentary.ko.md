# 합성곱 신경망과 특징 학습 해설

## 1. 한눈에 보기

- 핵심 주제: 이미지의 가까운 픽셀끼리 먼저 살피고 같은 특징 검출기를 여러 위치에서 재사용하도록 설계한 합성곱 신경망(Convolutional Neural Network, CNN)
- 등장 배경: 완전 연결망으로 이미지를 처리할 때 생기는 막대한 매개변수를 줄이고, 완전 연결망이 구조적으로 강제하지 않는 국소성과 위치별 가중치 공유를 손글씨 인식에 맞는 가정으로 넣으려는 연구
- 가장 중요한 아이디어: 국소 연결, 가중치 공유, 계층적 특징 학습을 결합해 데이터가 가진 공간적 규칙성을 활용하는 것
- 역사적 경계: 1980년 네오코그니트론, 1987년 TDNN, 1989년 르쿤 등의 손글씨 우편번호 연구가 이어진 누적 역사이며, “1988년 한 사람이 CNN을 단독 발명했다”라고 압축하면 선행 연구와 공개 연도를 놓치게 된다.
- LLM/NLP와의 관계: 텍스트 CNN과 문자 단위 CNN은 합성곱을 언어에 직접 적용한 계보이지만, Word2Vec·GloVe·LSTM 기반 seq2seq·어텐션·Transformer는 각각 다른 핵심 연산과 연구 문제에서 나온 별도 계보다.

> 이 문서는 021 번역문을 이해하기 위한 해설입니다. 원문의 교육적 설명은 살리되, 1988년이라는 연대, 합성곱의 수학적 명칭, 이동 등변성과 불변성, 그리고 현대 LLM으로 이어지는 계보를 1차 문헌에 맞춰 구분합니다.

## 2. 핵심 요약

CNN의 힘은 단순히 “깊은 신경망”이라는 데 있지 않다. 이미지처럼 가까운 위치끼리 강하게 관련되고 같은 패턴이 여러 곳에 반복되는 데이터에 맞춰 연결 구조를 제한한 데 핵심이 있다. 작은 커널이 국소 영역을 훑고, 같은 커널의 가중치를 모든 위치에서 공유하므로 완전 연결층보다 훨씬 적은 매개변수로 패턴을 찾을 수 있다. 층을 쌓으면 각 층의 유효 수용 영역이 넓어져 국소 특징을 더 큰 구조로 조합할 수 있다.

다만 보통 딥러닝 라이브러리가 “합성곱”이라고 부르는 연산은 커널을 뒤집지 않는 교차상관(cross-correlation)이다. 학습되는 커널이라는 조건에서는 두 연산의 표현 능력이 사실상 같지만, 수학적 명칭은 구분하는 편이 정확하다. 또한 가중치 공유가 주는 기본 성질은 입력이 이동하면 특징 맵도 함께 이동하는 **이동 등변성**이다. 최종 출력이 이동해도 같게 유지되는 **이동 불변성**과는 다르다. 풀링은 작은 위치 변화에 대한 허용도를 높이고 해상도를 줄일 수 있지만, 완전한 불변성을 자동으로 보장하지 않는다.

역사도 한 날짜로 환원하기 어렵다. 후쿠시마의 네오코그니트론은 1980년에 국소 수용 영역과 계층적 위치 강건성을 제시했고, 와이벨 등의 TDNN은 1987년부터 시간축 가중치 공유와 역전파를 사용했다. 르쿤은 1988년 AT&T 벨 연구소에 합류해 손글씨 인식에 합성곱망을 적용했지만, 널리 인용되는 우편번호 논문은 1989년에 출판됐다. 흔히 교과서에 등장하는 LeNet-5는 1998년 논문에 실린 모델이다.

정리하면 다음 네 문장이 핵심이다.

1. CNN은 데이터의 공간적 규칙성을 아키텍처에 넣은 신경망이다.
2. 합성곱층의 기본 성질은 불변성이 아니라 등변성이다.
3. CNN의 역사는 네오코그니트론·TDNN·르쿤 연구가 이어진 누적 과정이다.
4. 텍스트 CNN은 직접적인 응용이지만 Transformer의 어텐션을 CNN의 발전형으로 보는 것은 계보를 지나치게 단순화한다.

원문의 “1988년 르쿤이 벨 연구소에서 CNN을 도입했다”는 문장은 연구 경력의 출발점을 짧게 요약한 표현으로는 이해할 수 있다. 그러나 학술사로 읽을 때는 세 가지를 분리해야 한다. 첫째, 계층적 국소 처리에는 네오코그니트론이라는 선행 연구가 있었다. 둘째, 시간축 공유 가중치와 역전파에는 TDNN이라는 가까운 선행 사례가 있었다. 셋째, 벨 연구소의 대표적인 우편번호 논문은 1988년이 아니라 1989년에 공개됐다. CNN은 한순간의 단독 발명이라기보다 여러 아이디어가 결합되고 실용화된 계보다.

## 4. 핵심 개념 해설

### 4.1 국소 연결과 가중치 공유

완전 연결층은 입력의 모든 값과 출력의 모든 값을 연결한다. 256×256 흑백 이미지를 1,000개 은닉 유닛에 연결하면 가중치만 약 6,554만 개가 필요하다. 반면 합성곱층은 작은 창 안의 값만 보고, 같은 커널을 이미지 전체 위치에서 반복 사용한다. 이는 “가까운 픽셀이 먼저 상호작용하고, 같은 무늬는 어디에 있든 같은 방식으로 찾을 수 있다”라는 귀납 편향(inductive bias)을 넣는 것이다.

단, 실제 3×3 합성곱층의 매개변수가 언제나 아홉 개인 것은 아니다. 입력 채널 수를 `C_in`, 출력 채널 수를 `C_out`이라 하면 기본 가중치 수는 `3×3×C_in×C_out`이고, 보통 출력 채널별 편향도 더한다. “3×3 필터는 아홉 개의 가중치”라는 설명은 입력 채널과 출력 필터 하나만 가정한 입문용 단순화다.

층이 깊어지면 뒤쪽 유닛 하나가 간접적으로 바라보는 입력 영역, 즉 유효 수용 영역이 넓어진다. 그래서 국소 선분이나 질감이 더 큰 모양의 단서로 조합될 수 있다. 흔히 말하는 “모서리→부분→사물”은 유용한 직관이지만, 모든 CNN의 모든 채널이 이런 인간 친화적 단계로 깔끔하게 해석된다는 보장은 없다.

### 4.2 합성곱과 교차상관

원문에 제시된 연산을 채널까지 포함해 쓰면 대략 다음과 같다.

`Y[i,j,o] = b[o] + Σ_c Σ_u Σ_v W[o,c,u,v] X[c,i+u,j+v]`

여기서는 커널 `W`의 인덱스를 뒤집지 않는다. 따라서 엄밀한 수학 용어로는 **이산 교차상관**이다. 진짜 이산 합성곱은 커널 방향을 뒤집어 `W[o,c,-u,-v]`에 대응하는 값을 사용한다. PyTorch의 `Conv2d` 문서도 실제 연산을 2차원 교차상관이라고 명시한다.

그런데 신경망의 커널은 사람이 미리 정한 필터가 아니라 학습되는 값이다. 뒤집힌 커널이 필요하면 학습 과정이 그 값을 그대로 배울 수 있으므로, 두 정의는 모델의 표현 능력에서 본질적인 차이를 만들지 않는다. 그래서 관례적으로 층 이름은 계속 “합성곱층”이라고 부른다. 원문의 공식은 계산 절차로는 맞지만, 신호 처리의 엄밀한 합성곱이라고 설명할 때는 이 명칭 차이를 밝혀야 한다.

### 4.3 등변성, 불변성, 풀링

입력을 오른쪽으로 옮겼을 때 특징 맵도 같은 만큼 오른쪽으로 옮겨진다면 그 연산은 이동 **등변적**이다. 기호로는 `f(Tx)=T f(x)`와 같이 쓸 수 있다. 반대로 입력을 옮겨도 분류 결과가 같다면 이동 **불변적**이며 `g(Tx)=g(x)`에 해당한다. 보폭 1의 합성곱은 경계 처리 같은 조건을 제외하면 이동 등변성을 갖는다. 가중치 공유만으로 분류 출력 전체가 불변이 되는 것은 아니다.

최대 풀링이나 평균 풀링은 작은 영역을 하나의 값으로 줄여 미세한 위치 차이에 덜 민감하게 만들고 계산량과 해상도를 낮춘다. 그러나 보폭을 둔 다운샘플링은 입력 이동과 샘플 격자가 어긋날 때 오히려 정확한 등변성을 깨뜨릴 수 있다. 현대 CNN이 작은 이동에도 출력이 크게 달라질 수 있다는 실험 결과도 있다. 전역 평균 풀링, 적절한 안티앨리어싱, 데이터 증강, 과제에 맞는 학습 등이 결합돼야 더 넓은 범위의 이동 불변성에 가까워질 수 있다. 풀링은 유용한 설계 요소이지, 이동·회전·크기 변화에 대한 보편적 불변성이나 과적합 방지를 자동 보장하는 장치는 아니다.

## 5. 원문의 논리 구조

원문은 다음 순서로 독자를 이끈다.

1. **역사적 장면 제시**: 1988년 벨 연구소와 손글씨 인식 문제를 CNN의 출발점으로 소개한다.
2. **완전 연결망과 대비**: 평탄화된 픽셀 인덱스에 위치 정보는 남아 있어도 국소성과 위치 공유가 구조적으로 강제되지 않고 매개변수가 폭증하는 문제를 설명한다.
3. **핵심 연산 해설**: 국소 수용 영역, 작은 필터, 가중치 공유, 특징 맵을 통해 합성곱층의 작동을 보여 준다.
4. **풀링과 계층화 설명**: 해상도를 줄이면서 국소 특징을 점차 더 추상적인 표현으로 결합한다고 설명한다.
5. **영향과 계보 확장**: 자동 특징 학습의 중요성을 강조하고 텍스트 CNN, 단어 임베딩, seq2seq, 어텐션, Transformer까지 연결한다.

이 흐름은 입문자가 “왜 필요한가→어떻게 작동하는가→무엇에 영향을 주었는가”를 따라가기에는 좋다. 다만 첫 단계는 네오코그니트론과 TDNN을 생략해 발명을 한 사람과 한 해에 집중시키고, 마지막 단계는 “신경망이 표현을 학습한다”는 공통점을 직접 기술 계보처럼 넓힌다. 따라서 가운데의 아키텍처 설명은 유용한 입문 틀로 읽되, 역사와 NLP 계보는 별도로 교정해 읽어야 한다.

## 6. 왜 중요한가

CNN이 남긴 가장 큰 교훈은 데이터의 구조를 무시한 범용 연결보다 **과제에 맞는 구조적 제약**이 학습을 더 효율적으로 만들 수 있다는 점이다. 이미지의 국소성과 위치 반복성을 반영하자 매개변수를 크게 줄이면서도 같은 특징 검출기를 여러 곳에서 재사용할 수 있었다. 이는 계산 효율뿐 아니라 제한된 데이터에서 유용한 규칙을 배우게 하는 귀납 편향이 됐다.

두 번째 의미는 특징 추출기와 분류기를 함께 학습하는 표현 학습의 실용성을 보여 준 데 있다. 이전 방식에서 사람이 설계하던 특징의 상당 부분을 데이터와 목적 함수로부터 학습할 수 있게 됐다. 그렇다고 특징 공학이 완전히 사라진 것은 아니다. 입력 정규화, 데이터 수집, 증강, 커널 크기, 보폭, 패딩, 네트워크 깊이 같은 선택에는 여전히 사람의 설계와 과제 지식이 들어간다. 1989년 논문도 “정규화된” 문자 이미지를 입력으로 삼았다.

세 번째 의미는 계층적으로 쌓인 국소 연산이 큰 구조를 다룰 수 있다는 사실을 널리 입증한 데 있다. 이 원리는 이미지뿐 아니라 음성, 오디오, 시계열, 문장과 문자 열에도 직접 재사용됐다. CNN의 중요성을 정확히 평가하는 방법은 모든 현대 신경망의 단일 조상으로 부르는 것이 아니라, **공유된 국소 연산과 학습된 표현을 실용적 규모로 정착시킨 핵심 계보**로 보는 것이다.

## 7. 현대 LLM과의 연결

CNN과 현대 언어 모델의 관계는 “직접 사용”과 “넓은 지적 영향”, “별도 계보”로 나누면 명확해진다.

| 기술 | 핵심 방식 | CNN과의 관계 |
| --- | --- | --- |
| 텍스트 CNN | 단어 임베딩 열에 1차원 필터를 적용해 n-그램과 비슷한 국소 패턴을 찾고 풀링으로 문장 표현을 만든다. | **직접 응용**. Collobert·Weston(2008)의 통합 NLP 합성곱망과 Kim(2014)의 문장 분류 CNN이 대표적이다. |
| 문자 단위 CNN | 원시 문자 열에 시간 합성곱과 풀링을 적용해 단어 사전 없이 텍스트 분류 특징을 학습한다. | **직접 응용**. Zhang·Zhao·LeCun(2015)이 대규모 문자 단위 분류를 실험했다. |
| Word2Vec | CBOW 또는 Skip-gram의 예측 과제로 단어 벡터를 학습한다. | **별도 계보**. 분산 표현 학습이라는 넓은 목표는 공유하지만 합성곱층에서 파생된 모델은 아니다. |
| GloVe | 말뭉치 전체의 단어 동시 출현 통계를 목적 함수에 반영해 벡터를 학습한다. | **별도 계보**. CNN의 국소 필터나 풀링이 핵심 연산이 아니다. |
| seq2seq | 한 LSTM이 입력 열을 고정 길이 벡터로 인코딩하고 다른 LSTM이 출력 열을 디코딩한다. | **순환망 계보**. 대표적인 2014년 모델은 CNN이 아니라 다층 LSTM을 사용했다. |
| 초기 신경망 어텐션 | 디코딩 시점마다 관련 있는 입력 위치를 내용 기반으로 가중합한다. | **RNN 인코더-디코더의 병목을 보완한 계보**. 위치마다 같은 국소 커널을 적용하는 CNN과 작동 원리가 다르다. |
| Transformer | 쿼리·키·값의 관계로 전역 self-attention을 계산하고 위치별 피드포워드층을 쌓는다. | **직계 후손이 아님**. 2017년 논문은 순환과 합성곱을 모두 제거한다고 명시한다. |

현대 LLM의 토큰 임베딩과 Transformer를 CNN에서 곧바로 유도할 수는 없다. Word2Vec과 GloVe는 정적 단어 표현의 별도 흐름이고, seq2seq와 초기 어텐션은 주로 RNN·LSTM 번역 모델의 흐름이며, Transformer는 self-attention으로 그 구조를 다시 설계했다. Transformer의 위치별 피드포워드층을 커널 크기 1의 합성곱과 수학적으로 같다고 표현할 수는 있지만, 이 사실이 어텐션 자체를 CNN의 발전형으로 만들지는 않는다.

그럼에도 간접 연결은 있다. CNN은 원시 입력에서 유용한 표현을 종단 간 학습하고, 같은 연산을 여러 위치에 재사용하며, 여러 층을 쌓아 추상화를 만드는 설계 문화를 강하게 정착시켰다. 현대 LLM도 표현 학습과 매개변수 공유를 사용한다. 다만 이것은 신경망 전반의 공통 설계 원리라는 수준의 연결이지, “CNN이 어텐션을 낳았다”는 직접 계보 주장은 아니다.

## 8. 한계와 비판적 관점

### 8.1 역사 서술의 한계

- **1988년 단독 발명**: 1988년은 르쿤이 벨 연구소에 합류해 적용 연구를 시작한 시점으로 설명할 수 있지만, 대표 우편번호 논문은 1989년 출판물이다. 네오코그니트론과 TDNN의 선행도 함께 봐야 한다.
- **Bell Labs와 연도**: 1989년 논문의 저자 소속이 AT&T Bell Laboratories였다는 사실과 논문 공개 연도는 분리해 기록해야 한다.
- **LeNet-5의 시기**: LeNet 계열의 초기 실험과 1998년에 문서화된 LeNet-5를 같은 모델처럼 다루면 안 된다. “원래 1988년 CNN이 3~4개 합성곱층이었다”와 같은 세부 수치는 특정 1차 자료 없이 단정하기 어렵다.
- **누적 발명**: CNN의 국소성·계층성·가중치 공유·역전파 학습은 여러 연구가 차례로 결합한 결과다. 한 사람의 기여를 낮출 필요는 없지만 선행 연구를 지우는 방식으로 강조해서도 안 된다.

### 8.2 기술 설명의 한계

- 원문의 공식은 엄밀히 교차상관이며, 커널 반전이 있는 수학적 합성곱과 구분해야 한다.
- 가중치 공유는 이동 등변성을 주는 핵심 장치이지 완전한 이동 불변성의 보증서가 아니다.
- 풀링은 국소 허용도와 다운샘플링을 제공하지만 공간 세부를 버리고, 보폭 때문에 작은 이동에 민감해질 수도 있다. 과적합 방지도 필연적 결과가 아니다.
- CNN이 손으로 만든 특징을 크게 줄였다는 평가는 타당하지만, 전처리·정규화·데이터 설계·아키텍처 선택까지 없앤 것은 아니다.
- 깊은 층의 특징을 “모서리, 부분, 사물”로 설명하는 것은 이해를 돕는 전형적 패턴이지 모든 채널에 대한 보편적 해석 법칙이 아니다.
- 국소 커널은 가까운 패턴에 강하지만 먼 위치의 관계를 직접 연결하려면 층을 많이 쌓거나 팽창 합성곱, 전역 연산 같은 보완이 필요하다. 회전·크기 변화에 대한 불변성도 기본 CNN이 자동으로 제공하지 않는다.
- 초기 CNN이 얕았던 데에는 계산 자원, 데이터, 최적화 도구의 제약이 함께 작용했다. 기울기 소실만을 단일 원인으로 제시하면 당시의 공학적 조건을 지나치게 단순화한다.

### 8.3 1차 문헌으로 확인한 경계

- [Fukushima, “Neocognitron” (1980)](https://www.cs.princeton.edu/courses/archive/spring08/cos598B/Readings/Fukushima1980.pdf): 계층적 국소 수용 영역과 위치 이동에 강건한 패턴 인식이라는 선행 아이디어를 확인할 수 있다.
- [Waibel et al., “Phoneme Recognition Using Time-Delay Neural Networks” (1989)](https://doi.org/10.1109/29.21701): 시간축 공유 연결과 역전파를 사용한 TDNN의 학술지 기록이다.
- [LeCun의 연구 회고](https://yann.lecun.com/ex/research/index.html)와 [LeCun et al., 우편번호 인식 논문 (1989)](https://doi.org/10.1162/neco.1989.1.4.541): 1988년 벨 연구소 합류·적용 시작과 1989년 공개 논문을 구분할 근거다.
- [LeCun et al., “Gradient-Based Learning Applied to Document Recognition” (1998)](https://yann.lecun.com/exdb/publis/pdf/lecun-98.pdf): LeNet-5의 구조와 문서 인식 체계를 확인하는 대표 자료다.
- [PyTorch `Conv2d` 문서](https://docs.pytorch.org/docs/stable/generated/torch.nn.Conv2d.html): 널리 쓰이는 합성곱층이 실제로는 유효 2차원 교차상관을 계산한다고 명시한다.
- [Zhang, “Making Convolutional Networks Shift-Invariant Again” (2019)](https://proceedings.mlr.press/v97/zhang19a.html): 풀링과 보폭을 포함한 현대 CNN이 작은 이동에도 완전 불변이 아님을 보여 준다.
- [Collobert·Weston (2008)](https://doi.org/10.1145/1390156.1390177), [Kim (2014)](https://aclanthology.org/D14-1181/), [Zhang·Zhao·LeCun (2015)](https://proceedings.neurips.cc/paper/2015/hash/250cf8b51c773f3f8dc8b4be867a9a02-Abstract.html): 텍스트와 문자 열에 CNN을 직접 적용한 계보다.
- [Word2Vec (2013)](https://research.google/pubs/efficient-estimation-of-word-representations-in-vector-space/), [GloVe (2014)](https://aclanthology.org/D14-1162/), [LSTM seq2seq (2014)](https://proceedings.neurips.cc/paper_files/paper/2014/hash/5a18e133cbf9f257297f410bb7eca942-Abstract.html), [Bahdanau attention (2014)](https://arxiv.org/abs/1409.0473), [Transformer (2017)](https://proceedings.neurips.cc/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html): 각 모델의 핵심 연산이 서로 다른 계보임을 원 논문에서 확인할 수 있다.

## 9. 용어 정리

| 용어 | 뜻 | 주의할 점 |
| --- | --- | --- |
| 합성곱 신경망(CNN) | 국소 연결과 공유 가중치를 중심으로 격자형·순서형 데이터를 처리하는 신경망 | 모든 층이 반드시 합성곱층일 필요는 없다. |
| 수용 영역(receptive field) | 출력 유닛 하나에 영향을 줄 수 있는 입력 영역 | 층을 쌓거나 보폭·팽창을 사용하면 유효 범위가 넓어진다. |
| 커널·필터 | 입력의 작은 영역에 반복 적용되는 학습 가중치 | 실제 매개변수 수에는 입력·출력 채널이 포함된다. |
| 특징 맵(feature map) | 한 필터가 여러 위치에 반응한 결과 배열 | 위치 정보를 완전히 없앤 표현이 아니다. |
| 가중치 공유 | 같은 커널 매개변수를 여러 위치에서 재사용하는 설계 | 매개변수를 줄이고 이동 등변성을 만드는 핵심이다. |
| 교차상관 | 커널을 뒤집지 않고 국소 곱의 합을 계산하는 연산 | 딥러닝에서 관례적으로 “합성곱”이라 부르는 경우가 많다. |
| 이동 등변성 | 입력이 이동하면 출력 특징도 대응해 이동하는 성질 | `f(Tx)=T f(x)`로 요약할 수 있다. |
| 이동 불변성 | 입력이 이동해도 과제 출력이 그대로인 성질 | `g(Tx)=g(x)`이며 등변성과 다르다. |
| 풀링(pooling) | 국소 영역을 최대값·평균값 등으로 요약해 해상도를 줄이는 연산 | 완전한 불변성이나 과적합 방지를 보장하지 않는다. |
| 귀납 편향 | 학습 전에 아키텍처가 전제한 데이터 구조에 관한 가정 | CNN에서는 국소성과 위치 반복성이 대표적이다. |
| 네오코그니트론 | 후쿠시마가 제안한 계층적 자기조직화 패턴 인식망 | 현대 역전파 CNN과 같지는 않지만 중요한 구조적 선행이다. |
| LeNet-5 | 1998년 문서 인식 논문에 제시된 대표적 합성곱망 | 1988년의 단일 모델로 소급하면 안 된다. |

## 12. 짧은 결론

CNN의 혁명성은 작은 필터 하나가 아니라, 데이터의 국소성과 반복 구조를 국소 연결·가중치 공유·계층적 표현 학습으로 묶어 실용적인 시스템으로 만든 데 있다. 그 역사는 1980년 네오코그니트론과 1987년 TDNN을 거쳐 1989년 벨 연구소의 손글씨 인식, 1998년 LeNet-5로 이어진 누적 과정이다. CNN은 텍스트와 문자 열에도 직접 적용됐지만, Word2Vec·GloVe·LSTM seq2seq·어텐션·Transformer를 모두 CNN의 직계 후손으로 묶어서는 안 된다. “무엇을 공유했고 무엇을 새로 바꿨는가”를 구분할 때 CNN의 실제 공헌과 현대 LLM의 계보가 모두 더 선명해진다.

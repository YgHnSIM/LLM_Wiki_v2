# 지속적 사후 학습: 동적 언어 모델을 위한 점진적 모델 업데이트

원본 출처: https://mbrenndoerfer.com/writing/continuous-post-training-incremental-model-updates-dynamic-language-models

---

LoRA를 활용한 매개변수 효율적 미세조정, 파국적 망각 방지, 점진적 모델 업데이트, 지속 학습 기법, 그리고 언어 모델을 최신 상태로 유지하면서 변화에 민감하게 대응하도록 만드는 효율적인 적응 전략을 아우르는 지속적 사후 학습 종합 안내서다.

## 2025년: 지속적 사후 학습

2025년 무렵 대규모 언어 모델은 [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development), 고객 서비스, 과학 연구, 창작 등 수많은 응용 분야의 핵심으로 자리 잡았다. 그러나 이러한 모델이 대규모로 배포되면서 근본적인 한계가 갈수록 뚜렷해졌다. 훈련 시점에 모델에 내재된 지식과 능력은 고정된 채로 남아, 비용과 시간이 많이 드는 전체 재훈련 없이는 새로운 정보, 달라진 사실, 진화하는 요구 사항에 적응할 수 없었다. 전통적인 미세조정 방식은 모델을 새로운 과제나 도메인에 적응시킬 수 있었지만, 대개 갱신된 데이터셋으로 완전히 다시 훈련해야 했다. 따라서 빠르게 변하는 정보를 모델에 계속 반영하거나 현실의 피드백을 바탕으로 모델을 지속해서 개선하기에는 실용성이 떨어졌다. 언어 모델의 이러한 정적 특성은 정보가 끊임없이 변하는 프로덕션 환경에서 장기적인 효과를 가로막는 중대한 장벽이 되었다.

언어 모델을 최신 상태로 유지하는 문제는 시사, 금융 시장, 과학 연구, 소프트웨어 개발처럼 지식 기반이 빠르게 변하는 영역에 모델이 배포되면서 특히 심각해졌다. 2024년 초에 훈련된 모델은 그해 후반에 발생한 주요 세계적 사건, 최신 과학적 돌파구, 새로 등장한 프로그래밍 프레임워크를 전혀 알지 못할 수 있었다. 마찬가지로 처음에는 유망한 성능을 보였던 모델도 현실에 광범위하게 배포된 뒤에야 약점이나 편향을 드러낼 수 있었다. 하지만 전통적인 재훈련 방식으로 이를 갱신하려면 속도가 느리고 비용이 많이 들었다. 이 분야에는 초기 훈련에서 얻은 가치 있는 일반 지식을 버리지 않으면서 모델의 지식과 행동을 점진적으로 갱신하는 방법이 필요했다.

지속적 사후 학습(continuous post-training)은 이러한 한계에 대응하는 패러다임 전환으로서 2025년에 부상했다. 지속적 사후 학습은 모델 훈련을 일회성 사건과 간헐적인 전체 재훈련으로 보지 않고, 새 데이터와 피드백, 지식이 생길 때마다 이를 모델에 점진적으로 반영하자고 제안했다. 이 접근법은 모델을 개선하기 위해 기존 능력을 내버릴 필요가 없으며, 학습한 가치 있는 지식을 보존하는 동시에 새로운 정보를 받아들이는 선택적 갱신이 가능해야 한다고 보았다. 핵심 혁신은 모델 가중치를 효율적으로 갱신하면서도 안정성을 유지하고, 이전에 학습한 지식의 [파국적 망각](/writing/catastrophic-forgetting-fine-tuning-mitigation)을 방지하는 훈련 절차를 개발한 데 있었다.

산업계와 학계의 여러 연구 그룹은 지속 학습, 전이 학습, LoRA([저순위 적응](/writing/lora-concept-low-rank-adaptation-efficient-llm-fine-tuning)) 같은 효율적 미세조정 기법에 관한 선행 연구를 바탕으로 지속적 사후 학습 방법의 발전에 기여했다. OpenAI, Anthropic, Google DeepMind를 비롯한 여러 기업은 모델을 더 자주, 더 표적화된 방식으로, 더 효율적으로 갱신하는 다양한 접근법을 탐구했다. 이 작업은 평생 학습과 파국적 망각에 관한 초기 연구의 통찰을 토대로 삼아, 더 작은 모델을 위해 개발된 기법을 현대 언어 모델의 방대한 규모에 맞게 조정했다. 목표는 모델 갱신을 비용이 많이 들고 운영을 방해하는 재훈련 주기가 아니라, 새 소프트웨어 버전을 배포하는 일만큼 일상적인 절차로 만드는 것이었다.

지속적 사후 학습의 의의는 기술 혁신을 넘어 AI 시스템이 어떻게 진화하고 적응해야 하는가라는 근본적인 물음으로 이어졌다. 이 접근법은 생물학적 학습 시스템과 마찬가지로 언어 모델도 초기 훈련 뒤 정적인 상태에 머무르지 않고 [지속적으로 개선](/writing/continuous-feedback-and-improvement-ai-agents)하고 적응할 수 있어야 한다고 제안했다. 이러한 관점은 배포 경험에서 배우고, 사용자 피드백을 반영하며, 기초 능력을 잃지 않은 채 변화하는 지식을 최신 상태로 유지하는 AI 시스템이라는 비전과 맞닿아 있었다. 지속적 사후 학습은 언어 모델을 더 역동적이고 반응성이 높으며 장기적으로 개선 가능한 시스템으로 만드는 한 걸음이었다.

## 문제

전통적으로 훈련된 언어 모델의 정적 특성은 모델이 대규모로 배포되면서 갈수록 심각해지는 몇 가지 근본적인 문제를 낳았다. 가장 명백한 문제는 지식의 노후화였다. 특정 시기의 데이터로 훈련된 모델은 그 지식이 고정되어 훈련 뒤에 나타난 새 정보를 받아들일 수 없었다. 이 한계는 뉴스 분석, 금융 조언, 기술 문서처럼 최신 정보가 필요한 응용 분야에서 특히 문제가 되었다. 모델은 폐기된 소프트웨어 라이브러리에 관한 정보를 자신 있게 제공하거나, 오래된 데이터셋의 통계를 인용하거나, 더 최근의 발전으로 이미 대체된 정보를 바탕으로 예측할 수도 있었다.

지식의 노후화를 넘어, 모델이 정적이라는 것은 배포 과정에서 발견한 개선 사항을 쉽게 반영할 수 없다는 뜻이기도 했다. 사용자들이 특정 응답이 도움이 되지 않는다고 거듭 피드백하거나 프로덕션 사용 중에 체계적인 편향이 발견되더라도, 이를 해결하려면 전체 재훈련 주기를 정당화할 만큼 문제 사례를 충분히 모아야 했다. 그 결과 개선 사항을 구현하는 데 몇 달이 걸릴 수 있는 긴 [피드백 루프](/writing/continuous-feedback-and-improvement-ai-agents)가 생겼고, 그동안 모델은 이미 알려진 문제를 계속 드러냈다. 수정 사항을 빠르게 반영할 수 없었기 때문에 모델의 품질과 사용자 요구에 대한 반응성을 반복적으로 개선하기가 어려웠다.

전통적인 미세조정 접근법은 이러한 한계를 일부 완화했지만, 상당한 비용과 제약이 따랐다. [전체 미세조정](/writing/full-fine-tuning-hyperparameters-learning-rate-schedules)은 모델의 모든 매개변수를 갱신해야 하므로, 대규모 모델에서는 막대한 계산 자원과 시간이 필요했다. 데이터 수집과 선별, 훈련 인프라 구성, 세심한 하이퍼파라미터 조정을 포함하는 이 과정에는 보통 수주 또는 수개월이 걸렸다. 이 기간에는 개선 중인 모델을 배포할 수 없어 상당한 기회비용이 발생했다. 또한 미세조정은 모델이 미세조정 데이터셋에 충분히 포함되지 않은 능력이나 지식을 잃는 [파국적 망각](/writing/catastrophic-forgetting-fine-tuning-mitigation)을 일으켜, 이전에 잘 처리하던 과제의 성능을 떨어뜨릴 수도 있었다.

현대 언어 모델의 규모는 전체 재훈련을 특히 비싸고 비현실적인 작업으로 만들었다. 수천억 개의 매개변수를 가진 모델을 훈련하려면 막대한 계산 자원이 필요했고, 한 차례 훈련 실행에 수백만 달러가 들기도 했다. 이러한 경제적 장벽 때문에 새 데이터나 확인된 개선 사항으로 갱신할 필요가 있더라도 재훈련을 자주 시행할 수 없었다. 높은 비용은 여러 개선 사항을 한데 묶어 드문 대규모 갱신으로 처리하도록 유도했고, 문제가 발견된 시점과 이를 해결하는 시점 사이의 간격을 더욱 늘렸다.

또 다른 근본적인 문제는 전통적인 훈련이 훈련 단계와 배포 단계 사이에 명확한 경계가 있다고 가정한다는 점이었다. 모델은 훈련과 배포를 마친 뒤 행동이 고정되는 동결 상태에 들어갔다. 이 가정은 모델을 주로 연구나 간헐적인 응용에 사용할 때는 어느 정도 타당했지만, 모델이 수백만 명의 사용자에게 서비스를 제공하는 프로덕션 시스템이 되자 더는 성립하지 않았다. 프로덕션 환경에서는 훈련과 배포의 구분이 덜 의미 있다. 배포는 피드백을 만들고, 경계 사례를 찾아내며, 개선 가능한 능력을 드러내지만 전통적인 방법은 이 정보를 모델에 쉽게 되돌려 반영할 수 없었다.

모델이 대규모로 배포되면서 모델 버전 관리와 조율 문제도 나타났다. 서로 다른 모델 버전이 각기 다른 사용자 집단이나 응용 프로그램에 서비스를 제공할 수 있었기 때문에 일관성을 보장하거나 개선 사항을 체계적으로 출시하기 어려웠다. 재훈련에 드는 높은 비용과 긴 시간 때문에 새 모델 버전은 드물게 나왔고, 그 결과 시스템의 여러 부분이 서로 다른 능력이나 지식을 가진 모델에서 장기간 실행될 수 있었다. 이러한 버전 분화는 일관된 경험을 제공하고 서로 다른 응용 프로그램이나 사용자 집단에 걸쳐 개선을 조율하는 일을 더 어렵게 했다.

또한 많은 응용 프로그램이 점진적 개선의 이점을 누린다는 현실과 정적 모델이라는 가정은 충돌했다. 여러 측면의 모델 행동을 한꺼번에 바꾸는 대규모 갱신보다, 특정 능력을 개선하거나 특정 도메인의 새 지식을 반영하는 표적화된 갱신이 더 유용한 사용 사례가 많았다. 전통적인 재훈련 방법은 이러한 세밀한 단위를 지원하지 않았다. 갱신은 대개 전부 아니면 전무였고, 원하는 모든 개선 사항을 동시에 포괄하는 종합 데이터셋으로 다시 훈련해야 했다. 이처럼 세분화가 부족했기 때문에 중요도나 실행 가능성에 따라 개선 사항의 우선순위를 정해 구현하기가 어려웠다.

이 분야에서는 언어 모델에 서로 다른 유형의 갱신이 필요할 수 있다는 점도 인식했다. 새 사실 지식을 반영하고, 특정 과제의 성능을 높이고, 사용자 피드백을 바탕으로 행동을 조정하거나, 확인된 버그나 편향을 수정해야 할 수 있었다. 각 갱신 유형에는 서로 다른 접근법이 더 적합할 수 있지만, 전통적인 방법은 원하는 변화의 범위나 성격과 무관하게 전체 재훈련을 요구함으로써 모든 갱신을 비슷하게 다뤘다. 이처럼 모든 경우에 같은 방법을 적용하는 방식은 비효율적이었고, 특정 개선 목표에 맞춰 갱신 전략을 조정하기 어렵게 했다.

## 해결책

지속적 사후 학습은 모델 개선을 서로 분리된 재훈련 과정의 연속이 아니라 지속되는 과정으로 다시 정의함으로써 이러한 문제에 대응했다. 핵심 혁신은 이전에 학습한 지식을 보존하고 모델의 안정성을 유지하면서도 새 데이터, 피드백, 확인된 개선 사항에 대응해 모델 가중치를 점진적으로 갱신할 수 있는 방법을 개발한 것이었다. 지속적 사후 학습은 기존 모델 매개변수를 버리고 처음부터 훈련하는 대신, 다른 능력을 떨어뜨리지 않으면서 특정 능력을 강화하는 선택적이고 표적화된 갱신을 지향했다.

이 접근법은 몇 가지 핵심 기술 혁신을 활용했다. 첫째, 지속적 사후 학습은 효율적인 적응을 위해 개발된 매개변수 효율적 미세조정 기법, 특히 모델 매개변수 중 일부만 변경해 갱신할 수 있는 LoRA([저순위 적응](/writing/lora-concept-low-rank-adaptation-efficient-llm-fine-tuning)) 같은 방법을 활용했다. 각 갱신 주기에서 모든 모델 가중치를 바꾸는 대신, 이러한 방법은 점진적으로 적용할 수 있는 작고 저순위인 적응값을 학습했다. 각 갱신 주기에 전체 재훈련보다 훨씬 적은 계산량만 필요했기 때문에 모델을 더 자주 갱신할 수 있었다.

둘째, 지속적 사후 학습은 [파국적 망각을 방지](/writing/catastrophic-forgetting-fine-tuning-mitigation)하는 것을 목표로 한 지속 학습 연구의 기법을 받아들였다. 이러한 방법은 새 지식이나 능력을 추가할 때 기존에 학습한 정보가 사라지지 않도록 했다. 중요한 가중치의 큰 변화를 벌점으로 주는 정규화 기법, 새 훈련 데이터에 이전 훈련 단계의 표본을 섞는 리플레이(replay) 메커니즘, 모델의 서로 다른 부분을 선택적으로 갱신할 수 있게 하는 아키텍처 변경 등이 여기에 포함됐다. 지속적 사후 학습은 파국적 망각을 방지함으로써 기존 지식을 새 지식으로 대체하는 대신, 시간이 흐르면서 지식과 개선 사항을 축적할 수 있게 했다.

셋째, 이 접근법은 각 갱신 주기에 어떤 정보를 반영해야 하는지 식별할 수 있는 효율적인 데이터 관리와 표본 추출 전략을 개발했다. 지속적 사후 학습 시스템은 기존 정보와 새 정보를 섞은 종합 데이터셋으로 다시 훈련하는 대신, 지식의 공백을 나타내는 새 데이터를 선택적으로 추출하고 사용자 피드백을 반영하거나 가장 개선이 필요한 영역에 집중할 수 있었다. 이러한 선택적 갱신은 과정을 더 효율적으로 만들었고, 특정 개선 목표에 맞춰 갱신할 수 있게 했다.

지속적 사후 학습의 훈련 절차는 보통 다음과 같이 진행됐다. 완전히 훈련되었거나 최근에 갱신된 기반 모델에서 출발해, 시스템은 반영해야 할 새 데이터나 피드백을 식별했다. 최근 문서, 사용자 피드백, 확인된 오류 사례, 오래되어 갱신해야 하는 지식 등이 여기에 포함될 수 있었다. 그런 다음 시스템은 LoRA 같은 기법으로 매개변수 효율적 미세조정을 수행해 새 정보를 반영하는 소규모 매개변수 갱신값을 학습했다. 이 과정에서 모델이 이전에 배운 지식을 잊지 않도록 정규화나 리플레이 기법을 적용했다. 개선이 이뤄졌고 기존 능력은 저하되지 않았는지 갱신 모델을 평가한 뒤, 성공적이면 갱신을 배포했다.

갱신 일정과 우선순위 시스템을 개발하는 것도 지속적 사후 학습의 중요한 측면이었다. 잠재적인 모든 갱신이 똑같이 중요하거나 실행 가능한 것은 아니었고, 이 접근법은 새 정보를 반영해 얻는 이점과 각 갱신의 비용 및 위험 사이에서 균형을 잡아야 했다. 이러한 시스템은 새 정보의 중요성, 특정 문제에 관한 사용자 피드백의 양, 개선의 잠재적 영향, 각 갱신에 필요한 자원 같은 요소를 바탕으로 우선순위를 정할 수 있었다. 이를 통해 조직은 모든 것을 드문 대규모 갱신에 한꺼번에 묶지 않고, 어떤 개선 사항을 언제 구현할지 전략적으로 결정할 수 있었다.

이 접근법은 전체 배포 전에 갱신을 평가하는 방법도 개발했다. 지속적 사후 학습 시스템은 새로운 능력과 기존 능력을 모두 다루되 학습에는 사용하지 않은 별도 평가 세트에서 갱신 모델을 시험해, 개선이 회귀를 대가로 얻어진 것은 아닌지 확인할 수 있었다. A/B 시험 프레임워크를 이용하면 프로덕션 환경에서 갱신 모델과 현재 모델을 비교할 수 있어, 전면 출시에 앞서 실제 운영 환경에서의 검증이 가능했다. 이러한 평가 메커니즘은 지속적인 갱신이 예기치 않은 문제를 일으키는 대신 실제로 모델 품질을 개선하도록 뒷받침했다.

갱신 버전 관리와 롤백 기능의 개발도 또 하나의 핵심 혁신이었다. 모델 버전이 드물게 나오고 변화 폭이 큰 전통적 재훈련과 달리, 지속적 사후 학습은 더 작고 빈번한 갱신을 가능하게 했다. 따라서 각 갱신이 도입한 변화를 추적하고, 비교할 수 있도록 이전 모델 버전을 유지하며, 갱신이 예상치 못한 문제를 일으켰을 때 되돌릴 수 있는 견고한 버전 관리 시스템이 필요했다. 이러한 버전 관리 역량은 지속적인 갱신을 더 안전하고 관리하기 쉽게 만들어 각 갱신 주기의 위험을 줄였다.

## 훈련 방법론

지속적 사후 학습의 기술적 구현은 이미 확립된 여러 기법을 토대로 하되, 대규모 언어 모델을 계속 갱신할 때 생기는 고유한 문제에 맞게 이를 조정했다. 갱신이 효과적이면서 안전하도록 하려면 데이터 관리, 훈련 절차, 평가를 세심하게 조율해야 했다.

지속적 사후 학습의 중심에는 [저순위 적응](/writing/lora-concept-low-rank-adaptation-efficient-llm-fine-tuning)(Low-Rank Adaptation, LoRA)을 비롯한 매개변수 효율적 미세조정 방법이 있었다. LoRA는 [가중치 갱신](/writing/mathematics-llm-fine-tuning-how-and-why-it-works-explained)을 저순위 행렬로 분해하는 방식으로 작동했다. 전체 가중치 행렬 $W \in \mathbb{R}^{m \times n}$을 갱신하는 대신, LoRA는 더 작은 두 행렬 $A \in \mathbb{R}^{r \times n}$과 $B \in \mathbb{R}^{m \times r}$을 학습했다. 여기서 $r \ll \min(m,n)$은 적응 랭크다. 갱신된 가중치는 $W + BA$가 되며, 훨씬 작은 행렬 $A$와 $B$만 훈련하고 저장하면 됐다. 매개변수가 수십억 개인 모델에서도 LoRA는 수백만 개의 적응 매개변수만 훈련하면 될 수 있으므로, [전체 미세조정](/writing/full-fine-tuning-hyperparameters-learning-rate-schedules)보다 훨씬 효율적으로 갱신할 수 있었다.

지속적 사후 학습의 훈련 과정은 일반적으로 다음과 같이 진행됐다. 먼저 데이터 수집 시스템이 최근 문서, 사용자 피드백, 확인된 오류 사례, 갱신이 필요한 지식처럼 반영해야 할 새 정보를 모았다. 이 데이터는 훈련에 알맞게 선별하고 형식을 갖췄다. 둘째, 시스템은 LoRA나 비슷한 매개변수 효율적 방법을 적용해 새 정보를 반영하는 적응값을 학습했다. 훈련 중에는 기존 능력에 중요한 가중치의 큰 변화를 벌점으로 주는 방식처럼 [파국적 망각을 방지](/writing/catastrophic-forgetting-fine-tuning-mitigation)하는 정규화 기법을 적용했다.

지속적 사후 학습은 파국적 망각을 방지하기 위해 여러 전략을 사용했다. 탄력적 가중치 통합(Elastic Weight Consolidation, EWC) 기법은 이전에 학습한 과제에서 각 매개변수가 얼마나 중요한지 계산한 다음, 새로 훈련할 때 중요한 매개변수가 크게 변하면 벌점을 부과했다. 이를 통해 기존 능력에 중요한 가중치가 지나치게 크게 수정되지 않도록 했다. 리플레이 메커니즘은 새 훈련 데이터에 이전 훈련 단계의 표본을 섞어, 모델이 새 정보를 반영하면서도 이전에 배운 지식을 유지하도록 도왔다. 일부 접근법은 지식 도메인이나 능력별로 별도의 [어댑터 모듈](/writing/adapter-layers-bottleneck-modules-transformer-fine-tuning)도 사용해, 갱신의 표적성을 높이고 서로 다른 개선 유형 사이의 간섭을 줄였다.

훈련 절차 자체는 점진적으로 이뤄지도록 설계됐다. 모든 것을 섞은 종합 데이터셋으로 훈련하는 대신, 지속적 사후 학습은 각 갱신 주기를 특정 개선 사항에 집중할 수 있었다. 각 주기는 수주가 아닌 몇 시간 또는 며칠 안에 끝낼 수 있었으므로 훈련이 더 빠르고 효율적이었다. 점진적 특성 덕분에 다음 갱신으로 넘어가기 전에 각 갱신을 시험하고 검증하기도 쉬워져, 더 반복적이고 반응성 높은 개발 과정이 가능해졌다.

평가는 지속적 사후 학습 방법론에서 매우 중요한 역할을 했다. 시스템은 갱신을 배포하기 전에 추가하려는 새 능력과 보존해야 할 기존 능력을 모두 아우르는 종합 시험 모음으로 갱신 모델을 평가했다. 이러한 평가는 개선이 실제로 이뤄졌으며 회귀가 새로 생기지 않았는지 확인하는 데 도움이 됐다. 표준 벤치마크를 이용한 자동 시험, 핵심 사용 사례에 관한 인간 평가, 이전 모델 버전과의 비교 등이 평가 과정에 포함될 수 있었다.

이 방법론은 시간이 지나면서 갱신이 누적되는 상황을 관리하는 기법도 개발했다. 여러 [LoRA 어댑터](/writing/lora-concept-low-rank-adaptation-efficient-llm-fine-tuning)나 점진적 갱신을 적용할수록 시스템은 이를 어떻게 결합할지 결정해야 했다. 일부 접근법은 새 갱신이 앞선 모든 갱신 위에 쌓이도록 순차적으로 적용했다. 다른 접근법은 여러 어댑터를 병합하고, 누적 갱신이 지나치게 커지는 것을 막기 위해 이를 압축할 수도 있는 방법을 개발했다. 이러한 결합 전략 덕분에 지속적 사후 학습은 수많은 갱신 주기가 이어지는 장기간에도 효과적으로 작동할 수 있었다.

서로 다른 갱신의 목표가 충돌할 수 있을 때 그 충돌과 우선순위를 처리하는 것 역시 방법론의 중요한 측면이었다. 예를 들어 한 갱신은 과학 도메인의 사실 정확도를 높이는 데 초점을 맞추고, 다른 갱신은 창작 능력을 향상하는 데 집중할 수 있었다. 시스템에는 서로 경쟁할 수 있는 이러한 개선 사항 사이에서 균형을 잡아, 갱신이 서로 방해하지 않고 함께 작동하도록 만드는 메커니즘이 필요했다. 일부 접근법은 서로 다른 어댑터의 가중 결합을 사용해 각 능력의 상대적 중요도를 조정할 수 있게 했다.

이 방법론은 지속적인 갱신에 특화된 안전과 품질 보증 절차도 개발했다. 각 갱신 주기에는 성능 회귀, 편향의 도입, 예상치 못한 행동 변화 같은 잠재적 문제를 확인하는 검사가 포함됐다. 이러한 검사는 문제가 프로덕션에 도달하기 전에 발견하도록 도와 지속적인 갱신 과정을 더 안전하고 신뢰할 만하게 만들었다. 문제가 발견되었을 때 갱신을 되돌릴 수 있다는 점도 추가적인 안전장치를 제공했다.

## 응용과 영향

지속적 사후 학습은 모델을 최신 상태로 유지하고 피드백에 민감하게 반응하는 일이 필수적인 프로덕션 언어 모델 시스템에 곧바로 적용됐다. 고객 서비스, 콘텐츠 생성, 그 밖의 프로덕션 응용 분야에 대규모 언어 모델을 배포한 기업들은 사용자 피드백을 반영하고, 확인된 문제를 수정하며, 변화하는 정보에 맞춰 모델을 최신 상태로 유지하기 위해 지속적 사후 학습을 사용하기 시작했다. 이러한 적용은 지속적 사후 학습이 대규모에서도 작동할 수 있고, 반응성이 더 높고 적응력 있는 언어 모델 시스템으로 나아가는 실용적인 길을 제공한다는 점을 보여줬다.

주요 응용 분야 가운데 하나는 빠르게 변하는 정보에 맞춰 모델을 최신 상태로 유지하는 일이었다. 뉴스 기관, 금융 서비스 기업, 연구 기관에는 최근 사건과 시장 동향, 과학적 발견을 값비싼 재훈련 주기를 기다리지 않고 반영할 수 있는 모델이 필요했다. 지속적 사후 학습을 사용하면 이러한 조직은 모델 지식을 점진적으로 갱신해, 기반 정보 환경이 변해도 모델의 유용성을 유지할 수 있었다. 이러한 능력은 오래된 시장 데이터를 바탕으로 금융 조언을 제공하거나 최근 세계적 사건에 관한 질문에 답하는 경우처럼, 정보의 노후화가 중대한 문제로 이어질 수 있는 도메인에서 특히 가치가 있었다.

현실의 사용 패턴을 바탕으로 사용자 피드백을 반영하고 모델을 개선하는 것도 핵심 응용이었다. 수백만 명의 사용자에게 서비스를 제공하도록 모델을 배포하면, 초기 훈련 중에는 드러나지 않은 경계 사례나 약점, 개선 영역이 필연적으로 발견됐다. 지속적 사후 학습을 통해 조직은 이러한 피드백을 수집하고 패턴을 식별해 개선 사항을 모델에 점진적으로 반영할 수 있었다. 이로써 배포와 개선 사이의 [피드백 루프](/writing/continuous-feedback-and-improvement-ai-agents)가 더 긴밀해졌고, 엄선한 훈련 데이터셋만이 아니라 실제 사용을 바탕으로 모델을 개선할 수 있었다.

이 접근법은 특정 능력이나 도메인을 더 표적화해서 개선할 수도 있게 했다. 특정 과제의 성능을 높이기 위해 종합적으로 다시 훈련하는 대신, 지속적 사후 학습을 통해 조직은 특정 영역에 갱신을 집중할 수 있었다. 예컨대 기업은 모델 전체를 다시 훈련하거나 다른 능력이 저하될 위험을 감수하지 않고도 [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development), 의료 [질의응답](/writing/ibm-watson-jeopardy-open-domain-question-answering-nlp-information-retrieval), 창작 성능을 높이는 데 지속적 사후 학습을 사용할 수 있었다. 이러한 세분화는 모델 개선을 더 실용적이고 비용 효율적으로 만들어, 조직이 구체적인 필요와 사용 사례에 따라 개선 사항의 우선순위를 정할 수 있게 했다.

지속적 사후 학습은 모델 개발에서 실험과 반복도 촉진했다. 더 적은 비용으로 더 자주 갱신할 수 있었기 때문에 조직은 다양한 개선 사항을 시험하고, 영향을 측정하고, 더 빠르게 반복할 수 있었다. 이처럼 실험할 수 있는 역량은 혁신의 속도를 높이고 개발 주기를 더 반응성 있게 만들었다. 팀은 전체 재훈련에 들이는 비용과 시간을 감수할 만큼 가치가 없다고 여겼을 개선 사항도 시도해 볼 수 있었고, 그렇지 않았다면 놓쳤을 가치 있는 향상을 발견할 수 있었다.

이 접근법은 모델이 진화하는 요구 사항에 적응하거나 도메인 특화 지식을 점진적으로 반영해야 하는 전문 영역에도 적용됐다. 법률 기술 기업은 새로운 판례나 규정이 나오면 모델을 갱신할 수 있었다. 의료 AI 시스템은 새로운 연구 결과나 갱신된 치료 지침을 반영할 수 있었다. 소프트웨어 개발 도구는 새로운 프로그래밍 언어나 프레임워크의 인기가 높아질 때 적응할 수 있었다. 이처럼 도메인에 특화된 적응 덕분에 지속적 사후 학습은 특정 분야의 심층 전문 지식이 필요한 응용에서 가치를 지녔다.

개별 응용을 넘어, 지속적 사후 학습은 언어 모델을 어떻게 개발하고 유지해야 하는지에 관한 더 폭넓은 사고에도 영향을 미쳤다. 이 접근법은 모델 훈련이 일회성 사건이라는 가정에 이의를 제기하며, 모델 개선을 지속되는 과정으로 봐야 한다고 제안했다. 이 관점은 시스템을 정기적으로 처음부터 다시 만드는 대신 갱신과 반복을 통해 끊임없이 개선하는 소프트웨어 개발 관행과 맞닿아 있었다. 그 영향은 조직이 AI 개발 팀과 절차를 구성하는 방식으로까지 이어져, 더 민첩하고 반응성 높은 개발 관행으로의 전환을 촉진했다.

지속적 사후 학습의 확장성 이점은 모델 배포와 유지 관리에도 새로운 가능성을 열었다. 조직은 대규모 언어 모델을 더 비용 효율적으로 유지하고 개선할 수 있었고, 더 많은 사용자나 응용 프로그램에 서비스를 제공하도록 규모를 확장해도 모델을 최신 상태로 유지하면서 피드백에도 민감하게 대응할 수 있었다. 이러한 확장성의 이점은 전체 재훈련을 자주 할 자원은 없지만 더 효율적인 지속 갱신을 통해 모델을 유지하고 개선할 수 있는 소규모 조직이나 연구 그룹에 특히 중요했다.

## 한계

지속적 사후 학습에는 장점이 있지만 적용 가능성과 효과를 제약하는 몇 가지 중요한 한계도 있었다. 근본적인 문제 가운데 하나는 갱신이 미묘한 회귀나 편향을 일으키지 않고 실제로 모델을 개선하는지 보장하는 일이었다. 평가 절차로 명백한 문제를 포착할 수는 있었지만, 장기간 배포한 뒤에야 드러나는 문제도 있을 수 있었다. 또한 지속적 사후 학습의 빠른 갱신 주기 때문에 어떤 갱신이 특정 문제를 일으켰는지 찾기 어려울 수 있었다. 갱신이 시간에 따라 누적되면 문제가 개별 변화가 아니라 여러 갱신의 상호작용에서 생길 수 있으므로 디버깅은 특히 어려워졌다.

이 접근법은 기반 모델의 근본적인 아키텍처 한계에도 부딪혔다. 지속적 사후 학습은 모델의 지식과 행동을 갱신할 수 있지만, 모델의 아키텍처와 훈련 목표, 근본적인 능력까지 바꿀 수는 없었다. 모델 아키텍처가 특정 유형의 과제 성능을 제약하거나 훈련 목표가 특정 응용에 잘 맞지 않는다면, 더 근본적인 변화 없이는 지속적 사후 학습으로 이런 한계를 해결할 수 없었다. 일부 개선에는 아키텍처 변경이나 다른 목표를 사용한 재훈련이 필요할 수 있는데, 지속적 사후 학습은 이를 위해 설계된 방식이 아니었다.

시간이 지나며 갱신이 쌓일수록 복잡성을 관리하기 어렵다는 점도 한계였다. 매개변수 효율적 방법은 개별 갱신의 계산 비용을 줄여 줬지만, 누적된 적응값은 관리하기 복잡해질 수 있었다. 여러 [LoRA 어댑터](/writing/lora-concept-low-rank-adaptation-efficient-llm-fine-tuning), 누적된 정규화 항, 버전 이력을 모두 세심하게 관리해야 했고, 장기간에 걸쳐 다루기 어려운 상태가 될 수 있었다. 이러한 복잡성 때문에 누적된 갱신을 주기적으로 통합하거나 압축하는 일이 중요했는데, 그러려면 때때로 더 종합적인 재훈련 주기가 필요할 수 있었다.

이 접근법은 지식이나 요구 사항의 중대한 변화를 처리하는 데도 어려움을 겪었다. 지속적 사후 학습은 점진적 개선과 새 정보 반영에는 효과적이었지만, 모델이 알아야 하거나 해야 하는 일이 근본적으로 바뀌면 어려움을 겪을 수 있었다. 모델을 완전히 다른 도메인에 적응시켜야 하거나 기반 [지식 베이스](/writing/wikidata-collaborative-knowledge-base-language-ai)에 큰 변화가 생기면, 더 종합적인 재훈련이 여전히 필요할 수 있었다. 지속적 사후 학습은 이따금 필요한 대규모 갱신이나 재훈련 주기를 대체하는 것이 아니라 보완했다.

또한 지속적 사후 학습을 운영하려면 지속적인 갱신 주기를 뒷받침하는 인프라와 절차가 필요했다. 조직에는 데이터 수집, 선별, 훈련, 평가, 배포를 위한 시스템이 필요했고, 이 모두에 지속적인 투자와 유지 관리가 요구됐다. 개별 갱신이 전체 재훈련보다 효율적이더라도 이러한 운영 부담 때문에 지속적 사후 학습에 비용이 전혀 들지 않는 것은 아니었다. 소규모 조직이나 연구 그룹은 효과적인 지속적 사후 학습에 필요한 인프라를 유지하기 어려울 수 있었다.

이 접근법은 배포 전반의 모델 버전 관리와 일관성에 관한 문제도 제기했다. 모델을 자주 갱신할 수 있으면 서로 다른 배포 환경이 각기 다른 버전을 실행해 행동이 일관되지 않을 수 있었다. 버전의 일관성을 관리하고, 여러 시스템에 걸쳐 갱신을 조율하며, 모든 배포가 개선의 혜택을 보게 하려면 세심한 조정이 필요했다. 이 버전 관리 문제는 서로 다른 사용자 집단이나 시점에 걸친 일관성이 중요한 응용 분야에서 특히 중요했다.

지속적 사후 학습으로 일부 유형의 모델 문제를 완전히 해결하지 못할 수 있다는 점도 한계였다. [파국적 망각](/writing/catastrophic-forgetting-fine-tuning-mitigation) 방지 기법은 기존 지식을 보존하는 데 도움이 됐지만 완벽하지 않았고, 수많은 갱신 주기를 거치면서 어느 정도 성능 저하가 여전히 생길 수 있었다. 또한 일부 모델 문제는 모델을 처음 훈련하거나 설계한 방식에 내재할 수 있으며, 이런 문제에는 지속적 사후 학습이 제공할 수 없는 더 종합적인 변화가 필요할 수 있었다. 이 접근법은 점진적 개선에는 강력했지만, 더 깊은 아키텍처나 훈련 목표의 한계를 해결하는 데는 제약이 있었다.

## 유산과 미래 전망

지속적 사후 학습은 언어 모델을 개발하고 유지하는 방식에 새로운 패러다임을 세웠다. 정적 모델이라는 가정에서 벗어나 지속해서 개선하고 적응할 수 있는 시스템으로 옮겨 간 것이다. 이 접근법은 모델을 더 자주, 더 표적화된 방식으로, 더 효율적으로 갱신할 수 있음을 보여 주었고, 언어 모델이 초기 훈련 뒤 고정된 채로 남는 대신 지속해서 진화할 수 있게 했다. 이러한 패러다임 전환은 조직이 모델 개발과 배포, 유지 관리를 바라보는 방식에 영향을 미쳤고, 언어 모델을 시간이 지나며 적응하고 개선되는 살아 있는 시스템에 더 가깝게 다뤄야 한다고 제안했다.

지속적 사후 학습의 기술 혁신, 특히 매개변수 효율적 미세조정과 지속 학습 기법의 결합은 효율적인 모델 적응과 평생 학습이라는 더 폭넓은 연구 방향에 영향을 미쳤다. 이 접근법은 [파국적 망각](/writing/catastrophic-forgetting-fine-tuning-mitigation)을 방지하면서 대규모 언어 모델을 효율적으로 갱신할 수 있음을 보여 주어, 모델이 시간에 따라 지식과 능력을 축적하는 방식에 새로운 가능성을 열었다. 후속 연구는 다양한 매개변수 효율적 방법과 지속 학습 기법, 갱신 전략을 시험하며 지속적 사후 학습의 변형을 탐구해 왔다.

점진적 개선과 반응성 높은 개발을 강조하는 이 접근법은 AI 시스템을 위한 소프트웨어 공학 관행에도 영향을 미쳤다. 지속적 사후 학습은 언어 모델 개발을, 이따금 큰 릴리스를 내는 대신 빈번한 소규모 갱신을 통해 시스템을 지속해서 개선하는 애자일 소프트웨어 개발에 더 가깝게 만들었다. 이러한 접점은 조직이 더 반복적이고 반응성 높은 개발 관행을 채택하도록 장려해, 모델 개선을 별개의 드문 활동으로 취급하는 대신 지속적인 개발 주기에 통합하게 했다.

앞으로 지속적 사후 학습은 한층 더 역동적이고 적응력 있는 AI 시스템으로 향하는 길을 가리킨다. 향후 발전을 통해 모델은 배포 경험에서 더 자율적으로 학습하고, 피드백을 더 직접적으로 반영하거나, 변화하는 요구 사항에 더 빠르게 적응할 수 있을지도 모른다. 효율적인 갱신, 지식 보존, [지속적인 개선](/writing/continuous-feedback-and-improvement-ai-agents)을 포함해 지속적 사후 학습이 세운 원칙은 언어 모델이 더욱 유능해지고 널리 배포되면서 계속 중요하게 남을 가능성이 크다.

이 접근법은 AI 시스템이 어떻게 진화해야 하며 누가 그 진화를 통제해야 하는지에 관한 더 폭넓은 물음도 제기한다. 지속적 사후 학습으로 모델을 더 자주, 더 쉽게 갱신할 수 있게 될수록 거버넌스, 투명성, 책임성에 관한 문제는 더욱 중요해진다. 지속적인 갱신이 모델을 바람직한 방향으로 개선하는지, 변화가 투명하고 감사 가능한지, 갱신이 의도하지 않은 결과를 일으키지 않는지 보장하는 일은 지속적 사후 학습이 널리 확산될수록 중요한 과제가 될 것이다.

지속적 사후 학습의 성공은 훨씬 더 효율적인 갱신 메커니즘에 관한 탐구도 촉진했다. 앞으로는 더 적은 계산량으로 모델을 갱신하는 방법이 개발되어 갱신 빈도를 높이거나, 자원이 적은 조직도 지속적 사후 학습을 활용할 수 있게 될지 모른다. 희소성, 양자화, 그 밖의 효율화 기법이 발전하면 지속적인 모델 개선의 비용과 장벽을 더욱 낮출 수 있을 것이다.

이 접근법은 언어 모델을 평가하고 검증하는 방식에 관한 사고에도 영향을 미쳤다. 지속적 사후 학습의 빈번한 갱신 주기에는 더 자동화되고 효율적인 평가 절차가 필요하므로, 갱신으로 모델이 개선됐는지 빠르게 판단할 수 있는 더 나은 평가 방법의 개발이 촉진됐다. 이러한 영향은 지속적 사후 학습을 넘어, 언어 모델의 능력이 향상되고 활용이 넓어짐에 따라 이를 어떻게 평가하고 검증할 것인가라는 더 폭넓은 물음으로 이어졌다.

언어 모델의 규모가 계속 커지고 응용 프로그램에서 더욱 중심적인 역할을 하게 되면서, 지속적 사후 학습이 세운 원칙은 갈수록 중요해질 가능성이 크다. 여기에는 모델이 [지속적으로 개선](/writing/continuous-feedback-and-improvement-ai-agents)될 수 있어야 하고, 갱신을 효율적이고 점진적으로 수행할 수 있어야 하며, 모델이 새 정보와 피드백에 적응해야 한다는 원칙이 포함된다. 이 접근법은 모델 훈련을 일회성 사건으로 보는 관점에서 벗어나, 이를 지속적인 개선과 적응의 과정으로 인식하도록 전환한 것으로서 앞으로 오랫동안 언어 모델의 발전 방향을 형성할 것이다.

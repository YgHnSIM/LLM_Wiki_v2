# DeepSeek-R1 해설

## 1. 한눈에 보기

- 핵심 주제: DeepSeek-R1이 대규모 강화학습, 콜드 스타트 데이터, 다단계 후훈련, 지식 증류를 결합해 수학·코딩·과학 추론 성능을 높인 방식
- 등장 배경: 더 긴 추론 과정을 생성하는 모델이 주목받았지만, 사람이 작성한 추론 시연과 값비싼 후훈련에 대한 의존이 컸던 시기
- 가장 중요한 아이디어: DeepSeek-R1의 핵심은 별도의 ‘추론 모듈’을 새로 붙인 데 있기보다, DeepSeek-V3-Base에 검증 가능한 보상과 GRPO를 적용해 추론 행동을 유도하고 그 결과를 다단계 학습과 증류로 정제한 데 있다.
- 이후 LLM/NLP에 남긴 영향: 대규모 모델에서 강화학습으로 발견한 추론 패턴을 공개 가중치와 소형 증류 모델로 배포해, 추론 모델 연구의 재현·비교·후속 실험 범위를 넓혔다.

> 이 문서는 `106_DeepSeek R1 Architectural Innovation in Reasoning Models.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 공식 기술 보고서와 저장소를 기준으로 확인된 사실, 원문의 해석, 근거가 부족한 확장 주장을 구분합니다.

## 2. 핵심 요약

원문은 DeepSeek-R1을 하드웨어 제약 속에서 ‘더 작은 모델’과 ‘특화 추론 아키텍처’로 거대 모델의 성능을 따라잡은 사례로 설명한다. 그러나 [DeepSeek-R1 공식 보고서](https://arxiv.org/abs/2501.12948)와 [공식 저장소](https://github.com/deepseek-ai/DeepSeek-R1)가 보여 주는 중심 서사는 다르다. 정식 DeepSeek-R1과 R1-Zero는 모두 DeepSeek-V3-Base에서 출발한 희소 Mixture-of-Experts(MoE) 모델로, 전체 매개변수는 671B이고 토큰당 활성 매개변수는 37B이다. 즉 전체 모델 자체가 작다기보다 희소 활성화로 한 번에 쓰는 계산을 줄인 대형 모델이다. R1-Zero는 사전 지도 미세조정 없이 GRPO 기반 강화학습을 적용해 긴 추론, 재검토, 자기 검증 같은 출력 행동이 나타나는지를 시험했다. 정식 R1은 R1-Zero의 가독성 저하와 언어 혼합을 보완하기 위해 소량의 콜드 스타트 데이터, 추론 강화학습, 거부 샘플링과 지도 미세조정, 일반 선호 정렬 강화학습을 차례로 적용했다. 작은 모델이라는 설명은 R1 본체가 아니라 R1이 생성한 데이터로 학습한 1.5B–70B의 Qwen·Llama 기반 증류 체크포인트에 해당한다. 공식 자료는 R1 전용 특화 추론 모듈, 새 메모리 모듈, 난이도를 점진적으로 올리는 커리큘럼 학습, R1에서 새로 개발한 어텐션 구조를 보고하지 않는다. 따라서 이 자료는 ‘아키텍처 혁신’이라는 제목보다 ‘대규모 강화학습과 증류를 통한 추론 후훈련’이라는 관점으로 읽을 때 더 정확하다.

- 무엇을 다루는가: R1 계열의 추론 성능, 효율성, 접근성, 영향과 한계
- 어떤 문제를 해결하려 했는가: 사람의 장문 추론 시연에 대한 의존을 줄이면서 검증 가능한 과제의 추론 성능을 높이는 문제
- 어떤 방식이 새로웠는가: 대형 기반 모델에 대규모 GRPO를 적용해 추론 행동을 유도하고, 콜드 스타트와 다단계 후훈련으로 가독성·일반 능력을 보완한 방식
- 결과적으로 무엇을 바꾸었는가: 강화학습 기반 추론 모델과 추론 데이터 증류를 공개적으로 분석하고 재사용할 수 있는 대표 사례를 제공했다.

## 3. 역사적 배경

[[080_Chain-of-Thought Prompting Unlocking Latent Reasoning in Language Models|Chain-of-Thought prompting]]은 2022년에 중간 추론 단계를 예시로 제시하면 큰 언어 모델의 산술·상식·기호 추론 성능이 개선될 수 있음을 보여 주었다. 이후 연구는 좋은 추론 경로를 사람이 작성하거나, 모델이 생성한 경로를 선별하거나, 과정·결과 검증기의 피드백으로 학습시키는 방향으로 확장됐다. 2024년 OpenAI o1은 답변 전에 더 긴 계산을 쓰는 추론 모델과 추론 시점 계산량 확대를 제품 수준에서 부각했다. 다만 o1의 구조와 훈련 세부는 공개되지 않아, R1 보고서는 공개 비교가 가능한 강화학습 경로를 제시한다는 데 별도의 의미가 있었다.

DeepSeek-R1의 직접적인 기반은 DeepSeek-V3-Base다. [DeepSeek-V3 기술 보고서](https://arxiv.org/abs/2412.19437)는 이 모델을 671B 전체 매개변수 중 토큰마다 37B를 활성화하는 MoE로 설명하며, Multi-head Latent Attention(MLA)과 DeepSeekMoE를 사용한다고 밝힌다. 그러나 MLA와 DeepSeekMoE는 R1을 위해 새로 만든 ‘추론 전용’ 구조가 아니라 DeepSeek-V2에서 검증되고 V3에 채택된 기반 아키텍처다. R1의 주된 연구 변화는 이 토대 위에 어떤 후훈련 보상과 데이터 파이프라인을 적용했는가에 있다.

또 하나의 선행 요소는 DeepSeekMath에서 제안된 Group Relative Policy Optimization(GRPO)이다. GRPO는 각 질문에 대해 여러 응답을 뽑고 같은 그룹 안에서 상대적인 보상을 계산해 정책을 갱신한다. 같은 크기의 별도 가치 모델을 두지 않아도 된다는 점이 PPO 계열 대비 실용적 이점이다. R1은 이 알고리즘을 훨씬 큰 기반 모델과 장문 추론 학습에 적용했다.

- 이전 접근법: 지도학습된 추론 예시, Chain-of-Thought prompting, 과정·결과 보상 모델, 탐색과 다수결, 선호 기반 강화학습
- 당시의 한계: 고품질 장문 추론 시연의 비용, 보상 모델의 해킹 가능성, 장문 생성의 높은 추론 비용, 폐쇄형 추론 모델의 낮은 검증 가능성
- 이 주제가 필요했던 이유: 정답을 자동 검증할 수 있는 문제에서 인간이 모든 추론 경로를 쓰지 않고도 모델의 풀이 행동을 개선할 수 있는지 시험하기 위해서다.

## 4. 핵심 개념 해설

### 4.1 R1-Zero·R1·증류 모델은 서로 다르다

‘DeepSeek-R1’이라는 이름 아래에는 목적과 크기가 다른 모델이 섞여 있다.

| 구분 | 출발점과 규모 | 핵심 학습 방식 | 해석할 때의 주의점 |
|---|---|---|---|
| DeepSeek-R1-Zero | DeepSeek-V3-Base, 671B 전체·37B 활성 | 사전 SFT 없이 GRPO 기반 추론 강화학습 | 순수 RL 실험에 가깝고, 가독성 저하·언어 혼합 문제가 컸다. |
| DeepSeek-R1 | DeepSeek-V3-Base, 671B 전체·37B 활성 | 콜드 스타트 SFT, 추론 RL, 거부 샘플링과 SFT, 두 번째 정렬 RL | 정식 모델은 ‘SFT 없이 RL만으로 만든 모델’이 아니다. |
| R1-Distill-Qwen/Llama | 1.5B, 7B, 8B, 14B, 32B, 70B의 조밀 모델 | R1이 생성·선별한 약 80만 개 샘플로 미세조정 | R1 본체의 축소판이나 동일 아키텍처가 아니라 Qwen·Llama 기반 파생 체크포인트다. |

이 구분을 놓치면 “R1은 작은 모델이다”, “R1은 지도 데이터 없이 학습됐다”, “R1을 모바일에서 바로 실행할 수 있다” 같은 잘못된 결론이 생긴다. 순수 RL 주장은 R1-Zero에, 소형화와 접근성 주장은 증류 모델에, 가장 강한 공개 성능 주장은 671B MoE인 정식 R1에 각각 대응한다.

### 4.2 GRPO와 검증 가능한 보상

GRPO에서는 한 질문에 대해 여러 후보 답변을 생성하고, 각 후보의 보상을 같은 그룹 평균과 분산에 비추어 상대적으로 정규화한다. 그 뒤 높은 상대 보상을 받은 응답의 확률을 높이되 기준 정책에서 지나치게 멀어지지 않도록 KL 항을 둔다. R1-Zero의 핵심 보상은 수학 정답이나 코드 테스트처럼 자동으로 판정할 수 있는 정확도 보상과 출력 형식을 지켰는지 확인하는 형식 보상이었다. 공식 보고서는 대규모 RL 중 보상 해킹과 재학습 비용을 우려해 R1-Zero에 신경망 기반 과정 보상 모델이나 결과 보상 모델을 쓰지 않았다고 설명한다.

이 설계는 ‘논리적 사고’를 직접 측정하는 손실 함수와는 다르다. 정답 검증기는 최종 결과가 맞는지를 확인하지만, 중간 설명이 충실한지 또는 모델 내부 계산을 그대로 드러내는지는 보장하지 않는다. 모델이 더 긴 풀이, 재검토, 전략 전환을 출력하게 됐다는 사실은 관찰 가능한 행동 변화이지만, 이를 별도의 추론 기관이나 인간과 같은 자기 성찰의 증거로 해석해서는 안 된다.

### 4.3 다단계 후훈련은 커리큘럼 학습과 다르다

정식 R1 파이프라인은 대략 네 단계로 구분된다.

1. 사람이 읽기 쉬운 장문 Chain-of-Thought 수천 개를 수집·정제해 DeepSeek-V3-Base를 콜드 스타트 미세조정한다.
2. 코딩·수학·과학·논리처럼 답을 비교적 명확히 검증할 수 있는 과제에 추론 중심 강화학습을 적용한다.
3. 강화학습 체크포인트의 출력을 거부 샘플링으로 선별하고, 비추론 데이터와 합쳐 약 80만 개 샘플을 구성해 다시 지도 미세조정한다.
4. 추론 과제의 규칙 기반 보상과 일반 과제의 도움성·무해성 선호 보상을 함께 사용해 두 번째 강화학습을 수행한다.

단계가 여러 개라는 사실만으로 커리큘럼 학습이라고 부를 수는 없다. 커리큘럼 학습은 보통 쉬운 예제에서 어려운 예제로 난이도나 데이터 분포를 계획적으로 바꾸는 절차를 뜻한다. 공식 R1 보고서는 난이도를 점진적으로 높인 커리큘럼을 핵심 방법으로 제시하지 않는다. 마찬가지로 ‘특화 추론 모듈’, ‘개선된 메모리 메커니즘’, ‘추론 전용 손실 함수’도 보고된 구성요소가 아니다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. **문제 제기**: 고급 추론은 거대한 모델과 막대한 계산 자원에 의존해 접근성이 낮다.
2. **핵심 아이디어**: 크기를 늘리는 대신 구조와 특화 훈련을 개선하면 더 작은 모델도 강한 추론을 할 수 있다.
3. **방법 또는 구조**: 개선된 어텐션, 특화 추론·메모리 모듈, 커리큘럼 학습, 특수 손실과 최적화를 결합했다고 서술한다.
4. **결과 또는 주장**: 제한된 자원으로 더 큰 모델과 경쟁했으며 엣지·모바일 배포와 연구 민주화를 촉진했다고 주장한다.
5. **의의와 한계**: 규모만이 답이 아니라는 교훈을 강조하면서도 일부 과제에는 큰 모델이 유리하다고 인정한다.

문제의식 자체는 유효하지만, 2단계에서 4단계로 넘어가는 구체적 설명이 공식 자료와 크게 어긋난다. 공식 근거가 지지하는 축은 ‘작은 R1 본체의 새 아키텍처’가 아니라 ‘대형 MoE 기반 모델의 강화학습 후훈련’과 ‘그 출력의 소형 모델 증류’다. 따라서 원문의 영향·모바일 배포·타 분야 전파 주장은 이 두 축을 분리한 뒤 별도로 검증해야 한다.

## 6. 왜 중요한가

DeepSeek-R1이 중요한 첫 번째 이유는 사람의 정답 풀이 시연을 먼저 제공하지 않은 R1-Zero 실험에서, 검증 가능한 결과 보상만으로 장문 풀이와 재검토 행동이 강화될 수 있음을 공개적으로 보여 주었다는 점이다. 두 번째 이유는 순수 RL의 성공만 강조하지 않고, 가독성과 일반 능력을 위해 콜드 스타트 SFT와 데이터 정제를 다시 결합했다는 점이다. 이는 지도학습과 강화학습 중 하나를 택하는 단순 대립보다, 각 단계가 서로 다른 실패를 보완한다는 실제적인 교훈을 준다.

특히 중요한 점:

- **훈련 단계의 분해**: R1-Zero와 R1을 나눠 순수 RL에서 나타난 이점과 실패를 비교할 수 있게 했다.
- **검증 가능한 보상의 확장**: 수학 정답과 코드 실행처럼 자동 판정이 가능한 영역에서 대규모 RL이 장문 추론 행동을 강화할 수 있음을 보였다.
- **증류의 실용성**: 큰 모델에서 발견된 풀이 패턴을 Qwen·Llama 기반 작은 조밀 모델에 전달했으며, 공식 32B 비교에서는 작은 기반 모델에 직접 RL을 적용한 경우보다 증류가 더 강했다.
- **공개 연구 기반**: 보고서, 가중치, 여섯 개 증류 체크포인트를 공개해 폐쇄형 추론 모델보다 후속 검증과 파생 연구가 쉬워졌다.

동시에 이 결과는 규모의 종말을 뜻하지 않는다. 공식 보고서 자체도 작은 32B 모델에 대규모 RL을 직접 적용하는 데 막대한 계산이 들고 증류보다 성능이 낮았으며, 새로운 성능 경계를 넘으려면 더 강한 기반 모델과 더 큰 강화학습이 여전히 필요할 수 있다고 결론짓는다.

## 7. 현대 LLM과의 연결

- **Chain-of-Thought와 추론 시점 계산**: [[080_Chain-of-Thought Prompting Unlocking Latent Reasoning in Language Models|Chain-of-Thought]]가 프롬프트 예시로 중간 풀이를 끌어냈다면, R1은 후훈련으로 긴 풀이를 생성하는 정책 자체를 강화했다. 더 오래 생성하고 여러 답을 샘플링해 다수결하면 성능이 오를 수 있지만, 지연 시간과 출력 토큰 비용도 함께 증가한다.
- **RLHF와 검증 가능한 보상 강화학습**: [[056_RLHF Foundations Learning from Human Preferences in Reinforcement Learning|RLHF]]와 [[077_InstructGPT and RLHF Aligning Language Models with Human Preferences|InstructGPT]]는 주로 인간 선호를 모델링한 보상으로 도움성과 안전성을 조정했다. R1의 추론 단계는 정답·테스트 케이스처럼 자동 확인되는 보상을 중심으로 하며, 마지막 일반 정렬 단계에서는 선호 보상을 다시 결합한다. 오늘날에는 전자를 RLVR(Reinforcement Learning with Verifiable Rewards)라고 구분해 부르기도 한다.
- **희소 MoE와 계산 효율**: [[103_Mixture of Experts at Scale Efficient Scaling Through Sparse Activation and Dynamic Routing|대규모 희소 MoE]]는 전체 용량과 토큰당 계산량을 분리한다. R1의 671B 전체·37B 활성 구조는 바로 이 장점을 사용하지만, 전체 가중치의 저장·분산 실행·통신 비용까지 37B 조밀 모델과 같아지는 것은 아니다.
- **지식 증류와 공개 소형 모델**: R1-Distill-Llama 체크포인트는 [[089_LLaMA Meta's Open Foundation Models That Democratized Language AI Research|LLaMA]], 다른 체크포인트는 Qwen 계열을 기반으로 한다. 강한 교사 모델의 출력 궤적이 작은 학생 모델의 학습 데이터가 될 수 있음을 보여 주지만, 학생 모델이 교사의 구조나 전체 능력을 그대로 복제하는 것은 아니다.
- **에이전트와의 구분**: [[104_Agentic AI Systems Autonomous Agents with Reasoning, Planning, and Tool Use|에이전트 시스템]]은 추론 외에도 환경 관찰, 도구 호출, 상태 관리, 실행 결과 피드백이 필요하다. R1이 긴 풀이를 생성한다는 사실만으로 자율 에이전트나 신뢰할 수 있는 계획 실행기가 되는 것은 아니다.

## 8. 한계와 비판적 관점

- **기술적 한계**: 정식 R1은 전체 671B 매개변수의 대형 MoE다. 희소 활성화는 토큰당 계산을 낮추지만 전체 가중치 저장, 여러 장치에 걸친 통신, 긴 출력의 KV 캐시와 지연을 없애지 않는다. R1-Zero는 반복·가독성 저하·언어 혼합을 보였고, 정식 R1도 프롬프트 형식과 언어에 민감할 수 있다.
- **이론적 한계**: 정답 보상으로 강화된 장문 출력이 충실한 내부 추론 기록이라는 보장은 없다. 재검토나 ‘아하 순간’ 같은 문구는 모델의 출력 행동을 기술하는 표현이지, 주관적 자각이나 인간과 같은 메타인지의 증거가 아니다.
- **평가 한계**: AIME, MATH-500, GPQA Diamond, LiveCodeBench, Codeforces 같은 벤치마크는 중요한 검증 가능 과제를 측정하지만 추론 능력 전체를 대표하지 않는다. 샘플링 설정, 최대 생성 길이, 다수결 여부가 결과를 바꾸므로 단일 수치만으로 모델의 절대 우위를 말하기 어렵다.
- **실용적 한계**: R1의 강한 결과에는 긴 추론과 반복 샘플링이 포함될 수 있어 비용·지연·에너지 사용이 커진다. 작은 증류 모델은 배포 선택지를 넓히지만, 이것이 정식 R1을 엣지나 모바일에서 실행할 수 있다는 뜻은 아니다.
- **재현 한계**: 공식 저장소는 모델 가중치와 보고서를 공개하지만 전체 사전학습 데이터, 후훈련 데이터 생성·필터링 세부, 대규모 학습 인프라를 완전한 재현 패키지로 제공하지는 않는다. ‘공개 가중치’와 ‘처음부터 완전 재현 가능한 훈련’을 구분해야 한다.
- **오늘날 관점에서 다시 봐야 할 점**: 원문은 R1에서 새로 개발된 구조와 V2/V3에서 상속된 MLA·MoE, R1 본체와 증류 모델, 훈련 효율과 배포 효율을 한데 섞는다. 이 경계를 나누면 R1의 실제 공헌과 한계가 더 선명해진다.

주요 주장별 검증 경계는 다음과 같다.

| 원문의 주장 | 공식 자료가 확인하는 범위 | 검증되지 않거나 수정이 필요한 부분 |
|---|---|---|
| 하드웨어 제약 때문에 R1의 매개변수 수가 더 작았다. | 정식 R1은 DeepSeek-V3-Base 기반의 671B MoE이며 토큰당 37B가 활성화된다. | R1 본체가 경쟁 모델보다 작은 총매개변수를 가졌다는 주장과 하드웨어 제약이 크기를 제한했다는 인과 |
| 개선된 어텐션이 R1의 추론을 가능하게 했다. | 기반 V3는 MLA를 사용한다. | MLA는 V2/V3에서 이미 검증된 구조이며, R1 보고서는 추론용 새 어텐션을 핵심 공헌으로 제시하지 않는다. |
| 특화 추론 모듈과 메모리 모듈을 넣었다. | 긴 출력, 재검토, 자기 검증 같은 행동이 RL 중 관찰됐다. | 별도 추론·메모리 모듈의 구조, 위치, 학습법은 공식 보고서에 제시되지 않는다. |
| 커리큘럼 학습으로 난이도를 점차 높였다. | R1은 콜드 스타트, 추론 RL, SFT, 정렬 RL의 다단계 파이프라인을 쓴다. | 과제 난이도를 계획적으로 높이는 커리큘럼은 핵심 방법으로 보고되지 않았다. |
| 특수 손실이 논리적 일관성을 직접 학습시켰다. | GRPO 목적과 정확도·형식·선호 보상이 사용됐다. | 논리적 일관성을 직접 측정하는 별도 손실이나 과정 전체의 참됨을 보장하는 손실은 보고되지 않았다. |
| 더 작은 R1이 더 큰 모델을 능가했다. | 1.5B–70B 증류 모델이 강한 벤치마크 결과를 냈고, 32B·70B는 여러 지표에서 o1-mini와 경쟁했다. | 정식 R1은 671B이며, 비공개 경쟁 모델과는 총매개변수·훈련량을 직접 비교할 수 없다. |
| 제한된 자원으로 훈련·모바일 배포가 가능하다. | 공개 증류 모델은 더 작은 배포 선택지를 제공한다. | 정식 R1의 후훈련 계산량은 상세 공개되지 않았고, 엣지·모바일 실증은 원문에 제시되지 않았다. |
| R1의 모듈이 비전·멀티모달 모델로 확산됐다. | R1식 검증 보상과 증류에 영감을 받은 후속 연구가 가능하다. | 특정 모듈의 직접 전파나 분야별 인과 영향은 공식 R1 자료로 입증되지 않는다. |

검증할 때는 [DeepSeek-R1 논문](https://arxiv.org/abs/2501.12948), [DeepSeek-R1 공식 저장소](https://github.com/deepseek-ai/DeepSeek-R1), [2025년 1월 공식 출시 공지](https://api-docs.deepseek.com/news/news250120)를 우선 읽는 것이 좋다. 기반 구조는 [DeepSeek-V3 논문](https://arxiv.org/abs/2412.19437)과 [DeepSeek-V3 공식 저장소](https://github.com/deepseek-ai/DeepSeek-V3)에서 별도로 확인해야 한다. 이 구분은 R1의 후훈련 공헌을 축소하는 것이 아니라, 어떤 혁신이 어느 모델 세대에서 나왔는지를 정확히 배치하기 위한 것이다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| DeepSeek-R1-Zero | DeepSeek-V3-Base에 사전 SFT 없이 추론 중심 GRPO를 직접 적용한 실험 모델 |
| DeepSeek-R1 | 콜드 스타트 데이터와 두 번의 SFT·두 번의 RL 단계를 결합한 정식 추론 모델 |
| GRPO | 같은 질문에서 생성한 응답 그룹의 상대 보상을 이용해 정책을 갱신하는 강화학습 알고리즘 |
| 검증 가능한 보상 | 수학 정답, 코드 테스트, 출력 형식처럼 프로그램이나 규칙으로 판정할 수 있는 보상 |
| 콜드 스타트 데이터 | 불안정한 순수 RL 시작점을 피하고 읽기 쉬운 추론 형식을 심기 위해 먼저 사용하는 소량의 고품질 예시 |
| 거부 샘플링 | 여러 생성 결과 가운데 정답성·가독성·형식 기준을 만족한 응답만 후속 학습 데이터로 고르는 절차 |
| 지식 증류 | 큰 교사 모델의 출력이나 분포를 이용해 작은 학생 모델의 능력을 학습시키는 방법 |
| 활성 매개변수 | 희소 MoE에서 한 토큰을 처리할 때 실제로 선택돼 계산에 참여하는 매개변수 부분 |
| 추론 시점 계산 | 훈련이 끝난 뒤 답을 생성할 때 더 긴 풀이, 더 많은 샘플, 탐색·검증에 추가로 쓰는 계산량 |

## 12. 짧은 결론

DeepSeek-R1은 작은 특화 아키텍처가 규모를 대체했다는 사례라기보다, 거대한 희소 MoE 기반 모델에서 대규모 강화학습으로 추론 행동을 유도하고 콜드 스타트·데이터 정제·두 번째 정렬 단계로 이를 실용화한 사례다. 소형화의 성과는 R1 본체가 아니라 Qwen·Llama 기반 증류 체크포인트에서 확인된다. 그러므로 R1의 역사적 위치는 ‘새 추론 모듈의 발명’보다 ‘검증 가능한 보상, 다단계 후훈련, 공개 가중치, 지식 증류를 한 계보 안에서 연결한 공개 추론 모델’로 정리하는 편이 정확하다.

# 신경 확률 언어 모형: 분산 단어 표현과 신경 언어 모델링

출처: https://mbrenndoerfer.com/writing/neural-probabilistic-language-model-distributed-word-representations-neural-language-modeling

---

Yoshua Bengio의 획기적인 2003년 신경 확률 언어 모형이 조밀한 연속 단어 임베딩을 학습해 NLP를 바꾼 과정을 살펴본다. 분산 표현이 의미 관계를 포착하고 전이 학습을 가능하게 하며 현대의 word2vec, GloVe와 Transformer 모형의 기반을 마련한 방식을 알아본다.

## 2003년: 신경 확률 언어 모형

2000년대 초 자연어 처리는 수십 년 동안 지배해 온 통계적 접근의 근본 한계를 인식하기 시작한 중요한 분기점에 있었다. n-gram 통계에 기반한 전통적 언어 모형은 합리적인 성능을 얻었지만 해결하기 어려워 보이는 약점을 안고 있었다. 이 모형은 단어를 이산적이고 원자적인 항목으로 다뤄 사람이 직관적으로 이해하는 의미 관계를 포착하기 어려웠다. `hot dog` 같은 구를 만나도 `dog`가 동물이 아니라 음식을 가리킨다는 사실을 알 방법이 없었다. 단어의 모든 출현을 문맥과 무관하게 같은 항목으로 처리했기 때문이다.

Yoshua Bengio와 몬트리올 대학교의 동료들은 이산 표현 패러다임이 언어 모델링의 진전을 막는 핵심 제약이라고 보았다. 2003년 그들은 자연어 처리 역사에서 매우 영향력 있는 논문이 된 「A Neural Probabilistic Language Model」을 발표했다. 논문은 신경망이 오늘날 단어 임베딩이라 부르는 조밀하고 연속적인 단어 벡터를 학습해 의미 관계를 포착하고 언어 모델링 성능을 개선할 수 있음을 보여주었다. 이 연구는 현대 단어 임베딩과 딥러닝 NLP 접근의 기반을 세우고 이후 수십 년 동안 분야를 바꿀 신경 혁명을 예고했다.

모형의 핵심 혁신은 각 단어에 조밀한 연속 벡터인 분산 표현을 학습해 기하적 성질로 의미 유사성을 담는 것이었다. 단어를 one-hot 벡터나 색인으로만 나타내는 전통적 방식과 달리, Bengio의 모형은 비슷한 뜻의 단어들이 임베딩 공간에서 자연스럽게 모이도록 학습했다. `king`은 `chair`보다 `queen`에 기하적으로 가까운 벡터를 가질 수 있었지만 n-gram 모형은 세 단어를 완전히 다른 항목으로 다뤘다. 이 돌파구는 신경 접근이 n-gram보다 나은 성능을 얻으면서 현대 NLP의 중심이 될 의미 있는 표현도 학습할 수 있음을 보여주었다.

## 문제: n-gram 모형의 한계

오랫동안 지배적이었던 전통 언어 모델링은 학습 자료에서 출현 횟수를 세어 문맥이 주어졌을 때 단어의 확률을 추정하는 n-gram 모형에 의존했다. 다음 단어를 예측할 때 앞선 $n-1$개 단어를 보고 각 후보가 그 문맥 뒤에 얼마나 자주 나타났는지를 센다. 예를 들어 trigram은 앞의 두 단어로 세 번째를 예측하고 $P(\text{word}_3\mid\text{word}_1,\text{word}_2)$ 같은 확률을 학습 자료의 횟수로 계산한다.

이 모형은 각 단어를 고유한 색인이나 one-hot 벡터로 나타내는 이산 희소 표현을 사용했다. 어휘가 100,000개라면 각 단어는 해당 위치 하나만 1이고 나머지는 0인 100,000차원 벡터가 된다. 이런 표현은 단어 유사성을 담지 못한다. `cat`과 `dog`는 여러 의미 속성을 공유하지만 완전히 다른 항목으로 처리되고, 유의어에 가까운 `happy`와 `joyful`도 무관한 것으로 취급된다.

차원의 저주는 n-gram 모형의 근본 난제였다. 문맥 창이 늘면 가능한 n-gram 조합 수가 지수적으로 증가한다. 어휘가 10,000개인 trigram은 가능한 조합이 $10{,}000^3=10^{12}$개다. 큰 학습 말뭉치에서도 대부분의 trigram은 한 번도 나타나지 않아 모형이 많은 유효 단어열에 대한 정보를 갖지 못하는 데이터 희소성이 생긴다. n이 커질수록 문제가 더 심해져 장거리 의존성을 모델링하기 어렵다.

또한 n-gram은 단어 사이 의미 관계를 포착하지 못한다. 비슷한 뜻의 단어도 다른 항목이므로 한 단어에서 배운 것을 의미적으로 가까운 단어에 일반화할 수 없다. 학습 자료에 `I like cats`는 있지만 `I like dogs`가 없다면, 두 동물이 이 문맥에서 비슷한 역할을 해도 후자의 확률을 0 또는 매우 낮게 줄 수 있다. 이런 일반화 부족은 희귀 단어, 어휘 밖 단어와 새로운 단어 조합을 처리하는 능력을 제한했다.

이 한계 때문에 n-gram은 합리적 성능을 위해 막대한 학습 자료가 필요했고 보지 못한 단어열의 일반화에도 어려움을 겪었다. 단어 사이 의미 관계를 포착하고 데이터에서 더 일반화 가능한 패턴을 학습하는 근본적으로 다른 접근이 필요하다는 인식이 커졌다.

## 해법: 분산 단어 표현

신경 확률 언어 모형은 현대 NLP의 기반이 될 몇 가지 혁신으로 이 문제를 다뤘다. 첫째, 어휘의 각 단어를 고차원 공간의 조밀한 연속 벡터에 대응시키는 분산 표현을 학습했다. 이 단어 벡터, 즉 임베딩은 기하적 성질로 의미 관계를 담을 수 있었다. 비슷한 뜻의 단어는 비슷한 벡터를 갖고 의미 관계는 임베딩 공간의 기하 관계로 표현될 수 있었다. 둘째, 문맥에서 다음 단어의 확률을 계산하는 신경망을 사용해 n-gram이 담기 어려운 복잡한 비선형 관계를 학습했다.

### 분산 표현의 혁명

이산 표현에서 분산 표현으로의 이동은 NLP에서 가장 중요한 개념적 진전 가운데 하나였다. 단어를 내부 구조가 없는 원자적 항목으로 다루지 않고 의미 구성 요소를 공유하게 했다. 단어의 뜻이 비슷하면 임베딩 공간에서 벡터가 비슷한 방향을 가리킨다. 이처럼 의미를 기하적으로 해석하는 관점은 word2vec부터 Transformer까지 현대 언어 모형의 중심이 되었다.

신경 확률 언어 모형은 단어 표현과 언어 모델링을 함께 학습하는 여러 구성 요소로 이루어졌다. 입력층은 문맥 창의 각 단어를 미리 정한 값이 아니라 학습되는 단어 벡터로 바꿨다. 이 벡터들을 이어 붙여 전체 문맥을 나타내는 하나의 벡터를 만들었다. 문맥이 네 단어이고 각 단어 벡터가 100차원이면 이어 붙인 문맥 벡터는 400차원이다.

문맥 벡터는 하나 이상의 신경망 은닉층을 통과해 전체 어휘에 대한 확률분포로 변환됐다. 은닉층은 단순 계수 방식이 나타내지 못하는 단어 사이의 복잡한 비선형 상호작용을 포착할 수 있었다. 출력층은 softmax를 사용해 모든 단어 확률의 합이 1인 올바른 확률분포를 만들었다. 역전파로 학습 자료의 가능도를 최대화하면서 단어 벡터와 신경망 가중치를 동시에 조정했다.

핵심 통찰은 단어 벡터를 언어 모형의 매개변수와 공동 학습해 언어 모델링 과제에 적합한 표현을 발견한다는 것이었다. 이렇게 학습한 벡터에는 학습 자료의 의미 관계, 통사 패턴과 다른 언어 규칙성이 담길 수 있었다. 학습된 표현은 다른 과제에도 사용할 수 있어 언어 모델링 과정의 가치 있는 부산물이 되었다.

## 영향과 능력

분산 표현을 학습하는 능력은 자연어 처리에 깊은 영향을 주었다. 각 단어를 별도 이산 항목으로 보는 n-gram과 달리 신경 모형은 벡터를 통해 단어 유사성을 포착했다. 비슷한 뜻의 단어는 비슷한 벡터를 가지므로 알려진 단어 사이 유사성을 활용해 보지 못한 단어열로 일반화할 수 있었다. 이는 n-gram의 큰 한계였던 희귀 단어와 어휘 밖 단어를 다루는 데 특히 중요했다.

모형은 전통 통계 방법으로 표현하기 어려운 복잡한 비선형 단어 관계를 신경망이 학습할 수 있음도 보여주었다. 은닉층은 단순 동시출현을 넘어 정교한 방식으로 단어 벡터를 결합할 수 있었다. 덕분에 더 적은 매개변수와 학습 자료로도 n-gram보다 나은 성능을 얻을 수 있었고, 자주 나타나지 않은 조합도 임베딩의 의미 유사성을 활용해 그 가능성을 학습할 수 있었다.

## 유산과 영향

신경 확률 언어 모형의 성공은 이후의 많은 자연어 처리 접근에 영향을 주었다. 분산 단어 표현 학습은 현대 NLP의 중심이 되어 2013년 word2vec, 2014년 GloVe와 다른 임베딩 기법으로 직접 이어졌다. 그 신경망 구조는 순환 신경망, LSTM, 그리고 오늘날 대규모 언어 모형을 구동하는 Transformer의 발전에도 영향을 주었다.

이 모형은 오늘날에도 중요한 신경 언어 모형 학습 원칙을 세웠다. 역전파로 종단 간 모형을 학습하고, 단어 표현과 모형 매개변수를 공동 학습하며, 신경망으로 복잡한 단어 관계를 포착하는 방식은 현대 NLP의 표준이 되었다. 그 성공은 신경 접근이 언어 모델링과 다른 NLP 과제에서 전통 통계 방식보다 효과적일 수 있음을 보여주어 2010·2020년대 신경 혁명의 초기 증거가 되었다.

분산 표현의 중요성은 기계학습과 AI 전반에도 영향을 주었다. 복잡한 개념을 고차원 공간의 조밀한 벡터로 나타내고 데이터에서 자동 학습한다는 생각은 현대 기계학습의 기본 원리가 되었다. 컴퓨터 비전, 음성 인식과 다른 AI 영역에도 영향을 주었고, 이미지 임베딩부터 추천 시스템의 사용자 임베딩까지 학습된 임베딩이 널리 쓰이게 됐다.

### 언어 모델링에서의 전이 학습

신경 확률 언어 모형의 중요한 기여 가운데 하나는 언어 모델링에서 배운 단어 표현을 다른 과제에 재사용할 수 있음을 보여준 것이다. 학습된 단어 표현은 품사 태깅, 개체명 인식, 감성 분석 같은 후속 과제의 입력 특징으로 사용할 수 있었다. 이런 전이 학습은 많은 비표지 텍스트에서 배운 지식을 표지 자료가 적은 과제에 활용해 여러 NLP 과제의 성능을 크게 높일 수 있게 했다. 한 과제에서 표현을 사전 학습하고 다른 과제에 맞춰 미세조정하는 원리는 초기 단어 임베딩에서 BERT와 GPT까지 현대 NLP의 중심이 됐다.

신경 확률 언어 모형은 NLP 전이 학습의 발전에도 영향을 주어 표준이 될 패턴을 확립했다. 언어 모델링에서 유용한 표현을 학습함으로써 많은 비표지 말뭉치의 사전 학습이 표지 자료가 제한된 지도 과제에 가치 있는 특징을 줄 수 있음을 보여주었다. 이 접근은 후대에 크게 정교해지고 확장되어 현대 NLP를 지배하는 사전 학습–미세조정 패러다임으로 이어졌다.

모형의 성공은 신경 언어 모형에 충분한 계산 자원과 학습 자료가 중요함도 보여주었다. 학습에는 상당한 계산 자원이 필요했고 더 큰 자료에서 성능이 개선됐다. 이 통찰은 방대한 데이터와 계산으로 최고 성능을 얻는 현대 대규모 언어 모형의 발전에 영향을 주었다. Bengio의 모형이 암시한 모형 크기·자료 규모·성능의 관계는 후대에 scaling law로 정식화되어 더 큰 언어 모형 개발의 중심 원리가 됐다.

## 한계와 도전

획기적인 기여에도 신경 확률 언어 모형에는 후속 연구가 다룬 여러 한계가 있었다. 특히 어휘가 크면 계산 복잡도가 높았다. 전체 어휘 softmax는 모든 단어의 확률을 계산해야 하므로 학습과 추론 비용이 컸다. 문맥 창은 고정되고 비교적 짧아 긴 의존성을 포착하는 능력이 제한됐다. 초기화와 hyperparameter 조정도 주의가 필요했고 2003년 하드웨어에서 학습은 느렸다.

모형은 고정 어휘를 사용했으므로 어휘 밖 단어에도 약했다. 학습 자료에 없는 희귀 단어나 신조어는 모형이 전혀 알 수 없었다. 후대에는 단어를 학습하고 다시 조합할 수 있는 더 작은 단위로 나누는 BPE와 SentencePiece 같은 subword tokenization이 이 한계를 다뤘다.

## 결론: 현대 NLP의 토대

신경 확률 언어 모형은 신경망이 의미 있는 표현을 학습하고 전통 통계 방법보다 나은 성능을 얻을 수 있음을 보여준 자연어 처리와 AI 역사의 중요한 이정표다. 분산 단어 표현, 언어 모델링 신경망과 표현·모형의 공동 학습은 현대 NLP의 기반 원리가 되었다.

이 연구는 후대의 신경 혁명을 예고하고 word2vec, GloVe, BERT, GPT와 다른 고급 NLP 시스템으로 이어질 원리를 확립했다. 후속 모형은 2003년에 가능했던 규모를 크게 넘어 구조를 정교하게 만들었지만, 단어를 이산 색인보다 학습된 조밀 벡터로 나타내야 한다는 Bengio 등의 핵심 통찰은 모든 현대 언어 모형의 중심에 남았다. 신경 확률 언어 모형은 신경 접근이 전통 방법을 능가하면서 인간 언어의 의미적 풍부함을 포착하는 표현을 학습할 수 있음을 보여주어 앞으로의 길을 제시했다.

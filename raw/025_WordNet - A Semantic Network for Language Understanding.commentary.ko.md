# WordNet과 관계 기반 어휘 의미 해설

## 1. 한눈에 보기

- 핵심 주제: 영어 단어를 표제어 하나당 정의 하나로 저장하지 않고, **단어 형식–단어 의미–동의어 집합(synset)**을 구분한 뒤 의미 사이의 관계를 연결한 WordNet
- 등장 배경: 인간의 어휘 기억에 관한 심리언어학적 문제의식, 기계가 조회할 수 있는 영어 어휘 자원, 1980년대 중반부터 이어진 프린스턴 대학교의 수작업 편찬
- 가장 중요한 아이디어: 다의어의 각 의미를 별도 synset으로 구분하고, 상·하위 관계와 부분–전체 관계처럼 종류가 명시된 포인터로 어휘 의미의 구조를 표현한다.
- 이후 LLM/NLP에 남긴 영향: 영어 어휘 의미의 공용 식별 체계와 평가 자원, 설명 가능한 어휘 관계 조회, 지식 기반 WSD·검색 확장·의미 유사도 연구의 기반

> 이 문서는 `025_WordNet - A Semantic Network for Language Understanding.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 WordNet의 실제 자료 구조와 역사적 위치를 설명하고, 1995년 단일 공개 서사, 자동차 예시, 응용 성능, 임베딩·지식 그래프·BERT로 이어지는 직접 계보처럼 근거가 더 필요한 주장을 분리합니다.

## 2. 핵심 요약

WordNet은 영어의 명사·동사·형용사·부사를 **인지적 동의어 집합(cognitive synonyms)**인 synset으로 묶고, synset 또는 개별 단어 의미 사이를 의미·어휘 관계로 연결한 전자 어휘 데이터베이스다. 같은 철자의 단어라도 의미가 다르면 서로 다른 synset에 속하므로, `bank`의 금융 기관 의미와 강둑 의미를 별도 노드처럼 다룰 수 있다. 명사에서는 상위어·하위어와 부분–전체 관계가 두드러지고, 동사에서는 행동의 더 구체적인 방식을 나타내는 troponymy와 함의 관계가 중요하다. 형용사와 부사는 명사와 똑같은 분류 트리로 구성되지 않으며, 반의·유사·파생 관계를 중심으로 별도의 조직 원리를 갖는다.

WordNet의 가치는 “컴퓨터가 뜻을 이해했다”는 데 있지 않다. 더 정확히는 어휘 편찬자가 구분한 의미 목록, 짧은 풀이(gloss), 용례, 관계 포인터를 프로그램이 반복해서 조회할 수 있게 했다는 데 있다. 이를 실제 WSD, 정보 검색, 기계 번역, 질의 응답에 쓰려면 문맥에서 어느 의미를 선택할지, 어떤 관계를 얼마나 확장할지, 결과를 어떻게 점수화할지를 정하는 별도 알고리즘과 평가가 필요하다. WordNet 사용이 곧 성능 향상을 보장하지 않으며, 지나친 질의 확장은 오히려 정밀도를 낮출 수 있다.

또한 WordNet은 1995년에 처음 한 번 공개된 산물이 아니다. 프로젝트는 1985년에 시작됐고, 1990년대 초 논문과 배포판이 이미 존재했으며, 1995년은 널리 알려진 CACM 논문과 WordNet 1.5의 시점으로 읽는 편이 정확하다. WordNet의 설계가 심리언어학 이론에서 영감을 받은 것은 확인되지만, 인간 의미 기억을 완전하거나 가장 충실하게 모사했다는 실증 결론과는 다르다.

WordNet과 Word2Vec·GloVe·BERT는 모두 단어 사이의 관계를 다룬다는 넓은 공통점이 있다. 그러나 WordNet은 사람이 명시적으로 관계를 편찬한 이산적 그래프이고, 임베딩과 문맥 언어 모델은 말뭉치의 통계 패턴에서 연속 벡터를 학습한다. 후자의 직접 조상으로 WordNet을 놓기보다는, 서로 다른 계보의 표현 방식이 이후 지식 주입·retrofitting·평가에서 만났다고 보는 것이 안전하다.

- 무엇을 다루는가: WordNet의 역사, synset과 다의성, 품사별 관계 구조, NLP 응용, 수작업 어휘 자원의 한계
- 어떤 문제를 해결하려 했는가: 인쇄 사전의 사람 중심 배열을 넘어 단어 형식과 의미, 의미 관계를 프로그램이 조회할 수 있게 하는 문제
- 어떤 방식이 새로웠는가: 대규모 영어 어휘를 synset과 종류가 명시된 관계 포인터의 네트워크로 구현하고 공개 연구 자원으로 배포한 점
- 결과적으로 무엇을 바꾸었는가: 서로 다른 연구가 공통 의미 목록과 관계를 참조하고, 지식 기반 의미 처리 방법을 재현·비교할 수 있는 기반을 제공한 점

## 3. 역사 배경

WordNet은 1980년대의 전자 사전 하나를 그래프로 바꾼 단순한 프로젝트가 아니었다. George A. Miller 연구진은 사람이 단어를 어떻게 저장하고 찾아내는지에 관한 심리언어학적 가설을 계산 가능한 어휘 자원으로 옮기려 했다. 전통 사전은 철자 순으로 표제어를 찾고 정의를 읽는 사람에게 맞춰져 있었지만, 프로그램은 한 단어의 여러 의미를 구분하고 각 의미와 관련된 다른 의미를 일정한 형식으로 조회할 필요가 있었다. WordNet은 이 문제를 단어 형식과 단어 의미를 나누고, 의미를 synset으로 묶고, 관계를 포인터로 기록하는 방식으로 다뤘다.

연대는 다음처럼 나누어 읽어야 한다.

1. **1985년**: 프린스턴 WordNet 프로젝트가 시작됐다. 프린스턴 FAQ는 Brown Corpus의 어휘와 품사별 빈도 자료에서 작업을 시작했다고 설명한다.
2. **1990년**: Miller·Beckwith·Fellbaum·Gross·Katherine J. Miller의 *Introduction to WordNet: An On-line Lexical Database*가 *International Journal of Lexicography* 특별호에 실렸다. 이는 완성 뒤의 회고가 아니라 당시 자원의 설계와 공개 상태를 보여 주는 초기 보고다.
3. **1992년**: Miller의 HLT 논문이 WordNet을 영어 어휘 데이터베이스로 보고했고, 후속 1993년 프로젝트 보고서는 WordNet 1.3이 1992년 12월 9일 공개됐다고 명시한다.
4. **1993년**: 8월에 WordNet 1.4가 공개됐다. 버전이 연속적으로 갱신됐다는 사실만으로도 1995년 단일 릴리스 서사는 성립하지 않는다.
5. **1995년**: WordNet 1.5가 배포되고 Miller의 CACM 소개 논문이 출판됐다. 이 해는 중요한 확산 시점이지만 “WordNet 최초 공개”와 같지 않다.
6. **1998년**: WordNet 1.6과 Fellbaum이 편집한 MIT Press 단행본을 구분해 볼 수 있다. 이후 버전과 다국어 wordnet 프로젝트가 구조와 응용 범위를 넓혔다.

당시 통계적 NLP가 성장하고 있었던 것은 맞지만, WordNet을 “빈도만 아는 통계 모델에 의미를 공급해 규칙을 대체한 자원”으로 설명하면 두 계보가 지나치게 정리된다. WordNet 자체가 전문가의 판단으로 만든 상징적·선언적 자원이며, 규칙 기반 방법과 통계 기반 방법 모두에 결합될 수 있었다. Lesk류 WSD처럼 사전 풀이를 이용하는 접근, 말뭉치 빈도와 WordNet 의미 목록을 함께 쓰는 접근, 검색어를 관계어로 확장하는 접근은 서로 다른 처리 알고리즘을 필요로 했다.

- 이전 접근법: 인쇄·기계 판독 사전, 시소러스, 의미망, 선택 제약과 수작업 의미 규칙, Lesk류 사전 기반 중의성 해소
- 당시의 한계: 표제어 중심 사전의 불균일한 내부 구조, 공용 의미 ID의 부족, 의미 관계를 프로그램으로 일관되게 따라가기 어려운 점
- 이 주제가 필요했던 이유: 어휘 의미를 여러 NLP 실험에서 공유하고, 관계 조회와 의미별 평가를 재현할 수 있는 대규모 공개 자원이 필요했기 때문

## 4. 핵심 개념

### 4.1 단어 형식, 단어 의미, synset

WordNet을 이해하려면 **문자열**, **문맥에 따른 단어 의미**, **synset이 나타내는 어휘화된 개념**을 구분해야 한다. `bank`라는 하나의 철자는 여러 의미 항목을 가질 수 있고, 각 의미는 서로 다른 synset에 연결된다. 반대로 `car`, `auto`, `automobile`, `machine`, `motorcar`처럼 특정 의미에서 가까운 여러 단어 형식이 하나의 synset을 이룰 수 있다. synset에는 보통 짧은 정의인 gloss와 용례가 붙는다.

synset의 구성원은 모든 문장에서 완전히 바꿔 쓸 수 있다는 뜻이 아니다. 말투, 시대, 지역, 연어가 다르므로 `car industry`와 `motorcar industry`의 자연스러움은 같지 않다. WordNet의 동의성은 특정 어휘 의미가 같은 개념을 표현한다는 편찬상 판단이며, 모든 용법의 완전한 치환 가능성을 보장하지 않는다.

### 4.2 관계는 종류와 연결 층위가 다르다

원문은 WordNet을 “노드는 개념, 간선은 관계”인 하나의 그래프로 설명한다. 입문용 비유로는 유용하지만 실제 자료는 명사·동사·형용사·부사의 네 하위망으로 나뉘며 품사 사이 포인터는 상대적으로 적다. 또한 관계가 **synset 사이의 의미·개념 관계**인지, **특정 단어 의미 사이의 어휘 관계**인지 구분해야 한다. 예를 들어 상위어·하위어는 synset 사이에 놓이고, 반의 관계는 특정 단어쌍 사이에 놓이는 어휘 관계다. 따라서 반의어 하나를 synset 전체의 정반대 개념으로 자동 확대해서는 안 된다.

| 품사 | 대표적인 조직 원리 | 주의할 점 |
| --- | --- | --- |
| 명사 | 상위어·하위어, 부분·전체, 구성원·집합, 물질·전체 | 여러 상위 경로가 가능해 단순한 한 그루의 트리보다 관계망 또는 DAG에 가깝다. 1990년 보고의 25개 unique beginner와 WordNet 3.0의 단일 `entity` 루트처럼 버전에 따라 최상위 구조도 다르다. |
| 동사 | 더 일반적인 행동과 구체적 수행 방식(troponymy), 함의, 원인 | 명사 synset과 하나의 통합 분류 트리를 이루지 않는다. `whisper`가 `speak`의 구체적 방식이라는 설명은 적절한 예다. |
| 형용사 | 직접·간접 반의, 유사성, 속성, 관련 명사와의 관계 | 명사처럼 `entity`에서 내려오는 상·하위 분류로 조직되지 않는다. `not hot`이 곧 `cold`라는 이항 추론도 성립하지 않는다. |
| 부사 | 반의, 형용사에서의 파생 등 | “수식하는 모든 동사 synset과 연결된다”는 구조가 아니다. 문법적 수식 관계와 WordNet 포인터를 혼동하면 안 된다. |

### 4.3 `car` 예시를 정확히 읽는 법

`car` 예시는 synset과 관계 이동을 설명하기 좋지만, 현실 세계의 상식 문장을 WordNet의 직접 간선처럼 바꾸면 오류가 생긴다. 대표적인 자동차 의미의 synset은 `car/auto/automobile/machine/motorcar`를 포함하며, 그 직접 상위 synset은 보통 `motor vehicle/automotive vehicle`이다. 더 일반적인 `vehicle`은 상위 경로에서 만나는 개념이므로 “car는 vehicle이다”라는 추론은 가능하지만, 두 노드가 언제나 직접 한 간선으로 연결된다고 쓰면 버전과 경로를 생략한 설명이 된다.

`sedan`이나 `coupe`는 자동차의 하위 종류를 보여 줄 수 있다. 반면 원문이 이어 붙인 `compact sedan → mid-size sedan → full-size sedan → Toyota Camry`는 한 방향으로 더 구체화되는 WordNet의 실제 계층이라고 보기 어렵다. compact·mid-size·full-size는 서로 병렬적인 크기 구분이며, 특정 차종명은 일반 영어 어휘 중심의 WordNet에 없는 고유명사일 수 있다. `wheel`과 `engine`이 현실의 자동차 부품이라는 사실도 정확하지만, 특정 WordNet 버전에서 `car` synset의 **직접 part-meronym**인지, 상위 `wheeled vehicle`이나 `motor vehicle`에서 물려받아 탐색되는 관계인지 확인해야 한다. 관계 예시는 반드시 버전, 단어 의미, 직접·간접 경로를 함께 적는 편이 재현 가능하다.

### 4.4 WordNet은 응용 프로그램이 아니라 자원이다

WordNet은 의미 목록과 관계를 제공하지만, 입력 문장을 스스로 해석하거나 번역·검색 결과를 직접 산출하지 않는다.

| 과제 | WordNet이 제공하는 것 | 별도로 필요한 것 |
| --- | --- | --- |
| 단어 의미 중의성 해소 | 후보 의미, gloss, 예문, 의미 관계 | 문맥 특징, 의미 선택 알고리즘, 의미 태깅 말뭉치, 평가 기준 |
| 정보 검색 | 동의어·상위어·하위어 등 확장 후보 | 질의 의도 판단, 관계별 가중치, 색인·순위 함수, 정밀도–재현율 평가 |
| 기계 번역 | 영어 쪽 의미 구분의 기준점 | 대상 언어 어휘와 의미 정렬, 병렬 자료, 번역 모델, 문맥에 맞는 표현 생성 |
| 의미 유사도 | 그래프 경로와 공통 상위 개념 | 경로의 의미, 깊이·정보량 추정, 품사와 버전 통제, 사람 판단과의 검증 |

WordNet을 사용했다는 사실만으로 성능 향상을 말할 수 없다. 예를 들어 검색어를 모든 상·하위어로 넓히면 재현율은 오를 수 있지만 질의 주제가 흐려져 정밀도가 떨어질 수 있다. WSD에서는 세밀한 의미 목록이 표현력을 높이는 동시에 학습 자료 부족과 의미 구분 난도를 키운다. 기계 번역에서는 영어 단일 언어 WordNet만으로 번역 대응어가 생기지 않으며, EuroWordNet·BabelNet 같은 별도의 다국어 정렬이 필요하다.

## 5. 논리 구조

원문은 대략 다음 흐름으로 전개된다.

1. **등장 서사**: 1995년 프린스턴이 WordNet을 공개해 고립된 사전 정의를 관계망으로 바꿨다고 소개한다.
2. **인지적 동기**: 사람이 단어를 정의 목록이 아니라 개념적 군집과 연상망으로 기억한다는 설명을 설계 근거로 제시한다.
3. **자료 모델**: synset, 다의성, 상위어·하위어, 부분·전체, 반의, troponymy, 함의를 설명한다.
4. **품사별 구조**: 명사·동사·형용사·부사가 서로 다른 관계로 조직된다고 서술한다.
5. **응용 확대**: WSD, 정보 검색, 분류, 기계 번역, 질의 응답, 의미 유사도에서의 사용 가능성을 제시한다.
6. **방법론적 전환**: 절차적 규칙 대신 선언적 의미 지식을 조회하는 방식이 규칙·통계 NLP를 보완했다고 주장한다.
7. **한계와 후대 계보**: 수작업 편찬, 영어 중심성, 이산 관계, 의미 단위의 세분성, 합성성 부족을 짚은 뒤 지식 그래프·임베딩·BERT로 유산을 연결한다.

이 전개는 WordNet의 직관을 잘 보여 주지만, **설계 목표 → 실제 인지 모형 검증 → 응용 성능 → 후대 기술의 직접 영향**을 하나의 직선으로 읽게 만들 수 있다. 해설에서는 이를 세 층으로 분리한다. WordNet의 데이터 구조와 배포 연대는 확인 가능한 사실이다. “관계 중심 표현이 유용했다”는 평가는 여러 응용 연구로 뒷받침할 수 있는 해석이다. 반면 Freebase·FrameNet·PropBank·Word2Vec·BERT가 WordNet에서 직접 파생됐다는 계보는 각 프로젝트의 설계 문헌으로 따로 입증해야 한다.

## 6. 중요성

WordNet의 가장 오래가는 공헌은 **공유 가능한 어휘 의미 좌표계**를 제공한 데 있다. 연구자는 서로 다른 문자열을 같은 synset으로 모으고, 한 문자열의 여러 의미를 서로 다른 ID로 지칭하며, 관계를 따라 이동하는 알고리즘을 같은 데이터 위에서 비교할 수 있었다. 의미 태깅 말뭉치와 결합하면 시스템이 어떤 의미를 선택했는지도 평가할 수 있다. 이런 공용 자원은 개별 연구실의 비공개 사전이나 일회성 규칙보다 재현성과 누적 가능성이 높았다.

둘째, WordNet은 관계의 종류를 노출한다. 임베딩의 가까운 두 벡터가 왜 가까운지 해석하기 어려운 것과 달리, WordNet에서는 동의, 상·하위, 부분–전체, 반의, 동작 방식 같은 링크 유형을 조회할 수 있다. 이 명시성은 설명 가능한 검색 확장, 의미 오류 분석, 통제된 평가 세트 구성에 유리하다. 다만 명시적이라는 사실이 완전하거나 문화적으로 중립적이라는 뜻은 아니다.

셋째, WordNet은 어휘 지식과 처리 절차를 분리해 재사용하게 했다. 같은 synset과 관계를 WSD, 검색, 유사도, 텍스트 분석에서 서로 다르게 활용할 수 있다. 이것은 규칙을 없앤 변화가 아니라 **지식을 공용 데이터로 외부화한 변화**에 가깝다. 어떤 관계를 따라갈지 정하는 규칙이나 통계 모델은 여전히 필요하다.

특히 중요한 점:

- 단어 철자와 단어 의미를 분리하고 의미별 식별자와 관계를 대규모로 제공한 점
- 사람이 검사할 수 있는 관계 유형 덕분에 의미 처리의 가정과 오류를 추적할 수 있게 한 점
- 지식 기반 방법과 말뭉치 기반 방법을 비교하거나 결합할 수 있는 공통 자원으로 자리 잡은 점

## 7. 현대 LLM 연결

### 7.1 이산 어휘망과 연속 임베딩은 다른 표현 방식이다

WordNet은 어휘 편찬자가 정한 synset과 관계 포인터를 저장한다. Word2Vec·GloVe류 임베딩은 주변 문맥 분포에서 벡터를 학습하며, 명시적 `hypernym` 간선 없이도 여러 종류의 유사성이 한 공간에 섞여 나타난다. 둘 다 “관계 속에서 의미를 본다”는 느슨한 비교는 가능하지만, 이 공통 문장만으로 직접 계보가 성립하지 않는다. 분포 의미론과 신경망의 distributed representation은 WordNet과 독립적인 역사적 뿌리를 갖는다.

두 방식을 실제로 연결한 연구는 별도로 존재한다. 예를 들어 사전·의미망의 관계를 이용해 이미 학습된 단어 벡터를 가깝게 조정하는 retrofitting, WordNet 관계를 제약이나 추가 손실로 넣는 지식 주입, synset 자체의 임베딩을 학습하는 방법이 있다. 여기서는 WordNet이 임베딩의 조상이 아니라 **외부 감독 신호 또는 구조화된 보완 자원**으로 작동한다.

### 7.2 BERT와 LLM은 고정 단어 의미 목록을 그대로 내장하지 않는다

BERT와 현대 LLM은 같은 문자열도 문맥마다 다른 은닉 상태로 표현한다. 이는 `bank`의 의미를 미리 나눈 고정 synset 목록과 다른 방식이다. 문맥 표현을 WordNet 의미 ID에 매핑해 WSD를 수행할 수는 있지만, 모델의 벡터 한 개가 특정 synset과 자동으로 일치하는 것은 아니다. 모델이 학습 말뭉치에서 동의·상위 관계와 비슷한 패턴을 보인다고 해서 WordNet 관계를 명시적으로 학습했거나 논리적으로 보존했다고 결론 내릴 수도 없다.

현대적 연결은 다음처럼 제한해 표현하는 편이 정확하다.

- **평가와 진단**: WordNet 의미 ID와 관계를 이용해 문맥별 의미 선택, 어휘 치환, 상·하위 관계 처리 능력을 시험할 수 있다.
- **지식 주입**: 학습 또는 미세조정 때 관계 제약과 추가 예시를 만들 수 있다. 이득은 과제와 방법에 따라 검증해야 한다.
- **도구 사용과 검색**: LLM이 필요할 때 WordNet API를 조회해 동의어 후보, 상위 개념, 특정 의미의 gloss를 근거로 제시하게 할 수 있다.
- **데이터 생성의 통제**: 동의어 치환이나 반례 생성에 활용할 수 있지만, 문맥·말투를 무시한 치환은 문장 의미와 레이블을 훼손할 수 있다.

### 7.3 지식 그래프·FrameNet·PropBank와는 범위를 비교해야 한다

WordNet은 일반 영어의 **어휘 의미**를 중심으로 한다. Freebase나 Wikidata 같은 지식 그래프는 사람·장소·사건 같은 개체와 사실 관계를 더 넓게 다루며, FrameNet은 프레임과 참여자 역할을, PropBank는 말뭉치 문장 안의 술어–논항 구조를 주로 기술한다. 모두 기계가 읽는 구조화된 자원이라는 공통점이 있고 서로 연결되기도 하지만, 공통 형식만으로 “WordNet의 직접 후손”이라고 부를 수는 없다. FrameNet은 Fillmore의 frame semantics, PropBank는 Penn Treebank와 의미역 주석, 대규모 지식 그래프는 데이터베이스·시맨틱 웹·협업 지식 구축의 독자적 계보도 함께 갖는다. 반면 BabelNet은 WordNet의 synset을 Wikipedia의 백과사전 지식과 직접 결합한 사례이므로, 단순한 유사성이 아니라 실제 자원 통합 관계라고 말할 수 있다.

### 8.2 사실, 해석, 계보의 경계

- **확인된 사실**: WordNet은 영어 명사·동사·형용사·부사를 synset으로 조직한다. synset과 단어 의미는 여러 의미·어휘 관계로 연결된다. 프로젝트는 1985년에 시작됐고 1995년 이전 배포판과 논문이 존재한다. WordNet 3.0은 117,659개 synset과 206,941개 단어–의미 쌍을 보고하므로, 규모를 말할 때는 버전과 집계 단위를 함께 밝혀야 한다.
- **근거 있는 해석**: 공용 의미 목록과 명시적 관계는 지식 기반 NLP의 재현성, 설명 가능성, 자원 재사용을 크게 높였다. 이 가치는 특정 응용의 성능 수치와 별개로 평가할 수 있다.
- **아직 입증되지 않은 계보**: WordNet의 “관계적 의미”가 임베딩·BERT·현대 지식 그래프를 직접 낳았다는 서술, FrameNet·PropBank가 WordNet의 설계에서 직접 파생됐다는 서술은 원문만으로 성립하지 않는다.

### 8.3 구조 자체의 한계

- **영어와 일반 어휘 중심성**: 전문어, 신조어, 속어, 고유명사, 다른 문화권의 범주화가 충분하지 않을 수 있다.
- **수작업 확장 비용**: 관계의 명시성과 품질 관리가 장점인 동시에 갱신 속도와 규모를 제한한다.
- **의미 세분성**: 비슷한 sense가 너무 잘게 나뉘면 사람 사이 일치도와 자동 WSD 학습이 어려워진다.
- **문맥과 화용 부족**: 고정 synset은 발화 상황, 담화, 은유, 새로운 의미 변화를 모두 표현하지 못한다.
- **합성성 부족**: 단어 의미 관계만으로 구·문장 전체의 조합 의미를 계산할 수 없다.
- **그래프 거리의 해석 문제**: 모든 간선이 같은 의미 거리를 나타내지 않으므로 경로 길이가 곧 사람의 유사도 판단은 아니다.

검증에 사용한 1차·공식 근거는 [Princeton WordNet 소개](https://wordnet.princeton.edu/), [Princeton WordNet FAQ](https://wordnet.princeton.edu/frequently-asked-questions), [1990년 온라인 어휘 데이터베이스 소개](https://doi.org/10.1093/ijl/3.4.235), [Miller의 1992년 HLT 보고](https://aclanthology.org/H92-1116/), [WordNet 1.3을 기록한 1993년 프로젝트 보고서](https://aclanthology.org/H93-1103/), [WordNet 1.4를 기록한 1994년 프로젝트 보고서](https://aclanthology.org/H94-1111/), [Miller의 1995년 CACM 논문](https://doi.org/10.1145/219717.219748)이다. 이 자료들은 WordNet의 목표·품사 범위·관계 구조와 1995년 이전 개발·배포를 확인하는 데 쓰며, 원문이 열거한 모든 후대 기술의 직접 계보를 입증하지는 않는다.

## 9. 용어

| 용어 | 설명 |
| --- | --- |
| WordNet | 영어의 열린 품사 어휘를 synset과 의미·어휘 관계로 조직한 전자 어휘 데이터베이스 |
| synset | 특정한 어휘화된 개념을 표현한다고 편찬자가 묶은 인지적 동의어 집합 |
| lemma | WordNet에 등록된 표제 형식. 같은 lemma가 여러 단어 의미에 연결될 수 있다. |
| word sense | 특정 lemma가 특정 synset에서 갖는 의미 항목 |
| gloss | synset의 짧은 정의와 필요할 경우 포함되는 용례 |
| synonymy | 특정 의미에서 여러 단어 형식이 같은 개념을 표현하는 관계. 모든 문맥의 완전 치환을 뜻하지 않는다. |
| hypernymy / hyponymy | 더 일반적인 종류와 더 구체적인 종류 사이의 상·하위 관계 |
| meronymy / holonymy | 부분과 전체를 각각 바라보는 관계. 구성원–집합, 물질–전체 등 세부 유형이 있다. |
| troponymy | 한 동작을 수행하는 더 구체적인 방식을 나타내는 동사 관계. `whisper`는 `speak`의 한 방식이다. |
| entailment | 한 동작의 성립이 다른 동작의 성립을 함의하는 동사 관계 |
| lexical relation | 특정 단어 의미 사이에 놓이는 관계. 반의 관계가 대표적이다. |
| semantic relation | synset이 나타내는 의미 사이에 놓이는 관계. 상·하위 관계가 대표적이다. |
| distributed representation | 정보가 여러 신경 단위나 벡터 차원에 분산되는 표상. 관계 그래프에 링크가 여러 개 있다는 뜻과 구분해야 한다. |

## 11. 질문

1. 공통 sense inventory가 평가의 재현성을 높이는 동시에, 지나치게 세밀한 의미 구분으로 WSD를 어렵게 만드는 이유는 무엇인가?
2. 검색 질의를 WordNet 동의어·상위어·하위어로 확장할 때 재현율과 정밀도 사이의 균형을 어떻게 검증할 수 있는가?
3. `car → motor vehicle → vehicle` 같은 경로와 임베딩의 코사인 유사도는 각각 어떤 종류의 의미 관계를 보여 주며, 무엇을 숨기는가?
4. WordNet의 설계가 인간 어휘 기억에서 영감을 받았다는 주장과 인간 기억을 실제로 모사한다는 주장을 구분하려면 어떤 실험이 필요한가?
5. WordNet 관계를 LLM에 주입했을 때 모델이 관계를 **기억**한 것과 새로운 문맥에서 관계를 **추론**한 것을 어떻게 나눠 평가할 수 있는가?
6. FrameNet·PropBank·지식 그래프·BERT를 WordNet의 “후손”이라고 부르기 전에 어떤 1차 문헌과 설계 인용을 확인해야 하는가?

## 12. 결론

WordNet은 1995년 한 번의 공개로 갑자기 등장한 의미 이해 시스템이 아니라, 1985년부터 축적된 심리언어학적 문제의식과 어휘 편찬을 대규모 기계 판독 자원으로 구현한 프로젝트다. 핵심 유산은 단어 형식과 의미를 분리하고, synset과 종류가 명시된 관계를 공용 데이터로 제공한 데 있다. 이 구조는 WSD·검색·의미 유사도 연구에 중요한 기반을 주었지만 그 자체가 문맥 해석기나 성능 보증서는 아니다. 현대 임베딩과 LLM은 WordNet의 직접적인 연속선이라기보다 별도의 분포 학습 계보이며, 두 접근은 오늘날 외부 지식 조회, 지식 주입, 평가에서 상보적으로 만난다. 따라서 WordNet을 가장 정확하게 평가하는 방식은 모든 현대 의미 표현의 조상으로 부르는 것이 아니라, **명시적이고 검사 가능한 어휘 관계를 공유 자원으로 만든 결정적 사례**로 위치시키는 것이다.

# Penn Treebank와 통계적 구문 분석 해설

## 1. 한눈에 보기

- 핵심 주제: 영어 문장에 품사와 구문 구조를 일관된 방식으로 표시한 Penn Treebank가 통계적 구문 분석의 공용 학습·평가 기반이 된 과정
- 등장 배경: 수작업 문법의 낮은 적용 범위와 통계 모델이 학습할 대규모 정답 구문 자료의 부족
- 가장 중요한 아이디어: 좋은 알고리즘 하나보다도 텍스트, 주석 지침, 작업 도구, 품질 관리, 공통 평가 관행을 묶은 **주석 인프라**(annotation infrastructure)가 연구 방향을 바꿀 수 있다는 점
- 이후 LLM/NLP에 남긴 영향: 지도학습용 정답 주석 자료, 고정된 분할과 지표를 통한 재현 가능한 비교, 사전학습 표현을 명시적 구문 과제에 적용하는 평가 방식

> 이 문서는 `023_1993 Penn Treebank Foundation of Statistical NLP & Syntactic Parsing.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 Penn Treebank의 실제 역할, 통계 파서의 계산 구조, 평가 관행, 그리고 원문에서 1차 문헌 확인이 필요한 주장을 구분해 정리합니다.

## 2. 핵심 요약

Penn Treebank는 하나의 구문 분석 알고리즘이 아니라 자연어 문장에 품사와 구성 성분 구조를 표시하고, 그 판단 기준을 지침과 도구로 재현할 수 있게 만든 주석 자원이다. 이 자원 덕분에 연구자는 트리에서 문법 규칙과 확률을 추정하고, 보지 못한 문장의 분석 결과를 같은 정답 자료에 맞춰 비교할 수 있었다. 단순 PCFG는 규칙 빈도를 확률로 바꾸는 명료한 출발점이었지만, 규칙 선택이 어휘와 상위 문맥에서 독립이라는 강한 가정 때문에 실제 영어의 중의성을 충분히 설명하지 못했다. 1990년대의 어휘화 파서는 각 구의 중심어와 생성 결정을 모델에 포함해 이 한계를 줄였고, 희소성은 백오프와 평활화로 다뤘다. PARSEVAL 계열의 괄호 정밀도·재현율과 Wall Street Journal Section 23 관행은 모델 간 비교를 빠르게 만들었지만, Penn Treebank 자체와 후대의 평가 관습을 같은 사건으로 합치면 안 된다. 또한 WSJ 중심의 영역, 영어 중심의 범주, 특정 주석 이론과 반복된 벤치마크 최적화는 결과의 일반화를 제한한다. 신경망과 사전학습 모델은 구문 특징을 직접 설계하는 방식을 바꾸었지만, 명시적 구문 분석을 학습하거나 진단하려면 여전히 사람이 정한 구조와 평가 자료가 필요하다.

- 무엇을 다루는가: Penn Treebank의 구축, 주석 체계, 통계적 구문 분석과 공통 평가의 형성
- 어떤 문제를 해결하려 했는가: 대규모 실제 문장에 대한 일관된 구문 정답이 없어 데이터 기반 파서를 학습·비교하기 어려웠던 문제
- 어떤 방식이 새로웠는가: 자동 전처리와 인간 교정을 결합하고, 주석 지침·품질 관리·배포 가능한 말뭉치를 하나의 연구 기반으로 구성한 점
- 결과적으로 무엇을 바꾸었는가: 구문 분석 연구의 중심 질문을 규칙의 가능성 시연에서 공통 자료 위의 일반화 성능 비교로 이동시킨 점

## 3. 역사적 배경

1980년대까지 계산언어학에는 문맥 자유 문법, ATN, 통합 기반 문법, 원리 기반 문법처럼 정교한 형식 체계가 이미 존재했다. 문제는 분석 이론의 부재가 아니라 실제 신문 문장에 필요한 어휘와 예외를 얼마나 넓게 다루고, 실패하지 않으면서 여러 가능한 분석 가운데 하나를 선택하느냐였다. 수작업 문법은 언어학적 제약을 명시적으로 표현할 수 있었지만, 새로운 어휘·문체·생략·병렬 구조가 나타날 때마다 유지 비용이 커졌다.

동시에 음성 인식과 언어 모델링에서는 관측 자료로부터 확률을 추정하는 연구가 성장하고 있었다. 구문 분석에도 같은 방향을 적용하려면 문장과 정답 트리의 대량 쌍이 필요했다. 품사 표지만 있거나 규모가 작은 선행 말뭉치는 이 목적에 충분하지 않았고, 모든 문장을 처음부터 전문가가 그리는 방식은 비용이 컸다. Penn Treebank 프로젝트는 자동 태깅·부분 분석 결과를 사람이 수정하고, 반복되는 판단을 지침으로 고정하는 방식으로 이 병목을 완화했다.

- 이전 접근법: 언어학자가 문법·어휘 규칙을 직접 작성하고 선택 제약을 설계하는 상징적 파서
- 당시의 한계: 실제 텍스트에 대한 적용 범위, 중의성 순위화, 미등록어 처리, 시스템 간 공정한 비교의 부족
- 이 주제가 필요했던 이유: 통계 모델의 매개변수를 추정할 학습 자료와 모델 개선을 확인할 공통 정답·평가 절차가 동시에 필요했기 때문

여기서 “상징 규칙에서 통계 학습으로 한순간에 교체됐다”는 서사는 주의해서 읽어야 한다. Penn Treebank의 트리와 범주 자체가 언어학자의 상징적 판단을 구조화한 결과이며, 통계 파서는 그 구조를 확률적으로 예측했다. 실제 변화는 상징과 통계의 단순한 대체보다 **사람이 정의한 표현 체계 위에서 데이터로 선택 규칙을 학습하는 혼합**에 가까웠다.

## 4. 핵심 개념 해설

### 4.1 Penn Treebank는 왜 ‘주석 인프라’인가

트리뱅크는 트리 파일만을 뜻하지 않는다. 연구에 반복해서 사용할 수 있으려면 다음 요소가 함께 작동해야 한다.

| 구성 요소 | 하는 일 | 학습할 때의 주의점 |
| --- | --- | --- |
| 원문 텍스트 | 분석 대상 문장을 제공한다. | Penn Treebank 전체와 널리 쓰인 WSJ 부분집합을 구분해야 한다. |
| 품사 주석 | 각 토큰의 문법 범주를 표시한다. | 태그 수와 정의는 릴리스·지침 버전에 따라 확인해야 한다. |
| 구성 성분 트리 | NP, VP, PP, S 계열 범주와 포함 관계를 표시한다. | 표면 괄호만이 아니라 기능 태그·빈 범주·공색인 정보가 포함될 수 있다. |
| 주석 지침 | 병렬 구조, 부착, 생략 같은 반복 판단을 통일한다. | 일관성은 자연의 유일한 정답이라기보다 운영 가능한 합의다. |
| 작업 도구와 선행 분석 | 자동 태깅·부분 분석 뒤 인간이 교정하게 해 비용을 줄인다. | 자동 분석의 편향이 인간 교정 결과에 남을 가능성도 검토해야 한다. |
| 품질 관리 | 이중 주석, 판정, 오류 수정으로 편차를 줄인다. | 합의 수치와 측정 단위는 반드시 해당 보고서에서 확인한다. |
| 배포·평가 관행 | 여러 연구자가 같은 자료를 재사용하고 결과를 비교하게 한다. | 데이터 릴리스와 후대의 표준 분할·도구를 같은 시점의 설계로 소급하지 않는다. |

원문은 Penn Treebank를 “skeletal”하고 비교적 표면적인 표현으로 설명한다. 이 요지는 세밀한 의미·담화 표현을 목표로 하지 않았다는 뜻에서는 유용하다. 그러나 Treebank II 계열에는 기능 태그, 빈 범주, 이동 관계를 나타내는 공색인처럼 단순한 표면 괄호를 넘어서는 장치도 있다. 따라서 “변형 관계나 생략을 표현하지 않았다”는 식의 절대적 문장은 버전별 지침과 실제 트리를 대조해 고쳐야 한다.

### 4.2 PCFG에서 어휘화 파서로

확률적 문맥 자유 문법(PCFG)은 비단말 기호 `A`가 오른쪽 구조 `β`로 확장될 확률을 둔다. 트리뱅크에서 가장 단순한 최대가능도 추정은 다음처럼 규칙 빈도를 같은 왼쪽 기호를 가진 모든 규칙의 빈도로 나누는 것이다.

```text
P(A → β | A) = count(A → β) / count(A)
P(T) = ∏ P(rule used in T)
```

이 모델은 트리에서 규칙을 자동으로 추출할 수 있고, 후보 트리의 점수를 명확하게 계산할 수 있다는 장점이 있다. CKY류 동적 계획법을 쓰려면 보통 문법을 적절한 정규형으로 바꾸거나 이진화하는 전처리가 필요하다. “가능한 모든 트리를 그대로 열거한다”기보다 동일한 부분 문제의 최적값을 차트에 재사용한다고 이해하는 편이 정확하다.

기본 PCFG의 핵심 한계는 규칙 선택이 현재 비단말 이외의 문맥과 독립이라는 점이다. 예를 들어 PP가 어떤 동사나 명사에 붙는지는 실제 단어 조합과 강하게 관련되지만, 범주만 보는 문법은 이를 충분히 구분하지 못한다. 어휘화(lexicalization)는 구마다 중심어(head word)와 품사 정보를 전달하고, 중심어·수식어·거리·방향 같은 생성 결정을 조건으로 사용해 이 독립 가정을 완화한다.

다만 “NP-company라는 새 범주를 만들었다”는 직관은 실제 Collins 계열 모델의 계산을 지나치게 단순화할 수 있다. 핵심은 트리를 중심어가 있는 구조로 변환한 뒤, 부모와 중심어 문맥에서 왼쪽·오른쪽 수식어와 STOP 결정을 확률적으로 분해하는 데 있다. Collins의 Model 2는 중심어별 하위범주화 틀을, Model 3은 wh-이동을 확률 모형에 더했다. 조건을 많이 넣으면 자료가 희소해지므로 백오프와 보간이 필수적이며, 이 지점은 [[019_Katz Back-off - Handling Sparse Data in Language Models]]에서 다루는 희소성 문제와 직접 맞닿는다.

### 4.3 PARSEVAL, EVALB, Section 23

구성 성분 파서는 예측 트리의 괄호 구간 `(시작 위치, 끝 위치, 범주)`을 정답 트리와 비교해 평가한다.

```text
labeled precision = 맞힌 예측 구성 성분 수 / 예측한 구성 성분 수
labeled recall    = 맞힌 예측 구성 성분 수 / 정답 구성 성분 수
F1                = 2PR / (P + R)
```

PARSEVAL은 이런 비교 절차를 정리한 평가 관행이며, 실제 Penn Treebank 파싱 논문에서는 EVALB 프로그램과 그 매개변수 파일이 널리 사용됐다. 어떤 구두점·최상위 범주·빈 범주를 제외하는지에 따라 점수가 달라지므로 “F1 몇 퍼센트”만 떼어 놓고 비교하면 안 된다. 문장 길이 제한과 평가 스크립트 설정도 함께 확인해야 한다.

WSJ Section 23은 후대 통계 파싱 논문에서 널리 쓰인 테스트 집합이다. Collins의 1997년 논문은 Sections 02–21을 학습하고 Section 23을 시험했지만 개발 집합은 명시하지 않았다. 다른 연구가 Section 00이나 22를 개발 집합으로 쓰기도 했으므로 하나의 분할을 1993년 프로젝트가 처음부터 공식 표준으로 고정했다고 소급하면 안 된다. 데이터셋의 존재, 분할 관습, PARSEVAL 제안, EVALB 구현은 서로 다른 층위와 시점의 인프라다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개된다.

1. **문제 제기**: 수작업 문법은 실제 신문 문장의 다양성과 중의성에 취약했고, 통계 모델은 정답 구문 자료가 부족했다.
2. **핵심 아이디어**: Penn Treebank가 품사·구성 성분 트리·주석 지침을 대규모로 제공해 데이터 병목을 해소했다.
3. **방법 또는 구조**: 자동 전처리와 인간 교정, 표면 구조를 중시한 주석 체계를 설명한다. 해설은 1993년 논문에 기능 태그와 빈 범주도 포함됐음을 별도로 보완한다.
4. **통계 파싱의 전개**: 빈도 기반 PCFG에서 어휘·문맥을 포함한 Collins식 모델로 정확도가 높아졌다고 서술한다.
5. **공통 평가의 형성**: PARSEVAL 계열 지표와 Section 23을 통해 모델 간 정량 비교가 가능해졌다고 주장한다.
6. **확장과 현대적 계보**: PropBank, 통계적 MT, 신경 파서, BERT·GPT와 Universal Dependencies까지 영향을 확장한다.
7. **한계**: WSJ 영역 편향, 이론 의존적 주석, 불완전한 일치도, 작은 규모와 접근 제약을 인정한다.

이 흐름은 “자료가 연구 방법을 바꾼다”는 메시지를 전달하는 데 효과적이다. 다만 여러 버전의 Penn Treebank와 후대 파서 관행을 “1993년 하나의 완성된 사건”으로 묶고, 기능적 유사성이나 넓은 방법론적 영향을 직접 계보처럼 서술하는 대목이 있다. 번역은 원문의 흐름을 보존하되, 공개 소스 처리 단계에서는 연대·버전·평가 조건을 따로 검증해야 한다.

## 6. 왜 중요한가

Penn Treebank의 첫째 의미는 **학습 가능한 대상의 정의**에 있다. “영어 구문을 이해한다”는 넓은 목표를 특정 범주와 트리 구조를 예측하는 과제로 바꾸고, 같은 문장과 정답을 여러 모델이 공유하게 했다. 이 과정은 모델이 무엇을 맞혀야 하는지, 오류를 어떻게 셀지, 개선을 어떤 수치로 주장할지를 함께 고정했다.

둘째 의미는 **누적 가능한 연구**에 있다. 같은 자료·분할·평가를 사용하면 한 모델의 개선이 다른 모델과 비교 가능해진다. PCFG의 독립 가정, 어휘화의 효과, 평활화와 표현 학습의 기여를 공통 조건에서 시험할 수 있었다. 이는 개별 예시 시연보다 재현 가능한 실험을 중심에 놓는 데 기여했다.

셋째 의미는 **주석의 층위화**다. 구문 트리 위에 술어-논항 정보를 더한 PropBank처럼, 한 번 구축한 구조를 다른 과제의 발판으로 재사용할 수 있었다. 다만 FrameNet이나 Universal Dependencies처럼 별도의 이론·자료·공동체에서 발전한 자원을 모두 Penn Treebank가 직접 낳았다고 표현해서는 안 된다. 더 정확한 설명은 Penn Treebank가 대규모 주석과 공용 평가의 가능성을 강하게 보여 준 선례라는 것이다.

특히 중요한 점:

- 알고리즘뿐 아니라 자료·지침·도구·평가가 함께 있어야 연구가 축적된다는 점
- 명시적 언어학 범주와 통계적 선택이 경쟁 관계만이 아니라 상호 의존적이었다는 점
- 공통 벤치마크가 비교를 가능하게 하는 동시에 특정 영역과 주석 관습에 대한 과최적화를 유도할 수 있다는 점

## 7. 현대 LLM과의 연결

Penn Treebank와 현대 LLM의 가장 중요한 연결은 구조가 동일하다는 데 있지 않고, **대규모 사전학습 뒤 명시적 정답 자료로 특정 능력을 학습·측정하는 역할 분담**에 있다.

| 현대 개념 | Penn Treebank와의 연결 | 구분해야 할 점 |
| --- | --- | --- |
| 신경 구문 분석 | 신경망 인코더가 전이 행동·스팬·의존 호를 점수화하고 Treebank 정답으로 학습한다. | 모델 내부가 신경망이어도 예측 대상은 사람이 정의한 주석 체계다. |
| 사전학습 표현 | BERT류 표현을 구문 분석기의 입력으로 사용할 수 있다. | 원시 텍스트 사전학습과 구문 지도학습은 같은 학습 목표가 아니며, 효과는 비교 조건을 확인해야 한다. |
| 구문 프로빙 | 고정된 표현에서 품사·구성 성분·의존 관계를 얼마나 복원할 수 있는지 본다. | 정보가 선형 탐침으로 읽힌다는 사실이 모델이 생성 때 그 정보를 실제 사용한다는 증거는 아니다. |
| 다중 과제·보조 손실 | 구문 예측을 다른 언어 과제의 보조 목표로 둘 수 있다. | 모든 과제에서 명시적 구문 감독이 일관되게 이득이라는 결론은 성립하지 않는다. |
| 벤치마크 문화 | 후대에 정착한 정답 집합과 지표로 모델을 비교하는 관행은 현대 평가에도 이어진다. | 고정 테스트 집합의 반복 사용은 누출·과적합·포화 문제를 낳는다. |

- **Transformer**: self-attention은 토큰 사이 관계를 학습하지만 Penn Treebank의 구성 성분 트리를 그대로 계산하지 않는다. 구문 구조와 상관된 패턴이 나타날 수 있다는 것과 동일한 구조를 명시적으로 구현했다는 것은 다르다.
- **BERT 계열 사전학습**: 명시적 구문 라벨 없이도 구문 정보를 어느 정도 복원 가능한 표현을 학습한다. 그러나 “암묵적 구문 정보”의 존재, 다운스트림에서의 실제 사용, 인간과 같은 문법 일반화는 별개의 주장이다.
- **GPT·현대 LLM**: 다음 토큰 예측으로 광범위한 통사 패턴을 학습할 수 있지만, Penn Treebank가 LLM의 직접 기술적 조상이라는 단순 계보는 근거가 부족하다. 더 안전한 연결은 데이터에서 분포를 학습하고 별도 평가 자료로 능력을 진단한다는 방법론적 연속성이다.

원문의 “가장 성공적인 현대 시스템은 명시적 구조와 분포 학습을 함께 쓴다”는 문장은 범위가 지나치게 넓다. 일부 구문 분석 시스템과 보조학습 연구에는 맞을 수 있지만, 범용 LLM 전체나 모든 다운스트림 과제에 일반화하려면 비교 실험과 시점을 명시해야 한다.

## 8. 한계와 비판적 관점

### 8.1 영역과 표본의 한계

- WSJ는 편집된 미국 비즈니스 뉴스다. 대화, 문학, 웹 문체, 소셜 미디어, 기술 문서, 아동 언어와 분포가 다르다.
- 같은 주석 범주라도 도메인이 바뀌면 어휘, 문장 길이, 생략, 구두점, 고유명사 분포가 달라져 파서 성능이 낮아질 수 있다.
- Penn Treebank 전체의 여러 자료와 구문 분석 연구에서 주로 쓴 WSJ 부분을 혼용하면 규모와 대표성에 관한 주장이 달라진다.
- 영어 중심의 구성 성분 범주를 다른 언어의 보편적 구조로 간주할 수 없다.

### 8.2 주석 이론과 gold standard의 한계

- 트리는 관측 사실을 그대로 옮긴 것이 아니라, 지침이 허용한 범주와 우선순위에 따라 내린 분석 판단이다.
- 부착·병렬·빈 범주·기능 태그에는 언어학적 가정과 실무적 타협이 함께 들어 있다.
- 주석자 간 일치도는 중요한 품질 지표지만, 어떤 항목을 제외하고 어떤 단위로 계산했는지에 따라 수치가 달라진다.
- 파서가 높은 점수를 얻었다는 것은 먼저 Penn Treebank식 분석을 잘 재현했다는 뜻이다. 곧바로 의미 이해나 인간과 같은 구문 능력을 입증하지 않는다.

### 8.3 평가와 연구 관행의 한계

- labeled bracket F1은 구성 성분 경계를 평가하지만 술어-논항 관계, 의미역, 담화 적합성, 문장 전체의 해석을 직접 측정하지 않는다.
- Section 23에 수년간 반복해서 모델을 맞추면 명시적 학습에는 쓰지 않았더라도 공동체 수준의 테스트 과적합이 생길 수 있다.
- 서로 다른 논문의 점수는 문장 길이 제한, 전처리, 구두점 제외, EVALB 설정, 외부 자료·사전학습 사용 여부가 같아야 비교할 수 있다.
- “인간 일치도에 접근했다”는 표현은 인간 재주석 조건과 모델 평가 조건이 동일한지 확인하지 않으면 성능 상한선으로 사용할 수 없다.

### 8.4 검증 정정과 남은 경계

1993년 프로젝트 논문, LDC 배포 문서, PARSEVAL 논문, Brill·Collins·Chiang의 원 논문을 대조하면 다음 항목은 정정할 수 있다.

| 원문의 서술 | 검증 결과 | 1차 근거 |
| --- | --- | --- |
| 1993년에 완전 공개된 WSJ 100만 단어 자료가 Penn Treebank였다는 서술 | 1993년 논문은 1989–1992년 1단계를 보고하며, 1992년 11월 기준 전체 4,885,798토큰에 품사를, 2,881,188토큰에 골격 구문을 주석했다고 기록한다. WSJ 100만 단어를 Treebank-2 방식으로 담은 LDC95T7 배포는 1995년이다. | [Marcus·Santorini·Marcinkiewicz 1993](https://aclanthology.org/J93-2004/), [LDC Treebank-2](https://catalog.ldc.upenn.edu/LDC95T7) |
| 약 45개 품사 태그와 약 15개 구문 범주라는 수치 | 1993년 논문의 표는 품사 태그 36개와 문장부호·통화 기호 12개, 구문 태그 14개를 제시한다. 무엇을 태그 수에 포함하는지 밝혀야 한다. | Marcus 외 1993, Tables 2–3 |
| 빈 범주 없이 표면 구조만 표시했다는 설명 | 1993년 논문은 골격 표현을 채택했지만 0, T, NIL 같은 빈 요소도 명시적으로 유지했다. 원문의 gapping 예시는 Treebank-2 지침과 별도로 대조해야 한다. | Marcus 외 1993, §4.2와 Table 3 |
| 주석 속도를 시간당 300–400단어로 단일화한 서술 | 완전 구조 교정은 훈련 3주 뒤 약 375단어, 6주 뒤 475단어였고, 골격 구조 교정은 3–4개월 뒤 약 750에서 1,000단어 이상이었다. 작업 형태와 숙련 기간을 분리해야 한다. | Marcus 외 1993, §4.3 |
| Collins의 1997년 ‘박사학위 연구’와 Model 3 약 88% F1 | 확인한 문헌은 ACL 논문이다. Sections 02–21로 학습하고 Section 23으로 시험했으며, 최종 결과를 구성 성분 정밀도 88.1%·재현율 87.5%로 보고했다. F1 하나로 바꾸지 않는다. | [Collins 1997](https://aclanthology.org/P97-1003/), §§1, 4와 Table 2 |
| Section 23·PARSEVAL·EVALB를 Penn Treebank가 한꺼번에 확립했다는 인상 | PARSEVAL의 괄호 정밀도·재현율 절차는 Black 외 1991의 별도 평가 연구다. Section 23 관행은 후대 파서 논문에서 확인되며, EVALB 구현도 자원 구축과 분리해야 한다. | [Black 외 1991](https://aclanthology.org/H91-1060/), Collins 1997 §4 |
| Brill 태거가 1992년에 Penn Treebank로 학습해 97%를 넘겼다는 서술 | 1992년 논문은 Brown Corpus의 90%를 초기 학습, 5%를 규칙 획득, 5%를 시험에 썼고 최종 오류율 5.1%, 즉 약 94.9% 정확도를 보고했다. 특정 조건의 결과를 품사 태깅 전체가 해결됐다는 결론으로 넓힐 수 없다. | [Brill 1992](https://aclanthology.org/A92-1021/), §§2–3 |
| 계층적 구 기반 번역이 Penn Treebank 파서에 크게 의존했다는 서술 | Chiang의 Hiero는 동기 문맥 자유 문법 형식을 쓰지만 통사 정보 없이 병렬 말뭉치에서 학습한다. 이를 통사 기반·트리-문자열 번역과 구분해야 한다. | [Chiang 2005](https://aclanthology.org/P05-1033/), 초록과 §1 |

아직 그대로 재사용하지 않을 항목도 남는다.

- 기본 PCFG의 70–75%와 ‘비약적 향상’은 대상 파서, 자료 분할, 문장 길이, 지표가 특정되지 않았다.
- 인간 구문 주석 일치도 92–95%와 2016년 신경 파서 94%는 동일한 평가 조건의 수치인지 확인되지 않았다.
- PropBank의 정확한 시작 시점, 신경망·사전학습의 효과, “명시적 구조와 분포 학습을 결합한 시스템이 가장 성공적”이라는 일반화에는 개별 연구가 더 필요하다.
- FrameNet·Universal Dependencies·Transformer·LLM은 기능적·방법론적 연결을 논할 수 있지만 Penn Treebank의 직접 후손으로 단정하지 않는다.
## 9. 용어 정리

| 용어 | 설명 | 주의할 점 |
| --- | --- | --- |
| treebank | 문장과 사람이 검토한 구문 구조를 연결한 말뭉치 | 텍스트뿐 아니라 주석 지침·버전·도구가 결과를 규정한다. |
| gold standard | 모델 평가의 기준으로 쓰는 인간 주석 | 절대적 진리라기보다 합의된 작업 정의이며 오류·변이가 남을 수 있다. |
| constituent | 문장에서 하나의 단위로 묶이는 연속 구간과 범주 | 의존 관계나 의미역과 같은 표현은 아니다. |
| function tag | `-SBJ`, `-TMP`처럼 구의 문법 기능을 보완하는 표지 | 의미역 전체를 표현하지 않는다. |
| empty category | 표면 토큰이 없지만 이동·생략 관계를 표시하기 위한 노드 | 평가 전처리에서 제외되기도 하므로 원 트리와 평가 트리를 구분한다. |
| PCFG | 각 문맥 자유 문법 규칙에 조건부 확률을 둔 생성 모형 | 기본형은 상위 문맥과 실제 단어에 대한 독립 가정이 강하다. |
| lexicalization | 구문 노드에 중심어 정보를 전달해 규칙 선택을 어휘 문맥에 조건화하는 방식 | 단순히 범주 이름 뒤에 단어를 붙이는 것보다 생성 결정 구조가 중요하다. |
| head word | 구에서 다른 성분과의 결합을 대표하도록 선택한 중심 단어 | 중심어 선택 규칙도 설계된 가정이다. |
| PARSEVAL | 예측 트리와 정답 트리의 구성 성분 괄호를 비교하는 평가 절차 | EVALB 설정, 제외 범주, 문장 길이 조건을 함께 봐야 한다. |
| Section 23 | Penn Treebank WSJ 부분에서 관습적으로 시험에 쓰인 구간 | Treebank 자체와 후대의 표준 분할 관습을 구분한다. |
| domain shift | 학습 자료와 적용 자료의 어휘·문체·구조 분포가 달라지는 현상 | WSJ 점수가 대화·웹·다른 언어 성능을 보장하지 않는다. |
| probing | 학습된 표현에서 특정 언어 정보가 얼마나 복원되는지 측정하는 실험 | 복원 가능성과 모델의 실제 인과적 사용은 다르다. |

## 12. 짧은 결론

Penn Treebank의 역사적 위치는 통계적 구문 분석 알고리즘을 하나 발명했다는 데 있지 않다. 자연어의 구조를 사람이 검토 가능한 표준 형식으로 만들고, 그 자료에서 PCFG와 어휘화 파서를 학습하고, 후대에 정착한 공통 지표와 데이터 분할로 결과를 누적 비교하게 한 **주석·평가 인프라**였다는 데 있다. 이 인프라는 신경망과 사전학습 시대에도 명시적 구문 감독과 진단 자료로 남아 있다. 동시에 WSJ 영역, 영어 중심 범주, 주석 이론, 고정 벤치마크라는 경계도 함께 물려주었다. 따라서 원문의 의의를 보존하려면 1993년 하나의 사건에 후대 관행을 소급하거나 Penn Treebank를 Transformer·LLM의 직접 원인으로 확대하기보다, 각 릴리스·모델·평가의 1차 근거를 분리해 읽어야 한다.

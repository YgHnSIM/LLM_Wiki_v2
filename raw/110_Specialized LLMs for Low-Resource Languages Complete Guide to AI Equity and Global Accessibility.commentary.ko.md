# 저자원 언어 특화 LLM 해설

원본 출처: https://mbrenndoerfer.com/writing/specialized-llms-low-resource-languages-ai-equity-global-accessibility

## 1. 한눈에 보기

- 핵심 주제: 디지털 텍스트·병렬 말뭉치·벤치마크·언어 도구가 부족한 언어에서 합성 데이터, 교차언어 전이, 지시 미세조정, 효율적 적응을 이용해 언어 모델의 성능 격차를 줄이는 방법
- 등장 배경: 대규모 언어 모델은 데이터가 풍부한 언어에서 더 많은 표현과 과제를 학습한다. 사용 인구가 많아도 특정 과제의 학습·평가 자료가 부족할 수 있으며, 하나의 다국어 모델이 언어 이름을 지원한다고 해서 언어별 품질이 같아지는 것은 아니다.
- 가장 중요한 아이디어: 저자원 언어 성능은 데이터 양 하나로 설명되지 않는다. 데이터의 품질과 도메인, 토크나이저 효율, 문자·형태론, 전이할 보조 언어, 목표 과제, 평가 설계, 계산 자원과 공동체의 통제 권한을 함께 봐야 한다.
- 확인된 역사적 흐름: XLM의 교차언어 사전학습, NLLB-200의 대규모 기계번역, Aya의 101개 언어 지시 미세조정, MaLA-500의 어휘 확장·계속 사전학습, InkubaLM의 소형 아프리카 언어 모델이 2025년보다 앞서 핵심 토대를 만들었다.
- 2025년에 확인된 진전: Alhanai 외는 아프리카 언어 벤치마크와 미세조정을, de Gibert 외는 LLM 생성 합성 병렬 데이터의 기계번역 효과를, Nagar 외는 Hindi–English 합성 코드스위칭 QLoRA를 각각 좁은 조건에서 검증했다.
- 반드시 지켜야 할 경계: 지원 언어 수, 훈련 토큰 수, 토크나이저 효율, 과제별 점수, 실제 배포, 공동체 거버넌스는 서로 다른 축이다. 특정 번역 점수나 다지선다 정확도를 여러 언어의 범용 LLM ‘영어 동등성’으로 일반화할 수 없다.

> 원문은 저자원 언어 AI의 실제 문제와 유망한 기법을 읽기 쉽게 설명하지만, 서로 다른 연구를 하나의 2025년 돌파구처럼 합친다. 이 해설은 2025년 8월 28일이라는 원문 공개 시점을 기준으로 선행 연구와 동시대 1차 자료를 분리하고, 확인된 과제별 개선과 아직 입증되지 않은 사회적 효과를 구분한다.

## 2. 핵심 요약

‘저자원 언어’는 사용자가 적다는 뜻이 아니라 특정 언어·도메인·과제에 필요한 텍스트, 라벨, 병렬 문장, 사전, 토크나이저, 벤치마크, 전문가와 계산 기반이 부족하다는 뜻이다. 스와힐리어나 벵골어처럼 사용 인구가 큰 언어도 영어와 비교하면 일부 NLP 과제에서 자원이 부족할 수 있지만, 언어 전체를 영구적인 단일 등급으로 고정해서는 안 된다. 실제로 Aya의 분류에서는 벵골어가 중간 자원 언어로 취급된다.

합성 데이터와 교차언어 전이는 이 격차를 줄이는 유력한 방법이다. 고자원 언어의 단일언어 텍스트를 번역해 병렬 자료를 만들거나, 여러 언어가 공유하는 표현을 학습한 뒤 목표 언어에 적응하거나, 소량의 목표 언어 지시 데이터로 모델을 미세조정할 수 있다. 그러나 합성 데이터는 교사 모델의 오류·편향·문체를 복제할 수 있고, 전이는 언어 거리·문자·도메인과 데이터 품질에 따라 이득 또는 간섭을 낳는다. 사람 번역과 검증을 ‘낡은 데이터 중심 접근’으로 밀어낼 수도 없다. Alhanai 외의 개선은 약 100만 단어의 사람 번역과 약 4만 달러의 번역·검증·평가 비용에 크게 의존했다.

2025년의 세 가까운 연구는 서로 다른 질문에 답했다. Alhanai 외는 11개 아프리카 언어의 번역 벤치마크와 400개가 넘는 미세조정 실험에서 단일언어 미세조정 평균 +5.6%p, 교차언어 전이 평균 +2.9%p를 보고했지만 영어와의 평균 격차는 과제에 따라 12.0–19.9%p 남았다. de Gibert 외는 GPT-4o가 Europarl을 7개 목표 언어로 번역해 만든 자료가 특정 기계번역 모델을 개선함을 보였지만, Georgian 합성 문장의 약 40%는 사람 평가에서 수용 불가 품질이었다. Nagar 외는 Llama-3-8B-Instruct를 Hindi–English 합성 코드스위칭 자료로 QLoRA 미세조정해 CommonSenseQA에서 영어 90.4%, Hindi 85.6%를 얻었지만, 이는 질문만 섞고 답 선택지는 영어로 둔 단일 언어쌍·단일 과제의 예비 결과다.

따라서 원문의 ‘여러 저자원 언어에서 영어에 근접한 성능’은 일반 명제로 확인되지 않는다. 독립적인 MMLU-ProX v1은 13개 언어와 언어별 11,829문항, 25개 모델을 평가했다. v1 Table 1의 5-shot CoT 조건에서 Qwen2.5-72B는 영어 70.3%, 스와힐리어 40.1%였다. 이 벤치마크 역시 번역·검수된 객관식 추론 평가라는 한계가 있지만, 최소한 범용 다국어 능력 격차가 2025년에 사라졌다는 서술과는 맞지 않는다.

교육·의료·기업 자동화·언어 보존은 가능한 응용 영역이지 위 세 연구가 입증한 배포 효과가 아니다. 현장 접근성은 모델 점수 외에도 가격, 장치와 네트워크, 응답 지연, 안전성, 방언 지원, 유지보수, 현지 전문가 검증, 데이터 동의와 수정 권한에 달려 있다. ‘잠재 사용자 수’와 ‘실제 혜택을 받은 사용자 수’를 혼동하지 않아야 한다.

- 무엇을 다루는가: 저자원 언어의 데이터·표현·평가 격차와 합성 데이터, 교차언어 전이, 지시 미세조정, QLoRA, 토크나이저 적응
- 어떤 문제를 해결하려 했는가: 고자원 언어 중심 모델이 언어별로 불균등한 품질과 비용을 제공하는 문제
- 무엇이 실제로 확인됐는가: 특정 언어·과제·모델에서의 개선, 새로운 사람 번역 벤치마크, 합성 병렬 자료의 기계번역 효용
- 무엇은 확인되지 않았는가: 2025년 단일 돌파구, 여러 언어의 범용 영어 동등성, 문화 보존의 실증, 교육·의료·기업의 광범위한 실제 배포
- 올바른 결론: 기술적 적응과 고품질 현지 데이터, 평가, 공동체 거버넌스가 함께 갈 때 격차를 줄일 수 있으며 하나의 지표가 AI 형평성을 대신하지 않는다.

## 3. 역사적 배경

저자원 언어 AI는 2025년에 갑자기 시작된 분야가 아니다. 2010년대 후반의 다국어 표현 학습, 2020년대 초의 대규모 번역·언어 불평등 연구, 2024년의 다국어 지시 미세조정과 소형 지역 모델을 거쳐 2025년의 과제별 적응 연구로 이어졌다.

이 연표가 보여 주는 핵심은 ‘최초’를 한 해에 배정하는 일이 아니라 증거의 층위를 구분하는 일이다. XLM은 교차언어 표현 학습의 방법을, NLLB는 대규모 번역을, Aya는 다국어 지시 추종을, InkubaLM은 작은 지역 특화 모델을, 2025년 연구들은 서로 다른 적응·평가 실험을 다뤘다. 서로의 성능 수치를 같은 척도로 합칠 수 없다.

- 이전 접근법: 병렬 말뭉치 기반 개별 번역 모델, 영어 중심 사전학습, 하나의 공유 다국어 모델에 언어를 함께 넣는 방식
- 당시의 한계: 데이터 불균형, 언어 간 간섭, 부적합한 토크나이저, 번역된 벤치마크의 문화 편향, 높은 학습·검증 비용
- 이 주제가 필요했던 이유: 소량의 현지 자료로도 목표 과제에 맞게 적응하면서 영어 능력의 망각과 언어별 품질 붕괴를 줄여야 했기 때문이다.
- 남아 있는 핵심 구분: ‘모델이 언어 코드를 받는다’와 ‘그 언어 공동체가 신뢰할 수 있는 서비스를 지속적으로 통제한다’는 전혀 다른 주장이다.

## 4. 핵심 개념 해설

### 4.1 저자원은 언어의 본질이 아니라 과제별 상태다

저자원성을 하나의 언어에 붙은 영구 꼬리표로 이해하면 중요한 차이를 놓친다. 같은 언어라도 뉴스 번역 자료는 많고 의료 대화 자료는 거의 없을 수 있다. 단일언어 웹 텍스트는 충분하지만 병렬 번역문, 음성, 형태 분석기, 안전 벤치마크가 부족할 수도 있다. 표준어 자료는 많아도 방언·코드스위칭·비표준 철자는 배제될 수 있다.

화자 수와 자원 등급도 다르다. 스와힐리어의 2억 명 이상이라는 수치는 모어와 제2언어 사용자를 어떻게 합산하는지에 따라 달라진다. 벵골어는 2억 5천만 명 넘게 쓰지만 Aya의 Joshi 기반 분류에서는 중간 자원 언어다. 더 정확한 문장은 ‘벵골어가 저자원 언어다’가 아니라 ‘특정 벵골어 도메인·과제의 학습과 평가 자원이 영어보다 부족하다’이다.

### 4.2 합성 데이터, 전이, 적응은 서로 다른 레버다

| 방법 | 무엇을 하는가 | 확인된 예 | 핵심 위험 |
|---|---|---|---|
| 교차언어 사전학습 | 여러 언어에서 공유되는 표현을 학습해 한 언어의 신호를 다른 언어 과제에 재사용한다. | XLM의 MLM·TLM, NLLB의 다국어 표현 | 관련 없는 언어·문자·도메인 사이의 음의 전이와 고자원 언어 지배 |
| 병렬 문장 마이닝·역번역 | 웹에서 의미가 맞는 문장쌍을 찾거나 한쪽 단일언어 문장을 번역해 병렬 자료를 늘린다. | NLLB-200 | 언어 식별 오류, 잘못 정렬된 문장, 번역투와 독성의 확산 |
| LLM 합성 병렬 데이터 | 강한 교사 LLM이 고자원 텍스트를 목표 언어로 번역하고 작은 MT 모델이 이를 학습한다. | de Gibert 외의 GPT-4o→7개 언어 | 폐쇄형 교사 의존, 언어별 품질 편차, 도메인 편향, 재현성·라이선스 문제 |
| 지시 미세조정 | 목표 언어로 된 지시와 응답을 학습해 과제 수행과 지시 추종을 맞춘다. | Aya, InkubaLM, Alhanai 외 | 번역된 지시가 현지의 실제 요청을 대표하지 않을 수 있고 데이터 품질 비용이 큼 |
| PEFT·QLoRA | 전체 가중치를 다시 학습하지 않고 작은 저랭크 어댑터와 양자화를 이용해 적응 비용을 줄인다. | Nagar 외의 Llama-3-8B QLoRA | 학습 메모리가 줄어도 데이터 생성·평가·서빙 비용과 기반 모델 라이선스는 남음 |
| 어휘 확장·토크나이저 적응 | 목표 언어의 문자·형태소가 지나치게 잘게 분해되지 않도록 어휘와 표현을 보강한다. | MaLA-500, InkubaLM의 다국어 BPE | 기존 임베딩과의 불일치, 추가 사전학습 비용, 언어·방언별 최적점 차이 |

합성 데이터는 실제 데이터를 ‘대체’하는 것이 아니라 부족한 부분을 보완하는 도구에 가깝다. 교사 모델이 틀리면 학생은 규모 있게 틀릴 수 있다. de Gibert 외에서 Macedonian과 Ukrainian 합성 표본의 92% 넘게 사람 평가 80–100점 구간에 들었지만, Georgian은 약 40%가 40점 미만의 수용 불가 품질이었다. 자동 품질 지표와 사람 평가의 Spearman 상관도 대체로 0.26 미만이었다. 같은 생성 파이프라인을 썼다는 사실만으로 언어별 품질을 보장할 수 없다는 뜻이다.

### 4.3 ‘언어 지원’을 최소 여섯 축으로 나눠야 한다

| 축 | 물어야 할 질문 | 혼동하면 생기는 오류 |
|---|---|---|
| 지원 언어 수 | 모델 카드에 어떤 언어가 명시됐고 어떤 문자·방언·코드스위칭을 실제 입력할 수 있는가? | ‘200개 언어’라는 숫자를 모든 언어의 동등한 품질로 읽는다. |
| 훈련 데이터·토큰 | 언어별 토큰, 문서, 병렬 문장, 도메인, 시점, 품질과 중복은 어떤가? | 총 토큰 수만 보고 목표 언어가 충분히 노출됐다고 가정한다. |
| 토크나이저 효율 | 단어·문자당 토큰 수가 얼마나 되며 형태소와 문자를 안정적으로 표현하는가? | 같은 문장이 더 많은 토큰을 써 비용·문맥 길이·학습 효율에서 불리한 점을 놓친다. |
| 과제별 성능 | 번역, 분류, 질의응답, 자유 생성, 추론, 음성 중 무엇을 어떤 지표와 프롬프트로 측정했는가? | BLEU·ChrF·정확도·사람 선호를 하나의 ‘언어 능력’으로 합친다. |
| 현실 배포 | 누가 어떤 장치·가격·지연·안전 조건으로 지속 사용하며 장애와 오류를 누가 고치는가? | 연구 체크포인트 공개를 교육·의료·기업의 실제 혜택으로 바꾼다. |
| 공동체 거버넌스 | 데이터 수집·표준어·방언·라이선스·수정·삭제·수익 배분을 누가 결정하는가? | 성능 향상을 곧 문화 보존과 형평성 달성으로 선언한다. |

토크나이저는 특히 자주 빠지는 축이다. 같은 의미를 표현하는데 저자원 언어 문장이 영어보다 훨씬 많은 토큰으로 쪼개지면, 같은 문맥 창에서 담을 수 있는 정보가 줄고 추론 비용은 늘어난다. 희귀 문자와 풍부한 굴절·교착 형태가 잘게 분해되면 학습 신호도 약해질 수 있다. 원문은 문법·문자·형태론을 ‘보존했다’고 말하지만 어떤 토크나이저 지표나 형태론 평가로 확인했는지는 제시하지 않는다.

### 4.4 2025년 세 연구의 결과를 정확히 읽기

**Alhanai 외 — 사람 번역 벤치마크와 미세조정.** 연구진은 Amharic, Bambara, Igbo, Sepedi, Shona, Sesotho, Setswana, Tsonga의 WinoGrande와 MMLU 일부를 새로 사람 번역하고 Afrikaans, Zulu, Xhosa 평가를 더했다. 새 번역량은 약 100만 단어이고, WinoGrande 3,674문항과 MMLU의 virology 189문항·clinical knowledge 299문항·college medicine 200문항을 포함한다. 400개가 넘는 미세조정 모델 결과에서 단일언어 적응은 평균 +5.6%p, 교차언어 전이는 +2.9%p, 고품질 데이터는 저품질 데이터 대비 +5.4%p를 보였다. 과제와 데이터가 잘 맞은 조건의 평균 최대 향상은 +17.4%p였다. 문화적으로 적합한 문항 하위집합은 평균 +3.0%p, 일부 조건에서는 최대 +15.6%p 높았다. 그러나 GPT-4o의 영어–11개 언어 평균 격차는 과제별 12.0–19.9%p 남았고, 언어별 극단인 Afrikaans와 Bambara 사이에는 과제에 따라 22.9–56.1%p 차이가 있었다. 미세조정한 Llama 3 70B도 GPT-4o보다 낮았다. ‘문화 적합 문항에서 정확도가 다르다’는 결과를 ‘모델이 문화를 보존한다’로 바꿀 수 없다. 근거는 pp. 27802–27805, Table 1 pp. 27805–27806, Figures 2–3 pp. 27808–27809, Limitations p. 27809다.

**Nagar 외 — 합성 코드스위칭 QLoRA.** 연구진은 CommonSenseQA의 1,200개 질문을 Hindi–English로 섞었다. GPT-3.5가 만든 GPTgen과 CoCoa 300M으로 혼합 비율을 통제한 CMI 1(0–16.7%), CMI 2(16.7–30%), CMI 3(30–50%) 조건을 만들었다. 질문만 코드스위칭하고 답 선택지는 영어로 유지했으며, 수동 검토는 매 50개 묶음에서 한 질문, 약 24개 표본이었다. Llama-3-8B-Instruct를 QLoRA로 5 epochs, 학습률 3×10^-5, batch 32로 미세조정하고 5-fold 교차검증과 문항당 5회 추론의 최빈 답을 사용했다.

| 조건 | English accuracy | Hindi accuracy | 영어–Hindi 격차 |
|---|---:|---:|---:|
| Base | 78.0% | 54.0% | 24.0%p |
| GPTgen | 88.8% | 79.6% | 9.2%p |
| CMI 1 | 81.6% | 75.2% | 6.4%p |
| CMI 2 | 90.4% | 85.6% | 4.8%p |
| CMI 3 | 87.2% | 77.2% | 10.0%p |

CMI 2의 4.8%p가 원문의 ‘영어에 근접’이라는 표현과 가장 닮았다. 하지만 이는 단일 언어쌍, 단일 상식추론 다지선다 과제, 영어 선택지, 합성 혼합 질문, 한 기반 모델의 예비 교차검증 평균이다. 논문은 NAACL 2025 Student Research Workshop의 non-archival work-in-progress이며, 자연스러운 코드스위칭 재현·긴 문장·작은 fold·생성 편향·다른 과제로의 일반화를 한계로 밝힌다. 공개 저장소의 기본 학습 설정이 논문과 다르고 결과 체크포인트가 없다는 재현성 문제도 있다. 근거는 §§3.1–3.3, §§4.1–4.2, Table 1, §§5–8이다.

**de Gibert 외 — LLM 생성 병렬 데이터와 기계번역.** GPT-4o-2024-08-06이 English Europarl을 Basque, Scottish Gaelic, Georgian, Icelandic, Macedonian, Somali, Ukrainian으로 번역했다. 언어별로 약 202만–235만 정렬 문장을 만들고 Europarl 구조로 147개 추가 언어쌍을 피벗했다. 실험은 약 60.6M Transformer-base, OPUS-MT, NLLB-200-distilled-1.3B, Llama-3.2-3B-Instruct를 FLORES-200에서 비교했다.

- 합성 데이터만으로 훈련한 60.6M Transformer의 English→Georgian은 49.49 ChrF로 NLLB baseline 48.31보다 높았다.
- NLLB 미세조정은 평균 +2.95 ChrF를 얻었다.
- Llama 미세조정은 평균 +20.63 ChrF 향상했지만 절대 성능은 작은 MT 전용 모델보다 여전히 낮았다.
- OPUS-MT의 Finnish→Somali와 Somali→Finnish는 각각 +14.78, +21.64 ChrF 향상했다.
- 같은 OPUS-MT의 Finnish→Ukrainian과 반대 방향은 각각 -1.21, -1.78 ChrF로 하락했다.

이 결과는 합성 데이터가 특정 저자원 MT를 크게 돕기도 하고 다른 방향을 해치기도 함을 동시에 보여 준다. English Europarl의 의회·정치 도메인 편향, GPT-4o가 이미 번역을 잘한 7개 언어의 사전 선택, 언어별 100개에 불과한 사람 평가, 폐쇄형 교사와 라이선스, 환각 문구, 벤치마크 오염 가능성이 남는다. 근거는 arXiv v1 §§3–5, Tables 1–5, Figure 1이다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. **문제 제기**: 영어·중국어·스페인어 중심의 디지털 자료와 LLM이 저자원 언어 사용자를 배제한다고 설명한다.
2. **핵심 주장**: 2025년에 합성 데이터, 교차언어 전이, 특화 훈련을 결합한 결정적 돌파구가 나왔다고 말한다.
3. **방법의 일반화**: 점진적 미세조정, 커리큘럼 학습, 저데이터 정규화, 언어·문화별 평가가 하나의 파이프라인을 이뤘다고 서술한다.
4. **응용과 영향**: 번역, 교육, 의료, 기업 자동화, 문화 보존에서 실제 접근성이 크게 늘었다고 확대한다.
5. **한계와 유산**: 합성 데이터 품질·언어 거리·계산 자원을 한계로 들면서도, 2025년의 변화가 이후 수년과 다른 AI 분야를 바꿨다고 결론짓는다.

문제의식과 일반적인 한계는 대체로 타당하다. 그러나 원문은 모델·논문·데이터셋·언어 목록·성능표·외부 참고문헌을 제시하지 않는다. 가장 가까운 세 연구를 역추적해도 다음과 같은 교정이 필요하다.

| 원문의 표현 | 1차 자료가 뒷받침하는 범위 |
|---|---|
| 2025년의 단일한 결정적 돌파구 | 해당하는 한 연구가 없다. 합성·전이·다국어 평가의 핵심 축은 XLM, NLLB, Aya 등 2019–2024년 선행 연구에 이미 있었다. |
| 여러 저자원 언어에서 영어에 근접한 범용 성능 | Alhanai 외에는 평균 12.0–19.9%p 격차가 남았다. Nagar 외의 4.8%p는 Hindi–English 한 혼합 과제에만 해당한다. MMLU-ProX도 영어와 스와힐리어 사이 큰 격차를 보고했다. |
| progressive fine-tuning·curriculum learning이 핵심 | 원문이 가리키는 특정 실험을 식별할 수 없고, 가까운 세 연구의 핵심 절차와 일치하지 않는다. NLLB의 정규화도 2022년 MT 연구다. |
| 합성 데이터가 문법과 문화를 보존 | 문화 보존 지표가 없다. de Gibert 외의 합성 품질은 언어별로 크게 달랐고 Nagar 외도 자연스러운 코드스위칭을 충분히 재현하지 못한다고 밝혔다. |
| 새로운 보편적 문화 평가 체계 | Alhanai 외는 번역 벤치마크와 문화 적합 문항 하위집합을 평가했지만 세계 모든 언어·문화에 적용하는 단일 체계를 만들지 않았다. |
| 고품질 저자원↔저자원 번역 | de Gibert 외의 Finnish–Somali는 개선됐지만 Finnish–Ukrainian OPUS-MT는 하락했다. 방향과 모델별 결과다. |
| 데이터 중심에서 기법 중심으로 전환 | 잘못된 이분법이다. Alhanai 외는 값비싼 사람 번역, de Gibert·Nagar 외는 대량 합성 데이터와 기존 데이터셋에 의존했다. |
| 교육·의료·기업 도구가 실제 제공됨 | 세 연구 모두 해당 현장 배포, 사용자 수, 안전성, 학습·건강·경제 결과를 평가하지 않았다. |
| 문화 보존과 언어 부흥을 달성 | 가능한 목표이지만 언어 사용 증가, 세대 간 전승, 공동체 만족·통제권을 측정한 증거가 없다. |
| 수십억 명이 고급 AI에 새로 접근 | 잠재 사용자 인구와 실제 접근·채택·혜택을 혼동한다. 비용·인프라·라이선스·지원·문해력의 증거가 필요하다. |
| 비전·멀티모달·의료영상으로 직접 파급 | 저데이터 학습이라는 일반적 유사성을 확인된 영향 계보로 바꾼 서술이다. 직접 인과 근거가 없다. |
| 이후 수년간 확립된 유산 | 원문은 2025-08-28에 공개됐다. 당시 이후 수년의 영향과 배포를 완료된 사실로 판정할 수 없다. |

## 6. 왜 중요한가

저자원 언어 연구의 중요성은 단순히 ‘언어 수를 늘리는 것’에 있지 않다. 모델이 모어로 된 정보를 제대로 이해하고 생성하지 못하면 사용자는 영어로 번역하는 추가 비용을 지고, 오류를 감지하기도 더 어렵다. 같은 서비스가 언어에 따라 다른 정확도·비용·위험을 제공하면 접근 가능성만이 아니라 안전과 의사결정의 형평성도 달라진다.

기술적으로도 이 분야는 LLM의 규모 법칙만으로는 보이지 않는 문제를 드러낸다. 모델 매개변수가 커도 목표 언어 토큰이 적거나 토크나이저가 부적합하면 작은 지역 특화 모델보다 특정 과제에서 약할 수 있다. InkubaLM은 0.422B 매개변수와 총 24억 토큰으로 훈련됐다. 이 중 약 19억 토큰은 Hausa, Yoruba, Swahili, isiZulu, isiXhosa이고 나머지는 영어·프랑스어였다. 감성 분석·기계번역·AfriMMLU·AfriXnli 같은 정해진 평가에서 더 큰 일부 모델과 경쟁하거나 앞선 결과는 ‘작고 현지에 맞춘 데이터’의 가치를 보여 주지만, 모든 과제에서 우수하다는 뜻은 아니다.

NLLB-200은 범위와 품질을 동시에 다루는 대표적인 선행 사례다. 200개 언어와 4만 개가 넘는 방향을 평가하고 이전 SOTA 대비 평균 44% 상대 BLEU 개선을 보고했으며, 148개 언어에서 11억 개가 넘는 새 문장쌍을 마이닝했다. Nature 논문은 공개 후 4개월 시점에 NLLB가 Wikipedia 편집자가 사용한 기계번역 엔진 중 세 번째로 많이 쓰였고 게시 번역의 3.8%를 차지했다고 보고한다. 이는 실제 사용의 좁고 유의미한 증거지만, 전 세계 교육·의료·기업 배포나 범용 LLM 영어 동등성을 뜻하지 않는다. 모델 카드도 연구용 번역을 주용도로 두고 생산·의료·법률 사용을 범위 밖으로 명시하며, 대표 체크포인트의 라이선스는 CC BY-NC 4.0이다.

Aya는 또 다른 축을 보여 준다. Aya Model은 101개 언어 중 절반 넘게를 더 낮은 자원 등급에서 포함했고, 99개 언어에 걸친 판별·생성 과제, 사람 평가, 모의 승률을 사용했다. Aya Dataset 연구는 65개 언어의 사람 작성 지시 자료와 119개국 참여자, 번역·템플릿으로 확장한 114개 언어 5억 1,300만 인스턴스를 구분한다. 참여 규모는 중요하지만, 참여가 곧 각 언어 공동체의 장기적 데이터 주권과 제품 결정권을 보장하는 것은 아니다.

### 응용 가능성과 실증 상태

| 응용 | 현재 자료가 직접 지지하는 것 | 실제 효과를 말하기 위해 더 필요한 것 |
|---|---|---|
| 기계번역 | NLLB와 de Gibert 외가 특정 언어·방향·벤치마크에서 품질 개선을 보고 | 현지 도메인별 사람 평가, 잘못된 번역의 피해, 방언·코드스위칭, 비용과 지속 운영 |
| 교육 | 모어 지시 추종과 질의응답이 교육 도구의 구성 요소가 될 가능성 | 학습자 대상 시험, 교과 정합성, 교사 감독, 연령별 안전, 장기 학습 성과 |
| 의료 | 현지 언어 이해·번역이 소통 보조에 쓰일 가능성 | 임상 용어 정확도, 긴급 상황 오류, 개인정보, 의료진 승인, 환자 결과와 규제 평가 |
| 기업·공공 서비스 | 현지 언어 챗봇과 문서 자동화의 기술적 가능성 | 실제 조직 배포, 서비스 도달률, 실패·불만 처리, 가격, 노동 영향과 차별 분석 |
| 문화 보존·언어 부흥 | 기록·검색·학습 자료 제작을 보조할 가능성 | 공동체 주도 데이터 수집, 방언·표기 선택권, 동의·철회·수정 권한, 실제 언어 사용과 전승 변화 |

특히 중요한 점:

- 과제별 성능 향상을 정확히 기록하면 어떤 기법이 어느 조건에서 재사용 가능한지 알 수 있다.
- 작은 모델·PEFT·합성 데이터는 적응 비용을 줄일 수 있지만, 검증·서빙·거버넌스 비용까지 없애지는 않는다.
- 형평성은 영어 점수와의 차이 하나가 아니라 오류의 피해, 접근 비용, 통제권, 지속 가능성을 포함하는 시스템 속성이다.

## 7. 현대 LLM과의 연결

- **[[062_XLM Cross-lingual Language Model for Multilingual NLP|XLM과 교차언어 표현]]**: 현대 저자원 언어 적응의 바탕은 고자원 언어에서 ‘지식’을 그대로 복사하는 단순 과정이 아니라, 공유 표현과 병렬 문장 신호를 이용해 언어 사이에 전이 가능한 특징을 학습하는 데 있다. XLM의 MLM·TLM은 이 계보의 대표적 출발점이다.
- **[[072_Instruction Tuning Adapting Language Models to Follow Explicit Instructions|지시 미세조정]]**: Aya, InkubaLM, Alhanai 외는 목표 언어의 지시 형식과 과제 예시가 기반 모델의 언어 지식을 실제 수행 능력으로 바꾸는 데 중요함을 보여 준다. 번역한 지시는 싸게 늘릴 수 있지만 현지 사용자가 실제로 묻는 방식과 어긋날 수 있다.
- **[[091_QLoRA Efficient Fine-Tuning of Quantized Language Models|QLoRA와 매개변수 효율 적응]]**: Nagar 외는 QLoRA로 8B 모델을 적응했다. 이는 전체 미세조정보다 학습 메모리를 줄이지만 실제 실험은 8×A100 80GB 또는 8×H100 80GB 노드를 사용했다. ‘PEFT 사용’과 ‘현지 기관이 저비용으로 전체 파이프라인을 운영 가능’은 같은 말이 아니다.
- **[[033_BLEU Metric - Automatic Evaluation for Machine Translation|BLEU·ChrF와 번역 평가]]**: NLLB의 BLEU, de Gibert 외의 ChrF·COMET은 번역 출력과 참조 번역의 가까움을 측정한다. 지시 추종, 자유 생성, 사실성, 문화 적합성, 의료 안전을 직접 측정하지 않는다.
- **[[095_BIG-bench and MMLU Comprehensive Evaluation Benchmarks for Large Language Models|MMLU 계열 평가]]**: Alhanai 외의 MMLU 일부 번역과 MMLU-ProX는 언어별 지식·추론 격차를 드러낸다. 번역 품질과 문항의 문화적 전제가 점수에 섞일 수 있으므로 영어 원문 점수만을 절대 기준으로 삼아도 안 된다.
- **[[082_BLOOM Open-Access Multilingual Language Model and the Democratization of AI Research|다국어 공개 모델과 접근성]]**: BLOOMZ, Aya, InkubaLM처럼 가중치나 데이터가 공개된 모델은 지역 연구의 출발 비용을 낮춘다. 그러나 Apache-2.0, CC BY-NC, Llama Community License, 독점 API처럼 자산별 조건이 다르므로 ‘오픈’도 모델·데이터·코드·상업 이용별로 분해해야 한다.

이 계보는 범용 모델 하나가 모든 언어를 균등하게 흡수하는 방향과, 작은 모델·어댑터·현지 데이터로 목표 언어를 깊게 다루는 방향이 공존함을 보여 준다. 최선의 선택은 언어 수가 가장 많은 모델이 아니라 목표 과제, 장치, 데이터 권리, 검증 능력에 맞는 시스템이다.

## 8. 한계와 비판적 관점

- **특정 2025년 사건의 부재**: 원문에는 연구팀·모델·데이터셋·언어 목록·표·DOI가 없다. 가까운 세 연구를 합쳐도 원문 전체 서사가 나오지 않으므로 `verification: partial` 수준으로 읽어야 한다.
- **영어 동등성의 과장**: 번역 ChrF, 아프리카 언어 객관식 정확도, Hindi 코드스위칭 CommonSenseQA를 같은 능력 척도로 합칠 수 없다. MMLU-ProX v1 Table 1의 Qwen2.5-72B 영어 70.3% 대 스와힐리어 40.1%는 일반 격차가 남았다는 별도 증거다.
- **선택 편향**: de Gibert 외는 39개 후보 중 GPT-4o가 이미 쓸 만한 번역을 만든 7개 언어를 골랐다. 완전히 미지원인 언어에서도 같은 결과가 난다고 추론할 수 없다.
- **합성 데이터의 언어별 실패**: Georgian 품질 실패, Finnish–Ukrainian 성능 하락, Nagar 외의 부자연스러운 코드스위칭은 합성 데이터가 규모와 함께 오류도 확대할 수 있음을 보여 준다.
- **사람 데이터의 필수성**: Alhanai 외의 사람 번역·검증 비용은 약 40,218.78달러였고 언어별 수정 비율은 4.9–65.3%였다. 기술 혁신이 현지 언어 전문가의 노동을 제거했다는 서술은 부정확하다.
- **토크나이저와 문자 체계**: 언어 코드가 지원돼도 단어가 과도하게 분절되면 비용·문맥·학습 효율이 악화된다. 원문은 보존을 주장하지만 토큰 효율·형태론·철자 변이 평가를 제시하지 않는다.
- **도메인 편향**: Europarl는 의회·정치, CommonSenseQA는 영어권 상식, 번역된 MMLU는 학술 객관식 문항이다. 일상 대화, 구전 지식, 의료·교육 현장을 대표하지 않는다.
- **문화 적합성과 문화 권위의 혼동**: 문화적으로 적합한 문항에서 정확도가 높아졌다는 결과는 유용하지만, 모델이 공동체의 가치·정체성·표준어 결정을 대표한다는 뜻은 아니다.
- **코드스위칭의 진정성**: 실제 화자는 상황·관계·정체성에 따라 언어를 섞는다. CMI 비율로 만든 합성 Hinglish와 영어 선택지의 과제는 이 사회언어학적 복잡성을 일부만 반영한다.
- **평가 번역의 불확실성**: 같은 개념을 옮겨도 난도·관용 표현·문화 배경이 달라질 수 있다. 자동 점수, 번역 검수, 원어민 사람 평가와 현장 과제를 함께 써야 한다.
- **재현성과 라이선스**: GPT-3.5·GPT-4o의 폐쇄형 출력, Nagar 논문과 저장소 설정 불일치, 비공개 체크포인트, OpenAI 사용 조건, NLLB 비상업 라이선스, Llama 커뮤니티 라이선스가 독립 재현과 배포를 제한한다.
- **계산 접근성**: QLoRA는 메모리를 줄이지만 Nagar 외는 다중 A100/H100 노드를 썼고, de Gibert 외는 수백만 문장의 GPT-4o 생성에 의존했다. 학습·추론·검증·운영의 총비용을 따로 계산해야 한다.
- **공동체 거버넌스**: 웹에서 자료를 찾거나 외부 모델로 합성하는 일에는 동의, 저작권, 데이터 주권, 방언 선택, 삭제·수정 권한, 수익 배분 문제가 따른다. 벤치마크 점수는 이 권리 문제를 해결하지 않는다.
- **배포와 연구 체크포인트의 차이**: 모델을 공개하거나 한 벤치마크를 통과한 사실은 서비스가 안정적으로 제공되고 사용자가 혜택을 얻었다는 증거가 아니다. 접근 경로, 가격, 지원, 장애, 안전 사건, 실제 이용률이 필요하다.
- **고위험 분야**: 의료 번역과 환자 소통은 작은 의미 오류도 큰 피해를 줄 수 있다. 의료·법률 사용을 범위 밖으로 둔 모델 카드를 무시하고 일반 언어 점수를 현장 안전성으로 바꾸면 안 된다.
- **시간상 성립하지 않는 유산**: 2025년 8월 공개 글이 ‘이후 수년간의 영향’을 과거형으로 확정한 부분은 역사 기록이 아니라 전망이다. 후속 인용·배포·정책 변화를 별도 자료로 검증해야 한다.

올바른 비판은 ‘저자원 언어 모델은 불가능하다’가 아니다. 확인된 개선은 실재한다. 다만 어느 언어, 데이터, 모델, 과제, 지표, 비용, 라이선스, 사람 검증에서 얻었는지를 붙여야 다른 공동체가 결과를 재사용하고 위험을 판단할 수 있다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 저자원 언어(low-resource language) | 특정 언어·도메인·과제에서 학습·평가 데이터, 도구, 전문가, 컴퓨팅 기반이 상대적으로 부족한 상태. 화자 수와 동일하지 않다. |
| 고자원 언어(high-resource language) | 대규모 디지털 텍스트·병렬 말뭉치·벤치마크·도구를 비교적 쉽게 구할 수 있는 언어. 모든 도메인에서 항상 고자원인 것은 아니다. |
| 교차언어 전이(cross-lingual transfer) | 한 언어 또는 여러 언어에서 학습한 표현과 과제 지식을 목표 언어 수행에 재사용하는 것 |
| 합성 데이터 | 사람의 자연 발생 자료를 그대로 수집하지 않고 모델의 번역·생성·변형으로 만든 학습 예시 |
| 병렬 말뭉치(bitext) | 같은 내용을 두 언어로 대응시킨 문장 또는 문서 쌍. 기계번역의 핵심 학습 자원 |
| 역번역(back-translation) | 목표 언어 단일언어 문장을 출발 언어로 번역해 합성 병렬 자료를 만드는 증강법 |
| 코드스위칭(code-switching) | 한 발화나 대화 안에서 둘 이상의 언어를 번갈아 사용하는 현상 |
| Code-Mixing Index(CMI) | 문장 안에서 언어별 단어 비율을 바탕으로 혼합 정도를 수치화한 지표 |
| 지시 미세조정 | 지시–응답 예시로 사전학습 모델을 조정해 사용자의 과제 지시를 따르게 하는 학습 |
| QLoRA | 양자화한 기반 모델에 저랭크 어댑터를 학습해 전체 미세조정의 메모리 비용을 줄이는 PEFT 기법 |
| 토크나이저 비옥도(tokenizer fertility) | 한 단어 또는 일정한 문자량이 평균 몇 개의 토큰으로 분해되는지 나타내는 효율 지표 |
| ChrF | 번역문과 참조문의 문자 n-gram 정밀도·재현율을 결합한 기계번역 지표 |
| 영어 동등성(parity) | 같은 과제·데이터·프롬프트·평가에서 영어와 다른 언어의 성능 격차가 충분히 작다는 제한적 판정. 범용 능력이나 사회적 형평성과 같지 않다. |
| 데이터 주권 | 공동체가 자기 언어 데이터의 수집, 저장, 접근, 사용, 수정, 삭제와 이익 배분을 결정할 권리 |
| 벤치마크 동등성과 사회적 형평성 | 전자는 정해진 시험 점수의 격차이고, 후자는 접근 비용·오류 피해·권리·실제 결과까지 포함한다. |

## 12. 짧은 결론

저자원 언어 LLM 연구의 실제 역사는 2025년 한 번의 돌파구가 아니라 여러 층의 누적이다. XLM은 교차언어 표현을, NLLB-200은 200개 언어 기계번역을, Aya는 101개 언어 지시 추종을, MaLA-500은 광범위한 언어 적응을, InkubaLM은 작고 지역 중심인 모델의 가능성을 보여 주었다. 2025년 Alhanai·de Gibert·Nagar 외 연구는 사람 번역 벤치마크, 교차언어 미세조정, LLM 합성 병렬 자료, 코드스위칭 QLoRA라는 서로 다른 방법을 좁은 조건에서 더 구체적으로 시험했다.

그 결과는 유망하지만 서로 바꿔 쓸 수 없다. Alhanai 외에는 영어 격차가 상당히 남았고, de Gibert 외에는 언어·방향별 개선과 실패가 함께 있었으며, Nagar 외의 작은 격차는 단일 Hindi–English 혼합 상식추론 과제에 한정됐다. NLLB의 번역 점수나 MMLU-ProX의 지식·추론 정확도도 일반 대화, 의료 안전, 교육 성과, 문화 보존을 대신하지 않는다.

따라서 이 주제의 핵심 표현은 ‘영어와 동등한 AI가 완성됐다’가 아니라 ‘언어·과제별 격차를 줄이는 방법과 검증 기준이 구체화됐다’이다. 포용적 AI는 더 많은 언어 코드를 모델에 넣는 데서 끝나지 않는다. 고품질 현지 데이터와 토크나이저, 명시적인 과제 평가, 현실적인 계산·라이선스, 사람 검증, 공동체의 동의와 통제권이 함께 갖춰질 때 비로소 접근성 향상이 실제 형평성으로 이어질 수 있다.

# 개념 의존과 정규 의미 표현 해설

## 1. 한눈에 보기

- 핵심 주제: 서로 다른 문장이 같은 사건을 나타낼 때, 표면 통사와 어휘를 넘어 공통된 개념 구조로 바꾸어 저장·추론하는 방법
- 등장 배경: 1960년대 자연어 프로그램이 구문 분석을 넘어 바꿔쓰기, 모호성 해소, 기억, 추론을 함께 다뤄야 했던 상황
- 가장 중요한 아이디어: 언어 표현을 행위·개체·상태와 그 의존 관계로 이루어진 언어 비종속적 네트워크에 대응시킨다.
- 이후 LLM/NLP에 미친 영향: 구조적 의미 표현과 지식 기반 이야기 이해의 대표적 전례가 되었지만, AMR·PropBank·현대 LLM의 직접 계보라고 단정할 근거는 부족하다.

> 이 문서는 `011_Conceptual Dependency - Canonical Meaning Representation for Natural Language Understanding.md`의 번역을 공부하기 위한 해설이다. 원문의 설명을 되풀이하기보다 1969·1972·1973·1975·1977년 문헌을 구분하고, 시스템의 실제 범위와 후대 기술과의 비교 한계를 점검한다.

## 2. 핵심 요약

개념 의존(Conceptual Dependency, CD)은 자연어 문장을 통사 구조 그대로 저장하지 않고, 언어에 직접 종속되지 않는 개념 네트워크로 바꾸려는 표현 이론이다. 섕크와 테슬러의 1969년 파서는 입력에서 개념을 식별·중의성 해소하고, 행위자·행위·대상 등의 의존 관계를 네트워크에 놓는 것을 목표로 했다. 같은 뜻을 여러 방식으로 말해도 같은 내부 표현에 접근하게 하려는 정규화가 핵심이었다. 이 표현 위에 추론과 생성기를 붙인 MARGIE는 바꿔쓰기와 여러 종류의 추론을 시연했다. 이어 SAM은 스크립트로 전형적 사건과 생략된 정보를 보완했고, PAM은 행위자의 계획과 목표를 추론했다. 그러나 어휘 의미와 원시 행위의 대응, 세계 지식, 추론 규칙은 대부분 사람이 만들어야 했다. 그래서 좁은 예제에서 명시적이고 추적 가능한 추론을 제공하는 대신, 개방된 언어로 확장할 때 지식 획득과 중의성 해소가 병목이 되었다.

- 무엇을 새로 만들었는가: 자연어 입력을 개념들의 의존 네트워크로 바꾸는 분석·표현 체계
- 어떤 문제를 해결하려 했는가: 표현이 다른 바꿔쓰기의 통합, 문맥을 이용한 의미 선택, 기억과 추론을 위한 공통 형식
- 어떤 방식을 열었는가: 언어 분석기와 기억·추론·생성기를 하나의 개념 표현으로 연결하는 방식
- 결과적으로 무엇이 바뀌었는가: 문법 분석만으로 끝나지 않고 세계 지식과 추론을 의미 표현 설계의 일부로 다루는 연구 프로그램이 구체화됐다.

## 3. 역사적 배경

개념 의존의 시작을 “1969년의 한 번의 발명”으로만 적으면 중요한 구분이 사라진다. 섕크는 1968년 스탠퍼드 AI 메모에서 언어 개념의 발상을 다뤘고, 1969년 5월 박사학위 논문 *A Conceptual Dependency Representation for a Computer-Oriented Semantics*를 제출했다. 같은 해 학술지 *Linguistics*에 「Conceptual Dependency as a Framework for Linguistic Analysis」가 실렸으며, 9월 COLING에서 래리 테슬러와 작동하는 개념 파서를 발표했다. 이론의 장문의 정식 논문 「Conceptual Dependency: A Theory of Natural Language Understanding」는 1972년 *Cognitive Psychology* 3권 4호, 552–631쪽에 출판됐다.

1969년 COLING 논문은 통사 트리를 출력하는 파서가 아니라, 입력의 기저 의미를 찾아 언어에 매이지 않는 네트워크로 만드는 파서를 설명한다. 당시 구현은 수백 단어 규모의 어휘로 정신과 면담 프로그램에서 작동했다. 이것은 제한 없는 자연어 전반을 해결했다는 뜻이 아니라, 정규 개념 표현으로 곧바로 파싱한다는 연구 가설을 제한된 시스템에서 시험했다는 뜻이다.

MARGIE의 공개 기록도 시기와 기능을 나눠야 한다. 1973년 IJCAI 논문은 개념 구조에서 최대 150개의 바꿔쓰기 문장을 생성한 예와 다섯 종류의 추론을 보고했다. 1975년 JACM 논문 「Inference and Paraphrase by Computer」가 이를 더 자세히 정리했다. 원문이 MARGIE의 능력으로 일반적 질의응답까지 함께 묶지만, 1973년 논문의 직접 시연 중심은 바꿔쓰기와 추론이다. 질의응답은 SAM 관련 1975년 문헌에서 명시적으로 다뤄진다.

- 이전 접근법: 통사 구조 중심 파싱, 표면 문장과 가까운 의미 표기, 좁은 규칙 기반 대화 프로그램
- 당시의 한계: 바꿔쓰기마다 다른 구조가 생기고, 문맥·세계 지식·추론을 분석기와 연결하기 어려웠다.
- 이 주제가 필요했던 이유: 입력 문장을 기억·추론·생성 모듈이 함께 사용할 수 있는 공통 표현으로 바꿀 필요가 있었다.

주요 1차 문헌:

- Roger C. Schank, Larry Tesler, [「A Conceptual Dependency Parser for Natural Language」](https://aclanthology.org/C69-0201/) (1969)
- Roger C. Schank, [「Conceptual Dependency: A Theory of Natural Language Understanding」](https://doi.org/10.1016/0010-0285(72)90022-9) (1972)
- Roger C. Schank 외, [「MARGIE: Memory Analysis Response Generation, and Inference on English」](https://www.ijcai.org/Proceedings/73/Papers/028.pdf) (1973)
- Roger C. Schank, [「The Primitive ACTs of Conceptual Dependency」](https://aclanthology.org/T75-2008/) (1975)
- Robert Wilensky, [「PAM — A Program That Infers Intentions」](https://www.ijcai.org/Proceedings/77-1/Papers/003A.pdf) (1977)

## 4. 핵심 개념 해설

### 4.1 정규 개념 표현

정규화의 목표는 문장의 단어 배열을 지우는 것 자체가 아니다. 같은 사건을 서로 다른 문법과 어휘로 표현해도 기억 속에서는 비교 가능한 하나의 개념 구조로 다루려는 것이다. 1969년 논문은 표현이 언어 비종속적이어야 하며, 번역에서도 한 언어의 입력을 개념 네트워크로 분석한 뒤 다른 언어로 생성할 수 있다는 중간언어 구상을 제시했다. 다만 실제 파서와 생성기는 언어별 어휘·구문 지식을 필요로 하므로 “언어 독립”은 완성된 보편 표현이라는 실증 결과보다 설계 목표로 읽어야 한다.

### 4.2 원시 ACT와 의존 관계

CD는 구체 동사를 ATRANS·PTRANS·MTRANS·PROPEL·INGEST 같은 더 일반적인 원시 ACT로 분해한다. 예를 들어 “주다”는 소유 관계의 이전인 ATRANS로 나타내고, 누가 무엇을 누구에게 옮겼는지를 의존 관계로 연결한다. 이 구조는 행위의 결과를 추론할 공통 지점을 제공한다.

원시 ACT의 수를 고정된 역사적 사실처럼 말하면 안 된다. 1973년 MARGIE 논문은 14개 행위를 사용했다고 적고, 1975년 「The Primitive ACTs of Conceptual Dependency」는 “12개”라고 설명하면서 11개 ACT를 열거한 뒤 PLAN을 덧붙인다. 이론이 발전하면서 목록과 분류가 바뀌었기 때문이다. 원문의 “대략 12개”는 후기 설명의 편의적 요약이지 1969년부터 변하지 않은 완결 목록이 아니다. 원문 도입부의 `TRANSFER`도 정식 단일 ACT라기보다 ATRANS·PTRANS·MTRANS 계열을 쉽게 설명한 일반어에 가깝다.

### 4.3 추론, 스크립트, 계획

개념 표현만으로 모든 추론이 자동 발생하지는 않는다. MARGIE는 개념 구조에 연결된 규칙을 이용해 규범적·주변적·인과적·결과적·예측적 추론을 수행했다. SAM은 식당이나 교통사고처럼 전형적인 사건 순서를 나타내는 스크립트와 입력 이야기를 맞추어 명시되지 않은 사건을 보충했다. PAM은 스크립트로 설명되지 않는 행동에 대해 행위자의 목표와 계획을 가정했다. 세 시스템은 모두 CD 표현을 활용했지만, MARGIE의 문장 수준 추론, SAM의 스크립트 기반 이야기 이해, PAM의 의도·계획 추론이라는 연구 초점은 구분해야 한다.

## 5. 원문의 논리 구조

원문은 대체로 다음 흐름으로 전개된다.

1. 같은 사건을 나타내는 능동·수동·바꿔쓰기 문장이 서로 다른 통사 구조를 갖는 문제를 제시한다.
2. 표면 형식을 공통 의미 구조로 바꾸는 정규 표현의 필요를 주장한다.
3. 원시 행위와 행위자·대상·방향 등의 역할로 CD 구조를 구성하는 방법을 설명한다.
4. 행위 결과, 상태 변화, 중첩된 사건을 추론하는 방식을 제시한다.
5. MARGIE·SAM·PAM을 바꿔쓰기, 이야기 이해, 스크립트, 계획 추론의 응용 사례로 든다.
6. 수작업 어휘·규칙, 원시 요소 선택, 중의성, 정규 형식의 정보 손실이라는 한계를 정리한다.
7. 프레임 의미론, 의미역 결정, AMR, 지식 그래프, LLM을 구조적 또는 기능적 유산으로 연결한다.

앞부분은 실제 CD의 핵심 문제와 잘 맞지만, 마지막 계보 부분은 “비슷한 문제를 다룬다”와 “직접 이어졌다”를 자주 구분하지 않는다. 공개 지식으로 사용할 때는 이 비교를 역사적 영향의 증거로 바꾸어 읽지 않아야 한다.

## 6. 왜 중요했는가

개념 의존의 중요성은 특정 원시 행위 목록이 오늘날 표준으로 남았다는 데 있지 않다. 언어 분석의 출력이 단순한 구문 트리가 아니라 기억·추론·생성에 바로 쓰이는 의미 구조여야 한다는 설계를 작동하는 프로그램으로 시험했다는 점이 중요하다. 또한 같은 내부 구조에서 여러 문장을 생성하고, 명시되지 않은 결과를 도출하는 시연은 “이해”라는 말을 계산 절차와 관찰 가능한 출력으로 구체화했다.

특히 중요한 점은 다음과 같다.

- 분석기·기억·추론기·생성기 사이에 공유되는 표현의 필요를 분명히 했다.
- 바꿔쓰기 동등성을 표면 문자열이 아니라 내부 개념 구조의 문제로 다뤘다.
- 언어 이해가 세계 지식과 기대 구조를 필요로 한다는 사실을 SAM·PAM 같은 후속 시스템으로 드러냈다.

## 7. 현대 LLM과의 연결

CD와 현대 LLM은 모두 표면 문장만 그대로 보관하지 않고 내부 표현을 사용하지만, 그 표현을 얻고 사용하는 방식은 크게 다르다.

- **학습된 분산 표현**: CD의 ACT와 의존 관계는 설계자가 이름과 규칙을 명시한다. LLM의 은닉 상태는 대규모 데이터와 학습 목표에서 연속적인 벡터로 학습되며, 대체로 사람이 읽을 수 있는 고정 슬롯과 일대일로 대응하지 않는다.
- **바꿔쓰기와 의미 유사성**: CD는 두 문장을 같은 정규 그래프로 분석하려 한다. LLM은 문맥적 표현과 학습된 확률 분포를 통해 유사한 문장에 비슷하게 반응할 수 있지만, 동일한 내부 구조를 보장하지 않는다.
- **추론의 추적 가능성**: CD 시스템은 어떤 원시 ACT와 규칙이 결론을 만들었는지 비교적 명시적으로 볼 수 있다. LLM은 넓은 범위를 다루지만 개별 출력의 내부 근거를 같은 방식으로 추적하기 어렵다.
- **도구·에이전트 상태**: 현대 에이전트가 명시적 세계 상태, 행동 전제조건, 계획을 별도로 유지할 때는 CD·SAM·PAM과 기능적으로 비교할 지점이 생긴다. 이는 직접 계승의 증거가 아니라 구조화된 상태가 행동과 추론을 돕는다는 반복되는 설계 문제다.
- **검색 증강 생성**: RAG는 외부 지식을 검색해 문맥으로 제공하지만, CD처럼 그 지식을 하나의 고정 원시 행위 체계로 변환하지 않는다.

## 8. 한계와 비판적 관점

- 기술적 한계: 어휘 의미를 ACT에 대응시키고, 역할을 채우고, 상태 변화와 추론 규칙을 작성하는 작업이 수작업에 크게 의존한다.
- 이론적 한계: 모든 의미를 하나의 정규 구조로 합치면 시점, 초점, 함축, 양태처럼 문장 간에 남는 차이를 지울 수 있다.
- 실용적 한계: 1969년 파서는 수백 단어 규모의 제한된 구현이었고, 후속 시스템도 준비된 이야기 영역과 지식베이스에 의존했다.
- 오늘의 관점에서 다시 볼 점: 명시적 구조가 해석 가능성을 주지만, 어떤 구조와 원시 요소가 충분한지를 사람이 미리 결정해야 한다는 비용이 있다.

원문의 사실관계와 계보에는 다음 정정이 필요하다.

1. 1969년에는 박사학위 논문, *Linguistics* 논문, Schank–Tesler COLING 파서 논문이 있으며, 장문의 이론 정식화는 1972년 논문이다.
2. 원시 ACT의 수와 목록은 시기별로 변했다. “약 12개”를 이론 전체의 고정 명세로 보아서는 안 된다.
3. 술어 논리가 능동·수동문을 필연적으로 서로 다른 술어로 표현한다는 설명은 부정확하다. 논리 표현 설계자는 두 문장을 같은 술어와 논항으로 정규화할 수 있다. CD의 차별점은 논리 일반의 무능력이 아니라, 자연어 분석·상식 추론을 위해 특정 원시 행위와 의존 구조를 적극적으로 설계했다는 데 있다.
4. MARGIE의 1973년 직접 시연은 바꿔쓰기와 다섯 종류의 추론이다. 원문처럼 일반 질의응답 능력을 MARGIE 하나에 일괄 귀속하지 않는다.
5. SAM은 1975년 문헌에서 작동 시스템과 질의응답이 보고됐고, PAM은 늦어도 1976년 예일 연구 보고서에 포함되며 1977년 IJCAI 논문에서 의도 추론 프로그램으로 발표됐다.
6. AMR·PropBank·FrameNet·지식 그래프가 CD의 “직접 후손”이라는 계보는 해당 프로젝트의 1차 문헌만으로 확인되지 않는다. 그래프 표현, 술어-논항, 의미역이라는 비교 가능한 공통점으로 한정한다.
7. AMR은 2013년 논문에서 영어 의미 은행을 위한 그래프 표현으로 제안됐으며, 처음부터 완성된 언어 독립 중간언어로 검증된 것은 아니다. 2014년 다언어 비교 연구 제목도 “Not an Interlingua, But Close”다.

## 12. 짧은 결론

개념 의존은 자연어 이해를 통사 분석 하나가 아니라 공통 의미 표현, 기억, 세계 지식, 추론, 생성이 맞물리는 시스템 문제로 만들었다. 1969년 제한된 개념 파서에서 출발해 1972년 이론 정식화, 1973년 MARGIE, 1975년 SAM, 1977년 PAM으로 이어진 기록을 구분하면 실제 성과와 교육용 서사의 과장을 함께 볼 수 있다. 고정된 원시 ACT와 수작업 지식은 확장성의 한계가 되었지만, 표면 형식이 달라도 비교·추론 가능한 내부 표현이 필요하다는 문제는 현대 의미 파싱과 LLM 기반 시스템에서도 여전히 남아 있다.

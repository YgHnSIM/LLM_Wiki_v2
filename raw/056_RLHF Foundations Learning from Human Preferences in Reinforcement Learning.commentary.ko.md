# 인간 선호 기반 강화학습의 토대 해설

## 1. 한눈에 보기

- 핵심 주제: 행동 구간 두 개에 대한 인간의 비교 판단으로 보상 모델을 학습하고 정책을 최적화하는 방법
- 등장 배경: 복잡한 행동의 좋은 보상을 사람이 수식으로 완전히 작성하기 어려운 문제
- 가장 중요한 아이디어: 보상을 직접 명세하지 않고 선호 비교에서 학습한다
- 이후 LLM/NLP에 남긴 영향: 언어 모델 응답 비교·보상 모델·정책 최적화로 이루어진 현대 RLHF의 선행 프레임워크

> 이 문서는 `056_RLHF Foundations Learning from Human Preferences in Reinforcement Learning.md`의 번역문을 이해하기 위한 해설입니다. 2017년 제어·게임 실험과 후대 언어 모델 RLHF를 구분합니다.

## 2. 핵심 요약

Christiano 등의 2017년 연구는 사람이 두 행동 구간 가운데 더 나은 것을 선택하면 신경망 보상 모델이 그 비교를 예측하고, 정책이 예측 보상을 최대화하도록 학습하는 반복 절차를 제안했다. 사람은 전체 보상 함수를 작성할 필요가 없고 전체 환경 상호작용의 일부만 관찰한다. 보상 모델은 각 구간의 시점별 보상 합을 Bradley–Terry형 확률로 바꿔 선호를 예측한다. 정책이 바뀌면 새 행동 구간을 다시 질의해 보상 모델의 분포 이동을 줄인다. 원 실험은 Atari와 MuJoCo형 시뮬레이션 제어였으며 언어 모델은 다루지 않았다. 언어 응답 비교와 PPO를 결합한 현대 RLHF는 이 아이디어를 다른 출력·모델·훈련 단계에 적용한 후속 발전이다.

- 무엇을 다루는가: 손으로 보상을 작성하기 어려운 강화학습
- 어떤 문제를 해결하려 했는가: 의도와 보상 함수 사이의 명세 격차
- 어떤 방식이 새로웠는가: 행동 구간의 쌍대 선호와 반복 보상 모델 학습
- 결과적으로 무엇을 바꾸었는가: 인간 평가를 정책 최적화의 학습 신호로 재사용하는 틀을 보였다

## 3. 역사적 배경

강화학습은 오랫동안 환경이 주는 보상을 최대화했다. 문제는 점수처럼 목표가 분명한 과제와 달리 안전성·미감·자연스러움은 수식으로 쓰기 어렵다는 데 있었다. 역강화학습은 시연에서 보상을 추론했고, 선호 학습은 비교 판단에서 효용을 추정했다. 2017년 연구는 이 흐름을 심층 보상 모델과 대규모 정책 학습의 반복 과정으로 결합했다.

- 이전 접근법: 손작성 보상, 전문가 시연, 역강화학습, 선호 순위 학습
- 당시의 한계: 보상 허점, 고차원 행동의 시연 비용, 명세가 어려운 질적 목표
- 이 주제가 필요했던 이유: 사람은 정확한 수치보다 두 결과 중 무엇이 나은지 판단하기 쉬운 경우가 많았다

## 4. 핵심 개념 해설

### 4.1 구간 선호 확률

두 구간 $\sigma^0,\sigma^1$의 시점별 예측 보상 합을 비교해 선호 확률을 만든다. 보상 값의 절대 척도보다 두 합의 차이가 중요하다. 이 모델은 인간 가치 전체를 복원하는 것이 아니라 수집된 비교 분포에서 순위를 예측한다.

### 4.2 능동 질의와 ensemble

원 연구는 여러 보상 모델의 예측 불일치를 이용해 어느 비교를 사람에게 물을지 고른다. 이는 보상 모델 하나가 잘 보정된 확신도를 직접 출력한다는 뜻이 아니다. ensemble disagreement는 정보가 클 후보를 고르는 휴리스틱이다.

### 4.3 정책–보상 모델의 동시 변화

정책이 보상 모델을 최적화하면 처음에 없던 행동을 만든다. 고정된 보상 모델만 계속 쓰면 허점을 악용할 수 있다. 새 정책의 구간을 반복 비교하는 이유는 학습 자료를 현재 정책 분포에 맞추기 위해서다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. 손작성 보상 함수의 명세 문제를 제기한다.
2. 인간이 행동 두 개를 비교하는 선호 자료를 도입한다.
3. 보상 모델 학습과 강화학습 정책 최적화를 설명한다.
4. 로봇·Atari에서 언어 모델 RLHF로 영향을 확장한다.
5. 평가자 불일치·비용·보상 해킹·대표성의 한계를 검토한다.

## 6. 왜 중요한가

이 연구는 인간 감독을 단순 최종 평가가 아니라 반복 학습 신호로 바꿨다. 행동 공간을 모두 열거하지 않고도 비교 판단을 일반화하는 보상 모델을 만들 수 있음을 보였다. 또한 정책이 강해질수록 보상 모델의 사각지대가 중요해진다는 현대 정렬 문제를 일찍 드러냈다.

특히 중요한 점:

- 보상 공학과 인간 판단 사이에 학습 가능한 인터페이스를 만들었다.
- 정책 개선과 피드백 수집을 하나의 반복 루프로 연결했다.
- 뒤의 언어 응답 선호 학습이 차용할 일반 절차를 제시했다.

## 7. 현대 LLM과의 연결

- 보상 모델: 동일 prompt의 여러 응답을 비교한 자료에서 선호 점수를 학습한다.
- 정책 최적화: PPO 기반 RLHF는 보상 모델 점수와 기준 정책에서의 이탈 제한을 함께 사용한다.
- 직접 선호 최적화: DPO 계열은 별도 보상 모델·온라인 RL을 명시적으로 거치지 않고 선호 쌍에서 정책을 학습한다.

[[055_The Transformer Attention Is All You Need]]가 계산 구조를 제공했다면, 선호 학습은 사전학습된 모델이 어떤 응답을 더 내도록 할지 정하는 후속 학습 신호다. Transformer와 RLHF를 같은 발명으로 합치지 않는다.

## 8. 한계와 비판적 관점

- 기술적 한계: 보상 모델은 정책이 만드는 분포 밖에서 틀릴 수 있고 최적화가 오차를 증폭한다.
- 이론적 한계: 쌍대 선호는 다차원 가치와 무관심·비교 불가능성을 한 순위로 축약한다.
- 실용적 한계: 평가자 모집·교육·합의·감사에 비용이 들고 문화적 대표성을 보장하기 어렵다.
- 오늘날 관점에서 다시 봐야 할 점: 2017년 연구는 LLM의 도움됨·정직성·무해성을 직접 실험하지 않았고, 현대 RLHF의 모든 구성 요소를 완성하지 않았다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 선호 비교 | 두 행동 또는 응답 가운데 어느 쪽이 나은지 고르는 감독 신호 |
| 보상 모델 | 관측된 비교를 예측하도록 궤적·응답에 스칼라 점수를 주는 모델 |
| 정책 | 상태나 문맥에서 행동·출력 분포를 정하는 모델 |
| 보상 해킹 | 실제 의도보다 보상 함수·모델의 허점을 최적화하는 현상 |
| 능동 질의 | 모델이 불확실하거나 정보가 클 비교를 골라 사람에게 묻는 절차 |

## 12. 짧은 결론

2017년 인간 선호 기반 심층 강화학습은 보상 함수를 손으로 작성하는 대신 비교 판단에서 학습하는 실용적 틀을 세웠다. 현대 LLM RLHF의 중요한 선행이지만, 원 연구의 제어·게임 실험과 후대의 언어 보상 모델·PPO·DPO를 시기와 근거별로 구분해야 그 유산을 정확히 이해할 수 있다.

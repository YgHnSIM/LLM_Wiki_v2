# 장단기 메모리(LSTM) 해설

## 1. 한눈에 보기

- 핵심 주제: 장단기 메모리(Long Short-Term Memory, LSTM)가 순환 신경망의 장거리 신용 할당 문제를 완화하도록 오류 흐름과 상태 접근을 구조적으로 제어한 방식
- 등장 배경: [[순환 신경망]]을 시간을 따라 펼쳐 [[역전파|시간을 통한 역전파]]를 적용하면 시점별 야코비안이 연속해서 곱해져 먼 과거의 학습 신호가 소실하거나 폭주할 수 있었다.
- 가장 중요한 아이디어: 1997년 원형은 상수 오류 순환로(constant error carousel, CEC)와 입력·출력 게이트를 사용했다. 오늘날 익숙한 망각 게이트를 포함한 3게이트 구성은 1999년에 접수되어 2000년에 출판된 후속 연구에서 형성됐다.
- 이후 LLM/NLP에 남긴 영향: LSTM은 게이트 순환망과 후대의 순서열 응용에 중요한 기반이 되었지만, 신경망 기계 번역·attention·Transformer는 별도 논문과 구조적 발명이 더해진 후속 계보다.

> 이 문서는 `028_Long Short-Term Memory - Solving the Memory Problem.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 1997년 원형과 후대의 표준 LSTM을 구분하고, 그래디언트 설명·언어 예시·현대 모델 계보에서 생긴 과장을 바로잡습니다.

## 2. 핵심 요약

LSTM은 순환 상태에 선형에 가까운 자기 연결 경로를 두고 곱셈 게이트로 쓰기와 읽기를 조절해, 먼 시점까지 오류 신호가 전달될 수 있는 조건을 설계한 순환망 계열이다. Hochreiter와 Schmidhuber의 1997년 논문은 고정 가중치 1의 자기 연결을 가진 CEC와 입력·출력 게이트를 제시하고, 인공 장기 지연 과제에서 기존 RNN 학습법보다 성공적인 결과를 보고했다. 이 원형에는 오늘날 표준 수식의 적응형 망각 게이트가 없었다. Gers·Schmidhuber·Cummins의 후속 논문은 1999년에 접수되고 2000년에 출판되면서, 연속 입력에서 셀 상태를 스스로 비울 수 있는 망각 게이트를 추가했다. LSTM의 셀 경로는 장기 그래디언트 흐름을 개선하지만 모든 계산 경로의 [[기울기 소실]]·폭주를 없애거나 임의 길이의 정보를 보존한다고 보장하지 않는다. 1997년 논문의 실험은 합성 장기 지연 과제였으며, 언어 모델링·기계 번역·음성 인식의 대규모 성과는 별도의 후대 연구로 확인해야 한다. 원문이 든 `The cat ... sat` 문장은 `sat`이 주어 수에 따라 변하지 않으므로 주어-동사 수 일치의 증거가 되지 않는다. Transformer는 순환 셀을 계승한 LSTM 변형이 아니라 핵심 순서열 계산에서 recurrence를 제거한 별도 구조다.

- 무엇을 다루는가: LSTM의 역사적 원형, 현대식 게이트 수식, 장기 그래디언트 흐름과 후대 순서열 모델의 관계
- 어떤 문제를 해결하려 했는가: 긴 시간 간격을 사이에 둔 원인과 결과를 그래디언트 학습으로 연결하기 어려운 문제
- 어떤 방식이 새로웠는가: 상태 보존 경로와 그 경로에 대한 입력·출력 제어를 구조적으로 분리한 점
- 결과적으로 무엇을 바꾸었는가: 장기 지연 과제를 학습할 수 있는 게이트 RNN의 실용적 연구 경로를 열었지만, 모든 응용과 후대 구조를 한 번에 만든 것은 아니다.

## 3. 역사적 배경

LSTM 이전에도 [[은닉 마르코프 모델]], 고정 문맥 창, [[시간 지연 신경망]], Jordan형·Elman형 RNN은 순서와 시간 정보를 처리했다. 문제는 순서 처리의 존재가 아니라, 학습 가능한 연속 상태를 통해 먼 시점의 의존성을 안정적으로 찾아내는 일이었다. [[026_순환 신경망과 시간적 문맥 학습]]에서 설명하듯 BPTT는 펼친 시간축에 일반 역전파를 적용하지만, 긴 경로에서는 국소 미분의 연속 곱 때문에 유용한 신호가 약해지거나 커질 수 있다.

## 4. 핵심 개념 해설

### 4.1 반복 야코비안과 기울기 소실

단순 RNN을 $h_t=\phi(W_{xh}x_t+W_{hh}h_{t-1}+b)$로 쓰면, 먼 시점 $k$가 현재 시점 $t$에 미치는 미분은 다음과 같은 시간별 국소 야코비안의 곱을 포함한다.

\[
\frac{\partial h_t}{\partial h_k}
=
\prod_{j=k+1}^{t}J_j,
\qquad
J_j=\partial h_j/\partial h_{j-1}
\]

$J_j$에는 순환 가중치뿐 아니라 활성화 함수의 도함수와 실제 상태 궤적이 함께 들어간다. 관련 방향이 반복해서 수축하면 그래디언트가 소실하고, 팽창하면 폭주할 수 있다. 따라서 원문처럼 `W_{hh}`의 가장 큰 고윳값이 1보다 작은가 큰가만으로 결과를 결정하는 설명은 불충분하다. 비정규 행렬에서는 고윳값과 유한 시간 증폭이 다를 수 있고, 시점마다 달라지는 활성화 도함수도 전체 곱을 바꾼다. [[기울기 소실]]은 먼 과거에 대한 표현 가능성이 전혀 없다는 뜻이 아니라, 손실이 그 의존성을 매개변수에 학습시키기 어려워진다는 뜻이다.

### 4.2 1997년 원형: CEC와 입력·출력 게이트

1997년 LSTM의 중심은 내부 자기 연결 가중치를 1로 고정한 CEC였다. 이 선형 자기 경로에서는 상태에 대한 직접 국소 미분을 1로 유지해, 셀 내부의 오류가 시간에 따라 곧바로 사라지거나 커지는 일을 막으려 했다. 입력 게이트는 새 정보와 외부 오류가 셀 상태에 들어오는 시점을 조절하고, 출력 게이트는 저장된 상태가 다른 유닛과 출력에 드러나는 시점을 조절한다. 원 논문의 표현대로 두 곱셈 게이트가 상수 오류 흐름에 대한 접근을 열고 닫는 구조다.

이 설명에서 중요한 것은 `상수 오류`가 네트워크 전체의 모든 그래디언트가 항상 일정하다는 뜻이 아니라는 점이다. CEC라는 특정 내부 경로의 자기 미분을 보존하는 설계이며, 입력·출력 경로와 게이트 매개변수에는 여전히 비선형 미분과 학습 문제가 남는다. 원 논문의 학습 절차도 오늘날 흔한 완전 BPTT 구현과 같지 않다. 저자들은 수정된 RTRL과 절단 BPTT를 결합해, 해롭지 않다고 본 경로에서 그래디언트를 끊는 국소 근사를 사용했다. 1997년 실험도 실수·잡음·분산 표현을 포함한 인공 장기 지연 과제를 중심으로 했고, 언어 이해나 기계 번역 시스템을 실증하지 않았다.

### 4.3 1999/2000년 이후의 망각 게이트 수식

오늘날 자주 소개되는 LSTM은 보통 다음처럼 쓴다.

\[
i_t=\sigma(W_i[h_{t-1},x_t]+b_i),\quad
f_t=\sigma(W_f[h_{t-1},x_t]+b_f),\quad
o_t=\sigma(W_o[h_{t-1},x_t]+b_o)
\]

\[
\tilde c_t=\tanh(W_c[h_{t-1},x_t]+b_c),\qquad
c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,qquad
h_t=o_t\odot\tanh(c_t)
\]

이 표준화된 형태의 $f_t$는 1997년 원형이 아니라 `Learning to Forget`에서 추가된 적응형 망각 게이트의 후속 계보를 반영한다. 연속 입력이 명시적으로 분절·초기화되지 않을 때 셀 상태가 계속 누적되는 문제를 다루고, 셀이 필요할 때 내부 자원을 스스로 비우게 한 것이 목적이었다.

게이트와 후보값을 고정해서 보는 직접 셀 경로의 미분은 대략 $f_t$의 연속 곱으로 나타난다. $f_t$가 필요한 구간에서 1에 가까우면 신호를 오래 보존할 수 있지만, 여러 시점에서 1보다 작으면 이 경로도 감쇠한다. 실제 전체 야코비안에는 $h_{t-1}$을 통한 게이트·후보값의 간접 의존성도 포함된다. 그러므로 `덧셈이 있으니 반복 곱이 사라진다`거나 `LSTM은 기울기 소실을 해결했다`고 무조건 표현하지 않고, 보존 가능한 경로와 학습 가능한 제어를 추가해 문제를 완화했다고 설명하는 편이 정확하다.

### 4.4 셀 상태, 기억 비유와 주어-동사 예시

셀 상태를 장기 기억이라고 부르는 것은 유용한 비유지만, 특정 차원이 `주어의 단수성` 같은 기호를 반드시 저장한다는 뜻은 아니다. 어떤 정보가 어느 방향에 표현되고 언제 유지·삭제·노출되는지는 과제, 데이터, 손실, 상태 차원과 최적화 결과에 달려 있다. 게이트 출력도 사람이 지정한 문법 규칙이 아니라 학습된 연속 값이다.

원문의 `The cat that chased the mice across the yard sat on the mat` 예시는 주어-동사 **수 일치**를 보여 주지 못한다. 영어 과거형 `sat`은 단수와 복수 주어에 동일하게 쓰이며, 원문이 대안으로 든 `sitted`는 복수형도 올바른 과거형도 아니다. 수 일치를 설명하려면 `The cat that chased the mice sits ...`와 `The cats that chased the mouse sit ...`처럼 현재형이 주어 수에 따라 달라지는 사례가 적절하다. 이 교정된 문장도 가능한 학습 과제를 설명하는 예시일 뿐, 특정 LSTM이 그 의존성을 실제로 학습했다는 실험 증거는 아니다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. 단순 RNN의 장기 의존 학습을 기울기 소실·폭주 문제로 제시한다.
2. 현대식 셀 상태와 입력·망각·출력 게이트를 1997년 LSTM의 해법으로 설명한다.
3. 언어 모델링·기계 번역·음성 인식 등 후대 응용을 LSTM 도입의 효과로 묶는다.
4. 주어-동사 수 일치 예시로 선택적 기억을 직관화하고, GRU·양방향·적층 변형과 한계를 소개한다.
5. attention과 Transformer를 LSTM의 선택적 정보 흐름 원리가 이어진 결과로 해석한다.

이 흐름은 직관을 제공하지만 서로 다른 시기의 구조와 실험을 한 서사에 합친다. 해설에서는 **1997년 원형**, **1999/2000년 망각 게이트**, **2014년 이후 실제 NLP 응용**, **2017년 Transformer의 비순환 구조**를 별도 단계로 읽는다.

## 6. 왜 중요한가

LSTM의 핵심 의의는 `더 오래 기억하는 유닛`이라는 비유보다, 미분 가능한 계산 경로 자체를 설계해 장기 신용 할당을 개선했다는 데 있다. 단순 RNN의 상태 변환을 그대로 반복하는 대신, 비교적 안정적인 내부 경로와 학습 가능한 접근 제어를 분리했다. 이는 모델 구조가 표현 능력뿐 아니라 최적화 가능성도 바꾼다는 중요한 사례다.

특히 중요한 점:

- 특정 내부 경로의 오류 흐름을 보존하도록 구조를 설계해 장기 지연 과제의 학습 성공률을 높였다.
- 상태에 쓰기, 상태를 유지·초기화하기, 상태를 출력으로 노출하기를 서로 다른 연산으로 나눴다.
- LSTM·GRU와 여러 게이트 RNN이 음성·언어·시계열 분야에서 후속 실험을 축적할 수 있는 출발점을 제공했다.
- `표현할 수 있음`과 `그래디언트로 실제 학습할 수 있음`을 구분하게 만들었다.

다만 `모든 순서열 모델에 영향을 주었다`거나 `처음으로 신경망 언어 처리를 가능하게 했다`는 보편 명제는 근거 범위를 넘는다. 1994년 RNN 음성 응용처럼 LSTM 이전 사례가 있었고, HMM·TDNN 같은 다른 계열도 이미 순서를 처리했다.

## 7. 현대 LLM과의 연결

### 7.1 확인 가능한 직접 계보: LSTM sequence-to-sequence

2014년 [Sequence to Sequence Learning with Neural Networks](https://proceedings.neurips.cc/paper_files/paper/2014/hash/5a18e133cbf9f257297f410bb7eca942-Abstract.html)은 다층 LSTM encoder가 입력을 고정 차원 벡터로 읽고 다른 LSTM decoder가 출력 순서열을 생성하는 구조를 실제 영어-프랑스어 번역에 적용했다. 이것은 LSTM에서 [[신경망 기계 번역]]으로 이어지는 구체적인 직접 응용 계보다. 그러나 이 성과는 1997년 원 논문의 실험 결과가 아니라 대규모 병렬 말뭉치, 깊은 구조, 계산 자원과 별도의 학습·디코딩 설계가 결합된 2014년 연구다.

### 7.2 RNN attention은 고정 벡터 병목에 대한 후속 해법

초기 encoder–decoder는 입력 전체를 마지막 encoder 상태 하나에 압축했다. Bahdanau·Cho·Bengio의 attention은 decoder의 각 출력 시점마다 encoder의 여러 시점 상태를 가중 결합해 이 병목을 완화했다. 이 구조에서는 attention과 recurrent state가 함께 사용된다. attention을 `망각 게이트를 크게 만든 것`으로 환원할 수 없고, 모든 LSTM이 고정 벡터 하나만 사용하는 것도 아니다.

### 7.3 Transformer와 LSTM의 연결은 문제 수준에서 제한한다

2017년 [Attention Is All You Need](https://proceedings.neurips.cc/paper_files/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html)은 핵심 encoder·decoder 표현 계산에서 recurrence와 convolution을 사용하지 않고 self-attention과 위치 표현을 채택했다. 학습 시 여러 위치를 병렬로 처리하기 쉬워졌지만, 표준 self-attention의 비용은 순서열 길이에 대해 제곱으로 커질 수 있고 자기회귀 생성은 앞선 출력에 의존한다. `관련 정보를 선택적으로 전달한다`는 넓은 기능적 유사성은 있지만, attention 가중치와 LSTM 게이트는 연산 대상·정규화·상태 구조가 다르다. Transformer를 LSTM 셀의 직접 후손으로 두지 않는다.

### 7.4 GPT·BERT·LLM은 순환 상태를 쓰지 않는다

GPT·BERT 계열의 [[대규모 언어 모델]]은 Transformer에 기반하며 LSTM식 단일 셀 상태를 시간마다 갱신하지 않는다. 두 계열은 [[역전파]]로 매개변수를 학습하고 문맥 의존성을 모델링한다는 공통점이 있지만, 문맥을 전달하는 계산 그래프는 다르다. LSTM이 현대 LLM을 단독으로 가능하게 했다고 설명하기보다, 장기 신용 할당과 정보 경로 설계라는 공통 문제에 서로 다른 구조가 답한 역사로 읽는 편이 정확하다.

## 8. 한계와 비판적 관점

### 8.1 원문에서 바로잡아야 할 주장

- **1997년부터 3게이트**: 원형에는 CEC와 입력·출력 게이트가 있었고, 적응형 망각 게이트는 1999년 접수·2000년 출판된 후속 연구의 기여다.
- **기울기 소실 해결**: 특정 셀 경로의 오류 흐름을 개선했지만 전체 네트워크의 소실·폭주와 장기 신용 할당을 모든 조건에서 제거하지 않는다.
- **초기 시간 단계의 매개변수가 초깃값에 갇힘**: 일반적인 RNN은 시간마다 다른 매개변수를 두지 않고 같은 순환 가중치를 공유한다. 먼 시점의 학습 신호가 약해지는 현상을 시점별 매개변수가 따로 멈춘 것처럼 설명하지 않는다.
- **후보값 tanh가 셀 상태의 무한 성장을 방지**: tanh는 한 시점의 후보 갱신량만 제한한다. 여러 시점의 덧셈으로 누적되는 셀 상태 자체를 항상 유계로 만들지는 않으며, 이 문제가 망각 게이트를 도입한 후속 연구의 동기였다.
- **시그모이드 게이트가 정확히 0 또는 1을 출력**: 유한한 입력에서 표준 시그모이드 출력은 0과 1 사이의 연속값이며, 실제 설명에서는 `0 또는 1`보다 `0 또는 1에 가까운 값`이라고 해야 정확하다.
- **LSTM이 게이팅 자체를 발명**: 곱셈 유닛과 게이트 아이디어에는 선행 연구가 있다. 1997년 LSTM의 구체적 기여는 CEC의 상수 오류 경로에 대한 입력·출력 접근을 학습 가능한 게이트로 제어한 구조다.
- **최초의 실용 언어·음성 신경망**: 1997년 논문은 합성 장기 지연 과제를 다뤘다. 실제 언어 모델링·번역·음성 성과는 과제별 후속 문헌으로 확인해야 한다.
- **주어-동사 예시**: `sat`은 수 일치 표지가 아니며 `sitted`는 올바른 대안이 아니다.
- **GRU는 입력·망각 게이트의 단순 결합**: GRU는 단일 상태에서 reset gate와 update gate로 새 상태를 계산하는 별도 순환 유닛이다. LSTM과의 기능적 비교는 가능하지만 두 게이트를 문자 그대로 합친 구조로만 정의하지 않는다.
- **도식이 남아 있다는 전제**: 수집된 원문에는 `Loading component...`라는 UI 문구만 있고, 뒤 문단이 가리키는 실제 도식은 없다. 색상·위치 설명은 확인할 그림이 결손된 상태로 읽어야 한다.
- **Transformer의 직접 계보**: Transformer는 recurrence를 제거한 별도 구조이며, attention을 LSTM 게이트의 확대판으로 동일시할 수 없다.
- **게이트 학습은 메타학습**: 한 과제의 손실로 게이트 매개변수를 함께 학습하는 일반적인 LSTM 훈련을 그 자체로 메타학습이라 부르는 것은 용어 범위를 넓힌다.

### 8.2 기술적 한계

LSTM은 같은 순서열 안에서 $h_t$와 $c_t$가 이전 시점에 의존하므로 시간축 계산이 순차적이다. BPTT 학습에는 시점별 활성화를 저장하거나 재계산해야 해 길이가 늘수록 시간과 메모리 비용이 커진다. 망각 게이트가 오래 닫히면 정보와 그래디언트가 사라질 수 있고, 열림을 유지하면 불필요한 상태가 누적될 수 있다. 게이트 포화, 초기화, 학습률, truncated BPTT 구간도 실제 장기 학습에 영향을 준다. [[기울기 소실]]을 완화해도 폭주가 남을 수 있으며 gradient clipping은 큰 업데이트를 제한할 뿐 이미 소실한 신호를 되살리지 않는다.

### 8.3 해석의 한계

셀 상태는 문법 규칙, 문단 주제나 화자 정보를 이름 붙은 칸에 저장하는 기호 메모리가 아니다. 특정 게이트가 열렸다는 관찰만으로 모델이 그 정보의 의미를 이해했다고 결론 내릴 수 없다. 언어 과제의 성능 향상과 `진정한 언어 이해`, 문단 단위 기억, 서사 일관성 같은 넓은 인지 주장을 구분해야 한다.

- 기술적 한계: 순차 계산, 긴 BPTT 경로, 게이트 포화와 상태 용량
- 이론적 한계: 안정적인 직접 경로가 전체 목적함수의 최적화나 무제한 기억을 보장하지 않음
- 실용적 한계: 계산·활성화 메모리 비용, 길이와 데이터에 민감한 학습
- 오늘날 관점에서 다시 봐야 할 점: 현대식 표준 LSTM을 1997년 원형으로 소급하거나 후대 NLP·Transformer 성과를 한 논문의 결과로 합치지 않기

## 9. 용어 정리

| 용어 | 설명 |
| --- | --- |
| 장단기 메모리(Long Short-Term Memory, LSTM) | 셀 상태와 곱셈 게이트를 이용해 장기 오류 흐름과 선택적 상태 갱신을 개선한 순환 신경망 계열 |
| 상수 오류 순환로(constant error carousel, CEC) | 1997년 원형에서 고정 가중치 1의 자기 연결로 셀 내부 오류의 직접 경로를 보존하려 한 구성 |
| 셀 상태(cell state) | 시간에 따라 전달·갱신되는 LSTM의 내부 연속 상태. 과거 입력의 완전한 저장본은 아니다. |
| 입력 게이트(input gate) | 후보 정보가 셀 상태에 쓰이는 정도를 조절하는 곱셈 게이트 |
| 출력 게이트(output gate) | 셀 상태가 외부 은닉 상태나 출력에 드러나는 정도를 조절하는 게이트 |
| 망각 게이트(forget gate) | 이전 셀 상태를 얼마나 유지·삭제할지 조절하는 후대의 적응형 게이트 |
| 시간을 통한 역전파(BPTT) | 순환망을 관측 시간만큼 펼친 계산 그래프에 역전파를 적용하는 학습 절차 |
| 국소 야코비안(local Jacobian) | 한 시점의 상태가 바로 이전 상태에 얼마나 민감한지를 나타내는 미분 행렬 |
| 장기 의존성(long-term dependency) | 멀리 떨어진 시점의 정보가 현재 예측이나 손실에 영향을 주는 관계 |

## 12. 짧은 결론

LSTM의 역사적 가치는 1997년에 언어 이해와 기계 번역을 한꺼번에 완성했다는 데 있지 않다. CEC와 입력·출력 게이트로 장기 오류 흐름을 구조적으로 다룬 원형, 1999/2000년 적응형 망각 게이트, 2014년 이후의 LSTM sequence-to-sequence와 attention 응용이 차례로 누적되며 게이트 순환망의 실용 범위를 넓혔다. LSTM은 장기 의존 학습을 크게 개선했지만 무제한 기억이나 보편적 그래디언트 안정성을 보장하지 않으며, Transformer는 그 셀을 직접 계승하지 않고 recurrence를 제거하는 다른 해법을 택했다. 따라서 LSTM은 현대 LLM의 단일 기원이라기보다, **학습 가능한 정보 경로와 신용 할당을 함께 설계해야 한다는 원칙을 분명하게 보여 준 핵심 순환망 이정표**로 이해하는 것이 가장 정확하다.

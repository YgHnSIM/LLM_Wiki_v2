# 시퀀스-투-시퀀스 신경 기계 번역: 종단간 학습 혁명 — 해설

## 1. 한눈에 보기

이 글은 2014년의 순환 신경망 인코더-디코더가 기계 번역을 구성 요소별 통계 파이프라인에서 단일 조건부 확률 모델로 재구성한 과정을 설명한다. 고정 길이 벡터, 자기회귀 디코더, teacher forcing, 빔 탐색, 어휘 제한, 어텐션으로 이어지는 흐름은 잘 잡아낸다. 다만 구 기반 SMT를 “손으로 쓴 규칙 묶음”으로 단순화하고, Cho 등의 모델을 수츠케버 등의 완전한 종단간 번역기와 같은 것으로 묶으며, 2014년 구조에서 현대 LLM까지의 계보를 지나치게 직선화한다.

## 2. 핵심 요약

- 인코더는 가변 길이 원문을 상태 표현으로 바꾸고, 디코더는 그 표현과 이전 목표 단어에 조건화해 다음 단어를 예측한다.
- 수츠케버·비냘스·레의 2014년 모델은 4층 LSTM, 원문 역순 입력, 제한 어휘와 빔 탐색으로 WMT14 영어-프랑스어에서 경쟁력 있는 결과를 냈다.
- 조경현 등의 RNN Encoder–Decoder/GRU는 중요한 독립 발명이지만, 해당 EMNLP 논문에서는 구 쌍 점수를 기존 구 기반 SMT의 특징으로 넣었다. 곧바로 완전 대체형 번역기를 만든 것은 아니다.
- 고정 벡터 병목은 바다나우·조·벤지오의 정렬·어텐션 모델이 완화했다. 논문은 2014년 9월 공개되고 ICLR 2015에 발표됐다.
- teacher forcing은 정답 이력을 조건으로 최대우도 학습을 쉽게 하지만 훈련·추론 문맥이 달라진다. 그러나 순환 디코더의 은닉 상태 계산 자체는 훈련 때도 순차적이다.
- 2016년 GNMT는 8층 LSTM, 어텐션, 잔차 연결, WordPiece 등을 결합한 후속 시스템이다. 2014년의 고정 벡터 seq2seq를 그대로 서비스에 넣은 사례가 아니다.

## 3. 역사적 배경

구 기반 통계 기계 번역은 단어 정렬에서 구 쌍을 추출하고, 구 번역 확률·어휘 가중치·언어 모델·재배열/왜곡 특징 등을 로그선형 모델로 결합한 뒤 최소 오류율 훈련 같은 방법으로 가중치를 조정했다. 언어별 수작업이 없었던 것은 아니지만, 재배열과 번역을 전부 언어학자가 규칙으로 작성했다는 설명은 정확하지 않다.

또 2014년 이전에도 신경망으로 번역을 연속 공간에서 모델링하려는 계보가 있었다. Kalchbrenner와 Blunsom의 2013년 Recurrent Continuous Translation Models는 정렬이나 구 단위 없이 문장 번역을 모델링했다. 2014년의 돌파구는 “아무도 생각하지 못한 최초”라기보다, 더 강한 순환 구조·대규모 실험·일반적인 시퀀스 변환 관점을 결합해 경쟁력을 입증한 순간으로 읽는 편이 정확하다.

## 4. 핵심 개념 해설

조건부 생성은 다음처럼 분해된다.

\[
p(y\mid x)=\prod_{t=1}^{T}p(y_t\mid y_{<t},x)
\]

인코더는 (x)를 상태로 변환하고, 디코더는 이전 정답 또는 예측 토큰과 상태에 따라 (y_t)의 분포를 계산한다. **teacher forcing**은 훈련 시 (y_{t-1}) 자리에 정답을 넣는 방식이다. 이는 각 단계의 손실을 안정적으로 계산하게 하지만, RNN의 (h_t=f(h_{t-1},y_{t-1})) 의존성을 없애지는 않는다. 따라서 “teacher forcing 덕분에 RNN 디코더의 모든 목표 단어를 병렬 처리한다”는 원문 문장은 Transformer 훈련과 혼동한 설명이다.

수츠케버 등의 모델은 마지막 LSTM 상태라는 하나의 고정 길이 표현을 사용했다. 이 벡터를 문장의 “전체 의미”라고 부르면 설명은 쉬워지지만, 실제로는 번역 목표에 맞춰 학습된 제한된 상태다. 의미를 완전하고 언어 독립적으로 보존한다고 보장하지 않는다.

## 5. 원문의 논리 구조

글은 먼저 통계 번역을 복잡한 조립 라인으로 제시한 뒤, 두 신경망만으로 이를 단순화하는 대비를 만든다. 이어 인코더, 디코더, 조건부 확률 분해, teacher forcing과 LSTM을 설명하고, 번역 외 응용으로 일반성을 강조한다. 후반에는 고정 벡터, 순차 추론, 노출 편향, 제한 어휘, 불투명성을 한계로 제시하고, 어텐션·Transformer·LLM으로 이어지는 유산을 서술한다. 교육적 흐름은 명료하지만 “낡은 수작업 시스템 대 스스로 배우는 신경망”이라는 대비가 역사적 세부를 평평하게 만든다.

## 6. 왜 중요한가

seq2seq의 핵심 기여는 특정 번역 기능 하나보다 **가변 길이 입력에서 가변 길이 출력을 학습하는 공통 인터페이스**를 널리 정착시킨 데 있다. 번역 모델을 여러 독립 점수의 조합이 아니라 하나의 미분 가능한 조건부 모델로 다룰 수 있게 했고, 표현 학습과 생성 학습을 같은 손실로 연결했다. 이 인터페이스는 뒤의 어텐션 기반 NMT와 Transformer 인코더-디코더에 직접 남아 있다.

## 7. 현대 LLM과의 연결

현대 LLM과의 연결은 “직접 후손” 하나로 묶기보다 세 갈래로 나누는 편이 좋다.

1. **번역 계보**: 고정 벡터 RNN 인코더-디코더 → 어텐션 RNN NMT → Transformer 인코더-디코더.
2. **언어 모델 계보**: 오래된 자기회귀 언어 모델 → 신경 언어 모델 → Transformer 디코더와 GPT. 자기회귀는 seq2seq가 발명한 것이 아니다.
3. **표현 학습 계보**: 양방향 문맥 표현과 사전학습 → Transformer 인코더와 BERT. BERT를 seq2seq 인코더의 단순한 확대판으로 보는 것은 마스킹 사전학습이라는 핵심 차이를 지운다.

세 계보는 어텐션과 Transformer에서 만나지만, GPT·BERT·ChatGPT의 모든 핵심이 2014년 seq2seq에서 직접 나왔다고 말할 수는 없다.

## 8. 한계와 비판적 관점

- 수츠케버 등의 직접 번역 앙상블은 특정 WMT14 영어-프랑스어 설정에서 BLEU 34.8로 구 기반 기준선 33.3을 앞섰다. 1000-best 재순위화의 36.5는 기존 SMT 후보를 이용한 혼합 결과다. “순수 신경망이 즉시 모든 통계 시스템을 압도했다”는 식으로 일반화하면 안 된다.
- 이 논문은 4층 LSTM을 사용했다. 원문의 다른 대목에서 흔히 보이는 5층 또는 GRU·양방향 인코더의 혼합 설명을 이 시스템의 사양으로 읽으면 안 된다.
- 원문 역순 입력은 실험상 BLEU와 perplexity를 크게 개선했지만 보편 법칙은 아니다.
- 긴 문장 병목은 중요한 문제였으나, 수츠케버 논문은 선택한 데이터 분포에서 긴 문장에도 비교적 잘 일반화했다고 보고했다. “길이가 늘면 반드시 꾸준히 붕괴했다”는 단정은 서로 다른 모델과 평가를 구분해야 한다.
- 초기 모델은 원문 16만, 목표 8만 단어 어휘를 쓰고 그 밖을 UNK로 처리했다. 뒤의 희귀 단어 복사, 서브워드, WordPiece는 별도의 후속 해결책이다.
- scheduled sampling은 노출 편향의 한 대응이지만, 최대우도 학습과 생성 시 분포 차이 전체를 해결한 방법으로 합의된 것은 아니다.
- 어텐션 가중치가 생겼다고 모델의 의사결정이 곧바로 완전히 설명 가능해지는 것은 아니다. 반대로 SMT도 모든 오류를 손쉽게 추적할 수 있는 투명한 시스템은 아니었다.

## 9. 용어 정리

- **Sequence-to-Sequence(seq2seq)**: 한 시퀀스에 조건화해 다른 길이의 시퀀스를 생성하는 학습 틀.
- **인코더-디코더**: 입력을 상태·표현으로 바꾸는 인코더와 그 표현에서 출력을 만드는 디코더의 결합.
- **자기회귀 생성**: 이전 출력에 조건화해 다음 요소를 순차적으로 생성하는 방식.
- **Teacher forcing**: 훈련 시 이전 모델 예측 대신 이전 정답 토큰을 다음 단계 입력으로 주는 방식.
- **노출 편향**: 훈련에서는 정답 이력, 추론에서는 모델 이력에 노출되는 조건 차이를 가리키는 말.
- **빔 탐색**: 각 단계에서 여러 상위 부분 가설을 유지해 전체 시퀀스 후보를 탐색하는 근사 디코딩.
- **고정 벡터 병목**: 모든 입력 정보를 크기가 고정된 하나의 표현에 모을 때 생기는 용량·접근 제약.
- **어텐션**: 출력 단계마다 입력 위치들의 가중 조합을 동적으로 계산하는 메커니즘.

## 12. 짧은 결론

2014년 seq2seq는 번역의 모든 문제를 한 번에 해결한 완성품이 아니라, 가변 길이 변환을 하나의 학습 가능한 조건부 모델로 묶는 강력한 공통 틀이었다. 그 역사적 의미는 기존 통계 번역을 과장해 낮추거나 현대 LLM 전체를 직계 후손으로 만들 때보다, 고정 벡터의 성과와 병목, 그리고 어텐션으로 이어진 구체적 수정 과정을 함께 볼 때 가장 분명해진다.

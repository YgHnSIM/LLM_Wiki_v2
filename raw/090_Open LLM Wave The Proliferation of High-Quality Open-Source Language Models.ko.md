# 오픈 LLM 물결: 고품질 오픈 소스 언어 모델의 확산

원본 출처: https://mbrenndoerfer.com/writing/open-llm-wave-proliferation-high-quality-open-source-language-models

MPT, Falcon, Mistral을 비롯한 여러 오픈 모델을 아우르며 2023년의 오픈 LLM 물결을 종합적으로 살펴보는 안내서다. 이 모델들이 어떻게 경쟁적인 생태계를 형성하고 혁신을 가속했으며, 독점 시스템에 대한 의존도를 낮추고, 아키텍처 혁신과 개선된 학습 데이터 큐레이션을 통해 최첨단 언어 모델 역량에 대한 접근을 민주화했는지 알아본다.

## 2023년: 오픈 LLM 물결

2023년은 대규모 언어 모델의 지형이 크게 바뀐 시기였다. 고품질 오픈 소스 모델의 물결이 등장해 독점 시스템의 지배력에 도전했기 때문이다. 효율적이고 경쟁력 있는 모델을 개발해 공개할 수 있음을 보여 준 Meta의 2023년 2월 [LLaMA](/writing/llama-meta-open-foundation-models-democratized-language-ai-research) 공개 이후, 수많은 조직이 그해 내내 자체 오픈 언어 모델을 개발하고 내놓기 시작했다. MosaicML의 [MPT](/writing/modern-portfolio-theory-mean-variance-optimization)(Mosaic Pretrained [Transformer](/writing/transformer-attention-is-all-you-need)), Technology Innovation Institute의 Falcon, [Mistral AI](/writing/mistral-architecture-sliding-window-attention)의 Mistral 모델 같은 모델들은 오픈 대안이 경쟁하는 생태계를 만들었다. 이 생태계는 혁신을 가속하고 독점 API에 대한 의존도를 낮췄으며, 최첨단 언어 모델 역량에 대한 접근을 민주화했다.

오픈 모델의 이러한 확산은 언어 AI 기술을 개발하고 배포하는 방식의 근본적인 변화를 의미했다. 통제된 API를 통해서만 이용할 수 있는 폐쇄형 독점 시스템이 지배하던 분야에서 벗어나, 2023년에는 연구자와 개발자, 조직이 강력한 언어 모델을 내려받고 수정해 로컬에 배포할 수 있는 활기찬 오픈 소스 생태계가 등장했다. 이 변화는 특히 데이터 프라이버시, 오프라인 배포 또는 비용 효율적인 확장이 필요한 분야에서 새로운 활용 사례를 가능하게 했다. 동시에 협업 개발과 투명한 평가를 통해 빠른 혁신도 촉진했다.

오픈 모델 물결은 투명성과 접근성을 지향하는 AI 공동체의 더 큰 흐름도 반영했다. [GPT-3](/writing/gpt3-in-context-learning-emergent-capabilities-from-scale)와 [GPT-4](/writing/gpt4-multimodal-language-models-reach-human-level-performance) 같은 앞선 독점 모델은 놀라운 역량을 보여 줬지만, 폐쇄적인 특성 때문에 연구와 맞춤화, 독립적인 평가가 제한됐다. 이와 달리 2023년의 오픈 모델은 전체 모델 가중치와 학습 절차를 제공했고, 많은 경우 학습 데이터까지 제공했다. 덕분에 연구자들은 이 시스템을 이해하고 감사하며 개선할 수 있었다. 이러한 투명성은 모델 최적화, 미세조정 기법, 안전 정렬 같은 영역의 연구를 가속했으며, 모델의 역량과 한계를 독립적으로 검증할 수 있게 했다.

2023년의 경쟁 구도는 효율적인 모델 아키텍처와 학습 절차가 얼마나 중요한지도 부각했다. 오픈 모델을 공개한 조직들은 계산 요구량을 최소화하면서 경쟁력 있는 성능을 달성하고자 했고, 이는 모델 아키텍처, 학습 데이터 큐레이션, 최적화 기법의 혁신으로 이어졌다. 이러한 발전은 신중한 엔지니어링을 거치면 더 효율적으로 학습한 작은 모델도 더 큰 독점 시스템에 견줄 만한 성능을 달성할 수 있음을 보여 주었고, 모델 크기와 역량의 관계에 관한 기존 가정에 도전했다.

혁신을 통한 효율성

오픈 모델 물결은 사려 깊은 아키텍처 선택을 통해 작은 모델도 더 큰 시스템의 역량에 필적하거나 이를 넘어설 수 있음을 보여 줬다. ALiBi, 그룹 질의 어텐션(grouped-query attention), 슬라이딩 윈도 어텐션(sliding window attention) 같은 혁신은 모델 효율성이 단순히 매개변수 수의 문제가 아니라 지능적인 설계의 문제임을 드러냈다. 효율성을 강조한 결과, 계산 자원이 제한된 조직도 강력한 언어 모델을 이용할 수 있게 되었고 최첨단 역량에 대한 접근이 민주화됐다.

## 문제

2023년 초에는 [LLaMA](/writing/llama-meta-open-foundation-models-democratized-language-ai-research)가 공개됐음에도 언어 AI 생태계에 널리 보급되고 혁신하는 것을 가로막는 상당한 장벽이 남아 있었다. OpenAI, Google, Anthropic의 독점 모델은 인상적인 역량을 제공했지만 중대한 한계가 따랐다. 사용료와 속도 제한이 있는 API를 통해서만 접근할 수 있었고, 사용자는 모델 내부 구조나 학습 데이터를 들여다볼 수 없었으며, 맞춤화 선택지는 프롬프트 엔지니어링과 독점 인터페이스를 통한 미세조정으로 제한됐다. 이러한 제약 때문에 연구자는 독립적으로 평가하기 어려웠고, 조직은 프라이버시에 민감한 환경에 모델을 배포하기 어려웠으며, 개발자는 예측 가능한 비용이나 오프라인 기능이 필요한 애플리케이션을 구축하기 어려웠다.

독점 모델의 폐쇄적인 특성은 의존성과 종속(lock-in)에 관한 우려도 낳았다. 독점 API 위에 애플리케이션을 구축한 조직은 서비스 중단, 정책 변경, 비용 인상으로 프로젝트가 위태로워질 위험에 직면했다. 모델의 동작을 검사하거나 수정할 수 없다는 점은 구체적인 안전 보장, 도메인 적응 또는 AI 배포 관련 규정 준수가 필요한 애플리케이션에 어려움을 안겼다. 이 모델의 작동 방식을 이해하고 역량을 개선하거나 한계를 해결하려는 연구자들은 API만이 유일한 인터페이스인 블랙박스 시스템을 다뤄야 했다.

또한 독점 모델 생태계는 혁신이 소수의 대형 기술 기업에 집중되는 환경을 만들었다. 방대한 계산 자원을 보유하지 못한 학계 연구자와 스타트업, 조직은 언어 모델 개발에 의미 있게 기여하기 어려웠다. 전이 학습과 미세조정 기법으로 어느 정도 맞춤화할 수는 있었지만, 기반 모델 자체에는 접근할 수 없었기 때문에 대형 기술 기업 밖에서 이루어질 수 있는 연구개발의 범위가 제한됐다.

이 분야에는 독점 모델과 비슷한 품질을 갖추면서도 개방적으로 접근할 수 있는 경쟁력 있는 대안도 부족했다. 2022년에 공개된 [BLOOM](/writing/bloom-open-access-multilingual-language-model-democratization-ai-research)은 오픈 대규모 언어 모델의 실현 가능성을 보여 줬지만, 성능은 최첨단 독점 시스템보다 뒤처졌고 1,760억 개에 이르는 매개변수 때문에 실제 배포와 사용이 어려웠다. [LLaMA](/writing/llama-meta-open-foundation-models-democratized-language-ai-research)는 효율적인 아키텍처가 경쟁력 있는 성능을 달성할 수 있음을 보여 줬지만, 한 조직이 내놓은 단일 모델이었으므로 오픈 생태계가 제공할 수 있는 것의 시작에 불과했다. 공동체에는 여러 조직이 각기 다른 아키텍처 선택, 학습 접근법, 최적화 전략을 탐구하는 다양한 오픈 모델 생태계가 필요했다.

경쟁력 있는 오픈 대안의 부재는 하위 도구와 인프라의 발전도 제한했다. 대부분의 개발자가 독점 API에 집중한 탓에 모델 서빙, 최적화, 양자화, 배포 도구의 생태계는 주로 API 기반 워크플로에 맞춰져 있었다. 이에 따라 모델을 로컬에 배포하거나 폭넓게 맞춤화하려는 조직에는 공백이 생겼다. 이들을 위한 도구 생태계가 독점 API용 생태계만큼 성숙하지 못했기 때문이다.

## 해결책

2023년의 오픈 모델 물결은 여러 조직이 고품질 오픈 언어 모델을 개발하고 공개하려고 힘을 모으면서 이러한 과제를 해결했다. 조직마다 서로 다른 기술적 접근법, 아키텍처 혁신, 학습 전략을 제시했고, 그 결과 독점 시스템의 대안을 제공하는 한편 새로운 활용 사례와 연구 방향을 가능하게 하는 다채로운 생태계가 형성됐다.

2023년 5월부터 공개된 MosaicML의 [MPT](/writing/modern-portfolio-theory-mean-variance-optimization)(Mosaic Pretrained [Transformer](/writing/transformer-attention-is-all-you-need)) 모델은 세심한 아키텍처 설계와 학습 효율성을 통해 오픈 모델도 경쟁력 있는 성능을 달성할 수 있음을 보여 줬다. MPT 모델은 가변적인 문맥 길이를 더 잘 처리하도록 [ALiBi](/writing/alibi-attention-linear-biases-position-encoding)(Attention with Linear Biases) 같은 혁신을 도입했다. 코드, 수학 텍스트, 웹 콘텐츠를 포함해 신중하게 큐레이션한 데이터셋으로 학습하기도 했다. MPT-7B와 MPT-30B는 강한 성능을 보이면서도 계산 자원이 많지 않은 조직이 이용할 수 있었으며, MosaicML은 상업적 사용과 수정을 허용하는 관대한 Apache 2.0 라이선스로 모델을 공개했다.

2023년 6월에 공개된 Technology Innovation Institute의 Falcon 모델은 경쟁력 있는 성능을 달성하기 위해 다른 접근법을 취했다. Falcon-40B와 Falcon-7B는 수조 개의 고품질 웹 텍스트 토큰을 담은 RefinedWeb이라는 방대하고 세심하게 필터링된 데이터셋으로 학습됐다. Falcon 모델은 양보다 [데이터 품질](/writing/data-quality-outliers-measurement-error-missing-data)의 중요성을 강조했다. 더 나은 데이터 큐레이션을 활용하면 작은 모델도 덜 세심하게 필터링한 데이터셋으로 학습한 큰 시스템에 견줄 만한 성능을 달성할 수 있음을 보여 줬다. Falcon 모델은 추론 속도와 메모리 사용량에 맞춰 최적화된 효율적인 아키텍처도 갖춰, 자원이 제한된 환경에 실용적으로 배포할 수 있었다.

2023년 9월 Mistral 7B로 시작한 [Mistral AI](/writing/mistral-architecture-sliding-window-attention)의 Mistral 모델은 오픈 생태계에 또 하나의 중요한 기여를 했다. Mistral 7B는 세심한 아키텍처 선택과 학습 기법을 활용하면 특정 벤치마크에서 훨씬 큰 독점 시스템을 앞서는 모델을 만들 수 있음을 보여 줬다. 이 모델은 효율성을 높이기 위해 [그룹 질의 어텐션](/writing/grouped-query-attention-gqa-efficient-llm-inference)과 [슬라이딩 윈도 어텐션](/writing/sliding-window-attention) 같은 혁신을 사용했으며, 추론 과제와 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 역량에서도 강한 성능을 보였다. Mistral AI의 접근법은 모델 품질과 배포 실용성을 모두 중시했으며, 모델은 소비자용 하드웨어에서도 효율적으로 실행되도록 설계됐다.

이러한 주요 공개 외에도 2023년에는 언어 모델 개발의 여러 측면을 탐구한 수많은 오픈 모델이 등장했다. 조직들은 다양한 아키텍처, 학습 데이터 구성, 최적화 기법, 라이선스 접근법을 실험했다. 이러한 다양성은 개발자와 연구자가 성능, 효율성, 라이선스 유연성, [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development)이나 다국어 지원 같은 특정 역량 중 무엇을 우선하든 각자의 필요에 가장 잘 맞는 모델을 고를 수 있는 풍부한 생태계를 만들었다.

2023년의 오픈 모델은 보완적인 도구와 인프라의 발전도 촉진했다. 로컬 배포가 가능한 모델이 등장하자 생태계는 모델 서빙 프레임워크, 메모리 요구량을 줄이는 양자화 기법, 오픈 모델에 최적화된 미세조정 라이브러리를 개선하며 호응했다. Hugging Face의 Transformers 라이브러리 같은 프로젝트는 새 모델에 대한 지원을 확대했고, 여러 공동체는 오픈 모델 배포에 특화된 평가 프레임워크, 배포 안내서, 최적화 기법을 개발했다.

이 오픈 모델들의 라이선스 선택은 서로 다른 활용 사례와 요구사항에도 대응했다. [MPT](/writing/modern-portfolio-theory-mean-variance-optimization) 같은 일부 모델은 제한 없는 상업적 사용을 허용하는 관대한 Apache 2.0 라이선스를 사용했다. [LLaMA](/writing/llama-meta-open-foundation-models-democratized-language-ai-research) 기반 모델 같은 다른 모델은 상업적 사용을 허용하되 허용 가능한 사용 정책을 준수하도록 요구하는 라이선스를 사용했다. 이러한 다양한 라이선스 덕분에 조직은 법적 요구와 사업상 필요에 맞는 모델을 유연하게 선택할 수 있었다.

## 아키텍처 혁신

2023년의 오픈 모델은 효율성과 성능을 높인 여러 아키텍처 혁신을 도입했다. 이러한 혁신은 사려 깊은 설계를 통해 작은 모델도 이전에는 훨씬 큰 모델과 연관되던 역량을 달성할 수 있음을 보여 줬다.

[ALiBi](/writing/alibi-attention-linear-biases-position-encoding)(Attention with Linear Biases)는 [MPT](/writing/modern-portfolio-theory-mean-variance-optimization) 모델에 사용된 기법으로, 고정 위치 [임베딩](/writing/long-term-knowledge-storage-and-retrieval)을 거리에 따라 변화하는 학습된 선형 편향으로 대체해 길이가 가변적인 시퀀스를 처리하는 문제에 대응했다. 이 접근법을 사용하면 모델이 학습 중에 본 것보다 긴 시퀀스에 일반화할 수 있었다. 이는 [긴 문맥](/writing/long-context-models-processing-million-token-sequences-language-ai) 창이 필요한 애플리케이션에 중요한 역량이다. ALiBi의 상대 위치 접근법은 기존의 절대 위치 부호화보다 효율적이면서 더 나은 일반화 성능을 제공하는 것으로도 드러났다.

[그룹 질의 어텐션](/writing/grouped-query-attention-gqa-efficient-llm-inference)은 [Mistral 7B](/writing/mistral-architecture-sliding-window-attention) 같은 모델에 사용된 기법으로, 생성 중에 필요한 [키-값 캐시](/writing/kv-cache-transformer-attention-optimization) 항목 수를 줄여 추론 효율성을 개선했다. 그룹 질의 어텐션은 어텐션 헤드마다 별도의 키-값 쌍을 유지하는 대신 여러 질의 헤드가 키-값 쌍을 공유하게 했다. 이로써 모델 품질을 유지하면서 추론 중 메모리 요구량을 크게 줄였다. 모델이 메모리 제약이 있는 프로덕션 환경에 배포되면서 이 최적화는 특히 중요해졌다.

[슬라이딩 윈도 어텐션](/writing/sliding-window-attention) 메커니즘은 각 토큰 주위의 로컬 윈도로 어텐션을 제한하면서도 여러 어텐션 층을 통해 일부 전역 문맥을 유지함으로써 모델이 매우 긴 시퀀스를 효율적으로 처리하게 했다. 이 접근법은 계산 비용을 관리 가능한 수준으로 유지하면서도 모델이 32,000개 이상의 토큰으로 이루어진 문맥 길이를 처리할 수 있게 했다. 그 결과 긴 문서를 처리하거나 확장된 [대화 기록](/writing/short-term-conversation-memory-ai-agents)을 유지해야 하는 새로운 활용 사례가 열렸다.

오픈 모델은 모델 용량과 계산 효율성 사이에서 균형을 잡기 위한 여러 아키텍처 선택도 탐구했다. 어떤 모델은 매개변수 수와 [모델 깊이](/writing/transformer-architecture-hyperparameters-design-guide)를 우선했고, 다른 모델은 아키텍처 효율성과 최적화된 학습 절차에 초점을 맞췄다. 이처럼 다양한 접근법은 공동체가 서로 다른 활용 사례와 성능 요구사항에서 어떤 설계 선택이 가장 중요한지 이해하는 데 도움을 줬다.

## 학습 데이터와 큐레이션

오픈 모델 물결의 핵심 요소는 학습 [데이터 품질](/writing/data-quality-outliers-measurement-error-missing-data)과 큐레이션을 강조한 점이었다. 오픈 모델을 공개한 조직들은 모델 크기가 작거나 계산 예산이 더 제한적이어도 강한 성능을 낼 수 있도록 학습 데이터셋을 수집하고 필터링하며 구성하는 데 상당한 노력을 기울였다.

Falcon 모델의 RefinedWeb 데이터셋은 데이터 품질의 중요성을 보여 줬다. Falcon 팀은 웹을 무차별적으로 스크레이핑하는 데 그치지 않고 정교한 필터링과 중복 제거 절차를 구현해 수조 개의 원시 웹 텍스트 토큰으로부터 고품질 데이터셋을 만들었다. 이러한 세심한 큐레이션 덕분에 Falcon 모델은 덜 세심하게 필터링한 더 큰 데이터셋으로 학습한 여러 독점 시스템보다 매개변수가 적었음에도 강한 성능을 달성할 수 있었다.

양보다 데이터 품질

Falcon 모델의 성공은 세심하게 큐레이션한 고품질 데이터로 학습한 작은 모델이 필터링 수준이 낮은 데이터셋으로 학습한 큰 모델에 필적하거나 이를 넘어설 수 있다는 중요한 통찰을 부각했다. 이 원칙은 이후의 모델 개발에 영향을 주었고, 단순히 데이터셋 크기를 늘리는 데서 데이터 품질, 다양성, 큐레이션 절차를 개선하는 쪽으로 초점을 옮겼다.

[MPT](/writing/modern-portfolio-theory-mean-variance-optimization) 모델은 다양한 학습 데이터 구성의 중요성을 강조했다. MPT의 학습 데이터셋은 웹 텍스트뿐 아니라 코드, 수학 콘텐츠, 그 밖의 전문적인 텍스트 유형도 상당한 비중으로 포함했다. 이러한 다양성은 모델이 일반 언어 이해부터 [코드 생성](/writing/codex-ai-assisted-code-generation-transformation-software-development)과 수학적 추론에 이르는 폭넓은 영역에서 역량을 개발하는 데 도움을 줬다.

이 모델들은 개방적이었기 때문에 학습 데이터 구성에 관한 투명성도 확보할 수 있었다. 학습 데이터를 기밀로 유지한 독점 모델과 달리, 오픈 모델 개발자들은 데이터 출처, 필터링 절차, 구성 전략에 관한 정보를 흔히 공개했다. 이 투명성은 연구자가 학습 데이터의 특성과 모델 역량 사이의 관계를 이해하고 향후 데이터 큐레이션 작업에 참고하는 데 도움을 줬다.

오픈 모델을 위해 개발된 데이터 큐레이션 기법은 더 넓은 분야의 발전에도 기여했다. 오픈 모델 학습을 위해 다듬어진 중복 제거, 품질 필터링, 유해성 탐지, 콘텐츠 균형 조정 절차는 독점 모델 개발과 하위 미세조정 데이터셋에도 적용됐다. 따라서 오픈 모델 물결은 새로운 모델뿐 아니라 학습 데이터를 준비하는 개선된 방법론에도 기여했다.

## 응용과 영향

2023년의 오픈 모델은 독점 API 기반 시스템으로는 어렵거나 불가능했던 다양한 새 애플리케이션과 활용 사례를 가능하게 했다. 이러한 응용은 로컬에서 실행하고 맞춤화할 수 있으며 투명한 언어 모델을 배포에 사용할 때의 가치를 보여 줬다.

오픈 모델을 통해 프라이버시에 민감한 애플리케이션이 실현 가능해졌다. 민감한 데이터를 처리해야 하는 의료 기관, 금융 기관, 정부 기관은 데이터를 외부 API로 보내지 않고 오픈 모델을 로컬에 배포할 수 있었다. 이 기능은 데이터 프라이버시 규정이나 보안 요구사항 때문에 이전에는 AI 배포가 비현실적이었던 영역에서 언어 모델 애플리케이션을 가능하게 했다.

비용에 민감한 애플리케이션도 오픈 모델의 혜택을 받았다. 대량의 텍스트를 처리하는 조직은 오픈 모델을 로컬에 배포하고 요청별 [API 비용](/writing/managing-reducing-ai-agent-costs-optimization-strategies)을 피할 수 있었기 때문에, 처리량이 많은 활용 사례에서도 언어 모델 역량을 경제적으로 사용할 수 있었다. 이러한 비용 구조 덕분에 API 가격이 너무 비쌌을 일괄 처리, 데이터 증강, 그 밖의 애플리케이션에도 언어 모델을 실용적으로 사용할 수 있었다.

오픈 모델을 통해 맞춤화와 미세조정에 대한 접근성도 높아졌다. 연구자와 개발자는 도메인별 데이터셋으로 오픈 모델을 미세조정해 특정 애플리케이션에 최적화된 전문 모델을 만들 수 있었다. 이 기능은 법률 문서 분석, 의료 기록 처리, 과학 문헌 검토를 비롯해 전문 지식과 용어가 필요한 여러 영역의 애플리케이션을 가능하게 했다.

최적화된 오픈 모델을 활용해 오프라인과 엣지 배포도 가능해졌다. 인터넷 연결이 안정적이지 않은 환경이나 엄격한 네트워크 보안 요구사항이 있는 환경에서 언어 모델 역량이 필요한 조직은 오픈 모델을 로컬에 배포할 수 있었다. 엣지 배포는 API 왕복 시간 때문에 문제가 생길 수 있는 저지연 애플리케이션도 가능하게 했다.

오픈 모델은 모델 최적화, 안전 정렬, 평가 연구도 가속했다. 전체 모델 가중치를 사용할 수 있게 되면서 연구자는 모델 내부를 상세히 분석하고, 새로운 최적화 기법을 개발하며, 더 철저한 평가 프레임워크를 만들 수 있었다. 이 연구는 언어 모델이 어떻게 작동하는지, 어떻게 개선할 수 있는지, 어떻게 하면 더 안전하고 신뢰할 수 있게 만들 수 있는지를 이해하는 데 기여했다.

오픈 모델의 경쟁적 생태계는 건전한 경쟁을 통해 혁신을 이끌기도 했다. 조직들은 새 모델을 공개하면서 서로 성능, 효율성, 역량을 개선하도록 자극했다. 이러한 경쟁 구도는 혁신의 속도를 높였고 오픈 생태계가 계속 진화하고 개선되도록 했다.

## 한계

2023년의 오픈 모델은 크게 기여했지만, 도입과 발전 방향을 결정한 중요한 한계도 안고 있었다. 이러한 한계를 이해하면 오픈 모델 물결의 성취와 여전히 남아 있던 과제를 모두 맥락 속에서 볼 수 있다.

오픈 모델과 가장 큰 독점 시스템 사이에는 여전히 성능 격차가 있었다. 오픈 모델이 여러 벤치마크에서 경쟁력 있는 성능을 달성했지만, [GPT-4](/writing/gpt4-multimodal-language-models-reach-human-level-performance) 같은 가장 강력한 독점 시스템은 복잡한 추론 과제, 창의적 생성, 전문 역량에서 계속 오픈 대안을 앞섰다. 이러한 성능 격차는 최고 수준의 역량이 필요한 활용 사례에 오픈 모델을 적용하는 데 제약을 줬다.

계산 요구량은 여전히 많은 잠재적 사용자에게 장벽이었다. [Mistral 7B](/writing/mistral-architecture-sliding-window-attention) 같은 작은 오픈 모델조차 학습과 추론에 상당한 계산 자원이 필요했다. 양자화와 효율적인 아키텍처 같은 최적화가 도움이 됐지만, 오픈 모델을 효과적으로 배포하고 사용하는 데는 여전히 독점 API를 사용할 때보다 더 많은 기술 전문성과 인프라가 필요했다. 이러한 복잡성은 강력한 기술팀을 보유하지 못한 조직의 도입을 제한했다.

오픈 모델 생태계는 모델 정렬과 안전 측면에서도 과제를 안고 있었다. 오픈 모델은 안전 대책을 독립적으로 평가하고 개선할 수 있게 했지만, 악의적 행위자가 안전 [가드레일](/writing/content-safety-and-moderation-ai-agents) 없이 모델을 배포하기도 쉽게 만들었다. 개방성과 안전성 사이의 균형은 계속 해결해야 할 과제로 남았으며, 지나치게 관대한 라이선스나 불충분한 안전 조치가 유해한 애플리케이션을 가능하게 할 수 있다는 주장도 나왔다.

개방성과 안전성의 긴장

연구와 정당한 애플리케이션에서 이 모델들의 가치를 높인 개방성은 위험도 함께 만들었다. 안전 가드레일이 내장된 독점 시스템과 달리 오픈 모델은 안전 조치 없이 수정하거나 배포할 수 있었다. 접근성과 안전성 사이의 이러한 긴장은 오픈 모델 생태계의 핵심 과제가 되었고, 라이선스, 모델 공개 관행, 공동체 거버넌스를 신중하게 검토할 필요를 낳았다.

라이선스와 법적 고려사항은 상업적 사용자에게 복잡성을 더했다. 오픈 모델마다 서로 다른 라이선스를 사용했고 상업적 사용, 수정, 재배포에 적용되는 제약도 달랐다. 여러 모델을 사용하거나 상업용 애플리케이션을 구축하려는 조직에는 이러한 라이선스 요구사항을 파악하고 준수하는 일이 어려울 수 있었다. 일부 라이선스는 허용되는 활용 사례나 파생 저작물에 적용되는 요구사항을 불확실하게 만들기도 했다.

오픈 생태계의 빠른 혁신 속도는 대체로 긍정적이었지만 과제도 만들었다. 새 모델과 업데이트가 자주 공개되면서 조직은 어떤 모델을 채택하고 언제 업그레이드할지 결정해야 했다. 생태계가 빠르게 진화했기 때문에 안정적인 도구와 인프라를 확립하기도 어려웠다.

[데이터 품질](/writing/data-quality-outliers-measurement-error-missing-data)과 투명성은 오픈 모델에서 개선됐지만 여전히 한계가 있었다. 개발자가 학습 데이터에 관한 정보를 공개하더라도 데이터셋의 크기나 라이선스 제약 때문에 완전한 투명성을 확보하기 어려운 경우가 많았다. 독점 시스템보다 투명성이 높아졌음에도 모델의 편향, 한계, 실패 양상을 이해하는 일은 여전히 어려웠다.

## 유산과 미래 전망

2023년의 오픈 모델 물결은 오픈 소스 언어 모델을 AI 생태계의 영구적이고 필수적인 구성 요소로 자리 잡게 했다. 고품질 오픈 모델의 확산은 서로 다른 요구를 충족하고 서로 다른 활용 사례를 가능하게 하는 독점 접근법과 오픈 접근법이 이 분야에 함께 존재할 수 있음을 보여 줬다. 이러한 이중 생태계 모델은 계속 진화해 왔으며, 독점 시스템과 오픈 시스템은 모두 발전하면서 서로에게 영향을 주고 있다.

오픈 모델이 도입한 아키텍처 혁신은 이후 오픈 시스템과 독점 시스템 모두의 모델 개발에 영향을 미쳤다. [ALiBi](/writing/alibi-attention-linear-biases-position-encoding), [그룹 질의 어텐션](/writing/grouped-query-attention-gqa-efficient-llm-inference), [슬라이딩 윈도 어텐션](/writing/sliding-window-attention) 같은 기법은 더 널리 채택돼 이 분야 전반의 효율성과 역량을 개선했다. 학습 [데이터 품질](/writing/data-quality-outliers-measurement-error-missing-data)과 큐레이션을 강조한 흐름도 모델 개발 방식에 영향을 줬으며, 오픈 진영과 독점 진영 모두 데이터 엔지니어링에 더 많이 투자하게 됐다.

오픈 모델 생태계는 모델 배포, 최적화, 미세조정을 위한 도구와 인프라의 개선도 촉진했다. 양자화, 서빙, 배포 프레임워크가 성숙하면서 오픈 모델을 프로덕션 환경에 배포하는 일이 점차 실용적으로 바뀌었다. 이러한 발전은 오픈 모델 사용자뿐 아니라 효율적인 모델 배포에 관심 있는 더 넓은 공동체에도 도움이 됐다.

2023년에 형성된 경쟁 구도는 계속 이어졌으며, 여러 조직이 역량, 효율성, 접근성의 한계를 넓히는 새 오픈 모델을 정기적으로 공개했다. 이러한 건전한 경쟁은 혁신을 가속하는 동시에 고품질 오픈 대안을 계속 이용할 수 있게 했다. 생태계에서는 특히 효과가 입증된 특정 모델과 접근법을 중심으로 통합이 이루어지기도 했지만, 다양성과 실험도 계속 지원했다.

오픈 모델 물결은 AI 개발을 둘러싼 정책과 거버넌스 논의에도 영향을 미쳤다. 오픈 모델의 성공은 투명성과 접근성이 높은 성능과 양립할 수 있음을 보여 줬고, AI 규제, 안전 기준, 접근 정책에 관한 논쟁에도 영향을 주었다. 경쟁력 있는 오픈 대안의 존재는 AI 집중과 다양한 생태계를 유지해야 할 중요성에 관한 논의에도 영향을 미쳤다.

앞으로도 오픈 모델 생태계는 더 큰 모델, 개선된 역량, 더 나은 효율성을 갖추며 계속 진화할 것이다. 여러 조직은 2023년의 물결을 특징지었던 개방성과 투명성에 대한 약속을 유지하면서 새로운 아키텍처, 학습 기법, 최적화 전략을 탐색하고 있다. 또한 오픈 모델을 안전하고 효과적으로 사용할 수 있도록 안전 정렬, 평가 프레임워크, 책임 있는 배포 관행에도 더 많은 관심을 기울이고 있다.

2023년 오픈 모델 물결의 유산은 그해 공개된 특정 모델을 넘어선다. 이 물결은 오픈 AI 개발의 패턴과 관행을 확립해 계속해서 이 분야에 영향을 주고 있다. 효율성, 투명성, 실용적 배포에 대한 강조는 이후 오픈 모델을 개발하는 방식과 오픈 생태계가 진화하는 방식을 형성했다. 2023년 물결의 성공은 오픈 AI 연구개발에 대한 지속적인 투자도 고무해, 언어 모델의 역량이 계속 발전하는 가운데 오픈 대안을 계속 이용할 수 있게 했다.

2023년의 오픈 모델 물결은 언어 AI의 민주화에서 결정적인 순간이었다. 이 물결은 독점 시스템에 견줄 만한 오픈 대안을 제공해 새로운 애플리케이션을 가능하게 하고 연구를 가속했으며 건전한 경쟁을 통해 혁신을 촉진했다. 이 시기의 아키텍처 혁신, 학습 방법론, 생태계 발전은 오늘날에도 언어 AI 개발에 계속 영향을 미치며, 오픈 모델을 현대 AI 지형의 필수 요소로 자리 잡게 했다.

# 멀티모달 대규모 언어 모델의 구조와 평가 경계 해설

## 1. 한눈에 보기

- 핵심 주제: 이미지 인코더가 만든 시각 특징을 연결 모듈을 거쳐 자기회귀 언어 모델에 조건으로 주는 시각-언어 생성 모델의 여러 설계와, 그 성능을 검증할 때 지켜야 할 경계
- 역사적 위치: 2023년은 시각-언어 결합이 처음 생긴 해가 아니라, CLIP·Flamingo 같은 선행 연구 위에서 BLIP-2·PaLM-E·LLaVA와 GPT-4의 시각 기능이 한꺼번에 주목받은 시기다.
- 가장 중요한 정정: OpenAI는 2023년 3월 GPT-4의 이미지 입력 능력을 발표했지만 당시 일반에 공개한 것은 텍스트 입력이었다. 이미지 입력은 제한된 파트너·알파 단계였고, ChatGPT의 광범위한 이미지 기능 출시는 9월, 개발자용 미리보기 API는 11월이었다.
- 구조상 핵심: “이미지를 토큰으로 바꾸어 LLM에 넣는다”는 문장은 공통 원리를 너무 압축한다. Flamingo의 게이트 교차 어텐션, BLIP-2의 Q-Former, LLaVA의 선형 투영은 서로 다른 정보 병목과 학습 경로를 만든다. GPT-4의 구체적인 시각 연결 구조는 공개되지 않았다.
- 평가상 핵심: OCR, 차트 질의응답, 일반 VQA, 공간 추론은 서로 다른 능력을 요구한다. 한 벤치마크의 총점이나 선택된 시연 몇 개만으로 “인간 수준의 시각 이해”를 결론 내릴 수 없다.
- 배포상 핵심: 자연어 인터페이스는 접근성을 높일 수 있지만, 존재하지 않는 물체를 말하는 환각, 작은 글자와 위치 관계 오류, 이미지 기반 우회 공격, 사생활 침해와 고위험 오판을 별도로 관리해야 한다.

## 2. 핵심 요약

멀티모달 LLM은 보통 이미지나 동영상 같은 비언어 입력을 표현 벡터로 바꾸고, 이를 대규모 언어 모델이 텍스트를 생성할 때 사용할 조건으로 제공하는 모델을 가리킨다. 이 정의에는 여러 구조가 들어간다. CLIP은 이미지와 텍스트를 대조학습으로 정렬하지만 긴 답변을 생성하는 LLM은 아니다. Flamingo는 동결한 시각 인코더와 동결한 언어 모델 사이에 Perceiver Resampler와 게이트 교차 어텐션 층을 학습한다. BLIP-2는 Q-Former가 동결 이미지 인코더에서 고정 개수 정보를 추출하고 그 결과를 동결 LLM의 소프트 시각 프롬프트로 투영한다. LLaVA 초판은 CLIP 시각 인코더의 특징을 단순한 학습 가능 선형층으로 Vicuna의 단어 임베딩 공간에 맞춘 뒤, 시각 지시 데이터로 연결부와 언어 모델을 조정했다. 이 차이는 “통합”이 하나의 표준 구조를 뜻하지 않음을 보여 준다.

GPT-4는 2023년 3월 14일 공개 자료에서 이미지와 텍스트를 입력받고 텍스트를 출력하는 대형 멀티모달 모델로 소개됐다. 그러나 GPT-4 기술 보고서는 경쟁과 안전을 이유로 모델 크기, 하드웨어, 훈련 데이터와 방법뿐 아니라 구체적인 구조도 공개하지 않았다. 따라서 원문처럼 GPT-4가 특정 시각 인코더의 임베딩을 텍스트 토큰 옆에 직접 삽입했다고 단정해서는 안 된다. 그 설명은 LLaVA 같은 공개 모델에는 적용할 수 있지만, GPT-4 내부에 대해서는 확인되지 않은 추정이다.

또한 “2023년 3월 GPT-4가 시각 기능을 출시했다”는 문장은 발표와 이용 가능성을 섞는다. 3월 공개 당시 OpenAI는 텍스트 입력을 ChatGPT Plus와 API 대기자에게 제공했고, 이미지 입력은 Be My Eyes 같은 제한된 파트너와 시험하고 있었다. 2023년 9월 25일에야 이미지 기능을 ChatGPT Plus·Enterprise 사용자에게 단계적으로 제공한다고 발표했고, 11월 6일 개발자 행사에서 `gpt-4-vision-preview` API를 알렸다. 따라서 3월은 능력의 공식 발표, 9월은 소비자 제품의 광범위한 배포 시작, 11월은 개발자용 미리보기 API라는 세 경계를 나누는 편이 정확하다.

원문의 주요 주장을 다음처럼 좁혀 읽을 수 있다.

| 원문의 넓은 서술 | 근거에 맞춘 해석 |
|---|---|

| 산업과 교육·과학·접근성을 변혁했다. | 가능성과 초기 사용 사례는 확인되지만, 넓은 인과 주장은 도메인별 사용자 수·오류율·비용·대조군을 갖춘 배포 연구가 필요하다. |

## 3. 역사적 배경

시각과 언어를 함께 다루는 연구는 2023년에 갑자기 시작되지 않았다. 이미지 캡셔닝, 시각 질의응답(VQA), 문서 이해와 대조학습은 오랫동안 서로 다른 문제 설정으로 발전해 왔다. 2021년 CLIP은 대규모 이미지-텍스트 쌍으로 두 인코더를 정렬하고, 자연어로 만든 클래스 설명을 이용한 제로샷 이미지 분류를 보여 주었다. 다만 CLIP의 기본 출력은 이미지와 텍스트의 유사도이며, 자유 형식의 설명이나 여러 단계 답변을 생성하는 모델은 아니었다.

같은 시기 Frozen은 동결 언어 모델에 이미지 표현을 접두 벡터로 넣어 소수 예시로 시각-언어 과제를 수행하는 방향을 탐색했다. 2022년 4월 공개된 Flamingo는 이 생각을 더 확장했다. 동결 시각 인코더의 가변 길이 특징을 Perceiver Resampler가 고정 개수 토큰으로 압축하고, 동결 언어 모델의 층 사이에 새 게이트 교차 어텐션 블록을 삽입했다. 이미지·동영상·텍스트가 교차된 문맥을 학습했기 때문에, 추론 때도 이미지와 답변 예시를 이어 붙이는 퓨샷 프롬프트를 사용할 수 있었다. 원 논문은 16개 과제에서 퓨샷 성능을 평가했으며, TextVQA·VQAv2·VizWiz·OK-VQA처럼 요구 능력이 다른 데이터셋을 함께 다뤘다.

2023년 초에는 연결부를 가볍게 만드는 연구가 이어졌다. BLIP-2는 동결 이미지 인코더와 동결 LLM 사이에 약 1억 8,800만 개 파라미터의 Q-Former를 두었다. 학습 가능한 질의 토큰이 시각 특징에서 LLM에 필요한 정보를 뽑고, 선형층이 이를 LLM 임베딩 차원으로 바꾸어 소프트 시각 프롬프트로 전달한다. PaLM-E는 로봇 센서 상태와 시각 정보를 인코더로 언어 임베딩 공간에 주입하고, 텍스트·시각 질의응답·로봇 제어 과제를 함께 학습하는 다른 경로를 보였다.

2023년의 주요 사건을 발표와 배포 기준으로 배열하면 다음과 같다.

| 시점 | 사건 | 해석의 경계 |
|---|---|---|
| 2021년 1월 | CLIP 공개 | 대조 정렬과 제로샷 분류의 강한 사례이지, 생성형 멀티모달 LLM은 아니다. |
| 2022년 4월 | Flamingo 논문 공개 | 동결 백본, Resampler, 게이트 교차 어텐션, 멀티모달 인컨텍스트 학습을 결합했다. |

| 2023년 3월 6일 | PaLM-E 논문 공개 | 시각뿐 아니라 연속 센서 표현을 언어 임베딩과 섞는 체화 멀티모달 모델을 제시했다. |

이 연표에서 2023년의 의의는 “최초의 통합”보다 세 변화의 동시 발생에 있다. 첫째, 강한 사전학습 시각 인코더와 강한 LLM을 적은 연결 파라미터로 재사용하는 설계가 다양해졌다. 둘째, 시각 지시 데이터로 자유 형식 대화를 조정하는 방법이 널리 실험됐다. 셋째, 연구용 모델이 소비자용 대화 인터페이스와 API로 이동하며 신뢰성·사생활·안전·운영 비용이 연구실 밖의 문제가 됐다.

## 4. 핵심 개념 해설

### 4.1 “멀티모달 통합”은 하나의 구조가 아니다

이미지 $I$, 텍스트 프롬프트 $x$, 생성 답변 $y$가 있다고 하자. 많은 시각-언어 생성 모델은 다음의 추상 형태로 쓸 수 있다.

\[
V = E_v(I), \qquad Z = C(V), \qquad
p(y\mid x,I)=\prod_t p(y_t\mid y_{<t},x,Z)
\]

$E_v$는 이미지의 패치나 영역을 특징 $V$로 바꾸는 시각 인코더다. $C$는 시각 특징의 개수·차원·분포를 언어 모델이 읽을 수 있는 표현 $Z$로 바꾸는 연결부(connector)다. 마지막 식의 LLM은 $x$와 $Z$를 조건으로 다음 텍스트 토큰을 생성한다. 공통점은 이 정도뿐이다. $C$가 단순 선형 투영인지, 학습 가능한 질의로 정보를 압축하는지, 언어 모델 여러 층에서 교차 어텐션을 수행하는지에 따라 모델의 계산과 오류 양상이 달라진다.

“통합”이라는 사용자 경험과 “통합”이라는 내부 구조도 구분해야 한다. 한 대화창에서 사진과 질문을 함께 보낸다고 해서 모든 모달리티가 하나의 동질적인 신경망에서 처음부터 끝까지 공동 학습됐다는 뜻은 아니다. 백본을 동결한 모듈식 시스템도 외부에서는 하나의 모델처럼 보일 수 있고, 반대로 단일 체크포인트 안에도 서로 다른 인코더·투영층·디코더가 남을 수 있다.

### 4.2 시각 인코더: 이미지를 어떤 정보 단위로 바꾸는가

Vision Transformer 계열 인코더는 이미지를 작은 패치로 나누고 각 패치를 벡터로 표현한다. 해상도가 높거나 패치가 작을수록 토큰 수가 늘어 세부 정보를 더 보존할 수 있지만, 연결부와 LLM이 처리할 계산량도 커진다. 입력 리사이즈·자르기·타일링 과정은 작은 글자, 축 눈금, 수학 기호, 물체 개수와 주변부 정보를 잃게 할 수 있다. 따라서 “모델이 이미지를 본다”는 말보다 실제 입력 해상도, 패치화 방법, 복수 이미지 처리 방식과 원본 좌표 보존 여부를 확인해야 한다.

CLIP처럼 대조학습된 인코더는 이미지 전체의 의미적 정렬에 강할 수 있지만, 정확한 문자 전사·개수 세기·좌표 관계에 최적화됐다고 자동으로 볼 수 없다. 이미지 안의 정보가 인코더 단계에서 사라지면 뒤의 LLM이 더 정교해도 복구할 수 없다. 반대로 OCR 도구나 차트의 원시 데이터 표를 별도로 제공하면, 모델의 답이 순수한 픽셀 이해보다 외부 추출기의 성능에 의존할 수 있다.

### 4.3 연결부: 투영, 질의 병목, 교차 어텐션

공개 모델들의 연결 방식은 다음처럼 비교할 수 있다.

| 모델 | 시각 쪽 | 연결부 | 언어 모델이 시각 정보를 읽는 방식 | 대표적인 정보 경계 |
|---|---|---|---|---|
| Flamingo | 동결 시각 인코더 | Perceiver Resampler + 게이트 교차 어텐션 | 언어 층 사이에서 텍스트 은닉 상태가 시각 토큰에 교차 어텐션 | 고정 64개 시각 토큰으로 압축하며, 새 경로는 0 초기화 게이트로 점진적으로 열린다. |
| BLIP-2 | 동결 이미지 인코더 | Q-Former + 선형 투영 | 질의 토큰의 출력이 LLM 앞부분의 소프트 시각 프롬프트가 된다. | 학습 가능한 고정 개수 질의가 시각 정보 병목을 만든다. |
| LLaVA 초판 | 동결 CLIP ViT-L/14 | 학습 가능 선형 투영 | 투영한 패치 특징을 언어 토큰 임베딩과 같은 차원에서 조건으로 사용 | 단순 연결부 대신 시각 지시 튜닝에서 projector와 LLM을 조정한다. |
| GPT-4 | 비공개 | 비공개 | 이미지와 텍스트 입력, 텍스트 출력만 공식 확인 | 공개 기술 보고서만으로 위 세 방식 중 어느 것인지 결정할 수 없다. |

Flamingo에서는 시각 토큰이 모든 텍스트 토큰과 처음부터 한 시퀀스로 섞이는 것이 아니라, 새 교차 어텐션 층을 통해 동결 언어 모델의 잔차 스트림에 들어간다. BLIP-2에서는 Q-Former가 이미지 인코더와 LLM 사이의 표현 차이를 먼저 좁힌다. LLaVA는 훨씬 단순한 선형 투영으로도 시각 지시 튜닝이 가능하다는 가설을 시험했다. 그러므로 “복잡할수록 깊은 통합” 또는 “선형 투영이면 얕은 이해”라고 구조만으로 성능을 단정할 수 없다. 데이터, 학습 목적, 해상도, 언어 모델과 평가가 함께 결정한다.

### 4.4 언어 모델: 시각을 조건으로 텍스트를 생성한다

많은 2021–2023년 모델의 출력은 텍스트이며, LLM은 인과적 다음 토큰 예측을 계속 수행한다. 시각 특징은 답변 생성의 조건이지만, 모델이 생성한 문장이 항상 시각 증거에 고정되어 있다는 보장은 없다. 언어 모델이 학습한 공기(共起) 지식과 문장 완성 경향은 모호한 이미지에서 그럴듯하지만 존재하지 않는 물체를 보충하게 만들 수 있다. 이것이 시각 환각의 한 원인이다.

원문은 사람의 시각과 언어가 “양방향으로 깊게 상호작용”하는 것과 모델 구조를 가깝게 놓는다. 그러나 많은 모델은 이미지가 텍스트 생성에 조건을 주는 비대칭 구조다. 생성된 텍스트가 다시 원본 픽셀 표현을 갱신하거나, 사람처럼 시선을 이동해 능동적으로 재관찰하는 과정이 기본적으로 포함되는 것은 아니다. 텍스트 질문이 교차 어텐션 가중치를 바꿀 수 있다는 사실과 인간의 양방향 지각을 구현했다는 주장은 서로 다르다.

### 4.5 동결, 공동 학습, 시각 지시 튜닝

“동결된 모델을 사용했다”는 말은 멀티모달 훈련을 하지 않았다는 뜻이 아니다. Flamingo는 두 백본을 동결했지만 Resampler와 교차 어텐션 블록을 방대한 웹 멀티모달 자료로 학습했다. BLIP-2도 Q-Former를 이미지-텍스트 표현 학습과 생성 학습의 두 단계로 훈련했다. LLaVA 초판은 595,000개 CC3M 기반 이미지-텍스트 쌍으로 projector를 먼저 정렬한 뒤, 약 158,000개 시각 지시 예시로 projector와 LLM을 조정했다. LLaVA의 지시 데이터는 텍스트 전용 GPT-4에 캡션과 경계 상자 정보를 주어 생성한 것이므로, GPT-4가 그 단계에서 원본 이미지를 직접 보았다고 표현하면 안 된다.

“제로샷”과 “퓨샷”도 훈련의 부재가 아니라 평가 시 적응 방식을 나타낸다.

- 제로샷: 대상 벤치마크의 예시나 대상 과제용 가중치 업데이트 없이 질의한다. 그러나 대규모 사전학습·시각-언어 정렬·지시 튜닝은 이미 끝난 상태다.
- 퓨샷 인컨텍스트 학습: 가중치를 바꾸지 않고 프롬프트에 몇 개의 시범 입력-출력 쌍을 넣는다.
- 퓨샷 미세조정: 소수 예시로 경사하강을 수행한다. 같은 “퓨샷”이라는 이름이어도 위 방식과 비교 조건이 다르다.
- 과제별 미세조정: 특정 데이터셋의 훈련 분할로 모델을 조정한다. 이 결과를 순수 제로샷 결과와 나란히 놓으려면 명시해야 한다.

### 4.6 OCR·차트·VQA는 서로 다른 평가다

이미지를 보고 답을 내는 과정은 최소한 다음 단계로 나눌 수 있다.

\[
\text{픽셀 인식/OCR} \rightarrow \text{대상 연결·위치 파악}
\rightarrow \text{지식·계산·추론} \rightarrow \text{답 형식 생성}
\]

총점 하나는 어느 단계에서 실패했는지 알려 주지 않는다. 작은 축 레이블을 잘못 읽은 차트 답변과 숫자는 정확히 읽었지만 비율을 잘못 계산한 답변은 다른 실패다. VQA에서 답을 맞혔더라도 이미지가 아니라 질문의 언어적 편향으로 추측했을 수 있다.

| 평가 예 | 주로 묻는 것 | 결과를 해석할 때의 제한 |
|---|---|---|
| VQA v2 | 자연 이미지에 대한 짧은 답변, 언어 편향을 줄이기 위한 대응 이미지 쌍 | 정답 일치 점수는 자유 형식 설명의 사실성이나 긴 추론을 직접 재지 않는다. |
| TextVQA | 장면 속 글자를 읽고 질문에 답하기 | OCR, 글자와 물체의 연결, 상식 추론이 섞여 있어 어느 모듈의 성능인지 분해해야 한다. |
| ChartQA | 차트의 시각 요소·레이블·수치에 대한 논리·산술 질의 | 일부 설정은 원시 데이터 표도 입력하므로, 픽셀만으로 읽은 결과와 직접 비교하면 안 된다. |
| ScienceQA | 과학 객관식 문제, 일부는 이미지 문맥 포함 | 텍스트 문제도 섞여 있고 과제별 미세조정·앙상블 여부가 점수에 큰 영향을 준다. |
| GPT-4 보고서의 시연 | 문서·사진·도표·스크린샷에 대한 선택된 예 | 능력의 존재를 보여 주는 사례이지, 모집단 오류율을 추정하는 완전한 벤치마크가 아니다. |

평가 설계는 [VQA v2 논문](https://openaccess.thecvf.com/content_cvpr_2017/html/Goyal_Making_the_V_CVPR_2017_paper.html)의 §3 데이터 수집·§4 평가, [TextVQA 논문](https://openaccess.thecvf.com/content_CVPR_2019/html/Singh_Towards_VQA_Models_That_Can_Read_CVPR_2019_paper.html)의 §3 데이터셋·§5 실험, [ChartQA 논문](https://aclanthology.org/2022.findings-acl.177/)의 §3 데이터셋·§4 실험을 기준으로 확인할 수 있다. VQA v2는 서로 비슷하지만 답이 다른 이미지 쌍으로 질문 편향을 줄였고, TextVQA는 28,408개 이미지와 45,336개 질문으로 장면 문자 읽기를 겨냥했으며, ChartQA는 사람 작성 질문 약 9,600개와 생성 질문 약 23,100개를 포함한다. 숫자의 크기 자체보다 각 데이터셋이 통제하려 한 실패 원인을 읽는 것이 중요하다.

LLaVA 초판의 “GPT-4 대비 85.1%”는 일반 시각 능력의 85.1%가 아니다. 30개 COCO 이미지와 90개 질문으로 만든 합성 LLaVA-Bench에서, 이미지 설명과 상자 정보를 받은 텍스트 전용 GPT-4의 답을 100으로 놓고 GPT-4를 판정자로 쓴 상대 점수다. ScienceQA 92.53%도 과제별 미세조정한 LLaVA와 GPT-4의 답을 앙상블한 설정이다. 이 숫자들은 그 평가 설계 안에서는 의미가 있지만, 곧바로 인간 수준이나 범용 제로샷 성능으로 확장할 수 없다.

## 5. 원문의 논리 구조

원문은 대략 다음 순서로 전개된다.

1. 문제 제기: 텍스트 LLM과 시각 모델은 각각 강했지만, 현실 과제에는 이미지와 텍스트를 함께 다루는 능력이 필요했다고 서술한다.
2. 선행 흐름: CLIP과 Flamingo를 언급한 뒤, 2023년에 더 강한 추론과 시각 표현을 결합하는 과제가 남았다고 설명한다.
3. 해결책: 시각 인코더가 이미지를 시각 토큰으로 바꾸고, 같은 표현 공간에서 언어 모델의 어텐션이 이를 처리하는 전형적 구조를 제시한다.
4. 대표 사례: GPT-4가 차트·사진·도표·이미지 속 글자를 처리했다고 설명하고, 이 성과를 2023년의 전환점으로 놓는다.
5. 응용과 영향: 연구·교육·창작·접근성·데이터 분석에서 즉각적인 활용과 배포 단순화가 일어났다고 주장한다.
6. 한계: 해상도, 공간 추론, 편향, 계산 비용, 복잡한 시각-텍스트 결합과 인간보다 얕은 이해를 열거한다.
7. 유산: 멀티모달 통합을 더 일반적인 AI와 AGI를 향한 경로로 평가한다.

이 논리는 개념 입문으로는 이해하기 쉽지만, 서로 다른 종류의 증거를 한 줄의 진보 서사로 묶는다. 공개 논문의 모델 구조, 제품 데모에서 확인된 기능, 벤치마크 점수, 실제 배포 효과, 인간 지능과 AGI에 관한 전망은 같은 증거 수준이 아니다. 특히 GPT-4의 비공개 구조를 공개 모델의 전형적 구조로 채워 넣고, 기능 시연을 산업 변혁이나 광범위한 채택의 증거로 확장하는 부분은 교정이 필요하다.

원문의 장점은 시각 인코더, 정보 밀도, 가변 길이 입력, 모달리티별 데이터 균형과 계산 비용 같은 실질적인 설계 문제를 한눈에 제시한다는 데 있다. 이를 살리려면 “모델들은 보통 이렇게 설계된다”와 “GPT-4가 실제로 이렇게 설계됐다”를 분리하고, 잠재 응용과 측정된 현장 성과를 구분해야 한다. 또한 한계 절의 일반적 경고를 구체적인 실패 프로토콜과 배포 제한으로 연결해야 한다.

## 6. 왜 중요한가

시각 입력을 자연어 생성 인터페이스에 연결한 변화는 실제로 중요했다. 사용자는 별도의 객체 탐지 API, OCR 프로그램, 질문 분류기와 답변 생성기를 각각 호출하지 않고도 사진·스크린샷·문서와 질문을 한 대화 안에 넣을 수 있게 됐다. 연구 관점에서는 기존의 강한 단일 모달 백본을 보존하면서 작은 연결부와 새로운 데이터로 능력을 조합하는 방법이 비용 대비 유효한지 실험할 수 있었다.

첫째, 과제의 출력 형식이 자연어로 통일됐다. 이미지 분류, 캡셔닝, VQA, 문서 설명이 모두 “주어진 시각 조건에서 다음 텍스트를 생성한다”는 인터페이스로 표현될 수 있다. 이는 과제마다 새 분류 헤드를 만드는 부담을 줄이고, 프롬프트로 질문 방식과 답 형식을 바꾸는 유연성을 제공한다.

둘째, 설계 공간이 명확해졌다. 연구자는 시각 인코더의 해상도와 학습 상태, 연결부의 토큰 수와 복잡도, LLM의 크기와 조정 범위, 멀티모달 데이터 품질을 서로 분리해 비교할 수 있다. Flamingo, BLIP-2, LLaVA는 모두 “강한 기존 모델을 재사용한다”는 공통점을 가지지만, 각기 다른 병목과 비용을 택했다. 이것은 단일한 정답보다 여러 공학적 절충이 있다는 사실을 보여 준다.

셋째, 모델의 평가가 현실의 복합 입력에 가까워졌다. 문서에는 글자, 표, 차트, 사진과 배치 정보가 함께 있고, 사용자 질문은 이들 사이의 관계를 묻는다. 이런 입력을 한 모델에 줄 수 있다는 것은 잠재적 가치가 크다. 다만 가능성의 입증과 신뢰 가능한 업무 자동화는 다르다. 현장 가치를 말하려면 정확도뿐 아니라 실패 탐지율, 사람이 수정하는 시간, 비용·지연, 민감 이미지 처리, 장애 시 대체 절차를 함께 측정해야 한다.

따라서 역사적 의의는 “사람처럼 보게 됐다”보다 더 구체적으로 표현할 수 있다. 2023년 전후의 멀티모달 LLM은 범용 텍스트 생성기를 시각 입력의 공통 인터페이스로 재사용하는 여러 방법을 확립했고, 그 인터페이스를 실제 사용자와 개발자에게 넓게 노출하면서 구조적 오류가 사회적 배포 문제로 바뀌는 분기점을 만들었다.

## 7. 현대 LLM과의 연결

### 7.1 시각 지시 튜닝과 대화형 인터페이스

LLaVA가 보여 준 시각 지시 튜닝은 오늘날 대화형 멀티모달 모델의 중요한 구성요소다. 이미지-캡션 정렬만으로는 “어떤 부분을 비교하라”, “표의 둘째 행을 근거로 설명하라”, “모르면 모른다고 답하라” 같은 대화 규칙을 충분히 배우기 어렵다. 지시 데이터는 사용자의 요청 형식과 답변 스타일을 학습시키지만, 데이터 생성 모델의 편향과 환각도 함께 전이할 수 있다. 합성 지시 데이터의 양보다 원본 이미지와 답변의 근거 정합성, 난이도 분포, 거절 예시와 오류 분석이 중요하다.

### 7.2 문서 이해, OCR, 검색과 도구 사용

현대 시스템은 이미지 하나를 LLM에 보내는 것만으로 끝나지 않는다. 고해상도 문서를 타일로 나누고, OCR 결과와 레이아웃 좌표를 보존하며, 표를 구조화하고, 원문 페이지를 검색해 답에 인용 근거를 붙이는 파이프라인이 흔하다. 이런 구성은 “단일 통합 모델”이라는 표현보다 시스템 관점이 더 정확함을 보여 준다. OCR이나 차트 파서가 틀리면 LLM은 잘못된 입력을 유창하게 설명할 수 있으므로, 중간 산출물과 원본 영역을 함께 검증해야 한다.

### 7.3 모듈식 결합과 네이티브 멀티모달 학습

후속 연구는 동결 백본을 연결하는 방식과 여러 모달리티를 더 일찍부터 공동 학습하는 방식을 모두 탐색한다. 전자는 기존 강한 모델을 재사용하고 구성요소를 교체하기 쉽지만, 표현 병목과 모달리티 불균형이 생길 수 있다. 후자는 더 긴밀한 정렬을 기대할 수 있지만 데이터·계산 비용이 크고, 어떤 모달리티가 성능을 지배하는지 분석하기 어렵다. “네이티브”라는 제품 용어만으로 공동 학습 범위나 내부 구조를 알 수 없으므로 기술 보고서의 학습 대상과 입출력 경계를 확인해야 한다.

### 7.4 멀티모달 RAG와 검증 가능한 답변

이미지와 문서를 검색한 뒤 LLM이 답을 합성하는 멀티모달 검색 증강 생성(RAG)은 모델 내부 기억만으로 답하는 위험을 줄일 수 있다. 그러나 검색 결과에 실제 이미지가 포함됐다는 사실만으로 근거성이 확보되지는 않는다. 답변의 각 주장에 대응하는 페이지·영역·표 셀을 연결하고, OCR 원문과 모델의 해석을 분리해야 한다. 공간 위치가 중요한 업무에서는 자연어 설명과 함께 경계 상자나 원본 크롭을 반환하는 편이 검증 가능성을 높인다.

### 7.5 배포 관측성과 인간 검토

텍스트 시스템의 로그만으로는 멀티모달 오류를 재현하기 어렵다. 이미지 전처리 버전, 리사이즈·타일링 좌표, OCR 결과, 모델 버전, 프롬프트와 도구 호출을 함께 기록해야 한다. 민감 이미지에서는 보존 기간과 접근 통제도 필요하다. 의료, 신원 확인, 이동 보조, 안전 검사처럼 오류 비용이 큰 영역에서는 모델 답을 최종 결정으로 쓰지 않고 전문 도구·사람 검토·확신 부족 시 중단 절차를 둬야 한다.

### 8.2 발표, 제한 시험, 광범위한 배포를 섞지 말아야 한다

GPT-4의 2023년 3월 발표 자료는 시각 입력 예시를 보여 주었지만, 바로 모든 사용자가 해당 기능을 쓸 수 있었던 것은 아니다. GPT-4V 시스템 카드에 따르면 Be My Eyes와의 제한된 시험은 3월부터 8월 초까지 약 200명의 베타 사용자로 진행됐고, 9월에는 약 16,000명의 사용자와 하루 약 25,000건의 설명 요청 규모로 확대됐다. 이 수치는 하나의 접근성 파트너 프로그램에서의 초기 사용을 보여 주는 자료이지, 모든 산업의 “대규모 채택”을 증명하는 수치가 아니다.

2023년 9월 25일 OpenAI는 [ChatGPT의 이미지·음성 기능](https://openai.com/index/chatgpt-can-now-see-hear-and-speak/)을 Plus와 Enterprise 사용자에게 2주에 걸쳐 출시한다고 발표했다. 11월 6일에는 [개발자용 `gpt-4-vision-preview`](https://openai.com/index/new-models-and-developer-products-announced-at-devday/)를 발표했다. 이 세 날짜를 나누면 기술 발표, 통제된 현장 시험, 소비자 배포, API 생태계 확산을 서로 다른 사건으로 분석할 수 있다.

### 8.3 GPT-4의 구조는 비공개다

원문의 가장 중요한 사실 오류는 GPT-4의 시각 인코더, 임베딩 결합 위치와 어텐션 경로를 확정된 구조처럼 설명한 부분이다. GPT-4 기술 보고서는 구체적인 구조를 공개하지 않았으며, 시각 입력 절도 입출력 능력과 예시만 설명한다. “시각 인코더 → 연결부 → LLM”은 당시 공개 모델을 설명하는 유용한 추상 틀이지만, GPT-4가 LLaVA처럼 패치 토큰을 입력 앞에 붙였는지, Flamingo처럼 중간 층 교차 어텐션을 썼는지, 다른 혼합·라우팅 방식을 썼는지는 공식 자료로 판단할 수 없다.

비공개 모델의 행동을 공개 모델과 비교할 수는 있지만, 행동 유사성이 구조 동일성을 입증하지는 않는다. 차트를 읽고 사진을 설명한다는 출력만으로 내부 인코더의 종류, 학습 시 동결 범위나 토큰 결합 방식을 역추론해서는 안 된다.

### 8.4 “인간 수준”은 대상·분포·기준을 밝혀야 한다

OpenAI는 GPT-4가 여러 전문·학술 벤치마크에서 인간 수준의 성능을 보였다고 소개하는 동시에, 현실의 많은 시나리오에서는 인간보다 덜 유능하다고 명시했다. 이때 전문 시험 결과의 상당 부분은 텍스트 입력 평가이며, 시각 이해 전체를 측정하지 않는다. 인간 수준이라는 말에는 최소한 어떤 사람 집단, 어떤 데이터 분포, 어떤 점수, 도구 사용 여부와 오류 비용을 밝혀야 한다.

정적 벤치마크에서 평균 정확도가 높아도 작은 글자·낯선 도식·비정상 관점·희귀 객체·다국어 장면·적대적 이미지에서는 성능이 달라질 수 있다. 사용자가 오류를 알아차리기 어려운 자연어 설명에서는 같은 정확도라도 과신의 비용이 더 크다. 따라서 인간 비교보다 과제별 실패율, 보정, 거절 품질과 분포 이동을 보고하는 것이 배포 판단에 유용하다.

### 8.5 “제로샷”은 무학습이나 미지의 세계를 뜻하지 않는다

CLIP의 제로샷 분류, BLIP-2의 제로샷 VQA, LLaVA의 지시 수행은 같은 말 아래 서로 다른 학습 이력을 가진다. 공통적인 최소 의미는 대상 벤치마크에 맞춘 추가 가중치 업데이트가 없다는 것이다. 웹 이미지-텍스트 사전학습, 합성 지시 생성, 유사 과제 학습과 프롬프트 설계는 여전히 존재한다. 공개 웹 데이터의 중복 여부가 완전히 알려지지 않았다면 “처음 보는 과제를 이해했다”보다 “명시적인 과제별 미세조정 없이 평가했다”라고 쓰는 편이 정확하다.

### 8.6 OCR·차트·VQA 점수는 능력의 합성물이다

TextVQA는 장면 속 글자를 읽어 답해야 하고, ChartQA는 글자 인식 외에도 범례 연결·수치 추출·비교·산술을 요구한다. VQA v2는 질문만 보고 답하는 언어 편향을 줄이려 대응 이미지 쌍을 설계했지만, 여전히 짧은 답변 점수다. 이들 점수를 합쳐 “시각을 이해한다”라고 말하면 오류의 원인을 잃는다.

실험 보고에서는 원본 픽셀만 사용했는지, 외부 OCR이나 차트 데이터 표를 함께 제공했는지, 답 형식을 강제했는지, 다중 시도·도구 사용·사람 검수가 있었는지 밝혀야 한다. 특히 GPT-4 기술 보고서의 차트와 문서 예시는 기능 시연으로 읽어야 한다. 선택된 성공 예시는 표본 추출 절차와 실패 건수를 알 수 없으므로 일반 오류율을 계산할 수 없다.

### 8.7 환각과 공간 추론은 별도 실패 축이다

시각 환각은 이미지에 없는 물체·속성·관계를 답에 넣는 현상이다. Flamingo 논문은 이미 2022년에 개방형 VQA에서 근거 없는 추측 사례를 보였고, POPE는 물체가 존재하는지 예/아니오로 묻는 방식으로 객체 환각을 더 체계적으로 측정했다. 언어 데이터에서 자주 함께 등장한 물체나 인기 있는 객체가 이미지 증거보다 강하게 답을 끌 수 있다.

공간 추론 오류는 환각과 겹치지만 동일하지 않다. 모델이 모든 물체를 정확히 인식해도 왼쪽·오른쪽, 앞·뒤, 포함 관계, 상대 크기, 차트 색과 범례의 대응을 잘못 연결할 수 있다. GPT-4V 시스템 카드는 과학 이미지에서 문자·수학 기호를 놓치거나 공간 위치와 색 매핑을 틀리는 사례를 보고했고, 이미지의 제시 순서가 추천 결과에 영향을 주는 시각적 취약성도 기록했다. 객체 존재, 문자 전사, 위치 관계, 계산을 분리해 시험해야 한다.

### 8.8 안전은 텍스트 안전 필터의 단순 확장이 아니다

이미지에는 사람의 얼굴, 위치 단서, 문서의 개인정보, 의료 정보와 저작물이 들어갈 수 있다. 이미지 안에 적힌 명령이나 스크린샷은 텍스트 필터를 우회하는 프롬프트 주입 경로가 될 수 있고, 작은 변화나 배치 순서가 답을 바꿀 수 있다. GPT-4V 시스템 카드는 인물 식별·민감 속성의 근거 없는 추론, 이미지에 삽입한 우회 요청, CAPTCHA, 지리 위치 추론과 허위정보 판별을 별도 위험으로 평가했다.

안전한 배포에는 입력 동의, 이미지 최소 수집, 보존 기간, 로그 접근 통제, OCR로 드러난 개인정보 처리와 제3자 얼굴 정책이 필요하다. 모델이 “확신한다”는 문장만으로 신뢰도를 판단하지 말고, 증거 영역을 표시하고 불확실할 때 거절하거나 사람에게 넘기는 절차를 둬야 한다.

### 8.9 접근성과 고위험 분야는 가능성과 위험이 함께 커진다

Be My Eyes 사례는 시각 정보에 접근하기 어려운 사용자가 사진을 자연어로 설명받을 수 있다는 실질적 가능성을 보여 주었다. 동시에 시스템 카드는 베타 시험에서 그럴듯한 오설명과 OCR 오류가 있었고, 안전·건강·길 건너기 같은 고위험 상황에는 사용하지 말라는 경고와 사람 자원봉사자 연결을 유지했다고 설명한다. 접근성 도구에서 오류는 단순 불편이 아니라 사용자가 직접 검증하기 어려운 비대칭 위험이 될 수 있다.

의료에서도 “적절한 주의를 기울이면 의료 영상을 분석할 수 있다”는 식의 표현은 부족하다. GPT-4V 시스템 카드의 의료 평가는 영상 해석이 일관되지 않고 좌우 방향까지 틀릴 수 있음을 보여 주며, 의료 기능이나 전문가 대체에 적합하지 않다고 명시한다. 고위험 영역에서는 일반 멀티모달 대화 모델을 전문 진단 모델과 혼동하지 말고, 규제·검증·전문가 검토의 경계를 유지해야 한다.

### 8.10 산업 변혁·채택·AGI는 별도의 증거가 필요하다

원문은 연구, 교육, 창작, 데이터 분석과 접근성에서 즉각적 변혁이 일어났고 자연스러운 상호작용이 채택을 촉진했다고 서술한다. 그러나 기술 기능과 산업 결과 사이에는 제품 통합, 비용, 지연, 오류 처리, 사용자 교육, 법적 책임과 조직 변화가 있다. 산업 변혁을 주장하려면 도메인별 도입 규모, 기존 방식과의 비교, 작업 시간과 품질 변화, 실패와 중단 사례를 추적한 자료가 필요하다.

여러 감각 입력을 처리한다는 사실도 인간과 같은 이해나 AGI로 곧바로 이어지지 않는다. 사람의 지각은 능동적 관찰, 신체 행동, 장기 기억, 사회적 맥락과 지속적인 환경 피드백을 포함한다. 정적 이미지를 조건으로 텍스트를 생성하는 능력은 중요한 범위 확장이지만, 일반 지능의 충분조건은 아니다. “AGI를 향한 경로”는 실험 결과라기보다 연구 전망으로 표시해야 한다.

### 8.11 단일 인터페이스가 운영 복잡성을 없애지는 않는다

모델 호출이 하나로 줄어도 고해상도 전처리, 토큰 예산, GPU 메모리, 응답 지연, 콘텐츠 필터, OCR·검색 도구, 캐시와 감사 로그가 필요하다. 이미지 토큰은 텍스트보다 비용이 클 수 있고, 복수 페이지 문서는 문맥 한도와 세부 보존 사이에서 절충한다. 모델 제공자의 입력 처리 정책이 바뀌거나 특정 이미지 유형이 거절될 때의 대체 경로도 설계해야 한다.

따라서 배포 단순화는 “사용자와 개발자가 하나의 자연어 API로 여러 과제를 표현하기 쉬워졌다”는 인터페이스 수준에서는 성립할 수 있다. 내부 시스템 수, 운영 책임, 검증 비용까지 줄었다는 주장은 별도의 측정이 필요하다.

| 교차 어텐션 | 한 표현의 질의가 다른 표현의 키·값을 읽는 연산 | 모든 모달리티가 대칭적으로 상호 수정된다는 뜻은 아니다. |

| 시각 지시 튜닝 | 이미지와 자연어 지시·응답 쌍으로 대화 행동을 조정하는 훈련 | 합성 데이터의 생성 방식, 실제 이미지 근거와 중복 여부를 확인해야 한다. |
| VQA | 이미지와 질문을 받아 보통 짧은 자연어 답을 내는 과제 | 데이터셋의 질문 분포와 채점법에 특화될 수 있다. |
| OCR | 이미지 속 문자를 인식해 텍스트로 옮기는 기술 | 전사 정확도와 문서 의미 이해는 서로 다른 단계다. |
| 시각 환각 | 이미지에 근거하지 않은 물체·속성·관계를 생성하는 현상 | 유창함이나 자기 보고 확신은 근거성의 지표가 아니다. |
| 제로샷 | 대상 과제용 추가 가중치 업데이트 없이 평가하는 설정 | 사전학습·지시 튜닝·유사 데이터 노출이 없다는 뜻이 아니다. |
| 퓨샷 인컨텍스트 학습 | 소수의 시범 예시를 프롬프트에 넣고 가중치 갱신 없이 수행하는 방식 | 소수 예시로 미세조정하는 퓨샷 학습과 구분한다. |
| 인간 수준 | 특정 인간 집단과 특정 평가에서 비슷한 점수를 얻었다는 비교 표현 | 과제, 사람 기준, 도구 사용, 분포와 오류 비용을 밝히지 않으면 의미가 지나치게 넓다. |

## 12. 짧은 결론

2023년의 멀티모달 LLM은 시각과 언어의 최초 결합이라기보다, CLIP과 Flamingo가 마련한 계보 위에서 여러 연결 구조가 빠르게 실험되고 대화형 제품과 API로 확장된 전환기였다. Flamingo의 게이트 교차 어텐션, BLIP-2의 Q-Former, LLaVA의 선형 projector는 “이미지를 LLM에 넣는다”는 공통 문장 아래 서로 다른 병목과 학습 전략이 있음을 보여 준다. GPT-4의 시각 기능은 중요한 제품 사건이었지만, 3월 발표와 9월 광범위 배포, 11월 API를 구분해야 하며 구체적인 내부 구조는 공개되지 않았다.

이 분야를 정확히 이해하려면 성공 시연이나 총점에서 한 단계 더 내려가야 한다. OCR, 차트, VQA와 공간 추론을 분리하고, 제로샷의 학습 경계와 인간 수준의 비교 대상을 밝히며, 객체 환각·시각적 우회 공격·고위험 오판을 실제 배포 절차와 연결해야 한다. 멀티모달 인터페이스는 분명 새로운 가능성을 열었지만, 인간과 같은 이해·산업 변혁·AGI를 증명하지는 않는다. 역사적으로 남는 성취는 더 제한적이면서도 충분히 크다. 기존 시각 모델과 언어 모델을 재사용하고 연결하는 설계 공간을 넓혔고, 그 결과를 현실의 사용자에게 제공하면서 평가와 안전의 기준까지 새로 요구하게 만들었다.

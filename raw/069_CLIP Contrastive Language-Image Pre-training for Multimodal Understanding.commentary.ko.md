# CLIP과 대조적 언어-이미지 사전학습 해설

## 1. 한눈에 보기

- 핵심 주제: 이미지와 텍스트를 같은 좌표계에 놓고, 맞는 쌍을 구별하도록 학습하는 이중 인코더(dual encoder)
- 등장 배경: 고정된 레이블 집합과 대규모 수작업 주석에 의존하던 시각 분류기의 경직성
- 가장 중요한 아이디어: 한 배치 안의 실제 이미지-텍스트 쌍은 가깝게, 나머지 조합은 멀게 만드는 대조 목적 함수
- 이후 LLM/NLP에 남긴 영향: 자연어를 새 과제의 분류 인터페이스로 사용하고, 사전학습 지식을 프롬프트로 불러오는 방식을 시각 영역에 확장

> 이 문서는 `069_CLIP Contrastive Language-Image Pre-training for Multimodal Understanding.md`의 번역문을 이해하기 위한 해설입니다. 원문의 장점을 살리되, 2021년 CLIP 논문이 실제로 입증한 범위와 후대의 해석을 구분합니다.

## 2. 핵심 요약

CLIP(Contrastive Language-Image Pre-training)은 이미지 인코더와 텍스트 인코더를 함께 학습해 두 출력이 공유 임베딩 공간에서 비교되도록 만든다. 한 배치에 이미지-텍스트 쌍이 $N$개 있으면 가능한 $N \times N$ 조합 중 실제로 짝지어진 $N$개를 양성으로 보고, 이미지에서 텍스트를 찾는 방향과 텍스트에서 이미지를 찾는 방향의 교차 엔트로피를 평균한다. 연구진은 공개 인터넷 출처에서 수집한 4억 개의 이미지-텍스트 쌍으로 WebImageText(WIT)를 구성했으며, 실험에서 사용한 큰 배치는 각 예시가 수많은 배치 내 음성(in-batch negatives)과 비교되게 했다. 사전학습 뒤에는 클래스 이름이나 설명을 텍스트 프롬프트로 바꾸어, 별도의 과제별 경사 하강 없이 이미지와 가장 가까운 클래스를 고를 수 있다. 최상위 모델은 ImageNet에서 제로샷 top-1 정확도 76.2%를 기록해 원래의 지도학습 ResNet-50과 같았지만, 이는 당시 전체 지도학습 최고 성능과 같다는 뜻은 아니다. 또한 논문은 30개가 넘는 데이터셋에서 전이를 평가했으나, 세밀한 분류·계수·위성 영상·거리 추정처럼 성능이 낮은 과제도 분명히 보고했다. 따라서 CLIP의 성과는 ‘이미지를 인간처럼 이해했다’기보다, 인터넷 규모의 자연어 감독으로 재사용 가능한 시각 표현과 유연한 분류 인터페이스를 만들었다는 데 있다.

- 무엇을 다루는가: 대조 학습으로 결합한 이미지-텍스트 표현과 자연어 기반 제로샷 전이
- 어떤 문제를 해결하려 했는가: 새로운 시각 과제마다 고정 레이블 데이터셋과 분류기를 다시 만드는 비용
- 어떤 방식이 새로웠는가: 웹 규모의 자연어 감독, 대규모 배치 내 음성, 클래스 설명으로 합성한 제로샷 분류기
- 결과적으로 무엇을 바꾸었는가: 시각 모델의 출력 공간을 자연어로 호출하고 재조합하는 연구 흐름을 크게 확장

## 3. 역사적 배경

CLIP 이전에도 이미지와 언어를 같은 표현 공간에 배치해 보지 못한 것은 아니다. DeVISE 계열은 단어 벡터를 이용해 학습 때 보지 못한 클래스에 전이했고, Visual N-Grams는 웹 이미지의 제목·설명·태그를 감독 신호로 사용했다. VirTex와 ICMLM은 각각 생성적 언어 모델링과 마스크 언어 모델링을 시각 표현 학습에 적용했으며, ConVIRT는 의료 영상에서 이미지-텍스트 대조 목적을 사용했다. CLIP의 역사적 위치는 이 아이디어들을 처음 발명했다는 데 있지 않고, 효율적인 대조 목적과 훨씬 큰 데이터·모델 규모를 결합해 범용 벤치마크 전이를 체계적으로 보였다는 데 있다.

- 이전 접근법: ImageNet식 고정 클래스 지도학습, 시각-의미 임베딩, 웹 기반 약한 감독, 이미지 캡션 생성
- 당시의 한계: 과제마다 새 레이블과 출력 헤드가 필요했고, 생성 목적은 대규모 제로샷 분류 전이를 학습하는 데 계산 효율이 낮았다.
- 이 주제가 필요했던 이유: 인터넷의 이미지 주변 텍스트를 더 넓은 시각 개념의 감독 신호로 바꾸고, 과제 정의를 자연어로 전달하려는 요구가 커졌다.

## 4. 핵심 개념 해설

### 4.1 이중 인코더와 공유 임베딩 공간

CLIP은 이미지를 처리하는 인코더와 텍스트를 처리하는 인코더를 따로 둔다. 이미지 인코더로는 수정한 ResNet 계열과 Vision Transformer(ViT) 계열을 모두 실험했으므로, 원문처럼 ‘이미지 인코더가 곧 ViT였다’고 단정하면 부정확하다. 텍스트 쪽은 12층·폭 512·8개 어텐션 헤드를 기본으로 한 Transformer이며, GPT-2 계열의 구조적 수정을 참고했지만 텍스트를 생성하는 GPT-2 모델 자체는 아니다. 두 인코더의 표현을 선형 투영한 뒤 L2 정규화하면, 내적이 코사인 유사도와 같아져 이미지와 문장을 직접 비교할 수 있다.

여기서 ‘공유 공간’은 두 모달리티의 모든 정보를 하나로 융합했다는 뜻이 아니다. CLIP에는 이미지 토큰과 텍스트 토큰이 서로를 읽는 교차 어텐션이 없고, 각 인코더가 만든 전역 벡터의 유사도를 비교한다. 따라서 검색과 분류에는 강력하지만, 그 사실만으로 세밀한 관계 추론이나 시각 질문 답변 능력이 보장되지는 않는다.

### 4.2 대조 목적과 배치 내 음성

한 배치의 정답 이미지-텍스트 쌍을 $(I_i, T_i)$라고 하자. 정규화된 이미지 표현과 텍스트 표현으로 $N \times N$ 유사도 행렬을 만들면 대각선이 실제 짝이고 나머지는 그 배치에서의 음성 후보가 된다. CLIP은 학습 가능한 온도(temperature)로 로짓의 척도를 조절하고, 이미지가 정답 텍스트를 고르는 손실과 텍스트가 정답 이미지를 고르는 손실을 대칭적으로 평균한다.

WIT는 인터넷의 모든 이미지를 무차별적으로 모은 데이터셋으로 설명하면 안 된다. 논문에 따르면 연구진은 50만 개 검색 질의를 정하고 질의마다 최대 2만 쌍을 넣어 결과를 대략적으로 균형화했으며, 그렇게 공개 인터넷 출처에서 4억 쌍을 구성했다. 이 절차는 개념 범위를 넓히려는 설계였지만, 검색어 선택과 인터넷의 기존 분포가 만든 편향까지 제거하지는 않는다.

공식 소개에서 설명한 배치 크기는 32,768쌍이다. 그러므로 하나의 예시는 정답 하나뿐 아니라 같은 배치의 매우 많은 다른 후보와 동시에 구별된다. 다만 ‘배치에 함께 들어왔지만 실제로는 의미상 비슷한 쌍’도 음성으로 취급될 수 있으며, 이 목적은 세계의 모든 의미 관계를 직접 가르치는 것이 아니라 쌍 식별을 위한 상대적 유사도를 최적화한다.

### 4.3 제로샷 분류와 프롬프트 앙상블

제로샷 분류에서는 각 클래스 이름을 `a photo of a {label}` 같은 문장으로 만들고 텍스트 인코더로 변환한다. 이렇게 얻은 클래스 벡터들은 선형 분류기의 가중치처럼 작동하며, 입력 이미지 벡터와 가장 유사한 클래스를 예측한다. 여러 문구와 맥락을 클래스별로 만들고 그 예측 또는 표현을 합치는 프롬프트 앙상블(prompt ensembling)은 단일 표현의 우연한 말투에 덜 의존하도록 한다.

이때 ‘제로샷’은 해당 벤치마크의 학습 예제로 과제별 모델을 맞추지 않았다는 뜻이다. CLIP 논문은 통상적인 ‘보지 못한 객체 클래스’보다 넓게 ‘보지 못한 데이터셋으로의 전이’를 제로샷이라 불렀다. 4억 쌍의 사전학습 데이터에 특정 개념이나 유사 이미지가 전혀 없었다는 뜻은 아니며, 클래스 이름을 문장으로 바꾸는 방식과 프롬프트 선택 자체도 과제에 대한 사람의 지식을 주입한다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. 고정 레이블과 수작업 주석에 묶인 전통적 시각 분류의 문제를 제기한다.
2. 이미지와 텍스트를 같은 임베딩 공간에서 정렬하는 대조 학습을 해결책으로 소개한다.
3. 두 인코더, 4억 쌍의 WIT, 배치 내 음성, 프롬프트 기반 제로샷 분류를 설명한다.
4. 분류·검색·생성 보조 등 다양한 응용과 후대의 영향으로 논의를 넓힌다.
5. 세밀한 인식, 데이터 편향, 계산 비용, 공간·수량 추론의 한계를 짚고 멀티모달 AI의 계보로 마무리한다.

이 전개는 학습용 개관으로 유용하지만, ‘CLIP 자체가 실험으로 보인 능력’, ‘CLIP 표현을 다른 시스템이 이용한 응용’, ‘후대 모델에 대한 계보적 해석’을 한 층위에서 서술하는 경향이 있다. 세 범주를 나누어 읽어야 과장을 피할 수 있다.

## 6. 왜 중요한가

CLIP은 자연어 감독을 시각 과제의 범용 인터페이스로 쓸 수 있음을 대규모로 입증했다. 2021년 논문은 30개가 넘는 데이터셋에서 OCR, 동작 인식, 지리 위치, 일반 및 세밀 분류 등을 시험했다. 최상위 CLIP의 ImageNet 제로샷 top-1은 76.2%로 원래 ResNet-50과 같았고, 27개 평가 중 16개에서는 ResNet-50 특징 위에 학습한 지도 선형 분류기보다 높은 점수를 냈다. 같은 CLIP 특징 위의 로지스틱 회귀와 비교하면 평균 제로샷 성능이 클래스당 4개 예시를 쓴 4-shot 성능과 맞먹었다.

특히 중요한 점:

- 자연어 설명을 분류기의 가중치로 바꾸어, 모델 파라미터를 다시 학습하지 않고 과제를 지정했다.
- 생성적 캡션 예측보다 단순한 쌍 식별 목적을 택해 대규모 전이에 필요한 계산 효율을 높였다.
- 인터넷 규모 사전학습과 제로샷 평가를 결합해, 벤치마크별 미세조정과 분리된 강건성 평가의 가능성을 보여 주었다.

그러나 ‘경쟁력 있다’는 표현의 비교 기준을 확인해야 한다. 76.2%는 원래 ResNet-50과의 비교이며 당시 지도학습 최고 성능은 아니었다. 큰 ViT 모델은 256대의 V100에서 12일 동안 학습했고, 최고 성능의 ViT-L/14@336px는 추가로 고해상도 한 에포크를 거쳤다. 논문의 18일 수치는 RN50x64를 592대 V100에서 학습한 경우다.

## 7. 현대 LLM과의 연결

CLIP은 언어 모델은 아니지만, 대규모 사전학습 뒤 자연어로 새 과제를 지정한다는 점에서 GPT 계열의 전이 패턴을 시각으로 옮겼다. [[066_GPT-3 and In-Context Learning Emergent Capabilities from Scale]]과 비교하면 공통점은 프롬프트가 과제 인터페이스라는 것이고, 차이점은 CLIP의 프롬프트가 텍스트 생성을 유도하는 입력 문맥이 아니라 후보 클래스 벡터를 만드는 데 쓰인다는 것이다.

- 자연어 기반 과제 지정: 사람이 클래스 의미를 문장으로 표현하면 텍스트 인코더가 제로샷 분류기의 가중치를 합성한다.
- Transformer의 역할: [[054_The Transformer Attention Is All You Need]]에서 정립한 어텐션 구조가 CLIP의 텍스트 인코더와 ViT 이미지 인코더에 쓰였지만, CLIP은 수정 ResNet도 함께 비교했다.
- 생성 모델과의 결합: [[084_DALL·E 2 Diffusion-Based Text-to-Image Generation with CLIP Guidance]]는 CLIP 이미지 표현을 생성 계층의 잠재 표적으로 직접 사용한 명확한 후속 사례다. 반면 모든 텍스트-이미지 모델이나 GPT-4V가 CLIP에서 직접 계승됐다고 단정할 수는 없다.
- 융합형 시각-언어 모델과의 차이: [[083_Flamingo Few-Shot Vision-Language Learning with Gated Cross-Attention]] 같은 후대 모델은 시각 특징과 언어 모델을 교차 어텐션으로 상호작용시켜 생성·질의응답을 수행한다. 이는 유사도 비교 중심의 CLIP 이중 인코더보다 넓은 기능을 노린다.

## 8. 한계와 비판적 관점

- 기술적 한계: 세밀 분류 성능은 데이터셋마다 크게 달랐고, 합성 장면의 물체 수 세기, 위성 영상 분류, 교통 표지 인식, 최근접 차량 거리 추정 같은 전문적·추상적 과제에서는 약했다. 자연어 문구에도 민감해 프롬프트를 시행착오로 조정해야 했다.
- 이론적 한계: 이미지-문장 유사도가 높다는 사실은 구성 관계, 인과, 공간 구조를 인간처럼 이해했다는 증거가 아니다. 공유 임베딩은 정렬된 측정 공간이지 완전한 의미 융합의 보증서가 아니다.
- 실용적 한계: 4억 쌍의 웹 데이터와 수백 대 GPU가 필요했고, 공개 인터넷 데이터의 잡음·대표성 부족·저작권 및 출처 문제를 규모만으로 해결하지 못한다.
- 공정성과 안전: 논문 자체가 사람 사진을 ‘criminal’, ‘animal’ 같은 모욕적 후보가 포함된 분류 집합에 넣었을 때 심각한 오류와 집단별 차이를 보고했다. 클래스 후보를 어떻게 정하느냐가 성능과 편향을 동시에 바꾸며, 얼굴 식별은 감시·사생활 위험을 키울 수 있다.
- 평가상의 한계: 주 평가 27개 데이터셋은 CLIP 능력에 다소 맞춰 고른 집합이라고 저자들도 인정했고, 개발 중 검증 집합을 반복 조회했으므로 엄격한 의미의 완전한 제로샷과는 거리가 있다. 대규모 웹 사전학습과 평가 데이터의 중복 가능성도 별도로 분석해야 한다.
- 오늘날 관점에서 다시 봐야 할 점: 이미지 검색과 분류는 CLIP의 유사도 출력에서 직접 구현할 수 있지만, 시각 질문 답변·스타일 변환·이미지 생성은 추가 모델이나 최적화가 필요하다. 원문의 응용 목록을 CLIP 단독 능력으로 읽어서는 안 된다.

검증 기준은 Radford et al.의 [ICML 2021 원 논문](https://proceedings.mlr.press/v139/radford21a.html)과 [OpenAI의 공식 CLIP 소개](https://openai.com/index/clip/)이다. 특히 아키텍처·평가 수치·편향·계산량은 2–6절과 부록의 실험 조건을 기준으로 보아야 한다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 대조 학습(contrastive learning) | 서로 대응하는 표현의 유사도는 높이고, 대응하지 않는 후보와의 상대적 유사도는 낮추는 표현 학습 방식 |
| 배치 내 음성(in-batch negatives) | 별도의 음성 데이터셋을 만들지 않고 같은 미니배치의 다른 짝을 오답 후보로 쓰는 방법 |
| 공유 임베딩 공간 | 이미지와 텍스트 벡터를 같은 차원과 척도로 투영해 코사인 유사도로 비교할 수 있게 한 공간 |
| 온도(temperature) | 유사도 로짓의 날카로움을 조절하는 값으로, CLIP에서는 학습 가능한 매개변수 |
| 제로샷 전이(zero-shot transfer) | 대상 데이터셋의 학습 예제로 과제별 파라미터를 맞추지 않고 사전학습 표현과 자연어 과제 정의로 예측하는 것 |
| 프롬프트 앙상블(prompt ensembling) | 같은 클래스를 여러 문장 틀과 맥락으로 표현한 뒤 그 결과를 합쳐 문구 민감도를 줄이는 방법 |
| 선형 프로브(linear probe) | 인코더는 고정하고 그 위의 선형 분류기만 학습해 표현의 재사용 가능성을 평가하는 절차 |

## 12. 짧은 결론

CLIP은 이미지와 자연어를 완전히 융합해 인간 수준으로 이해한 모델이라기보다, 웹 규모의 자연어 감독을 대조 학습으로 압축해 유연한 시각 분류·검색 인터페이스를 만든 모델이다. 수정 ResNet과 ViT 이미지 인코더, Transformer 텍스트 인코더, 대규모 배치 내 음성, 프롬프트 기반 제로샷 분류를 한 체계로 묶은 점이 핵심 성과다. 그 영향은 DALL·E 2 같은 후속 시스템에서 분명히 이어지지만, 공유 임베딩을 곧바로 일반적 멀티모달 이해나 모든 후대 모델의 직접 계보로 확대해서는 안 된다. CLIP을 정확히 읽는 방법은 뛰어난 전이 성능과 함께 프롬프트 민감도, 과제별 편차, 데이터 편향, 높은 계산 비용, 제한된 관계 추론을 동시에 보는 것이다.

# IBM 통계적 기계 번역과 데이터 기반 전환 해설

## 1. 한눈에 보기

- 핵심 주제: 병렬 말뭉치에서 번역 확률과 숨은 단어 정렬을 추정하고, 목표 언어 모델과 결합해 번역 후보를 고르는 IBM의 통계적 기계 번역(Statistical Machine Translation, SMT)
- 등장 배경: 언어쌍마다 사전·문법·변환 규칙을 수작업으로 구축하던 방식의 비용과 범위를 줄이고, 영어–프랑스어 Hansard 자료에서 번역 대응을 학습하려는 연구
- 가장 중요한 아이디어: 번역을 `P(e|f)`의 확률적 선택 문제로 두고 잡음 채널 분해, 잠재 정렬, 기댓값 최대화(EM)를 결합한 것
- 역사적 경계: 단일한 “1991년 발명”이 아니라 1988년 연구 구상, 1990년 예비 시스템과 실험, 1991년 병렬 문장 정렬, 1993년 IBM Models 1–5의 정식화로 나누어야 한다.
- 후대와의 관계: 구 기반 SMT는 IBM 정렬을 직접 활용한 공학적 연속성이 있지만, 신경망 기계 번역과 어텐션은 조건부 번역과 대응 관계라는 문제를 다른 매개변수화로 푼 별도 구조다.

> 이 문서는 022 번역문을 이해하기 위한 해설입니다. 번역문은 원문의 연대와 기술 서술을 그대로 옮겼고, 이 해설은 1차 논문을 기준으로 1991년 최초성, IBM Models의 차이, EM의 E 단계, Hansard 규모, BLEU의 시기와 현대 NMT 계보를 교정합니다.

## 2. 핵심 요약

IBM 연구진의 핵심 전환은 번역 규칙을 전혀 사용하지 않았다는 단순한 구호보다, 번역을 확률 모형의 매개변수 추정 문제로 만들었다는 데 있다. 프랑스어 문장 `f`가 주어졌을 때 영어 문장 `e`를 찾는다면 최종 목표는 `argmax_e P(e|f)`다. 베이즈 정리를 적용하면 분모와 무관한 후보 비교에서 `P(e)P(f|e)`를 최대화할 수 있다. `P(e)`는 영어 문장의 가능성을 평가하는 언어 모델이고, `P(f|e)`는 영어 문장이 어떤 프랑스어 문장을 생성할지를 나타내는 번역 모델이다.

두 언어의 문장 쌍에는 어느 단어가 어느 단어와 대응하는지 표시돼 있지 않다. IBM 모델은 이 정렬을 잠재 변수로 두고 EM으로 번역·정렬 매개변수를 추정했다. 여기서 E 단계는 “가장 좋은 정렬 하나”를 확정하는 절차가 아니다. 가능한 정렬들이 현재 모형 아래에서 갖는 사후확률로 기대 계수를 계산하고, M 단계에서 그 기대 계수로 확률을 다시 정규화한다.

IBM Models 1–5도 단순히 단어, 위치, 다단어 생성, 왜곡, 수치 안정성을 하나씩 더한 목록으로 읽으면 부정확하다. 모델 1은 어휘 번역 확률과 균일 정렬, 모델 2는 위치별 정렬 확률을 둔다. 두 모델에서도 한 영어 단어에 여러 프랑스어 단어가 정렬될 수 있다. 모델 3의 차이는 생성도(fertility), NULL 생성과 배치를 명시적으로 매개변수화한 데 있다. 모델 4는 단어 부류와 상대 위치를 이용해 왜곡을 정교화하고, 모델 5는 앞선 모델이 유효하지 않은 배치에도 확률 질량을 주는 결손 분포(deficient distribution) 문제를 제거한다.

따라서 이 자료의 요점은 다음 네 문장으로 정리할 수 있다.

1. IBM SMT는 번역을 병렬 자료에서 학습하는 조건부 확률 문제로 만들었다.
2. 단어 정렬은 관측된 정답이 아니라 주변화하거나 근사해야 하는 잠재 구조다.
3. IBM Models의 정식 연표는 1988·1990·1991·1993년의 서로 다른 연구 결과를 구분해야 한다.
4. BLEU, 구 기반 SMT, 신경망 번역과 어텐션은 후속 발전이며 초기 IBM Models의 구성 요소가 아니다.

## 4. 핵심 개념 해설

### 4.1 잡음 채널 분해

프랑스어 `f`를 영어 `e`로 번역하는 Brown 등의 방향을 따르면 최선의 번역은 다음처럼 쓸 수 있다.

`e* = argmax_e P(e|f) = argmax_e P(e)P(f|e)`

`P(e)`는 영어 언어 모델이고 `P(f|e)`는 번역 모델이다. `P(f)`는 모든 영어 후보에 공통이므로 최대값을 찾을 때 생략할 수 있다. “영어가 프랑스어를 생성한다”는 방향은 실제 번역 절차의 방향과 반대로 보여 처음에는 어색하지만, 디코더는 관측된 프랑스어를 생성했을 법하면서 영어 자체로도 자연스러운 후보를 찾는다.

이 분해의 장점은 유창성과 언어 간 대응을 별도 모형으로 추정할 수 있다는 데 있다. 한계는 두 구성 요소의 결합만으로 의미 보존이나 문서 수준 일관성이 자동 보장되지 않는다는 점이다. 원문에 세 번 겹쳐 렌더링된 베이즈 식은 이 하나의 식을 표시하는 과정에서 생긴 중복이다.

### 4.2 정렬과 IBM Models 1–5

IBM 모델의 정렬 변수 `a_j=i`는 프랑스어 위치 `j`의 단어가 영어 위치 `i` 또는 NULL에서 생성됐다는 가설을 나타낸다. 모델 1은 어휘 번역 확률을 사용하고 위치 선택을 균일하게 둔다. 모델 2는 문장 길이와 두 위치에 따른 정렬 확률을 더한다.

모델 1·2에서도 여러 프랑스어 단어가 같은 영어 단어에 정렬될 수 있다. 따라서 “앞선 모델은 단어 하나가 정확히 한 단어만 생성한다고 가정했다”는 원문 설명은 맞지 않는다. 모델 3은 한 영어 단어가 생성하는 프랑스어 단어 수의 분포인 생성도를 명시적으로 도입하고 NULL 단어와 단어 배치를 함께 모델링한다. 모델 4는 단어 부류와 이미 배치된 단어의 상대 위치를 이용해 왜곡 모형을 개선한다.

모델 3·4는 두 생성물이 같은 위치를 차지하거나 빈 위치를 남기는 등 유효하지 않은 결과에도 확률 질량을 배정할 수 있어 결손 분포가 된다. 모델 5는 빈 자리 목록을 고려하는 배치 절차로 이 문제를 제거한다. 이를 단순한 “수치 안정성 개선”으로 요약하면 모델 5가 겨냥한 구조적 결손을 놓치게 된다.

### 4.3 EM과 숨은 정렬

정렬이 관측되지 않으므로 번역 확률과 정렬은 서로를 필요로 한다. EM은 현재 매개변수로 각 가능한 정렬의 확률을 계산하고, 그 확률로 단어 쌍·위치·생성도의 기대 계수를 누적한 뒤, 기대 완전자료 로그가능도를 높이도록 매개변수를 갱신한다.

E 단계에서 최고 정렬 하나만 고르면 hard EM 또는 Viterbi식 근사에 가깝다. 원래 Models 1·2의 핵심 계산은 가능한 정렬 전체의 확률 질량을 합산한다. Models 3 이상에서는 정렬 공간이 너무 커서 좋은 정렬 주변을 탐색하는 근사가 사용됐다. 따라서 원문의 “가장 가능성 높은 정렬을 추정한 뒤 갱신한다”는 설명은 입문용 직관으로는 이해할 수 있지만 정확한 EM 정의는 아니다.

### 4.4 Hansard와 학습 자료

Canadian Hansard는 통계 모델을 위해 새로 만든 벤치마크가 아니라 캐나다 의회의 영어·프랑스어 공식 기록이다. IBM 연구진은 여기에서 병렬 문장쌍을 추출하고 정렬해 학습 자료로 사용했다. 1990년 논문은 약 300만 문장쌍을 추출했다고 설명하지만, 보고된 첫 번역 모형 실험에는 40,000쌍, 언어별 약 80만 단어의 부분집합을 사용했다. 1993년의 더 큰 실험은 1,778,620 문장쌍을 사용했다.

원문이 기술 설명서와 국제기구 뉴스까지 초기 IBM 학습 자료로 함께 열거하는 부분은 등록된 1988·1990·1993년 핵심 논문에서 확인되지 않는다. 병렬 자료의 일반적 출처와 이 특정 실험의 실제 자료를 구분해야 한다.

### 4.5 BLEU의 실제 위치

BLEU는 IBM Models를 훈련한 연구진이 1991년에 만든 지표가 아니다. Papineni·Roukos·Ward·Zhu가 2002년 ACL 논문으로 발표했다. 후보 번역의 n-그램이 참조 번역에 얼마나 포함되는지 단순히 세는 데서 끝나지 않고, 과도한 반복을 막는 수정 정밀도와 지나치게 짧은 출력을 벌주는 brevity penalty를 결합한다.

BLEU는 시스템 개발과 말뭉치 수준 비교를 빠르게 만드는 데 큰 역할을 했지만, 문장 하나의 의미 보존이나 모든 언어쌍의 번역 품질을 완전하게 측정하지 않는다. 초기 IBM Models의 성과와 2002년 이후 자동 평가 관행을 같은 시기에 묶지 않는 것이 중요하다.

## 5. 원문의 논리 구조

원문은 다음과 같은 흐름으로 주장을 확장한다.

1. **1991년 혁명 서사**: IBM 연구를 규칙 기반 MT에서 통계적 MT로 바뀐 단일한 출발점으로 제시한다.
2. **확률 정식화**: 베이즈 정리와 잡음 채널 분해로 번역 모형과 언어 모형을 나눈다.
3. **Models 1–5 설명**: 어휘, 위치, 생성도, 왜곡, 마지막 개선을 점진적인 정교화로 소개한다.
4. **숨은 정렬과 EM**: 문장쌍만 관측되는 상황에서 대응 관계가 데이터로부터 나타난다고 설명한다.
5. **확장성과 한계**: 데이터 기반 방식의 장점, 단어 수준 모델의 제약과 구 기반 SMT의 등장을 연결한다.
6. **현대 AI 계보**: 신경망 번역, 어텐션, Transformer와 LLM을 IBM의 원리가 재현된 후속 흐름으로 묶는다.

이 구조는 “규칙을 직접 쓰는 대신 데이터에서 확률을 추정한다”는 전환을 직관적으로 설명하는 데 효과적이다. 그러나 첫 단계는 1988–1993년의 논문을 1991년 하나로 합치고, 중간 단계는 Models 1·2의 다중 생성 가능성과 EM의 기대 계수를 단순화한다. 마지막 단계는 문제와 기능의 유사성을 직접 역사 계보처럼 확대한다. 번역문은 이 논리 흐름을 보존하되, 학습할 때는 각 단계의 증거 수준을 따로 확인해야 한다.

## 6. 왜 중요한가

IBM SMT의 가장 큰 공헌은 언어 사이의 대응을 대규모 병렬 자료에서 재현 가능한 방식으로 추정하게 한 것이다. 어휘표와 정렬을 사람이 완성해 주지 않아도 잠재 구조 모형과 EM을 사용해 번역 후보를 점수화할 수 있었다. 이는 번역 시스템 개발을 언어쌍별 규칙 작성만의 문제에서 데이터·확률 모형·탐색·평가의 공동 문제로 이동시켰다.

두 번째 의미는 단순한 모델에서 복잡한 모델로 매개변수를 전달하는 계층적 훈련 전략이다. 계산 가능한 모델 1에서 시작해 정렬·생성도·왜곡 모형을 더하는 과정은 복잡한 잠재 변수 모형을 처음부터 직접 최적화하기 어려울 때 유용한 실용 원칙을 보여 준다.

세 번째 의미는 정렬 자료가 구 기반 SMT 같은 후속 시스템의 핵심 자원이 됐다는 데 있다. 후대 구 기반 모형은 양방향 IBM 정렬을 결합해 구 대응 후보를 추출했고, 언어 모형·왜곡·특징 가중치와 함께 디코딩했다. 이는 IBM Models의 직접적인 공학적 유산이다.

다만 이를 “통계가 언어 이해를 입증했다”거나 “NLP 전체가 곧바로 같은 방식으로 바뀌었다”는 결론으로 확대할 필요는 없다. 확인되는 성과는 특정 영어–프랑스어 Hansard 설정에서 번역 모형과 디코딩을 구성하고 평가한 것이다. 다른 언어쌍·영역·문체·저자원 환경의 결과는 별도 증거가 필요하다.

## 7. 현대 LLM과의 연결

IBM SMT와 현대 신경 언어 모델은 데이터에서 확률적 예측 규칙을 학습한다는 넓은 공통점이 있다. 그러나 무엇을 매개변수화하고 어떤 자료와 목적을 쓰는지는 크게 다르다.

| 기술 | 핵심 계산 | IBM SMT와의 관계 |
| --- | --- | --- |
| 구 기반 SMT | 단어 정렬에서 구 대응을 추출하고 여러 특징과 언어 모형으로 후보를 점수화한다. | **직접적인 공학적 연속성**. IBM 정렬 모형을 실제 훈련 파이프라인에 사용한다. |
| 신경망 seq2seq | 신경망이 문장 조건부 분포 `P(y|x)`를 직접 매개변수화한다. | **별도 구조의 확률 번역**. 확률을 없앤 것이 아니라 IBM식 어휘·정렬·왜곡 표의 분해를 바꾼 것이다. |
| 신경망 어텐션 | 디코딩할 때 입력 위치별 내용 기반 가중치를 동적으로 계산한다. | 정렬과 **기능적 유사성**이 있지만 IBM EM 정렬이 직접 변형됐다는 역사적 인과는 별도 근거가 필요하다. |
| Transformer | self-attention으로 입력·출력 위치 관계를 계산하고 순환 없이 문장 변환을 학습한다. | 병렬 자료와 조건부 예측을 공유하지만 핵심 연산과 훈련 구조가 다르다. |
| 현대 LLM | 대규모 텍스트의 자기지도 목표로 범용 토큰 표현과 생성 분포를 학습한다. | 데이터 기반 확률 학습이라는 넓은 전통을 공유할 뿐, IBM Models 1–5의 직접 확장이나 같은 목적 함수는 아니다. |

원문은 어텐션이 정렬을 “새 형태로 다시 발명했다”고 서술한다. 두 방법 모두 어떤 출력과 어떤 입력이 관련되는지를 표현한다는 비교는 유익하다. 그러나 IBM 정렬은 생성 모형의 이산 잠재 변수이고, 신경망 어텐션은 현재 은닉 상태에서 계산되는 연속 가중치다. 기능적 유비를 직접 계보로 바꾸지 않아야 한다.

현대 LLM과도 같은 구분이 필요하다. LLM은 대규모 자료에서 패턴을 학습하지만, 병렬 문장쌍과 번역 정렬을 필수로 하지 않으며 자기회귀·마스크드 언어 모델링 등 다른 목표를 사용할 수 있다. “데이터에서 학습한다”는 공통 원리는 중요하지만 너무 넓어서 IBM 연구가 LLM의 모든 구조와 능력을 직접 낳았다는 증거가 되지는 않는다.

## 8. 한계와 비판적 관점

### 8.1 연대와 자료의 혼합

- **1991년 최초성**: 1988년 연구 구상, 1990년 예비 번역 시스템, 1991년 문장 정렬, 1993년 Models 1–5를 분리해야 한다.
- **저자 구성**: 1990년 논문은 여덟 저자, 1993년 핵심 수학 논문은 네 저자다. 특정 네 사람을 모든 단계의 유일한 팀으로 만들지 않는다.
- **Hansard의 목적**: 의회 기록을 연구자가 병렬 말뭉치로 추출한 것이지, 처음부터 통계 MT 벤치마크로 만든 자료가 아니다.
- **BLEU의 시기**: BLEU는 2002년 논문이며 1988–1993년 IBM Models 연구의 자체 평가 도구가 아니다.
- **Moses의 위치**: 구 기반 SMT의 대표 정식화는 2003년, Moses 공개 툴킷은 2007년이다. Moses가 IBM Models 바로 다음에 구 기반 번역을 발명한 시스템은 아니다.

### 8.2 기술 설명의 단순화

- Models 1·2에서도 한 영어 단어에 여러 프랑스어 단어가 정렬될 수 있다. 모델 3은 이 가능성을 처음 허용한 것이 아니라 생성도를 명시적으로 매개변수화했다.
- 모델 5의 핵심은 단순한 수치 안정성보다 Models 3·4의 결손 분포와 유효하지 않은 배치 문제를 제거하는 데 있다.
- EM의 E 단계는 최고 정렬 하나를 선택하는 절차가 아니라 가능한 정렬의 사후확률로 기대 통계를 계산한다.
- IBM 번역 모형은 작은 주변 어휘 ‘문맥 창’을 직접 사용하는 모델이 아니다. 어휘·정렬·위치·생성도 요인과 별도 n-그램 언어 모형을 결합하고 문장 후보를 탐색한다.
- NMT도 `P(y|x)`를 학습하는 확률 모델이다. 사라진 것은 번역 확률 자체가 아니라 IBM식 이산 표와 명시적 모형 분해다.

### 8.3 효과와 사회적 해석의 과장

- 통계 시스템이 모든 규칙 기반 시스템보다 강건하고 일관되며 전문가가 거의 필요 없었다는 보편적 결론은 초기 Hansard 실험만으로 입증되지 않는다. 1994년 Candide–SYSTRAN 인간 평가도 유창성은 Candide, 내용 적합성은 SYSTRAN 쪽 선호가 높아 단일한 승리로 정리되지 않았다.
- 규칙 기반·통계 기반·하이브리드 시스템은 오랫동안 공존했다. 2000년대 초에 “모든 경쟁 시스템”과 주요 기업이 같은 시점에 규칙 기반 투자를 버렸다는 서술은 별도 산업 근거가 필요하다.
- 데이터 기반 MT의 성공이 인간 언어 습득이나 상징적 추론의 불필요성을 직접 입증하지 않는다. 이는 기술적 성과에서 확장한 철학적 해석이다.
- 병렬 자료의 품질·도메인·언어쌍이 바뀌면 성과도 달라진다. 저자원 언어에서는 데이터 요구가 규칙 작성 비용과 다른 형태의 병목이 될 수 있다.

### 8.4 1차 문헌으로 확인할 경계

- [Brown et al., “A Statistical Approach to Language Translation” (1988)](https://aclanthology.org/C88-1016/): 통계 번역 연구 구상과 잡음 채널 번역 계획.
- [Brown et al., “A Statistical Approach to Machine Translation” (1990)](https://aclanthology.org/J90-2002/): Hansard 예비 실험, 언어·번역 모형과 디코딩.
- [Brown·Lai·Mercer, “Aligning Sentences in Parallel Corpora” (1991)](https://aclanthology.org/P91-1022/): 길이에 기반한 영어–프랑스어 문장 정렬.
- [Brown et al., “The Mathematics of Statistical Machine Translation” (1993)](https://aclanthology.org/J93-2003/): Models 1–5, EM, 정렬 탐색, 생성도와 왜곡 모형.
- [Berger et al., “The Candide System for Machine Translation” (1994)](https://aclanthology.org/H94-1028/): 통계 번역 구성 요소의 시스템 통합과 SYSTRAN 비교 평가.
- [Papineni et al., “BLEU” (2002)](https://aclanthology.org/P02-1040/): 수정 n-그램 정밀도와 brevity penalty.
- [Koehn et al., “Statistical Phrase-Based Translation” (2003)](https://aclanthology.org/N03-1017/): 구 기반 SMT의 핵심 정식화와 실험.
- [Koehn et al., “Moses” (2007)](https://aclanthology.org/P07-2045/): 통계적 기계 번역용 공개 툴킷.
- [Sutskever·Vinyals·Le (2014)](https://proceedings.neurips.cc/paper_files/paper/2014/hash/a14ac55a4f27472c5d894ec1c3c743d2-Abstract.html), [Bahdanau·Cho·Bengio (2015)](https://arxiv.org/abs/1409.0473), [Vaswani et al. (2017)](https://proceedings.neurips.cc/paper_files/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html): seq2seq, 내용 기반 어텐션과 Transformer의 서로 다른 신경망 구조.

| --- | --- | --- |
| 통계적 기계 번역(SMT) | 병렬 자료에서 번역 모형을 추정하고 확률로 번역 후보를 선택하는 접근 | 하나의 단일 모델이 아니라 단어·구·구문 기반 등 여러 계열을 포함한다. |
| 잡음 채널 모델 | 관측 문장을 다른 언어 문장이 변형된 결과로 보고 `P(e)P(f|e)`를 최대화하는 분해 | 실제 번역 방향과 생성 모형의 방향을 구분해야 한다. |
| 병렬 말뭉치 | 같은 내용을 두 언어 이상으로 표현한 문서·문장 쌍의 모음 | 문장 대응과 단어 정렬은 별도 추정이 필요할 수 있다. |
| 단어 정렬 | 한 문장의 단어가 번역문 어느 단어 또는 NULL과 대응하는지 나타내는 구조 | IBM Models에서는 관측 정답이 아니라 잠재 변수다. |
| NULL 단어 | 명시적인 반대편 단어 없이 나타나는 단어를 설명하기 위한 가상 위치 | 관사 삽입처럼 직접 대응이 없는 생성을 다룬다. |
| 생성도(fertility) | 한 목표 언어 단어가 생성하는 반대편 언어 단어 수의 분포 | Models 1·2의 암묵적 가능성과 Model 3의 명시적 매개변수를 구분한다. |
| 왜곡(distortion) | 번역 과정에서 대응 단어들의 위치가 재배열되는 확률 모형 | 일반적 의미의 오류가 아니라 어순 배치 항이다. |
| EM 알고리즘 | 잠재 변수의 기대 통계를 계산하고 매개변수를 갱신하는 반복 최적화 | E 단계는 보통 최고 가설 하나를 고르는 절차가 아니다. |
| 결손 분포 | 유효하지 않은 결과에도 확률 질량을 줘 유효 결과의 합이 1보다 작아지는 분포 | Model 5가 Models 3·4에서 제거한 문제다. |
| 디코딩 | 관측 원문에 대해 점수가 가장 높은 번역문 후보를 탐색하는 과정 | 모형 훈련과 별도의 계산 문제다. |
| BLEU | 참조 번역과의 수정 n-그램 정밀도에 길이 패널티를 결합한 말뭉치 수준 지표 | 초기 IBM Models의 지표가 아니며 의미 품질을 완전하게 측정하지 않는다. |

## 12. 짧은 결론

IBM 통계적 기계 번역의 핵심은 번역을 1991년 한 사건으로 발명한 데 있지 않다. 1988년의 연구 구상, 1990년의 예비 시스템, 1991년의 문장 정렬, 1993년의 Models 1–5를 거치며 병렬 자료·잡음 채널·잠재 정렬·EM·디코딩을 하나의 재현 가능한 연구 프로그램으로 만든 데 있다. 이 흐름은 구 기반 SMT에 직접 이어졌고 신경망 번역과는 데이터 기반 조건부 예측이라는 넓은 문제의식을 공유한다. BLEU와 어텐션, Transformer, 현대 LLM을 모두 초기 IBM Models 안에 소급하지 않을 때 이 연구의 실제 공헌과 한계가 더 선명해진다.

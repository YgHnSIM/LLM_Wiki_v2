# Stable Diffusion과 잠재 확산 모델 해설

## 1. 한눈에 보기

- 핵심 주제: 픽셀 공간이 아니라 학습된 저차원 잠재 공간에서 확산 과정을 수행해 이미지 생성의 훈련·추론 비용을 줄이는 잠재 확산 모델(Latent Diffusion Model, LDM)과, 이를 바탕으로 공개된 Stable Diffusion v1
- 등장 배경: 픽셀 기반 확산 모델은 고해상도 이미지의 모든 픽셀에서 U-Net을 여러 번 평가해야 했고, DALL·E 같은 자기회귀 모델은 강한 압축과 큰 Transformer를 요구했다. 2022년 전후에는 품질을 유지하면서 이 계산 병목을 줄이고 조건 입력을 유연하게 연결할 방법이 필요했다.
- 가장 중요한 아이디어: 먼저 오토인코더가 이미지를 지각적으로 충실한 잠재 표현으로 압축하고, U-Net은 그 잠재 표현에 더해진 잡음을 예측한다. 텍스트 토큰 표현은 교차 어텐션을 통해 U-Net에 조건으로 들어간다.
- 이후 LLM/NLP에 남긴 영향: 자연어를 연속 표현으로 바꿔 생성 모델의 여러 층에 조건으로 공급하는 구조를 대규모로 실용화했다. 다만 Stable Diffusion의 CLIP 텍스트 인코더는 자기회귀 LLM이 아니며, 이미지 생성 결과를 언어 추론 능력의 증거로 해석해서는 안 된다.

> 이 문서는 `086_Stable Diffusion Latent Diffusion Models for Accessible Text-to-Image Generation.md`의 번역문을 이해하기 위한 해설입니다. 원문의 홍보적 서술을 반복하기보다 2021년 LDM 논문, 2022년 CVPR 발표, 2022년 8월 Stable Diffusion v1 공개를 분리하고, 계산 효율·공개성·안전성 주장이 실제 근거로 확인되는 범위를 정리합니다.

## 2. 핵심 요약

잠재 확산 모델은 이미지 생성 학습을 두 단계로 나눈다. 첫 단계의 오토인코더는 RGB 이미지를 공간 해상도가 더 작은 잠재 텐서로 인코딩하고, 디코더는 이를 다시 이미지로 복원한다. 둘째 단계의 확산 U-Net은 픽셀이 아니라 이 잠재 텐서에서 잡음 제거 과정을 학습한다. 그 결과 반복되는 U-Net 계산의 공간 크기를 크게 줄이면서, 마지막에는 디코더 한 번으로 픽셀 이미지를 얻을 수 있다. Rombach 등의 LDM 논문은 압축률이 너무 낮으면 계산 이점이 작고 너무 높으면 복원 정보가 손실되므로, 둘 사이의 적절한 지점이 필요하다는 것을 비교 실험으로 보였다. 또한 교차 어텐션을 도입해 텍스트·클래스·레이아웃 같은 서로 다른 조건을 U-Net에 주입하는 일반 인터페이스를 제시했다.

Stable Diffusion v1은 이 일반적인 LDM 연구와 동일한 이름의 단일 논문 모델이 아니라, 그 설계를 바탕으로 2022년 별도로 훈련·배포한 텍스트-이미지 체크포인트 계열이다. v1은 다운샘플링 계수 8의 오토인코더, 약 860M 파라미터 U-Net, 동결된 CLIP ViT-L/14 텍스트 인코더를 사용하며 LAION 계열 자료의 여러 부분집합에서 단계적으로 훈련됐다. 텍스트 조건은 CLIP의 비풀링 토큰 출력이 교차 어텐션으로 들어가는 방식이고, 샘플 품질과 조건 일치는 조건부·무조건부 잡음 예측의 차이를 확대하는 classifier-free guidance로 조절한다. 이는 생성 중인 이미지를 CLIP 이미지 인코더로 매 단계 채점해 기울기를 역전파하는 ‘CLIP guidance’와 다르다.

공개 코드와 가중치 덕분에 기존 폐쇄형 서비스보다 로컬 실험과 개조의 문턱이 크게 낮아진 것은 분명하다. 그러나 공식 저장소는 초기 구성을 최소 10GB VRAM의 GPU 대상으로 설명했고, Stability AI의 공개 발표는 릴리스 빌드의 메모리 사용량을 약 6.9GB로 제시했다. 따라서 “6GB면 누구나 실행한다”는 식의 일반화는 정밀도·샘플러·해상도·구현 최적화와 버전에 따라 달라지는 조건을 지운다. 더구나 v1 모델 카드가 밝힌 훈련은 256대 규모의 A100 구성과 대규모 계산을 사용했으므로, 저렴해진 것은 특히 사전학습 가중치의 추론·재사용이지 기초 모델의 전체 훈련이 아니다.

- 무엇을 다루는가: 잠재 공간 확산의 두 단계 구조와 Stable Diffusion v1의 텍스트 조건부 이미지 생성·공개 배포
- 어떤 문제를 해결하려 했는가: 고차원 픽셀 공간에서 반복되는 확산 계산과 그에 따른 훈련·추론 비용
- 어떤 방식이 새로웠는가: 지각 압축과 의미 생성의 분리, 2차원 잠재 공간의 U-Net 확산, 여러 조건을 받는 교차 어텐션 인터페이스
- 결과적으로 무엇을 바꾸었는가: 고성능 텍스트-이미지 모델의 코드와 가중치를 개인 개발자가 내려받아 실행·연구·변형할 수 있는 범위를 크게 넓혔다. 다만 장기 산업 영향과 모든 응용 효과는 LDM 논문의 통제 실험 결과가 아니다.

## 3. 역사적 배경

고해상도 이미지 생성에는 서로 다른 절충이 있었다. GAN은 한 번의 전방 계산으로 빠르게 샘플링하지만 훈련이 불안정하고 복잡한 데이터 분포의 모드를 놓칠 수 있었다. 픽셀 단위 자기회귀 모델은 가능도 학습이 명확하지만 이미지 토큰을 순차적으로 생성하므로 느렸고, 계산을 감당하려면 DALL·E와 VQGAN 계열처럼 이미지를 강하게 압축한 이산 토큰으로 바꾸어야 했다. 픽셀 확산 모델은 안정적인 훈련과 높은 표본 품질을 보여 주었지만, 수십에서 수백 회의 U-Net 평가를 원래 이미지 해상도에서 반복했다.

Rombach 등의 문제 설정은 “확산 모델이 의미 없는 고주파 픽셀까지 계속 계산해야 하는가?”였다. 연구진은 이미지 학습을 지각 압축(perceptual compression)과 의미 압축(semantic compression)으로 구분했다. 오토인코더가 사람이 거의 알아차리지 못하는 세부를 먼저 줄이고, 확산 모델은 남은 잠재 공간에서 장면의 구성과 의미 변이를 배운다는 구상이다. 2021년 12월 arXiv에 공개되고 2022년 CVPR에 실린 LDM 논문은 단일 Stable Diffusion 제품의 출시 논문이 아니라, 비조건부 생성·텍스트-이미지·레이아웃-이미지·초해상도·인페인팅을 아우르는 모델 계열과 계산 절충을 평가한 연구다.

Stable Diffusion v1은 그 다음 층에 놓인다. CompVis 연구진의 LDM 코드와 오토인코더를 토대로 Stability AI의 계산 지원, LAION 자료, Runway의 협업을 받아 512×512 텍스트-이미지 체크포인트를 훈련했다. 공식 CompVis 저장소는 이를 LDM 연구를 바탕으로 한 특정 구성이라고 명시하며, Stability AI는 2022년 8월 22일 코드·가중치·모델 카드를 함께 공개했다. 그러므로 “LMU와 Stability AI가 CVPR 논문에서 Stable Diffusion v1을 발표했다”거나 “LDM 논문의 모든 결과가 공개 v1 체크포인트의 성능”이라고 합치는 서술은 부정확하다.

- 이전 접근법: GAN의 직접 생성, 이산 잠재 토큰을 순차 생성하는 DALL·E/VQGAN 계열, 고해상도 픽셀 공간 확산
- 당시의 한계: 픽셀 확산의 반복 계산 비용, 자기회귀 모델에 필요한 강한 압축과 순차 샘플링, 조건 입력마다 달라지는 전용 구조
- 이 주제가 필요했던 이유: 이미지의 2차원 구조와 지각적 세부를 충분히 남기면서도 반복 확산 계산의 차원을 줄이고, 텍스트·레이아웃·이미지 같은 조건을 하나의 구조로 연결할 필요가 있었다.

## 4. 핵심 개념 해설

### 4.1 오토인코더와 지각 압축: 512×512 픽셀을 64×64×4 잠재로

Stable Diffusion v1의 첫 단계는 인코더 $E$와 디코더 $D$다. 이미지 $x$를 잠재 표현 $z=E(x)$로 바꾸고, 필요할 때 $\hat{x}=D(z)$로 복원한다. v1의 다운샘플링 계수는 $f=8$이므로 512×512 이미지는 공간적으로 64×64인 잠재가 되며 채널 수는 4다. 여기서 “64배 압축”은 가로와 세로가 각각 8분의 1이 되어 공간 위치 수가 $8^2=64$분의 1이라는 뜻이다. RGB 채널 3개와 잠재 채널 4개까지 포함한 스칼라 개수의 비는 64가 아니라 48이고, 실제 U-Net 계산량 감소도 층 폭·어텐션·메모리 이동 때문에 이 숫자와 정확히 같지 않다.

LDM의 오토인코더는 흔히 간단히 VAE라고 불리지만, 원 논문은 KL-regularized와 VQ-regularized 변형을 모두 조사했고 지각 손실과 패치 판별기의 적대적 목적도 사용했다. Stable Diffusion v1은 KL 정규화 오토인코더를 쓰는 계열이다. 이 단계는 “무손실 압축”이 아니다. 디코더는 원래 해상도의 이미지를 출력하지만, 작은 글자·정확한 선·미세한 질감처럼 압축에서 사라진 정보를 되살릴 수 없다. 원 논문도 고정밀 픽셀 작업에서 오토인코더 복원이 병목이 될 수 있다고 명시했고, v1 모델 카드 역시 오토인코더가 손실형이라고 경고한다.

압축률에는 최적점이 있다. $f$가 너무 작으면 잠재 격자가 여전히 커서 픽셀 확산에 가까운 비용을 치르고, 너무 크면 첫 단계가 의미 있는 세부까지 제거해 생성 품질의 상한을 낮춘다. LDM 논문의 같은 계산 예산 비교에서는 대체로 $f=4$와 $f=8$이 품질과 처리량 사이에서 좋은 절충을 보였다. “잠재 공간이면 품질 손실 없이 항상 64배 빠르다”가 아니라, 데이터와 과제에 맞는 완만한 지각 압축을 선택하는 것이 연구의 핵심이다.

### 4.2 잠재 공간의 잡음 예측과 classifier-free guidance

오토인코더를 학습한 뒤에는 그 가중치를 고정하고 잠재 표현에 확산 과정을 적용한다. 훈련 시 깨끗한 잠재 $z_0$에 시점 $t$에 맞는 가우스 잡음 $\epsilon$을 섞어 $z_t$를 만든다. 시간 조건부 U-Net $\epsilon_\theta$는 현재 잡음 잠재, 시점, 조건 $c$를 받아 실제로 더한 잡음을 예측한다.

\[
z_t=\sqrt{\bar{\alpha}_t}z_0+\sqrt{1-\bar{\alpha}_t}\epsilon,
\qquad
\mathcal{L}=\mathbb{E}\left[\lVert \epsilon-\epsilon_\theta(z_t,t,c)\rVert_2^2\right]
\]

생성할 때는 무작위 잠재 잡음에서 출발해 스케줄러가 예측 잡음을 여러 차례 제거한 뒤, 최종 잠재를 디코더로 한 번 복원한다. 잠재 공간으로 옮겨도 확산의 순차성은 남는다. 따라서 GAN처럼 한 번에 생성하는 모델보다 원칙적으로 느릴 수 있고, 속도는 DDIM·PLMS 같은 샘플러와 스텝 수에 크게 좌우된다.

Stable Diffusion v1의 대표적인 제어 방식은 classifier-free guidance(CFG)다. 같은 잠재에서 텍스트 조건을 준 잡음 예측 $\epsilon_\mathrm{cond}$와 빈 조건의 예측 $\epsilon_\mathrm{uncond}$를 구하고, 두 예측의 차이를 척도 $s$만큼 확대한다.

\[
\epsilon_\mathrm{cfg}=\epsilon_\mathrm{uncond}
+s\left(\epsilon_\mathrm{cond}-\epsilon_\mathrm{uncond}\right)
\]

이를 가능하게 하려고 v1-3와 v1-4 훈련에서는 텍스트 조건을 10% 확률로 버렸다. guidance scale을 높이면 프롬프트 조건이 강해지는 경향이 있지만, 지나치면 다양성이 줄고 색·형태가 과장되거나 품질이 깨질 수 있다. CFG는 별도의 이미지 분류기나 CLIP 이미지 점수의 기울기를 사용하는 방식이 아니다.

### 4.3 텍스트 조건, CLIP, 교차 어텐션을 구분하기

Stable Diffusion v1은 동결된 CLIP ViT-L/14의 텍스트 인코더로 프롬프트를 토큰별 연속 표현으로 바꾼다. 풀링된 하나의 문장 벡터만 쓰는 것이 아니라 비풀링 토큰 출력을 U-Net 중간 특징에 교차 어텐션으로 제공한다. U-Net의 공간 위치 특징이 질의가 되고 텍스트 토큰 표현이 키와 값이 되어, 잡음 예측의 여러 층이 프롬프트의 서로 다른 단어를 참조할 수 있다.

이 구조는 세 가지를 구분해야 이해하기 쉽다.

| 구분 | Stable Diffusion v1에서의 역할 | 혼동하면 안 되는 것 |
|---|---|---|
| CLIP 텍스트 조건 | 동결된 CLIP 텍스트 인코더가 프롬프트 토큰 표현을 생성 | CLIP이 완성 이미지를 직접 생성하는 것 |
| 교차 어텐션 | U-Net 특징이 텍스트 토큰을 읽어 조건부 잡음을 예측 | 단어별 위치와 물체 관계를 완벽히 보장하는 제약식 |
| classifier-free guidance | 조건부·무조건부 U-Net 예측 차이를 확대 | CLIP 이미지 인코더 점수의 기울기로 매 스텝 이미지를 수정하는 CLIP guidance |

LDM 원 논문의 텍스트-이미지 실험과 Stable Diffusion v1도 분리해야 한다. 원 논문의 1.45B 텍스트 조건 LDM은 LAION-400M에서 학습됐고 BERT 토크나이저와 별도 Transformer 조건 인코더를 사용했다. 반면 공개 v1 체크포인트는 LAION-2B(en) 계열의 여러 부분집합에서 단계적으로 학습했고 CLIP ViT-L/14 텍스트 인코더를 사용했다. LDM 논문의 아키텍처 원리는 직접적인 기반이지만, 논문 속 모든 하이퍼파라미터와 평가 수치를 v1에 그대로 옮길 수는 없다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. 문제 제기: 2022년 초의 고성능 텍스트-이미지 시스템은 막대한 계산과 폐쇄형 접근 때문에 개인이 실행·수정하기 어려웠다.
2. 핵심 아이디어: 이미지를 잠재 공간으로 압축하고 그 작은 격자에서 확산을 수행하면 고해상도 픽셀 확산의 비용을 줄일 수 있다.
3. 방법 또는 구조: 오토인코더, 잠재 U-Net, 텍스트 인코더와 교차 어텐션, 대규모 이미지-텍스트 데이터 훈련을 결합한다.
4. 결과 또는 주장: 공개 코드·가중치와 비교적 낮은 추론 메모리 요구가 개인 창작자·개발자의 로컬 사용과 커뮤니티 개조를 넓혔다.
5. 의의와 한계: 창작·연구·제품 생태계에 큰 변화를 주었다고 평가하면서도 프롬프트 이해, 일관성, 편향, 안전, 저작권, 하드웨어 요구를 한계로 든다.

이 흐름에는 서로 다른 근거 층이 섞여 있다. LDM 논문은 압축률별 품질·처리량, 여러 생성 과제, 교차 어텐션 조건화에 관한 통제 실험을 제공한다. Stable Diffusion v1 모델 카드와 저장소는 공개 체크포인트의 구조·훈련 자료·하드웨어·면허·한계를 기록한다. Stability AI의 출시 글은 공개 날짜, 배포 구성, 당시 권장 VRAM과 안전 분류기를 설명하지만 회사의 홍보 문서이기도 하다. 예술·게임·마케팅·교육·의료·건축 전반의 “혁명”이나 후속 AI 공개 정책에 미친 인과 효과는 이 세 자료만으로 입증되지 않는다.

원문에서 특히 교정해야 할 지점은 다음과 같다.

- 512×512에서 64×64로 줄어드는 것은 공간 위치 수 기준 64배이며, 전체 값이나 연산량이 정확히 64배라는 뜻은 아니다.
- 디코더는 원래 해상도를 출력하지만 손실 압축에서 사라진 정보를 보장하지 않는다.
- 공개 v1의 텍스트 조건은 CLIP 표현을 쓰지만, 외부 CLIP 이미지 점수로 역전파하는 guidance와는 다르다.
- “소비자 GPU 실행”은 v1 릴리스와 구현 조건에 관한 주장이다. LDM 원리 자체가 모든 모델을 6GB에서 실행 가능하게 한다는 뜻이 아니다.
- 코드와 가중치는 공개됐지만 사용 제한이 있는 CreativeML OpenRAIL-M 면허였다. 제한 없는 퍼블릭 도메인이나 OSI 의미의 오픈소스와 동일시하지 않는 편이 정확하다.
- LDM은 훈련 비용을 픽셀 확산보다 줄였지만, Stable Diffusion v1 전체 훈련은 여전히 대규모 A100 클러스터를 사용했다.

## 6. 왜 중요한가

LDM의 가장 중요한 공헌은 확산 모델이 계산을 어디에 써야 하는지를 다시 나눈 데 있다. 오토인코더는 고주파 지각 세부를 한 번 압축하고, 확산 U-Net은 장면의 의미 구성과 변이를 더 작은 2차원 격자에서 반복 학습한다. 이 분리는 하나의 오토인코더를 여러 생성 과제에 재사용할 수 있게 했고, 픽셀 기반 확산과 강한 이산 압축 기반 자기회귀 모델 사이에 새로운 실용적 절충을 만들었다.

교차 어텐션도 중요하다. 텍스트 전용 구조를 별도의 이미지 생성기 앞에 단순 연결하는 데 그치지 않고, U-Net의 여러 해상도에서 조건 토큰을 읽게 했다. 같은 원리를 텍스트뿐 아니라 클래스·바운딩 박스·레이아웃 등에 적용할 수 있어, LDM은 특정 텍스트-이미지 제품보다 넓은 조건부 생성 프레임워크가 됐다.

Stable Diffusion v1의 역사적 중요성은 아키텍처만으로 설명되지 않는다. 코드, 모델 카드, 체크포인트를 함께 내려받아 로컬에서 실행하고 수정할 수 있도록 공개한 배포 선택이 기술적 효율과 결합했다. 폐쇄형 웹 서비스에서만 보던 기능을 연구자와 개발자가 내부 구성까지 살펴볼 수 있게 했고, 미세조정·인터페이스·샘플러 연구의 실험 기반을 넓혔다. 그러나 이 사실을 “AI가 완전히 민주화됐다”는 규범적 결론으로 바로 바꾸면, 고가의 전체 훈련 자원, GPU 보유 격차, 면허 제한, 데이터 권리와 안전 비용이 사라진다.

특히 중요한 점:

- 지각 압축과 의미 생성을 분리해 확산 모델의 반복 계산을 더 정보 밀도가 높은 공간으로 옮겼다.
- 교차 어텐션을 일반 조건 인터페이스로 삼아 텍스트·레이아웃·이미지 조건 과제를 하나의 LDM 계열에서 다룰 수 있게 했다.
- Stable Diffusion v1은 공개 가중치와 상대적으로 작은 추론 메모리 요구를 결합해, 사전학습 모델의 재사용과 독립적인 실험 범위를 크게 넓혔다.
- 모델 카드에 훈련 절차·한계·편향·환경 추정치를 함께 기록해, 품질 데모만으로는 드러나지 않는 배포 조건을 검토할 근거를 제공했다.

## 7. 현대 LLM과의 연결

Stable Diffusion은 언어를 생성하는 LLM은 아니지만, 현대 멀티모달 시스템과 공유하는 설계 질문을 선명하게 보여 준다. “사전학습된 언어 표현을 다른 생성 모듈의 어느 층에 어떤 대역폭으로 연결할 것인가?”, “조건과 무조건 예측의 차이를 어떻게 제어 신호로 사용할 것인가?”, “거대한 기반 모델을 처음부터 다시 학습하지 않고 어떻게 재사용할 것인가?”가 그 질문이다.

- Transformer 표현: CLIP의 텍스트 인코더는 Transformer로 프롬프트 토큰을 문맥화한다. 그러나 다음 토큰을 생성하는 GPT형 언어 모델이 아니며, 긴 설명을 추론한 뒤 이미지 계획으로 변환한다고 단정할 수 없다.
- 교차 어텐션: 텍스트 토큰이 U-Net의 공간 특징에 조건으로 들어가는 방식은 멀티모달 LLM에서 시각 토큰이 언어 모델에 들어가는 방향과 반대에 가깝다. 양쪽 모두 서로 다른 표현의 질의·키·값을 연결하지만, 출력 모달리티와 학습 목적은 다르다.
- 동결 백본과 모듈 재사용: Stable Diffusion v1은 사전학습 CLIP 텍스트 인코더를 동결해 사용한다. 이는 이미 학습된 표현을 새 생성 과제의 조건 모듈로 재사용하는 사례이며, 오늘날 어댑터·LoRA·멀티모달 커넥터를 이해할 때 유용한 선행 구조다.
- 조건 강도와 정렬: classifier-free guidance는 프롬프트 조건을 따르는 방향과 표본 다양성 사이의 절충을 추론 시점에 조절한다. 이것은 LLM의 instruction tuning이나 RLHF와 목적이 일부 비슷해 보일 수 있지만, 사람 선호 보상으로 모델 가중치를 정렬하는 절차와는 수학적으로 다른 샘플링 기법이다.
- 잠재 생성: 원시 입력 공간보다 압축된 연속 공간에서 어려운 생성 문제를 푸는 발상은 이미지·영상·오디오 생성에 널리 재사용됐다. 개별 후속 모델이 Stable Diffusion을 직접 계승했는지는 해당 논문의 구조와 인용으로 별도 확인해야 한다.

연결 흐름을 따라 읽으려면 [[055_The Transformer Attention Is All You Need.ko|Transformer의 어텐션]], [[070_CLIP Contrastive Language-Image Pre-training for Multimodal Understanding.ko|CLIP의 시각-언어 표현 정렬]], [[075_DALL·E Text-to-Image Generation with Transformer Architectures.ko|DALL·E의 이산 이미지 토큰]], [[085_DALL·E 2 Diffusion-Based Text-to-Image Generation with CLIP Guidance.ko|DALL·E 2의 CLIP 이미지 잠재와 확산 디코더]]를 비교하면 좋다. 특히 Stable Diffusion의 CLIP 텍스트 조건과 DALL·E 2의 CLIP 이미지 임베딩 prior는 같은 구조가 아니다.

## 8. 한계와 비판적 관점

- 기술적 한계: 잠재 확산도 여러 단계의 U-Net 평가를 요구해 GAN보다 느릴 수 있다. 오토인코더는 손실형이므로 픽셀 수준 정밀도가 필요한 작업에서 상한이 되고, v1 모델 카드는 읽을 수 있는 글자, 복잡한 속성-객체 결합, 얼굴·사람, 완전한 사진 사실성에 실패할 수 있다고 명시한다.
- 조건 이해의 한계: 교차 어텐션은 단어와 공간 특징의 상호작용을 제공하지만 정확한 개수·좌우 관계·물체별 속성 결합을 강제하지 않는다. 자연스러운 결과가 프롬프트의 모든 제약을 충족한다는 보장은 없다.
- 계산과 접근성의 한계: v1 추론은 당시 폐쇄형 대형 시스템보다 훨씬 가까워졌지만 여전히 적절한 GPU와 설치 지식이 필요했다. 공식 문서의 6.9GB와 10GB 수치도 서로 다른 릴리스·구성의 기준이다. 전체 훈련은 모델 카드 기준 대규모 A100 자원을 사용했으므로 “개인도 같은 모델을 처음부터 훈련할 수 있었다”는 뜻이 아니다.
- 데이터 한계: v1은 주로 영어 설명이 붙은 LAION 부분집합에서 학습됐다. 모델 카드는 비영어 프롬프트 성능 저하, 서구·백인 문화의 기본값화, 성인 자료 포함, 별도 중복 제거 부재와 중복 이미지 기억을 직접 경고한다.
- 안전과 사실성: 모델은 사람이나 사건의 사실적 재현을 위해 훈련되지 않았고 그러한 사용은 모델 카드상 범위 밖이다. 출시 파이프라인의 NSFW safety checker는 생성 뒤 CLIP 공간의 고정 개념과 비교하는 보조 필터이며, 학습 데이터 문제를 제거하거나 공개 가중치의 개조를 막지 못한다.
- 공개성의 한계: CreativeML OpenRAIL-M은 상업·비상업 이용을 폭넓게 허용하면서 특정 오용을 금지하는 사용 제한 면허다. 따라서 “코드와 가중치가 공개됐다”는 검증 가능한 사실과 “아무 제한 없는 오픈소스”라는 표현은 구분해야 한다.
- 사회적 한계: LDM 논문 자체가 조작 이미지, 허위정보·스팸, 비동의 딥페이크의 성별 피해, 민감한 훈련 자료 노출, 데이터 편향을 위험으로 든다. 계산 비용을 줄이는 성과는 유익한 연구와 창작뿐 아니라 오용의 비용도 함께 낮춘다.
- 근거 범위의 한계: 원문이 열거한 게임·마케팅·교육·의료·건축·상업 성과와 “후속 AI 공개 방식의 변화”는 개연성 있는 관찰이나 역사적 평가일 수 있지만, LDM 논문과 v1 모델 카드의 실험으로 인과적으로 입증된 결과는 아니다. 응용별 품질·노동 효과·권리 침해·시장 영향을 판단하려면 별도의 연구가 필요하다.

오늘날 관점에서 가장 중요한 비판은 “효율”과 “민주화”를 같은 말로 쓰지 않는 것이다. 잠재 공간은 동일 계열의 픽셀 확산보다 계산 효율을 높였고, 공개 체크포인트는 모델 접근을 넓혔다. 그러나 누가 GPU·데이터·법률 검토·안전 인프라를 감당할 수 있는지, 훈련 자료의 당사자가 어떤 권리를 가지는지, 생성물이 기존 창작 생태계에 어떤 영향을 주는지는 아키텍처 효율만으로 해결되지 않는다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 잠재 확산 모델(LDM) | 학습된 오토인코더의 저차원 잠재 공간에서 잡음 추가·제거 과정을 학습하는 확산 모델 계열 |
| 지각 압축 | 사람이 중요하게 느끼는 구조는 보존하면서 고주파 세부와 중복 정보를 줄이는 첫 단계 표현 학습 |
| 의미 압축 | 잠재 공간의 데이터 분포와 장면 구성·개념 변이를 생성 모델이 학습하는 둘째 단계 |
| 다운샘플링 계수 $f$ | 입력 이미지의 가로·세로를 잠재 격자에서 각각 얼마나 줄이는지 나타내는 값. Stable Diffusion v1은 $f=8$을 사용한다. |
| KL-regularized autoencoder | 잠재 분포에 약한 KL 정규화를 주면서 지각·적대적 손실로 복원하는 오토인코더. 일반 VAE와 같은 계열이지만 목적 구성은 더 복합적이다. |
| 잠재 U-Net | 잡음이 섞인 잠재, 시점, 조건을 받아 잠재에 더해진 잡음을 예측하는 2차원 합성곱 기반 네트워크 |
| 교차 어텐션 | U-Net의 공간 특징이 텍스트 등 외부 조건 토큰을 키·값으로 조회하는 연결 방식 |
| CLIP 텍스트 조건 | 동결된 CLIP 텍스트 인코더의 토큰 표현으로 생성 과정을 조건화하는 것. CLIP 이미지 점수 기반 guidance와 다르다. |
| classifier-free guidance | 별도 분류기 없이 조건부·무조건부 잡음 예측의 차이를 확대해 조건 준수 강도를 조절하는 샘플링 방식 |
| 체크포인트 | 학습된 모델 파라미터를 저장한 파일. Stable Diffusion v1-1부터 v1-4는 서로 이어서 훈련된 별도 상태다. |
| 공개 가중치(open weights) | 학습된 파라미터를 내려받을 수 있게 공개한 배포 형태. 소스 코드 공개나 제한 없는 오픈소스 면허와 자동으로 같지 않다. |
| CreativeML OpenRAIL-M | Stable Diffusion v1 가중치에 적용된 사용 제한 포함 면허. 폭넓은 이용을 허용하지만 금지 용도를 둔다. |

## 12. 짧은 결론

잠재 확산 모델은 고해상도 이미지의 모든 픽셀에서 반복 계산하던 확산 과정을 지각적으로 압축된 2차원 공간으로 옮겨, 품질과 비용 사이의 새로운 실용적 지점을 만들었다. 오토인코더가 지각 압축을 맡고 잠재 U-Net이 의미 생성을 맡으며, 교차 어텐션이 텍스트 같은 다양한 조건을 연결한다는 분업이 핵심이다. Stable Diffusion v1은 이 연구 원리를 CLIP 텍스트 조건부 512×512 모델로 구체화하고 코드와 가중치를 공개해 로컬 재사용과 개조의 문턱을 크게 낮췄다. 그러나 손실 압축, 순차 샘플링, 조합적 프롬프트 실패, 영어·서구 중심 편향, 중복 기억, 안전과 권리 문제, 대규모 전체 훈련 비용은 남았다. 따라서 Stable Diffusion의 역사적 위치는 “품질 저하 없이 누구에게나 무료인 완전한 민주화”가 아니라, 계산 효율과 공개 배포가 결합할 때 생성 모델의 접근 범위와 위험 범위가 동시에 얼마나 커질 수 있는지를 보여 준 이정표로 이해하는 편이 정확하다. 기술 구조와 실험은 [Rombach et al.의 CVPR 2022 LDM 논문](https://arxiv.org/abs/2112.10752), 공개 v1의 구성·훈련·한계는 [CompVis Stable Diffusion v1-4 모델 카드](https://huggingface.co/CompVis/stable-diffusion-v1-4), 배포 범위와 면허·메모리 기준은 [공식 저장소](https://github.com/CompVis/stable-diffusion)와 [2022년 공개 발표](https://stability.ai/news-updates/stable-diffusion-public-release)에서 확인할 수 있다.

# 비터비 알고리즘과 시퀀스 디코딩 해설

## 1. 한눈에 보기

- 핵심 주제: 관측 시퀀스가 주어졌을 때 점수가 가장 높은 은닉 상태 경로를 동적 계획법으로 찾는 방법
- 등장 배경: 잡음이 있는 통신 채널에서 길쌈 부호를 완전 탐색 없이 복호화해야 했던 1960년대의 계산 문제
- 가장 중요한 아이디어: 각 시간·상태에 도달하는 최선의 경로 하나만 남겨 지수적인 후보 공간을 재사용 가능한 하위 문제로 축약하는 것
- 이후 LLM/NLP에 남긴 영향: HMM·CRF의 시퀀스 디코딩, 격자 탐색, 가지치기, $k$-best 탐색과 빔 탐색을 이해하는 핵심 비교 기준을 제공함

> 이 문서는 `008_Viterbi Algorithm - Dynamic Programming Foundation for Sequence Decoding in Speech Recognition and NLP.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 개념적 배경, 역사적 의미, 현대적 연결점과 주의할 한계를 정리합니다.

## 2. 핵심 요약

비터비 알고리즘은 길이 $T$의 관측열과 상태 전이·방출 점수가 주어졌을 때 최고 점수의 상태열을 찾는 동적 계획법이다. 모든 $N^T$개 상태열을 평가하는 대신, 각 시간 $t$와 상태 $j$에 대해 그 지점에 도달하는 최고 점수와 직전 상태만 저장한다. 마르코프 구조처럼 전체 경로 점수가 인접 단계의 국소 점수로 분해될 때, 같은 상태에 더 낮은 점수로 도착한 경로는 이후 어떤 동일한 접미 경로를 붙여도 최고 경로가 될 수 없다. 이 지배 관계 때문에 후보를 안전하게 버리면서도 모델 아래의 전역 최적해를 보장할 수 있다. 알고리즘은 통신 부호 복호화에서 출발했지만 HMM 기반 음성 인식, 품사 태깅, 개체명 인식으로 확장되었다. 이후 CRF도 선형 체인 구조에서 유사한 디코딩을 사용했고, 현대 생성 모델의 빔 탐색은 최적성 보장 없이 여러 부분 가설을 유지한다는 점에서 비교할 만한 후손이다. 핵심은 "매 순간 가장 좋아 보이는 상태"를 고르는 것이 아니라, 미래의 선택을 고려할 수 있도록 상태별 최선 경로를 보존한다는 데 있다.

- 무엇을 다루는가: 확률적 또는 점수 기반 순차 모델의 최대 점수 경로 복원
- 어떤 문제를 해결하려 했는가: 시퀀스 길이에 따라 지수적으로 늘어나는 완전 탐색
- 어떤 방식이 새로웠는가: 겹치는 하위 문제와 최적 부분 구조를 이용한 상태별 경로 압축
- 결과적으로 무엇을 바꾸었는가: 대규모 음성·언어 시퀀스를 실용적인 시간 안에 디코딩할 수 있게 함

## 3. 역사적 배경

비터비 알고리즘은 본래 자연어 처리용으로 만들어진 것이 아니다. Andrew Viterbi의 1967년 연구는 잡음이 섞인 통신에서 길쌈 부호를 복호화하는 문제를 다뤘다. 길쌈 부호는 이전 입력의 영향을 내부 상태에 남기므로 수신 신호를 복호화하는 일은 시간에 따라 이어지는 상태 경로를 찾는 문제로 표현할 수 있다. 상태 전이를 격자(trellis)로 그리면, 완전 탐색은 격자의 모든 경로를 따로 비교하는 일이 된다. 비터비 알고리즘은 같은 상태로 합류하는 경로 가운데 최선만 남겨 격자 폭을 통제했다.

1970~1980년대에는 HMM이 음성 인식의 대표적인 확률 모델로 자리 잡았다. 음향 특징을 관측값, 음소나 그보다 작은 음향 단위를 은닉 상태로 두면 음성 인식도 같은 최적 경로 문제로 바뀐다. 이 구조 덕분에 통신에서 개발된 복호화 알고리즘이 음성 인식과 이후의 NLP 작업으로 옮겨갈 수 있었다.

- 이전 접근법: 가능한 경로를 모두 열거하거나, 각 시점에서 가장 높은 점수의 상태를 즉시 고르는 탐욕적 선택
- 당시의 한계: 완전 탐색은 지수적으로 커지고 탐욕적 선택은 전체 문맥에서 더 좋은 경로를 놓침
- 이 주제가 필요했던 이유: 모델의 전역 최적 경로를 보장하면서도 긴 시퀀스를 감당할 계산 방법이 필요했음

## 4. 핵심 개념 해설

### 4.1 최적 부분 구조와 상태별 생존 경로

동적 계획법이 성립하려면 큰 문제의 최적해가 작은 문제의 최적해를 포함해야 한다. 시간 $t$의 상태 $j$에 두 경로가 도달했다고 하자. 이후의 점수가 현재 상태 $j$와 미래 전이에만 의존한다면, 지금까지 점수가 낮은 경로가 나중에 높은 경로를 역전할 수 없다. 두 경로에 붙을 수 있는 미래가 같기 때문이다. 따라서 상태 $j$마다 최고 점수 경로 하나만 "생존 경로(survivor path)"로 남길 수 있다.

이 점은 매 시점의 최고 상태 하나만 고르는 탐욕법과 다르다. 비터비 알고리즘은 전체에서 상태 하나만 남기는 것이 아니라 **각 상태에 이르는 최선의 경로를 하나씩** 남긴다. 그래서 지금 당장 점수가 조금 낮아도 이후에 더 좋은 전체 경로로 이어질 수 있는 상태를 보존한다.

### 4.2 재귀식, 로그 확률, 역추적

HMM에서 전이 확률을 $a_{ij}$, 상태 $j$의 관측 $o_t$ 방출 확률을 $b_j(o_t)$라고 하면 핵심 재귀식은 다음과 같다.

$$
v_t(j)=\max_i\left[v_{t-1}(i)a_{ij}b_j(o_t)\right]
$$

실제 구현에서는 작은 확률을 계속 곱할 때 생기는 언더플로를 피하려고 로그 확률을 사용한다. 곱셈은 덧셈으로 바뀌지만 $\log$가 단조 증가 함수이므로 최댓값을 만드는 경로는 달라지지 않는다. 각 $v_t(j)$를 만들었던 이전 상태 $i$를 역추적 포인터에 기록해 두었다가 마지막 최고 상태에서 거꾸로 따라가면 전체 상태열을 복원할 수 있다.

조밀한 전이 행렬을 가정하면 시간 복잡도는 $O(TN^2)$, 역추적 포인터까지 저장하는 전형적인 구현의 공간 복잡도는 $O(TN)$이다. 전이 그래프가 희소하면 실제 계산량은 가능한 간선 수에 비례하도록 줄일 수 있다.

### 4.3 비터비, 순방향-역방향, 빔 탐색의 차이

세 방법은 모두 시퀀스 후보를 효율적으로 다루지만 질문이 다르다.

| 방법 | 구하는 것 | 최적성·정보 보존 |
|---|---|---|
| 비터비 | 최고 점수 경로 하나 | 모델과 분해 구조가 맞으면 전역 최적 경로 보장 |
| 순방향-역방향 | 상태·전이의 주변 확률 또는 전체 합 | 여러 경로의 확률 질량을 합산 |
| 빔 탐색 | 상위 $k$개 부분 가설을 확장한 후보 | 고정 빔 폭에서는 휴리스틱이며 전역 최적 보장 없음 |

비터비는 각 상태별 최고 경로를 남기지만, 빔 탐색은 상태 동치 관계가 명확하지 않은 자기회귀 생성에서 전체 부분 시퀀스 중 상위 몇 개만 남긴다. 가지치기라는 공통점은 있으나 수학적으로 같은 알고리즘은 아니다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개된다.

1. 길쌈 부호 복호화에서 가능한 비트열이 지수적으로 늘어나는 문제를 제기한다.
2. 마르코프 구조와 최적 부분 구조를 이용해 상태별 최선 경로만 남기는 아이디어를 소개한다.
3. 재귀식, 역추적 포인터, 로그 확률, 시간·공간 복잡도로 구현 원리를 설명한다.
4. 음성 인식, 품사 태깅, 개체명 인식, 기계 번역으로 확장된 응용을 살핀다.
5. 단일 최적 경로, 모델 가정, 큰 상태 공간이라는 한계와 CRF·빔 탐색·Transformer로 이어지는 개념적 유산을 논한다.

## 6. 왜 중요한가

비터비 알고리즘의 중요성은 단순히 오래된 알고리즘 하나가 여러 분야에서 사용되었다는 데 있지 않다. 이 알고리즘은 "시퀀스 전체를 고려하면 계산이 폭발한다"는 문제를, 미래에 영향을 주는 정보를 상태로 압축하면 정확하게 풀 수 있다는 사실을 보여준다. 모델 설계와 알고리즘 설계가 맞물릴 때 계산 불가능해 보이는 추론이 실용적인 연산으로 바뀌는 대표적인 사례다.

특히 중요한 점:

- 통신의 격자 복호화와 언어 처리의 은닉 상태 추론이 같은 최적 경로 문제임을 보여준다.
- 국소적인 최고 선택과 전역 최적 시퀀스 사이의 차이를 명확히 드러낸다.
- HMM과 선형 체인 CRF 같은 구조화 예측 모델을 실제 시스템에서 사용할 수 있게 한 핵심 추론 절차다.

## 7. 현대 LLM과의 연결

현대 LLM은 보통 HMM처럼 작은 고정 상태 집합 위에서 비터비 디코딩을 수행하지 않는다. Transformer의 은닉 표현은 연속적이고 문맥 전체에 따라 달라지며, 자기회귀 생성의 후보 상태는 지금까지 생성한 토큰열 자체다. 따라서 비터비 재귀식을 그대로 적용할 수는 없다. 그럼에도 후보 공간을 그대로 열거하지 않고 부분 결과를 유지·재사용·가지치기한다는 문제 해결 관점은 여전히 유효하다.

- 빔 탐색: 여러 부분 토큰열 가운데 상위 $k$개만 유지한다는 점에서 비터비의 생존 경로와 닮았지만, 서로 다른 토큰열을 동일한 상태로 합칠 수 없으므로 일반적으로 근사 탐색이다.
- 구조화 출력: LLM의 토큰 확률에 유한상태 제약이나 문법 제약을 결합하면, 허용 상태를 따라 최적 또는 상위 경로를 찾는 동적 계획법·그래프 탐색 관점이 다시 중요해진다.
- 하이브리드 모델: 신경망이 국소 점수나 방출 점수를 만들고 CRF·HMM 층이 비터비로 전역 레이블열을 디코딩하는 구조는 신경망 표현 학습과 구조화 추론을 결합한다.
- CTC와 음성 인식: 현대 음성 모델에서도 프레임 수준 점수를 전사 경로로 바꾸는 디코딩이 필요하며, 탐욕 디코딩·빔 탐색·언어 모델 결합을 비교할 때 비터비의 전역 경로 관점이 유용하다.

## 8. 한계와 비판적 관점

비터비 알고리즘은 **주어진 모델의 점수 함수 아래에서** 최적 경로를 찾는다. 모델이 현실을 잘못 표현하거나 매개변수를 잘못 학습했다면, 알고리즘이 정확하게 찾은 최적해도 실제 정답과 다를 수 있다. "최적"은 모델 내부의 최적성과 현실의 정확성을 구분해서 읽어야 한다.

- 기술적 한계: 조밀한 상태 전이에서는 $O(TN^2)$가 크며, 경로 하나만 남기는 표준 형태는 대안 가설의 확률 질량을 보존하지 않는다.
- 이론적 한계: 마르코프성과 조건부 독립성은 주로 HMM의 모델 가정이다. 비터비 알고리즘 자체의 보편적 가정으로 뭉뚱그리기보다, 점수가 국소 항으로 분해되어 동적 계획법이 가능해야 한다고 표현하는 편이 정확하다.
- 실용적 한계: 실제 음성·번역 시스템은 $n$-best 목록, 격자, 빔 가지치기, 외부 언어 모델과 도메인 제약이 필요할 수 있다. 이때 정확한 단일 경로 알고리즘만으로는 충분하지 않다.
- 오늘날 관점에서 다시 봐야 할 점: 원문은 $N=50, T=20$일 때 $O(TN^2)$를 약 20,000회 연산이라고 적지만 단순 곱은 $20\times 50^2=50{,}000$이다. 또한 Transformer가 시퀀스 디코딩을 병렬 처리로 "대체"했다는 설명은 훈련 시 병렬성과 자기회귀 추론의 순차성을 구분해 읽어야 한다.

원문의 "로그 영역에서는 덧셈이 곱셈보다 빠르다"는 설명도 부차적인 주장이다. 로그 확률을 쓰는 가장 중요한 이유는 언더플로 방지와 수치 안정성이며, 실제 하드웨어에서의 연산 속도 비교는 구현에 따라 달라진다. 또한 표준 역추적은 전체 포인터가 필요하므로, 오래된 포인터를 버리면서 정확한 전체 경로를 복원하려면 체크포인팅·재계산·온라인 디코딩 같은 별도 기법이 필요하다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 길쌈 부호(convolutional code) | 현재 입력과 인코더의 이전 상태를 함께 이용해 중복 비트를 만드는 오류 정정 부호 |
| 격자(trellis) | 시간에 따른 상태와 가능한 전이를 층별 그래프로 펼친 표현 |
| 은닉 상태(hidden state) | 직접 관측되지 않지만 관측값을 설명하도록 모델이 추론하는 상태 |
| 전이 확률 | 이전 상태에서 다음 상태로 이동할 확률 또는 점수 |
| 방출 확률(emission probability) | 특정 은닉 상태에서 관측값이 나타날 확률 |
| 역추적 포인터(backpointer) | 각 상태의 최고 점수를 만든 이전 상태를 기록한 포인터 |
| 최적 부분 구조 | 전체 최적해가 적절한 하위 문제의 최적해를 포함하는 성질 |
| 생존 경로(survivor path) | 각 상태에 도달한 후보 중 이후 탐색을 위해 남기는 최고 점수 경로 |
| $k$-best | 최고 경로 하나가 아니라 점수가 높은 $k$개 경로를 구하는 확장 |

## 12. 짧은 결론

비터비 알고리즘은 통신 부호 복호화에서 출발해 확률적 음성 인식과 NLP의 시퀀스 추론을 실용화한 대표적인 동적 계획법이다. 그 역사적 의미는 특정 모델의 유행을 넘어선다. 복잡한 후보 공간을 상태와 국소 점수로 분해하고, 재사용 가능한 하위 문제를 통해 전역 최적 경로를 찾는다는 사고방식은 HMM·CRF·격자 디코딩은 물론 현대 생성 탐색을 비판적으로 이해하는 기준으로 남아 있다.

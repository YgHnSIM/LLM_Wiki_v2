# Whisper: 트랜스포머 아키텍처를 활용한 대규모 다국어 음성 인식
원본 출처: https://mbrenndoerfer.com/writing/whisper-large-scale-multilingual-speech-recognition-with-transformer-architecture

---

OpenAI가 2022년에 선보인 자동 음성 인식의 획기적 성과인 Whisper를 종합적으로 살펴본다. 다양한 오디오 데이터로 대규모 다국어 학습을 수행해 90개가 넘는 언어에서 견고한 전사 성능을 확보한 방법, 트랜스포머 기반 인코더-디코더 아키텍처로 음성 인식을 단순화한 방법, 그리고 Whisper가 다국어 ASR 시스템의 새로운 기준을 세운 과정을 알아본다.

## 2022년: Whisper

2022년에 공개된 OpenAI의 Whisper는 다양하게 구성된 오디오 데이터로 대규모 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 학습을 수행하면 90개가 넘는 언어에서 견고한 전사와 음성-텍스트 번역이 가능하다는 사실을 보여 주며 자동 음성 인식(automatic speech recognition, ASR)의 획기적 진전을 이뤘다. 웹에서 수집한 약 68만 시간 분량의 다국어·다중 과제 지도 데이터로 학습한 이 시스템은 음성 인식 과제에서 최고 수준의 성능을 달성했으며, 서로 다른 억양과 배경 소음, 전문 용어에도 강했다. Whisper의 성공은 음성 인식 학습 데이터에서 규모와 다양성이 지닌 힘을 입증했고, 다국어 ASR 시스템의 새로운 기준을 세웠으며, 이후 여러 음성 처리 기술의 발전에도 영향을 주었다.

Whisper의 의의는 당장의 기술적 성과를 넘어, 견고한 음성 인식 시스템을 어떻게 구축해야 하는가라는 근본적인 질문에까지 닿았다. Whisper 이전의 음성 인식 시스템은 언어와 과제, 음향 조건에 따라 별도의 모델을 요구하는 경우가 일반적이었다. 이런 파편화된 접근으로는 다양한 억양과 배경 소음, 전문 용어를 비롯한 현실 세계 음성의 다양성을 처리하는 포괄적 시스템을 개발하기 어려웠다. Whisper는 제대로 학습한 단일 모델 하나로 이 모든 변이를 다룰 수 있음을 보여 주었고, 음성 인식 시스템의 효율성과 실용성을 크게 끌어올렸다.

Whisper는 여러 모달리티에서 [트랜스포머](/writing/transformer-attention-is-all-you-need) 기반 아키텍처의 한계를 탐구하던 시기에 개발되었다. 자연어 처리와 컴퓨터 비전에서 트랜스포머 모델이 성공하면서, 이 아키텍처를 오디오와 음성 과제에도 적용할 수 있는지에 관심이 모였다. Whisper는 오디오 특징을 처리해 텍스트 전사를 생성하는 [인코더-디코더 아키텍처](/writing/encoder-decoder-architecture-cross-attention-transformers)를 사용해 트랜스포머가 음성 인식에서도 최고 수준의 성능을 낼 수 있음을 입증했다. 이 결과는 음성 과제에 트랜스포머 아키텍처를 사용하는 방식을 뒷받침했으며, 멀티모달 AI 시스템의 새로운 가능성을 열었다.

Whisper의 학습 방법론은 음성 인식용 대규모 학습 데이터를 수집하고 선별하는 방식에서도 중요한 진전을 이뤘다. 이 시스템은 팟캐스트, 인터뷰, 강의 등 여러 종류의 발화 콘텐츠를 포함해 웹에서 수집한 약 68만 시간 분량의 오디오 데이터로 학습되었다. 이처럼 방대하고 다양한 데이터셋 덕분에 모델은 언어와 억양, 음향 조건이 달라져도 잘 일반화되는 견고한 표현을 학습할 수 있었다. 이 접근의 성공은 세심한 데이터 수집과 선별이 단순한 아키텍처를 보완할 수 있으며, 정교한 모델 설계 대신 규모와 다양성을 통해서도 최고 수준의 성능을 달성할 수 있음을 보여 주었다.

Whisper가 오픈 소스로 공개되자 전 세계 연구자와 개발자가 곧바로 활용할 수 있게 되었고, 빠른 도입과 후속 개발이 가능해졌다. 모델 가중치와 학습 코드가 제공되면서 다른 이들이 이 성과를 바탕으로 특정 언어나 과제에 특화된 버전을 개발할 수 있었다. 이러한 개방형 접근은 음성 인식과 관련 분야의 연구·개발을 가속했고, 기술 수준을 진전시키는 데 오픈 소스 공개가 지닌 가치를 입증했다.

## 문제

전통적인 음성 인식 접근법은 언어와 과제, 음향 조건마다 별도의 모델을 학습하는 방식에 의존해 왔다. 이 방식은 각 언어와 과제에 상당한 자원을 요구했기 때문에 현실 세계 음성의 다양성을 처리할 수 있는 포괄적 음성 인식 시스템을 개발하기 어려웠다. [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 음성 인식 시스템을 구축하는 조직은 언어마다, 과제마다, 음향 조건 집합마다 별도의 모델을 학습하고 유지하며 배포하는 데 드는 막대한 비용과 복잡성을 감당해야 했다. 이처럼 파편화된 접근은 견고한 범용 음성 인식 시스템을 구축하는 데 장벽이 되었다.

전통적인 음성 인식 시스템은 서로 다른 억양과 배경 소음, 전문 용어에 대한 견고성도 부족했다. 원어민의 깨끗한 음성으로 학습한 모델은 억양이 강하거나 배경 소음이 섞였거나 전문 용어가 포함된 음성에서는 성능이 크게 떨어질 수 있었다. 이런 변이를 처리하는 시스템을 만들려면 대개 구체적인 사용 사례마다 광범위한 조정과 적응을 거쳐야 했고, 그만큼 복잡성과 비용이 더해졌다. 견고성이 부족한 탓에 오디오 조건이 일정하지 않거나 완벽하지 않은 여러 현실적 상황에는 음성 인식 시스템을 활용하기 어려웠다.

다국어 응용에서는 언어별로 별도의 모델을 학습해야 했기 때문에 문제가 더 커졌다. 이 방식은 언어마다 연산 자원과 전문 지식을 요구하므로 비용이 많이 들고 비효율적이었다. 특히 [저자원 언어](/writing/specialized-llms-low-resource-languages-ai-equity-global-accessibility)는 견고한 모델을 개발하는 데 필요한 학습 데이터나 자원이 충분하지 않을 수 있어 효과적인 음성 인식 시스템을 구축하기가 매우 어려웠다. [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 처리 능력의 부족은 음성 인식 시스템의 전 세계적 활용을 제약했고, 여러 국제적 맥락에서 이 기술을 사용하지 못하게 했다.

전통적인 음성 인식 시스템이 요구하는 데이터도 문제를 낳았다. 효과적인 모델을 구축하려면 대개 언어와 도메인마다 고품질로 세심하게 전사한 오디오 데이터가 대량으로 필요했다. 이런 데이터를 수집하고 정제하며 전사하는 일은 비용과 시간이 많이 들어 학습 데이터셋의 범위와 품질을 제한했다. 수작업 전사에 의존하면서 데이터셋 구축에 병목이 생겼고, 다양한 언어와 억양, 도메인을 처리할 수 있는 시스템의 개발이 가로막혔다.

전통적인 음성 인식 시스템의 아키텍처도 문제를 키웠다. 여러 시스템은 특징 추출, 음향 모델링, 언어 모델링, 디코딩을 각각 담당하는 별도 구성 요소로 이뤄진 복잡한 파이프라인을 사용했다. 이런 복잡한 아키텍처는 최적화하기 어려웠고, 개발과 배포에도 깊은 도메인 전문 지식이 필요했다. 새로운 언어와 과제, 도메인에 시스템을 적응시키는 일도 복잡했으며, 새 응용 분야마다 상당한 엔지니어링 노력이 들었다.

## 해결책

Whisper는 다양한 언어와 억양, 음향 조건의 음성을 포함한 방대하고 다양한 데이터셋으로 단일 모델 아키텍처를 학습해 이러한 한계를 해결했다. 모델은 [트랜스포머](/writing/transformer-attention-is-all-you-need)를 토대로 한 단순한 [인코더-디코더 아키텍처](/writing/encoder-decoder-architecture-cross-attention-transformers)를 사용했으므로 구현과 배포가 비교적 간단했다. 핵심 혁신은 깨끗한 음성뿐 아니라 소음이 섞인 오디오, 서로 다른 억양, 여러 도메인의 전문 용어까지 담은 대규모의 다양한 학습 데이터를 사용한 데 있었다. 이 접근은 복잡한 아키텍처가 아니라 규모와 다양성을 통해 견고성을 확보했다.

### 아키텍처 설계

Whisper 아키텍처는 자연어 처리에서 성공을 거둔 구조와 비슷한, 어텐션 메커니즘을 갖춘 표준 트랜스포머 [인코더-디코더](/writing/sequence-to-sequence-neural-machine-translation)를 사용했다. 인코더는 입력 오디오 특징을 처리해 음향 정보와 언어 정보를 모두 포착한 표현으로 변환했다. 디코더는 어텐션 메커니즘으로 오디오 구간과 텍스트 토큰을 정렬하면서 그에 대응하는 텍스트를 생성했다. 이 단순한 아키텍처는 복잡한 다단계 파이프라인보다 구현하고 최적화하기가 훨씬 쉬우면서도 최고 수준의 성능을 달성했다.

모델은 원하는 출력을 나타내는 과제별 토큰을 사용해 음성 인식, 번역, 언어 식별 등 여러 과제를 수행하도록 학습되었다. 이 다중 과제 학습 방식 덕분에 과제마다 별도의 아키텍처나 학습 절차를 마련하지 않고도 여러 작업을 처리할 수 있었다. Whisper는 동일한 기반 아키텍처와 가중치를 사용해 원래 언어로 음성을 전사하거나 다른 언어로 번역하고, 입력 음성의 언어를 식별할 수도 있었다.

### 학습 데이터 수집

Whisper의 학습 데이터는 웹에서 수집했으며, 팟캐스트, 인터뷰, 강의 등 여러 출처의 발화 콘텐츠를 담았다. 기존 음성 인식 시스템으로 데이터를 자동 전사한 다음, 품질을 확보하기 위해 필터링하고 정제했다. 학습 데이터의 다양성은 모델의 견고성에 결정적이었다. 모델이 매우 폭넓은 음향 조건과 발화 방식, 콘텐츠 유형을 접할 수 있었기 때문이다. 이러한 노출 덕분에 모델은 시나리오마다 특화된 학습 데이터 없이도 새로운 언어와 억양, 도메인에 잘 일반화할 수 있었다.

약 68만 시간에 이르는 학습 데이터의 규모는 여러 언어와 조건에 걸쳐 견고한 표현을 학습하는 데 충분한 사례를 모델에 제공했다. 데이터셋의 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 특성 덕분에 모델은 [저자원 언어](/writing/specialized-llms-low-resource-languages-ai-equity-global-accessibility)를 처리할 때 고자원 언어에서 얻은 지식을 활용할 수 있었고, 학습 데이터가 적은 언어에서도 성능을 높일 수 있었다. 데이터의 다양성은 모델이 폭넓은 억양과 발화 방식, 전문 용어를 접하게 해 현실 세계 음성에 존재하는 변이에도 견고하게 만들었다.

### 과제별 학습

단일 아키텍처로 여러 과제를 수행하는 모델의 능력은 특히 중요한 의미가 있었다. Whisper는 음성을 원래 언어로 전사할 뿐 아니라 다른 언어로 번역할 수도 있어 다국어 응용에 유용했다. 또한 입력 음성의 언어를 식별할 수 있어 언어를 자동으로 감지하고 적절한 처리 파이프라인으로 보낼 수 있었다. 이러한 다중 과제 능력은 과제마다 별도의 모델이 필요한 시스템보다 실용성과 효율성을 높였다.

학습 과정에서 사용한 과제별 토큰은 동일한 아키텍처 안에서 서로 다른 과제를 수행하는 방법을 모델이 배우게 했다. 추론할 때 다른 과제 토큰을 제공하면 모델은 그에 따라 다른 출력을 생성했고, 동일한 모델 가중치를 여러 목적으로 유연하게 사용할 수 있었다. 이 설계 덕분에 Whisper는 과제별로 별도의 모델이나 학습 절차가 필요한 시스템보다 더 효율적이고 실용적이었다.

## 응용과 영향

Whisper의 성공은 여러 분야의 음성 인식 응용에 즉각적인 실용적 영향을 미쳤다. 서로 다른 억양과 배경 소음, 전문 용어에 대한 시스템의 견고성은 전통적 시스템이 어려움을 겪던 상황에도 Whisper를 적용할 수 있게 했다. 동영상 자막 생성, 회의 전사, 접근성 도구 같은 응용은 Whisper의 향상된 정확도와 견고성의 혜택을 받았고, 다양한 맥락과 조건에 놓인 사용자를 더 잘 지원할 수 있게 되었다.

Whisper의 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 능력은 국제적 응용과 교차 언어 연구에서 특히 가치가 컸다. 단일 모델로 90개가 넘는 언어를 처리할 수 있어 조직은 언어마다 별도 모델을 마련하지 않고도 전 세계 대상 응용 프로그램을 구축할 수 있었다. 이 능력은 개발 비용을 줄이고 배포를 단순화했으며, 모어와 관계없이 전 세계 사용자가 고급 음성 인식 기술을 이용할 수 있게 했다.

Whisper의 오픈 소스 공개는 음성 인식과 관련 분야의 연구·개발을 가속했다. 모델 가중치와 학습 코드가 제공되면서 연구자와 개발자는 이 성과를 토대로 특정 언어나 과제에 특화된 버전을 개발할 수 있었다. 이러한 개방형 접근은 빠른 혁신을 가능하게 했고, 이후 여러 시스템이 Whisper의 아키텍처와 학습 방법론을 직접 토대로 개발되었다. 모델을 쉽게 이용할 수 있게 되면서 소규모 조직과 개인 연구자도 최고 수준의 음성 인식 기술을 다룰 수 있었고, 고급 기능에 대한 접근이 넓어졌다.

시스템의 영향은 음성 인식을 넘어 AI와 자연어 처리의 다른 영역까지 이어졌다. Whisper의 성공은 방대하고 다양한 학습 데이터가 단순한 아키텍처를 보완할 수 있으며, 정교한 모델 설계 대신 규모와 다양성을 통해서도 최고 수준의 성능을 달성할 수 있음을 보여 주었다. 이러한 통찰은 데이터의 세심한 수집과 선별이 아키텍처 혁신만큼 중요할 수 있음을 드러내며 다른 멀티모달 AI 시스템의 발전에도 영향을 미쳤다.

Whisper의 아키텍처와 학습 방식은 다른 대규모 음성 인식 프로젝트의 본보기가 되었다. 시스템의 성능 벤치마크는 새 시스템을 위한 표준 [평가 지표](/writing/history-rouge-meteor-evaluation-metrics)가 되었고, 음성 인식 시스템을 평가하고 비교하는 방식의 새로운 기준을 세웠다. 이 연구는 이후 여러 음성 처리 기술의 발전에 영향을 주었으며, 견고한 AI 시스템을 구현하는 데 학습 데이터의 규모와 다양성이 지닌 힘을 입증했다.

단일 모델로 여러 언어와 과제를 처리하는 Whisper의 능력은 다른 멀티모달 AI 시스템의 발전에도 영향을 미쳤다. 하나의 아키텍처로 관련된 여러 과제를 다루는 발상은 현대 AI 시스템의 표준 접근법으로 자리 잡아 더욱 효율적인 학습과 배포를 가능하게 했다. 이 원칙은 여러 모달리티와 과제를 처리할 수 있는 후속 시스템의 개발에 영향을 주었으며, 통합 아키텍처가 특화된 시스템보다 더 실용적이고 효율적일 수 있음을 보여 주었다.

## 한계

Whisper는 상당한 기여를 했지만 실용적 적용에 영향을 미치는 중요한 한계도 있었다. 주요 과제 가운데 하나는 학습과 추론에 필요한 연산량이었다. 아키텍처 자체는 비교적 단순했지만, 68만 시간 분량의 오디오 데이터로 학습하려면 막대한 연산 자원이 필요했다. 모델의 규모와 복잡성 때문에 추론에도 상당한 연산 비용이 들 수 있었으며, 특히 실시간 응용이나 자원이 제한된 환경에서는 부담이 컸다. 이러한 요구 사항은 충분한 연산 자원을 보유하지 못한 조직의 접근을 제한했다.

모델의 성능은 언어와 과제에 따라 크게 달랐다. Whisper는 90개가 넘는 언어를 지원했지만, 학습 데이터가 풍부한 고자원 언어에서 성능이 훨씬 좋았다. [저자원 언어](/writing/specialized-llms-low-resource-languages-ai-equity-global-accessibility)는 같은 수준의 정확도나 견고성을 확보하지 못할 수 있어 일부 국제적 맥락에서는 시스템의 적용이 제한되었다. 마찬가지로 전문 용어나 특화 도메인을 처리하는 능력도 그런 콘텐츠가 학습 데이터에 포함되었는지에 달렸으며, 그 비중은 언어나 도메인마다 고르지 않을 수 있었다.

학습 데이터의 품질은 Whisper의 성능에 결정적이었지만, 데이터 수집과 선별 과정은 완전히 투명하지 않았다. 시스템은 웹에서 수집해 자동 전사한 오디오에 의존했으며, 여기에는 오류나 편향, 저품질 콘텐츠가 포함되었을 수 있다. 품질을 확보하기 위해 사용한 필터링과 정제 과정이 충분히 문서화되지 않아 [데이터 품질](/writing/data-quality-outliers-measurement-error-missing-data)이 성능에 어떤 영향을 미쳤는지, 향후 시스템의 데이터 수집을 어떻게 개선해야 하는지 파악하기 어려웠다. 웹에서 수집한 데이터에 의존하는 방식은 데이터 프라이버시와 저작권, 윤리 문제에 관한 의문도 제기했다.

모델의 아키텍처는 단순하고 효과적이었지만, 모든 사용 사례에 최적이라고 할 수는 없었다. [트랜스포머](/writing/transformer-attention-is-all-you-need) 기반 [인코더-디코더 아키텍처](/writing/encoder-decoder-architecture-cross-attention-transformers)에는 매우 긴 오디오 시퀀스나 실시간 스트리밍 응용을 처리하기 어렵다는 등의 한계가 있었다. 일부 응용에는 구체적인 요구 사항에 더 적합한 다른 아키텍처나 접근법이 필요할 수 있었다. 모든 상황에 하나의 방식을 적용하는 접근은 실용적이지만, 각 응용 시나리오에서 최적의 성능을 내지는 못할 수 있었다.

Whisper의 성공은 학습 데이터 다양성의 중요성을 부각했지만, 그런 다양성을 확보하는 데는 상당한 자원과 인프라가 필요했다. 비슷한 시스템을 구축하려는 조직에는 대량의 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 오디오 데이터와 학습용 연산 자원, 데이터 수집·선별 전문 지식이 필요했다. 이러한 요구 사항은 진입 장벽을 높였고, 음성 인식 분야의 연구 방향과 혁신의 다양성을 제한할 가능성이 있었다.

시스템의 오픈 소스 공개는 가치가 컸지만 모델 해석 가능성과 편향, 공정성에 관한 의문을 완전히 해소하지는 못했다. 모델이 어떻게 판단을 내리는지, 특정 억양이나 언어에 대한 편향이 있는지, 서로 다른 집단을 공정하게 대우하려면 어떻게 해야 하는지는 여전히 열린 문제였다. 이런 우려는 의료, 법률, 교육처럼 민감한 영역에 적용할 때 특히 중요했다.

## 유산과 향후 전망

Whisper는 대규모의 다양한 학습을 통해 견고한 [다국어](/writing/xlm-cross-lingual-language-model-multilingual-nlp) 음성 인식 시스템을 만들 수 있음을 보여 준, 음성 인식과 인공지능 역사에서 중요한 이정표다. 단일 모델을 활용한 다국어 처리, 다양한 음향 조건에서의 견고한 성능, 오픈 소스 제공이라는 혁신은 음성 인식 시스템의 새로운 기준을 세웠다. 이 연구는 이후 여러 음성 처리 기술의 발전에 영향을 미쳤으며, 견고한 AI 시스템을 달성하는 데 학습 데이터의 규모와 다양성이 지닌 힘을 입증했다.

Whisper의 아키텍처와 학습 방식은 다른 대규모 음성 인식 프로젝트의 본보기가 되었다. 후속 시스템은 Whisper의 토대를 바탕으로 아키텍처를 다듬고 학습 절차를 개선하며 언어 범위를 넓혔다. Whisper의 성공은 [트랜스포머](/writing/transformer-attention-is-all-you-need) 기반 아키텍처가 음성 인식에서 최고 수준의 성능을 달성할 수 있음을 보여 주었고, 오디오·음성 과제에서 이 아키텍처를 사용하는 방식을 뒷받침하며 이후 여러 시스템의 설계에 영향을 미쳤다.

Whisper의 성공은 음성 인식 시스템에 다양하고 품질 높은 학습 데이터가 중요하다는 점도 부각했다. 시스템의 성능은 견고한 성능을 달성할 때 정교한 모델 아키텍처보다 학습 데이터의 품질과 다양성이 더 중요하다는 사실을 보여 주었다. 이러한 통찰은 이후 여러 음성 인식 시스템의 발전에 영향을 주었고, 데이터 수집과 선별의 새로운 기준을 세웠다. [데이터 품질](/writing/data-quality-outliers-measurement-error-missing-data)과 다양성에 대한 강조는 음성 인식 개발의 핵심 원칙으로 자리 잡았다.

단일 모델로 여러 언어와 과제를 처리하는 Whisper의 능력은 다른 멀티모달 AI 시스템의 발전에도 영향을 미쳤다. 하나의 아키텍처로 관련된 여러 과제를 다룬다는 발상은 현대 AI 시스템의 표준 접근법으로 자리 잡아 더욱 효율적인 학습과 배포를 가능하게 했다. 이 원칙은 여러 모달리티와 과제를 처리할 수 있는 후속 시스템의 발전에 영향을 주었으며, 통합 아키텍처가 다양한 시나리오에서도 견고한 성능을 달성할 수 있음을 보여 주었다.

Whisper의 성공은 음성 인식 시스템을 위한 견고한 평가 방법론의 중요성도 드러냈다. 다양한 테스트 세트에서 거둔 성능은 여러 언어와 억양, 음향 조건을 포괄하는 종합적 평가의 가치를 보여 주었다. 이 통찰은 다른 음성 인식 시스템을 위한 평가 프레임워크의 발전에 영향을 주었고, 벤치마킹의 새로운 기준을 세웠다. 다양하고 종합적인 평가를 강조하는 방식은 시스템이 현실 세계 조건에서 제대로 작동하도록 보장하는 데 중요해졌다.

시스템의 오픈 소스 공개는 음성 인식과 관련 분야의 연구·개발을 가속했다. 모델 가중치와 학습 코드가 제공되면서 빠른 혁신이 가능해졌고, 음성 인식 연구에 더 폭넓게 참여할 수 있게 되었다. 이러한 개방형 접근은 AI 연구의 진전을 가속하는 본보기가 되었으며, 오픈 소스 공개가 원래 연구의 영향력을 유지하면서도 빠른 도입과 후속 개발을 촉진할 수 있음을 보여 주었다.

앞으로도 Whisper의 원칙은 음성 인식 기술의 발전 방향을 이끌 것이다. 대규모의 다양한 학습 데이터, 단순하지만 효과적인 아키텍처, 다중 과제 능력에 대한 강조는 분야가 발전하는 가운데서도 여전히 유효하다. 후속 연구는 이러한 토대를 바탕으로 효율성을 높이고 언어 범위를 넓히며 한계를 해결해 왔다. 음성 인식 시스템의 지속적인 진화에는 Whisper가 입증한 통찰과 혁신이 계속 반영되고 있으며, 이로써 Whisper는 해당 분야에 오래도록 영향을 미치게 되었다.

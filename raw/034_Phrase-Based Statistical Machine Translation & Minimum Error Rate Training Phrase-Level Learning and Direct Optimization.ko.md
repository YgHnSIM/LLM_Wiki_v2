# 구 기반 통계적 기계 번역과 최소 오류율 훈련: 구 단위 학습과 직접 최적화

## 2003년: 구 기반 통계적 기계 번역과 최소 오류율 훈련

2003년 무렵 통계적 기계 번역은 1990년대 초 단어 단위 IBM 모형을 넘어 성숙해 있었다. IBM의 기초 연구는 번역 패턴을 데이터에서 학습할 수 있음을 보여주었지만, 단어 단위 접근에는 뚜렷한 한계가 있었다. 관용 표현, 여러 단어로 이루어진 번역, 구 단위 대응을 개별 단어 번역만으로는 효과적으로 포착하기 어려웠다. 구 기반 번역은 통계적 틀을 여러 단어의 연속으로 확장해 그 대응을 학습하는 자연스러운 발전으로 등장했다. 이와 동시에 최소 오류율 훈련(Minimum Error Rate Training, MERT)은 최종 번역 품질과 맞지 않는 중간 목적 대신 BLEU 같은 평가 지표를 직접 개선하도록 번역 시스템의 매개변수를 최적화하는 문제를 다루었다.

구 기반 통계적 기계 번역은 번역 단위의 세분성을 근본적으로 바꾸었다. 시스템은 단어별로 번역한 뒤 재배열하는 대신 연속된 단어열에 대한 번역 확률을 추출하고 학습했다. `kick the bucket`을 각 단어로 번역하려 하지 않고 `죽다`라는 뜻의 하나의 단위로 학습할 수 있었다. 이 방식은 단어 기반 시스템이 놓치던 연어, 관용 표현, 흔한 다단어 패턴을 포착했다. 병렬 자료에서 학습하고 확률 모형과 데이터 기반 번역을 사용한다는 통계적 틀의 핵심 원리는 유지하면서 더 자연스러운 추상화 수준에서 작동했다.

Franz Josef Och가 2003년에 소개한 MERT는 통계 번역 시스템의 중요한 최적화 문제를 다루었다. 초기 시스템은 학습 자료의 가능도를 최대화하도록 모형 매개변수를 최적화했지만, 최대 가능도 학습이 BLEU 같은 평가 지표에서 가장 좋은 번역을 반드시 만들지는 않았다. 시스템이 높은 가능도를 얻고도 BLEU는 낮을 수 있었다. MERT는 개발 자료에서 BLEU를 최대화하도록 특징 가중치를 직접 조정해 학습 목적과 평가 지표를 맞추었다. 이러한 원리에 따른 매개변수 튜닝은 표준 관행이 되었고, 더 나은 최적화를 통해 번역 성능을 높였다.

구 기반 번역과 MERT는 함께 2000년대 통계적 기계 번역의 지배적 패러다임을 이루었다. 이 원리를 구현한 Moses 같은 시스템은 표준 공개 툴킷이 되었다. 구 기반 틀은 다양한 언어쌍과 영역에서 견고함을 보였고, MERT는 여러 특징으로 이루어진 복합 시스템의 가중치를 조정하는 방법을 제공했다. 이 발전은 통계 번역 패러다임을 적절히 확장하고 최적화하면 실용적인 번역 품질을 얻을 수 있음을 보여주었다. 신경 기계 번역이 등장한 뒤에도 그 기반은 영향을 남겼으며, 일부 신경 시스템은 구 기반 구성 요소를 포함했고 attention은 구 추출·정렬과 유사한 기능을 수행했다.

## 단어 기반 번역의 한계

1990년대 초 IBM 통계 번역 모형은 병렬 자료에서 번역 패턴을 학습할 수 있음을 보여주어 기계 번역에 큰 변화를 일으켰다. IBM 모형은 단어 단위 번역 확률을 학습하고 정렬 모형과 결합해 번역문을 생성했다. 이 방식은 규칙 기반 시스템과 비교해 전례 없는 성공을 거두었지만, 더 높은 품질을 추구하면서 근본적인 제약이 드러났다.

가장 큰 한계는 단어 단위 세분성이었다. 자연어에는 단어별로 번역되지 않는 다단어 단위가 많다. `kick the bucket`은 `죽다`를 뜻하지만 각 단어를 따로 옮기면 무의미해질 수 있다. 관용 표현이 아니어도 다단어 번역 단위가 필요하다. 프랑스어 `je ne sais pas`와 영어 `I don't know`의 대응은 낱말별 대응보다 구 단위에서 더 잘 나타난다. 단어 기반 시스템은 이런 패턴을 놓치거나 어색한 직역을 만들기 쉬웠다.

연어와 고정 표현도 문제였다. `hot dog`, `machine learning`, `United Nations` 같은 다단어 조합은 개별 단어 번역에서 바로 도출하기 어려운 특정 번역을 갖는다. 단어 기반 시스템은 `hot`과 `dog`를 따로 번역해 `hot dog`라는 하나의 어휘 단위를 놓칠 수 있다. 독일어 같은 언어의 합성명사도 구 단위 처리가 필요하다. `Maschinenlernen`을 영어로 옮길 때는 그 구성 요소를 흩뜨리기보다 `machine learning`이라는 단위로 다뤄야 한다.

어순 문제는 어려움을 더했다. IBM 모형에는 언어 사이의 어순 차이를 다루는 왜곡·재배열 모형이 있었지만 단어 단위 재배열은 부자연스러울 수 있었다. 영어 `the red car`는 프랑스어 `la voiture rouge`가 된다. 단어 기반 시스템은 `the→la`, `red→rouge`, `car→voiture`를 번역한 뒤 다시 순서를 바꾸려 한다. 구 기반 시스템은 `the red car→la voiture rouge`를 한 쌍으로 학습해 번역과 어순을 하나의 단위에 담을 수 있었다.

단어 단위에서도 데이터 희소성은 심각했다. 큰 병렬 말뭉치가 있어도 많은 단어열은 드물거나 전혀 나타나지 않는다. `purple elephant`가 학습 자료에 없으면 시스템은 `purple`과 `elephant`의 지식을 따로 사용해 번역하며, 언어별 연어나 관습을 놓칠 수 있다. 구 기반 시스템은 비슷한 구와 패턴을 이용해 어떤 단어 조합이 일관된 번역 단위를 이루는지 학습할 수 있었다.

재배열도 단어 단위에서는 더 복잡했다. 언어마다 어순이 크게 다르므로 단어 수준 모형은 많은 구체적 패턴을 포착해야 했다. 구 기반 시스템은 구 단위 재배열을 학습해 더 단순하고 언어학적으로 자연스러운 패턴을 포착할 수 있었다. 예컨대 영어의 형용사–명사 구가 프랑스어에서는 흔히 명사–형용사로 바뀌는 경향을 직접 학습할 수 있었다.

## 구 기반 번역: 자연스러운 발전

구 기반 통계적 기계 번역은 여러 단어로 이루어진 구를 번역 단위로 삼아 단어 단위의 한계를 다뤘다. 많은 번역 대응이 개별 단어가 아니라 구 단위에서 자연스럽게 나타난다는 것이 핵심 통찰이었다. 병렬 자료에서 구 쌍을 추출하고 학습하면 단어 기반 시스템이 놓친 관용 표현, 연어, 다단어 패턴을 포착할 수 있었다. 통계 패러다임의 원리는 유지하면서 번역 단위를 더 적절한 세분성으로 옮겼다.

구 추출은 단어 정렬에서 시작했다. 병렬 문장과 그 안의 어느 원문 단어가 어느 번역문 단어에 대응하는지를 나타내는 단어 정렬이 주어지면, 시스템은 정렬과 일관적인 모든 연속 구 쌍을 추출했다. 원문 구 안의 단어가 번역 구 밖의 단어에 정렬되지 않고 그 반대도 성립하면 구 쌍이 일관적이라고 보았다. 이 제약은 임의의 단어열이 아니라 응집된 번역 단위를 얻기 위한 것이었다. 한 정렬 문장쌍에서도 겹치는 여러 구 쌍을 추출해 가능한 번역의 풍부한 목록을 만들 수 있었다.

구 추출은 가능한 조합을 폭넓게 열거했다. 각 문장쌍에서 정렬 일관성 제약을 만족하는 모든 구 쌍을 찾아 단어 하나부터 긴 구까지 포함했다. 이렇게 만든 구 표는 각 구 쌍의 번역 확률을 저장하며 IBM 모형의 단어 번역표를 대신하는 구 기반 시스템의 핵심 구성 요소가 되었다.

구 쌍의 번역 확률은 단어 기반 접근처럼 상대 빈도로 추정했다. 특정 원문 구와 번역 구가 함께 나타난 횟수를 그 원문 구가 나타난 총횟수로 나눴다. 더 정교한 방법은 희귀 구를 위한 평활화를 포함할 수 있지만, 단순 상대 빈도도 효과적이었다.

번역할 때 시스템은 원문 문장을 구들로 나누는 최선의 방법을 찾고 각 구를 번역했다. 가능한 분절을 고려해 구 표에서 번역을 고른 다음 번역된 구들을 재배열해 유창한 목표 문장을 만들었다. 이 탐색은 계산량이 많아 동적 계획법이나 빔 탐색으로 높은 점수의 번역을 효율적으로 찾았다. 후보 점수에는 구 번역 확률, 언어 모형 점수, 재배열 비용과 다른 특징을 로그선형으로 결합했다.

구 기반 재배열은 단어보다 구 수준에서 작동했다. 시스템은 번역 과정에서 구가 이동하는 경향을 나타내는 확률을 학습했다. 영어의 형용사–명사 구가 프랑스어의 명사–형용사 순서가 되는 것처럼, 특정 위치의 구가 어떤 방식으로 재배열되는지를 모델링했다.

### 정렬에서 구 추출하기

통계적 기계 번역의 구 추출은 단어 정렬에서 일관적인 구 쌍을 찾는 과정이다. 병렬 문장과 단어 정렬이 주어졌을 때 원문 구의 모든 단어가 번역 구 안에만 정렬되고, 번역 구의 모든 단어도 원문 구 안에만 정렬되면 그 구 쌍을 일관적이라고 본다. 이 제약은 구 쌍이 응집된 번역 단위를 나타내도록 한다. 예컨대 영어–프랑스어 정렬 문장에서 `the red car`와 `la voiture rouge`를 하나의 구 쌍으로 추출해 번역과 어순을 함께 포착할 수 있다.

구 기반 시스템은 특징 조합을 통해 단어 기반 정보도 유지했다. 로그선형 모형은 구 번역 확률, 언어 모형 점수, 대체 경로로 쓰이는 단어 번역 확률, 재배열 비용, 더 적고 긴 구를 선호하는 구 패널티 등을 결합했다. 흔한 패턴은 구 번역으로 처리하고 희귀하거나 새로운 조합에는 단어 정보를 활용할 수 있었다.

구 기반 틀은 다양한 언어쌍과 영역에서 효과를 보였다. 특히 구조 차이가 큰 언어쌍에서 단어 기반 접근보다 번역 품질을 높였고, 관용 표현·연어·다단어 표현·구 단위 재배열을 자연스럽게 포착했다. 2000년대에는 Moses 같은 툴킷으로 구현되어 통계적 기계 번역의 지배적 접근이 되었고 여러 언어쌍에서 실용적인 번역을 제공했다.

## 최소 오류율 훈련: 평가를 위한 최적화

통계적 기계 번역 시스템은 구 번역 확률, 언어 모형 점수, 재배열 비용, 구 패널티 등 여러 특징을 로그선형 모형으로 결합한다. 각 특징의 가중치는 번역 품질에 큰 영향을 준다. 초기 시스템은 학습 자료의 확률을 최대화하는 최대 가능도 방식으로 이 가중치를 정했다. 그러나 최대 가능도는 BLEU 같은 최종 평가 지표에서 가장 좋은 번역을 보장하지 않아 학습 목적과 평가 기준 사이에 불일치가 생겼다.

Franz Josef Och가 2003년에 제안한 MERT는 개발 자료에서 BLEU를 최대화하도록 특징 가중치를 직접 조정해 이 문제를 다뤘다. 가능도 대신 실제 시스템 평가에 쓰이는 지표를 최적화했다. 학습 목적과 평가 지표의 정렬은 중요했고, MERT로 튜닝한 시스템은 가능도만 최적화한 시스템보다 높은 BLEU와 더 나은 번역 품질을 얻었다.

MERT 알고리즘은 특징 가중치를 반복해 개선했다. 초기 가중치로 개발 문장의 번역 후보를 생성하고 BLEU를 계산한 다음, 다른 가중치는 고정한 채 한 탐색 방향을 따라 지표가 가장 좋아지는 값을 찾았다. 이런 선 탐색과 좌표 방향의 반복을 수렴할 때까지 수행해 BLEU로 측정한 번역 품질을 직접 최적화하는 가중치를 얻었다.

핵심 통찰은 중간 목적이 아니라 실제 번역 과제의 평가 기준에 맞추어 가중치를 튜닝한다는 데 있었다. 최대 가능도는 학습 번역의 확률을 높이지만 새 입력의 좋은 번역을 보장하지 않는다. MERT는 평가자가 측정하는 참조 번역과의 n-gram 중첩, 유창성과 적절성을 겨냥했다. 최적화와 평가를 맞추어 실용 성능을 높일 수 있었다.

MERT에는 후속 연구를 자극한 중요한 한계도 있었다. 최적화하는 동안 번역 생성을 여러 번 수행해야 해 계산 비용이 컸다. 개발 자료의 작은 변화에도 가중치가 크게 달라지는 불안정성이 있었고, 특징이 많아질수록 확장성이 나빠 대략 20~30개를 넘는 특징에서는 비실용적이었다. 이런 한계에도 MERT는 구 기반 시스템의 표준 관행이 되었고 올바른 목적을 최적화하는 일의 중요성을 보여주었다.

후대에는 margin-infused relaxed algorithm(MIRA)과 PRO 같은 대안이 더 많은 특징과 안정성을 다루기 위해 다른 최적화 전략을 사용했다. 이 방법들은 확장성과 견고성을 높이면서 평가 지표에 맞춰 최적화한다는 MERT의 핵심 통찰을 유지했다. 최적화 목적이 평가 기준과 맞아야 한다는 원리는 기계 번역과 더 넓은 언어 AI 연구의 지침이 되었다.

### 학습 목적의 정렬

MERT는 최적화 목적이 평가 지표와 맞아야 한다는 중요한 원리를 보여주었다. 최대 가능도는 번역 품질을 직접 재지 않는 중간 목적을 최적화했지만, MERT는 실제 평가 지표인 BLEU를 최적화해 더 나은 성능을 얻었다. 이 원리는 기계 번역을 넘어 언어 AI에도 적용된다. BLEU, perplexity, 인간 평정, 과제별 지표 가운데 실제로 중요한 기준을 최적화하면 중간 목적만 최적화할 때보다 좋은 시스템을 만들 가능성이 높다. 무엇을 최적화하고 무엇으로 평가하는지를 맞추는 일은 언어 AI 학습의 기초 원리가 되었다.

## 구현과 툴킷

MERT를 결합한 구 기반 통계적 기계 번역은 견고한 공개 툴킷의 지원을 받아 2000년대 지배적 접근이 되었다. Philipp Koehn 등을 중심으로 개발된 Moses는 구 기반 시스템 학습, 구 표 추출, MERT 튜닝과 번역 디코딩 도구를 제공하는 표준 구현이 되었다. 연구자와 실무자가 기존 구현 위에서 실험할 수 있게 해 널리 채택되고 후속 연구가 촉진되었다.

Moses의 작업 흐름은 구 기반 접근을 하나의 파이프라인으로 묶었다. 먼저 IBM 모형을 구현한 GIZA++ 같은 도구로 단어 정렬을 학습했다. 이 정렬에서 일관성 제약을 만족하는 구 쌍을 추출하고 번역 확률을 가진 구 표를 만들었다. 목표 언어 말뭉치로 언어 모형을 따로 학습했다. 디코더는 동적 계획법과 빔 탐색을 사용해 구 번역 확률, 언어 모형 점수, 재배열 비용과 다른 특징의 로그선형 조합에서 높은 점수의 번역을 찾았다.

MERT 튜닝도 Moses 작업 흐름에 통합됐다. 학습된 구 표와 언어 모형이 있으면 개발 자료에서 특징 가중치를 최적화했다. 가중치를 바꿀 때마다 번역 후보를 여러 번 생성해야 해 계산 비용이 들었지만 좋은 성능에 필수적이었다. Moses는 MERT를 기본 튜닝법으로 제공하고 특징 수나 안정성 요구가 다른 시스템을 위한 대안도 지원했다.

Moses와 비슷한 툴킷은 구 기반 번역의 실용 가능성을 보여주었다. 이 도구로 만든 시스템은 여러 언어쌍에서 실용적인 품질을 달성해 상용 번역 서비스와 연구 응용에 사용됐다. 공개 구현 덕분에 연구자는 시스템 전체를 처음부터 만들지 않고 기존 구성 요소 위에서 연구할 수 있었고, 구 기반 번역은 표준 통계 접근으로 자리 잡았다.

## 한계와 도전

성공에도 불구하고 구 기반 번역과 MERT에는 큰 한계가 있었다. 구 기반 시스템은 대체로 국소 결정을 내렸고 강한 전역 일관성 장치 없이 각 구를 번역했다. 개별 구는 맞아도 전체 문장이 어색하거나 일관되지 않을 수 있었다. 한 구의 대명사가 멀리 떨어진 명사를 가리키는 장거리 의존성도 다루기 어려웠다.

구 추출 과정에는 다소 임시방편적인 면이 있었다. 정렬 일관성에 따라 구 쌍을 뽑지만, 그 구가 의미적으로 응집됐거나 언어학적으로 타당하다는 보장은 없었다. 일부 구는 유용했지만 일부는 우연히 일관된 정렬을 이룬 임의의 단어열이었다. 시스템은 의미 있는 구와 정렬 산물을 원리적으로 구분하지 못하고 빈도와 확률 추정으로 유용한 구를 우선했다.

시스템이 복잡해지면서 MERT의 한계도 커졌다. 특징이 대략 20~30개를 넘으면 확장성이 나빴고, 무작위 시드나 개발 자료의 작은 차이에도 매우 다른 가중치를 얻을 수 있었다. 여러 차례 디코딩이 필요해 큰 시스템이나 잦은 재튜닝에는 비용도 컸다.

영역 적응도 어려웠다. 뉴스로 학습한 구 기반 시스템은 소셜 미디어, 과학 문헌, 대화 음성과 같은 다른 영역에서 성능이 낮아지기 쉬웠다. 영역별 구, 어휘와 문체에는 재학습이나 적응 기법이 필요해 텍스트 종류와 장르 사이의 이동성이 제한됐다.

특정 언어 현상도 어려웠다. 단어 형태가 크게 변하는 형태적으로 풍부한 언어에서는 단어 정렬의 신뢰도가 낮아져 구 추출이 힘들었다. 자유 어순 언어에는 더 정교한 재배열 모형이 필요했다. 병렬 자료가 적은 저자원 언어쌍은 구 추출과 확률 추정에 필요한 증거가 부족했다.

## 신경 기계 번역으로의 전환

구 기반 통계적 기계 번역은 2000년대와 2010년대 초까지 분야를 지배했다. Moses와 MERT로 만든 시스템은 여러 언어쌍에서 실용적인 번역을 제공했다. 그러나 2010년대 중반 신경 기계 번역이 더 나은 성능을 보이기 시작했고, 대부분의 응용에서 통계적 접근을 대체했다.

신경 기계 번역은 학습된 표현과 종단 간 학습으로 구 기반 접근의 여러 제약을 다뤘다. 이산 구 쌍을 추출하는 대신 의미 관계와 장거리 의존성을 담을 수 있는 연속 표현을 학습했다. attention은 각 목표 단어를 생성할 때 관련 원문 단어에 집중해 구 정렬과 비슷한 기능을 자동으로 학습했다. 종단 간 학습은 MERT가 최적화와 평가를 맞춘 것처럼 번역 품질을 직접 높이도록 신경 매개변수를 최적화했다.

신경 번역의 많은 개념에는 통계적 유사물이 있었다. attention은 목표 단어마다 관련 원문을 찾는다는 점에서 구 정렬과 비슷한 기능을 했다. 별도 n-gram 언어 모형은 번역 시스템 안에서 학습되는 신경 언어 모형으로 바뀌었다. 원문을 처리하고 목표문을 생성하는 인코더–디코더 구조는 번역과 언어 모델링을 나누던 잡음 채널 틀을 연상시켰다.

그러나 신경 접근은 근본적인 전환이기도 했다. 수동 특징 공학을 학습 표현이 대신했고, 구 표와 언어 모형을 따로 학습하던 방식은 종단 간 최적화로 바뀌었다. 이산 구·단어 어휘 대신 연속 벡터 공간을 사용했다. 이런 변화는 장거리 의존성, 의미 관계, 문맥 의존 번역처럼 구 기반 시스템이 놓치던 패턴을 포착하게 했다.

전환이 완전한 폐기는 아니었다. 일부 신경 시스템은 구 표를 추가 특징으로 사용하거나 구 기반 시스템에서 초기화했다. 정렬, 재배열, 다단어 단위와 최적화에 관한 구 기반 시대의 지식은 신경 구조 설계에 영향을 주었다. 평가 지표를 최적화해야 한다는 MERT의 원리는 신경 학습으로 이어져, 시스템은 가능도만이 아니라 BLEU 같은 지표도 직접 최적화했다.

## 유산과 현대적 의의

구 기반 통계적 기계 번역과 MERT는 여러 유산을 남겼다. 기술적으로 단어가 아니라 구 수준에서 작동하면 다단어 패턴, 관용 표현과 연어를 더 잘 포착할 수 있음을 보여주었다. 번역 단위의 세분성이 중요함을 확립했다. MERT는 학습 목적과 평가 지표를 맞추면 더 나은 시스템을 얻을 수 있다는 원리를 보여주었다.

방법론적으로 구 기반 시스템의 작업 흐름은 계속 영향을 미쳤다. 단어 정렬, 구 추출, 확률 추정, 디코딩으로 이어지는 파이프라인은 번역 시스템 구축의 명확한 틀을 제공했다. MERT는 자동 튜닝이 좋은 성능에 필수적이며 매개변수 최적화가 모형 설계만큼 중요함을 보여주었다.

실용적으로 구 기반 번역은 여러 언어쌍에서 실제 사용 가능한 결과를 만들었다. Moses 같은 공개 툴킷은 보급과 후속 연구를 촉진했다. 여러 상용 번역 시스템은 2010년대까지 구 기반 방법을 사용했고 일부 혼합 시스템에도 구성 요소가 남았다.

구 기반 시대에 축적된 전문성은 후대 연구에도 영향을 주었다. 정렬, 재배열, 구 추출, 특징 결합에 관한 이해는 신경 시스템으로 이어졌다. 장거리 의존성, 영역 적응과 형태 복잡성 같은 당시의 문제도 신경 접근에서 여전히 중요하다. BLEU 같은 자동 지표와 튜닝 절차를 포함한 평가 방법론도 현대 기계 번역 연구에 남아 있다.

가장 근본적으로 구 기반 번역과 MERT는 통계적 틀을 원리 있게 확장하고 적절히 최적화하면 강한 실용 성능을 낼 수 있음을 보여주었다. 구 기반 틀은 단어 기반 IBM 모형을 더 알맞은 세분성으로 확장했고, MERT는 가능도에서 평가 지표로 최적화 목표를 옮겼다. 이런 발전은 신경 번역 같은 패러다임 전환 전에도 한 패러다임 내부의 진화가 큰 개선을 만들 수 있음을 보여주었다.

## 결론: 구 단위 학습과 직접 최적화

구 기반 통계적 기계 번역과 MERT는 통계 번역 패러다임의 중요한 발전이었다. 단어에서 구 단위로 옮겨 여러 단어의 패턴, 관용 표현과 연어를 포착했고, 특징 가중치를 BLEU에 맞춰 조정해 학습 목적과 평가 지표를 연결했다.

이 발전은 IBM의 기초 연구를 이어받으면서 그 한계를 다뤘다. 구 기반 번역은 병렬 자료에서 학습하고 확률 모형을 사용한다는 통계적 틀을 유지하되 더 적절한 세분성에서 작동했다. MERT는 로그선형 특징 결합을 유지하면서 중간 목적이 아니라 실제 평가 지표를 최적화했다.

실용적 영향도 컸다. 구 기반 시스템은 여러 언어쌍에서 실제 사용 가능한 번역을 제공했고 상용 서비스와 연구 응용에 쓰였다. Moses의 공개는 채택과 혁신을 촉진했다. 이 접근은 2000년대와 2010년대 초 기계 번역을 지배하며, 적절히 확장하고 최적화한 통계적 방법이 현실의 번역 요구를 충족할 수 있음을 보여주었다.

신경 기계 번역으로의 전환이 구 기반 기여를 무효화한 것은 아니다. 신경 시스템은 이산 구 쌍 대신 표현을 자동 학습하지만 다단어 패턴, 정렬과 재배열은 여전히 처리해야 한다. attention은 각 목표 단어에 관련된 원문을 찾는다는 점에서 구 정렬과 유사한 기능을 했다. 최적화와 평가를 맞춰야 한다는 MERT의 원리도 신경 학습에 남았다.

구 기반 번역과 MERT 시대가 남긴 교훈은 적절한 세분성과 올바른 최적화가 고성능 언어 AI에 모두 중요하다는 것이다. 단어보다 구라는 추상화 수준은 더 미세한 단위가 놓치는 언어 패턴을 포착했다. 가능도보다 BLEU처럼 실제로 중요한 지표를 겨냥한 최적화는 더 좋은 실용 성능을 만들었다. 이 원리는 작동 방식과 구조가 바뀐 오늘날에도 언어 AI 연구를 이끈다.

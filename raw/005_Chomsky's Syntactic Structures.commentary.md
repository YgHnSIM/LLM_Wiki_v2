# Chomsky's Syntactic Structures 해설

## 1. 한눈에 보기

- 핵심 주제: Noam Chomsky의 *Syntactic Structures*가 언어를 위계적 규칙 체계로 재정의한 방식
- 등장 배경: 1950년대 행동주의 언어관, 유한상태 모델, 초기 계산언어학
- 가장 중요한 아이디어: 변형생성문법, 심층 구조와 표층 구조, 보편문법, 자극의 빈곤, 촘스키 위계
- 이후 LLM/NLP에 남긴 영향: 파싱, 형식언어 이론, 규칙 기반 NLP, 그리고 현대 LLM의 구조 학습 논쟁으로 이어지는 문제 설정

> 이 문서는 `005_Chomsky's Syntactic Structures.md`의 번역문을 이해하기 위한 해설입니다. 원문을 반복하기보다 개념적 배경, 역사적 의미, 현대적 연결점을 정리합니다.

## 2. 핵심 요약

이 원문은 1957년 Noam Chomsky의 *Syntactic Structures*가 언어학, 인지과학, 컴퓨터과학, 자연어 처리에 남긴 영향을 설명한다. 당시 지배적이던 행동주의는 언어를 자극과 반응, 강화로 학습되는 행동으로 보았지만, Chomsky는 인간이 한 번도 들은 적 없는 문장을 만들고 이해한다는 사실에 주목했다. 그는 언어가 단순한 단어 나열이 아니라 위계적 통사 구조와 재귀 규칙을 가진 체계라고 주장했다. 이 관점은 변형생성문법, 심층 구조와 표층 구조, 보편문법, 자극의 빈곤 논증으로 구체화되었다. 계산적 측면에서는 문맥자유문법, 파싱 알고리즘, 촘스키 위계가 초기 NLP와 컴파일러 이론에 강한 영향을 주었다. 현대 LLM은 명시적 문법 규칙 없이도 유창한 문장을 생성하지만, 원문은 이런 성공이 오히려 언어 구조와 학습의 관계를 다시 묻게 만든다고 본다.

- 무엇을 다루는가: *Syntactic Structures*가 언어 구조, 습득, 계산 모델에 던진 질문
- 어떤 문제를 해결하려 했는가: 자연어의 무한한 생산성, 중첩 구조, 언어 습득의 빠른 일반화
- 어떤 방식이 새로웠는가: 언어를 형식 규칙과 위계 구조로 설명하려 한 점
- 결과적으로 무엇을 바꾸었는가: 언어학을 형식화하고, 인지 혁명과 계산언어학의 핵심 문제를 재구성했다

## 3. 역사적 배경

1950년대 언어 연구와 심리학에서는 행동주의의 영향이 컸다. 언어는 관찰 가능한 발화 행동이며, 아이는 반복, 모방, 보상, 교정을 통해 언어를 배운다는 설명이 널리 통용되었다. 동시에 초기 컴퓨터과학과 정보 이론에서는 유한상태 모델과 확률적 시퀀스 모델이 언어를 다루는 유망한 형식으로 보였다.

Chomsky는 이 두 흐름에 모두 문제를 제기했다. 행동주의는 언어 사용의 창의성과 구조성을 충분히 설명하지 못했고, 유한상태 모델은 자연어의 중첩 의존성과 재귀 구조를 안정적으로 포착하기 어려웠다. 그래서 그는 자연어를 설명하려면 단어열의 표면 패턴보다 더 깊은 문법 구조와 더 강한 형식 체계가 필요하다고 보았다.

- 이전 접근법: 행동주의적 학습 설명, 유한상태 모델, 얕은 패턴 처리
- 당시의 한계: 장거리 의존성, 재귀, 새로운 문장 생성, 언어 습득의 빠른 일반화를 설명하기 어려움
- 이 주제가 필요했던 이유: 언어를 과학적으로 설명할 수 있는 형식 이론과 계산 가능한 모델이 필요했기 때문

## 4. 핵심 개념 해설

### 4.1 변형생성문법

변형생성문법(transformational generative grammar)은 유한한 규칙 집합으로 무한히 많은 문법적 문장을 생성할 수 있다고 보는 문법 이론이다. 여기서 "생성"은 임의로 문장을 많이 만든다는 뜻이 아니라, 어떤 문장이 문법적으로 가능한지를 규칙 체계가 산출하거나 판정할 수 있다는 뜻에 가깝다.

이 이론은 문장을 표면의 단어 순서만으로 보지 않는다. 구 구조 규칙은 문장의 기본 위계 구조를 만들고, 변형 규칙은 그 구조를 의문문, 수동문, 삽입절 같은 여러 표면 형태로 바꾼다. 원문에서 중요한 점은 Chomsky가 언어의 창의성을 "많은 문장을 외운 결과"가 아니라 "규칙을 적용해 새로운 문장을 만드는 능력"으로 해석했다는 것이다.

### 4.2 심층 구조와 표층 구조

심층 구조(deep structure)는 문장의 밑바탕에 있는 문법 관계와 의미 관계를 가리키고, 표층 구조(surface structure)는 실제로 말하거나 쓰인 단어들의 선형 순서를 가리킨다. 예를 들어 "John is eager to please"와 "John is easy to please"는 겉보기에는 비슷하지만, John이 행위자인지 대상자인지가 달라진다.

이 구분은 자연어 처리에서 중요한 직관을 제공한다. 단어가 어떤 순서로 등장했는지만으로는 충분하지 않고, 주어, 목적어, 수식 관계, 절의 포함 관계를 분석해야 의미를 안정적으로 해석할 수 있다. 현대 언어학은 초기의 심층 구조 개념을 그대로 유지하지는 않지만, 표면 문자열 너머의 구조를 봐야 한다는 문제의식은 여전히 남아 있다.

### 4.3 보편문법과 자극의 빈곤

자극의 빈곤(poverty of the stimulus)은 아이가 받는 언어 입력이 불완전하고 제한적인데도 복잡한 문법 지식을 빠르게 습득한다는 논증이다. Chomsky는 이 간극을 설명하기 위해 인간이 언어 습득에 필요한 선천적 구조, 즉 보편문법(Universal Grammar)을 갖고 태어난다고 주장했다.

이 주장은 인지과학의 중심 논쟁이 되었다. 한쪽에서는 언어 구조가 인간 마음의 선천적 설계를 드러낸다고 보았고, 다른 쪽에서는 실제 입력, 사회적 상호작용, 통계적 학습 능력이 Chomsky가 생각한 것보다 훨씬 풍부하다고 보았다. 현대 LLM은 대규모 데이터에서 문법적 패턴을 학습하기 때문에 이 논쟁을 다시 열어 놓는다.

## 5. 원문의 논리 구조

원문은 대략 다음 흐름으로 전개됩니다.

1. 행동주의 언어관이 언어의 창의성과 구조성을 설명하지 못한다는 문제를 제기한다.
2. 유한상태 모델이 자연어의 중첩 의존성과 재귀를 다루기 어렵다는 한계를 설명한다.
3. 변형생성문법, 심층 구조, 표층 구조를 대안적 형식 이론으로 제시한다.
4. 자극의 빈곤과 보편문법을 통해 언어 습득 문제를 인지과학의 질문으로 확장한다.
5. 문맥자유문법, 촘스키 위계, 파싱, 초기 NLP, 현대 LLM 논쟁으로 이어지는 의의와 한계를 정리한다.

## 6. 왜 중요한가

*Syntactic Structures*의 중요성은 Chomsky의 특정 이론이 모두 그대로 받아들여졌다는 데 있지 않다. 더 중요한 것은 그가 언어를 구조화된 계산 대상으로 만들었다는 점이다. 언어학은 직관적 서술을 넘어 형식 규칙, 생성력, 문법성, 구조 표현을 다루게 되었고, 이는 컴퓨터가 언어를 분석하는 방식에도 직접 영향을 주었다.

특히 중요한 점:

- 언어를 단어 빈도나 행동 습관이 아니라 위계적 구조를 가진 체계로 보게 했다.
- 문법 이론과 계산 모델을 연결해 파싱, 형식언어 이론, 컴파일러 설계에 영향을 주었다.
- 현대 LLM의 성공을 평가할 때도 "유창한 출력"과 "구조적 이해"를 구분해야 한다는 질문을 남겼다.

## 7. 현대 LLM과의 연결

현대 LLM은 Chomsky식 문법 규칙을 직접 내장하지 않는다. GPT, BERT, T5, Llama 계열 모델은 대규모 말뭉치에서 다음 토큰 예측, 마스크드 언어 모델링, 지시 따르기 같은 학습 목표를 통해 언어 패턴을 습득한다. 그럼에도 이 모델들이 통사 구조, 장거리 의존성, 합성적 의미를 어느 정도 학습하는지는 중요한 연구 주제다.

- Transformer: self-attention은 문장 안의 멀리 떨어진 토큰 사이 관계를 모델링할 수 있어, 전통적 파싱과 다른 방식으로 장거리 의존성을 다룬다. 관련 항목: [[055_The Transformer Attention Is All You Need]]
- BERT와 GPT: 명시적 문법 규칙 없이도 문법성, 구문 관계, 의미 패턴을 내부 표현에 담을 수 있는지에 관한 논쟁을 촉발했다. 관련 항목: [[058_BERT Bidirectional Pretraining Revolutionizes Language Understanding]], [[059_GPT-1 & GPT-2 Autoregressive Pretraining and Transfer Learning]]
- 구조적 평가: LLM이 그럴듯한 문장을 생성하는 것과 조건, 범위, 부정, 지시 관계를 안정적으로 해석하는 것은 다르다. 긴 문서 분석, 법률 문서, 코드 이해에서는 Chomsky식 구조 감각이 여전히 실용적이다.

## 8. 한계와 비판적 관점

Chomsky식 접근은 언어의 구조성과 창의성을 강하게 설명했지만, 실제 언어 사용의 확률성, 사회성, 의미와 화용 맥락을 충분히 다루지 못했다는 비판을 받는다. 자연어는 예외, 관용 표현, 모호성, 장르별 관습, 대화 맥락으로 가득하며, 완전한 수작업 문법을 만드는 일은 매우 어렵다.

- 기술적 한계: 포괄적 문법과 변형 규칙을 사람이 직접 작성하고 유지하기 어렵다.
- 이론적 한계: 심층 구조와 변형 규칙이 실제 인간 인지 과정과 얼마나 일치하는지는 논쟁적이다.
- 실용적 한계: 문법 구조만으로는 의미, 세계 지식, 화용론적 의도를 결정할 수 없다.
- 오늘날 관점에서 다시 봐야 할 점: LLM의 경험적 성공은 강한 규칙 기반 설명에 도전하지만, 구조적 일반화와 신뢰성 문제는 여전히 남아 있다.

## 9. 용어 정리

| 용어 | 설명 |
|---|---|
| 통사론 (syntax) | 단어가 구와 문장으로 결합하는 규칙과 구조를 연구하는 분야. |
| 변형생성문법 (transformational generative grammar) | 구 구조 규칙과 변형 규칙으로 문장의 생성과 구조 관계를 설명하려는 문법 이론. |
| 심층 구조 (deep structure) | 문장의 밑바탕에 있는 위계적 문법 관계와 의미 관계. |
| 표층 구조 (surface structure) | 실제로 관찰되는 단어의 선형 순서와 표면 형태. |
| 보편문법 (Universal Grammar) | 인간이 선천적으로 갖는다고 가정되는 언어 습득의 일반 원리. |
| 자극의 빈곤 (poverty of the stimulus) | 입력이 제한적인데도 아이가 풍부한 문법 지식을 습득한다는 논증. |
| 유한상태 모델 (finite-state model) | 유한한 상태와 입력 전이로 문자열을 처리하는 선형 형식 모델. |
| 문맥자유문법 (context-free grammar) | 구 구조를 재작성 규칙으로 표현하는 형식문법. |
| 촘스키 위계 (Chomsky hierarchy) | 문법을 생성력에 따라 정규문법, 문맥자유문법, 문맥의존문법, 무제한문법으로 분류한 체계. |
| 파싱 (parsing) | 문장의 문법 구조를 분석하는 과정. |

## 12. 짧은 결론

*Syntactic Structures*는 NLP/LLM 역사에서 언어를 계산 가능한 구조로 다루게 만든 핵심 분기점이다. Chomsky의 구체적 이론은 이후 크게 수정되고 비판받았지만, 언어에는 표면 단어열을 넘어서는 위계 구조가 있으며 그 구조를 어떻게 학습하고 표현하고 평가할 것인가라는 질문은 여전히 살아 있다. 현대 LLM은 Chomsky식 규칙 기반 시스템과 다른 방식으로 작동하지만, 그 성공과 한계를 이해하려면 이 원문이 제기한 구조, 재귀, 습득, 이해의 문제를 계속 검토해야 한다.

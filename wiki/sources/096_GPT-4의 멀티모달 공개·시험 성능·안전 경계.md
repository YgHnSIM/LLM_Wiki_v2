# GPT-4의 멀티모달 공개·시험 성능·안전 경계

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[concept.멀티모달-대규모-언어-모델|멀티모달 대규모 언어 모델]], [[concept.big-bench-mmlu|BIG-bench와 MMLU]]<br>
> **읽고 나면:** GPT-4의 2023년 3월 text 공개와 GPT-4V의 제한 접근·9월 rollout을 구분하고, 시험 점수·백분위·실무 능력 및 model architecture·제품 안전 사이의 서로 다른 근거 경계를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### GPT-4의 ‘출시’는 한 날짜가 아니다

공식 096 raw는 2023년 3월 GPT-4가 image와 text를 처리하는 model로 공개되어 곧바로 폭넓은 응용을 바꾼 것처럼 서술한다. 실제 공개 경계는 다음처럼 나뉜다.

| 시점 | 확인된 사건 | 그때 공개되지 않았던 것 |
| --- | --- | --- |
| 2022년 | GPT-4V system card 기준 model 훈련 완료 | 제품 접근, 상세 architecture·data·compute |
| 2023-03-14 | 기술 보고서와 제품 발표, ChatGPT Plus·API waitlist의 **text 입력** 공개 | API image 입력은 limited alpha, 일반 사용자 vision은 미공개 |
| 2023년 3월 이후 | Be My Eyes 등 제한된 early-access pilot | 일반적인 ChatGPT image rollout |
| 2023-09-25 | GPT-4V system card와 Plus·Enterprise 대상 2주간 image rollout 발표 | 모든 사용자·개발자의 동일 접근 |
| 2023-11-06 | 개발자용 `gpt-4-vision-preview` 발표 | 안정된 영구 사양이나 공개 내부 구조 |

따라서 기술 보고서의 multimodal 능력, 제한된 pilot, ChatGPT 배포와 API preview를 하나의 ‘3월 출시’로 합치지 않는다. [[093_멀티모달 LLM과 시각-언어 연결 방식의 분화]]는 이 공개 chronology와 다른 model의 bridge 설계를 더 넓게 비교한다.

### ‘인간 수준’은 범위를 붙여야 하는 평가 문장이다

OpenAI는 GPT-4가 일부 전문·학술 benchmark에서 인간 수준 성능을 보였다고 보고했다. 그러나 같은 보고서는 많은 현실 시나리오에서 여전히 인간보다 덜 유능하다고 명시한다. 시험마다 결과도 크게 달랐다.

| 시험·과제 | 보고된 GPT-4 결과 | 해석 경계 |
| --- | --- | --- |
| simulated UBE | 298/400, OpenAI 환산 약 90백분위 | 비공식 비교 분포에 민감; 합격과 변호사 실무는 다름 |
| LSAT | 163, 약 88백분위 | 시험 응시자와 현업 전문가를 합치지 않음 |
| GRE Verbal | 약 99백분위 | 같은 GRE Writing은 약 54백분위 |
| AP English Literature | 약 8–22백분위 | ‘모든 전문·학술 시험에서 상위권’이 아님 |
| Codeforces | 5백분위 미만 | 한 시점의 coding contest protocol 결과 |
| MMLU | base GPT-4 5-shot 86.4% | 57개 객관식 평균이며 실제 전문 수행 전체가 아님 |

시험에서 정답을 고르거나 답안을 생성하는 행동과 최신 자료를 찾고 설명하며 책임지는 실제 업무는 다른 평가 대상이다. [[095_BIG-bench와 MMLU의 평가 범위·집계 경계]]에서처럼 model·snapshot·prompt·shot·scoring·오염·비교 모집단을 점수와 함께 남겨야 한다.

### 핵심 문장

- GPT-4의 관찰 가능한 multimodal signature는 `image + text → text`다. Image를 입력받는 것과 image를 직접 생성하는 것은 다르다.
- 공개 자료는 Transformer-style next-token pretraining, public·licensed data와 RLHF라는 높은 수준만 밝힌다. Parameter 수, dense/MoE 여부, vision encoder, bridge, hardware, training compute와 dataset construction은 공개하지 않았다.
- UBE 298점이 여러 관할의 합격선을 넘는다는 결론과 그 점수가 90백분위라는 환산, 실제 변호사 역량은 세 가지 다른 주장이다.
- 안전 평가의 상대 개선은 jailbreak·환각·편향·과잉 거절·multimodal 취약성이 사라졌다는 뜻이 아니다.

## 2단계 — 작동 원리

### 공개된 model·post-training·제품 층을 분리한다

공개된 훈련 설명에서 base GPT-4는 document의 다음 token을 예측하도록 public·licensed data에서 사전 학습됐다. 그 뒤 supervised·RLHF 계열 post-training과 안전 보상, red teaming이 사용자가 접하는 행동을 조정했다. ChatGPT·API 제품은 다시 system message, 정책·모니터링, access·rate limit과 version routing을 더한다.

$$
\text{사용자 결과}
=f(\text{base model},\text{post-training},\text{snapshot},\text{system prompt},\text{tools},\text{policy})
$$

따라서 시험의 base GPT-4 결과, RLHF model의 대화 행동, GPT-4V의 image 입력과 특정 ChatGPT 제품을 하나의 고정 model 속성으로 합치지 않는다. 객관식 시험 평균에서 base와 RLHF 성능이 비슷했다는 보고도 RLHF가 사실성·거부·말투에 영향을 주지 않았다는 뜻은 아니다.

### 특정 vision architecture는 공개되지 않았다

096 raw는 vision encoder가 image를 표현으로 바꾸고 language model과 결합한다고 구체적으로 설명한다. 이는 여러 [[멀티모달 대규모 언어 모델]]을 설명하는 일반 도식일 수 있지만 GPT-4의 확인된 내부 구조는 아니다. 기술 보고서는 경쟁 환경과 안전을 이유로 model size·architecture·hardware·compute·dataset construction·training method의 세부를 공개하지 않았다.

그러므로 다음처럼 기록한다.

1. **확인 가능:** image와 text를 섞어 입력하고 자연어·code 등의 text를 출력했다.
2. **고수준 설명:** Transformer-style 다음 token 예측과 RLHF를 사용했다.
3. **비공개:** vision encoder 종류, projection·cross-attention·shared token 방식, parameter와 update 경계.
4. **추론 금지:** 외부 행동이 공개 model과 비슷하다는 이유로 특정 bridge 계보를 채우지 않는다.

### 시험 점수는 protocol을 거쳐 만들어진다

GPT-4 시험 평가는 공개 past exam 또는 2022–2023 practice material을 사용했다. 객관식은 일부 정답·해설 few-shot 예시와 temperature 0.3, free response는 best-guess prompt와 temperature 0.6을 사용했다. Non-holdout에서 방법을 정한 뒤 holdout을 한 번 실행했고, 일부 서술형은 관련 경험이 있는 외부 contractor 1–2명이 채점했다. 객관식과 free-response에 서로 다른 2023년 3월 이전 snapshot이 쓰였고 일부 code mismatch도 사후 확인됐다.

즉 보고할 최소 단위는 다음과 같다.

$$
E=(\text{snapshot},\text{exam version},\text{prompt},\text{shots},
\text{temperature},\text{scoring},\text{grader},\text{contamination})
$$

`GPT-4가 시험에서 X점`만 남기면 $E$의 차이를 model 차이로 오인할 수 있다.

### UBE 백분위에는 별도의 변환 경계가 있다

UBE 결과는 model output에서 곧바로 백분위가 나오지 않는다.

$$
\text{응답}
\rightarrow \text{MBE·MEE·MPT raw score}
\rightarrow \text{scaled UBE score}
\rightarrow \text{선택한 인간 분포}
\rightarrow \text{percentile}
$$

Katz 등은 GPT-4의 약 297점이 주요 관할의 합격 기준을 넘는다고 보고했다. 그러나 미국 NCBE는 공식 UBE percentile을 공개하지 않는다. 후속 재평가에서 Martínez는 OpenAI의 약 90백분위가 낮은 성과의 재응시자가 많은 2월 Illinois 분포와 연결된다고 지적했다. 같은 점수를 7월 전체 응시자와 비교하면 약 68백분위, 7월 첫 응시자와 비교하면 약 62백분위, 합격자 집단과 비교하면 약 45–48백분위로 추정됐다. Essay는 합격자 집단에서 약 15백분위였고 rubric·grader training·blind calibration의 결손도 제기됐다.

이 논쟁은 합격 결과를 지우지 않는다. 대신 `298`, `약 90백분위`, `변호사 실무 수준` 사이에 서로 다른 근거가 필요함을 보여 준다.

## 3단계 — 기술과 근거

### Benchmark 향상과 오염 조건

GPT-4 technical report는 MMLU·HumanEval·GSM8K 등에서 이전 model보다 높은 결과를 보고했다. 그러나 benchmark 이름은 조건을 고정하지 않는다.

- MMLU 86.4%는 base GPT-4의 5-shot 조건이다.
- BIG-bench 일부가 training mixture에 포함된 것을 발견해 결과를 보고하지 않았다. 빈칸을 성공으로 채우지 않는다.
- MMLU 오염 표본 추정 약 0.6%는 contamination-free 점수가 아니다.
- GSM8K training 일부가 pretraining mixture에 들어가 저자들은 순수 few-shot transfer와 benchmark-specific tuning 사이로 해석하도록 권고했다.
- LSAT은 보고서의 오염 분석에서 상당한 overlap 신호가 있었으므로 88백분위와 data boundary를 함께 본다.

공개 test는 재현성을 높이지만 공개 뒤 model의 독립 test로서 수명이 짧아지는 긴장도 만든다. Exact substring audit나 training cutoff만으로 paraphrase·풀이·정답표 노출을 전부 배제할 수 없다.

### 안전 수치는 선택된 내부 평가의 상대 결과다

OpenAI는 50명 이상의 domain expert red teaming과 safety prompt·RLHF·model 기반 rule 보상 등을 보고했다. 특정 내부 비교에서 GPT-4는 GPT-3.5보다 다음처럼 개선됐다.

- 금지 content 요청에 응답하는 경향 82% 감소
- 민감 요청에 policy에 맞게 응답하는 비율 29% 증가
- RealToxicityPrompts toxic generation 0.73% 대 6.48%
- 별도 내부 factuality 평가에서 최신 GPT-3.5보다 19%p 높음

이 수치는 당시 snapshot·prompt set·policy·classifier가 만든 상대 결과다. 보고서 자체도 unsafe input에 취약하고 valid request를 과잉 거절하며 jailbreak가 남는다고 적었다. Post-training 뒤 MMLU calibration이 나빠진 결과도 있어 유해성 완화, 사실 정확도와 confidence calibration을 하나의 ‘안전성’ 열로 합치지 않는다.

### GPT-4V는 새로운 입력과 새로운 실패를 함께 열었다

GPT-4V system card는 가까운 text component의 병합, 문자·수학 기호 누락, 공간 위치·색 mapping 오류와 비로마자 OCR 약화를 기록했다. 화학 구조·유독 식품·의료 image의 불안정한 해석, image 순서 민감성, 근거 없는 사람·장소 추론과 stereotype도 남았다.

당시 version은 어떤 의료 기능이나 전문 조언·진단·치료의 대체에도 적합하지 않다고 명시됐다. Image 속 text를 이용한 multimodal jailbreak, 사람 식별·민감 특성 추론·geolocation·CAPTCHA 같은 위험은 text-only interface의 공격 표면을 넓혔다. Vision access는 접근성 가치를 만들었지만 사람 자원봉사자의 확인과 고위험 사용 경고를 없애지 않았다.

### 예측 가능한 scaling 주장은 범위가 좁다

OpenAI는 같은 방법으로 10,000배 적은 compute를 쓴 run에서 GPT-4의 internal code loss를 예측했고, HumanEval의 제한된 subset에서도 scaling 예측 사례를 보고했다. 이는 training infrastructure의 중요한 결과지만 미래의 모든 reasoning·multimodal·safety 능력을 사전에 맞혔다는 뜻은 아니다. Raw의 ‘architecture 개선이 문제를 단계로 분해하게 했다’는 인과는 공개 자료로 검증할 수 없다.

## 검증과 한계

### raw 설명의 검증 정정

- **GPT-4가 2023년 3월 multimodal 제품으로 일반 공개됐다:** 3월에는 text access와 image research preview·limited alpha가 있었고, 광범위한 ChatGPT image rollout은 9월이었다.
- **Vision encoder와 language model의 구체 결합 구조가 알려졌다:** 입출력은 공개됐지만 encoder·bridge·parameter와 update 구조는 비공개다.
- **UBE 90백분위와 LSAT 88백분위가 인간 전문가 수준을 입증했다:** 시험 응시자 분포와 현업 전문가 집단은 다르며 UBE 90백분위 환산은 공식 전국 통계가 아니다.
- **GPT-3.5는 표준 시험 전반에서 인간 이하였고 GPT-4가 이를 처음 넘었다:** GPT-3.5도 SAT EBRW와 여러 AP 시험에서 높은 percentile을 보였다. 시험별 차이로 좁힌다.
- **더 좋은 data·objective·architecture가 복잡한 문제를 단계화했다:** 세부 data·objective·architecture가 비공개라 성능 향상의 원인을 이렇게 분해할 수 없다.
- **RLHF와 안전 훈련이 시험 능력 향상의 원인이다:** 보고서는 시험 능력이 주로 pretraining에서 왔다고 설명하며, 객관식 평균에서는 base와 RLHF가 비슷했다.
- **GPT-4가 범용으로 안전함을 입증했다:** 특정 내부 평가에서 개선됐지만 hallucination·편향·jailbreak·과잉 거절과 multimodal 위험이 남았다.
- **GPT-4의 architecture와 benchmark가 후속 model의 표준이 됐다:** 내부 기술이 비공개이며 MMLU·HumanEval·GSM8K 등은 GPT-4 이전 benchmark다.
- **시험·multimodal 성능이 AGI 이정표를 입증했다:** AGI는 이 자료가 조작적으로 판정한 평가 변수가 아니다.

### 네 경계를 함께 기록한다

1. **Model 경계:** base·RLHF, snapshot, text·vision variant를 구분한다.
2. **평가 경계:** prompt·shot·temperature·grader·오염·비교 모집단을 남긴다.
3. **제품 경계:** 보고서 공개, alpha·pilot, ChatGPT rollout과 API access를 구분한다.
4. **사용 경계:** 시험 정답, 실제 전문 업무, 고위험 의사결정과 안전한 자율 실행을 따로 검증한다.

### 공개성의 비대칭

GPT-4는 외부에서 반복할 수 있는 interface와 일부 평가를 공개했지만 model 자체의 parameter·data·compute·architecture는 공개하지 않았다. 따라서 기능·시험 protocol·안전 incident를 검증하는 문서와 내부 계산 graph를 설명하는 문서의 증거 수준이 다르다. [[멀티모달 대규모 언어 모델]]의 공개 model 구조를 GPT-4에 빌려 채우지 않는다.

# 메모리 네트워크와 외부 지식 접근

> [!note] 학습 안내
> **난이도:** 심화<br>
> **선수 지식:** [[개방 영역 질의응답]]<br>
> **읽고 나면:** 원형 Memory Network의 I·G·O·R 흐름과 hard supporting-fact 선택을 설명하고, 후속 soft attention·RAG·Transformer와의 차이를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

원문은 2014년 [[메모리 네트워크]]가 신경망에 외부 도서관과 soft attention을 붙여 대규모 지식·다중 홉 추론·동적 갱신을 가능하게 했고 현대 RAG의 직접 청사진이 됐다고 설명한다. 문제의식은 유효하지만 2014년 원형, 2015년 End-To-End Memory Networks와 bAbI, 2020년 RAG를 한 구조처럼 섞는다. 공개 문서는 **일반 메모리 인터페이스**, **실제 구현의 hard selection과 감독**, **후대 soft attention·검색 증강**을 시기별로 분리한다.

### 핵심 문장

- Memory Networks는 외부 객체 배열과 읽기·쓰기·응답을 (I,G,O,R) 인터페이스로 분리했다.
- 2014년 대표 MemNN은 soft attention이 아니라 supporting-fact 라벨로 학습한 hard `argmax` 검색을 사용했다.
- 다중 홉 성과는 통제된 합성 세계와 최대 두 supporting facts의 조건에서 해석해야 한다.
- End-To-End Memory Networks와 bAbI는 2015년의 별도 후속 단계다.
- RAG와는 외부 비매개변수 지식 접근을 공유하지만 단일한 동일 구조나 유일한 직계 계보는 아니다.

## 2단계 — 작동 원리

### 질문에서 답까지

입력을 내부 표현으로 바꿔 메모리에 쓰고, 질문과 관련된 슬롯을 읽어 답에 필요한 정보를 모은 뒤 응답을 만든다. 두 사실이 필요하면 첫 선택 결과를 다음 선택의 조건으로 사용한다.

### 외부 메모리의 일반 틀

Weston·Chopra·Bordes는 메모리 (m)를 문자열이나 벡터 객체의 배열로 두고 네 구성 요소를 정의했다.

- (I), input feature map: 입력을 내부 특징 표현으로 바꾼다.
- (G), generalization: 새 입력에 따라 메모리를 갱신한다.
- (O), output feature map: 입력과 현재 메모리에서 출력 특징을 만든다.
- (R), response: 출력 특징을 텍스트 답이나 행동으로 변환한다.

일반 정의는 시험 시점에도 새 입력을 메모리에 쓸 수 있고 (I,G,O,R)에 다양한 학습기를 넣을 수 있는 넓은 틀이었다. 그러나 제시된 텍스트 MemNN 구현의 (G)는 새 문장을 다음 빈 슬롯에 원문 형태로 저장하고 과거 슬롯은 갱신하지 않았다. “모든 지식을 이해해 정교한 벡터 메모리로 자동 재구성했다”는 설명은 실제 구현 범위를 넘는다.

## 3단계 — 기술과 근거

### 원 구현은 soft attention이 아니라 hard supporting-fact 선택

첫 supporting memory는 다음 점수의 최댓값으로 고른다.

$$
o_1=\arg\max_i s_O(x,m_i)
$$

둘째 홉은 원 질문과 첫 메모리를 함께 사용한다.

$$
o_2=\arg\max_i s_O([x,m_{o_1}],m_i)
$$

점수 함수는 bag-of-words 특징을 저차원 임베딩으로 보내 내적하는 bilinear 형태였다. 여러 슬롯의 softmax 가중 합을 계산하는 후대의 soft attention과 다르다. (R)도 대표 실험에서 자유로운 설명문을 생성하기보다 질문과 최대 두 supporting facts를 보고 전체 어휘 중 한 단어 답을 `argmax` 순위화했다. RNN 응답 생성은 가능한 확장으로 논의됐지만 원 실험의 중심 결과가 아니었다.

### 강한 감독과 margin ranking

원 논문은 훈련 때 정답과 함께 첫째·둘째 supporting sentence의 라벨을 제공받는 **fully supervised setting**을 사용했다. 옳은 supporting fact와 표본 오답 fact 사이에 margin을 두는 ranking loss, 그리고 정답 단어와 오답 단어의 ranking loss를 따로 최적화했다.

따라서 raw의 “어느 슬롯을 봐야 하는지 명시 감독 없이 최종 답 오류를 전체 soft attention에 역전파했다”는 설명은 2014년 원형에 맞지 않는다. 이산 `argmax` 접근의 정답 경로를 supporting-fact 라벨로 가르쳤다. 2015년 Sukhbaatar 등의 End-To-End Memory Networks가 recurrent soft attention으로 이 감독 요구를 크게 줄이고 질문-정답 수준에서 여러 홉을 학습했다.

### 실제 읽기·쓰기와 규모 확장

일반 틀에서 (G)는 과거 메모리를 고치거나 덜 유용한 슬롯을 잊는 방법까지 포함할 수 있었지만, 논문은 forgetting을 실험하지 않았다고 명시했다. 텍스트 구현의 proof-of-concept word sequence segmenter와 write-time 특징, 미지 단어의 좌우 문맥 특징은 제시했으나 범용 데이터베이스 갱신기의 완성품은 아니었다.

모든 메모리를 선형으로 채점하면 큰 지식 베이스에서 느리다. 논문은 단어 해시와 학습된 단어 임베딩의 (K)-means cluster로 후보 버킷을 줄였다. 1,400만 사실 규모 실험에서 cluster hashing이 비슷한 성능을 유지하며 약 80배 속도를 높였다고 보고했지만, 이는 현대 ANN 벡터 데이터베이스와 동일한 구현이 아니다.

large-scale QA에서는 기존 시스템이 반환한 상위 답 후보를 (k=1) MemNN으로 재순위화했고 F1은 약 0.72로 직전 임베딩 접근 0.73과 비슷했다. 외부 메모리가 곧바로 모든 개방 영역 QA를 압도했다는 결과가 아니다.

### 합성 세계에서의 두 홉

작은 시뮬레이션은 인물·물체·방의 이동과 집기·놓기를 문장으로 만들었다. “우유는 지금 어디에 있는가?”에 답하려면 “Joe가 우유를 놓았다”와 “Joe가 사무실로 갔다” 같은 supporting facts를 이어야 했다. 시간 특징을 둔 (k=2) MemNN은 난이도별 actor·object 질문에서 거의 0에 가까운 오류를 보였고, (k=1)이나 RNN보다 두 사실 결합에 유리했다.

이 실험은 통제된 합성 세계와 라벨된 supporting facts의 성과다. 2015년에 제안된 20개 bAbI prerequisite task 전체와 같지 않으며, 자유 문서에서 임의 길이의 논리 추론을 일반적으로 해결한 증거도 아니다. “multi-hop”은 반복적으로 supporting memory를 선택하는 계산 구조이지 인간의 숨은 chain of thought를 관찰한 것이 아니다.

### End-To-End Memory Networks와 bAbI는 후속 단계다

Sukhbaatar 등의 2015년 구조는 가능한 큰 외부 메모리에 recurrent soft attention을 적용하고, 한 출력 기호마다 여러 계산 홉을 수행했다. 원 MemNN보다 훨씬 적은 감독으로 합성 QA에서 경쟁력 있는 결과를 냈고 Penn Treebank·Text8 언어 모델에도 적용했다. soft attention 가중 합과 질문 표현 갱신을 반복하는 오늘날 익숙한 설명은 주로 이 변형에 맞는다.

같은 해 Weston 등의 bAbI 연구는 사실 연결·귀납·추론·시간·공간 등 20개 합성 prerequisite task를 제안했다. 개선한 MemNN도 일부 과제를 해결하지 못했다고 보고했다. 따라서 “Memory Networks가 bAbI에서 모든 다단계 이해를 해결했다”는 raw의 일반화는 채택하지 않는다.

### RAG와의 유사성·차이

Lewis 등의 2020년 RAG는 사전학습 seq2seq 모델을 parametric memory, Wikipedia dense vector index를 non-parametric memory로 두고 사전학습 신경 검색기로 passage를 찾았다. 같은 passage를 전체 생성 시퀀스에 쓰는 RAG-Sequence와 토큰마다 잠재 passage를 다르게 주변화하는 RAG-Token을 비교했다.

외부 저장, 질의 기반 접근, 검색 결과를 답에 사용, 지식 갱신이라는 기능적 공통점은 분명하다. 그러나 원 MemNN은 단답 ranking·hard supporting-fact 선택·강한 감독·소규모 반복 홉을 사용했고, RAG는 대규모 dense retrieval·사전학습 생성·잠재 문서 주변화를 사용한다. 고전 정보 검색과 지식 베이스 QA도 외부 자료 접근을 오래 사용했으므로 Memory Networks를 RAG의 유일한 직접 조상이라고 단정하지 않는다.

## 검증과 한계

### 지식 저장·갱신·해석 가능성의 범위

외부 슬롯은 특정 문장을 개별적으로 저장하고 선택할 수 있어 모든 지식을 매개변수에만 분산시키는 방식과 다르다. 새 입력을 저장할 수 있고 어떤 supporting fact가 선택됐는지 볼 수 있다는 장점도 있다. 다만 다음 조건이 남는다.

- 새 문서가 기존 질문 표현·점수 모델과 맞지 않으면 저장만으로 정확히 검색되지 않는다.
- 문장·문단·사실 가운데 어떤 단위를 슬롯으로 삼을지는 사람이 설계해야 한다.
- 후보 생성이 정답 근거를 놓치면 뒤의 응답기가 복구할 수 없다.
- 선택된 슬롯을 보는 것은 유용한 진단이지만 답 전체의 인과나 충실성을 증명하지 않는다.
- 평평한 슬롯과 두 번의 검색은 명시적 지식 그래프의 관계 제약·논리 규칙과 같지 않다.

### Transformer 어텐션과의 경계

Transformer self-attention과 memory access는 관련도 점수로 표현을 결합하고 미분 가능하게 학습한다는 수학적 가족 resemblance가 있다. 하지만 Transformer는 기본적으로 현재 입력 시퀀스 위치 사이를 매 층 연결하며, 원 MemNN은 세션 밖에 남을 수 있는 외부 슬롯에서 supporting fact를 선택한다. 여러 memory hop과 multi-head attention도 “여러 번/여러 관점으로 본다”는 비유만으로 직접 동일시할 수 없다.

### 검증 정정

- **2014년 이전 신경망에는 외부 저장·검색 발상이 없었다**: 전통 IR·KB QA·associative memory·nearest-neighbor와 differentiable stack 선행 계보가 있었다.
- **원 MemNN이 모든 슬롯의 soft attention 가중 합을 사용**: 실제 텍스트 구현은 최대 두 supporting memory를 hard `argmax`로 선택했다.
- **정답만으로 전체 접근을 end-to-end 역전파**: 원 훈련에는 supporting sentence 라벨이 주어졌다.
- **메모리에 넣은 모든 문서는 곧바로 정확히 검색**: 표현·분할·후보화·훈련 분포가 접근 품질을 제약한다.
- **bAbI 20개 과제가 2014년 원 논문의 대표 벤치마크**: 2015년 별도 연구이며 MemNN도 일부 과제를 풀지 못했다.
- **대규모 QA에서 당시 최고 성능을 크게 경신**: 기존 후보 재순위화에서 F1 0.72로 비교 모델 0.73과 비슷했다.
- **attention weight가 모델 추론을 완전히 설명**: 원형은 이산 supporting fact 선택이며 선택 근거도 최종 답 생성의 충실성을 보장하지 않는다.
- **RAG는 Memory Networks를 규모만 키운 동일 구조**: 공통 설계 원리는 있지만 검색기·생성기·학습 목적·색인과 정보 검색 계보가 다르다.
- **memory hop이 Transformer multi-head attention의 직접 원형**: 반복 외부 검색과 동시 다중 head는 역할과 계산이 다르다.

## 학습 확인

3. 원형 Memory Network를 후속 soft attention 모델·RAG·Transformer와 동일한 구조로 볼 수 없는 이유는 무엇인가?

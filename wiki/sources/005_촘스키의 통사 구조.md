# 촘스키의 통사 구조

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[concept.통사론|통사론]], [[concept.유한상태-모델|유한상태 모델]]<br>
> **읽고 나면:** 1957년 책의 구 구조·변형 분석과 후대 촘스키 이론을 구분하고, 형식문법이 제기한 핵심 문제를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 요약

[[노엄 촘스키]]의 1957년 *Syntactic Structures*는 문법을 관찰된 문장 목록이 아니라 문장을 생성하는 형식 체계로 다루었다. 책의 중심은 유한상태 문법, 구 구조 문법, 변형 분석, 핵문장과 문법 이론의 평가다. 언어를 위계적 [[통사 구조]]로 분석해야 한다는 문제를 선명하게 만들었지만, 촘스키의 후대 언어 이론 전체를 이 한 권에 담긴 내용으로 취급해서는 안 된다.

쉽게 말하면 문장을 하나씩 외워 두는 대신 `명사구 + 동사구` 같은 규칙으로 여러 문장 구조를 만들고, 서로 관련된 문장 형태가 어떻게 연결되는지 설명하려는 접근이다. 이 단순 예시는 책의 전체 형식 분석을 대신하지 않지만, 문법을 유한한 규칙으로 무한히 많은 가능한 문장에 적용한다는 직관을 먼저 잡게 해 준다.

### 주요 인사이트

- *Syntactic Structures*의 핵심은 문법을 문장을 생성하는 형식 체계로 분석한 데 있다.
- 1957년 책, 1959년 행동주의 비판, 1965년 표준이론을 서로 분리해야 한다.
- 보편문법과 자극의 빈곤은 촘스키 계열의 중요한 논쟁이지만 1957년 책의 목차처럼 제시하면 안 된다.
- 형식문법과 파싱의 관계는 영향과 후속 발전이지 직접 구현 관계가 아니다.
- 현대 LLM과의 연결은 특정 문법 이론의 계승이 아니라 구조적 일반화가 필요한지 묻는 공통 문제에서 찾을 수 있다.

### 핵심 문장

- 1957년 책은 구 구조와 변형을 중심으로 문법의 생성적 기술을 제안했다.
- 심층·표층 구조의 성숙한 체계, Skinner 비판, 원리와 매개변수는 서로 다른 시기의 저작에 속한다.
- 촘스키에서 LLM으로 이어지는 관계는 직접 계승보다 언어 구조를 어떻게 설명하고 학습하는가라는 논쟁의 연속성이다.

## 2단계 — 작동 원리

### 문제와 간단한 예시

관찰된 문장 목록만으로는 처음 보는 문장이 왜 자연스럽거나 부자연스러운지, 문장 사이의 구조적 관계가 무엇인지 설명하기 어렵다. 예를 들어 평서문과 그에 대응하는 의문문을 별개 문장으로 저장하기보다, 공통 구조와 형태를 바꾸는 규칙으로 설명할 수 있는지가 핵심 문제다.

### 구 구조에서 변형까지

1957년 책에서는 구 구조 규칙이 핵문장의 바탕이 되는 종결 문자열과 성분 구조를 제공한다. 이 구조는 의무적 변형을 거쳐 핵문장이 되고, 선택적 변형이 더해져 의문문·수동문 같은 비핵 문장이 파생된다. 반면 성숙한 [[심층 구조]]·[[표층 구조]] 구분과 표준이론은 1965년 *Aspects of the Theory of Syntax*에서 더 명시적으로 체계화됐다. 두 시기의 용어와 이론을 구분해야 한다.

초보자용으로 논증 흐름을 압축하면 다음과 같다.

1. 문장의 어휘와 성분을 문법 범주로 구분한다.
2. 구 구조 규칙으로 기본적인 핵문장 구조를 생성한다.
3. 변형 규칙으로 의문문·수동문처럼 서로 관련된 형식을 연결한다.
4. 어떤 문법이 문장 구조를 더 적절하게 기술하는지 평가한다.

이 네 단계는 책의 세부 형식화를 대체하는 새 이론이 아니라, 구 구조와 변형의 역할을 읽기 위한 프로젝트의 학습용 요약이다.

### 결과를 읽는 법

이 관점에서 문법은 이미 본 문장을 모아 둔 목록이 아니라, 가능한 구조를 생성하고 문장 사이의 관계를 기술하는 체계가 된다. 다만 이 결론을 촘스키의 모든 후대 용어와 이론이 1957년에 완성됐다는 뜻으로 확대해서는 안 된다.

## 3단계 — 기술과 근거

### 시기별 구분

| 시기 | 이 프로젝트에서 귀속할 내용 |
| --- | --- |
| 1956 | 형식언어의 세 모델과 생성력 비교 |
| 1957 | 구 구조, 핵문장, 변형, 유한상태 문법의 한계 |
| 1959 | Skinner의 언어 행동 이론에 대한 직접 비판 |
| 1965 | 표준이론과 심층·표층 구조의 체계화 |
| 1980년대 | 원리와 매개변수, 언어별 매개변수 설정 모형 |

### 형식언어 모델의 생성력

[[유한상태 모델]]과 형식문법의 생성력 비교는 1956년 「Three Models for the Description of Language」와 1957년 책에 걸쳐 전개됐다. 이 연구는 [[문맥자유문법]]과 [[촘스키 위계]]가 발전한 역사와 연결되지만, 오늘날의 완성된 위계 전체를 1957년 책 한 권의 직접 산물로 서술하는 것은 부정확하다.

### 형식문법과 후대 파싱

형식문법은 후대의 [[파싱]]과 프로그래밍 언어 연구에 중요한 어휘와 문제 틀을 제공했다. 그러나 CYK나 1970년 Earley 파서를 “1957년 책의 직접 구현”이라고 부르기보다는, 후대 연구자들이 형식언어 틀을 계산 알고리즘으로 발전시켰다고 설명하는 편이 정확하다.

## 검증과 한계

### 확인된 사실

[[B.F. 스키너]]의 *Verbal Behavior*에 대한 직접적이고 상세한 비판은 1959년 서평에 있다. [[행동주의 언어관]] 비판을 1957년 책의 주된 장이나 직접 논쟁으로 서술해서는 안 된다. 마찬가지로 [[자극의 빈곤]], 성숙한 [[보편문법]], 원리와 매개변수, 핵어 방향·무주어 매개변수는 후대의 이론 전개다. 특히 매개변수 설정 모형은 1980년대의 정부결속이론·원리와 매개변수 접근과 연결된다.

### 프로젝트 해석

이 프로젝트는 1957년 책, 1959년 서평, 1965년 표준이론, 1980년대 원리와 매개변수를 서로 다른 근거 단위로 읽고, 후대 용어를 앞선 저작에 소급하지 않는다.

### 후대 평가와 계보의 한계

후대 파싱 알고리즘은 형식언어의 문제 틀을 계산 절차로 발전시킨 사례이지, 1957년 책의 내용을 그대로 옮긴 구현으로 평가하지 않는다.

현대 LLM과의 비교도 1957년 이론이 현대 모델로 직접 구현됐다는 계보가 아니라, 언어 구조를 명시 규칙으로 기술할지 학습된 표현으로 포착할지 묻는 비교 질문으로 제한한다.

## 학습 확인

1. 문법을 문장 목록이 아니라 생성 체계로 본다는 것은 무슨 뜻인가?
2. 1957년 책에서 구 구조 규칙과 변형 규칙은 각각 어떤 역할을 하는가?
3. 심층·표층 구조, Skinner 비판, 후대 파싱을 1957년 책의 직접 내용과 구분해야 하는 이유는 무엇인가?

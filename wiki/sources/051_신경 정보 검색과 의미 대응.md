# 신경 정보 검색과 의미 대응

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[BM25]]<br>
> **읽고 나면:** 표현 중심·상호작용 중심 신경 검색을 구분하고 의미 유사도와 검색 관련성의 차이를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

051 raw는 2016년을 [[신경 정보 검색]]의 단일 전환점으로 두고, 희소 키워드 검색에서 질의·문서 밀집 벡터와 이중 인코더로 이동한 뒤 현대 벡터 데이터베이스·RAG까지 직접 이어졌다고 설명한다. 공개 문서는 **2013년 DSSM**, **2014년 C-DSSM**, **2016년 DRMM**, **2020년대 첫 단계 밀집 검색**을 분리하고, 의미 유사성과 ad-hoc relevance가 같은 목표가 아님을 검증한다.

### 핵심 문장

- 신경 정보 검색은 질의와 문서의 표현·점수 함수를 관련성 자료에서 학습하는 접근군이다.
- 독립 전역 표현은 사전 계산과 대규모 비교에 유리하지만 국소 exact interaction을 잃을 수 있다.
- 검색 관련성은 두 텍스트의 일반 의미 유사성과 같지 않으며 희귀 질의어·정확 일치·긴 문서의 일부 대응이 중요하다.
- 음성 표본과 클릭 편향은 신경 검색이 어떤 관련성 경계를 배우는지 결정한다.
- 현대 RAG는 검색과 생성의 연쇄 시스템이므로 retrieval recall과 answer faithfulness를 분리해 평가해야 한다.

## 2단계 — 작동 원리

### 검색 파이프라인의 흐름

빠른 표현 모델이 전체 컬렉션에서 후보를 찾고, 더 비싼 상호작용 모델이 상위 후보의 세부 대응을 보며 순위를 다시 매길 수 있다. 질의·문서 표현, 점수, 음성 표본은 연결되지만 서로 다른 학습 선택이다.

## 3단계 — 기술과 근거

### 2016년 한 번의 출현이 아닌 누적 과정

신경망 이전의 정보 검색도 의미 간극을 알지 못한 것은 아니다. [[010_벡터 공간 모델과 TF-IDF|벡터 공간 모델]]은 용어 가중과 질의-문서 벡터 비교를, LSI는 저차원 잠재 공간을, 확률 언어 모형과 [[BM25]]는 질의어 증거·문서 길이·용어 빈도를 모델링했다. learning to rank도 사람이 정의한 여러 특징을 감독 자료로 결합했다.

신경 검색의 변화는 “검색에 의미를 처음 도입”한 사건이라기보다 텍스트 표현과 관련성 점수를 심층망으로 학습하는 방법이 확대된 과정이다. 대표 연표는 다음과 같다.

| 시기 | 연구 | 핵심 입력·구조 | 직접 평가 범위 |
| --- | --- | --- | --- |
| 2013 | DSSM | 문자 trigram word hashing, 질의·문서 제목의 심층 전역 벡터, 코사인 유사도 | 실제 클릭 자료의 Web document ranking |
| 2014 | C-DSSM | 문맥 창 convolution, max pooling, 전역 의미 벡터 | 실제 클릭 자료의 Web document ranking |
| 2016 | DRMM | 질의어-문서어 유사도 histogram, feed-forward matching, term gating | Robust04·ClueWeb-09-Cat-B 상위 2,000개 재순위화 |
| 2020 | DPR | Transformer dual encoder, passage 내적, in-batch·hard negatives | 여러 개방 영역 QA 자료의 passage retrieval |

따라서 raw의 “2016년 출현”은 신경 IR이 연구 영역으로 확실해진 시기를 느슨하게 가리킬 수 있지만, DSSM·C-DSSM의 공개 연대를 대체할 수 없다.

### DSSM: 클릭으로 공통 표현 학습하기

2013년 DSSM은 질의 $Q$와 문서 제목 $D$를 각각 심층 신경망으로 연속 벡터 $y_Q$, $y_D$에 사상하고 코사인 유사도를 계산했다.

$$
R(Q,D)=\frac{y_Q^\top y_D}{\lVert y_Q\rVert\lVert y_D\rVert}
$$

클릭된 문서 $D^+$와 표본화한 비클릭 문서를 후보로 두고, scale을 적용한 유사도의 softmax에서 $D^+$의 조건부 가능도를 높였다. 모델은 사람이 relevance feature를 하나씩 정하는 대신 클릭된 질의-문서 쌍을 구별하는 표현을 학습했다.

DSSM의 `word hashing`은 각 단어를 문자 trigram count 벡터로 바꿔 큰 단어 어휘의 입력 차원을 줄이는 기법이다. `#dog#`처럼 단어 경계 기호를 붙인 trigram을 공유하면 미등록 단어도 입력 형태를 만들 수 있다. 여기서 hashing은 현대 ANN 색인이나 locality-sensitive hashing이 아니라 **어휘 입력 표현의 차원 축소**다.

논문의 문서 입력은 전체 본문이 아니라 검색 결과의 document title이다. 실제 클릭 자료의 NDCG@1에서 비교 잠재 의미 모델보다 개선했지만, 이를 모든 장문·도메인·질의에서 전통 검색을 대체한 보편 결과로 확대하지 않는다.

### C-DSSM: 지역 문맥을 전역 벡터에 넣기

DSSM의 word hashing은 단어 순서와 국소 문맥을 직접 보존하지 않는다. 2014년 C-DSSM은 단어 문맥 창에 convolution을 적용해 word n-gram 수준의 지역 특징을 만들고, max pooling으로 두드러진 특징을 모아 전역 벡터를 계산했다. 학습 목적은 클릭된 문서의 조건부 가능도를 높이는 DSSM 계열을 유지했다.

CNN을 썼다는 사실만으로 질의와 긴 문서의 모든 세밀한 상호작용을 보존하지는 않는다. max pooling 뒤에는 여전히 각 텍스트가 하나의 전역 벡터로 압축되고 마지막에 유사도를 계산한다. 이는 문서 표현을 미리 계산할 수 있는 장점과, 특정 질의어가 문서의 어느 부분에 정확히 대응했는지 잃을 수 있는 한계를 함께 만든다.

### DRMM: 의미 유사성과 검색 관련성은 다르다

2016년 DRMM은 기존 심층 대응 모델이 paraphrase·질의응답 같은 semantic matching과 ad-hoc retrieval의 relevance matching을 너무 비슷하게 취급한다고 비판했다. 긴 문서의 관련성에는 세 요소가 특히 중요하다고 보았다.

1. **exact matching signal**: 같은 핵심 용어가 직접 등장하는가.
2. **query term importance**: 흔한 용어와 희귀한 핵심 용어의 기여가 같은가.
3. **diverse matching requirement**: 긴 문서의 서로 다른 위치와 강도에서 대응이 일어나는가.

DRMM은 각 질의어와 모든 문서어 임베딩의 코사인 유사도를 계산하고, 위치 대신 강도 구간별 histogram으로 모았다. feed-forward network가 질의어별 점수를 만들며, IDF 또는 학습된 term gating이 질의어 점수를 합친다. exact match는 가장 높은 유사도 bin에서 별도 신호로 남을 수 있다.

실험은 Robust04와 ClueWeb-09-Cat-B에서 query-likelihood 모델이 먼저 찾은 상위 2,000개 문서를 신경 모델로 재순위화했다. DRMM이 전체 컬렉션의 첫 단계 후보 생성을 대체했다고 기록하면 안 된다. 이 논문의 결과는 오히려 전역 의미 벡터만으로는 전통 검색보다 나쁠 수 있으며, 희소 exact signal을 버리지 않는 relevance 설계가 중요하다는 증거다.

### 표현 중심과 상호작용 중심의 trade-off

질의와 문서를 독립적으로 한 벡터에 담는 표현 중심 모델은 문서 벡터를 오프라인에서 계산할 수 있다. 반면 두 텍스트의 token-level 대응을 먼저 계산하는 상호작용 중심 모델은 더 많은 세부 신호를 볼 수 있지만 질의가 들어올 때 문서마다 비싼 계산이 필요하다.

| 질문 | 독립 전역 표현 | 국소 상호작용 |
| --- | --- | --- |
| 문서 사전 계산 | 가능 | 제한적 |
| 큰 후보 집합 비교 | 벡터 색인이 있으면 효율적 | 보통 재순위화에 적합 |
| exact match 보존 | 압축 과정에서 약해질 수 있음 | 직접 특징으로 남길 수 있음 |
| 질의-문서 세부 관계 | 한 점수에 압축 | token·passage별로 모델링 가능 |
| 대표 초기 예 | DSSM·C-DSSM | DRMM |

현대 시스템의 dual encoder와 [[교차 인코더 재순위화|cross-encoder]]도 이 trade-off를 다른 인코더와 자료 규모에서 반복한다. 보통 빠른 희소·밀집 검색으로 후보 재현율을 확보하고, 더 비싼 상호작용 모델로 일부 후보를 재순위화한다. [[064_BERT 기반 passage 재순위화]]는 BM25 상위 후보를 BERT cross-encoder로 다시 정렬하는 이 후속 구성을 구체적으로 다룬다.

### 음성 표본과 클릭 표지의 의미

검색에서는 질의마다 관련 문서가 적고 잠재 음성 문서가 매우 많다. DSSM은 클릭된 문서와 함께 같은 질의에서 무작위로 고른 비클릭 문서를 음성 후보로 사용했다. 현대 dense retrieval은 batch의 다른 양성 문서를 음성으로 재사용하거나, BM25·현재 모델이 잘못 높게 찾은 hard negative를 사용한다.

음성 표본은 계산량뿐 아니라 모델이 배우는 경계를 정한다. 너무 쉬운 무작위 음성만 쓰면 비슷하지만 틀린 문서를 구분하지 못하고, false negative를 hard negative로 넣으면 실제 관련 문서를 밀어낼 수 있다.

클릭도 깨끗한 relevance 정답이 아니다. 높은 위치의 결과가 더 많이 보이는 position bias, snippet·브랜드가 클릭에 주는 presentation bias, 사용자가 보지 않은 비클릭 결과를 무관련으로 보는 오류가 있다. 대규모 클릭 자료의 양과 판단 품질은 별도 축이다.

### 희소 검색을 대체하지 않는 이유

raw는 전통 검색이 동의어를 거의 처리하지 못하고 복잡한 비선형 관계도 배울 수 없었다고 단순화한다. 그러나 LSI, query expansion, 확률 언어 모형, learning to rank가 이미 여러 대응을 다뤘고, [[BM25]]의 exact lexical signal은 신경 검색에서도 강한 기준선이다.

고유명사, 제품 번호, 법령 조항, 오류 코드, 희귀 수치처럼 표면 일치가 핵심인 질의에서는 밀집 벡터가 비슷한 일반 개념을 찾는 동안 정확한 대상을 놓칠 수 있다. 반대로 질의와 문서가 서로 다른 표현을 쓰는 설명형 질의에서는 밀집 검색이 희소 검색을 보완할 수 있다. `keyword`와 `semantic`을 상호 배타적인 세대로 놓기보다 후보를 합치고 실제 질의 분포에서 평가해야 한다.

### 검색과 독해의 경계

[[050_SQuAD와 추출형 독해 평가|SQuAD 1.1]]은 이미 주어진 문단에서 답 구간을 찾는다. 신경 정보 검색은 질문 또는 질의를 받아 큰 컬렉션에서 관련 문서·passage의 순위를 만든다. 개방 영역 질의응답에서는 두 단계를 연쇄할 수 있다.

$$
Q\xrightarrow{\text{retriever}}D_{1:k}
\xrightarrow{\text{reader or generator}}A
$$

검색기가 정답 근거를 top-$k$ 후보에서 놓치면 완벽한 reader도 복구할 수 없다. 반대로 근거가 후보에 있어도 reader가 잘못된 구간을 고르거나 generator가 근거와 다른 답을 만들 수 있다. 최종 정답률만 보면 검색 실패와 독해·생성 실패가 섞이므로 retrieval recall과 answer accuracy를 따로 측정해야 한다.

### 현대 밀집 검색과 RAG 연결의 범위

2020년 DPR은 BERT 기반 question encoder와 passage encoder, 내적 점수, in-batch negatives를 사용해 Wikipedia passage를 검색했다. 여러 개방 영역 QA 자료에서 BM25보다 높은 top-$k$ passage retrieval accuracy를 보고했다. 같은 해 RAG는 사전학습된 dense retriever와 seq2seq generator를 결합하고 검색 문서를 잠재 변수로 다뤘다.

질의와 문서를 따로 인코딩한다는 구조적 공통점은 DSSM 계열과 현대 dense retrieval 사이에 있다. 그러나 다음 요소를 생략하고 2016년 모델이 RAG를 “직접 가능하게 했다”고 말할 수는 없다.

- Transformer의 문맥 표현과 대규모 사전학습
- open-domain QA에 맞춘 passage 단위 감독
- in-batch·hard negative 설계
- 최대 내적·근사 최근접 이웃 색인
- 검색 결과를 조건으로 생성하고 그 불확실성을 다루는 학습

벡터 데이터베이스도 초기 논문이 자동으로 제공한 제품이 아니라, 고차원 벡터의 저장·갱신·ANN 검색·filter·sharding을 다루는 별도 시스템 계층이다.

## 검증과 한계

### 검증 정정

- 신경 정보 검색은 2016년에 단독으로 출현하지 않았다. 대표 DSSM은 2013년, C-DSSM은 2014년이다.
- 전통 검색은 단순한 원시 키워드 중첩만 사용하지 않았다. TF-IDF·BM25·LSI·언어 모형·learning to rank의 서로 다른 기능을 구분한다.
- DSSM의 word hashing은 문자 trigram 입력 축약이며 ANN 검색용 hash가 아니다.
- 원 DSSM·C-DSSM의 문서 표현은 Web document title 중심이며 모든 장문을 독립 인코딩한 웹 전체 검색 실증으로 확대하지 않는다.
- 의미가 비슷한 두 텍스트와 검색 질의에 관련된 문서는 같은 관계가 아니다. DRMM은 exact match와 질의어 중요도를 별도로 보존했다.
- DRMM은 query-likelihood 모델의 상위 2,000개를 재순위화했으며 첫 단계 검색을 대체하지 않았다.
- 클릭과 비클릭은 편향 없는 관련·무관련 정답이 아니다.
- 새 문서를 즉시 색인할 수 있는 희소 내용 검색을 일률적으로 cold-start에 취약하다고 보지 않는다.
- 웹·상품·기업·학술·법률 검색과 추천의 효과는 구체적 제품·자료·지표 없이 초기 세 논문의 직접 실증으로 채택하지 않는다.
- DSSM과 현대 DPR·RAG의 구조적 공통점은 인정하되 Transformer·passage supervision·ANN·생성 결합을 생략한 단일 직접 계보는 채택하지 않는다.

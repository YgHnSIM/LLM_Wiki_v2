# 멀티모달 LLM과 시각-언어 연결 방식의 분화

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[CLIP]], [[Flamingo]], [[Transformer]]<br>
> **읽고 나면:** 2023년의 멀티모달 LLM을 하나의 공통 architecture로 뭉뚱그리지 않고, Frozen·Flamingo·PaLI·BLIP-2·LLaVA·PaLM-E·GPT-4V가 시각 정보를 언어 model에 전달한 서로 다른 경로와 공개 범위를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 한 사건보다 여러 연결 방식의 수렴이었다

2023년에는 image와 text를 함께 받아 text를 생성하는 **[[멀티모달 대규모 언어 모델]]**이 연구 prototype과 사용자 제품 양쪽에서 두드러졌다. 그러나 이를 “비전 인코더가 image를 text token과 같은 공간으로 바꾸고 하나의 LLM이 모두 처리하게 된 해”라고 단일화하면 실제 설계를 놓친다. [[070_CLIP과 대조적 언어-이미지 사전 학습|CLIP]]은 2021년에 image와 text의 전역 표현을 대조 학습으로 정렬했고, 같은 해 Frozen은 학습되는 vision encoder의 연속 prefix를 동결 언어 model에 넣었다. [[084_Flamingo와 게이트 교차 어텐션 기반 퓨샷 시각-언어 학습|Flamingo]]와 PaLI는 2022년에 각각 삽입형 cross-attention과 ViT–encoder-decoder 결합을 공개했다. 2023년의 BLIP-2·PaLM-E·LLaVA와 GPT-4V는 이 문제를 서로 다른 훈련 경계와 bridge로 풀었다.

| 계열 | 시각 정보가 언어 model에 도착하는 경로 | 큰 사전 학습 구성요소의 처리 | 공개 범위 |
| --- | --- | --- | --- |
| CLIP | image·text를 각각 부호화해 전역 embedding 유사도 비교 | 두 encoder를 대조 학습 | 논문·model 공개 |
| Frozen | vision encoder가 만든 연속 embedding을 동결 autoregressive LM의 입력 prefix로 사용 | LM 동결, vision encoder 학습 | 논문 상세 공개 |
| Flamingo | Perceiver Resampler의 시각 token을 새 gated cross-attention이 읽음 | 시각 encoder·causal LM 동결, Resampler와 GATED XATTN-DENSE 학습 | 논문 상세 공개 |
| PaLI | ViT patch feature를 pooling 없이 mT5 encoder-decoder의 cross-attention에 전달 | 224px 사전 학습은 vision 동결·language 갱신, 짧은 588px 단계는 전체 갱신 | 논문 상세 공개 |
| BLIP-2 | 학습된 query가 Q-Former로 시각 특징을 압축하고 projection을 거쳐 LLM 입력이 됨 | image encoder·LLM 동결, Q-Former와 projection 학습 | 논문 상세 공개 |
| LLaVA | CLIP grid feature를 선형층으로 Vicuna word-embedding 차원에 투사 | 시각 encoder는 계속 동결, 1단계 projection만·2단계 projection+LLM 갱신 | 논문·code·data 공개 |
| PaLM-E | image·상태 추정을 연속 vector로 부호화해 text token과 같은 차원의 embedding sequence로 삽입 | 사전 학습 PaLM과 sensor encoder를 여러 embodied·vision-language 자료로 결합 | 논문 상세 공개 |
| GPT-4V | image 입력과 text 출력의 관찰 가능한 동작은 공개 | 내부 vision encoder·bridge·fusion 방식은 비공개 | 기술 보고서·system card·제품 interface 공개 |

따라서 공통점은 “image가 어떤 중간 표현을 거쳐 자기회귀 text 생성에 조건을 준다”는 높은 수준에 있다. Shared embedding, query bottleneck, 삽입형 cross-attention, 선형 projection, 연속 sensor token은 같은 연산이 아니다.

### 입력 모달리티와 출력 모달리티를 분리한다

여기서 다루는 주된 계열은 `image + text → text`다. Image를 이해한다고 해서 같은 model이 pixel image를 생성하는 것은 아니다. GPT-4V의 text 답변과 [[DALL·E 2]]·[[Stable Diffusion]]의 image 생성은 제품에서 함께 쓰일 수 있지만 model의 상태·loss·decoder가 다르다. “멀티모달”은 입력·출력·학습 자료 가운데 어느 경계를 뜻하는지 먼저 적어야 한다.

## 2단계 — 작동 원리

### 공통 그림은 유용하지만 architecture 명세는 아니다

시각-언어 생성 model을 다음과 같이 추상화할 수 있다.

$$
Z_v=E_v(I),\qquad V=B(Z_v),\qquad
p(y_t\mid I,x,y_{<t})=D(V,x,y_{<t}).
$$

$E_v$는 image encoder, $B$는 시각 표현을 언어 model에 연결하는 bridge, $D$는 text decoder다. 이 식은 비교용 지도일 뿐 모든 model이 $V$를 일반 word token처럼 같은 위치에 삽입한다는 뜻이 아니다. Flamingo의 $V$는 별도 key/value memory이고, BLIP-2의 Q-Former는 학습 query로 고정 수 특징을 고르며, LLaVA는 projection된 visual token sequence를 언어 입력에 둔다. PaLM-E는 image뿐 아니라 continuous state estimate도 같은 embedding 차원의 vector sequence로 만든다.

### 동결 경계가 재사용 비용과 적응 범위를 정한다

BLIP-2의 **두 단계 사전 학습**은 off-the-shelf image encoder와 LLM을 모두 동결하고 Q-Former를 학습한다. 첫 단계는 image–text contrastive learning·image-grounded text generation·image–text matching으로 text와 관련된 visual representation을 만들고, 둘째 단계는 Q-Former 출력이 동결 LLM에 해석되도록 생성 학습을 한다. 다만 downstream captioning fine-tuning에서는 LLM을 계속 동결한 채 image encoder를 풀 수 있다. 동결 경계는 pretraining과 downstream adaptation을 나눠 적어야 하며, bridge가 모든 시각 세부의 보존을 보장하지도 않는다.

PaLI는 별도 query 병목 대신 ViT의 patch feature를 pooling하지 않고 mT5 encoder-decoder에 visual token으로 전달한다. 1.6B example을 224×224로 한 번 도는 주된 사전 학습에서는 vision component를 동결하고 language component만 갱신했다. PaLI-17B의 추가 588×588 단계는 10,000 step·10M example 동안 전체 parameter를 갱신했다. “동결 model”이나 “공동 학습 model”이라는 한 단어보다 단계별 경계를 기록해야 하는 사례다.

LLaVA는 다른 경계를 택했다. CLIP ViT-L/14의 feature를 projection matrix $W$로 Vicuna의 word-embedding 차원에 맞춘다. Feature-alignment 단계에서는 vision encoder와 LLM을 모두 동결하고 $W$만 학습한다. Visual instruction tuning 단계에서는 vision encoder는 동결한 채 $W$와 LLM을 함께 갱신한다. 논문이 이를 end-to-end fine-tuning이라고 부르더라도 vision encoder까지 모두 갱신했다는 뜻은 아니다.

PaLM-E는 embodied observation을 language embedding과 같은 차원의 vector로 만들고 text와 번갈아 배치한다. 기본 구성은 encoder·projection·PaLM을 end-to-end로 갱신하며, PaLM을 동결하는 조건은 별도 비교 실험이다. 가장 큰 PaLM-E-562B도 ViT-22B와 PaLM-540B를 함께 갱신한 구성이다. 이 interface는 image caption이나 VQA를 넘어 robot state·sensor observation을 prompt 안에 넣을 수 있게 한다. 반면 “PaLM-E와 PaLM 2가 모두 vision model이었다”는 raw 설명은 구분해야 한다. PaLM-E는 PaLM을 embodied하게 확장한 별도 연구다. PaLM 2 technical report는 Transformer-based **language model**의 text corpus·다국어·추론·coding·안전 평가를 기술하며 base model의 image-input interface나 vision architecture를 문서화하지 않는다. 제품의 전후처리나 다른 model 결합 가능성도 base PaLM 2 자체의 vision 근거가 되지 않는다.

### Instruction data는 bridge와 별도의 축이다

LLaVA의 또 다른 변화는 architecture보다 data interface에 있었다. 당시 text-only GPT-4에 image 자체를 보여 준 것이 아니라 COCO caption과 bounding box를 text로 제공해 대화·상세 설명·복합 추론 형식의 158K instruction sample을 만들었다. 그 뒤 실제 image와 이 답변을 LLaVA의 visual instruction tuning에 사용했다. “GPT-4가 image를 보고 LLaVA data를 직접 작성했다”는 설명은 당시 data 생성 절차와 다르다.

Instruction tuning은 사용자의 질문 형식을 따르는 능력을 개선하지만 시각 근거의 정확성을 자동으로 보장하지 않는다. LLaVA 논문의 85.1%는 30개 image·90개 question으로 구성한 자체 benchmark에서, caption·bounding box를 받은 text-only GPT-4의 답을 reference와 judge에 포함해 얻은 상대 점수다. ScienceQA 92.53%도 LLaVA 단독 점수가 아니라 LLaVA와 text-only GPT-4의 답을 결합한 조건이다. Benchmark, 입력 표현, judge, ensemble과 denominator를 떼어 기록해야 한다.

### GPT-4V의 보고·접근·제품 공개는 날짜가 다르다

GPT-4 기술 보고서는 2023년 3월 image와 text 입력 사례를 소개했지만, OpenAI는 경쟁·안전 이유로 model 크기를 포함한 architecture, hardware, training compute, dataset construction과 구체적 training method를 공개하지 않았다. 따라서 “vision encoder가 image를 같은 token 공간으로 변환하고 cross-attention으로 GPT-4에 넣었다”는 일반적인 설명을 GPT-4의 확인된 내부 구조로 쓸 수 없다.

GPT-4V system card에 따르면 훈련은 2022년에 끝났고 소규모 early access는 2023년 3월 시작됐다. ChatGPT Plus·Enterprise의 image 입력은 9월 25일 발표 뒤 2주에 걸쳐 배포됐고, 개발자용 `gpt-4-vision-preview`는 11월 6일 공개됐다. 연구 보고서, 제한된 pilot, 일반 사용자 rollout, API preview는 모두 다른 공개 경계다.

## 3단계 — 기술과 근거

### Bridge는 압축률·위치 정보·계산량을 서로 다르게 교환한다

Flamingo의 Resampler와 BLIP-2의 Q-Former는 가변 길이 시각 feature에서 고정 수 query 출력을 만드는 정보 병목이다. 이는 언어 model이 읽는 token 수를 제한하지만 작은 글자·정밀 위치·개수 같은 정보까지 무손실로 보존한다는 보장은 없다. LLaVA의 단순 선형 projection은 연결부가 가볍고 data·훈련 절차의 효과를 비교하기 쉽지만, 원 논문도 gated cross-attention이나 Q-Former 같은 더 복잡한 대안을 후속 연구로 남겼다.

PaLM-E의 연속 embedding injection은 camera image와 robot state를 같은 autoregressive interface로 다룬다. 그러나 출력되는 계획 text와 실제 robot 동작 사이에는 low-level policy·sensor loop·환경 제약이 남는다. 자연어 계획을 생성하는 model 하나가 물리 시스템 전체를 대체했다는 뜻이 아니다.

### 제품 사례는 효과와 실패를 함께 보여 준다

OpenAI와 Be My Eyes는 2023년 3월부터 8월 초까지 약 200명의 blind·low-vision beta tester로 Be My AI를 시험했고, 9월에는 16,000명과 하루 평균 25,000건의 설명 요청으로 확대했다. 이 수치는 접근성 interface의 실제 사용 가능성을 보여 주지만 정확성 인증은 아니다. 같은 system card는 tester가 hallucination·오류·과도하게 확신하는 답을 발견했고, 배포 전 OCR 같은 부분을 개선했다고 기록한다.

GPT-4V red teaming에서는 가까이 붙은 text component의 병합, 문자·수학 기호 누락, 공간 위치·색 mapping 오류, 비로마자 OCR 약화가 관찰됐다. 화학 구조·유독 식품·의료 image의 불안정한 해석, 사람·장소에 대한 근거 없는 추론, stereotype, image 순서 민감성과 disinformation 판별의 불일치도 남았다. OpenAI는 당시 version을 어떤 의료 기능이나 전문 조언·진단·치료의 대체에도 적합하지 않다고 명시했다. “의료 image 분석이 가능하다”와 “의료 판단에 사용할 만큼 검증됐다”는 전혀 다른 주장이다.

### 평가 단위는 ‘멀티모달 이해’ 하나가 아니다

Image captioning, VQA, OCR, chart reading, counting, spatial relation과 multi-image comparison은 입력 해상도·crop·prompt·decoding·후처리에 서로 다르게 민감하다. 한 예시의 설득력 있는 설명이나 특정 benchmark의 높은 점수로 이 능력을 모두 입증할 수 없다. 특히 open-ended 답은 정답 문자열 비교, 사람 평가, model judge 가운데 무엇을 사용했는지에 따라 score 의미가 달라진다.

PaLI-17B의 COCO CIDEr 149.1과 VQAv2 84.3은 각 downstream dataset으로 미세조정한 결과다. PaLM-E-562B generalist checkpoint의 VQAv2 80.0·OK-VQA 66.1·COCO 138.7도 하나의 weight set이라는 의미는 있지만, 학습 mixture에 세 과제가 각각 0.5% 포함됐다. 하나의 checkpoint, task-specific fine-tuning 없음과 held-out zero-shot은 같은 조건이 아니다.

Model 수준과 system 수준도 나눠야 한다. Image resize·tile, OCR, retrieval, moderation, UI annotation과 외부 도구가 최종 결과에 들어갈 수 있다. “한 model이 분리된 모든 vision·language pipeline을 없앴다”는 주장은 공개된 제품 구성과 평가 조건 없이는 검증할 수 없다.

## 검증과 한계

### raw 설명의 검증 정정

- **멀티모달 LLM은 2023년에 처음 통합됐다:** CLIP은 2021년에 image–text alignment를, Flamingo는 2022년에 image·video 조건부 text 생성과 multimodal few-shot prompting을 보였다. 2023년은 여러 bridge·instruction-tuning 방식과 제품 접근이 빠르게 확장된 시기다.
- **GPT-4의 vision encoder와 cross-attention 구조가 공개됐다:** GPT-4 technical report는 구체적인 architecture를 의도적으로 공개하지 않았다. 관찰된 image-input 능력을 특정 공개 model의 구조로 역추론하지 않는다.
- **GPT-4는 2023년 3월부터 누구나 image를 넣을 수 있었다:** 3월에는 보고와 제한된 early access가 있었고, ChatGPT의 광범위한 image rollout은 9월, 개발자 API preview는 11월이었다.
- **PaLM-E와 PaLM 2가 같은 방식으로 vision을 통합했다:** 확인된 model은 PaLM을 sensor·vision 입력으로 확장한 PaLM-E다. PaLM 2의 이름을 근거로 같은 architecture나 vision capability를 부여하지 않는다.
- **Claude가 2023년 vision 통합의 기술적 토대를 제공했다:** raw는 이를 뒷받침하는 architecture·실험·release 근거를 제시하지 않는다.
- **모든 model이 image를 text token과 같은 representation space에 넣었다:** Frozen의 연속 prefix, Flamingo의 별도 cross-attention memory, PaLI의 encoder-decoder visual token, BLIP-2의 Q-Former 병목, LLaVA의 projection, PaLM-E의 continuous embedding injection은 구별해야 한다.
- **멀티모달 통합이 human-like understanding이나 AGI 경로를 입증했다:** 입력 channel의 확대와 특정 task 결과는 사람과 같은 지각·추론 방식이나 범용 지능을 입증하지 않는다.
- **과학·의료·교육·산업이 이미 혁신됐다:** Raw의 많은 사례는 가능성 또는 초기 deployment다. 분야별 정확성, 안전성, 업무 성과와 장기 영향은 별도 평가가 필요하다.

### 공개 정보의 비대칭이 비교를 제한한다

BLIP-2·LLaVA·PaLM-E·PaLI·Flamingo는 architecture와 훈련 절차를 논문에서 비교적 자세히 공개했다. GPT-4V는 기능·일부 훈련 개요·안전 평가와 interface를 공개했지만 내부 연결부는 공개하지 않았다. 따라서 동일한 표에 놓을 때 GPT-4V의 architecture 칸은 “비공개”로 남겨야 하며, 공개 model의 구조를 유추해 채우면 안 된다.

Data 규모와 정렬 품질, training compute도 model마다 공개 수준이 다르다. 같은 benchmark score라도 pretraining contamination, prompt selection, image resolution, support example과 model judge 조건이 다르면 직접적인 효율 비교가 어렵다.

### 더 많은 입력은 더 넓은 위험 표면이기도 하다

Image에는 얼굴·주소·문서·위치·건강 정보처럼 text prompt보다 쉽게 노출되는 민감 정보가 들어갈 수 있다. 시각적 prompt injection, 작은 글자와 도표 오독, image 안의 stereotype 단서, 근거 없는 identity inference도 추가된다. Multimodal input이 text-only model의 hallucination을 없애는 것이 아니라, 시각 정보와 언어 prior가 충돌할 새 경로를 만든다.

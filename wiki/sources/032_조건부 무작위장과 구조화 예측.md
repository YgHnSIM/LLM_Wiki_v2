# 조건부 무작위장과 구조화 예측

032 raw는 조건부 무작위장(Conditional Random Field, CRF)을 각 위치의 독립 예측을 순서열 전체의 공동 예측으로 바꾼 2001년의 혁명으로 서술한다. 공개 문서는 HMM과 MEMM도 이미 순서열 구조를 모델링했다는 선행 맥락을 복원하고, Lafferty·McCallum·Pereira의 실제 기여를 **관측열에 조건부인 판별 모델**, **중첩 관측 특징**, **라벨열 전체의 전역 정규화**, **동적 계획법 기반 학습·추론**의 결합으로 한정한다.

CRF가 해결하려 한 직접 문제는 “아무 구조도 없는 독립 분류”만이 아니다. 생성 모델 HMM은 관측 분포까지 모델링하기 위해 강한 독립성 가정을 두었고, 조건부 모델 MEMM은 각 상태에서 나가는 전이를 국소 정규화해 label bias가 생길 수 있었다. CRF는 입력 $x$ 전체를 조건으로 고정한 채 완전한 출력 $y$ 후보들을 하나의 분배 함수로 정규화했다.

## 선행 순서열 모델과 2001년의 변화

[[은닉 마르코프 모델]]은 CRF보다 앞서 상태 전이와 관측 방출로 상태열 전체를 모델링하고 [[비터비 알고리즘]]으로 최고 경로를 찾았다. 확률적 품사 태깅도 1980년대에 단어별 독립 결정이 아니라 태그 전이와 단어 가능도를 결합했다. 따라서 “전통적 방법은 `cat`을 고립해 명사·동사로 분류했다”는 raw의 대조는 순서열 모델의 역사를 대표하지 않는다.

HMM은 $P(x,y)$라는 관측열과 상태열의 결합분포를 둔다. 계산 가능성을 유지하려면 현재 상태가 주어졌을 때 관측의 여러 속성을 조건부 독립으로 보는 식의 가정이 필요해진다. 철자, 접사, 대문자 여부, 문서 배치, 앞뒤 단어처럼 겹치는 특징을 임의로 추가하면 관측 생성분포를 일관되게 정규화하기 어렵다.

2000년의 maximum entropy Markov model(MEMM)은 이 문제를 피하려고 현재 상태와 관측 특징에서 다음 상태로 가는 조건부 확률을 직접 모델링했다. 중첩 특징을 넣을 수 있었지만 각 출발 상태에서 나가는 전이끼리 정규화했다. 한 상태의 출구가 하나뿐이면 그 전이는 관측과 무관하게 확률 1을 받고, 나갈 길이 적은 상태가 전체 경로 경쟁에서 유리해질 수 있다. Lafferty 등은 이를 **label bias**라고 불렀다.

CRF의 역사적 차이는 조건부 특징 표현을 유지하면서 무방향 무작위장의 전역 정규화를 사용한 데 있다. 원 논문의 표현대로라면 CRF는 조건부 모델의 장점과 random field의 global normalization을 결합했다.

## 일반 정의와 선형 사슬 CRF

입력 자료열을 확률변수 $X$, 대응하는 출력 라벨들을 $Y=(Y_v)_{v\in V}$라고 하자. 그래프 $G=(V,E)$에서 $X$가 주어졌을 때 각 $Y_v$가 이웃 출력 변수에 대해서만 마르코프 성질을 만족하면 $(X,Y)$를 조건부 무작위장이라고 정의한다.

원 논문이 학습과 실험에 사용한 대표적 경우는 출력 그래프가 사슬인 **선형 사슬 CRF**다. 시작·종료 상태를 포함하고, 인접 라벨 쌍과 위치별 관측 특징의 점수를 더하면 다음처럼 쓸 수 있다.

$$
P_\theta(y\mid x)
=\frac{1}{Z_\theta(x)}
\exp\!\left(
\sum_{t=1}^{T}
\sum_k \theta_k f_k(y_{t-1},y_t,x,t)
\right)
$$

$$
Z_\theta(x)=\sum_{y'}
\exp\!\left(
\sum_{t=1}^{T}
\sum_k \theta_k f_k(y'_{t-1},y'_t,x,t)
\right)
$$

$Z_\theta(x)$는 주어진 입력에 대해 가능한 모든 라벨열의 비정규화 점수를 합한다. 따라서 한 전이는 같은 상태에서 나가는 다른 전이만이 아니라 서로 다른 완전 경로와 경쟁한다. raw의 웹 수식은 `xxx`, `yyy`와 동일 식 세 벌이 겹쳐 있었으므로 한국어 번역에서는 위와 같은 표준 조건부 로그선형 식으로 한 번만 복원했다.

일반 CRF와 선형 사슬 CRF를 같은 범위로 축소하지 않는다. 일반 정의는 임의의 출력 그래프를 허용하지만, 사슬이 아닌 그래프나 분해되지 않는 전역 특징에서는 정확한 정규화·추론이 비싸거나 불가능할 수 있다.

## 상태 특징과 전이 특징

raw가 말하는 상태 특징은 현재 라벨과 입력 속성의 적합도를 나타낸다. 예를 들어 현재 단어가 대문자로 시작하고 후보 라벨이 고유명사일 때, 접미사가 `-ing`이고 후보 라벨이 동사일 때 활성화되는 특징을 둘 수 있다. CRF는 $P(x)$를 모델링하지 않으므로 서로 겹치고 비독립적인 입력 특징을 함께 사용할 수 있다.

전이 특징은 인접 라벨 조합을 점수화한다. 품사 태깅에서는 `DT→NN`, 개체명 인식의 BIO 표기에서는 `B-PER→I-PER` 같은 전이가 예다. 전이 가중치는 어떤 라벨 쌍이 학습 자료에서 일관된 순서열을 이루는지 나타낸다.

“어떤 계산 가능한 함수든 특징으로 쓸 수 있다”는 설명에는 계산 조건이 따른다. 정확한 forward-backward와 Viterbi를 사용하려면 전체 순서열 점수가 사슬의 국소 위치·전이 항으로 분해되어야 한다. 임의의 전역 특징을 추가하면 상태 공간을 확장하거나 근사 추론을 사용해야 할 수 있다.

## 학습과 추론

고정된 특징을 사용하는 로그선형 CRF는 학습 자료의 조건부 로그가능도를 최대화한다. 원 논문은 improved iterative scaling을 바탕으로 한 두 학습 알고리즘을 제시하고 보조 함수를 이용한 수렴을 설명했다. 오늘날 다른 수치 최적화와 규제를 사용할 수 있으므로 이 역사적 알고리즘을 CRF의 유일한 학습법으로 보지 않는다.

선형 사슬에서는 forward-backward로 분배 함수, 위치·전이 주변확률과 모델의 기대 특징 빈도를 계산한다. Viterbi는 합산 연산을 최댓값 선택으로 바꾸어 최고 점수 라벨열을 찾는다. 길이를 $T$, 라벨 수를 $K$라고 할 때 밀집 1차 전이의 대표 비용은 $O(TK^2)$다. raw의 “순서열 길이에 비례한다”는 설명은 $K$를 고정한 경우의 길이 의존성만 말하며 라벨 수의 제곱 비용을 생략한다.

고정 특징 로그선형 CRF의 음의 로그가능도는 볼록하다. 그러나 “국소 최적점이 없으므로 하나의 전역 최적점이 있다”는 문장은 매개변수 식별성과 규제를 구분해야 한다. 중복 특징이 있거나 엄격한 볼록성이 없으면 서로 다른 매개변수가 같은 분포·목적값을 낼 수 있다. 신경망 인코더와 CRF를 함께 학습하는 neural CRF의 전체 목적은 일반적으로 비볼록하므로 2001년 결과를 그대로 적용할 수 없다.

## 원 논문의 실험 범위

원 논문은 세 종류의 비교를 보고했다.

1. label bias를 드러내도록 만든 합성 유한상태 자료에서 같은 topology를 가진 MEMM과 CRF를 비교했다. 한 대표 실행에서 CRF 오류는 4.6%, MEMM 오류는 42%였다.
2. 1차·2차 의존성을 섞어 생성한 합성 자료에서 1차 HMM·MEMM·CRF를 비교했다. 2차 성분이 커질수록 모든 1차 모델의 오류가 늘었고, 대체로 CRF가 MEMM보다 낮은 오류를 보였다.
3. Penn Treebank 110만 단어 말뭉치의 50% 학습 분할과 45개 품사 태그를 사용했다. 표에 보고된 단어 오류율은 HMM 5.69%, MEMM 6.37%, CRF 5.55%였다. 숫자·대문자·하이픈·접미사 철자 특징을 더한 MEMM+는 4.81%, CRF+는 4.27%였다.

세 번째 실험의 OOV 오류율은 HMM 45.99%, MEMM 54.61%, CRF 48.05%, MEMM+ 26.99%, CRF+ 23.76%였다. 이는 중첩 철자 특징과 전역 정규화의 이점을 그 설정에서 보여준다. 그러나 무작위 50–50 분할, 특징 템플릿과 학습 수렴 조건에 종속된 결과이며, NER·청킹·정보 추출 전반의 보편적 성능 순위를 증명하지 않는다.

원 논문은 CRF 학습이 느리다는 한계도 직접 보고했다. 철자 특징을 넣은 MEMM+는 약 100회 반복에 수렴했고, 그 매개변수로 초기화한 CRF+는 1,000회 반복에 수렴했다. 균일 분포에서 시작한 같은 CRF는 2,000회 뒤에도 수렴하지 않았다. 이 결과를 “볼록하므로 계산도 항상 쉽다”는 주장과 구분한다.

## 응용 범위

선형 사슬 CRF는 품사 태깅, 구 청킹, 개체명 인식처럼 입력 위치마다 상호 의존하는 라벨을 부여하는 과제에 잘 맞는다. 특히 BIO 라벨처럼 한 개체의 시작과 내부 라벨이 일관되어야 하는 경우 전이 점수가 유용하다.

다만 2001년 원 논문이 직접 평가한 자연어 과제는 Penn Treebank 품사 태깅이다. raw가 개체명 인식·정보 추출·광고 가격·사건 참여자 추출을 CRF의 즉각적이고 광범위한 성공으로 묶은 부분은 후속 시스템별 근거가 필요하다. 입력의 단어마다 하나의 라벨을 붙이는 선형 사슬 구조와 임의 span·관계·트리·문서 수준 사건 구조를 같은 문제로 보지 않는다.

CRF의 정규화된 확률은 라벨열과 위치별 주변확률을 제공한다. 그러나 확률 형식이라는 사실만으로 confidence가 실제 오류 빈도와 맞는 calibration이 보장되지는 않는다. 모델 부적합, 규제, 자료 이동과 과적합이 있으면 별도 검증·보정이 필요하다.

## 신경 순서열 모델과의 관계

2015년 Huang·Xu·Yu는 LSTM, 양방향 LSTM, LSTM-CRF, BiLSTM-CRF를 품사 태깅·청킹·NER에서 비교했다. 이 구조에서는 LSTM 계열 인코더가 입력의 문맥 표현을 학습하고 CRF 층이 문장 수준 라벨 전이를 점수화한다. 수작업 상태 특징을 신경 표현으로 바꾸면서도 구조 출력 층을 유지한 직접 결합 사례다.

이 직접 결합을 RNN·attention·Transformer·LLM 전체의 직접 계보로 확대하지 않는다. Transformer 인코더 위에도 CRF 층을 붙일 수 있지만 self-attention의 문맥 혼합과 CRF의 출력 정규화는 서로 다른 계산이다. 자기회귀 LLM의 다음 토큰 softmax도 위치별 조건부 분포이며, 완전한 라벨열을 선형 사슬 CRF의 분배 함수로 한꺼번에 정규화하는 것과 동일하지 않다.

구조화 출력이라는 넓은 문제의식은 공유할 수 있다. 하지만 JSON schema 검증, 문법 제약 디코딩, tool calling을 CRF라고 부르려면 조건부 무작위장 그래프, 특징 분해와 전역 정규화라는 구체적인 모델 구조가 실제로 있어야 한다.

## 검증 정정

- **이전 방식은 각 단어를 독립 분류**: HMM·확률 태거·MEMM은 이미 상태·라벨 순서열을 모델링했다. CRF의 직접 차이는 조건부 특징과 전역 정규화의 결합이다.
- **일반 CRF 식**: raw의 식은 위치·clique 분해가 생략된 교육용 점수식이고 웹 렌더링이 중복됐다. 선형 사슬에서는 위치별 상태·전이 특징의 합과 입력별 분배 함수를 명시해야 한다.
- **비터비가 길이에만 비례**: 밀집 1차 사슬의 대표 복잡도는 $O(TK^2)$다. $K$를 고정하면 $T$에 선형이지만 라벨 수 비용은 남는다.
- **볼록 목적은 항상 유일한 최적 매개변수**: 고정 로그선형 목적의 전역 최적화와 매개변수의 유일성은 다르며, neural CRF 전체에는 같은 볼록성이 적용되지 않는다.
- **보정된 확률**: CRF는 정규화 확률을 주지만 calibration은 별도 경험적 평가 대상이다.
- **전형적 CRF는 본질적으로 1차**: 1차 선형 사슬은 대표 구현일 뿐 CRF의 일반 정의 자체가 이웃 쌍으로만 제한되는 것은 아니다. 고차·다른 그래프는 계산 비용을 늘린다.
- **NLP 전반의 즉각적 혁명과 상용 채택**: 원 논문의 자연어 증거는 Penn Treebank 품사 실험이다. 다른 과제와 산업 배치는 후속 1차 연구로 확인해야 한다.
- **CRF에서 모든 현대 순서열 모델로 이어지는 직접 계보**: BiLSTM-CRF는 직접 결합이지만 RNN·Transformer·LLM 전체의 기원이나 필수 구성 요소라는 주장은 입증되지 않는다.

## 핵심 문장

- CRF는 관측열 전체가 주어졌을 때 구조화된 라벨 변수의 조건부 분포를 모델링한다.
- 선형 사슬 CRF는 가능한 완전 라벨열 전체를 $Z(x)$로 정규화해 MEMM의 국소 정규화 label bias를 다룬다.
- 상태·전이 점수의 국소 분해가 forward-backward와 Viterbi의 정확한 동적 계획법을 가능하게 한다.
- 원 논문의 직접 자연어 증거는 Penn Treebank 품사 태깅이며, 철자 특징과 전역 정규화의 효과를 그 설정에서 비교했다.
- neural CRF는 표현 학습과 구조 출력 층의 직접 결합이지만 Transformer·LLM 전체를 CRF의 단순한 확장으로 볼 수는 없다.

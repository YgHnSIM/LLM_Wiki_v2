# 지속 사전 학습의 연표와 지식 갱신 경계

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[언어 모델 전이 학습]], [[저순위 적응]]<br>
> **읽고 나면:** 지속 사전 학습을 PEFT·검색·선호 정렬·배포 운영과 구분하고, 새 분포 적응과 기존 능력 보존을 함께 평가해야 하는 이유를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 2025년의 새 발명이라는 연표를 바로잡는다

원 웹글은 지속 사후 학습(continuous post-training)이 2025년에 등장해 정적인 언어 모델을 선택적으로 갱신하는 패러다임이 됐다고 서술한다. 그러나 목표 영역 텍스트에서 언어 모델 목적을 이어 학습한 ULMFiT는 2018년, 영역·과제 적응 사전 학습(DAPT·TAPT)은 2020년에 공개됐다. 순차 corpus에서 이전 능력을 보존하며 모델을 갱신하는 lifelong pretraining·continual knowledge learning·continual post-training 연구도 2022년에 발표됐다.

따라서 2025년은 원 웹글의 공개 시점이지 이 연구 문제의 시작점이 아니다. 이 글에서 재사용할 핵심은 “모델은 새 자료를 어떻게 받아들이면서 이전 능력을 보존하는가”라는 질문이다. 최초성·기업 채택·보편적 해결이라는 서사는 1차 연구가 확인한 범위로 다시 제한한다.

### 핵심 문장

- **지속 사전 학습(continual pre-training)**은 이전 checkpoint에서 출발해 시간·영역 순서로 들어오는 비표지 corpus의 언어 모델 목적을 계속 최적화하는 연구 설정이다.
- 새 자료의 손실이 줄었다는 사실만으로 이전 지식 보존, 특정 사실의 정확한 교체, 후속 과제 향상까지 보장되지 않는다.
- [[저순위 적응|LoRA]]는 어떤 매개변수를 적게 갱신할지 정하는 PEFT 매개변수화다. 순차 학습 목적·replay·망각 평가를 자동으로 제공하지 않는다.
- [[검색 증강 생성]]은 외부 색인을 추론 때 읽어 최신 자료를 반영할 수 있다. 가중치에 새 지식을 흡수하는 지속 사전 학습과 갱신 위치가 다르다.
- A/B test·model version·rollback은 중요한 배포 안전장치지만, 학습 알고리즘이 망각을 해결했다는 증거는 아니다.

### 한 이름 아래 섞인 다섯 경계

| 경로 | 주로 바꾸는 것 | 대표 입력·목적 | 그 자체로 보장하지 않는 것 |
| --- | --- | --- | --- |
| 지속 사전 학습 | 기반 model weight의 전부 또는 일부 | 시간·영역별 비표지 text와 LM loss | 이전 지식 보존, 사실 단위 교정 |
| 과제·지시·선호 사후 학습 | 과제 수행과 응답 행동 | 정답·지시·선호 비교와 SFT·RL 목적 | 최신 외부 사실의 포괄적 습득 |
| PEFT·adapter | 학습되는 parameter subset과 update 좌표 | LoRA factor·adapter module | 순차 자료 관리와 망각 방지 |
| 검색·외부 memory | 추론 입력과 비매개변수적 기억 | 검색 index·document context | Weight 내부 지식의 갱신 |
| 배포 운영 | 어느 checkpoint를 누구에게 제공할지 | 평가 suite·version·traffic·rollback | 새 model의 학습 품질 자체 |

## 2단계 — 작동 원리

### 새 corpus를 받는 한 주기

지속 사전 학습의 기본 입력은 이전 checkpoint $\theta_{t-1}$와 새 corpus $D_t$다. 먼저 새 자료의 출처·시점·중복·품질을 정하고, 기존 사전 학습과 같거나 호환되는 next-token 또는 masked-token 목적을 이어 최적화한다. 그 뒤 새 분포 적응뿐 아니라 이전 분포의 언어 모델 손실, 지식 probe와 후속 과제 성능을 함께 측정해 $\theta_t$를 채택할지 결정한다.

여러 방법을 묶어 쓴 개념식은 다음과 같다.

$$
\theta_t
=\arg\min_{\theta}
\mathcal L_{\mathrm{LM}}(D_t;\theta)
+\lambda R(\theta,\theta_{t-1},M_{<t})
$$

$R$은 이전 parameter와의 거리, 이전 model 출력에 대한 distillation, 과거 자료 memory $M_{<t}$의 replay처럼 보존을 돕는 항을 나타낼 수 있다. 모든 지속 사전 학습 방법이 같은 $R$을 쓰는 것은 아니다. 중요한 점은 새 자료 손실 하나만 줄이면 안정성–가소성(stability–plasticity) 절충을 측정할 수 없다는 것이다.

### Replay·규제·확장은 서로 다른 선택이다

Replay는 새 자료에 이전 자료 일부를 섞어 옛 분포의 gradient를 다시 제공한다. 규제와 distillation은 이전 weight나 출력에서 너무 멀어지는 것을 제한한다. Parameter masking·adapter·확장은 새 update가 기존 parameter와 충돌할 통로를 줄이거나 새 용량을 더한다.

이 선택들은 서로 대체 가능한 만능 부품이 아니다. 과거 원문을 저장하는 replay는 storage·privacy·licensing 조건을 가진다. 강한 규제는 망각을 줄이는 대신 새 분포 적응을 막을 수 있다. Parameter 확장은 보존에 도움이 될 수 있지만 model·routing·checkpoint 관리 비용을 늘린다. LoRA처럼 작은 update를 쓴다고 interference가 사라지는 것도 아니다.

### 세 종류의 성공을 따로 잰다

1. **가소성:** 새 corpus의 loss와 새 영역·시점의 후속 과제가 좋아지는가?
2. **보존:** 이전 corpus·불변 지식·기존 과제의 성능이 유지되는가?
3. **전이:** 앞서 학습한 분포가 뒤의 자료 학습을 돕고, 뒤의 학습이 과거 과제를 뜻밖에 개선하거나 훼손하는가?

지식 갱신에는 네 번째 질문도 필요하다. “새 사실을 읽었다”와 “오래된 답을 정확히 교체했다”는 다르다. Jang 등의 continual knowledge learning은 불변 지식 보존, 오래된 지식 갱신, 새 지식 획득을 나눠 측정했다. 이 구분 없이 평균 benchmark 하나만 보면 새 지식 습득과 기존 사실 손상을 상쇄해 숨길 수 있다.

### 최신성은 weight 안팎에 다르게 놓인다

지속 사전 학습은 새 분포를 parameter에 압축하므로 별도 document를 제공하지 않아도 행동이 달라질 수 있다. 그러나 어떤 문장이 어느 weight에 저장됐는지 추적하기 어렵고, 틀린 사실 하나를 정확히 제거했다는 보장도 약하다.

[[검색 증강 생성]]은 index를 바꾸고 질의 때 document를 가져오므로 출처 후보를 갱신하기 쉽다. 대신 retrieval 실패·오래된 index·문서 오독이 남는다. 두 경로는 경쟁만 하는 것이 아니라, 비교적 느린 weight update와 빠른 외부 memory 교체를 함께 쓰는 계층으로 구성할 수 있다.

## 3단계 — 기술과 근거

### 2017–2024년의 실제 연표

| 연도 | 연구 | 직접 확인되는 범위 |
| ---: | --- | --- |
| 2017 | EWC | Fisher 정보로 중요한 weight의 큰 변화를 벌하는 quadratic penalty를 permuted MNIST와 Atari 순차 학습에서 평가 |
| 2018 | ULMFiT | 일반 LM을 목표 영역 비표지 text에서 계속 학습한 뒤 분류기로 적응 |
| 2020 | DAPT·TAPT | 네 영역·여덟 분류 과제에서 영역 및 과제 비표지 corpus의 추가 사전 학습을 평가 |
| 2022 | Lifelong Pretraining | 연구 논문의 영역 stream과 시간순 tweet stream에서 새 분포 적응과 과거 downstream 성능 보존을 비교 |
| 2022 | Continual Knowledge Learning | 불변·갱신·신규 지식을 나눈 benchmark와 metric으로 parameter 지식 갱신을 평가 |
| 2022 | CPT | 여러 비표지 영역 corpus를 차례로 post-train하고 각 영역의 few-shot end-task를 수행하는 task-incremental 설정을 제안 |
| 2024 | 대규모 지속 사전 학습 | Learning-rate re-warming·re-decay·replay를 405M과 10B model의 제한된 분포 이동에서 평가 |

EWC는 지속 학습의 중요한 선행 방법이지만 현대 LLM용 지속 사전 학습 recipe로 처음부터 설계된 것은 아니다. 반대로 CPT 논문의 “첫 continual post-training system”은 저자들이 정의한 순차 비표지 영역·few-shot task 설정에 대한 주장이다. 2017년부터의 모든 지속 학습이나 2020년 DAPT까지 없었다는 뜻이 아니다.

### DAPT·TAPT는 한 번의 적응과 순차 학습을 잇는 징검다리다

Gururangan 등은 biomedical·computer science·news·reviews 네 영역과 여덟 분류 과제에서 RoBERTa를 영역 corpus로 더 사전 학습하는 DAPT, 과제의 비표지 text로 더 학습하는 TAPT를 비교했다. 두 단계가 후속 분류에 도움을 준 결과는 “일반 사전 학습 뒤에도 text distribution 적응이 가치 있다”는 근거다.

그러나 이 실험은 끝없이 들어오는 corpus stream에서 매 시점의 과거 능력을 보존하는 설정이 아니다. DAPT의 성과를 곧바로 지속적 사실 갱신이나 생산 model의 무중단 업데이트 증거로 바꾸지 않는다.

### 2022년 연구들은 서로 다른 지속성 단위를 측정했다

Jin 등은 domain-incremental 연구 논문 stream과 시간순 tweet stream에서 pretraining을 이어 가고, 매 단계 뒤 downstream fine-tuning 성능으로 새 자료 적응과 이전 영역 보존을 추적했다. 비교한 방법 가운데 distillation 계열이 이전 영역 성능 보존에 가장 효과적이라는 결과를 보고했지만, replay·EWC를 포함한 방법의 순위는 stream과 지표에 따라 같지 않았다.

Jang 등은 문장 분포보다 parameter 지식의 시간 변화를 전면에 놓았다. 불변 사실, 이미 바뀐 사실, 새 사실을 구분했고, 시험한 baseline에서는 parameter expansion이 학습과 보존을 함께 달성하는 데 필요하다는 결론을 냈다. 이는 모든 최신 사실이 model expansion만으로 해결된다는 법칙이 아니라 해당 benchmark와 baseline의 결과다.

Ke 등은 RoBERTa에서 비표지 영역 corpus를 순서대로 학습하고 이후 few-shot end-task에 쓰는 CPT를 제안했다. Domain ID가 주어지는 task-incremental 조건과 과거 영역 자료에 다시 접근하지 않는 조건을 사용했다. 따라서 이 결과를 domain ID가 없고 자료가 연속적으로 섞이는 production stream에 그대로 옮기려면 별도 검증이 필요하다.

### 2024년 대규모 실험이 확인한 것

Ibrahim 등은 learning rate를 새 단계에서 다시 높인 뒤 다시 낮추고, 이전 자료 일부를 replay하는 단순 조합을 검토했다. 405M model에서는 영어→영어와 영어→독일어 분포 이동을, 10B model에서는 더 약한 영어→영어 이동을 평가했다. 이 조건에서 최종 loss와 여러 LM benchmark 평균은 모든 이용 자료로 처음부터 다시 학습한 baseline에 맞먹으면서 계산량은 더 적었다.

이 결과는 “몇백억·몇천억 parameter production model을 몇 시간마다 안전하게 갱신한다”는 증거가 아니다. 가장 큰 실험은 10B이고 강한 영어→독일어 이동은 405M에서 시험했다. Match의 뜻도 특정 final loss와 benchmark 평균이며, 임의의 사실 교체·안전 정렬·모든 과거 능력의 동일 출력을 보장하지 않는다.

### PEFT와 운영 장치는 다른 비용 장부다

LoRA는 frozen base 옆의 작은 low-rank update를 학습해 optimizer state와 task별 추가 artifact를 줄일 수 있다. 하지만 지속 사전 학습에서 무엇을 replay할지, adapter를 누적·병합할 때 충돌을 어떻게 평가할지, base와 adapter 조합을 언제 다시 통합할지는 별도 문제다.

원 웹글의 update scheduling·A/B test·versioning·rollback은 실제 운영에 유용하다. 다만 이 장치들은 model update가 안전하다는 전제가 아니라 안전한지 시험하고 실패 시 되돌리는 통제다. Training compute, data curation, evaluation, serving storage와 rollback 가능성을 각각 기록해야 “작은 adapter”를 “전체 갱신 비용이 같은 비율로 감소했다”로 잘못 번역하지 않는다.

## 검증과 한계

### 원 웹글의 주요 정정

- **지속 사후 학습은 2025년에 등장했다:** DAPT·TAPT는 2020년, lifelong pretraining·continual knowledge learning·CPT는 2022년에 공개됐다.
- **전통적 fine-tuning은 갱신 자료 전체로 완전 재훈련해야 한다:** Fine-tuning은 기존 checkpoint에서 시작한다. 모든 pretraining data로 처음부터 학습하는 retraining과 다르다.
- **새 model을 훈련하는 동안 서비스 model을 사용할 수 없다:** 이전 version을 제공하면서 별도 checkpoint를 학습·평가할 수 있다. Availability는 배포 architecture의 문제다.
- **LoRA update를 누적하면 기존 지식을 보존한다:** 적은 parameter를 학습한다는 사실은 interference·망각·adapter merge의 안전성을 보장하지 않는다.
- **EWC·replay·별도 adapter가 현대 LLM의 표준 recipe다:** EWC의 원 실험은 LLM이 아니며, LLM 연구에서도 방법별 효과는 자료 순서·model·지표에 따라 달랐다.
- **Weight 갱신은 새 사실을 선택적으로 교체한다:** Corpus 적응은 분포 수준 학습이다. 오래된 사실 제거와 새 사실의 정확한 회상은 별도 지식 갱신 평가가 필요하다.
- **OpenAI·Anthropic·Google DeepMind 등의 production 채택이 확인됐다:** 원 웹글은 회사별 공개 training procedure·model version·비교 자료를 제시하지 않는다.
- **법률·의료·금융·뉴스에서 즉시 적용돼 최신성을 해결했다:** 가능한 사용 사례와 검증된 deployment를 구분해야 하며, 고위험 영역은 출처·시간·오류·회귀 평가가 더 필요하다.
- **비용·접근성·탄소 효과가 자동으로 개선된다:** Model size, token 수, replay 비율, hardware, 재평가·serving 비용과 전력 자료 없이는 정량 결론을 낼 수 없다.

### 용어와 적용 범위

Ke 등의 2022년 논문에서 post-training은 비표지 영역 corpus로 언어 모델 목적을 계속 학습하는 뜻이다. 오늘날 post-training은 SFT·선호 최적화·안전 정렬까지 넓게 가리키기도 한다. 같은 단어를 보고 같은 data와 loss를 썼다고 가정하지 말고, 비표지 corpus인지 지도 응답·선호 자료인지 확인해야 한다.

이 문서가 확인한 연구는 주로 RoBERTa 계열 또는 405M·10B autoregressive model과 연구용 stream이다. 수백억–수천억 parameter의 비공개 production model, 다국어 혼합 stream, 공격적 데이터 오염, 장기간 반복 update와 실제 사용자 feedback loop에는 결과를 그대로 일반화할 수 없다.

### 남는 연구 문제

새 자료가 이전 자료와 모순할 때 무엇을 보존하고 무엇을 교체할지 결정하려면 시간·출처 신뢰도와 질문 맥락이 필요하다. Replay는 과거 data 접근권을 전제하고, distillation은 이전 model의 오류까지 보존할 수 있다. Parameter 확장은 용량을 늘리지만 끝없는 확장의 routing·serving 비용을 만든다.

결국 지속 사전 학습의 성공은 “학습을 계속했다”가 아니라 **새 분포 적응, 이전 능력 보존, 지식 교정, 계산·자료 비용을 동시에 어떤 조건에서 달성했는가**로 판단해야 한다.

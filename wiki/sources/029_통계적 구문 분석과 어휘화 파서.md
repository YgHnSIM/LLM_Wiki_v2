# 통계적 구문 분석과 어휘화 파서

029 raw는 1997년 Michael Collins의 파서를 규칙 기반 구문 분석에서 확률 기반 구문 분석으로 넘어간 단일한 혁명으로 묘사하고, 그 성과를 자연어 이해·정보 추출·기계 번역·질의응답과 Transformer·BERT·GPT까지 곧바로 연결한다. 이 공개 문서는 그 서사를 **1970년대부터 축적된 확률 문법**, **1990년대의 트리뱅크와 공통 평가**, **Collins의 생성적 어휘화 모델**, **후대 응용과 신경망 파서**로 나누어 검증한다.

1997년 논문의 중요한 성과는 문법 규칙을 없앤 데 있지 않다. 사람이 정한 구성 성분 범주, 중심어 규칙과 문법 구조를 유지하면서, 어떤 구조를 선택할지에 필요한 확률을 [[말뭉치 기반 학습|주석 말뭉치]]에서 추정한 데 있다. 따라서 이 역사는 “규칙에서 확률로”라는 교체보다 **구조를 기술하는 규칙과 구조를 선택하는 통계가 결합된 과정**으로 읽는 편이 정확하다.

## 하나의 1997년 혁명이 아닌 누적된 전환

Collins의 1997년 논문은 통계 구문 분석의 출발점이 아니다. 논문 자체가 Booth와 Thompson의 1973년 확률 문법, Jelinek 등의 1994년 hidden derivation model, Magerman의 1995년 SPATTER, Collins 자신의 1996년 bigram lexical dependency parser를 선행 연구로 제시한다. Pereira와 Schabes도 1992년에 부분 괄호 말뭉치에서 확률 문법을 재추정하는 방법을 발표했다.

여기에 [[023_Penn Treebank와 통계적 구문 분석|Penn Treebank]]의 주석 자료와 PARSEVAL 평가 절차가 결합되면서 서로 다른 파서를 같은 학습·시험 자료와 정밀도·재현율로 비교할 수 있게 됐다. 이 인프라는 Collins 한 사람이나 1997년 한 논문이 만든 것이 아니다. Collins의 성과는 이미 형성된 연구 기반 위에서 어휘 정보, 하위범주화와 이동 제약을 하나의 생성 모델과 효율적인 차트 탐색에 결합하고, 강한 실험 결과로 그 접근을 정착시키는 데 기여한 것이다.

## PCFG가 학습하는 것

확률적 문맥 자유 문법(PCFG)은 [[문맥자유문법]]의 각 규칙 $A\rightarrow\beta$에, 같은 왼쪽 비단말 $A$에서 시작하는 규칙들 사이의 [[조건부 확률]]을 부여한다. 완전히 주석된 학습 트리에서 가장 단순한 최대우도 추정은 다음과 같다.

\[
\widehat P(A\rightarrow\beta)
=
\frac{c(A\rightarrow\beta)}
{\sum_{A\rightarrow\gamma\in R}c(A\rightarrow\gamma)}
\]

한 트리 $T$와 그 단어열 $w$의 결합 확률은 트리에 사용된 규칙들의 확률 곱으로 계산할 수 있다.

\[
P(T,w)=\prod_{r\in T}P(r)
\]

같은 문장에 여러 트리가 가능하면 파서는 문장을 산출할 수 있는 후보 가운데 확률이 가장 높은 트리를 고른다.

\[
\widehat T=\underset{T}{\operatorname{argmax}}\;P(T\mid w)
=\underset{T}{\operatorname{argmax}}\;P(T,w)
\]

두 번째 등식은 관측 문장 $w$가 모든 후보에서 같기 때문에 성립한다. 이 계산은 문법 규칙을 버리는 것이 아니라, 같은 규칙 집합이 허용하는 여러 분석에 순위를 부여한다.

기본 PCFG의 강한 독립 가정은 각 규칙 선택이 현재 왼쪽 비단말 $A$에만 조건화된다는 점이다. 어떤 단어가 구성 성분의 중심어인지, 그 성분의 조상이나 형제는 무엇인지, 앞서 어떤 보어를 생성했는지를 기본 상태만으로는 구분하지 못한다. 이는 언어가 실제로 독립이라는 주장이 아니라 계산과 추정을 가능하게 하기 위한 모델링 근사다.

기본 PCFG도 `NN → dog` 같은 어휘 방출 규칙을 포함할 수 있다. 따라서 PCFG를 “단어를 전혀 보지 않는 모델”이라고 정의하면 안 된다. Collins 모델과의 핵심 차이는 단어의 존재 여부가 아니라 **구조 선택 확률을 중심어와 더 풍부한 생성 이력에 조건화하는 방식**이다.

## Collins의 세 생성적 어휘화 모델

Collins는 각 구성 성분에 중심 비단말과 중심 단어를 붙이고, 부모 구성 성분에서 중심 자식을 선택한 뒤 중심에서 바깥쪽으로 왼쪽·오른쪽 수식어를 생성하는 과정을 모델링했다. 각 수식어는 자신의 비단말과 중심 단어를 가지며, 양쪽 생성은 `STOP` 결정으로 끝난다. 세 모델은 이 공통 골격에 서로 다른 구조 정보를 추가한다.

### Model 1: 중심어 주변의 수식어 생성

Model 1은 부모 범주와 중심어 조건에서 중심 자식을 고르고, 중심의 왼쪽과 오른쪽에 수식어를 차례로 생성한다. 단순 PCFG의 `VP → V NP PP` 한 번을 선택하는 대신, 중심 동사와 이미 생성된 이력을 보면서 다음 구성 성분과 그 중심어 또는 `STOP`을 선택한다. 어휘별 부착 선호를 반영할 수 있다는 것이 장점이지만, 어떤 수식어가 필수 보어이고 어떤 것이 선택적 부가어인지는 명시적으로 구분하지 않는다.

### Model 2: 보어와 부가어, 하위범주화

Model 2는 왼쪽과 오른쪽에 필요한 보어 목록인 하위범주화 틀을 추가한다. 보어가 생성되면 해당 요구가 목록에서 제거되고, 요구된 보어가 남아 있는 동안에는 그 방향의 `STOP` 전이가 허용되지 않는다. 반면 부가어는 필수 목록을 소진하지 않는다. 이 제약은 모든 희귀 사건을 0으로 만드는 일반적 평활화 규칙이 아니라, 모델이 허용하는 생성 이력을 문법적으로 제한하는 장치다.

### Model 3: wh-이동과 gap 상태

Model 3은 wh-구문에서 표면 위치와 해석 위치가 떨어지는 관계를 다루기 위해 gap 요구를 추가하고, 구성 성분을 따라 그 상태를 전달하거나 소비한다. 이는 완전한 의미 해석이나 일반적인 장거리 의존성 해결 장치가 아니라 Penn Treebank의 특정 이동 표기와 모델의 생성 과정에 맞춘 확장이다.

Model 2와 Model 3은 Model 1보다 구조 정보를 더 많이 사용하지만, 복잡성이 늘었다는 사실만으로 모든 문장이나 장르에서 반드시 더 낫다고 결론 내릴 수는 없다. 1997년 논문의 Table 2에서도 최종 집계 수치는 Model 2와 Model 3 사이에서 크게 갈리지 않는다.

## 최대우도 추정, 보간과 UNKNOWN

세분된 조건은 더 정확한 문맥을 표현하는 대신 같은 사건을 관측할 횟수를 줄인다. 중심 단어, 부모·자식 범주, 이전 수식어 거리, 하위범주화와 gap 상태를 모두 함께 세면 많은 조합이 드물거나 한 번도 나타나지 않는다. 이것이 [[데이터 희소성]] 문제다.

Collins는 관측 빈도에서 국소 확률을 추정하되, 자세한 조건의 추정치와 조건을 덜 사용한 백오프 추정치를 보간했다. 개념적으로는 다음처럼 쓸 수 있다.

\[
\widetilde P(e\mid h)
=\lambda(h)\widehat P(e\mid h)
+(1-\lambda(h))\widetilde P(e\mid h')
\]

$h$는 풍부한 이력, $h'$는 일부 조건을 제거한 이력이다. 자료가 충분한 문맥에서는 자세한 추정치를 더 신뢰하고, 희소한 문맥에서는 넓은 분포를 더 많이 섞는다. 이는 [[019_Katz 백오프와 희소 데이터 확률 추정|Katz 백오프]]와 목적을 공유하지만 할인·잔여 확률을 배분하는 식까지 같은 알고리즘은 아니다.

논문은 학습 자료에서 5회 미만 등장한 단어를 `UNKNOWN`으로 바꾸고, 학습에서 보지 못한 시험 단어도 같은 기호로 처리했다. 이 방법은 미등록어 때문에 전체 분석 확률이 즉시 0이 되는 일을 줄이지만, 서로 다른 희귀어의 구문 선호를 하나의 기호로 합치는 손실도 만든다.

평활화가 “문법적으로 상상 가능한 모든 규칙”에 자동으로 양의 확률을 주는 것은 아니다. 확률은 모델이 정의한 사건 공간과 백오프 경로 안에서만 재분배된다. Model 2에서 요구된 보어가 남아 있을 때 `STOP`을 금지하는 것처럼, 구조적 제약이 배제한 유도는 여전히 허용되지 않는다.

## CKY식 차트 탐색과 풍부한 상태

Collins 논문은 추론기를 “CKY-style dynamic-programming chart parser”로 설명한다. [[동적 계획법]]은 같은 부분 구문 분석을 여러 전체 후보가 공유할 때 그 계산을 차트에 저장하고 재사용한다. 그러나 이것을 기본 PCFG의 단순한 `[시작, 끝, 비단말]` CKY 항목과 동일시하면 안 된다.

어휘화 모델의 차트 항목에는 구간과 범주뿐 아니라 중심 단어·중심 위치, 구성 성분이 완성됐는지 여부가 필요하다. Model 2에서는 남은 하위범주화 요구, Model 3에서는 gap 상태까지 구분해야 한다. 서로 같은 구간과 범주를 덮더라도 이런 상태가 다르면 이후 결합 가능성과 확률이 달라지므로 별도 항목이다.

따라서 Collins의 파서는 CKY의 재사용 원리를 따르지만 상태 공간과 결합 조건이 더 풍부한 **CKY식 차트 파서**다. 이것을 “모든 단어 조합을 순서대로 전부 시도한다”거나 “표준 CKY만 실행한다”고 설명하는 것은 모두 부정확하다. 더 풍부한 상태는 언어적 조건을 보존하는 대신 메모리·탐색 비용을 높인다.

## 학습 자료와 1997년 결과

Collins는 Penn Treebank Wall Street Journal Sections 02–21의 약 4만 문장으로 모델을 학습하고, Section 23의 2,416문장으로 시험했다. 논문이 보고한 최종 구성 성분 정밀도는 88.1%, 재현율은 87.5%다. 이는 Collins의 1996년 파서보다 두 지표 평균으로 2.3점 개선된 결과로 제시됐다.

이 수치는 다음과 같이 한정해 읽어야 한다.

- 정밀도와 재현율은 예측 트리와 기준 트리의 레이블 괄호 일치를 측정한다. 문장의 의미를 이해했는지 직접 측정하지 않는다.
- 학습과 시험은 편집된 미국 비즈니스 뉴스인 WSJ에 집중돼 있다. 대화·웹·문학·전문 영역과 다른 언어의 성능을 보장하지 않는다.
- 논문은 Sections 02–21과 23을 명시하지만, 후대에 익숙한 Section 22 개발 집합 관행 전체를 이 논문에 소급해 적으면 안 된다.
- 88.1과 87.5는 각각 constituent precision과 recall이다. 이를 다른 길이 제한이나 평가 조건의 F1, 인간 주석자 일치도와 그대로 바꾸어 비교하지 않는다.

## 규칙과 확률은 대립항이 아니다

초기 광범위 문법은 적용 범위, 모호성 순위 결정과 유지 보수에 큰 비용이 들었다. 그러나 “규칙 기반 파서는 항상 같은 점수의 분석을 수십 개 내고 새로운 문장을 처리하지 못했다”는 식의 절대명제는 성립하지 않는다. 규칙 기반 시스템도 우선순위, 가중치, 의미·화용 제약, 결정적 선호와 부분 분석을 사용할 수 있었다. Penn Treebank 구축에 사용된 Fidditch도 하나의 분석을 제안하고 확신이 없는 구간은 부분 구조로 남겨 사람이 교정하게 했다.

Magerman이 1995년에 비교한 기존 IBM 시스템도 특정 IBM 매뉴얼 영역을 위해 오랫동안 개발된 “rule-based, unification-style probabilistic CFG”였다. 그 한 실험을 모든 상징 시스템과 모든 통계 시스템의 보편적 승패로 확대할 수 없다.

반대로 통계 파서 역시 규칙에서 자유롭지 않았다. Penn Treebank의 범주·주석 지침, 구성 성분 구조, 중심어를 정하는 head rules, 보어·부가어 구분과 gap 전파는 사람이 설계한 표현이다. 학습이 옮긴 것은 주로 **허용 구조 전체를 손으로 열거하는 부담**과 **후보 사이의 선호를 수작업으로 조율하는 부담**이다. 확률은 주어진 표현과 자료 안에서 선택을 학습한다.

이 때문에 “규칙 기반”과 “통계 기반”을 상호 배타적 시대 구분으로 쓰기보다 다음 세 층을 구분하는 편이 낫다.

1. 어떤 구조를 표현할지 정하는 문법·주석 설계
2. 구조별 점수나 확률을 자료에서 추정하는 학습
3. 가능한 후보를 효율적으로 찾는 탐색·동적 계획

Collins의 모델은 세 층을 모두 사용한다.

## NLU·정보 추출·기계 번역·질의응답의 후속 사용

통계 구문 분석은 여러 자연어 처리 시스템에 구조적 특징이나 후보 분석을 제공했다. 하지만 각 분야의 발전을 Collins 1997 한 논문이 직접 일으켰다고 쓰면 인과가 과장된다.

- **자연어 이해 인터페이스**: Miller 등은 1996년에 이미 통계 구문·의미·담화 모델을 결합한 자연어 인터페이스를 발표했다. 따라서 통계적 NLU의 시작을 Collins 1997 이후로 둘 수 없다.
- **정보 추출**: Miller 등의 2000년 시스템은 Collins 1996·1997과 유사한 어휘화 PCFG를 정보 추출 구조에 맞게 사용하고 MUC-7에서 평가했다. 이는 Collins 계열 아이디어가 실제 후속 과제에 채택된 직접 사례다.
- **기계 번역**: Yamada·Knight의 2001년 통사 기반 통계 번역은 영어 문장을 Collins 1999 파서로 분석한 트리에서 변환·재배열·단어 생성을 모델링했다. 특정 통사 기반 모델의 사례이지, 통계 기계 번역 전체가 구문 파서에 의존했다는 증거는 아니다.
- **질의응답**: Li 등의 2002년 연구는 질문과 후보 답의 의존 구조 사이 링크를 이용해 정확한 답을 추출했다. 예비 실험의 개선은 구조 정보가 유용할 수 있음을 보이지만 모든 QA 데이터와 시스템에 대한 보장은 아니다.

이 사례들의 공통점은 파서가 만든 구조를 후속 모델의 입력이나 특징으로 사용했다는 것이다. 파싱 오류는 아래 단계로 전달될 수 있고, 목표 영역의 문체가 WSJ와 다르면 별도의 주석·적응이 필요하다. “학습 자료만 바꾸면 쉽게 모든 분야에 적용된다”는 주장도 주석 비용과 영역 이동을 생략한다.

## 2003년 이후: 어휘화의 재평가와 신경망 파서

Klein·Manning의 2003년 파서는 단어 중심어에 의존하지 않고도 비단말 상태에 부모·구성 문맥을 세분해 높은 구성 성분 분석 성능을 얻을 수 있음을 보였다. 이는 Collins의 어휘화가 무의미했다는 뜻이 아니라, 당시 어휘화가 주던 이점 일부가 더 정교한 문법 상태 표현에서도 나올 수 있음을 보여 준다. “어휘화에서 신경망으로”라는 단선 계보보다 어떤 문맥을 상태와 특징에 담을 것인지에 대한 경쟁으로 보는 편이 정확하다.

2018년 Kitaev·Klein의 파서는 self-attention encoder로 문장 위치별 표현을 만들고, 레이블이 있는 구간 점수와 차트 디코딩을 결합했다. 여기서는 Transformer 계열의 표현 계산이 구성 성분 파서에 들어왔다. 1997년 생성 모델의 확률 분해나 중심어 기반 수식어 생성이 Transformer의 self-attention으로 변형된 것은 아니다.

2019년 Kitaev·Cao·Klein은 BERT 사전학습 표현을 self-attentive constituency parser에 결합했다. 같은 해 Hewitt·Manning의 구조 프로브는 BERT 표현의 기하에서 통사 거리와 깊이를 복원할 수 있는지 시험했다. 이 프로브 자체는 Penn Treebank 통사 감독으로 학습되므로, 결과는 BERT 안에서 구조가 **읽혀 나올 수 있음**을 보이는 증거이지 BERT가 명시적 파서를 실행하거나 그 구조를 사전학습 목표로 사용했다는 증거가 아니다.

## Transformer·BERT·GPT와의 비직접 계보

Transformer 원 논문은 기계 번역을 위해 recurrence를 self-attention으로 대체한 encoder–decoder를 제안했다. GPT는 다음 토큰을 예측하는 생성 사전학습 뒤 과제별 미세조정을 사용했고, BERT는 masked language modeling과 next sentence prediction으로 BooksCorpus·Wikipedia에서 사전학습했다. 세 원 논문의 핵심 훈련 절차에 Collins식 정답 구문 트리나 head-dependent 생성 과정은 들어가지 않는다.

통계 파서와 대규모 언어 모델은 말뭉치에서 매개변수를 학습하고 [[조건부 확률]]을 사용한다는 넓은 방법론을 공유한다. 그러나 확률을 두는 대상과 분해 방식은 다르다.

- Collins 모델은 문장과 어휘화 구문 트리의 생성 확률을 구조 결정들의 곱으로 분해한다.
- GPT 계열 언어 모델은 토큰열 확률을 앞 토큰들에 조건화된 다음 토큰 확률의 곱으로 분해한다.
- BERT의 원래 masked language modeling은 가려진 토큰을 양방향 문맥에서 복원한다.

따라서 “구문 분석에 확률을 썼으므로 Transformer와 GPT가 직접 탄생했다”는 설명은 너무 넓은 공통점을 기술 계보로 바꾼다. 확인 가능한 연결은 Penn Treebank 같은 감독 자료와 평가 관행이 후대 통사 연구에 계속 쓰였고, Transformer·BERT 표현이 2018–2019년 파서와 통사 프로브에 **역방향으로 도입됐다**는 것이다.

## 범위와 한계

- 모델의 중심어 규칙, 보어·부가어 분류, gap 표시는 사람의 언어학적 설계와 Penn Treebank 표기에 의존한다.
- 기본 PCFG의 국소 독립 가정은 실제 어휘·담화 문맥을 놓치며, 어휘화 모델의 세분화는 다시 희소성과 계산 비용을 키운다.
- `UNKNOWN` 처리는 미등록어 확률을 안정시키지만 서로 다른 희귀 단어의 정보를 합친다.
- WSJ에서 얻은 성능은 다른 장르·시대·언어로 자동 이전되지 않는다. 목표 영역 적응에는 자료와 주석 비용이 든다.
- 괄호 정밀도·재현율은 통사 구조 일치를 측정할 뿐 의미 이해, 사실성이나 실제 과제 효용을 직접 보장하지 않는다.
- 후속 NLU·IE·MT·QA 사례는 통사 구조의 가능한 효용을 보여 주지만 분야 전체의 보편적 인과나 일관된 성능 향상을 입증하지 않는다.
- BERT·GPT 표현에서 통사 정보가 복원될 수 있다는 결과와 명시적 파싱이 모든 downstream 과제에 필요하다는 주장은 서로 다르다.

## 검증 정정

- **1997년 통계 파싱 혁명**: 확률 문법, 부분 괄호 학습, 공통 평가와 강한 통계 파서는 1997년 이전부터 발전했다. Collins 논문은 중요한 통합과 성능 개선이지 단일한 출발점이 아니다.
- **규칙에서 확률로 완전 교체**: PCFG와 Collins 모델은 문법 범주·구조·중심어 규칙을 유지하고 그 선택 확률을 학습한다.
- **기본 PCFG는 단어를 보지 않음**: 어휘 방출 규칙을 포함할 수 있다. Collins의 차이는 중심어에 구조 선택을 조건화하는 데 있다.
- **평활화는 모든 규칙에 양의 확률을 부여**: 보간은 정의된 사건과 백오프 경로 안에서 희소한 추정을 보완하며 구조적으로 금지된 유도를 자동 허용하지 않는다.
- **일반 CKY만 사용**: Collins는 CKY식 동적 계획을 쓰지만 중심어·완결 여부와 모델별 하위범주화·gap 상태를 가진 더 풍부한 차트를 사용한다.
- **Penn Treebank 분할과 결과**: Sections 02–21 약 4만 문장 학습, Section 23의 2,416문장 시험이며 최종 구성 성분 정밀도 88.1%, 재현율 87.5%다.
- **통계 파서는 본 문장만 처리**: 문법과 생성 과정을 조합해 학습에서 보지 못한 전체 트리도 만들 수 있다. 다만 미등록어·희소 문맥과 영역 이동에는 약하다.
- **NLU·IE·MT·QA를 Collins 1997이 직접 탄생시킴**: 통계 NLU는 앞서 존재했고, 후대 문헌은 과제별 사용 사례를 보여 줄 뿐 분야 전체의 단일 인과를 증명하지 않는다.
- **Collins에서 Transformer·BERT·GPT로 직접 진화**: 원래 Transformer·GPT·BERT 훈련에는 Collins식 트리 생성 감독이 없다. 확인되는 후대 방향은 self-attention과 BERT 표현이 파서에 도입된 것이다.
- **구조 프로브는 BERT가 명시적으로 파싱한다는 증거**: 감독된 프로브가 구조를 복원할 수 있다는 결과이며 사전학습의 직접 목표나 인과 메커니즘을 증명하지 않는다.

## 핵심 문장

- 통계적 구문 분석은 규칙을 폐기한 것이 아니라 사람이 정의한 구조 후보 사이의 선호를 말뭉치에서 학습했다.
- Collins의 1997년 기여는 통계 파싱의 발명이 아니라 중심어 생성, 하위범주화와 gap 제약을 결합한 세 어휘화 모델과 그 실증이다.
- 기본 PCFG의 단순한 조건화는 추정을 쉽게 하지만 어휘·구조 문맥을 놓치고, 어휘화는 그 문맥을 늘리는 대신 희소성과 탐색 비용을 키운다.
- CKY식 동적 계획은 부분 분석을 재사용하지만 Collins 모델의 항목은 중심어와 모델별 구조 상태까지 보존한다.
- NLU·IE·MT·QA의 후속 사용과 Transformer·BERT 기반 파서는 확인할 수 있지만, 이를 Collins에서 현대 LLM으로 이어지는 단일 직접 계보로 만들 수는 없다.

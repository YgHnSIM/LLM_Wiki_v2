# 순환 신경망과 시간적 문맥 학습

026 raw는 1995년에 [[순환 신경망]](Recurrent Neural Network, RNN)이 등장해 기계에 기억을 부여하고 음성·언어 처리를 가능하게 했다고 서술한다. 이 공개 문서는 특정한 “1995년 RNN 혁명” 대신 1986년 Jordan의 순서 수행 구조, 1989년 순환망 학습, 1990년 Elman의 단순 순환망과 BPTT, 1994년 장기 의존성 분석과 음성 응용, 1995년 LSTM 기술보고서와 1997년 저널판으로 이어진 여러 갈래를 구분한다. 이 계보에서 분명해진 RNN의 실제 기여는 순서의 발견 자체가 아니라 **학습 가능한 연속 상태 전이를 시간마다 재사용해 가변 길이 이력을 압축한 것**으로 한정한다.

## 핵심 요약

가장 단순한 RNN은 현재 입력과 이전 은닉 상태를 결합해 새 은닉 상태를 만든다. 같은 상태 전이 매개변수를 모든 시간 위치에 공유하므로 입력 길이에 비례해 새로운 가중치를 만들지 않고도 서로 다른 길이의 순서열을 처리할 수 있다. 그러나 은닉 상태는 지금까지 본 모든 내용을 보존하는 저장 장치가 아니라 과제·데이터·손실에 맞춰 학습된 유한 차원 벡터다.

훈련할 때는 순환 구조를 관측한 시간 단계만큼 펼친 계산 그래프에 [[역전파|시간을 통한 역전파]](backpropagation through time, BPTT)를 적용할 수 있다. 같은 매개변수가 여러 시점에서 받은 그래디언트 기여를 합산하는 방식이다. 긴 시간축에서는 야코비안이 반복해서 곱해져 특정 방향의 그래디언트가 매우 작아지거나 커질 수 있고, 이는 [[기울기 소실]]·폭주 및 장거리 의존성 학습의 어려움으로 이어진다.

RNN 이전에도 n-gram, [[은닉 마르코프 모델]], 고정 문맥 창, [[시간 지연 신경망]]은 순서와 시간 정보를 다뤘다. 따라서 RNN이 음성 인식·언어 모델링·시계열 예측을 처음 가능하게 했다고 기록하지 않는다. HMM은 사람이 설계한 유한 이산 상태 공간 안에서 전이·방출 확률을 학습하고, 고정 문맥 창은 최근 입력 범위를 미리 정한다. RNN은 이와 달리 과제에 필요한 연속 문맥 표현과 비선형 상태 전이를 데이터에서 함께 학습하는 선택지를 넓혔다.

이 연표는 RNN에 유일한 발명자를 새로 배정하려는 것이 아니다. Jordan형 출력 되먹임, Elman형 은닉 상태 되먹임, RTRL과 BPTT 같은 학습 알고리즘은 구조와 목적이 서로 다르며, 오늘날 `RNN`이라는 이름은 이들 중 하나의 단일 논문보다 넓은 모델 계열을 가리킨다.

## 순환 상태와 시간축 매개변수 공유

단순한 Elman형 RNN은 현대 표기로 다음처럼 나타낼 수 있다.

\[
h_t=\phi(W_{xh}x_t+W_{hh}h_{t-1}+b_h)
\]

\[
o_t=g(W_{ho}h_t+b_o)
\]

$x_t$는 현재 입력, $h_{t-1}$는 이전 상태, $h_t$는 갱신된 상태, $o_t$는 선택적인 출력이다. $W_{xh}$·$W_{hh}$·$W_{ho}$는 모든 시점에서 같은 값이 사용된다. 입력 단어는 문자열 그대로가 아니라 보통 벡터로 표현되고, 출력 함수와 손실은 분류·회귀·다음 토큰 예측 등 과제에 따라 달라진다.

시간축 가중치 공유는 문장의 첫 위치와 마지막 위치에 서로 다른 모델을 두지 않고 같은 전이 규칙을 적용하게 한다. 한 위치에서 학습한 변환을 다른 위치에도 재사용할 수 있고 길이가 다른 순서열에도 같은 매개변수를 쓸 수 있다. 이 성질이 임의 길이의 모든 정보를 보존한다는 뜻은 아니다. 순서열 길이는 가변이어도 상태 차원, 계산 정밀도와 학습된 동역학은 유한하다.

RNN의 시간 단계에는 $h_t$가 $h_{t-1}$에 의존하는 데이터 의존성이 있다. 따라서 하나의 순서열 안에서 모든 시간 위치의 상태를 동시에 계산하기 어렵다. 그렇다고 RNN의 모든 계산이 직렬이라는 뜻은 아니다. 배치 안의 여러 순서열, 한 시점의 행렬 연산과 여러 은닉 단위는 병렬화할 수 있다.

## 펼치기와 시간을 통한 역전파

접힌 RNN 그림에는 순환 간선이 있지만 길이 $T$의 입력에 대해 펼치면 $h_0\rightarrow h_1\rightarrow\cdots\rightarrow h_T$로 이어지는 유한한 비순환 계산 그래프가 된다. 각 시점의 셀은 서로 다른 층처럼 그려지지만 실제로는 동일한 매개변수를 반복 사용한다.

BPTT는 이 펼친 그래프에 일반 [[역전파]]를 적용한다. 손실은 마지막 시점에만 둘 필요가 없으며, 여러 시점의 출력을 평가해 합할 수 있다. 공유 매개변수 $W_{hh}$의 그래디언트도 각 사용 시점의 기여를 합산한다. 전체 순서열을 모두 보관하고 미분하면 계산량과 중간 활성화 메모리가 길이에 따라 늘어난다. Williams·Peng의 1990년 방법처럼 제한된 시간 구간만 거슬러 가는 truncated BPTT는 계산을 줄이는 대신 잘린 구간보다 먼 직접 학습 신호를 생략하는 근사다.

Williams·Zipser의 RTRL 미분은 가중치를 고정한 궤적에 대해 시간 의존성을 자르지 않은 정확한 도함수를 전방으로 계산한다. 다만 그 값을 사용해 매 시점 가중치를 바꾸는 real-time 절차에서는 이후 상태 궤적도 달라지므로 전체 궤적 목적의 정확한 음의 그래디언트를 더는 따르지 않으며, 작은 학습률에서 가까운 근사가 된다. 이 방법은 큰 계산·저장 비용도 가진다. BPTT와 RTRL을 모두 “순환망의 역전파”라는 한 이름으로 합치면 정확성의 조건, 계산 방향과 비용 차이가 사라진다.

## 은닉 상태와 기억 비유의 범위

은닉 상태를 “기억”이라고 부르면 현재 예측에 과거 입력이 영향을 주는 직관을 전달하기 쉽다. 하지만 $h_t$는 입력 이력의 학습된 함수이지 앞선 토큰을 그대로 저장한 목록이 아니다. 상태 갱신 과정에서 정보가 유지·변형·소실될 수 있고, 무엇이 과제에 관련된 정보인지는 훈련 목표가 결정한다.

이 점은 세 가지 주장을 구분하게 한다.

- **표현 가능성**: 현재 상태가 먼 과거의 입력에 수학적으로 의존할 수 있다.
- **학습 가능성**: 최적화 과정이 그 먼 의존성을 실제 데이터에서 발견하고 가중치에 반영할 수 있다.
- **복원 가능성**: 상태만 보고 과거 입력 전체를 정확히 되살릴 수 있다.

첫 번째가 가능하다고 두 번째와 세 번째가 보장되지는 않는다. 또한 “고정 크기 상태 병목”은 특히 입력 전체를 마지막 상태 하나로 압축한 초기 RNN encoder–decoder에서 분명하게 드러났다. 모든 RNN 응용이 마지막 상태 하나만 쓰는 것은 아니며, 시점별 출력을 유지하거나 외부 메모리·attention을 결합하는 설계도 있다.

## 장기 의존성과 기울기 소실·폭주

먼 시점 $k$의 상태가 현재 시점 $t$에 미치는 미분에는 다음과 같은 국소 야코비안의 연속 곱이 들어간다.

\[
\frac{\partial h_t}{\partial h_k}
=
\frac{\partial h_t}{\partial h_{t-1}}
\frac{\partial h_{t-1}}{\partial h_{t-2}}
\cdots
\frac{\partial h_{k+1}}{\partial h_k}
\]

관련 방향의 크기가 반복해서 줄면 그래디언트가 소실되고, 반복해서 커지면 폭주할 수 있다. raw는 가중치 행렬의 고윳값이 1보다 작은지 큰지로 이를 설명하지만, 비선형 RNN에서는 활성화 함수의 시점별 도함수, 실제 상태 궤적, 행렬의 방향별 증폭과 비정규성까지 포함한 전체 야코비안 곱이 중요하다.

Bengio·Simard·Frasconi의 1994년 연구는 긴 시간 간격의 의존성과 효율적인 그래디언트 학습 사이의 난점을 분석했다. Pascanu·Mikolov·Bengio는 2013년에 이 문제를 기하·동역학 관점에서 다시 설명하고 폭주에 대한 노름 기반 gradient clipping을 제시했다. clipping은 너무 큰 갱신을 제한할 수 있지만 이미 사라진 장거리 학습 신호를 복원하지는 않는다. 특정 clipping 변형 하나를 모든 딥러닝 모델의 필수 표준이나 유일한 발명 시점으로도 기록하지 않는다.

## 응용 시기의 실제 범위

RNN은 음성 인식, 언어 모델링, 순서열 표지, 필기 인식과 시계열 예측에 사용됐다. 그러나 raw가 말하는 “1995년에 실용적 RNN이 등장해 이전에는 불가능했던 응용이 열렸다”는 문장은 과제별 연대와 증거를 지운다.

Robinson의 1994년 연구는 RNN으로 음향 프레임에서 음소 사후확률을 추정하고 이를 Markov 모델 기반 인식기에 결합했다. 이는 1995년 이전의 실제 음성 응용이지만, RNN이 HMM과 신호 전처리를 없앤 종단간 시스템은 아니었다. 논문도 전통적 방법과 **경쟁력 있는** 결과라고 한정하므로 모든 음성 자료에서의 보편적 최고 성능으로 확대하지 않는다.

Elman의 1990년 실험은 문자열 예측과 단어의 통사·의미 범주가 은닉 상태에 형성되는지를 탐구했다. 이는 학습된 문맥 상태의 가능성을 보여 주지만 현대적 대규모 언어 모델이나 실제 서비스 성능을 입증한 실험은 아니다. raw가 열거한 품사 태깅·필기·금융·기후 응용도 각 논문, 데이터, 기준선과 발표 시기를 따로 확인해야 하며 1995년 하나의 결과로 묶지 않는다.

Robinson의 음성 시스템은 사람이 설계한 음향 전처리와 Markov 디코더를 사용했고, Elman의 실험은 연구자가 구성한 문자·단어 순서 과제를 사용했다. 이런 사례에서 순환 상태를 데이터로 학습했다는 사실을 모든 특징 공학·과제 설계·후처리가 사라졌다는 뜻으로 바꾸지 않는다. 다른 초기 RNN 응용의 전처리와 디코더 구성은 각 논문별로 확인해야 한다.

## LSTM·GRU·attention·Transformer의 관계

LSTM과 GRU는 recurrent state를 유지하면서 갱신 경로를 게이트로 조절하는 RNN 변형이다. Hochreiter·Schmidhuber의 1997년 LSTM은 constant error carousel과 입력·출력 게이트를 사용해 긴 시간 간격의 인공 과제를 다뤘다. 오늘날 표준 설명에 포함되는 adaptive forget gate는 Gers·Schmidhuber·Cummins의 2000년 논문에서 추가됐다. LSTM이 장거리 오류 흐름을 개선했다는 사실과 모든 데이터에서 소실·폭주를 제거한다는 보장은 다르다.

Cho 등의 2014년 RNN encoder–decoder는 reset·update gate를 가진 새로운 은닉 단위를 제시했다. 후대에 GRU라고 불린 이 구조는 LSTM보다 단순한 recurrent update의 대안이다. 같은 해 Sutskever·Vinyals·Le의 sequence-to-sequence 모델은 LSTM encoder가 입력을 고정 길이 벡터로 읽고 LSTM decoder가 출력 순서열을 생성하게 했다. 이것은 RNN에서 [[신경망 기계 번역]]으로 이어지는 확인 가능한 직접 응용 계보다.

Bahdanau·Cho·Bengio의 attention은 출력 시점마다 입력 위치별 은닉 표현을 가중 결합해 고정 벡터 병목을 완화했다. 2017년 Transformer는 이 RNN 상태 갱신을 그대로 보존한 구조가 아니라, 핵심 encoder·decoder 연산에서 recurrence와 convolution을 제거하고 self-attention과 위치 표현을 사용했다. 학습 시 위치별 표현을 병렬 계산하기 쉬워졌지만 attention의 비용은 순서열 길이에 따라 제곱으로 늘 수 있고, 자기회귀 생성은 이전 출력에 의존해 여전히 토큰 단위로 진행된다.

GPT와 BERT는 Transformer 계열이며 RNN식 단일 은닉 상태 갱신을 사용하지 않는다. GPT의 causal language modeling은 RNN 언어 모델과 자기회귀 조건부 확률 분해를 공유할 수 있지만, BERT의 masked language modeling은 양쪽 문맥을 사용한다. 공통으로 문맥을 다룬다는 문제 수준의 연결과 RNN 계산의 직접 상속을 구분한다.

## 검증 정정

- Jordan의 1986년 구조, Williams·Zipser의 1989년 학습 연구, Elman과 Werbos의 1990년 논문이 있으므로 1995년을 RNN의 발명·실용화·훈련법 확립 시점으로 삼지 않는다.
- LSTM은 1995년 8월 기술보고서로 공개됐고 저널 원고가 같은 달 접수됐으며, 동료 심사 저널판은 1997년에 출판됐다.
- 일반 순방향 MLP에는 지속 상태가 없지만 n-gram·HMM·TDNN과 고정 문맥 창 모델은 RNN 이전에도 순서 정보를 처리했다.
- raw의 상태식은 RNN 계열 전체의 유일한 정의가 아니라 단순 Elman형 은닉 상태 되먹임에 가까운 한 형태다.
- 은닉 상태는 과거 전체의 완전한 기억이나 이해를 보장하지 않고, 입력 이력의 과제 의존적 압축 표현이다.
- BPTT의 손실은 마지막 시점에만 있을 필요가 없으며 공유 매개변수의 그래디언트는 관련 시점들의 기여를 합산한다.
- 그래디언트 소실·폭주는 가중치 고윳값 하나가 아니라 비선형 활성화를 포함한 시간별 야코비안 곱에 달려 있다.
- gradient clipping은 폭주를 관리하지만 소실을 복원하지 않으며, 단일 논문의 독점적 발명으로 기록하지 않는다.
- 고정 길이 병목은 특히 마지막 encoder state 하나에 입력을 압축한 초기 sequence-to-sequence 설정의 문제다. 모든 RNN이 같은 입출력 구조를 쓰지는 않는다.
- 음성·언어·필기·시계열은 RNN 이전부터 존재한 과제이며, 1995년에 한꺼번에 가능해졌다는 응용 서사를 채택하지 않는다.
- LSTM·GRU는 순환 구조의 변형이지만 Transformer는 핵심 연산에서 recurrence를 제거했다. GPT·BERT를 1995년 RNN의 직접 후손으로 두지 않는다.

## 핵심 문장

- RNN은 현재 입력과 이전 상태로 새 상태를 계산하고 같은 전이 매개변수를 시간마다 공유한다.
- 은닉 상태는 과거 전체의 저장본이 아니라 과제 손실에 맞춰 학습된 유한 차원 압축 표현이다.
- BPTT는 펼친 시간축에 역전파를 적용하고 공유 매개변수가 여러 시점에서 받은 그래디언트를 합한다.
- 긴 시간축의 학습 난점은 반복되는 야코비안 곱과 방향별 증폭·감쇠에서 발생한다.
- 학습 가능한 순서 처리 RNN의 이 계보는 1995년 한 사건이 아니라 1980년대 중반부터 구조·학습·응용·한계 분석이 누적된 과정이다.
- LSTM·GRU와 RNN encoder–decoder는 직접적인 순환 구조 계보가 있지만 Transformer·GPT·BERT는 RNN 상태 갱신을 사용하지 않는다.

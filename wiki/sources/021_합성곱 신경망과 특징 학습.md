# 합성곱 신경망과 특징 학습

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[concept.역전파|역전파]], [[concept.특징-공학|특징 공학]]<br>
> **읽고 나면:** CNN이 국소 연결과 가중치 공유로 특징을 학습하는 방식, 이동 등변성과 불변성의 차이, 주요 역사적 이정표를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 이 문서의 범위

원문은 [[합성곱 신경망]]을 1988년 [[얀 르쿤]] 한 사람이 벨 연구소에서 도입한 발명으로 소개하고, 자동 특징 학습에서 Word2Vec·GloVe·어텐션·Transformer까지 이어지는 직접 계보를 제시한다. 이 공개 문서는 1차 문헌을 기준으로 국소 연결과 공유 가중치의 실제 계산, 이동 등변성과 불변성의 차이, 손글씨 인식의 연대와 과업 범위, 시각 합성곱을 언어에 직접 적용한 연구와 별도 NLP 계보를 구분한다. raw의 중복·훼손된 수식 문자열은 보존 자료의 상태로 남기고 공개 계산식에는 사용하지 않았다.

### 핵심 요약

합성곱 신경망은 입력 전체를 한꺼번에 완전 연결하는 대신 작은 국소 영역을 보고, 같은 커널 가중치를 여러 공간 위치에서 재사용하는 순방향 신경망이다. 이 두 제약은 이미지의 가까운 픽셀이 관련되고 같은 패턴이 여러 위치에 나타난다는 귀납 편향을 아키텍처에 넣는다. 여러 층을 쌓으면 저수준의 국소 반응을 더 넓은 수용 영역의 표현으로 조합할 수 있고, [[역전파]]로 커널과 분류기를 함께 학습할 수 있다.

같은 검출기를 여러 위치에서 재사용하면 입력 위치가 조금 달라져도 비슷한 패턴을 찾기 쉽다. 다만 공유 가중치만으로 최종 예측이 모든 위치 변화에서 같아지는 것은 아니며, 풀링과 학습 설계도 함께 작용한다.

역사적으로는 1980년 네오코그니트론, 1986년 오차 역전파의 재소개, 1987년 시간축 공유 가중치를 학습한 TDNN, 1989년 르쿤 등 일곱 명이 수행한 우편번호 숫자 연구를 구분해야 한다. 1998년 논문은 LeNet-5와 문서·수표 판독 체계를 종합했고, 2012년 ImageNet 연구는 대규모 데이터와 GPU로 훨씬 큰 CNN의 성능을 보여 준 별도 전환점이다.

### 핵심 문장

- CNN의 핵심은 국소 연결, 위치별 가중치 공유, 계층적 표현 학습이라는 구조적 제약이다.
- 1980년 네오코그니트론, 1987년 TDNN, 1989년 벨 연구소의 일곱 저자, 1998년 LeNet-5, 2012년 ImageNet CNN은 하나의 1988년 사건이 아니다.
- 자동 특징 학습의 중요성은 특징 공학과 사람의 설계가 완전히 사라졌다고 과장하지 않아도 설명할 수 있다.
- 텍스트 CNN의 직접 응용과 임베딩·순환 seq2seq·어텐션·Transformer의 별도 계보를 구분해야 현대 LLM과의 관계가 정확해진다.

## 2단계 — 작동 원리

### 처리 흐름

CNN은 작은 커널을 입력의 여러 위치에 적용해 국소 특징 지도를 만든다. 여러 층을 쌓으면 수용 영역이 넓어지고 특징이 조합되며, 풀링이나 전역 집계가 위치별 증거를 요약해 최종 예측으로 보낸다.

## 3단계 — 기술과 근거

### 네오코그니트론에서 ImageNet까지

Hubel과 Wiesel의 1962년 시각 피질 연구는 국소 수용 영역과 단순·복합 세포의 반응을 기록했다. 이 생물학적 관찰은 후대 계층 시각 모델의 중요한 배경이지만, 그 논문이 현대 CNN의 가중치 공유나 역전파를 제안한 것은 아니다. 생물학적 유사성과 공학적 아키텍처의 동일성을 전제하지 않는다.

| 연도 | 문헌과 모델 | 확인되는 기여와 경계 |
| --- | --- | --- |
| 1980 | Kunihiko Fukushima의 네오코그니트론 | 국소 수용 영역을 가진 S-cell과 위치 변화에 강건한 C-cell을 계층적으로 쌓은 자기조직화 모델이다. 현대 CNN과 구조적 선행 관계가 있지만 오차 역전파로 전체를 공동 학습한 모델은 아니다. |

| 1987 | Waibel 등 다섯 저자의 [[시간 지연 신경망]] | 시간축의 국소 창과 공유 가중치를 역전파로 학습한 기술 보고서다. 공간 CNN과 가까운 합성곱적 선행 사례지만 이미지 CNN을 이 보고서 하나의 단순한 2차원 확장으로 환원하지 않는다. |
| 1989 | LeCun 등 일곱 저자의 우편번호 논문 | AT&T Bell Laboratories 소속 연구진이 국소 수용 영역, 공간 공유 가중치, 서브샘플링을 과업 제약으로 넣고 정규화된 손글씨 숫자를 역전파로 분류했다. |
| 1998 | LeCun·Bottou·Bengio·Haffner의 문서 인식 논문 | LeNet-5 구조와 고립 문자 실험, 문서·수표 판독을 위한 더 큰 시스템을 한 논문에서 구분해 설명했다. |
| 2012 | Krizhevsky·Sutskever·Hinton의 ImageNet CNN | 약 120만 장·1,000개 범주, 다섯 합성곱층과 세 완전 연결층, 약 6천만 매개변수와 GPU 훈련으로 대규모 시각 분류의 전환을 보였다. |

이 표는 한 사람이 한 해에 완성한 단일 발명보다 국소 수용 영역, 계층 처리, 가중치 공유, 역전파 학습, 대규모 계산이 단계적으로 결합된 역사를 보여 준다. 네오코그니트론과 TDNN은 선행 맥락이고 르쿤 연구진의 1989년 논문은 공간 공유 가중치를 실용 손글씨 과제에 적용한 핵심 문헌이며, LeNet-5와 ImageNet CNN은 서로 다른 시기의 후속 구조다.

### 1988년 주장과 우편번호·수표를 분리하기

원문은 1988년을 CNN 도입 시점으로 제시하지만, 현재 등록된 1차 문헌에서 직접 확인되는 대표 공동 논문은 1989년 Neural Computation에 실린 Backpropagation Applied to Handwritten Zip Code Recognition이다. 저자는 Yann LeCun·Bernhard Boser·John S. Denker·Donnie Henderson·Richard E. Howard·Wayne Hubbard·Lawrence D. Jackel의 일곱 명이다. 따라서 별도 1차 근거 없이 1988년을 르쿤 한 사람의 단독 발명이나 논문 출판 연도로 기록하지 않는다.

1989년 연구의 입력은 미국 우편번호에서 얻은 크기 정규화된 고립 숫자 이미지였다. 우편물 전체에서 주소를 찾고 숫자를 분할하는 종단 간 우편 분류 시스템도, 은행 수표를 판독하는 실험도 아니었다. 수표 판독 체계와 상용 배치 기록은 1998년 문서 인식 논문에서 그래프 변환 네트워크와 합성곱 문자 인식기를 결합한 별도 시스템으로 다뤄졌다. 같은 연구 계열이라는 이유로 1989년 우편번호 숫자 분류, 1998년 LeNet-5, 수표 판독 배치를 하나의 1988년 시스템으로 합치지 않는다.

LeNet-5 역시 1988년 모델명이 아니다. 1998년 논문은 입력을 제외하고 학습 매개변수가 있는 일곱 층의 LeNet-5를 Fig. 2에 제시한다. C1·C3 합성곱층과 S2·S4 서브샘플링층을 거친 C5는 해당 입력 크기에서는 공간 크기가 $1\times1$이므로 완전 연결처럼 작동한다. 초기 CNN을 근거 없이 1988년의 서너 개 합성곱층이라고 고정하거나, LeNet-5를 그때 이미 완성된 단일 구조로 소급하지 않는다.

### 국소 연결, 공유 가중치와 매개변수 수

입력 $X$의 채널 수를 $C_{in}$, 출력 특징 맵 수를 $C_{out}$, 커널의 높이와 너비를 $K_h,K_w$라고 하자. 출력 위치 $(i,j)$와 출력 채널 $o$의 국소 계산은 다음처럼 쓸 수 있다.

\[
Y_{i,j,o}
=
b_o+
\sum_{c=1}^{C_{in}}
\sum_{u=0}^{K_h-1}
\sum_{v=0}^{K_w-1}
W_{o,c,u,v}X_{c,i+u,j+v}
\]

국소 연결은 $Y_{i,j,o}$가 입력 전체가 아니라 $K_h\times K_w$ 이웃만 보게 한다. 가중치 공유는 모든 공간 위치 $(i,j)$에서 같은 $W_{o,c,u,v}$를 사용한다. 따라서 입력 높이와 너비가 커져도 한 합성곱층의 기본 매개변수 수는 공간 위치 수에 비례하지 않고, 편향을 포함하면 $K_hK_wC_{in}C_{out}+C_{out}$이다.

원문의 3×3 필터는 매개변수가 아홉 개라는 설명은 입력 채널 하나와 출력 필터 하나에서 편향을 제외한 경우에만 맞다. RGB 입력에서 출력 특징 맵이 64개라면 같은 3×3 층도 편향을 포함해 $3\times3\times3\times64+64$개의 매개변수를 갖는다. 반대로 256×256 흑백 이미지를 1,000개 유닛에 완전 연결하면 가중치만 $256\times256\times1{,}000=65{,}536{,}000$개이고 편향 1,000개가 더해진다. CNN의 절감 효과는 입력 크기와 무관하게 언제나 아홉 개라는 뜻이 아니라 국소성과 위치 공유에서 나온다.

### 원문의 공식은 교차상관이다

위 식은 커널 인덱스 $(u,v)$를 뒤집지 않고 입력의 같은 방향 이웃과 곱한다. 엄밀한 신호 처리 용어로는 이산 합성곱이 아니라 교차상관(cross-correlation)이다. 참된 이산 합성곱은 공간축에서 커널 방향을 반전해 대응시키는 정의를 쓴다.

학습되는 신경망 커널에서는 이 명칭 차이가 보통 표현 능력을 바꾸지 않는다. 필요한 반전 값을 훈련 과정에서 그대로 배울 수 있기 때문이다. 그래서 딥러닝 문헌은 교차상관 형태의 층도 관례적으로 합성곱층이라고 부른다. 원문의 계산 절차는 CNN의 일반적인 전방 계산을 나타내지만, 이를 신호 처리의 엄밀한 합성곱 정의와 같은 식이라고 설명하지 않는다. 원문에 세 번 중복되고 표시가 훼손된 수식은 이 공개 식으로 복원했다.

- 딥러닝에서 합성곱층이라 부르는 일반적 전방 계산은 수학적으로 교차상관이며, 채널을 포함한 매개변수 수를 계산해야 한다.

### 이동 등변성, 불변성과 앨리어싱

이상적인 경계 조건에서 보폭 1의 공유 합성곱을 $C$, 입력의 정수 이동을 $T_\delta$라고 하면 $C(T_\delta X)=T_\delta C(X)$로 쓸 수 있다. 입력이 이동하면 특징 맵도 대응해 이동한다는 이동 등변성이다. 최종 분류기 $g$가 $g(T_\delta X)=g(X)$를 만족하는 이동 불변성과는 다른 성질이다.

최대·평균 풀링은 국소 영역을 요약해 해상도와 계산량을 줄이고 작은 위치 변화에 대한 허용도를 높일 수 있다. 그러나 보폭을 둔 풀링과 합성곱은 샘플을 건너뛰므로 입력 이동과 표본 격자가 어긋날 때 앨리어싱이 생길 수 있다. Zhang의 2019년 실험은 현대 CNN도 작은 입력 이동에 출력이 크게 달라질 수 있고, 다운샘플링 전 저역 통과 필터를 넣으면 이동 안정성을 높일 수 있음을 보였다. 따라서 풀링이 완전한 불변성을 자동 보장한다거나 항상 같은 출력을 만든다고 쓰지 않는다.

전역 평균 풀링, 적절한 패딩과 안티앨리어싱, 데이터 증강과 과제별 학습은 위치 변화에 대한 분류 안정성을 보완할 수 있다. 하지만 기본 CNN은 회전과 크기 변화에 본질적으로 불변하지 않으며, 이동에 대해서도 경계·보폭·패딩 조건을 따져야 한다. 풀링이 과적합을 줄일 수 있다는 경험적 효과와 불변성을 수학적으로 보장한다는 주장은 분리한다.

그러나 공유 가중치가 직접 보장하는 성질은 입력이 이동하면 특징 맵도 이동하는 등변성(equivariance)이지 최종 분류값이 언제나 같아지는 불변성(invariance)이 아니다. 풀링과 다운샘플링은 해상도를 줄이고 작은 위치 변화에 대한 허용도를 높일 수 있지만, 표본 격자와 어긋난 이동에서는 앨리어싱 때문에 오히려 등변성을 깨뜨릴 수 있다. 회전·크기 변화에 대한 불변성도 기본 합성곱만으로 자동 보장되지 않는다.

- 합성곱 특징은 이동 등변적일 수 있지만 최종 불변성은 풀링·전역 집계·안티앨리어싱·데이터와 학습 설계를 함께 따져야 한다.

### 특징 학습이 남긴 것과 없애지 않은 것

CNN의 중요한 공헌은 사람이 각 커널의 값을 직접 정하는 대신 분류 목적 함수에서 필터와 분류기를 함께 학습한 것이다. 이는 [[특징 공학]]의 상당 부분을 학습 가능한 표현으로 옮겼고, 같은 국소 검출기를 여러 위치에서 재사용하게 했다. 그러나 데이터 수집과 레이블, 입력 정규화, 분할, 커널 크기, 채널 수, 패딩, 보폭, 깊이, 손실과 평가 기준은 여전히 사람이 정한다.

1989년 우편번호 논문도 크기가 정규화된 고립 숫자 이미지를 사용했고, 1998년 LeNet-5 실험은 중심 정렬과 크기 정규화된 입력 및 인위적 변형을 사용했다. 따라서 원시 우편물이나 수표 영상에서 모든 전처리와 과업 정의를 사람의 개입 없이 발견한 시스템이 아니다. 자동 특징 학습은 특징 공학의 경계를 이동시켰지 데이터·아키텍처·평가 설계를 제거하지 않았다.

원문은 Local Binary Pattern(LBP)을 CNN 이전의 수작업 특징 예로 묶지만, Ojala·Pietikäinen·Harwood의 해당 질감 측정 논문은 1994년으로 1989년 CNN 논문보다 뒤다. LBP는 수작업 질감 기술자의 유용한 사례이지만 CNN 이전 시대만을 대표하는 연대 근거는 아니다. 수작업 특징과 학습 특징은 어느 날 한 번에 교체된 것이 아니라 오랫동안 공존했다.

### 초기 깊이의 한계, BatchNorm과 ResNet

초기 CNN이 오늘날보다 작았던 것은 사실이지만 단일한 1988년 표준 구조나 서너 개 합성곱층이라는 수치는 확인되지 않는다. 당시에는 계산 자원, 데이터 규모, 활성화 함수, 초기화와 최적화 방법이 함께 제약으로 작용했다. [[기울기 소실]]은 깊은 포화 비선형망의 중요한 문제지만 초기 CNN의 규모를 설명하는 유일한 원인으로 환원하지 않는다.

2012년 ImageNet 논문은 다섯 합성곱층과 세 완전 연결층, 약 6천만 매개변수를 두 GPU에서 학습하고 대규모 분류에서 큰 성능 차이를 보고했다. 이 결과는 1989년의 고립 숫자 인식과 데이터·과업·계산 규모가 다르다. 원문이 말하는 CNN의 현대적 시각 혁명은 1988년 한 사건보다 2012년의 대규모 ImageNet 결과를 별도 전환점으로 포함해야 정확하다. 1989년 논문에는 얼굴·사물 전반의 인간 수준 정확도 비교가 없었다.

Ioffe와 Szegedy의 2015년 Batch Normalization은 미니배치 통계로 층 입력을 정규화해 더 큰 학습률과 초기화 민감도 완화를 보고했고, 그래디언트 흐름에도 유리한 효과를 기술했다. He 등의 2016년 ResNet은 항등 지름길을 통해 잔차 함수를 학습하게 하여 더 깊은 평범한 망에서 나타난 최적화의 degradation 문제를 완화했다. 두 연구는 깊은 망 훈련에 중요한 진전이지만, BatchNorm과 잔차 연결이 [[기울기 소실]] 하나를 동일한 방식으로 해결했다고 합치지 않는다.

### 시각 합성곱에서 언어 모델로

합성곱을 언어에 직접 적용한 계보는 분명히 존재한다. Collobert 등의 2011년 문장 접근법은 단어 표현의 연속 창에 같은 가중치를 적용하고 문장 전체에서 최대값을 취해 의미역 표지용 고정 길이 표현을 만들었다. Kim의 2014년 문장 분류 CNN은 여러 너비의 단어 임베딩 필터와 max-over-time pooling을 사용했고, Zhang·Zhao·LeCun의 2015년 연구는 고정 알파벳으로 부호화한 문자 열에 시간 합성곱을 적용해 대규모 텍스트 분류를 실험했다. 이것들은 이미지의 국소 공유 연산을 순서축에 옮긴 직접 응용이다.

다만 문자 CNN 한 연구가 철자 오류, 모든 희귀어와 여러 문자 체계를 보편적으로 해결했다고 일반화하지 않는다. 2015년 논문은 고정 문자표를 사용했고 중국어 자료에는 Jieba 분절과 pinyin 변환을 적용했다. 직접 평가한 것은 이렇게 구성한 대규모 텍스트 분류 데이터셋에서 문자 수준 CNN과 여러 기준 모델을 비교한 결과다. 언어·문자 집합·전처리·과업·훈련 데이터가 바뀌면 별도 검증이 필요하다.

Word2Vec은 CBOW와 Skip-gram 예측 과제로 단어 벡터를 학습했고, GloVe는 전역 단어 동시 출현 통계의 가중 회귀 목적을 사용했다. 두 모델은 표현 학습이라는 넓은 목표는 공유하지만 CNN의 국소 필터와 풀링에서 파생된 구조가 아니다. Sutskever·Vinyals·Le의 2014년 seq2seq는 다층 LSTM 인코더와 디코더를 사용했고, Bahdanau·Cho·Bengio의 어텐션은 고정 길이 벡터 병목을 줄이기 위해 RNN 인코더 위치를 디코딩 시점마다 내용 기반으로 가중했다.

Vaswani 등의 2017년 Transformer는 순환과 합성곱을 모두 제거하고 쿼리·키·값의 자기어텐션을 중심 연산으로 삼았다. 합성곱 필터는 훈련 뒤 모든 입력 위치에 같은 값을 적용하지만 어텐션 가중치는 현재 입력 내용에 따라 위치 쌍마다 다시 계산된다. Transformer의 위치별 피드포워드층을 커널 크기 1의 합성곱과 동등하게 표현할 수 있어도 어텐션 자체가 CNN 필터의 직접 발전형이 되는 것은 아니다. 현대 [[대규모 언어 모델]]이 표현 학습·층 쌓기·매개변수 공유라는 넓은 신경망 원리를 공유한다는 사실과 CNN에서 어텐션이 직접 유래했다는 역사 주장을 구분한다.

## 검증과 한계

### 검증 정정

- raw가 제시한 1988년은 현재 등록된 1차 논문의 출판 연도가 아니다. 직접 확인되는 대표 우편번호 논문은 일곱 저자의 1989년 출판물이며 단독 발명 논문이 아니다.
- 1989년 과제는 정규화된 고립 우편번호 숫자 분류다. 수표 판독 시스템과 LeNet-5를 하나의 1988년 과업으로 합치지 않는다.
- LeNet-5는 1998년 문서 인식 논문에 명시된 일곱 학습 층의 구조다. 초기 CNN 전체를 1988년의 서너 개 합성곱층으로 고정하지 않는다.
- 2012년 ImageNet CNN은 대규모 데이터·GPU·다섯 합성곱층을 사용한 별도 전환점이다. 1989년 결과를 얼굴·사물 전반의 인간 수준 정확도로 확대하지 않는다.
- 원문 식은 커널을 뒤집지 않는 교차상관이다. 학습 커널에서는 표현력이 같아 관례적으로 합성곱층이라 부르지만 수학적 정의는 구분한다.
- 3×3 필터의 가중치가 아홉 개라는 설명은 단일 입력 채널·출력 필터 하나·편향 제외 조건이다. 일반 매개변수 수는 $K_hK_wC_{in}C_{out}+C_{out}$이다.
- 공유 가중치는 우선 이동 등변성을 만든다. 풀링과 다운샘플링은 완전한 이동 불변성을 보장하지 않으며 앨리어싱으로 작은 이동에 민감해질 수도 있다.
- CNN은 학습 특징의 범위를 넓혔지만 입력 정규화·분할·데이터 증강·아키텍처·목적 함수와 평가 설계를 없애지 않았다.
- 1994년 LBP를 1989년 CNN 이전의 특징 공학으로 소급하지 않는다.
- BatchNorm과 ResNet은 깊은 망의 훈련과 최적화를 서로 다른 방식으로 개선했다. 둘을 단순히 기울기 소실 하나의 해결책으로 합치지 않는다.
- 텍스트·문자 CNN은 합성곱의 직접 언어 응용이다. Word2Vec·GloVe·LSTM seq2seq·내용 기반 어텐션·Transformer는 핵심 연산과 연구 문제가 다른 계보이다.

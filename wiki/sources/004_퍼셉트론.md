# 퍼셉트론

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[선형 분류기]], [[지도 학습]]<br>
> **읽고 나면:** 퍼셉트론의 판정과 오류 수정 과정을 설명하고, 수렴 조건·표현 한계·현대 신경망과의 계보 범위를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 요약

기본 [[퍼셉트론]]은 입력의 가중합과 임계값으로 이진 결정을 내리는 [[선형 분류기]]다. 예측이 틀렸을 때 정답 방향으로 가중치를 바꾸는 퍼셉트론 규칙은 오류 수정(error-correction) 규칙이다. 미분 가능한 손실 함수를 따라가는 일반적인 [[경사하강법]]과 같은 것으로 설명해서는 안 된다. 제곱오차의 그래디언트를 명시적으로 이용한 초기 계보는 [[ADALINE]]과 [[LMS 알고리즘]]에서 더 분명하다.

쉽게 말해, 여러 입력 특징에 서로 다른 중요도를 주어 점수 하나를 만들고 그 점수가 기준선을 넘는지로 두 부류를 가르는 모델이다. 틀린 답이 나오면 같은 실수를 줄이는 방향으로 중요도를 고치는 과정이 학습이다.

### 쉬운 예시

설명용으로 전자우편을 두 부류로 나누는 장면을 생각해 보자. 특정 낱말의 출현과 발신자 정보에 서로 다른 가중치를 주고 합산한 뒤, 임계값을 넘으면 한 부류로 판정한다. 정답과 다르게 분류했다면 그 사례의 특징을 이용해 가중치를 고치지만, 이 예시는 작동 직관을 위한 것이며 프로젝트 raw의 잘못된 수치 계산을 되살리는 예가 아니다.

### 왜 중요한가

퍼셉트론은 사람이 모든 판정 규칙을 직접 열거하는 대신, 라벨이 있는 사례의 오분류를 이용해 결정 경계를 조정하는 초기 학습 원리를 보여 준다. 동시에 학습이 수렴하는 조건과 한 모델이 표현하지 못하는 함수가 무엇인지 함께 드러낸다.

### 핵심 문장

- 퍼셉트론은 오분류를 줄이도록 가중치를 수정하는 초기 학습 규칙을 구현했다.
- 수렴 정리는 선형 분리 가능성을 전제로 하며 학습 가능한 함수의 범위를 함께 드러낸다.
- 현대 딥러닝과의 관계는 동일한 훈련 방식이 아니라 학습 가능한 가중치라는 넓은 계보로 설명해야 한다.

## 2단계 — 작동 원리

### 입력에서 판정까지

1. **문제:** 라벨이 있는 입력을 두 부류 가운데 하나로 나눈다.
2. **표현:** 각 입력 특징에 학습 가능한 가중치를 붙인다.
3. **계산:** 입력값과 가중치를 결합해 하나의 점수를 만든다.
4. **판정:** 점수가 임계값의 어느 쪽에 있는지에 따라 예측 부류를 정한다.
5. **결과:** 하나의 선형 결정 경계가 입력 공간을 두 영역으로 나눈다.

### 오분류에서 가중치 수정까지

1. 현재 가중치로 입력을 분류한다.
2. 예측과 정답 라벨을 비교한다.
3. 오분류했다면 정답 쪽 판정을 강화하도록 가중치를 수정한다.
4. 훈련 사례를 반복해 더 이상 오분류하지 않는 경계를 찾는다.

마지막 단계가 언제나 성공하는 것은 아니다. 자료가 선형으로 분리될 때는 수렴 조건을 적용할 수 있지만, 그렇지 않은 자료에서는 같은 갱신을 계속해도 모든 사례를 가르는 선형 경계가 존재하지 않는다.

## 3단계 — 기술과 근거

### 제안·논문·하드웨어의 연표

[[프랭크 로젠블랫]]은 1957년 연구 보고서에서 퍼셉트론 구상을 제시했고, 1958년 논문에서 확률적 신경망 모델과 학습 원리를 발표했다. Mark I 퍼셉트론 하드웨어는 그 뒤에 제작됐다. 따라서 “1958년에 퍼셉트론과 하드웨어가 한꺼번에 만들어졌다”는 연표는 피해야 한다.

### 수렴 조건과 증명의 귀속

훈련 자료가 [[선형 분리 가능성|선형 분리 가능]]한 경우, 퍼셉트론 갱신은 유한한 횟수 안에 분리 초평면을 찾는다. 이 결과의 초기 형태는 Rosenblatt와 동료들의 연구에서 제시되었고, Albert Novikoff가 1963년에 간결한 증명과 경계 분석을 제시했다. 모든 증명을 한 사람에게 단독으로 귀속하지 않는 편이 정확하다.

수렴 정리는 모든 분류 과제에 대한 성공 보장이 아니다. 선형 분리 가능성이라는 전제가 충족될 때 갱신이 분리 초평면에 도달한다는 조건부 결과다.

### 표현 한계와 1969년 분석

단층 퍼셉트론은 [[XOR 문제]]처럼 선형으로 분리되지 않는 함수를 표현하지 못한다. Minsky와 Papert의 1969년 분석은 이러한 한계를 체계화했지만, XOR 하나가 신경망 연구 침체나 “AI 겨울”을 단독으로 일으켰다고 설명하는 것은 지나친 단순화다. 연구비, 계산 자원, 학습 알고리즘과 당시의 기대가 함께 작용했다.

### 현대 언어 모델과의 비교

현대 [[대규모 언어 모델]]은 가중합과 학습 가능한 매개변수를 사용한다는 넓은 신경망 계보를 공유한다. 그러나 GPT의 생성 사전학습과 BERT의 마스크드 언어 모델링은 비라벨 텍스트를 이용한 사전학습이며, 퍼셉트론식 라벨 지도학습과 “동일한 기본 접근”은 아니다. 지도 미세조정은 여러 후속 학습 단계 중 하나다.

## 검증과 한계

### 확인된 사실

- 퍼셉트론은 입력의 가중합과 임계값으로 이진 결정을 내리고, 오분류 사례를 이용해 가중치를 수정한다.
- 수렴 결과는 훈련 자료가 선형으로 분리된다는 전제를 필요로 한다.
- 단층 퍼셉트론은 XOR처럼 선형으로 분리되지 않는 함수를 표현하지 못한다.

### 검증 정정

- 프로젝트 raw의 계산 예시는 양의 값 `0.69`를 계산한 뒤 근거 없이 음의 결과를 가정하므로 사용하지 않는다.
- 퍼셉트론 규칙은 오류 수정 규칙으로, ADALINE/LMS의 제곱오차 경사하강과 구분한다.
- GPT·BERT의 핵심 사전학습을 라벨 기반 지도학습으로 분류하지 않는다.
- XOR에서 AI 겨울로 이어지는 단일 원인 서사를 사용하지 않는다.

### 프로젝트 해석

퍼셉트론과 현대 신경망을 잇는 공통점은 학습 가능한 가중치를 사용한다는 넓은 구조적 계보이다. 이를 동일한 목적함수·자료 구성·훈련 절차가 직접 이어졌다는 주장으로 확대하지 않는다.

### 후대 평가와 계보의 한계

- Rosenblatt의 초기 결과와 Novikoff의 1963년 증명·경계 분석을 구분하며, 수렴 증명을 한 사람에게만 귀속하지 않는다.
- Minsky와 Papert가 분석한 표현 한계는 확인할 수 있지만, XOR 하나를 연구 침체의 단일 원인으로 삼지 않는다.
- ADALINE/LMS의 제곱오차 경사하강, GPT의 생성 사전학습과 BERT의 마스크드 언어 모델링은 퍼셉트론 오류 수정 규칙과 구별되는 후대 방법이다.

## 학습 확인

### 확인 질문

1. 퍼셉트론은 입력에서 이진 판정을 만들고 오분류를 이용해 가중치를 고치기까지 어떤 순서로 작동하는가?
2. 선형 분리 가능성은 수렴 정리가 보장하는 범위와 XOR이 드러내는 한계를 어떻게 가르는가?
3. 퍼셉트론 규칙을 ADALINE/LMS의 경사하강이나 GPT·BERT의 사전학습과 같은 훈련 방식으로 설명하면 안 되는 이유는 무엇인가?

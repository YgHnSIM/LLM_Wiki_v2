# 최대 엔트로피와 서포트 벡터 머신

027 raw는 [[최대 엔트로피 모델]](Maximum Entropy model, MaxEnt)과 [[서포트 벡터 머신]](Support Vector Machine, SVM)이 1996년에 함께 자연어 처리를 혁신하고 품사 태깅·개체명 인식·청킹·텍스트 분류를 지배했다고 서술한다. 이 공개 문서는 두 모델이 공유한 **특징 기반 판별 학습**이라는 문제의식과 서로 다른 확률·최적화 원리를 구분한다. MaxEnt의 1993–1994년 NLP 적용, 1995년 SVM 논문, 1996년 MaxEnt 정식화와 품사 태거, 1998년 이후 SVM의 텍스트·순서열 적용을 각각의 1차 자료로 복원한다.

## 핵심 요약

MaxEnt 분류기는 사람이 정의한 특징 함수들의 가중합을 각 출력의 점수로 만들고 이를 정규화해 [[조건부 확률]]을 계산하는 로그선형 모델이다. 서로 겹치는 어휘·형태·문맥 특징을 하나의 분포 안에 넣을 수 있지만, 필요한 상호작용을 스스로 발명하지는 않는다. 특정 단어와 이전 품사의 결합처럼 별도의 상호작용이 필요하면 결합 특징이나 특징 유도 절차를 명시해야 한다.

SVM은 분류 경계와 가까운 훈련 예시들이 만드는 마진을 크게 하는 결정 경계를 학습한다. 기본 목적은 정규화된 확률을 추정하는 것이 아니라 분류 점수와 경계를 얻는 것이다. 커널은 선택 사항이며, 선형 SVM은 희소 텍스트 벡터에 직접 선형 경계를 둔다. 비선형 커널을 사용할 때에만 특징 조합을 더 높은 차원의 공간에서 암묵적으로 표현한다.

두 모델은 모두 입력이 주어졌을 때 출력을 구분하는 판별 학습에 쓰이고 고차원 희소 특징을 다룰 수 있었다. 그러나 MaxEnt의 조건부 로그가능도와 SVM의 최대 마진 목적, 확률 출력 여부, 다중 클래스·순서열 확장 방법은 같지 않다. 1996년을 두 계열의 공동 발명·동시 확산 시점으로 묶으면 실제 연구 순서가 사라진다.

이 연표는 한 방법이 다른 방법을 즉시 대체했다는 뜻이 아니다. [[은닉 마르코프 모델]], 변환 기반 학습, 결정 트리, MaxEnt, SVM과 후대의 조건부 순서열 모델은 과제·자료·계산 조건에 따라 공존했다.

## 최대 엔트로피 분류기의 계산

입력 문맥을 (x), 후보 출력을 (y), 특징 함수를 (f_i(x,y)), 학습된 가중치를 \(\lambda_i\)라고 하면 조건부 MaxEnt 모델은 보통 다음 로그선형 형태로 쓸 수 있다.

\[
P(y\mid x)=
\frac{\exp\!\left(\sum_i \lambda_i f_i(x,y)\right)}
{\sum_{y'}\exp\!\left(\sum_i \lambda_i f_i(x,y')\right)}
\]

분모는 같은 입력에서 가능한 출력의 확률 합을 1로 만드는 정규화 항이다. Berger 등의 구성에서는 훈련 자료에서 관측한 특징의 기대값을 모델의 기대값과 맞추는 제약을 두고, 그 제약을 만족하는 분포 가운데 조건부 엔트로피가 최대인 분포를 선택한다. 이 문제의 해는 지수형 모델의 조건부 가능도를 최대화하는 쌍대 문제와 연결된다.

여기서 “알려진 것만 제약하고 나머지는 가정하지 않는다”는 원리는 모델이 언어 지식을 자동으로 찾아낸다는 뜻이 아니다. 어떤 통계를 특징으로 삼을지, 어느 빈도 이하를 버릴지, 어떤 단어·접사·품사 조합을 결합할지는 여전히 [[특징 공학]]의 문제다. Berger 등의 1996년 논문도 모델 결합만으로 끝내지 않고 수많은 후보에서 특징을 선택하는 별도 알고리즘과 그 계산 비용을 다뤘다.

정규화된 (P(y\mid x))를 출력한다는 사실과 그 값이 실제 장기 빈도에 맞게 **보정**됐다는 주장은 다르다. 1996년 논문들은 조건부 확률 모델과 분류 정확도를 제시했지만 현대적인 calibration 지표로 예측 신뢰도를 검증하지 않았다.

## Ratnaparkhi 품사 태거가 실제로 한 일

Ratnaparkhi의 1996년 태거는 현재 단어와 앞뒤 단어, 앞선 두 품사, 접두사·접미사, 숫자·하이픈·대문자 여부 같은 정보를 이진 특징 템플릿으로 만들었다. 현재 단어의 후보 품사에 조건부 확률을 부여하고 beam search로 높은 점수의 품사열을 유지했다. 이 구조는 단일 위치의 분류만 독립적으로 수행한 것도, 가능한 문장 전체의 품사열을 한 번에 전역 정규화한 것도 아니다.

실험 자료는 Penn Treebank WSJ에서 훈련 40,000문장·962,687단어, 개발 8,000문장·192,826단어, 시험 5,485문장·133,805단어로 나뉘었다. Table 11의 최종 시험 결과는 전체 단어 정확도 **96.63%**, 훈련에 없던 단어 정확도 **85.56%**, 문장 전체 정확도 **47.51%**다. “약 97%”만 남기면 미등록어와 문장 단위의 훨씬 어려운 조건이 가려진다.

전문화 특징은 기본 특징과 단어 조건을 명시적으로 결합해 만들었다. 이 시도는 일부 오류를 줄였지만 주석자별 불일치에 민감했고, 전체 개발 성능 향상은 작았다. 논문은 Penn Treebank에서 MaxEnt, tri-tag Markov 모델, 통계적 결정 트리와 변환 기반 학습의 전체 단어 정확도가 대략 비슷한 수준이라고 결론 내렸다. 따라서 이 결과를 HMM이 1996년에 일괄적으로 밀려났다는 증거로 사용하지 않는다.

## SVM의 마진·커널·서포트 벡터

선형 이진 SVM의 결정 함수는 특징 벡터 \(\phi(x)\)에 대해 다음처럼 쓸 수 있다.

\[
\hat y=\operatorname{sign}(w\cdot\phi(x)+b)
\]

분리 가능한 경우에는 두 클래스에서 가장 가까운 예시와 경계 사이의 여유, 즉 마진이 최대가 되도록 \(\lVert w\rVert\)를 줄인다. Cortes·Vapnik의 1995년 soft-margin 구성은 일부 위반을 허용하는 slack 변수와 그 비용을 더해 잡음이나 겹치는 클래스도 다룬다. 결과는 선택한 특징 표현, 손실, 규제와 soft-margin 매개변수에 대한 최대 마진 해이지 모든 현실 분포에서 보편적으로 “최적인 경계”가 아니다.

커널 \(K(x,x')\)은 두 예시를 명시적으로 고차원 벡터로 펼치지 않고 해당 공간의 내적을 계산하게 한다. 다항·방사 기저 같은 비선형 커널은 특징 조합이나 비선형 경계를 표현할 수 있다. 그러나 텍스트 분류에서 자주 쓰인 선형 SVM에는 이런 비선형 커널 상호작용이 없으며, 고차원이라는 사실 자체가 커널 사용을 뜻하지 않는다.

서포트 벡터는 훈련 전에 “중요한 예시”만 골라 두는 입력이 아니라 전체 최적화의 해에서 계수가 남은 훈련 예시다. 비선형 SVM의 예측은 입력과 서포트 벡터 사이의 커널 값을 계산하므로 서포트 벡터 수가 많으면 느릴 수 있다. Isozaki·Kazawa는 개체명 인식용 기본 SVM이 초당 85바이트에 그쳤다고 보고하고, 서포트 벡터 수를 줄이지 않은 채 2차 커널 결정을 특징·특징쌍 가중치로 재구성한 XQK로 분류를 가속했다. 별도 XQK-FS 실험은 특징의 75%를 제거하면서 F1이 88.31에서 88.03으로 소폭 낮아졌다. “서포트 벡터만 쓰므로 항상 효율적”이라고 일반화하지 않는다.

## 텍스트 분류·청킹·개체명 인식의 조건

Joachims의 1998년 실험은 문서를 단어 특징으로 표현하고 최소 빈도, 불용어 제거, IDF와 벡터 정규화를 적용했다. Reuters ModApte와 Ohsumed에서 SVM이 비교 방법보다 높은 결과를 냈지만, 전처리 없는 보편적 우위나 모든 NLP 과제의 지배를 입증한 것은 아니다. 학습 비용도 Naive Bayes·Rocchio·kNN보다 컸다고 보고했다.

Kudo·Matsumoto의 2001년 영어 청킹 실험은 CoNLL-2000의 WSJ 15–18절로 학습하고 20절에서 평가했으며 2차 다항 커널을 사용했다. 가중 투표에 들어간 여덟 Inside/Outside 단일 모델의 F1은 93.45–93.85였고, 별도 IOBES 단일 모델은 93.31과 93.41이었다. 널리 인용되는 **93.91**은 여덟 모델의 가중 투표 결과다. 단일 1996년 모델의 점수로 옮기지 않는다.

Isozaki·Kazawa의 2002년 일본어 IREX 개체명 실험은 학습 자료에 따라 F1 85.04와 90.03을 보고했다. 높은 값은 추가 자료와 1,038,986개 학습 벡터를 사용한 조건이다. raw의 “NER 85–90%, 청킹 93–94%”는 서로 다른 연도·언어·말뭉치·ensemble·학습량을 하나의 일반 성능 범위로 합친 값이다.

## 지역 분류와 구조화된 순서열

MaxEnt 분류기는 한 입력 문맥의 후보 라벨을 정규화한다. 이를 각 시점에 적용하고 이전 예측 라벨을 특징으로 쓰면 순서열을 처리할 수 있지만, 지역별 정규화 때문에 상태별로 나가는 전이 수가 다른 상황에서 label bias가 생길 수 있다. Lafferty·McCallum·Pereira의 2001년 CRF는 관측열이 주어졌을 때 라벨열 전체를 전역 정규화하는 별도 모델로 이 문제를 다뤘다. CRF를 1996년 MaxEnt 분류기와 같은 모델로 합치지 않는다.

기본 SVM도 하나의 이진 라벨을 예측하는 분류기다. 다중 클래스는 one-vs-rest 같은 구성이나 별도 다중 클래스 목적이 필요하고, 품사열·구문 트리처럼 상호 의존하는 출력에는 joint feature map과 구조 손실을 둔 확장이 필요하다. Tsochantaridis 등의 2004년 구조 SVM은 이런 일반화를 정식화했다. 후대 확장을 기본 SVM의 1995년 성질로 소급하지 않는다.

## 두 모델의 공통점과 차이

| 항목 | 최대 엔트로피 분류기 | 서포트 벡터 머신 |
| --- | --- | --- |
| 기본 학습 목표 | 조건부 로그가능도 최대화와 최대 엔트로피 제약의 쌍대성 | 가중치 노름과 분류 위반 비용을 절충하는 최대 마진 학습 |
| 기본 출력 | 후보 라벨에 대한 정규화 조건부 확률 | 경계로부터의 부호 있는 점수와 클래스 |
| 경계 | 명시적 특징 공간에서 로그선형 | 선형 또는 선택한 커널 공간의 선형 경계 |
| 특징 상호작용 | 결합 특징이나 특징 유도를 명시해야 함 | 명시적 조합 또는 비선형 커널이 필요함 |
| 확률 보정 | 확률 형식이지만 calibration은 별도 검증 대상 | 기본 출력은 확률이 아니며 별도 변환이 필요함 |
| 기본 출력 구조 | 다중 후보 라벨을 정규화할 수 있는 분류 | 원래 정식화는 이진 분류 |
| 순서열 확장 | 지역 조건부 모델, MEMM·CRF 등 별도 구조 | 여러 이진 분류기 또는 구조 SVM 등 별도 구조 |

공통점은 생성 모델보다 적은 결합분포 가정을 두고 입력-출력 판별에 집중할 수 있다는 데 있다. 차이까지 지운 채 두 모델을 하나의 “특징 통합 알고리즘”으로 부르면 어떤 수치가 어느 모델·목적 함수·출력에 해당하는지 알 수 없게 된다.

## 특징 공학에서 표현 학습으로

특징 기반 NLP의 핵심 성과는 언어 전문가가 어휘·접사·주변 단어·이전 라벨·문서 빈도처럼 서로 다른 신호를 명시적인 입력으로 만들고, 모델은 그 가중치나 경계를 자료에서 학습하게 한 것이다. 이는 모든 규칙을 손으로 써야 했던 시스템과 달랐지만 사람의 역할을 없애지는 않았다. 템플릿, 토큰화, 주석 범주, 훈련·시험 분할과 평가 지표가 모델이 배울 문제를 정했다.

Collobert 등의 2011년 신경 NLP 구조는 품사 태깅·청킹·개체명 인식·의미역 표지에서 단어 표현과 신경망 매개변수를 함께 학습했다. Mikolov 등의 2013년 CBOW·Skip-gram은 대규모 텍스트의 예측 과제로 단어 벡터를 학습했다. 이들은 많은 수작업 특징을 연속 표현 학습으로 옮긴 중요한 전개지만 MaxEnt나 SVM의 단순한 크기 확대판은 아니다.

신경망의 마지막 softmax 층은 학습된 표현 위의 로그선형 분류기로 쓸 수 있고, margin loss를 신경망과 결합할 수도 있다. 그러나 출력층의 수학적 유사성이 전체 신경망 구조의 직접 역사 계보를 입증하지 않는다. [[021_합성곱 신경망과 특징 학습]]이 보여 주듯 표현을 데이터에서 학습해도 토큰화·입력 구성·아키텍처·목표 함수와 평가 설계는 남는다. 특징 공학은 사라지기보다 다른 추상화 수준으로 이동했다.

## 한계와 적용 판단

- MaxEnt는 출력 수와 활성 특징이 많을수록 정규화·학습 비용이 커질 수 있고, 희소 특징은 [[데이터 희소성]]과 과적합에 취약하다.
- 규제가 없는 1990년대식 최대가능도 모델과 현대의 규제된 로그선형 분류기를 같은 조건으로 보지 않는다.
- SVM의 성능과 비용은 특징 스케일, 정규화, 커널, soft-margin 매개변수, 클래스 불균형과 다중 클래스 구성에 달려 있다.
- 선형 SVM은 대규모 희소 텍스트에 효율적일 수 있지만, 비선형 커널과 많은 서포트 벡터를 쓰는 모델까지 같은 추론 비용으로 일반화하지 않는다.
- 특징 가중치나 서포트 벡터를 볼 수 있다는 사실만으로 모델의 결정이 인간에게 충분히 설명된다고 보장되지 않는다.
- 작은 자료·제한된 계산·명시적 특징이 있는 환경에서 두 모델이 유용할 수 있다는 판단은 과제별 기준선과 최신 실험으로 다시 확인해야 한다.

## 검증 정정

- 1996년은 MaxEnt NLP의 중요한 이정표지만 MaxEnt와 SVM이 함께 NLP를 전환한 단일 연도는 아니다.
- MaxEnt 언어 모델과 전치사구 부착 연구는 1993·1994년에 이미 발표됐고, SVM 저널 논문은 1995년, 대표적 텍스트 분류 적용은 1998년이다.
- Ratnaparkhi 품사 태거의 최종 수치는 전체 단어 96.63%, 미등록어 85.56%, 문장 47.51%이며 HMM·결정 트리·변환 기반 태거를 일괄 압도했다고 보고하지 않았다.
- MaxEnt는 겹치는 특징을 독립 가정 없이 결합하지만 임의의 상호작용을 자동 발견하지 않는다. 결합 특징이나 특징 유도는 별도 설계다.
- 정규화 확률을 출력한다는 사실은 calibration을 보장하지 않는다.
- SVM의 “최적”은 선택한 특징·손실·규제 안의 최대 마진 해이며 보편적으로 가장 정확한 현실 경계라는 뜻이 아니다.
- 커널은 선택 사항이고, 비선형 커널에만 암묵적 비선형 특징 조합이 있다.
- 서포트 벡터는 훈련 전에 선별되지 않으며 수가 많으면 비선형 예측 비용도 커진다.
- NER 85–90%와 청킹 93–94%는 2001–2002년의 서로 다른 조건에서 나온 수치다.
- CRF와 구조 SVM은 각각 2001년과 2004년의 별도 순서열·구조 출력 전개다.
- 신경 표현 학습은 특징 기반 판별 학습과 문제의식을 공유하지만 Word2Vec·신경 NLP 전체가 MaxEnt·SVM에서 직접 파생됐다고 기록하지 않는다.

## 핵심 문장

- MaxEnt와 SVM은 모두 풍부한 희소 특징을 판별 학습에 사용할 수 있었지만 확률 모델과 최대 마진 분류기라는 서로 다른 계열이다.
- 특징을 많이 넣을 수 있다는 능력과 유용한 특징·상호작용을 자동으로 발견한다는 능력은 다르다.
- Ratnaparkhi의 96.63% 단어 정확도는 같은 시험의 85.56% 미등록어 정확도와 47.51% 문장 정확도와 함께 읽어야 한다.
- SVM의 커널·서포트 벡터·마진은 표현력과 일반화를 설명하는 도구이지 모든 자료에서의 속도·확률·최적 성능 보장이 아니다.
- 특징 기반 모델에서 신경 표현 학습으로의 이동은 사람의 설계를 제거하기보다 설계와 학습의 경계를 옮겼다.

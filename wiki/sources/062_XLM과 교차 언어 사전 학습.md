# XLM과 교차 언어 사전 학습

> [!note] 학습 안내
> **난이도:** 심화<br>
> **선수 지식:** [[마스크드 언어 모델링]], [[Byte Pair Encoding|BPE]]<br>
> **읽고 나면:** XLM의 CLM·MLM·TLM을 구분하고, XNLI zero-shot에서 보이지 않는 것이 target 언어가 아니라 target-language task label임을 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

061 raw는 [[XLM]]을 여러 언어의 text를 동시에 이해·생성하는 하나의 획기적 모델로 설명한다. 핵심은 더 구체적이다. XLM 연구는 단일 언어 corpus만 쓰는 CLM·MLM과 병렬 문장쌍을 쓰는 MLM+TLM 설정을 비교했고, 영어 NLI label로 fine-tune한 classifier를 다른 언어에 옮기는 교차 언어 전이를 측정했다. raw는 zero-shot을 “훈련에서 전혀 보지 않은 언어”로 잘못 넓히고, 평가하지 않은 few-shot·질의응답·정보검색·범용 배포와 후속 계보까지 성과로 묶는다.

### 핵심 문장

- XLM은 하나의 고정 objective보다 CLM·MLM·MLM+TLM을 비교한 교차 언어 사전 학습 방법군이다.
- TLM은 번역문을 생성하는 decoder 목표가 아니라 병렬 문장쌍 양쪽의 masked token을 함께 복원하는 MLM 확장이다.
- XNLI zero-shot은 target 언어의 **표지 NLI data 없이** 평가한다는 뜻이며, target 언어의 비표지 text는 사전 학습에 포함됐다.
- monolingual-only MLM도 XNLI 평균 71.5를 냈고 parallel data를 더한 MLM+TLM은 75.1이었다.
- 공유 BPE는 문자열 anchor를 제공하지만 철자가 다른 번역어의 의미 정렬을 자동 보장하지 않는다.

## 2단계 — 작동 원리

### 세 objective와 전이 흐름

| 설정 | 입력 자료 | 예측할 것 | 언어 사이 직접 신호 |
|---|---|---|---|
| CLM | 언어별 단일 언어 text | 앞 문맥에서 다음 token | shared parameter·어휘를 통한 간접 공유 |
| MLM | 언어별 단일 언어 text | 가린 token을 같은 문장의 양쪽 문맥에서 복원 | shared parameter·어휘를 통한 간접 공유 |
| MLM+TLM | 단일 언어 text와 병렬 문장쌍 | MLM과, 번역쌍 양쪽의 가린 token 복원 | 병렬 문장 전체에 대한 cross-attention |

XNLI 전이는 다음 순서다.

1. 평가할 여러 언어의 **비표지 text**로 multilingual encoder를 사전 학습한다.
2. 영어의 **표지 NLI example**로 classifier와 encoder를 fine-tune한다.
3. 같은 가중치를 target 언어의 XNLI test set에 적용한다.

3단계에서 target-language NLI label로 학습하지 않기 때문에 zero-shot이다. 1단계에서 target 언어 자체가 없었던 것은 아니다.

## 3단계 — 기술과 근거

### shared BPE 어휘 구성과 학습 batch sampling

XLM은 shared BPE split을 학습할 문장을 뽑을 때 언어 $i$의 문장 비율 $p_i$를 다음처럼 평탄화했다.

$$
q_i=\frac{p_i^{\alpha}}{\sum_j p_j^{\alpha}},\qquad \alpha=0.5.
$$

$\alpha<1$이면 작은 corpus 언어의 sampling 비중이 원 data 비율보다 커진다. 별도로 CLM·MLM 학습 batch의 언어를 고를 때도 같은 식을 쓰되 $\alpha=0.7$로 설정했다. BPE 어휘 구성의 $0.5$와 학습 batch 선택의 $0.7$은 서로 다른 sampling 단계다. 이 평탄화는 저자원 언어의 관측 기회를 늘리지만, data 품질이나 언어별 최적 배분을 자동 보장하지 않는다.

BPE code와 Transformer parameter를 언어 사이에서 공유하면 같은 alphabet의 subword, 숫자, 고유명 같은 문자열 anchor를 재사용할 수 있다. 그러나 `dog`·`chien`·`perro`처럼 표면형이 다른 단어가 BPE만으로 번역 관계를 얻는 것은 아니다. 정렬은 shared training과 TLM의 병렬 문장 문맥 같은 추가 신호에서 생긴다.

### CLM과 MLM

CLM은 일반적인 왼쪽→오른쪽 factorization을 사용한다.

$$
\mathcal{L}_{\mathrm{CLM}}(x)
=-\sum_t\log p_\theta(x_t\mid x_{<t}).
$$

각 언어의 문장을 같은 Transformer와 vocabulary로 학습하지만 token 예측은 언어별 sequence 안에서 일어난다. MLM은 일부 token을 가리고 같은 문장의 좌우 문맥에서 복원한다. 두 방식은 병렬 corpus 없이 monolingual data만으로 교차 언어 표현을 학습하는 비지도 설정이다.

### TLM은 번역쌍을 하나의 복원 문맥으로 만든다

TLM은 같은 내용을 담은 두 언어 문장을 이어 붙이고 양쪽에서 token을 가린다. 각 target은 자신의 언어 문맥뿐 아니라 번역문 전체에도 attention할 수 있다. position은 문장마다 다시 시작하고 language embedding으로 두 언어를 구분한다.

MLM+TLM 설정은 CLM을 먼저 끝낸 다음 TLM으로 넘어가는 고정 순차 학습이 아니다. monolingual MLM batch와 parallel TLM batch를 번갈아 사용한다. TLM에는 병렬 data가 필요하지만 CLM·MLM 기반 XLM에는 필요하지 않다.

### zero-shot XNLI의 정확한 범위

XNLI는 15개 언어의 natural language inference 평가다. XLM encoder는 이 언어들의 비표지 corpus를 사전 학습에서 보았고, fine-tuning label은 영어 NLI만 사용했다. 그러므로 다른 14개 언어 test 성능은 **target-language labeled fine-tuning이 없는 전이**를 측정한다.

| 사전 학습 설정 | XNLI 15언어 평균 accuracy | 해석 |
|---|---:|---|
| XLM MLM | 71.5 | parallel data 없이도 당시 강한 교차 언어 전이 |
| XLM MLM+TLM | 75.1 | 병렬 TLM 추가로 MLM보다 3.6%p 상승 |

75.1은 당시 종전 최고 70.2보다 4.9%p 높았다. TLM의 MLM 대비 증분 3.6%p와 종전 방식 대비 4.9%p를 혼동하지 않는다.

### 원 논문이 실제로 평가한 과제

| 과제 | 대표 결과 | 검증 범위 |
|---|---:|---|
| XNLI | MLM+TLM 평균 75.1 accuracy | 영어 label fine-tuning 뒤 15개 언어 평가 |
| 비지도 MT | German→English 34.3 BLEU | 해당 WMT data·학습 recipe 조건 |
| 지도 MT | Romanian→English 38.5 BLEU | WMT16 조건 |
| 저자원 LM | Nepali perplexity 157.2→109.3 | Hindi·English를 함께 훈련한 특정 비교 |
| cross-lingual word similarity | SemEval17 Pearson 0.69 | word-level representation 비교 |

raw가 예로 든 Italian QA와 교차 언어 정보검색은 이 논문의 실험이 아니다. 저자원 결과도 모든 언어의 보편적 개선이 아니라 Swahili·Urdu XNLI와 Nepali LM 같은 구체 조건으로 읽어야 한다.

### 공유 모델의 비용과 capacity

XNLI용 language model은 12-layer Transformer와 약 95k vocabulary를 사용했고 훈련에는 64개 Volta GPU가 사용됐다. 한 encoder가 여러 언어를 담는다는 사실은 언어별 모델 파일 수를 줄일 가능성을 주지만, 논문이 실제 deployment 비용 절감을 측정한 것은 아니다. 공유 capacity 안에서 언어가 많아질 때 생기는 간섭도 “한 모델이 모든 언어를 처리한다”는 문장만으로 사라지지 않는다.

## 검증과 한계

### 검증 정정

- **XLM은 하나의 고정 모델이다**: CLM·MLM·MLM+TLM 설정을 비교한 방법·모델군이다.
- **CLM을 먼저 훈련한 뒤 TLM으로 넘어간다**: MLM+TLM은 두 objective의 batch를 교대로 학습했다.
- **zero-shot은 훈련에서 보지 않은 언어를 뜻한다**: target 언어 text는 pretraining에 있었고 target-language NLI label이 없었다.
- **영어·프랑스어·스페인어만 보고 Italian QA를 했다**: Italian은 XNLI 15개 언어가 아니며 QA도 평가하지 않았다.
- **few-shot·교차 언어 검색·QA가 입증됐다**: 원 논문의 직접 평가는 XNLI·지도/비지도 MT·Nepali LM·word similarity다.
- **TLM만이 XLM의 성공 원인이다**: monolingual-only MLM도 XNLI 71.5를 냈고 TLM은 이를 75.1로 높였다.
- **공유 BPE가 번역어 의미를 자동 정렬한다**: 문자열 anchor와 shared training·parallel context의 역할을 분리해야 한다.
- **mBERT는 XLM의 후속 모델이다**: XLM 논문에서 이미 비교 baseline으로 다뤄진 동시대 선행 방식이다.
- **하나의 모델이 deployment compute를 크게 줄였다**: 사전 학습은 64 Volta GPU 조건이며 배포 절감은 측정하지 않았다.
- **다국어 GPT·mT5·multimodal system이 모두 XLM에서 직접 나왔다**: 별도 후속 문헌 없이 확정할 수 없는 계보다.
- **data 품질이 architecture보다 중요하다고 입증했다**: 원 논문의 ablation으로 확인된 결론이 아니다.

### 남는 한계

TLM은 강한 명시적 정렬 신호를 주지만 병렬 corpus가 있는 언어쌍에 의존한다. 원 실험의 TLM parallel pair는 한쪽이 모두 영어였다. shared vocabulary와 parameter는 언어 사이 positive transfer를 만들 수 있지만, script·형태·corpus 규모가 다른 언어에서 같은 정도의 전이를 보장하지 않는다. 평균 성능 상승은 언어별 격차·negative transfer·training cost를 함께 보여 주지 않는다.

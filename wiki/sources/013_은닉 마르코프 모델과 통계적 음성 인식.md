# 은닉 마르코프 모델과 통계적 음성 인식

## 핵심 요약

[[은닉 마르코프 모델]](Hidden Markov model, HMM)은 직접 관측되지 않는 유한 상태가 확률적으로 전이하고 각 상태가 관측값을 확률적으로 생성한다고 보는 순차 모델이다. [[레너드 바움]]과 Ted Petrie의 1966년 논문은 유한상태 마르코프 연쇄의 확률 함수에 대한 통계적 추론을 다뤘고, Baum·Petrie·George Soules·Norman Weiss는 1970년에 가능도를 증가시키는 재추정 변환을 제시했다. 따라서 HMM의 수학적 기반을 “1970년대 음성 인식에서 처음 발명됐다”고 설명하지 않는다.

음성 인식 적용은 별도의 단계다. James K. Baker의 1975년 DRAGON 논문은 연속 음성 인식의 여러 지식원을 마르코프 과정의 확률 함수로 나타냈다. 같은 해 Frederick Jelinek·Lalit Bahl·Robert Mercer는 통계 언어 모델, 음소 사전과 통계적 음운 규칙, 음성 정합, 단어 수준 탐색 제어를 결합한 연속 음성 디코더를 기술했다. Jelinek의 1976년 논문은 화자와 음향 처리기의 모델링, 통계 매개변수 추정, 가설 탐색과 가능도 계산을 함께 정리했다. 이는 1960년대의 수학적 기반과 1970년대 중반의 음성 응용을 구분할 근거다.

HMM은 평가·디코딩·학습을 계산 가능한 문제로 조직했다. 가능한 상태 경로의 확률을 모두 더하는 순방향 계산, 단일 최고 경로를 찾는 [[비터비 알고리즘]], 매개변수를 반복 재추정하는 [[Baum–Welch 알고리즘]]은 목적이 서로 다르다. 이 구분은 raw의 날씨 예처럼 최고 경로와 경로 전체의 분포를 한 계산으로 합치는 설명을 교정한다.

## 기원과 음성 적용 연표

| 연도 | 문헌 | 확인되는 단계 |
|---:|---|---|
| 1966 | Baum·Petrie | 은닉된 유한상태 마르코프 과정의 확률 함수에 대한 통계적 추론 |
| 1967 | Viterbi | 길쌈 부호의 오류 경계와 복호 절차. 처음부터 음성 인식용으로 제안된 것은 아님 |
| 1970 | Baum·Petrie·Soules·Weiss | 관측 가능도를 감소시키지 않는 매개변수 재추정 변환 |
| 1975 | Baker, DRAGON | 연속 음성 이해의 지식원에 마르코프 과정의 확률 함수를 적용 |
| 1975 | Jelinek·Bahl·Mercer | 언어 모델·음소 사전·음운 규칙·정합·탐색을 결합한 통계 디코더 |
| 1976 | Jelinek | 연속 음성 인식의 모델 추정·가능도 계산·가설 탐색을 종합 |
| 1980 | Davis·Mermelstein | 멜 기반 켑스트럼 매개변수를 포함한 음향 표현을 연속 발화 문장에서 비교 |
| 1989 | Rabiner | HMM의 세 계산 문제와 음성 인식 응용을 후대 관점에서 체계화 |

이 연표는 하나의 발명 연도를 정하기보다 수학, 복호 알고리즘, 음향 표현, 음성 시스템이 서로 다른 문헌에서 결합된 과정을 보여 준다. 1989년 Rabiner의 논문은 중요한 정리이지만 HMM이나 음성 적용의 최초 제안은 아니다.

## 모델 가정과 계산

1차 HMM은 초기 상태 확률, 상태 전이 확률, 상태별 관측 분포로 이루어진다. 상태 전이에는 현재 상태가 직전 상태에만 의존한다는 [[마르코프 가정]]을 둔다. 표준 HMM은 여기에 현재 상태가 주어졌을 때 현재 관측이 다른 상태·관측과 조건부 독립이라는 방출 가정도 둔다. raw는 첫 번째 가정만 강조하지만 두 번째 가정도 모델의 계산 가능성과 한계를 결정한다.

상태 수를 $N$, 관측열 길이를 $T$라고 할 때 조밀한 전이의 순방향·비터비 계산은 일반적으로 $O(TN^2)$이다. 모든 경로를 직접 열거하는 대신 시간과 상태별 부분 결과를 재사용하기 때문이다. 다만 마르코프 가정이 없는 모든 수열 모델이 필연적으로 지수 시간이 된다는 뜻은 아니다. 복잡도는 모델의 의존 구조와 사용할 수 있는 분해 방식에 따라 달라진다.

평가 문제는 모든 상태 경로의 확률을 합산해 관측열의 가능도를 구한다. 디코딩 문제는 주어진 모형 안에서 가장 높은 점수의 상태 경로 하나를 찾는다. 학습 문제는 관측 자료에 맞게 전이와 방출 매개변수를 재추정한다. Baum–Welch 재추정은 반복마다 관측 가능도를 낮추지 않지만 전역 최적해를 보장하지는 않는다. 초기값과 모델 구조에 따라 정지점이나 서로 다른 국소해에 도달할 수 있다.

## 음성 인식에서 상태와 관측

음성 HMM의 상태는 음소·문맥 의존 음향 단위·더 작은 하위 상태에 대응하도록 설계할 수 있는 모델 변수다. 이를 화자의 성도나 뇌에 문자 그대로 존재하는 “진짜 소리”라고 해석하지 않는다. 관측값은 음성 파형에서 계산한 음향 특징이며, 상태 토폴로지와 발음 사전, 특징 표현, 언어 모델, 탐색 절차도 시스템 성능에 관여한다.

1975년 Jelinek·Bahl·Mercer의 디코더는 데이터 기반 통계를 사용하면서도 음소 사전과 통계적 음운 규칙, 음향 처리기의 성능을 이용하는 정합 알고리즘, 탐색 제어를 명시적으로 포함했다. HMM 음성 인식은 “규칙을 완전히 제거하고 데이터만 바꾸면 새 화자·억양·도메인을 자동 처리한 시스템”이 아니었다. 사람이 설계한 표현과 구조 안에서 매개변수 일부를 자료로 추정한 혼합 시스템으로 보는 편이 정확하다.

표준 HMM은 이산 관측만을 위한 이론이 아니다. 상태별로 연속 확률 밀도를 둘 수 있으며 가우시안 또는 가우시안 혼합 방출은 대표적인 구현이다. raw가 예로 든 MFCC도 초기 HMM 수학과 동시에 등장한 구성 요소가 아니다. Davis와 Mermelstein의 대표적 비교 연구는 1980년에 출판됐으므로 1960년대 HMM 기반, 1970년대 중반 음성 응용, 1980년 음향 특징 연구를 한 시점으로 합치지 않는다.

자기 전이가 있는 보통 HMM에서 한 상태에 머무는 길이는 기하분포 형태가 된다. Rabiner는 물리 신호의 실제 지속 시간에 이 가정이 부적절할 수 있음을 지적하고 지속 시간을 명시적으로 모델링하는 확장을 설명했다. 장거리 의존성뿐 아니라 상태 지속 시간의 형태도 표준 HMM이 현실 자료를 단순화하는 지점이다.

## NLP와 현대 모델의 범위

HMM 계열 계산은 음성 인식 밖에서도 품사 태깅 같은 순차 레이블링에 사용됐다. 그러나 raw의 개체명 인식·기계 번역 일반화는 특정 시스템과 시기를 밝히지 않으면 너무 넓다. 예를 들어 통계 기계 번역에서는 후대 HMM 계열 단어 정렬이 쓰였지만, 이를 HMM이 기계 번역 전체를 “구동했다”는 문장으로 바꾸지 않는다.

현대 [[대규모 언어 모델]]도 확률 분포와 순차 자료를 다룬다는 넓은 공통점이 있다. 하지만 HMM의 유한한 이산 상태·국소 조건부 독립 구조와 Transformer의 고차원 연속 표현·자기어텐션은 서로 다른 모델이다. RNN의 시간 역전파도 미분 가능한 순환 계산 그래프의 기울기를 구하는 절차이며, HMM의 순방향-역방향 확률 계산과 “직접 대응하는 알고리즘”은 아니다. HMM이 RNN·Transformer·LLM을 직접 낳았다는 계보보다 확률적 수열 모델링이라는 비교 가능한 문제를 공유한다고 표현한다.

## 검증 정정

- HMM의 수학적 기반은 Baum·Petrie의 1966년 연구와 1970년 재추정 논문에 놓여 있다. 1970년대는 발명 시점이 아니라 음성 응용이 본격화된 시기로 구분한다.
- [[앤드루 비터비]]의 1967년 알고리즘은 길쌈 부호 복호 연구에서 출발했으며 음성 인식을 위해 “정확히 이 목적으로” 개발된 것이 아니다.
- 표준 HMM에는 1차 상태 전이 가정뿐 아니라 상태가 주어졌을 때 관측의 조건부 독립 가정도 있다.
- 비터비 알고리즘은 최고 경로 하나를 구한다. 상태열 전체의 확률 분포나 시점별 사후확률은 순방향-역방향 계산과 구분한다.
- 날씨 예의 최고 경로는 전이·방출 확률만이 아니라 문서에 제시되지 않은 초기 상태 확률에도 의존하므로 특정 경로를 단정할 수 없다.
- Baum–Welch 재추정은 가능도를 단조롭게 개선할 수 있지만 전역 최적해를 보장하지 않는다.
- 음성 상태는 분석자가 정한 확률 모델의 변수이며 실제 조음 기관이나 뇌 속의 언어 단위를 그대로 관측한 것이 아니다.
- MFCC, 문맥 의존 음향 상태, 가우시안 혼합, 신경망-HMM 결합은 서로 다른 후속 시기의 기술이다. 이를 초기 HMM이 한꺼번에 제공한 기능으로 쓰지 않는다.
- Davis·Mermelstein의 1980년 MFCC 비교 실험은 동적 시간 정합을 사용했다. MFCC라는 특징 표현과 HMM이라는 순차 확률 모델을 같은 기술로 취급하지 않는다.
- 표준 자기 전이 HMM은 상태 지속 시간에 기하분포를 암묵적으로 부여한다. 물리적 음성 구간의 지속 시간을 항상 적절히 나타내지는 않는다.
- DRAGON의 1975년 논문은 연속 음성에 마르코프 확률 모형을 적용한 중요한 사례지만, p. 29의 실제 음성 평가는 아홉 문장을 사용한 예비 시험이었다. 이를 즉각적인 대규모 성능 혁명으로 확대하지 않는다.
- 1980년대 후반부터 2000년대 초까지 “사실상 모든” 상용 시스템이 HMM 기반이었다는 raw의 포괄적 주장은 제품별 1차 문헌이 없어 공개 핵심 사실로 채택하지 않았다.
- HMM에서 RNN·Transformer·LLM으로 이어지는 직접 지적 계보, 순방향-역방향과 시간 역전파의 직접 대응은 검증된 인과보다 구조적 비유로 한정한다.

## 핵심 문장

- HMM의 수학적 기반과 음성 인식 적용은 1960년대와 1970년대 중반의 서로 다른 단계다.
- 평가의 경로 합, 비터비 디코딩의 최고 경로, Baum–Welch 학습의 매개변수 재추정은 목적이 다르다.
- 통계적 음성 인식은 확률을 데이터에서 추정하면서도 사람이 설계한 음향 특징·상태 구조·발음 사전·언어 모델·탐색을 결합했다.
- HMM과 LLM은 확률적 수열 모델링이라는 넓은 문제를 공유하지만 직접적인 단일 계보는 아니다.

# 상징 규칙에서 통계 학습으로

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[source.005|촘스키의 통사 구조]], [[source.001|섀넌의 N-gram 모델]]<br>
> **읽고 나면:** NLP의 통계적 전환을 과제별로 다른 속도의 변화로 설명하고 상징 구조와 데이터 학습이 한 시스템에서 결합되는 방식을 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 요약

자연어 처리에서 상징적 접근은 사람이 명시한 문법 범주·규칙·논리 관계·지식 구조를 중심으로 입력을 분석한다. [[통계적 자연어 처리]]는 말뭉치에서 확률과 매개변수를 추정해 가능한 품사열·구문 트리·번역·단어열의 순위를 정한다. 두 접근의 차이는 언어 구조를 인정하는지 여부보다 구조와 지식을 어디에서 얻고, 여러 후보 가운데 하나를 어떻게 선택하는지에 있다.

[[케네스 처치]]와 Robert Mercer가 1993년에 이 흐름을 “1950년대식 경험적·통계적 방법의 부활”로 설명한 점이 중요하다. 이는 통계적 언어 처리가 1980년대에 처음 발명됐다는 뜻이 아니라, 한동안 지식 중심 연구에 가려졌던 경험적 전통이 더 큰 자료·계산·평가 관행과 결합해 다시 중심으로 이동했다는 뜻이다.

### 한 과제로 보는 차이

한 단어에 가능한 품사가 둘 이상일 때, 상징 시스템은 사람이 적은 문맥 규칙으로 후보를 거를 수 있다. 통계 시스템은 주석 말뭉치에서 각 후보의 점수를 추정해 가장 높은 것을 고를 수 있다. 실제 시스템은 품사라는 상징 범주와 데이터에서 얻은 확률을 함께 사용할 수도 있다.

### 핵심 문장

- NLP의 통계적 전환은 한 번의 1980년대 혁명보다, 1950년대식 경험적 방법이 여러 과제에서 서로 다른 속도로 재부상하고 제도화된 과정이다.
- 통계 모델의 핵심 성과는 모호성을 제거한 것이 아니라 후보의 확률을 자료에서 추정하고 보류 자료에서 선택 성능을 검증한 데 있다.
- 말뭉치와 학습은 수작업 규칙 비용을 줄이는 대신 표집·주석·희소성·영역 이동·평가라는 새 병목을 만든다.
- 형식 구조와 통계 학습은 배타적이지 않으며, 품사 태깅과 확률 파싱은 두 전통이 결합된 대표 사례다.

## 2단계 — 작동 원리

### 문제에서 평가까지

1. 언어 입력에 가능한 품사열·구문 트리·번역 같은 후보 구조를 정한다.
2. 규칙, 확률 또는 두 방법의 결합으로 후보에 제약과 점수를 준다.
3. 말뭉치에서 필요한 매개변수나 변환 규칙을 추정한다.
4. 학습에 쓰지 않은 자료와 명시된 지표로 선택 성능을 평가한다.

### 규칙·구조와 확률의 관계

[[문맥자유문법]]과 의존 문법은 문장에 계층과 문법 관계를 부여한다. [[파싱]]은 이 구조를 입력에서 찾는 계산 과정이다. 확률을 도입하면 구조가 사라지는 것이 아니라 같은 문법이 허용하는 여러 분석에 우선순위를 줄 수 있다. HMM 품사 태거도 품사라는 상징 범주를 상태로 사용하면서 전이·방출 확률을 자료에서 추정한다. 따라서 “상징”과 “통계”는 언제나 서로 배타적인 시스템 분류가 아니다.

통계적 방법의 실용적 장점은 모호성을 논리적으로 없앴다는 데 있지 않다. 가능한 후보에 점수를 부여하고, 학습 자료에 맞춘 선택 규칙을 처음 보는 자료에서 평가할 수 있게 했다는 데 있다. 수작업 규칙도 문맥·세계 지식·휴리스틱으로 모호성을 다룰 수 있지만, 개방 영역의 어휘·예외·지식을 계속 확장하는 데 [[지식 공학 병목]]이 생긴다. 통계 학습은 이 비용 일부를 자료 수집·주석·추정·평가의 비용으로 바꾼다.

1992년 Brill의 품사 태거는 이 이분법의 경계를 잘 보여 준다. 출력 모델은 사람이 읽을 수 있는 변환 규칙의 순서지만, 어떤 규칙을 추가할지는 주석 말뭉치의 오류 감소량으로 결정한다. 같은 해 Pereira와 Schabes는 사람이 부분적으로 괄호를 표시한 말뭉치와 확률 문법의 inside–outside 재추정을 결합했다. 상징적 구조와 데이터 학습은 하나의 시스템 안에서 서로 다른 역할을 맡을 수 있다.

### 말뭉치와 경험적 평가

[[말뭉치 기반 학습]]은 단순히 많은 문장을 모으는 방식이 아니다. 표본의 모집단과 장르, 주석 지침, 학습·시험 분할, 평가 지표가 모델이 무엇을 학습하고 어떤 성능을 보이는지 결정한다. Brown Corpus는 여러 장르의 기계 가독 표본을 제공했고, Penn Treebank는 약 450만 단어의 품사 주석과 일부 구문 주석을 제공했다. 이런 공유 자료가 생기면서 연구자는 같은 입력과 지표로 서로 다른 방법을 비교할 수 있었다.

데이터가 늘면 성능이 자동으로 향상된다는 보장은 없다. 목표 영역과 다른 자료, 잘못되거나 일관되지 않은 주석, 희소한 표현, 사회적 편향은 모델의 오류로 이어진다. 통계적 전환은 지식 구축 문제를 없애기보다 데이터 대표성·희소성·영역 이동·평가 설계라는 새 형태로 재배치했다.

## 3단계 — 기술과 근거

### 통계적 전환의 선행 흐름

이 변화를 “1950~1980년대 상징주의가 지배하다가 1980년대 통계 혁명으로 교체됐다”는 한 줄의 연표로 만들면 실제 문헌을 놓친다. 섀넌은 1948년에 영어의 통계 구조와 예측 가능성을 분석했고, Brown Corpus는 1963~1964년에 편찬되어 1964년에 공개됐다. Booth와 Thompson은 1973년에 문법 생성 규칙에 확률을 부여했으며, Frederick Jelinek는 1976년에 통계적 연속 음성 인식의 모델 추정·가설 탐색·언어 디코딩을 정리했다. 텍스트 NLP에서는 1988년 확률적 품사 태깅과 통계 기계 번역 연구, 1990년 번역 실험, 1993년 대규모 주석 말뭉치와 특집호가 눈에 띄는 이정표다.

### 서로 다른 과제의 시간표

| 시기 | 문헌·자원 | 확인되는 의미 |
|---:|---|---|
| 1948 | Shannon, 「A Mathematical Theory of Communication」 Part III | 영어의 통계 구조, 예측 실험과 엔트로피 근사 |
| 1956~1957 | Chomsky의 형식 문법 연구 | 유한 상태·구 구조·변환을 구분하는 명시적 언어 구조 |
| 1963~1964 | Brown Corpus 편찬·공개 | 약 100만 단어의 기계 가독 미국 영어 표본 |
| 1970 | Earley 파싱 알고리즘 | [[문맥자유문법]]을 효율적으로 처리하는 동적 파싱 절차 |
| 1973 | Booth–Thompson 확률 문법 | 생성 규칙에 확률 측도를 부여한 PCFG 계열의 선행 형식화 |
| 1976 | Jelinek 통계 음성 인식 | 모델 매개변수 추정, 가능도 계산, 가설 탐색을 결합한 연속 음성 인식 |
| 1988 | Church·DeRose | 제한 없는 텍스트의 품사 중의성을 통계적으로 결정하는 시스템 |
| 1988·1990 | Brown 외 통계 기계 번역 | 1988년 연구 계획·초기 모델과 1990년 번역 실험을 구분해야 하는 IBM 연구 |
| 1992 | Brill, Pereira–Schabes | 자료에서 규칙을 유도하는 태거와 부분 주석으로 확률 문법을 재추정하는 혼합 접근 |
| 1993 | Church–Mercer, Penn Treebank | 대규모 말뭉치 연구의 재부상에 대한 동시대 정리와 공유 주석 자료의 확장 |

이 표는 하나의 방법이 모든 과제에서 동시에 바뀌지 않았음을 보여 준다. 음성 인식의 확률 모델은 1970년대에 이미 본격화됐고, 텍스트 품사 태깅과 번역에서의 가시적인 재편은 1980년대 후반에 나타났다. 확률적 문법의 형식화와 실제 말뭉치 파싱의 확산도 구분해야 한다.

### 통계 기계 번역 사례

IBM 연구진의 1988년 「A Statistical Approach to Language Translation」는 번역을 잡음 채널의 복원 문제로 두고 언어 모델과 번역 모델을 결합하는 연구 계획을 제시했다. 그러나 이 논문은 프로젝트가 시작된 지 1년이 되지 않았고 실제 번역 결과는 아직 없다고 명시한다. 같은 연구진의 1990년 논문은 프랑스어 문장에서 영어 문장을 생성하는 매개변수화된 모델과 실험을 보고했다. 따라서 1988년 발표만으로 통계 번역이 이미 규칙 기반 번역을 경험적으로 능가했다고 쓰면 안 된다.

이 사례는 패러다임 변화가 구호·모델 제안·작동 실험·과제별 우위라는 서로 다른 단계를 거친다는 점을 보여 준다. [[규칙 기반 기계 번역]]이 한순간 사라진 것도 아니며, 후대의 [[신경망 기계 번역]] 역시 병렬 자료와 언어학적 전처리·평가라는 인간 설계를 필요로 한다.

### 지속된 상징적 구조

상징적 연구가 남긴 유산을 “오래된 규칙이 신경망 안에 그대로 들어갔다”는 직접 계보로 표현할 필요는 없다. 문법 범주, 구성 성분, 의존 관계, 합성 구조는 통계 모델의 상태·주석·예측 대상으로 계속 쓰였다. 프로그래밍 언어와 데이터 형식에도 형식 문법과 파싱이 중요하지만, 이를 자연어 파싱 연구의 직접적인 부산물이라고 단정하기보다 형식 언어 이론과 알고리즘을 공유한다고 설명하는 편이 정확하다.

현대 [[대규모 언어 모델]]은 대규모 텍스트에서 다음 토큰의 조건부 분포를 학습한다는 점에서 통계적 전통과 연결된다. 그러나 HMM처럼 사람이 정한 소수 상태와 전이·방출 표를 사용하는 모델은 아니다. 또한 LLM을 문법 제약, 검색, 코드 실행, 지식 그래프와 결합하는 시스템은 학습된 분포와 명시 구조가 현대에도 공존함을 보여 준다.

## 검증과 한계

### 검증 정정

#### 확인된 사실과 시기

- 통계적 언어 처리는 1980년대에 처음 등장하지 않았다. 1940~1970년대의 정보 이론, 말뭉치, 확률 문법, 통계 음성 인식을 선행 흐름으로 구분한다.
- Brown Corpus는 1980년대의 새 자원이 아니라 1963~1964년에 편찬되어 1964년에 공개된 약 100만 단어 말뭉치다.
- 확률적 문맥 자유 문법을 1980년대에 갑자기 등장한 것으로 묶지 않는다. Booth–Thompson의 1973년 확률 생성 문법과 1990년대의 말뭉치 기반 실용 파싱 확산은 서로 다른 단계다.

#### 합성 해석의 경계

- 규칙 기반 시스템이 문맥과 세계 지식을 “원리상” 사용할 수 없었다는 설명은 부정확하다. [[009_SHRDLU]]와 [[011_개념 의존]]은 제한된 영역에서 두 정보를 명시적으로 사용했다. 병목은 논리적 불가능성이 아니라 지식 구축과 개방 영역 확장 비용이었다.
- 규칙 하나를 추가할 때 상호작용이 항상 지수적으로 늘어난다는 일반 법칙은 없다. 문법 형식, 파싱 알고리즘, 후보 공간과 구현 방식에 따라 계산 복잡도가 달라진다.
- 자연어가 형식 체계가 아니라는 사실이 상징 시스템의 한계로 입증됐다고 단정하지 않는다. 자연어의 부분 구조는 형식 문법으로 유용하게 모델링된다. 고정된 수작업 규칙만으로 실제 사용 전체를 포괄할 수 있는지가 별도의 문제다.
- 통계 모델은 변이와 예외를 자동으로 완전히 흡수하지 않는다. 학습 자료에 거의 없는 방언·신조어·영역은 낮은 확률과 오류를 낳을 수 있다.

#### 후대 평가와 계보

- Church–Mercer는 1993년에도 기계 번역에서 합리주의적 접근이 우세하고 방법론 논쟁이 이어지고 있다고 적었다. 1990년대가 시작되자 모든 NLP가 통계 방식으로 일괄 교체됐다는 서술은 피한다.
- 상징 시스템은 항상 완전히 투명하고 통계·신경망 시스템은 항상 불투명하다는 이분법도 피한다. 명시적 규칙은 추적에 유리하지만 큰 규칙 집합과 절차 코드의 전체 동작을 설명하는 일은 여전히 어렵다.

### 적용 범위와 남은 한계

이 문서는 단일한 승자 교체를 주장하지 않고, 과제별 문헌에서 확인되는 모델·자료·평가 관행의 변화를 비교한다. `verification: partial`은 연대 근거가 비어 있다는 뜻이 아니라, 여러 과제의 변화를 하나의 전환으로 묶는 합성 판단이 포함됐다는 뜻이다.

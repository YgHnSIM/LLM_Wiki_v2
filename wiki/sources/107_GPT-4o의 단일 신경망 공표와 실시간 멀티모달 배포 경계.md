# GPT-4o의 단일 신경망 공표와 실시간 멀티모달 배포 경계

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[GPT-4]], [[멀티모달 대규모 언어 모델]], [[Transformer]]<br>
> **읽고 나면:** GPT-4o의 end-to-end 단일 신경망 공표가 실제로 말하는 범위와 말하지 않는 내부 구조를 구분하고, 2024년 5월의 model capability·제품 rollout·후속 기능 및 latency·benchmark·safety 수치의 평가 조건을 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 사건은 2024년 5월이고 글은 2025년의 회고다

원 웹글은 2025년 9월 9일 게시됐고 책 목차에서도 GPT-4o를 2025년 사건으로 배치한다. 본문은 출시를 “2025년 5월”이라고 두 차례 적지만, OpenAI의 공식 발표일은 **2024년 5월 13일**이다. 따라서 이 글은 동시대 기술 보고서가 아니라 공개 16개월 뒤의 회고이며, 날짜부터 1차 자료로 교정해야 한다.

GPT-4o에서 확인되는 중요한 변화는 text·vision·audio를 end-to-end로 학습한 하나의 새 신경망이라는 회사의 공표와, 기존 3-model 음성 pipeline보다 훨씬 낮은 audio 응답 지연을 시연한 것이다. 그러나 이 고수준 설명이 곧 하나의 공통 tokenizer, 특정 cross-modal attention, 별도 encoder·codec의 완전한 제거, 장기 memory module을 뜻하지는 않는다. OpenAI는 parameter 수, layer 구성, modality별 tokenizer·encoder·decoder, attention 변형, context 구현, loss와 ablation을 공개하지 않았다.

또한 **model이 가능하다고 발표된 입출력**과 **2024년 5월 13일 사용자가 실제로 쓸 수 있었던 제품 기능**은 달랐다. 발표 당일 ChatGPT와 API에는 text·image input과 text output이 먼저 배포됐다. Native audio output, 실시간 video와 native image generation은 안전 평가와 제품 준비를 거쳐 서로 다른 시점에 뒤따랐다.

### 네 장부로 읽는다

| 장부 | 확인 질문 | GPT-4o에서 확인되는 답 |
| --- | --- | --- |
| Training claim | 무엇을 함께 학습했다고 밝혔는가? | Text·vision·audio를 한 신경망에서 end-to-end로 학습 |
| Announced model I/O | Model family가 무엇을 받고 낼 수 있다고 공표했는가? | Text·audio·image·video 입력, text·audio·image 출력의 임의 조합 |
| Launch surface | 2024-05-13에 무엇을 실제 배포했는가? | ChatGPT·API의 text·image input과 text output |
| Later product surface | 후속 기능은 언제 별도로 공개됐는가? | Advanced Voice, API realtime audio, video·screen share, native image generation이 단계적으로 추가 |

### 핵심 문장

- “같은 신경망이 모든 입력과 출력을 처리한다”는 공식 공표는 인용할 수 있지만, 비공개 modality interface를 임의의 “공유 token 공간”이나 “별도 encoder 없음”으로 채우면 안 된다.
- 232 ms 최저·320 ms 평균은 OpenAI가 보고한 **audio input에 대한 model 응답 latency**다. Network·device·streaming을 포함한 모든 사용자 환경의 보장치가 아니다.
- 발표한 model I/O, 출시 당일 product surface, system card가 평가한 snapshot과 후속 rollout을 날짜별로 분리해야 한다.
- 시연과 benchmark는 가능성을 보여 주지만 “인간과 구별되지 않는 의사소통”, 임상 효과, 일반 지능을 증명하지 않는다.

## 2단계 — 작동 원리

### 3-model 음성 pipeline에서 native audio model로

기존 ChatGPT Voice Mode는 대략 다음 세 단계를 거쳤다.

$$
\text{audio}
\xrightarrow{\text{ASR}}
\text{text}
\xrightarrow{\text{GPT-3.5/4}}
\text{text}
\xrightarrow{\text{TTS}}
\text{audio}
$$

OpenAI가 2024년 5월 발표한 평균 지연은 GPT-3.5 pipeline 2.8초, GPT-4 pipeline 5.4초였다. 이 경로에서는 중심 language model이 tone, 여러 speaker, 배경 소리를 직접 보지 못하고 laughter·singing·emotion을 직접 생성하지도 못한다. GPT-4o는 text·vision·audio를 end-to-end로 학습한 한 model이 audio를 직접 조건으로 받고 audio를 낼 수 있게 설계됐다고 공표됐다. 이 차이가 발표 당시 “omni”의 가장 구체적인 의미다.

### 단일 신경망은 단일 전처리를 뜻하지 않는다

Multimodal model을 다음처럼 추상화할 수 있다.

$$
z_m=T_m(x_m),\qquad
h=F_\theta(z_{m_1},\ldots,z_{m_k}),\qquad
y_o=H_o(h)
$$

$T_m$은 waveform·pixel·text를 model 표현으로 바꾸는 modality interface, $F_\theta$는 공유 core, $H_o$는 text·audio·image 출력 경계다. GPT-4o 공식 자료는 이 전체가 같은 신경망에서 end-to-end로 훈련됐다고 말하지만, $T_m$, $F_\theta$, $H_o$의 구현을 공개하지 않는다. 따라서 다음 세 문장은 서로 다른 주장이다.

1. 여러 modality가 gradient를 통해 공동 학습됐다.
2. 여러 modality가 일부 core weight를 공유한다.
3. Raw waveform·pixel·text가 같은 tokenizer와 완전히 같은 계산 경로를 쓴다.

공식 자료는 1번을 명시하고 single-network 처리를 공표하지만, 3번을 재현 가능한 구조로 설명하지 않는다. “Unified tokenization이 별도 encoder와 fusion을 제거했다”, “고급 cross-modal attention이 실시간 성능을 만들었다”는 원 웹글의 서술에는 이를 확인할 layer diagram·algorithm·ablation이 없다.

### Latency는 측정 경계를 붙여 읽는다

사용자가 체감하는 전체 지연은 대략 다음 항들의 합이다.

$$
L_{\mathrm{user}}
=L_{\mathrm{capture}}
+L_{\mathrm{network}}
+L_{\mathrm{model}}
+L_{\mathrm{stream}}
+L_{\mathrm{playback}}
$$

OpenAI는 GPT-4o가 audio input에 최저 232 ms, 평균 320 ms로 응답할 수 있다고 보고했다. 발표문은 이 수치의 표본 수, hardware, input 길이, network 조건과 percentile 분포를 공개하지 않았다. 그러므로 이를 중요한 공개 성능 지표로 기록하되, 모든 기기·지역·대화에서의 end-to-end SLA나 “인간과 동일한 상호작용”으로 확대하지 않는다.

### Context와 제품 memory는 내부 memory module의 증거가 아니다

대화 기록을 context에 다시 넣는 것, ChatGPT의 제품 memory가 사용자 정보를 저장·검색하는 것, model 내부에 recurrent memory mechanism이 있는 것은 서로 다른 구조다. 원 웹글은 GPT-4o가 별도의 memory mechanism으로 긴 multimodal interaction을 유지한다고 말하지만 공식 발표와 system card는 그런 module을 설명하지 않는다. 관찰되는 multi-turn 일관성만으로 내부 memory architecture를 역추론하지 않는다.

## 3단계 — 기술과 근거

### 가능한 입출력과 공개 시점

| 시점 | 공식적으로 확인되는 공개 범위 | 이 시점에 소급하면 안 되는 기능 |
| --- | --- | --- |
| 2024-05-13 | GPT-4o 발표; ChatGPT·API에서 text·image input과 text output 시작 | Native audio output·real-time video·native image generation의 일반 이용 |
| 2024-08-08 | GPT-4o System Card; 제한된 Advanced Voice alpha와 voice 위험 평가 공개 | 모든 지역·plan·API의 일반 제공 |
| 2024-09-24 | Plus·Team에 GPT-4o native audio 기반 Advanced Voice rollout | 발표 당일 이미 배포됐다는 서술 |
| 2024-10-01 | Realtime API public beta에서 GPT-4o speech-to-speech surface 제공 | 2024년 5월 API가 이미 audio·video를 지원했다는 서술 |
| 2024-12-12 | Advanced Voice의 video·screen share 단계적 rollout 시작 | 2024년 5월 live camera 기능의 일반 제공 |
| 2025-03-25 | GPT-4o native image generation의 ChatGPT rollout | 2024년 5월 text-to-image 제품 공개 |

후대 기능은 GPT-4o 계열의 폭을 보여 주지만 launch surface를 바꾸지는 않는다. Model snapshot, ChatGPT feature, API endpoint와 공개 날짜를 함께 기록한다.

### 새 tokenizer에서 확인되는 것

발표문은 새 tokenizer의 언어별 압축 예시 20개를 제시했다. 같은 예문에서 한국어는 45 token에서 27 token으로, Gujarati는 145에서 33으로 줄었다. 이는 특정 문자열에서 tokenization 효율이 개선됐다는 증거다. Vocabulary 크기, algorithm, audio·vision codec과 text tokenizer의 관계, 전체 corpus 평균 compression, downstream quality의 인과는 공개되지 않았다. 이 표를 “모든 modality를 하나의 shared token space로 바꿨다”는 architecture 증명으로 사용할 수 없다.

### 능력 benchmark와 제품 주장을 분리한다

2024년 5월 발표는 전통 benchmark에서 GPT-4 Turbo 수준의 English text·reasoning·coding 성능, multilingual·audio·vision의 개선을 보고했다. 하지만 공개 chart는 model snapshot, prompt·decoding, sample 수와 통계적 불확실성을 모든 항목에 일관되게 제공하지 않는다. 개별 benchmark 결과를 “모든 modality에서 인간 수준”으로 합산하지 않는다.

2024년 8월 system card의 underrepresented-language 평가는 Amharic·Hausa·Northern Sotho·Swahili·Yoruba의 translated ARC-Easy·TruthfulQA와 새 Uhura-Eval을 0-shot으로 비교했다. 이는 English 밖의 개선을 더 구체적으로 보여 주지만, 번역 dataset과 다섯 언어라는 평가 범위를 유지해야 한다.

### Audio 안전 평가는 audio 전체를 직접 채점하지 않았다

System card는 기존 text 평가를 Voice Engine TTS로 변환해 GPT-4o에 넣고, voice cloning처럼 음향 자체가 핵심인 경우를 제외하면 **출력 transcript의 text 내용**을 채점했다.

$$
\text{text task}
\xrightarrow{\mathrm{TTS}}
\text{audio prompt}
\xrightarrow{\mathrm{GPT\text{-}4o}}
\text{audio output}
\xrightarrow{\mathrm{transcription}}
\text{text score}
$$

이 protocol은 많은 기존 평가를 재사용할 수 있지만 수식·code·공백·기호가 TTS에서 손실될 수 있다. 실제 사용의 intonation, background noise, cross-talk와 interruption도 충분히 포착하지 못하고, transcript 점수는 음향적 artifact나 승인되지 않은 voice를 놓칠 수 있다. OpenAI는 별도 voice classifier와 일부 직접 음향 평가를 함께 사용했다.

### 안전 수치는 내부 조건과 완화책을 포함한다

System card는 2024년 3월부터 6월까지 100명이 넘는 external red teamer가 45개 언어·29개국 배경으로 여러 개발 snapshot을 시험했다고 기록한다. 발표 당일의 “70명 이상”과 수가 다른 것은 평가가 후속 단계까지 확대됐기 때문이다.

중요한 결과는 조건과 함께 읽는다.

- 승인되지 않은 voice 생성을 막기 위해 preset voice만 허용하고 streaming output classifier를 적용했다. “의미 있는 이탈 100% 포착”은 공개된 내부 sample 조건의 결과이지 모든 공격에 대한 보증이 아니다.
- Speaker identification safe behavior의 should-refuse 정확도는 early 0.83에서 deployed 0.98로, should-comply는 0.70에서 0.83으로 보고됐다. Privacy risk 감소와 benign over-refusal을 함께 본다.
- Text safety task를 audio로 옮긴 평가에서 not-unsafe는 text 0.95, audio 0.93, not-over-refuse는 0.81과 0.82였다. TTS·transcript 기반 조건을 떼어 내지 않는다.
- Preparedness 평가는 cyber·biological threat·model autonomy를 low, persuasion을 borderline medium으로 분류했다. Voice persuasion은 low였고 text persuasion이 medium 경계를 넘었다. 최고 category를 따라 overall medium이 됐다.

이는 model·post-training·preset voice·classifier·moderation·monitoring을 합친 배포 system 평가다. “GPT-4o model 자체가 안전하다”는 무조건 명제가 아니다.

### 시연 가능한 응용과 검증된 현장 효과

실시간 통역, screen·camera context, 접근성, tutoring은 중요한 사용 가능성이다. 그러나 원 웹글의 교육 효과, 의료 workflow 개선, 더 철저한 환자 care, robotics·autonomous vehicle·smart-home 계보에는 task protocol, 임상 외부 검증, 사용자 연구, deployment 통계가 없다. 특히 medical image와 spoken symptom을 함께 처리할 수 있다는 capability가 진단 정확도·책임·privacy를 자동으로 충족하지 않는다.

“Communication quality가 인간과 구별되지 않는다”, 여러 modality가 “더 인간 같은 이해”를 만들었다는 표현도 별도 blinded human study나 general-intelligence 평가 없이 성립하지 않는다. 빠르고 표현력 있는 interface와 신뢰할 수 있는 world model은 다른 주장이다.

## 검증과 한계

### 원 웹글의 주요 정정

- **GPT-4o는 2025년 5월 출시됐다:** 공식 발표는 2024-05-13이다. 원 웹글은 2025-09-09 게시된 후대 회고다.
- **출시 때 speech·vision·text를 동시에 자유롭게 입출력했다:** 발표된 model I/O는 넓었지만 당일 제품은 text·image input과 text output부터 배포했다.
- **GPT-4o는 모든 modality의 unified tokenizer를 공개했다:** 발표문은 새 language tokenizer의 예문별 compression만 공개했다. Audio·vision과의 shared vocabulary·codec 구조는 비공개다.
- **별도 encoder와 fusion mechanism을 제거했다:** Single-network end-to-end 공표만으로 modality-specific interface가 없다고 결론 내릴 수 없다.
- **특수 cross-modal attention이 성능을 만들었다:** Attention layer·fusion 위치·ablation이 공개되지 않았다.
- **별도 memory mechanism이 장기 multimodal coherence를 보장한다:** 공식 구조 명세가 없다. Context window와 제품 memory도 별개다.
- **232–320 ms는 모든 사용자의 전체 대화 latency다:** Audio input에 대한 보고 수치이며 device·network·streaming을 포함한 보편적 SLA가 아니다.
- **하나의 model이라 compute가 줄었다:** API는 GPT-4 Turbo보다 2배 빠르고 절반 가격으로 발표됐지만, 이를 modality 통합 한 요소의 인과 효과로 분해한 ablation은 없다.
- **Image 생성·live video·screen share가 출시일부터 제공됐다:** 이 기능들은 2024년 하반기와 2025년에 별도 rollout됐다.
- **Multimodal interaction은 인간과 구별되지 않았다:** 이를 뒷받침하는 포괄적 blinded 평가가 없다.
- **교육·의료·robotics를 이미 변혁했다:** 가능한 use case와 검증된 현장 효과가 혼합돼 있다.
- **여러 modality 처리는 더 인간 같은 이해·일반 지능의 증거다:** Channel 수, grounding, causal reasoning과 reliability는 별도 평가가 필요하다.

### 공개된 것과 비공개인 것

| 구분 | 내용 |
| --- | --- |
| 확인 | Autoregressive omni model이라는 설명, text·vision·audio end-to-end training, 넓은 model I/O 공표, launch rollout, latency·평가·안전 수치 |
| 비공개 | Parameter 수, dense·MoE 여부, layer·attention, modality tokenizer·encoder·decoder·codec, context·memory 구현, 총 compute, dataset composition, loss·ablation |
| 외삽 금지 | “Unified token space”, encoder 제거, 통합이 latency·가격 개선의 단일 원인, 인간 수준 일반 이해, 분야별 실사용 효과 |

### System card의 snapshot과 제품 변화를 고정한다

System card는 여러 개발 checkpoint와 2024년 제한 alpha를 평가했고, 그 뒤에도 model snapshot·voice·moderation·API surface가 바뀌었다. 후속 ChatGPT 기능을 2024년 5월 model launch의 속성으로 소급하지 않고, 반대로 초기 제한을 GPT-4o 계열의 영구 사양으로도 고정하지 않는다. 평가에는 날짜, snapshot, modality, product surface와 보조 classifier를 함께 적는다.

### 공개 자료의 재현성 한계

OpenAI 자료는 제품 배포와 risk evaluation을 상세히 제공하지만 공개 weight·training code·architecture diagram·dataset 목록·end-to-end benchmark recipe는 제공하지 않는다. 따라서 GPT-4o를 [[105_통합 멀티모달 아키텍처의 공유 범위와 입출력 경계|공개 멀티모달 model]]의 layer 수준 구조처럼 재현하거나, 특정 내부 부품을 후속 model의 직접 계보로 연결할 수 없다.

# 파운데이션 모델 보고서와 AI 생태계

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[언어 모델 전이 학습]], [[대규모 언어 모델]]<br>
> **읽고 나면:** 2021년 보고서의 파운데이션 모델 정의와 창발·동질화의 양면성을 설명하고, 보고서의 연구 의제와 2025년 회고 글의 후대 평가를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 문장

Bommasani 등은 [[파운데이션 모델]]을 광범위한 데이터로 대규모 훈련한 뒤 다양한 후속 과제에 적응할 수 있는 모델로 정의했다. 이 이름은 단순히 매개변수가 큰 모델이 아니라 **하나의 모델이 여러 응용의 공통 기반으로 재사용되는 역할**을 가리킨다.

보고서가 꼽은 핵심은 창발(emergence)과 동질화(homogenization)다. 창발은 행동이 사람이 과제별 규칙으로 직접 구성한 것이 아니라 학습에서 암묵적으로 형성된다는 뜻이다. 동질화는 여러 응용이 같은 방법을 넘어 같은 기반 모델까지 공유하는 현상이다.

이 두 현상은 기회와 위험을 동시에 만든다. 공통 모델을 한 번 개선하면 여러 응용이 이익을 얻을 수 있지만, 편향·취약점·접근 제한도 여러 파생 시스템으로 전파될 수 있다.

### 역사적 위치

*On the Opportunities and Risks of Foundation Models*의 arXiv 초판은 2021년 8월 16일 공개됐다. 2022년 7월 12일의 v3 PDF는 총 214면이며, 26개 본문 절과 p. 161의 결론 뒤에 참고문헌·부록이 이어진다. 114명이 저자로 참여했고, Author Contributions는 Percy Liang이 전체 구상과 구조를 시작해 Liang과 Rishi Bommasani가 집필을 공동 주도했다고 기록한다.

보고서는 새 model이나 benchmark를 발표한 실험 논문이 아니다. 당시의 연구를 26개 절로 종합해 능력, 응용, 기술과 사회를 함께 조사하고 다음 연구 의제를 제시한 보고서다. [[BERT]], GPT-3와 [[CLIP]]은 본문 §1의 당시 사례이며 초록에는 [[DALL·E (2021)|DALL·E]]도 나온다.

### 이 문서의 범위

프로젝트 raw는 Michael Brenndoerfer가 2025년 7월 29일 공개한 회고 글의 번역과 해설이다. 회고 글은 보고서의 정의와 위험을 소개하면서 후대의 연구·정책 영향도 평가한다. 공개 문서는 2021년 보고서가 직접 말한 내용, 당시의 전망, 2025년 저자의 후대 평가를 분리한다.

## 2단계 — 작동 원리

### 과제별 모델보다 공통 기반을 본다

전통적인 과제별 관점에서는 번역기·분류기·검색기를 별개 모델로 평가한다. 파운데이션 모델 관점은 이 응용들이 같은 사전 학습 모델을 출발점으로 삼는지를 묻는다. 분석 단위가 model 하나에서 다음 생태계로 넓어진다.

1. 사람이 data를 만들고 조직이 이를 수집·선별한다.
2. 큰 data와 compute로 파운데이션 모델을 훈련한다.
3. 개발자가 fine-tuning·prompting 같은 방법으로 특정 과제에 적응시킨다.
4. 적응 model을 domain data, 도구, interface와 결합해 배포한다.
5. 실제 사용자는 완성된 응용의 출력과 영향을 경험한다.

보고서는 파운데이션 모델을 완성된 사용자 제품보다 중간 자산(intermediary asset)으로 본다. 기반 모델의 성질은 중요하지만 실제 결과는 적응 자료·접근 권한·도구·배포 맥락과 함께 만들어진다.

### 창발은 예상 밖 행동을 조사하게 한다

2021년 보고서에서 창발은 system behavior가 명시적으로 구성되지 않고 학습에서 암묵적으로 유도되는 현상이다. 유용한 능력뿐 아니라 예상하지 못한 실패도 포함한다. 그래서 모델이 무엇을 할 수 있고 언제 실패하는지 사후에 발견하고 평가해야 한다.

이는 후대의 좁은 ‘창발 능력’ 정의와 같지 않다. 2022년 이후 일부 연구는 작은 model에서는 보이지 않던 특정 task score가 큰 model에서 나타나는 곡선을 창발 능력이라 불렀다. 두 용어의 측정 경계는 [[손실 곡선과 능력 곡선 사이]]에서 따로 비교한다.

### 동질화는 개선과 결함을 함께 전파한다

여러 응용이 같은 기반을 쓰면 개선 노력을 한곳에 집중할 수 있다. Base model의 효율이나 robustness가 좋아지면 여러 적응 모델이 그 이익을 이어 받을 가능성이 있다.

반대 방향도 같다. 기반 data의 누락, 편향이나 보안 취약점은 여러 하위 응용에 공통 실패점을 만들 수 있다. 소수 조직이 학습 compute와 model access를 통제하면 하위 개발자의 참여가 늘더라도 핵심 설계 권력은 집중될 수 있다.

### 평가는 기반과 응용을 나누어야 한다

보고서 §4.4는 적응 전 내재 평가(intrinsic evaluation)와 특정 과제로 적응한 뒤의 외재 평가(extrinsic evaluation)를 구분한다. 같은 기반을 공정하게 비교하려면 적응 data, model access와 compute 같은 자원을 통제해야 한다.

정확도 하나만으로 충분하지 않다. Robustness·fairness·efficiency·environmental impact도 함께 봐야 한다. 실제 harm은 특정 domain과 사용자에게 배포된 응용에서 생기므로, 기반 model benchmark와 배포 결과를 같은 수치처럼 읽지 않는다.

이 구분은 [[079_HELM과 다차원 언어 모델 평가|HELM]]과 비교해 읽을 수 있다. HELM은 범용 언어 모델을 같은 scenario·adaptation 조건에 놓고 여러 metric으로 비교하지만, 그 결과 역시 특정 prompt와 benchmark에서 관측한 외재 행동이며 실제 배포의 효용과 harm을 대신하지 않는다.

## 3단계 — 기술과 근거

### 정의의 정확한 범위

보고서 §1은 파운데이션 모델을 광범위한 데이터로, 일반적으로 대규모 자기지도 학습을 통해 훈련하고, 다양한 후속 과제에 적응할 수 있는 모델로 정의한다. 이 정의에는 세 가지 중요한 경계가 있다.

- **광범위한 데이터:** 좁은 단일 과제의 표지 자료를 넘어선다는 뜻이지 모든 언어·영역·양식을 반드시 포함한다는 뜻은 아니다.
- **대규모 훈련:** 최근 모델의 규모와 범위가 중요하지만 deep learning·self-supervision·transfer learning 자체가 2021년에 새로 발명됐다는 뜻은 아니다.
- **적응:** Fine-tuning이 명시적인 예이며 prompting도 가능한 방식이다. 과제별 학습이 반드시 ‘거의 없어야’ 하는 것은 아니다.

따라서 [[BERT]]의 전체 미세조정과 GPT-3의 [[문맥 내 학습]]은 서로 다른 적응 경로이면서 같은 범주 안에서 비교될 수 있다. [[CLIP]]처럼 언어 모델이 아닌 image–text model도 여러 후속 과제의 기반으로 적응되므로 사례가 된다.

### 보고서가 조직한 네 영역

보고서의 큰 구조는 다음 네 묶음이다.

| 영역 | 보고서가 묻는 질문 | 입증 범위 |
|---|---|---|
| Capabilities | 언어·비전·로보틱스·추론·상호작용에서 무엇이 가능하고 부족한가 | 개별 문헌의 결과와 향후 질문을 종합한다 |
| Applications | 의료·법·교육에서 어떤 필요 조건과 위험이 있는가 | 실제 모든 영역의 배포 효과를 측정하지 않는다 |
| Technology | 모델링·학습·데이터·시스템·보안·평가·이론·해석 가능성을 어떻게 연구할 것인가 | 하나의 공통 benchmark나 새 model을 제안한 것이 아니다 |
| Society | 불평등·오용·환경·법·경제·규모의 윤리를 어떻게 다룰 것인가 | 영향의 크기와 정책 효과를 단일 실험으로 추정하지 않는다 |

회고 글의 ‘기술·사회·윤리’ 3분류는 유용한 요약이지만 원 보고서의 목차를 그대로 복원한 것은 아니다.

### 접근 확대와 권력 집중은 같은 구조에서 나온다

이미 훈련된 모델을 적응시키면 처음부터 훈련하는 것보다 data·compute 비용을 줄일 수 있다. 그러나 보고서는 model 공개만으로 참여가 민주화된다고 보지 않는다. Weight 접근, API 조건, 적응 compute와 engineering expertise가 새 장벽이 될 수 있다.

§1.3과 §5.6은 대규모 학습 능력이 산업에 집중된 현실과 학계의 접근성 저하를 함께 다룬다. ‘하위 응용 개발자가 늘었다’와 ‘기반 설계 권력이 분산됐다’는 서로 다른 주장이다.

### 환경 영향은 훈련과 추론을 모두 포함한다

회고 글은 2021년 보고서가 추론의 환경 영향을 충분히 포착하지 못했다고 평가한다. 그러나 보고서 §5.3은 훈련 energy뿐 아니라 대규모 inference·deployment의 반복 비용, 전력망과 carbon intensity, 여러 사용에 걸친 훈련 비용의 상각을 이미 논의했다.

후대의 실제 배포 규모와 측정 자료로 분석을 갱신할 필요는 있다. 그렇다고 추론 비용이 원 보고서에 없었다고 쓸 수는 없다.

### 보고서의 범위와 작성 책임

보고서 제목의 저자 순서는 Rishi Bommasani, Drew A. Hudson, Ehsan Adeli 등으로 시작한다. 이것이 곧 세 사람이 전체 기획을 같은 방식으로 이끌었다는 뜻은 아니다. p. 14의 기여 명세는 Percy Liang과 Rishi Bommasani가 분산 집필을 공동 주도했고 Drew A. Hudson은 모든 도표를 만들었다고 구분한다.

초판은 2021년 8월 16일, v2는 8월 18일, 현재 arXiv v3는 2022년 7월 12일이다. 본문의 페이지 locator는 v3 PDF를 기준으로 한다.

## 검증과 한계

### 원문 상태

Raw 번역은 2025년 회고 글의 서술을 충실히 보존한다. 글 안의 `/writing/...` 링크는 같은 사이트의 설명 페이지로 이동하는 탐색 링크이며, 2021년 보고서 주장의 1차 근거가 아니다.

회고 글은 보고서가 공통 어휘를 제공했다는 핵심을 잘 짚지만, 당시의 연구 의제와 후대의 결과를 한 흐름에 섞는다. ‘분수령’, ‘가장 영향력 있는 문서’, ‘정책과 투자를 변화시켰다’ 같은 표현은 2025년 저자의 평가다.

### 검증 정정

- **Drew Hudson·Ehsan Adeli 등이 전체 보고서를 이끌었다:** 기여 명세는 Percy Liang과 Rishi Bommasani의 집필 공동 주도, Hudson의 도표 기여를 구분한다.
- **보고서의 인용 정의가 원문 그대로다:** 회고 글의 따옴표 문장은 원 보고서 정의를 줄여 다시 쓴 표현이다.
- **최소 과제별 학습이 정의 요건이다:** 적응 가능성이 요건이며 BERT 같은 미세조정 계열도 포함된다.
- **GPT-4가 2021년 보고서의 사례다:** GPT-4는 2023년에 공개됐다. 2021년 본문 사례는 BERT·GPT-3·CLIP이다.
- **파운데이션 모델은 모두 대규모 언어 모델이다:** 이 이름은 modality보다 downstream ecosystem에서의 역할을 강조한다.
- **보고서가 새 deep-learning 기술을 발명했다:** 보고서는 기반 기술이 새롭지 않으며 최근의 규모·범위가 가능성과 위험을 바꿨다고 명시한다.
- **파운데이션 모델이 접근을 민주화했다:** 비용을 나눌 기회와 compute·access·ownership 집중 위험을 함께 제시했다. 달성된 효과를 측정한 주장이 아니다.
- **여러 영역의 지식·이해·추론을 보편적으로 입증했다:** 보고서는 개별 연구를 종합하고 능력의 불확실성과 grounding 문제를 연구 의제로 남겼다.
- **보고서가 inference 환경비용을 빠뜨렸다:** §5.3에서 훈련과 반복 추론의 energy·carbon cost를 모두 논의한다.
- **보고서가 bias·alignment·prompting·scaling 연구와 규제를 촉발했다:** 이 연구 주제 다수는 2021년 이전부터 존재했다. 직접 영향에는 후속 citation과 정책 기록이 필요하다.

### 남는 한계

파운데이션 모델 정의에는 data breadth, scale과 downstream range의 경계값이 없다. 서로 다른 architecture·training·access 조건을 한 범주로 묶으면 차이를 가릴 수 있다.

보고서 자체도 패러다임이 막 시작됐고 작동·실패·능력에 대한 이해가 부족하다고 밝혔다. 응용 장의 상당 부분은 가능성과 필요 조건이지 의료·법·교육의 배포 효과를 확인한 결과가 아니다.

공통 이름은 협업을 돕지만 대규모 사전 학습 패러다임을 불가피한 중심으로 보이게 할 수 있다. 동시대 비평은 grounding 부족, 교육 내용의 동질화, 관련 역사와 대안 연구의 주변화를 우려했다. 이들은 검증된 보편 결과가 아니라 보고서가 연 비판적 논쟁의 일부다.

# Overview

이 위키는 현재 언어 모델링의 초기 역사, 언어 기반 AI 평가, 초기 [[기계 번역]], 신경망 학습, 그리고 언어 구조 이론의 형성을 함께 다룬다. 첫 소스인 [[001_섀넌의 N-gram 모델]]은 [[클로드 섀넌]]의 정보 이론이 [[N-gram 모델]], [[조건부 확률]], [[마르코프 가정]]을 통해 자연어 처리의 통계적 패러다임으로 이어지는 흐름을 설명한다. 두 번째 소스인 [[002_튜링 테스트]]는 [[앨런 튜링]]의 [[모방 게임]]이 자연어 대화를 기계 지능 평가의 중심 장면으로 만든 과정을 정리한다. 세 번째 소스인 [[003_Georgetown-IBM 기계 번역 시연]]은 1954년 공개 시연이 [[규칙 기반 기계 번역]]과 계산언어학 연구의 제도적 출발점 중 하나가 되었음을 보여준다. 네 번째 소스인 [[004_퍼셉트론]]은 [[프랭크 로젠블랫]]의 [[퍼셉트론]]이 예시에서 가중치를 학습하는 신경망 계보를 열었음을 정리한다. 다섯 번째 소스인 [[005_촘스키의 통사 구조]]는 [[노엄 촘스키]]의 [[통사 구조]] 이론이 형식문법과 언어 AI의 구조 논쟁을 열었음을 보여준다.

## 현재 핵심 주제

- 언어를 규칙 기반 체계가 아니라 확률적 예측 대상으로 보는 관점
- n-gram 모델의 실용성과 한계
- [[데이터 희소성]]과 [[Smoothing]]의 필요성
- [[Perplexity]]와 정보 이론적 언어 모델 평가
- [[대규모 언어 모델]]과 [[N-gram에서 LLM으로]] 이어지는 다음 토큰 예측의 계보
- [[튜링 테스트]]와 [[행동주의적 지능 기준]]
- 현대 LLM 평가에서 인간 유사성, 이해, 신뢰성의 관계
- 냉전기 정보 수요와 초기 [[기계 번역]] 연구
- [[지식 공학 병목]]과 규칙 기반 NLP에서 학습 기반 NLP로의 전환
- 통제된 AI 시연과 실제 성능 평가의 간극
- [[퍼셉트론]], [[지도 학습]], [[선형 분리 가능성]]을 통한 신경망 학습의 초기 형식화
- [[XOR 문제]]와 단층 모델의 한계
- [[규칙 기반 AI에서 데이터 기반 학습으로]] 이어지는 방법론 전환
- [[통사론]], [[변형생성문법]], [[문맥자유문법]]을 통한 언어 구조의 형식화
- [[자극의 빈곤]]과 [[보편문법]]을 둘러싼 언어 습득 논쟁
- [[촘스키에서 LLM으로]] 이어지는 구조적 언어관과 데이터 기반 학습의 긴장

## 현재 상태

다섯 번째 소스 처리까지 완료되어 소스 요약 5개, 개념 페이지 34개, 개체 페이지 9개, 분석 페이지 5개가 정리되었다. 현재까지 페이지 간 직접 모순은 발견되지 않았다. 새 소스는 기존 통계적 언어 모델링 계보, 언어 행동 기반 평가 축, 초기 기계 번역 축, 데이터 기반 신경망 학습 축에 언어 구조와 형식문법의 축을 추가한다.

# Overview

이 위키는 현재 언어 모델링의 초기 역사, 언어 기반 AI 평가, 초기 [[기계 번역]]의 형성을 함께 다룬다. 첫 소스인 [[001_섀넌의 N-gram 모델]]은 [[클로드 섀넌]]의 정보 이론이 [[N-gram 모델]], [[조건부 확률]], [[마르코프 가정]]을 통해 자연어 처리의 통계적 패러다임으로 이어지는 흐름을 설명한다. 두 번째 소스인 [[002_튜링 테스트]]는 [[앨런 튜링]]의 [[모방 게임]]이 자연어 대화를 기계 지능 평가의 중심 장면으로 만든 과정을 정리한다. 세 번째 소스인 [[003_Georgetown-IBM 기계 번역 시연]]은 1954년 공개 시연이 [[규칙 기반 기계 번역]]과 계산언어학 연구의 제도적 출발점 중 하나가 되었음을 보여준다.

## 현재 핵심 주제

- 언어를 규칙 기반 체계가 아니라 확률적 예측 대상으로 보는 관점
- n-gram 모델의 실용성과 한계
- [[데이터 희소성]]과 [[Smoothing]]의 필요성
- [[Perplexity]]와 정보 이론적 언어 모델 평가
- [[대규모 언어 모델]]과 [[N-gram에서 LLM으로]] 이어지는 다음 토큰 예측의 계보
- [[튜링 테스트]]와 [[행동주의적 지능 기준]]
- 현대 LLM 평가에서 인간 유사성, 이해, 신뢰성의 관계
- 냉전기 정보 수요와 초기 [[기계 번역]] 연구
- [[지식 공학 병목]]과 규칙 기반 NLP에서 학습 기반 NLP로의 전환
- 통제된 AI 시연과 실제 성능 평가의 간극

## 현재 상태

세 번째 소스 처리까지 완료되어 소스 요약 3개, 개념 페이지 14개, 개체 페이지 6개, 분석 페이지 3개가 정리되었다. 현재까지 페이지 간 직접 모순은 발견되지 않았다. 새 소스는 기존 통계적 언어 모델링 계보와 언어 행동 기반 평가 축에, 실용 과업으로서의 번역과 AI 시연 평가라는 축을 추가한다.

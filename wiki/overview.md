# Overview

이 위키는 현재 언어 모델링의 초기 역사, 언어 기반 AI 평가, 초기 [[기계 번역]], 신경망 학습과 공학적 배치, 언어 구조 이론, 대화형 AI의 형성을 함께 다룬다. 첫 소스인 [[001_섀넌의 N-gram 모델]]은 [[클로드 섀넌]]의 정보 이론이 [[N-gram 모델]], [[조건부 확률]], [[마르코프 가정]]을 통해 자연어 처리의 통계적 패러다임으로 이어지는 흐름을 설명한다. 두 번째 소스인 [[002_튜링 테스트]]는 [[앨런 튜링]]의 [[모방 게임]]이 자연어 대화를 기계 지능 평가의 중심 장면으로 만든 과정을 정리한다. 세 번째 소스인 [[003_Georgetown-IBM 기계 번역 시연]]은 1954년 공개 시연이 [[규칙 기반 기계 번역]]과 계산언어학 연구의 제도적 출발점 중 하나가 되었음을 보여준다. 네 번째 소스인 [[004_퍼셉트론]]은 [[프랭크 로젠블랫]]의 [[퍼셉트론]]이 예시에서 가중치를 학습하는 신경망 계보를 열었음을 정리한다. 다섯 번째 소스인 [[005_촘스키의 통사 구조]]는 [[노엄 촘스키]]의 [[통사 구조]] 이론이 형식문법과 언어 AI의 구조 논쟁을 열었음을 보여준다. 여섯 번째 소스인 [[006_위드로-호프의 MADALINE]]은 [[ADALINE]], [[LMS 알고리즘]], [[MADALINE]]을 통해 초기 신경망이 통신과 신호 처리의 실제 시스템으로 이동한 과정을 다룬다. 일곱 번째 소스인 [[007_ELIZA]]는 [[ELIZA]]가 패턴·템플릿·치료사 역할을 이용해 대화의 설득력을 만들고, 그 과정에서 [[ELIZA 효과]]라는 이해와 의인화의 문제를 드러낸 역사를 정리한다.

## 현재 핵심 주제

- 언어를 규칙 기반 체계가 아니라 확률적 예측 대상으로 보는 관점
- n-gram 모델의 실용성과 한계
- [[데이터 희소성]]과 [[Smoothing]]의 필요성
- [[Perplexity]]와 정보 이론적 언어 모델 평가
- [[대규모 언어 모델]]과 [[N-gram에서 LLM으로]] 이어지는 다음 토큰 예측의 계보
- [[튜링 테스트]]와 [[행동주의적 지능 기준]]
- 현대 LLM 평가에서 인간 유사성, 이해, 신뢰성의 관계
- 냉전기 정보 수요와 초기 [[기계 번역]] 연구
- [[지식 공학 병목]]과 규칙 기반 NLP에서 학습 기반 NLP로의 전환
- 통제된 AI 시연과 실제 성능 평가의 간극
- [[퍼셉트론]], [[지도 학습]], [[선형 분리 가능성]]을 통한 신경망 학습의 초기 형식화
- [[XOR 문제]]와 단층 모델의 한계
- [[규칙 기반 AI에서 데이터 기반 학습으로]] 이어지는 방법론 전환
- [[통사론]], [[변형생성문법]], [[문맥자유문법]]을 통한 언어 구조의 형식화
- [[자극의 빈곤]]과 [[보편문법]]을 둘러싼 언어 습득 논쟁
- [[촘스키에서 LLM으로]] 이어지는 구조적 언어관과 데이터 기반 학습의 긴장
- [[ADALINE]]의 연속 출력과 [[LMS 알고리즘]]을 통한 오류 기반 적응 학습
- [[MADALINE]]의 학습 가능한 유닛과 고정 논리층이 결합된 혼합 구조
- [[적응 필터]], [[음성 활동 감지]], 잡음·에코 처리로 이어지는 신경망의 공학적 배치
- [[특징 공학]]과 고정 구조가 남긴 수작업 설계 병목
- [[퍼셉트론에서 MADALINE으로]] 이어지는 초기 신경망의 안정화와 실용화
- [[ELIZA]]의 [[패턴 매칭]], [[템플릿 기반 응답 생성]], 문법적 반사
- [[DOCTOR 스크립트]]와 [[로저스식 심리치료]]의 대화 역할 설계
- [[대화 복구]]와 fallback을 통한 실패 관리
- [[ELIZA 효과]]가 보여주는 대화 유창성, 이해, 신뢰의 분리
- [[ELIZA에서 LLM으로]] 이어지는 대화형 AI의 의인화와 평가 문제

## 현재 상태

일곱 번째 소스 처리까지 완료되어 소스 요약 7개, 개념 페이지 48개, 개체 페이지 15개, 분석 페이지 7개가 정리되었다. `006` 자료의 명칭·연도 불일치와 `007` 원문의 누락된 대화 예시·불명확한 링크 때문에 두 소스 페이지는 `review` 상태다. `007`은 기존 언어 행동 평가 축에 실제 대화 설계, 사용자 의인화, fallback, 정서적 신뢰라는 인간-컴퓨터 상호작용의 축을 추가한다.

# Overview

이 위키는 현재 언어 모델링의 초기 역사와 핵심 개념을 중심으로 시작되었다. 첫 소스인 [[001_섀넌의 N-gram 모델]]은 [[클로드 섀넌]]의 정보 이론이 [[N-gram 모델]], [[조건부 확률]], [[마르코프 가정]]을 통해 자연어 처리의 통계적 패러다임으로 이어지는 흐름을 설명한다.

## 현재 핵심 주제

- 언어를 규칙 기반 체계가 아니라 확률적 예측 대상으로 보는 관점
- n-gram 모델의 실용성과 한계
- [[데이터 희소성]]과 [[Smoothing]]의 필요성
- [[Perplexity]]와 정보 이론적 언어 모델 평가
- [[대규모 언어 모델]]과 [[N-gram에서 LLM으로]] 이어지는 다음 토큰 예측의 계보

## 현재 상태

첫 소스 처리로 소스 요약 1개, 개념 페이지 7개, 인물 페이지 3개, 분석 페이지 1개가 생성되었다. 아직 다른 원본 소스가 수집되지 않았으므로, 페이지 간 모순은 발견되지 않았다.

# Overview

이 위키는 현재 언어 모델링의 초기 역사와 언어 기반 AI 평가의 형성을 함께 다룬다. 첫 소스인 [[001_섀넌의 N-gram 모델]]은 [[클로드 섀넌]]의 정보 이론이 [[N-gram 모델]], [[조건부 확률]], [[마르코프 가정]]을 통해 자연어 처리의 통계적 패러다임으로 이어지는 흐름을 설명한다. 두 번째 소스인 [[002_튜링 테스트]]는 [[앨런 튜링]]의 [[모방 게임]]이 자연어 대화를 기계 지능 평가의 중심 장면으로 만든 과정을 정리한다.

## 현재 핵심 주제

- 언어를 규칙 기반 체계가 아니라 확률적 예측 대상으로 보는 관점
- n-gram 모델의 실용성과 한계
- [[데이터 희소성]]과 [[Smoothing]]의 필요성
- [[Perplexity]]와 정보 이론적 언어 모델 평가
- [[대규모 언어 모델]]과 [[N-gram에서 LLM으로]] 이어지는 다음 토큰 예측의 계보
- [[튜링 테스트]]와 [[행동주의적 지능 기준]]
- 현대 LLM 평가에서 인간 유사성, 이해, 신뢰성의 관계

## 현재 상태

두 번째 소스 처리까지 완료되어 소스 요약 2개, 개념 페이지 10개, 인물 페이지 4개, 분석 페이지 2개가 정리되었다. 현재까지 페이지 간 직접 모순은 발견되지 않았고, 새 소스는 기존 통계적 언어 모델링 계보에 언어 행동 기반 평가라는 별도 축을 추가한다.

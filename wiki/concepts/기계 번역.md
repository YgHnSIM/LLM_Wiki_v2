# 기계 번역

> [!note] 학습 안내
> **난이도:** 입문<br>
> **선수 지식:** 없음<br>
> **읽고 나면:** 기계 번역의 과제와 규칙·통계·신경 접근의 차이를 설명하고, 자동 평가 점수가 보장하지 않는 범위를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 정의

[[기계 번역]](Machine Translation, MT)은 컴퓨터가 한 언어의 텍스트를 다른 언어의 텍스트로 자동 변환하는 기술이다. [[003_Georgetown-IBM 기계 번역 시연]]은 이 과제가 냉전기 러시아어 과학·기술 문서를 빠르게 이해해야 하는 실무적 요구에서 강한 추진력을 얻었다고 설명한다.

### 초기 문제 설정

1950년대 초 기계 번역의 핵심 문제는 규모와 속도였다. 인간 번역가만으로는 방대한 러시아어 문헌을 빠르게 처리하기 어려웠고, 기술 문서는 언어 능력뿐 아니라 과학·공학 영역 지식까지 요구했다. 이 때문에 번역은 단순한 언어 서비스가 아니라 정보 처리 병목으로 이해되었다.

## 2단계 — 작동 원리

### 접근의 변화

초기 시스템은 [[규칙 기반 기계 번역]]처럼 사전과 문법 규칙을 직접 설계하는 방식에 의존했다. [[022_IBM 통계적 기계 번역과 데이터 기반 전환]]이 다루는 [[통계적 기계 번역]]은 영어–프랑스어 Hansard의 병렬 문장쌍에서 언어 모델과 번역 모델의 매개변수를 추정하고, 관측되지 않은 단어 정렬을 잠재 구조로 다루었다. 이후 [[신경망 기계 번역]]은 병렬 말뭉치라는 학습 설정을 이어받되 IBM식 어휘·정렬·왜곡 표와 다른 신경망 매개변수화로 조건부 번역을 학습했다. 현대 [[대규모 언어 모델]]은 번역을 별도 규칙 시스템이 아니라 다언어 텍스트 생성 능력의 일부로 수행할 수 있다.

세 접근은 모두 원천 문장에서 목표 문장을 만들지만, 사람이 직접 쓰는 규칙, 말뭉치에서 추정하는 확률표, 신경망 매개변수 가운데 어디에 번역 대응을 담는지가 다르다.

## 3단계 — 기술과 근거

### 지속되는 쟁점

기계 번역은 의미 보존, 자연스러움, 용어 일관성, 문맥 해석, 문화적 표현 처리라는 여러 기준을 동시에 만족해야 한다. Georgetown-IBM 시연이 보여준 것처럼 제한된 문장에서는 성공적으로 보이는 시스템도 실제 문서에서는 모호성과 복잡한 구문 때문에 크게 흔들릴 수 있다.

[[BLEU]]는 후보와 참조의 수정 n-gram 정밀도와 짧은 출력 벌점을 결합해 같은 말뭉치에서 시스템을 빠르게 비교한다. 그러나 표면 일치가 의미·사실성·담화 품질을 모두 나타내지는 않으며, 참조 수와 전처리 조건도 점수에 영향을 준다. [[033_BLEU와 기계 번역 자동 평가]]는 원 지표의 말뭉치 단위 정의와 후속 재현성·타당성 비판을 함께 정리한다.

## 검증과 한계

### 평가 결과의 적용 범위

기계 번역의 성능 주장은 사용한 언어쌍, 영역, 참조 번역, 전처리와 평가 지표의 조건 안에서 읽어야 한다. 하나의 자동 점수는 의미 보존과 자연스러움 등 서로 다른 품질 기준 전체를 대신하지 않는다.

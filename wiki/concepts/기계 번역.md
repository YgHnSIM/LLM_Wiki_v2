# 기계 번역

[[기계 번역]](Machine Translation, MT)은 컴퓨터가 한 언어의 텍스트를 다른 언어의 텍스트로 자동 변환하는 기술이다. [[003_Georgetown-IBM 기계 번역 시연]]은 이 과제가 냉전기 러시아어 과학·기술 문서를 빠르게 이해해야 하는 실무적 요구에서 강한 추진력을 얻었다고 설명한다.

## 초기 문제 설정

1950년대 초 기계 번역의 핵심 문제는 규모와 속도였다. 인간 번역가만으로는 방대한 러시아어 문헌을 빠르게 처리하기 어려웠고, 기술 문서는 언어 능력뿐 아니라 과학·공학 영역 지식까지 요구했다. 이 때문에 번역은 단순한 언어 서비스가 아니라 정보 처리 병목으로 이해되었다.

## 접근의 변화

초기 시스템은 [[규칙 기반 기계 번역]]처럼 사전과 문법 규칙을 직접 설계하는 방식에 의존했다. 이후 연구는 통계적 기계 번역을 거쳐, 병렬 말뭉치에서 번역 대응을 학습하는 [[신경망 기계 번역]]으로 이동했다. 현대 [[대규모 언어 모델]]은 번역을 별도 규칙 시스템이 아니라 다언어 텍스트 생성 능력의 일부로 수행할 수 있다.

## 지속되는 쟁점

기계 번역은 의미 보존, 자연스러움, 용어 일관성, 문맥 해석, 문화적 표현 처리라는 여러 기준을 동시에 만족해야 한다. Georgetown-IBM 시연이 보여준 것처럼 제한된 문장에서는 성공적으로 보이는 시스템도 실제 문서에서는 모호성과 복잡한 구문 때문에 크게 흔들릴 수 있다.

# 지시 미세조정

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[언어 모델 전이 학습]], [[문맥 내 학습]]<br>
> **읽고 나면:** 지시 미세조정의 감독 자료·가중치 갱신·추론 interface를 설명하고, 과제별 미세조정·T5 prefix·문맥 내 학습·RLHF와 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 한 문장 정의

**지시 미세조정(instruction tuning)**은 여러 과제의 예시를 자연어 지시와 목표 출력 형태로 바꾸어 사전 학습 모델을 지도 미세조정하고, 추론할 때 지시로 지정한 보지 못한 과제에도 일반화하도록 만드는 적응 방식이다.

핵심은 자연어 지시를 사용한다는 사실만이 아니다. 세 위치를 함께 봐야 한다.

1. **감독 자료:** 서로 다른 과제의 지시–입력–목표 출력 example을 모은다.
2. **가중치:** 이 mixture의 정답을 예측하도록 pretrained checkpoint를 갱신한다.
3. **추론 입력:** 현재 과제의 지시와 입력을 넣고 원하는 text 출력을 생성한다.

그래서 지시 미세조정은 task-specific weight update와 prompt-only adaptation 사이에 놓인다. 여러 과제의 규칙과 지시 형식은 앞선 학습에서 가중치에 축적되고, 현재 요청은 inference text가 지정한다.

### 이름이 같아도 범위를 확인한다

2021년 FLAN은 137B LaMDA-PT 전체 모델을 62개 dataset의 짧은 instruction template으로 미세조정했다. Natural Instructions는 61개 과제에 대해 정의·주의사항·양성·음성 예시를 포함한, 사람이 작성한 더 상세한 지시를 사용했다. 둘 다 cross-task instruction generalization을 연구했지만 모델, instruction schema와 zero-shot protocol이 같지 않다.

후대의 `instruction-tuned model`은 대화, code, tool use, 거절과 합성 응답까지 더 넓은 supervised post-training을 가리킬 수 있다. 이름만 보고 FLAN과 같은 data·loss·분할을 썼다고 가정하지 않는다.

## 2단계 — 작동 원리

### 여러 과제를 공통 조건부 생성 문제로 바꾼다

지시 $I$, 선택적 입력 $x$, 목표 text $y$를 모아 다음과 같은 example을 만든다.

| 과제 | 지시 $I$ | 입력 $x$ | 목표 $y$ |
|---|---|---|---|
| 감성 분류 | 문장의 감성을 positive/negative로 분류하라 | review text | `positive` |
| 번역 | English 문장을 French로 번역하라 | source sentence | target sentence |
| 질의응답 | 문맥을 근거로 질문에 답하라 | context와 question | answer text |

모델은 공통 token likelihood로 target을 예측한다.

$$
\mathcal{L}(\theta)=-\sum_{(I,x,y)}\sum_t \log p_\theta(y_t\mid I,x,y_{<t})
$$

공통 loss가 과제 차이를 없애지는 않는다. 어떤 dataset을 얼마나 섞는지, class 후보를 어떻게 쓰는지, 어느 output을 정답으로 인정하는지와 accuracy·F1·BLEU 같은 평가는 과제별로 남는다.

### 네 적응 경로를 구분한다

| 경로 | 학습 단위 | 추론 시 과제 명세 | 현재 과제 label로 가중치 갱신 |
|---|---|---|---|
| 과제별 미세조정 | 한 downstream dataset | 고정된 입력 형식 | 있음 |
| T5 대표 recipe | 여러 과제의 공통 text interface 뒤 task별 checkpoint | 지도학습 입력에 함께 넣은 과제별 고정 text prefix | 최종 task별로 있음 |
| 문맥 내 학습 | 사전 학습 model을 그대로 사용 | 자연어 지시·0개 이상 demonstration | 없음 |
| 지시 미세조정 | 여러 과제의 instruction mixture | 현재 지시와 입력 | 보류 과제 label은 없지만 다른 과제 mixture로 앞서 갱신 |

같은 model에 이 경로들을 순서대로 결합할 수 있다. FLAN의 few-shot 절제는 학습 과제에서도 exemplar가 든 형식으로 별도 지시 미세조정을 하고, 보류 과제의 exemplar는 inference에서만 제공했다. 이 조건은 모든 평가 군집에서 zero-shot FLAN보다 높았으므로 다과제 지시 미세조정과 보류 과제의 문맥 내 예시를 결합할 수 있음을 보이지만, 같은 zero-shot checkpoint에 추론 예시만 덧붙인 대조는 아니다. 지시 미세조정 뒤 특정 과제로 다시 미세조정하거나 soft prompt를 학습하는 것도 가능하다.

### 보류 단위를 먼저 정한다

`unseen`은 적어도 세 뜻을 가질 수 있다.

- **example 보류:** 같은 dataset의 training example은 봤지만 test example은 보지 않았다.
- **dataset 보류:** 같은 task type의 다른 dataset은 봤지만 평가 dataset은 보지 않았다.
- **task-type 보류:** 평가 과제와 같은 군집의 어떤 dataset도 instruction tuning에서 보지 않았다.

FLAN은 세 번째에 가까운 leave-one-cluster-out 절차를 썼다. Natural Instructions는 seen task와 unseen task를 나눴고, 상세 지시에 example 자체가 포함될 수 있었다. `zero-shot`이라는 한 단어만으로 supervision 경계를 판단하지 않는다.

## 3단계 — 기술과 근거

### FLAN이 분리해 본 세 조건

[[072_지시 미세조정과 FLAN의 제로샷 일반화]]는 원 FLAN의 세 절제를 복원한다.

- **과제 다양성:** 정한 순서에서 instruction-tuning 군집이 1→7개로 늘자 세 보류 군집 평균이 49.9→63.5로 올랐다. 어느 특정 군집이 어느 평가 과제에 원인이었는지는 식별하지 못했다.
- **모델 규모:** 422M·2B·8B에서는 보류 성능이 나빠졌고 68B·137B에서 좋아졌다. 특정 family와 split의 개입 효과다.
- **instruction text:** 자연어 지시를 사용한 조건 55.2가 지시 없는 조건 37.3과 dataset 이름 조건 46.6/47.0보다 높았다. 단순 multi-task exposure만으로 전체 결과를 설명하기 어렵다는 근거다.

이 결과는 모델이 지시의 의미를 사람처럼 이해한다는 내부 메커니즘을 직접 확인하지 않는다. Template wording·label token·후보 목록과 decoding이 관측 성능에 계속 영향을 준다.

### prompt와 weight가 역할을 나눈다

문맥 내 학습에서 현재 task의 example은 inference context에만 있고 optimizer step이 없다. 지시 미세조정에서는 다른 task의 example이 gradient를 통해 가중치에 들어간다. 이후 현재 instruction이 어느 learned behavior를 꺼낼지 조건화한다.

이 차이는 비용 장부도 바꾼다.

- 지시 미세조정은 공통 checkpoint를 만드는 선행 data·training cost가 있다.
- 문맥 내 학습은 task별 training은 없지만 매 요청마다 demonstration token과 prompt 설계 비용을 쓴다.
- 보류 task에서 높은 성능을 내려면 후보 label, output parser와 metric 같은 외부 interface가 남을 수 있다.

### RLHF와 안전 정렬은 별도 단계다

FLAN의 target은 기존 benchmark의 정답 label·answer·translation이다. [[인간 피드백 강화학습]]은 여러 model 응답 가운데 무엇을 선호하는지 비교하는 자료로 reward signal을 학습하고 policy를 조정한다. InstructGPT는 사람 시연의 supervised fine-tuning 뒤 response ranking, reward model과 PPO를 사용했다.

따라서 instruction SFT는 RLHF pipeline의 앞 단계가 될 수 있지만 두 용어는 동의어가 아니다. 정답 형식을 잘 따르는 능력도 사실성·무해성·사용자 의도 충족을 자동 보장하지 않는다.

### 공통 interface와 공통 metric은 다르다

모든 target을 text로 만들면 architecture와 token likelihood를 공유할 수 있다. 그러나 NLI accuracy, reading-comprehension F1, translation BLEU와 생성의 사람이 읽는 품질은 서로 다른 측정이다. 여러 점수를 평균하려면 task weighting과 normalization이 들어간다. `통합 지시 형식`에서 `통합된 능력 하나`로 바로 이동하지 않는다.

## 검증과 한계

### 흔한 오해

- **자연어 prompt를 쓰면 모두 지시 미세조정이다**: inference prompt만 쓰고 weight를 갱신하지 않으면 문맥 내 학습 또는 prompting이다.
- **zero-shot은 지도 자료를 전혀 쓰지 않는다**: 보류 task의 label은 없을 수 있지만 다른 task의 지도 mixture가 가중치에 들어간다.
- **T5 task prefix와 같다**: 원 T5의 prefix는 seen task의 supervised identifier였고 대표 최종 결과는 task별 fine-tuning을 사용했다.
- **작은 adapter만 추가한다**: instruction dataset은 full fine-tuning에도 parameter-efficient tuning에도 쓸 수 있다. 원 FLAN은 전체 model을 갱신했다.
- **prompt engineering을 제거한다**: template의 표현·후보·output parsing은 여전히 결과를 바꾼다.
- **과제 수가 많으면 항상 일반화한다**: mixture 품질·비중·model capacity·task conflict와 holdout 정의에 따라 이득의 크기와 부호가 달라질 수 있다.
- **지시를 따르므로 정렬됐다**: 잘못되거나 유해한 instruction을 더 잘 수행할 수도 있다. 선호·안전·사실성에는 별도 자료와 평가가 필요하다.

### 검증 범위

이 문서는 FLAN·Natural Instructions·T5·GPT-3·InstructGPT의 공개 1차 자료에서 supervision 위치와 평가 protocol을 비교했다. `여러 task의 감독 신호가 weights에 축적되고 현재 instruction이 그중 하나를 불러내도록 조건화한다`는 설명은 관측 가능한 학습 절차의 요약이지 내부 지식 단위의 인과적 위치를 해부한 결과가 아니다.

상용 model의 전체 post-training data와 단계는 공개 범위가 다르다. 특정 model이 ‘instruction tuned’라고 알려졌더라도 FLAN data·leave-one-cluster-out 평가·전체 미세조정을 그대로 사용했다고 단정하지 않는다.

# 특징 공학

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[concept.선형-분류기|선형 분류기]]<br>
> **읽고 나면:** 사람이 만든 입력 특징과 모델이 학습한 표현의 경계가 시대별로 어떻게 이동했는지 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 정의

[[특징 공학]](Feature Engineering)은 원시 데이터에서 모델이 사용할 입력 변수를 사람이 선택하거나 계산하는 작업이다. 어떤 정보가 과업에 유용한지에 대한 도메인 지식을 모델 입력으로 변환한다.

## 2단계 — 작동 원리

### 입력을 만드는 흐름

설계자는 원시 데이터에서 과업에 유용하다고 판단한 측정값을 고르고 계산해 모델 입력으로 만든다. 모델은 주어진 특징의 가중치나 조합을 학습하지만, 입력 단위와 전처리 자체는 별도의 설계 선택으로 남을 수 있다.

## 3단계 — 기술과 근거

### 초기 신경망 사례

[[ADALINE]]과 초기 [[MADALINE]]은 주어진 입력 좌표에서 가중치를 학습했지만, 원시 신호를 어떤 수치로 표현할지는 설계자가 정했다. 다항식 전처리나 과업별 신호 특징을 추가하면 선형 유닛이 더 복잡한 경계를 만들 수 있지만, 어떤 전처리가 유효한지는 자동으로 결정되지 않았다.

### TDNN 사례

[[020_시간 지연 신경망과 음소 인식]]의 [[시간 지연 신경망]]은 시간축 공유 가중치로 분류에 유용한 내부 음향 특징을 학습했다. 그러나 원 실험은 원시 파형을 곧바로 음소로 바꾸지 않았다. 12 kHz 음성을 FFT로 처리해 16개 정규화 멜 스케일 스펙트럼 계수를 만들고, 사람이 표시한 모음 시작점을 중심으로 15프레임 입력을 잘라 사용했다.

이 사례는 표현 학습이 특징 공학을 한 번에 없애기보다 경계를 이동시켰음을 보여 준다. 스펙트럼 표현·시간 간격·토큰 경계·분류 목표는 설계자가 정했고, 네트워크는 그 입력 위에서 국소 시간 특징과 조합을 학습했다.

### CNN 사례

[[021_합성곱 신경망과 특징 학습]]의 [[합성곱 신경망]]도 영상 위치마다 별도 검출기를 손으로 작성하는 대신 국소 필터와 그 조합을 데이터에서 학습한다. LeCun 등의 1989년 우편번호 인식기는 학습된 특징 추출기와 분류기를 하나의 역전파 절차로 훈련했고, 1998년 LeNet-5는 이 방식을 문서 인식에 확장했다.

그렇다고 수작업 설계가 사라진 것은 아니다. 1989년 시스템은 숫자 분할과 정규화·입력 부호화를 사용했고, 1998년 시스템도 입력 정규화와 구조 선택을 명시했다. 오늘날에도 커널 크기·층 구조·데이터 증강·평가 설계는 사람이 정한다. CNN은 특징 공학의 많은 부분을 학습 가능한 표현으로 옮겼지만 모든 전처리와 귀납 편향을 제거하지는 않았다.

### 특징 템플릿 기반 NLP

[[027_최대 엔트로피와 서포트 벡터 머신]]이 다루는 1990년대 특징 기반 NLP에서는 현재 단어, 앞뒤 단어, 접두사·접미사, 대문자·숫자·하이픈 여부, 앞선 품사 같은 관측을 이진 특징으로 만들었다. Ratnaparkhi의 품사 태거는 이런 템플릿을 훈련 자료에 적용해 실제 특징을 생성하고, [[최대 엔트로피 모델]]이 각 특징의 가중치를 학습하게 했다. 여러 특징을 한 조건부 모델에 넣을 수 있다는 사실이 어떤 특징을 만들지까지 자동으로 결정해 주지는 않았다.

특징이 동시에 활성화되면 로그선형 모델의 가중치가 더해진다. 특정 단어와 이전 품사의 결합처럼 별도 상호작용이 필요하면 두 조건을 함께 묻는 결합 특징을 명시해야 한다. [[서포트 벡터 머신]]도 선형 모델에서는 주어진 특징의 가중합을 사용하고, 비선형 커널이나 명시적 결합을 선택할 때에만 추가 상호작용을 표현한다. “고차원 특징을 다룬다”와 “유용한 특징을 스스로 발명한다”는 서로 다른 능력이다.

Joachims의 텍스트 분류 실험도 최소 빈도, 불용어 제거, IDF와 길이 정규화를 거친 문서 벡터를 사용했다. Collobert 등의 2011년 신경 NLP는 단어 표현과 상위 특징을 과제 손실에서 함께 학습해 많은 수작업 템플릿을 줄였다. 이 변화는 특징 공학의 제거보다 경계 이동에 가깝다. 신경망에서도 토큰화, 입력 단위, 아키텍처, 주석 범주와 목표 함수는 설계자가 정한다.

## 검증과 한계

### 장점과 병목

잘 설계된 특징은 작은 모델과 제한된 하드웨어에서도 높은 실용성을 제공할 수 있다. 반면 과업이 바뀔 때마다 전문가가 새로운 특징을 찾아야 하므로 [[지식 공학 병목]]과 비슷한 확장성 문제가 생긴다. 현대 딥러닝은 더 많은 표현을 데이터에서 자동으로 학습하지만, 입력 구성과 평가 설계에서 사람의 판단은 여전히 남는다.

## 학습 확인

### 확인 질문

1. 특징 공학은 원시 데이터를 모델 입력으로 바꾸는 과정에서 어떤 판단을 사람이 맡는가?
2. TDNN과 CNN은 특징 공학을 완전히 없애기보다 그 경계를 어떻게 이동시켰는가?
3. 고차원 특징을 다루는 능력과 유용한 특징을 스스로 만드는 능력이 다른 이유는 무엇인가?

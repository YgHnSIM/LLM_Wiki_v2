# 데이터 희소성

> [!note] 학습 안내
> **난이도:** 입문<br>
> **선수 지식:** [[N-gram 모델]]<br>
> **읽고 나면:** 가능한 조합 수와 관측 데이터의 차이가 확률 0 문제를 만드는 이유와 평활화의 역할을 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 정의

[[데이터 희소성]]은 가능한 조합은 매우 많지만 실제 학습 데이터에서 관찰되는 조합은 그중 일부에 그쳐 확률 추정이 어려워지는 문제다. [[N-gram 모델]]에서는 n이 커질수록 가능한 n-gram 수가 지수적으로 증가하기 때문에 이 문제가 특히 두드러진다.

예를 들어 고정 어휘가 10,000개라면 가능한 bigram은 1억 개, trigram은 1조 개다. 큰 말뭉치가 있더라도 대부분의 조합은 한 번도 나타나지 않는다. 평활화하지 않은 최대우도 추정에서 문장 안의 조건부 확률 하나라도 0이면 문장 전체의 곱도 0이 되고, 음의 로그우도와 [[Perplexity]]는 무한대로 발산한다. 이는 어휘에 이미 있는 단어들의 조합을 보지 못한 문제다. 어휘 자체에 없는 OOV 단어를 어떻게 표현할지는 별도의 어휘·토큰화 문제다.

## 2단계 — 작동 원리

### N-gram에서의 의미

긴 n-gram은 더 많은 문맥을 제공하지만 더 드물다. 짧은 n-gram은 자주 관찰되지만 문맥 정보가 빈약하다. 이 절충은 n-gram 언어 모델의 핵심 병목이다.

## 3단계 — 기술과 근거

### 해결 방향

[[Smoothing]]은 미관측 사건에도 0이 아닌 확률을 배분하는 기법이다. [[슬라바 카츠]]가 제안한 [[019_Katz 백오프와 희소 데이터 확률 추정|Katz back-off]]는 관측된 낮은 빈도 `1≤r≤k`에는 할인된 상위 n-gram 확률을 그대로 쓰고, `r=0`일 때만 더 짧은 문맥으로 후퇴한다. 빈도가 작다는 이유만으로 후퇴하거나 OOV 단어 문제를 직접 해결하는 방식은 아니다.

## 검증과 한계

### 적용 범위

데이터 희소성은 관측되지 않은 조합의 확률 추정 문제다. 기존 어휘 밖의 OOV 단어를 표현하는 문제와 짧은 문맥만 보는 [[마르코프 가정]]의 한계는 별도로 구분해야 한다.

## 학습 확인

1. n이 커질수록 데이터 희소성이 심해지는 이유는 무엇인가?
2. 미관측 n-gram 하나의 확률이 0이면 문장 확률과 perplexity에는 어떤 일이 생기는가?
3. Katz back-off가 낮은 빈도와 빈도 0을 다르게 처리하는 이유는 무엇인가?

다음에는 [[Smoothing]]에서 미관측 조합에 확률을 배분하는 방법을 본다. 문맥 길이와 희소성의 절충을 복습하려면 [[N-gram 모델]]로 이어 간다.

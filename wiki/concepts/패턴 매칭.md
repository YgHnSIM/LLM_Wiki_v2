# 패턴 매칭

> [!note] 학습 안내
> **난이도:** 입문<br>
> **선수 지식:** 없음<br>
> **읽고 나면:** 입력 패턴의 일치와 우선순위가 ELIZA의 응답 규칙을 어떻게 선택하는지 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 정의

[[패턴 매칭]](Pattern Matching)은 입력에서 미리 정의한 단어나 구조를 찾아 대응 규칙을 선택하는 방식이다. [[ELIZA]]는 사용자 문장의 의미를 해석하는 대신 키워드와 키워드 조합을 검색했다.

## 2단계 — 작동 원리

### 역할

일치한 패턴은 [[템플릿 기반 응답 생성|응답 템플릿]]과 변환 규칙을 선택하는 열쇠였다. 일치하는 패턴이 없으면 [[대화 복구]] 전략이 사용되었다.

## 3단계 — 기술과 근거

### 우선순위

여러 패턴이 동시에 일치할 때 ELIZA는 사전에 정한 우선순위를 사용했다. 가족, 감정, 꿈과 관련된 단어에 높은 순위를 부여하면 프로그램이 사용자의 중요한 문제를 알아차린 것처럼 보일 수 있었다. 그러나 중요성 판단은 프로그램의 이해가 아니라 설계자의 규칙에서 나왔다.

## 검증과 한계

### 의미 이해와의 경계

패턴이 일치했다는 사실은 입력의 의미나 사용자의 의도를 이해했다는 증거가 아니다. 우선순위도 프로그램이 발견한 중요도가 아니라 설계자가 규칙에 부여한 값이다.

## 학습 확인

### 확인 질문

1. 패턴 매칭은 입력에서 무엇을 찾아 어떤 결정을 내리는 방식인가?
2. 일치한 패턴과 일치하지 않은 입력은 각각 어떤 응답 경로로 이어지는가?
3. 높은 우선순위의 키워드가 의미 이해를 증명하지 않는 이유는 무엇인가?

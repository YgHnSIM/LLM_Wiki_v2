# 문맥자유문법

[[문맥자유문법]](Context-Free Grammar, CFG)은 구 구조를 재작성 규칙으로 나타내는 형식문법이다. [[005_촘스키의 통사 구조]]는 문맥자유문법을 [[변형생성문법]]의 단순화된 형식이자 초기 [[파싱]]의 표준 도구로 설명한다.

## 역할

문맥자유문법은 문장을 명사구와 동사구 같은 하위 구성요소로 분해한다. 이런 규칙은 [[통사 구조]]를 트리 형태로 표현할 수 있게 해 주며, [[유한상태 모델]]보다 중첩 구조를 더 잘 다룬다.

## 컴퓨터과학과의 관계

이 형식은 자연어 처리뿐 아니라 프로그래밍 언어와 컴파일러에도 중요하다. 컴파일러가 소스 코드를 파싱해 추상 구문 트리를 만들 때, 문맥자유문법의 계보에 있는 도구를 사용한다.

## 재귀 전이망과의 동등성

[[014_증강 전이망과 절차적 자연어 파싱]]에서 구분하는 재귀 전이망(RTN)은 하위 전이망 호출을 위한 푸시다운 스택을 갖는다. 우즈는 RTN, 푸시다운 오토마톤, 문맥자유문법이 약한 생성 능력에서 동등하다고 설명했다. 레지스터의 임의 조건과 동작을 더한 [[증강 전이망]]은 이 범위를 넘어갈 수 있으므로 RTN과 완전한 ATN을 같은 형식 능력으로 취급하지 않는다.

## 확률과 말뭉치의 결합

문맥자유문법에 확률을 더한다고 계층 구조가 사라지는 것은 아니다. Booth와 Thompson은 1973년에 문법 생성 규칙에 확률 측도를 부여했고, Pereira와 Schabes는 1992년에 부분적으로 괄호가 표시된 말뭉치로 확률 문법을 재추정했다. [[012_상징 규칙에서 통계 학습으로]]가 설명하는 통계적 전환은 형식문법의 폐기보다, 같은 문법이 허용하는 여러 [[파싱|구문 분석]]의 순위를 자료로 추정하는 방향을 포함한다.

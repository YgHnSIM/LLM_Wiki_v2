# 인간 피드백 강화학습

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** 정책·보상의 기초 개념, [[대규모 언어 모델]]<br>
> **읽고 나면:** 사람의 비교 판단을 보상 신호로 바꾸어 정책을 갱신하는 RLHF 순환과 그 한계를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

[[인간 피드백 강화학습]](Reinforcement Learning from Human Feedback, RLHF)은 사람이 평가한 행동·출력의 상대적 선호를 학습 신호로 바꾸고, 그 신호에 맞춰 정책을 최적화하는 방법 계열이다. 2017년 인간 선호 기반 심층 강화학습은 짧은 행동 구간의 쌍대 비교로 보상 모델을 학습했으며, 2019년 이후 언어 모델 응답에 이 틀이 적용됐다.

## 2단계 — 작동 원리

### 비교에서 정책 갱신까지

정책이 만든 두 행동 구간이나 응답을 사람이 비교한다. 보상 모델은 이 비교 순서를 예측하도록 학습되고, 정책은 그 예측 보상을 높이는 방향으로 갱신된다. 바뀐 정책의 새 출력을 다시 비교해 자료 분포와 보상 모델을 반복해서 맞춘다.

## 3단계 — 기술과 근거

### 2017년 프레임워크

두 행동 구간 $\sigma^0,\sigma^1$에서 보상 모델 $\hat r_\theta$가 예측한 시점별 보상 합을 비교한다.

$$
P_\theta[\sigma^1\succ\sigma^0]=
\frac{\exp\sum_{(s,a)\in\sigma^1}\hat r_\theta(s,a)}
{\exp\sum_{(s,a)\in\sigma^0}\hat r_\theta(s,a)+\exp\sum_{(s,a)\in\sigma^1}\hat r_\theta(s,a)}.
$$

인간의 선택·무승부 라벨에 대한 교차 엔트로피로 보상 모델을 훈련하고, 예측 보상으로 정책을 학습한다. 정책이 달라지면 새 구간을 만들고 다시 비교를 받아 보상 모델을 갱신한다. 고정된 초기 비교만으로 끝나는 절차가 아니다.

원 논문은 여러 보상 모델의 예측 불일치를 이용해 정보가 클 구간 쌍을 질의했다. 이를 단일 모델이 잘 보정된 확신도를 직접 출력했다고 해석하지 않는다. ensemble disagreement는 능동 자료 선택 신호다.

### 원 실험의 범위

Christiano 등의 실험은 Atari 게임과 MuJoCo형 시뮬레이션 로봇 이동·제어 과제였다. 인간은 에이전트 상호작용의 1% 미만을 보면서 비교를 제공했고, 일부 새 행동은 약 한 시간의 인간 피드백으로 학습됐다고 보고됐다.

이 연구는 자연어 응답·도움됨·정직성·무해성이나 Transformer 정책을 직접 실험하지 않았다. ‘RLHF의 토대’라는 후대 평가는 정당하지만 오늘날 언어 모델 파이프라인이 2017년에 완성됐다고 소급하지 않는다.

### 언어 모델로의 전환

2019년 Ziegler 등은 GPT-2 계열 언어 모델의 출력 비교에서 보상 모델을 학습하고 PPO로 정책을 미세조정했다. 긍정적 정서·물리적 묘사·요약 과제에서 선호 학습을 시험했으며, 인간 평가자가 단순 휴리스틱에 의존할 수 있다는 한계도 보고했다.

2020년 요약 연구는 비교 자료, 보상 모델, PPO 정책을 더 체계적으로 평가했다. 2022년 InstructGPT는 다음 세 단계를 명시했다.

1. 평가자 시연으로 지도 미세조정(SFT) 모델을 만든다.
2. 같은 prompt의 4–9개 응답 순위를 받고, 동률을 제외한 쌍 비교로 보상 모델을 학습한다.
3. 보상과 SFT 기준 정책에서의 KL 이탈 제한을 사용해 PPO로 정책을 미세조정한다.

현대 RLHF는 보상 모델 하나만을 뜻하지 않고 자료 수집·평가 지침·SFT·정책 제약·안전 평가를 포함한 파이프라인이다.

### InstructGPT의 두 제약 장치

InstructGPT에서 토큰별 KL 패널티는 PPO 정책이 **SFT 정책**에서 멀어지는 것을 벌한다. 원래 사전 학습 GPT-3를 직접 KL 기준으로 둔 것이 아니다. 논문이 주로 InstructGPT라 부른 PPO-ptx는 이 제약과 별도로 사전 학습 자료의 다음 토큰 예측 기울기를 섞어 공개 NLP 과제의 성능 회귀를 줄였다.

두 장치는 역할이 다르다. KL 패널티는 학습된 보상을 과도하게 좇는 정책 이동을 제한하고, 사전 학습 혼합은 일부 기존 능력을 보존하려는 보조 목적이다. PPO-ptx도 모든 성능 회귀를 없애지 못했으며 두 장치 모두 보상 모델의 사각지대나 평가자 대표성을 해결하지 않는다.

## 검증과 한계

### 선호와 가치의 차이

보상 모델은 수집된 평가자·지침·prompt 분포의 비교를 예측한다. 인간 가치 전체나 보편적 도덕을 복원하는 모델이 아니다. 사람 사이 불일치, 비교 불가능성, 문화적 차이와 여러 목표의 절충을 하나의 스칼라 순위로 축약한다.

InstructGPT의 약 40명 계약 평가자와 96% 이상 영어인 자료는 실제 운영을 향한 중요한 표본이었지만 보편적 모집단은 아니다. 보상 모델이 학습 평가자와 분리한 보류 평가자에게도 어느 정도 일반화됐다는 결과는 같은 공급업체 기반 평가 절차 안의 재현성을 보여 줄 뿐, 더 넓은 사회·문화 집단의 대표성을 입증하지 않는다.

따라서 응답 선호율이 높아졌다는 사실을 사실성·안전성·공정성의 완전한 달성으로 해석하지 않는다. InstructGPT도 단순한 오류를 남겼고, 평가 분포 밖 일반화와 평가자 대표성은 별도 문제다.

### 보상 해킹과 분포 이동

정책은 실제 인간 의도가 아니라 학습된 보상 모델을 직접 최적화한다. 보상 모델의 사각지대가 있으면 높은 점수와 낮은 실제 선호가 갈라질 수 있다. 정책 최적화가 강할수록 이 proxy 오차를 증폭할 위험이 있다.

새 정책 응답을 다시 평가하고 KL 규제·조기 중단·독립 인간 평가를 사용하는 이유가 여기에 있다. 그러나 이런 장치도 보상 모델의 완전한 견고성을 보장하지 않는다.

### RL이 없는 선호 최적화

Direct Preference Optimization 같은 후속 방법은 선호 쌍과 기준 정책을 이용해 별도 보상 모델과 온라인 PPO 단계를 명시적으로 거치지 않고 정책을 학습한다. 넓은 의미의 인간 선호 학습에는 포함될 수 있지만, 알고리즘상 강화학습 단계가 없으므로 전통적 세 단계 RLHF와 구분한다.

# 지속 사전 학습

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[concept.언어-모델-전이-학습|언어 모델 전이 학습]]<br>
> **읽고 나면:** 순차 corpus에서 새 분포 적응과 기존 능력 보존을 함께 다루는 지속 사전 학습의 입력·목적·평가를 설명하고, PEFT·RAG·RLHF와 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 한 문장 정의

**지속 사전 학습**(continual pre-training)은 사전 학습된 언어 모델이 시간이나 영역에 따라 차례로 도착하는 비표지 corpus를 받아 언어 모델 목적을 이어 학습하되, 새 분포에 적응하면서 이전 분포의 능력과 지식을 얼마나 보존하는지 함께 다루는 연구 설정이다.

핵심은 “한 번 더 사전 학습했다”보다 **자료에 순서가 있고 각 단계 뒤의 보존과 전이를 측정한다**는 데 있다. 어떤 논문은 lifelong pretraining, continual post-training 또는 continual knowledge learning이라는 이름을 쓴다. 이름만으로 같은 설정이라 가정하지 말고 corpus의 순서, 과거 자료 접근 가능성, task ID 제공 여부와 평가 단위를 확인해야 한다.

### 인접 개념과의 경계

| 개념 | 자료·목적 | Update 위치 | 지속 사전 학습과 다른 질문 |
| --- | --- | --- | --- |
| 한 번의 영역 적응(DAPT·TAPT) | 특정 영역·과제의 비표지 text와 LM loss | 주로 전체 weight | 여러 단계 뒤 과거 분포를 계속 평가하지 않을 수 있음 |
| 지도 미세조정·[[인간 피드백 강화학습|RLHF]] | 지시–응답·label·선호 비교 | 전체 또는 일부 weight | 지식 분포보다 과제 수행·응답 선호를 직접 최적화 |
| [[저순위 적응|LoRA·PEFT]] | 어떤 학습 자료와도 결합 가능 | 작은 adapter·low-rank update | 무엇을 적게 갱신할지 정할 뿐 순차 목적과 망각 metric은 별도 |
| [[검색 증강 생성|RAG]] | 질의와 외부 document | 추론 context·외부 index | Weight를 다시 학습하지 않고 비매개변수적 기억을 교체 |
| Model versioning·rollback | 평가 결과와 배포 traffic | Serving checkpoint | 학습 방법이 아니라 release 위험을 관리하는 운영 통제 |

### 왜 중요한가

현실의 text distribution은 새 논문·software·사건·표현과 함께 바뀐다. 처음부터 모든 과거·신규 자료를 합쳐 다시 학습하면 강한 baseline을 만들 수 있지만 data·compute가 커지고, 과거 원자료에 다시 접근할 수 없는 경우도 있다. 이전 checkpoint를 재사용하면 계산을 줄일 가능성이 있지만 새 자료에 대한 가소성과 이전 능력의 안정성이 충돌한다.

지속 사전 학습은 이 절충을 명시적으로 측정한다. 다만 새 corpus에 노출됐다는 사실을 정확한 사실 기억, 오래된 답의 삭제, 안전한 배포와 동일시하지 않는다.

## 2단계 — 작동 원리

### 순차 자료와 checkpoint

초기 model $\theta_0$와 시간 또는 영역 순서의 corpus $D_1,D_2,\ldots,D_T$를 생각하자. 단계 $t$에서는 $\theta_{t-1}$에서 시작해 새 corpus $D_t$의 언어 모델 손실을 낮추고 $\theta_t$를 만든다. 그다음 새 corpus뿐 아니라 $D_1$부터 $D_{t-1}$까지의 대표 평가와 downstream task를 다시 측정한다.

보존 장치를 포함한 여러 방법의 공통 구조는 다음 개념식으로 나타낼 수 있다.

$$
\theta_t
=\arg\min_{\theta}
\mathcal L_{\mathrm{LM}}(D_t;\theta)
+\lambda R_t(\theta,\theta_{t-1},M_{<t})
$$

$M_{<t}$는 허용될 때 보관한 과거 자료나 그 요약이고, $R_t$는 replay·distillation·weight regularization·masking처럼 이전 능력 손실을 줄이는 항을 포괄한다. 모든 논문이 이 식을 그대로 쓰지는 않는다. 이는 새 자료 적응과 보존 장치를 분리해 읽기 위한 개념적 표기다.

### 한 update 주기의 네 단계

1. **자료 경계 지정:** 새 corpus의 시점·영역·언어·중복·출처와 과거 자료 접근 가능성을 기록한다.
2. **학습 경계 선택:** 전체 weight, 일부 layer, adapter 또는 확장 parameter 중 무엇을 갱신하고 어떤 LM objective·learning-rate schedule을 쓸지 정한다.
3. **보존 신호 구성:** Replay, 이전 model distillation, weight 제약, mask·확장 가운데 setting에 맞는 방법을 사용한다.
4. **다축 평가와 release:** 새 분포 적응, 과거 능력 보존, 지식 교정과 비용을 평가한다. 채택·A/B test·rollback은 그 뒤의 배포 판단이다.

### 안정성–가소성 절충

새 corpus만 강하게 최적화하면 새 영역 loss는 빠르게 줄지만 이전 영역의 표현과 출력이 손상될 수 있다. 반대로 이전 parameter에서 거의 움직이지 못하게 하면 보존 점수는 높아도 새 분포를 배우지 못한다.

Replay는 과거 gradient를 다시 보여 주지만 과거 자료 저장·재사용 권한을 전제한다. Distillation은 원자료 대신 이전 model의 출력 분포를 기준으로 삼을 수 있으나 기존 오류까지 보존할 수 있다. Weight regularization은 중요한 parameter의 변화를 제한하지만 중요도 추정과 새 task 충돌에 민감하다. Mask·parameter expansion은 interference를 줄일 수 있으나 model 크기와 domain routing 부담을 늘린다.

### 평가 행렬

한 단계의 점수 하나보다, 학습 단계 $t$와 평가 분포 $j$를 교차한 행렬 $S_{t,j}$가 유용하다.

| 읽는 방향 | 질문 |
| --- | --- |
| 대각선 $S_{t,t}$ | 현재 들어온 분포를 배웠는가? |
| 대각선 왼쪽 $S_{t,j}, j<t$ | 이전 분포·과제를 보존했는가? |
| 다음 단계와의 비교 | 앞선 학습이 새 분포 적응을 도왔는가? |
| 지식 유형별 점수 | 불변 사실을 보존하고 오래된 사실은 바꾸며 새 사실은 얻었는가? |

평균 하나만 보면 새 영역 향상과 과거 영역 손상이 상쇄될 수 있다. Language-model loss, downstream fine-tuning, 사실 probe와 실제 생성 평가도 서로 다른 능력을 측정하므로 같은 값처럼 합치지 않는다.

## 3단계 — 기술과 근거

### 영역 적응에서 순차 사전 학습으로

[[057_ELMo와 ULMFiT의 두 전이 학습 경로]]에서 ULMFiT는 일반 언어 모델을 목표 영역의 비표지 text에서 더 학습한 뒤 분류기로 적응했다. Gururangan 등의 DAPT·TAPT는 biomedical·computer science·news·reviews 네 영역과 여덟 분류 과제에서 영역·과제 corpus의 추가 사전 학습 이득을 체계적으로 비교했다.

이 연구들은 일반 사전 학습 뒤에도 비표지 분포 적응이 유효하다는 토대를 제공한다. 하지만 하나의 목표 영역에 적응한 뒤 끝나는 실험과, 여러 corpus가 순서대로 들어오며 각 과거 능력을 계속 재평가하는 지속 설정은 구분한다.

### 2022년의 세 설정

Jin 등의 lifelong pretraining은 domain-incremental 연구 논문 stream과 chronologically ordered tweet stream을 사용했다. 매 단계 후 downstream fine-tuning으로 이전 영역 보존과 최신 자료 적응을 평가했고, 비교 조건에서는 distillation 계열이 과거 downstream 성능 보존에 가장 효과적이었다. 방법의 우위가 두 stream과 모든 지표에서 같았다는 뜻은 아니다.

Jang 등의 continual knowledge learning(CKL)은 distribution 적응을 지식 유형으로 세분했다. 불변 지식의 보존, outdated knowledge의 갱신, 새 지식의 획득을 별도 benchmark와 metric으로 측정했다. 시험한 baseline에서는 parameter expansion이 학습과 보존을 함께 달성하는 데 중요했지만, 이는 모든 model·자료에서 확장이 유일한 해법이라는 결론은 아니다.

Ke 등의 CPT는 RoBERTa에서 여러 비표지 영역 corpus를 차례로 post-train하고, 학습한 각 영역의 few-shot end-task에 사용하는 task-incremental setting이다. Domain ID가 제공되고 지나간 영역 자료에 다시 접근하지 않는 조건에서 hard masking으로 망각과 downstream fine-tuning 뒤 증폭되는 성능 손상을 다뤘다. 이 setting은 task ID가 없는 연속 stream과 다르다.

### EWC를 LLM 근거로 소급하지 않는다

Elastic Weight Consolidation(EWC)은 이전 task에 중요하다고 추정한 parameter가 크게 움직이면 벌점을 준다. 대표식은 다음과 같다.

$$
\mathcal L_t(\theta)
=\mathcal L_{\mathrm{new}}(\theta)
+\frac{\lambda}{2}\sum_i F_i(\theta_i-\theta_i^\ast)^2
$$

$F_i$는 이전 task에서 parameter $i$의 중요도를 근사하는 Fisher 정보의 대각 성분이고 $\theta^\ast$는 이전 해다. Kirkpatrick 등의 2017년 원 연구는 permuted MNIST와 Atari 순차 학습을 평가했다. 따라서 EWC는 개념적 선행 방법이지만 수십억 parameter 언어 모델의 사실 갱신을 이미 검증한 증거가 아니다.

Jin 등의 LLM 연구에서도 EWC·replay·distillation의 효과는 stream과 평가에 따라 달랐다. 방법 이름보다 model 규모, corpus 순서, 이전 data 접근권과 보존 metric을 함께 기록해야 한다.

### Learning rate와 replay의 대규모 조건

Ibrahim 등은 새 data 단계에서 learning rate를 다시 높이고(re-warming) 다시 낮추며(re-decay), 과거 data 일부를 replay하는 조합을 시험했다. 405M model의 영어→영어·영어→독일어 이동과 10B model의 약한 영어→영어 이동에서, 특정 final loss와 LM benchmark 평균이 모든 이용 자료로 처음부터 다시 학습한 baseline에 맞먹었다. 필요한 계산은 baseline보다 적었다.

Re-warming은 새 분포 적응을 돕지만 처음에는 이전·새 분포 loss를 모두 올릴 수 있고, 높은 최대 learning rate는 망각을 키울 수 있다. Replay 비율과 schedule은 공짜 상수가 아니라 분포 이동·token budget·model 규모에 맞춰 검증할 항목이다.

### 지식이 도착하는 네 위치

[[사전 학습 지식은 과제에 어떻게 도착하는가]]의 비교 축에 지속 사전 학습을 추가하면 다음처럼 정리할 수 있다.

| 경로 | 새 정보가 놓이는 위치 | 빠르게 바꿀 수 있는 것 | 대표 한계 |
| --- | --- | --- | --- |
| 지속 사전 학습 | Base 또는 확장 parameter | 넓은 분포·언어 규칙·영역 표현 | 망각, 사실 단위 추적 어려움 |
| LoRA·adapter 학습 | 별도 작은 update artifact | 특정 data·task에 대한 행동 | Adapter 충돌·routing·base 의존 |
| RAG | 외부 index와 현재 context | Document 집합·출처 후보 | 검색 실패·문서 오독 |
| RLHF·선호 최적화 | 응답 정책 parameter | 지시 따르기·선호 행동 | 최신 사실 습득을 직접 보장하지 않음 |

“Post-training”이라는 말도 문맥에 따라 달라진다. Ke 등의 CPT는 비표지 영역 corpus와 언어 모델 목적을 뜻하지만, InstructGPT 계열의 post-training은 SFT·선호 보상·정책 최적화를 포함한다. Data와 objective를 확인하지 않은 용어 비교는 피한다.

## 검증과 한계

### 성공 조건과 실패 조건

- 새 corpus loss가 낮아져도 이전 분포의 downstream 능력이 손상될 수 있다.
- 이전 점수가 유지돼도 새 사실을 정확히 회상하거나 오래된 답만 선택적으로 지웠다고 볼 수 없다.
- Replay는 원자료 보존·재사용이 허용돼야 하며 privacy·copyright·storage 조건을 가진다.
- Distillation은 이전 model의 유용한 행동과 함께 편향·오류도 보존할 수 있다.
- Parameter masking·adapter·확장은 interference를 줄여도 model routing과 장기 누적 복잡성을 만든다.
- 평균 benchmark는 희귀 과제·언어·안전 행동의 회귀를 숨길 수 있다.
- 지속 학습 논문의 연구용 stream 결과는 사용자 interaction에서 즉시 online update하는 production system의 증거가 아니다.

### 흔한 오해

- **Fine-tuning과 처음부터의 retraining은 같다:** 둘 다 weight를 바꿀 수 있지만 출발 checkpoint와 사용 data·compute가 다르다.
- **PEFT면 망각이 없다:** Trainable parameter 수와 과거 능력 보존은 별도 축이다.
- **새 문서를 학습하면 사실이 database처럼 교체된다:** 언어 모델 학습은 distribution-level optimization이며 사실 단위 update·삭제를 직접 보장하지 않는다.
- **RAG는 지속 사전 학습의 한 방법이다:** RAG는 보통 추론 시 외부 memory를 읽고 base weight를 그대로 둔다.
- **Versioning·rollback이 continual-learning algorithm이다:** 이는 실패를 관리하는 운영 장치이며 학습 성질이 아니다.
- **2025년에 처음 등장했다:** 순차 언어 모델 pretraining과 지식 갱신의 직접 연구는 적어도 2022년에 공개됐고, 영역 적응의 토대는 더 이르다.

### 현재 근거의 범위

핵심 연구는 RoBERTa 계열, 405M·10B autoregressive model, 제한된 domain·temporal stream과 연구용 benchmark를 사용한다. 수천억 parameter의 비공개 model, 장기간 수십·수백 회 update, 다국어·고위험 영역, 오염되거나 상충하는 실시간 data에서 같은 절충이 유지되는지는 별도 실증이 필요하다.

지속 사전 학습은 최신성 문제의 한 경로다. 빠르게 변하는 사실은 RAG 같은 외부 memory, 좁은 오류는 model editing, 행동 목표는 지도·선호 post-training이 더 직접적일 수 있다. 실제 system은 이 경로들을 조합하되 어느 층이 어떤 근거로 갱신됐는지 기록해야 한다.

# 언어 모델 전이 학습

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[단어 임베딩]]<br>
> **읽고 나면:** 무엇을 고정·갱신하고 과제를 어떤 출력 interface로 표현하는지에 따라 특징 추출·전체 미세조정·영역 적응·text-to-text·지시 미세조정을 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

[[언어 모델 전이 학습]]은 큰 비표지 텍스트에서 언어 모델이 학습한 매개변수나 내부 표현을 후속 과제에 재사용하는 방법 계열이다. 2018년 ELMo와 ULMFiT는 각각 고정 특징 추출과 모델 전체 미세조정이라는 서로 다른 전이 경로를 선명하게 실증했다.

## 2단계 — 작동 원리

### 전이하는 대상

‘사전 학습 모델을 사용한다’는 말은 하나의 절차가 아니다.

| 경로 | 고정하는 것 | 새로 학습하는 것 | 대표 사례 |
|---|---|---|---|
| 정적 lookup 재사용 | 단어별 벡터 또는 일부 입력층 | 후속 과제 모델 | Word2Vec·GloVe 입력 초기화 |
| 문맥 특징 추출 | 사전 학습 언어 모델 | 층 혼합·과제 모델 | ELMo |
| 전체 미세조정 | 초기에는 사전 학습값을 사용하되 매개변수 갱신 | 영역 LM·과제 분류기와 언어 모델 | ULMFiT |
| 공통 text-to-text 전체 미세조정 | 같은 pretrained encoder–decoder에서 시작 | 과제별 label·answer·summary를 target text로 학습 | T5 |
| 다과제 지시 미세조정 | pretrained checkpoint에서 시작 | 여러 과제의 지시–입력–출력 mixture로 가중치를 갱신하고 현재 과제는 지시로 지정 | FLAN |
| 문맥 내 적응 | 사전 학습 매개변수 | 추론 입력의 instruction·demonstration; 가중치 갱신 없음 | GPT-3 |
| 영역 계속학습과 과제 분포 미세조정 | GPT 계열 초기값 | 코드 next-token 학습 뒤 올바른 독립 함수로 추가 지도 미세조정 | Codex·Codex-S |
| 부분 매개변수 적응 | 기반 모델 대부분 | adapter·저랭크 행렬·prompt 등 | 후대 parameter-efficient tuning |

전이 단위를 구분해야 계산 비용, 자료 요구량, 표현 고정성, 파국적 망각 위험을 비교할 수 있다.

### 특징 추출과 전체 미세조정

ELMo는 입력 문장마다 biLM의 위치별 내부 상태를 계산하고 과제별 가중합을 만든다. 사전 학습 biLM을 고정하면 원 지식의 급격한 손실을 막고 여러 과제에서 같은 모델을 공유하기 쉽다. 대신 표현 자체를 목표 과제에 맞게 크게 바꾸지는 못하고, 후속 과제 구조를 별도로 훈련해야 한다.

ULMFiT는 사전 학습 AWD-LSTM을 목표 텍스트 분포와 분류 목표에 맞춰 갱신한다. 더 큰 적응력을 얻지만 작은 자료에서 과적합·파국적 망각이 생길 수 있다. 층별 학습률, 점진적 동결 해제, 학습률 일정은 이 균형을 조절한다.

### 일반 사전 학습과 영역 적응

일반 말뭉치는 넓은 언어 규칙성을 제공하지만 목표 영역의 어휘·문체·주제 분포와 다를 수 있다. ULMFiT는 분류 라벨을 쓰기 전에 목표 과제의 텍스트로 언어 모델을 미세조정했다. 이 단계는 비표지 목표 자료를 이용해 분포 차이를 줄이고, 표지 자료가 적은 상황의 감독 학습을 준비한다.

영역 적응이 항상 성능을 높이거나 편향을 없애는 것은 아니다. 목표 텍스트의 양과 대표성, 일반 지식 손실, 평가 분포를 함께 확인해야 한다.

### 문맥화와 전이의 구분

문맥화는 같은 token이 주변 입력에 따라 다른 은닉 상태를 얻는 성질이고, 전이는 한 자료·목적에서 배운 지식을 다른 과제에 재사용하는 절차다. ELMo는 둘을 결합했지만 두 개념은 동일하지 않다. 무작위 초기화한 과제별 biLSTM도 문맥화할 수 있고, 정적 Word2Vec 벡터도 과제 사이에 전이할 수 있다.

## 3단계 — 기술과 근거

### 후대 모델을 읽는 기준

[[Transformer]] 기반 모델에서도 다음 질문이 남는다.

1. 사전 학습 목적은 다음 token 예측, masked token 복원, 또는 다른 목표 가운데 무엇인가?
2. 후속 과제에서 기반 모델을 고정하는가, 전체를 갱신하는가, 일부 매개변수만 학습하는가?
3. 목표 영역의 비표지 적응과 과제 라벨 학습을 분리하는가?
4. 평가 개선이 어떤 과제·언어·자료 크기에서 확인됐는가?

이 기준은 ELMo·ULMFiT·BERT·GPT를 ‘모두 사전 학습’이라는 한 문장으로 평평하게 만들지 않게 한다.

[[BERT]]는 ELMo와 달리 기반 encoder를 고정 특징으로만 쓰지 않고 후속 손실로 전체 미세조정했다. ULMFiT와 전체 적응 인터페이스를 공유하지만 목표 영역 LM 적응을 동일한 필수 단계로 두지 않았고, 자기회귀 LM 대신 [[마스크드 언어 모델링]]을 사용했다.

[[GPT-1과 GPT-2]]는 같은 causal 언어 모델 계열 안에서도 전이 위치가 달라질 수 있음을 보였다. GPT-1은 과제 입력 변환·출력층과 지도 fine-tuning을 사용했고, GPT-2는 가중치 갱신 없이 cue·scoring·decoding으로 task를 text continuation에 배치했다. 후자는 현대 in-context learning의 초기 전조지만 당시 과제별 절대 성능과 제한을 함께 봐야 한다.

### T5: 과제별 출력을 같은 text target으로 옮긴다

[[T5]]는 분류 label, answer, summary와 translation을 모두 target token sequence로 만들었다. BERT처럼 pretrained parameter를 downstream label로 전체 fine-tuning하지만, 과제별 분류·span head 대신 같은 encoder–decoder와 vocabulary를 사용한다. GPT-2 zero-shot과 달리 대표 T5 결과에는 각 task의 labeled example과 weight update가 들어간다.

T5의 task prefix는 supervised training에서 과제를 식별하는 text input이다. 현대 instruction-following model처럼 처음 보는 과제를 자유로운 자연어 지시만으로 해결했다는 뜻은 아니다. 또한 output interface가 같아져도 dataset, label 의미, decoding 조건과 metric은 과제별로 남는다.

### FLAN: 여러 과제의 감독 신호를 weights에 넣고 현재 과제는 지시로 고른다

[[지시 미세조정]]은 T5의 공통 text output과 GPT-3의 inference instruction 사이에 또 다른 적응 경로를 놓는다. [[072_지시 미세조정과 FLAN의 제로샷 일반화]]의 원 FLAN은 62개 dataset을 12개 task cluster로 묶고, 평가할 cluster 전체를 제외한 나머지 과제의 자연어 지시와 target으로 137B LaMDA-PT 전체를 미세조정했다.

여기서 여러 과제의 지도 정보는 gradient를 통해 **가중치**에 들어간다. 현재 보류 과제는 **inference instruction·input·분류 OPTIONS**가 지정한다. GPT-3 zero-shot처럼 현재 과제 demonstration은 없지만, task supervision 전체가 없는 것은 아니다. T5 대표 결과처럼 평가 과제의 label로 다시 fine-tuning하지도 않는다.

FLAN의 25개 결과는 하나의 checkpoint가 아니라 평가 cluster마다 그 cluster를 뺀 별도 checkpoint에서 나왔다. 또한 422M·2B·8B에서는 보류 성능이 악화되고 68B·137B에서 좋아졌다. 따라서 다과제 supervision을 weights에 넣는다는 절차와 모든 규모·과제에서 일반화한다는 성능 주장을 분리한다.

### GPT-3: 표지 예시를 가중치가 아닌 입력에 둔다

[[문맥 내 학습]]에서 task-specific example은 사라지지 않고 입력 sequence의 demonstration으로 이동한다. [[067_GPT-3와 문맥 내 학습]]의 few-shot 조건은 보통 2048-token 문맥에 10–100개 예시를 넣었고, one-shot은 하나, zero-shot은 예시 없이 instruction만 제공했다. 세 조건 모두 optimizer step이나 역전파 없이 같은 사전 학습 가중치로 평가됐다.

이 방식은 ‘전이 학습이 없어졌다’기보다 **후속 과제 적응의 계산 위치가 바뀌었다**고 보는 편이 정확하다. 과제별 checkpoint는 만들지 않지만 prompt 형식, example 선택, context 길이, candidate scoring과 metric이 과제 명세로 남는다. Brown 등은 문맥에서 새 과제를 학습한 것인지 사전 학습 중 익힌 과제를 식별한 것인지도 확정하지 않았다.

### Codex: 코드 분포·함수 과제·선택 절차를 나눈다

[[OpenAI Codex (2021)]]의 연구 계열은 GPT 계열 causal language model을 공개 GitHub Python 코드의 다음-token 예측으로 계속 학습했다. [[071_Codex와 HumanEval 기반 코드 생성 평가]]는 이 단계를 최대 12B 모델과 필터링된 159GB Python 자료에서 평가했다. GPT 초기화는 처음부터 학습한 모델보다 수렴을 빠르게 했지만 최종 성능 향상은 관찰되지 않았으므로, GPT-3의 추론 능력을 그대로 물려받았기 때문에 성공했다고 단정할 수 없다.

Codex-S는 여기서 한 단계를 더 나아가 올바르게 구현된 독립 함수와 docstring 쌍으로 지도 미세조정했다. 실제 HumanEval 과제는 함수 signature와 docstring이 입력 prompt에 놓였고, 여러 후보를 생성한 뒤 unit test나 평균 log-probability로 선택했다. 따라서 과제 정보는 **코드 분포에 맞춘 매개변수**, **함수 합성 분포의 지도 미세조정**, **입력 명세**, **표본 예산과 선택 규칙**에 나뉘어 있다. 이는 GPT-3처럼 가중치를 고정한 문맥 내 적응과 다른 경로다.

## 검증과 한계

### 한계

- 사전 학습 자료의 언어·영역·사회적 편향도 함께 전이될 수 있다.
- 고정 특징은 적응력이 제한되고, 전체 미세조정은 계산 비용과 망각 위험이 크다.
- 적은 표지 자료의 이득은 과제·영역 유사성·모델 규모에 따라 달라진다.
- 문맥 내 적응은 가중치 갱신 비용을 없애지만 demonstration token·추론 비용·prompt 및 scoring 설계 비용을 없애지 않는다.
- 지시 미세조정은 공통 checkpoint의 활용 범위를 넓힐 수 있지만 mixture 구성·template·보류 단위·model capacity에 따라 보지 못한 과제의 이득이 달라진다.
- 코드 영역 미세조정의 benchmark 이득은 짧은 독립 함수·특정 언어·unit-test coverage에 묶이며, 여러 파일의 시스템 개발 능력을 자동으로 보장하지 않는다.
- 벤치마크 성능 향상만으로 일반 언어 이해나 분포 밖 견고성을 보장할 수 없다.

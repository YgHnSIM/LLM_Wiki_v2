# 규칙 기반 기계 번역

> [!note] 학습 안내
> **난이도:** 입문<br>
> **선수 지식:** [[기계 번역]]<br>
> **읽고 나면:** 사전 조회에서 문법 규칙 적용과 목표 문장 생성까지의 흐름을 설명하고, 규칙 기반 번역의 강점과 확장 한계를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 정의

[[규칙 기반 기계 번역]](Rule-Based Machine Translation, RBMT)은 사람이 만든 사전, 문법 정보, 변환 규칙을 이용해 원천 언어 문장을 목표 언어 문장으로 바꾸는 접근이다. [[003_Georgetown-IBM 기계 번역 시연]]의 시스템은 러시아어 단어 사전과 기본 통사 규칙을 결합한 초기 사례였다.

쉽게 말하면, 단어를 사전에서 하나씩 바꾼 뒤 원천 언어와 목표 언어의 문법 차이에 맞춰 형태와 순서를 다시 정리하는 방식이다.

## 2단계 — 작동 원리

### 작동 방식

Georgetown-IBM 시스템은 러시아어 입력을 단어 단위로 나누고, 각 단어를 사전에서 조회해 영어 번역 후보와 품사·격 같은 문법 정보를 가져왔다. 그다음 러시아어의 격 표시와 어순 정보를 바탕으로 주어와 목적어 관계를 추정하고, 영어 문법에 맞게 단어 순서와 표현을 조정했다.

## 3단계 — 기술과 근거

### 강점

규칙 기반 접근은 처리 과정이 비교적 명시적이고, 시스템이 어떤 규칙을 적용했는지 추적하기 쉽다. 제한된 영역과 통제된 문장에서는 이해 가능한 번역을 만들 수 있으며, 초기 컴퓨터의 제한된 계산 자원에서도 구현 가능했다.

## 검증과 한계

### 한계

이 접근은 사전에 없는 단어, 관용 표현, 복잡한 통사 구조, 문맥에 따른 의미 차이에 취약하다. 새로운 언어쌍과 전문 영역을 추가할 때마다 사전과 규칙을 수작업으로 확장해야 하므로 [[지식 공학 병목]]이 발생한다.

[[005_촘스키의 통사 구조]]는 이런 한계를 더 일반적인 언어 구조 문제와 연결한다. 규칙 기반 번역이 원천 언어를 [[심층 구조]]나 [[통사 구조]]로 분석해 목표 언어의 [[표층 구조]]를 생성하려는 이상을 가졌지만, 실제 자연어의 모호성, 관용 표현, 세계 지식은 수작업 규칙만으로 포괄하기 어려웠다.

## 학습 확인

### 확인 질문

1. 규칙 기반 기계 번역을 구성하는 세 가지 사람이 설계한 자원은 무엇인가?
2. Georgetown-IBM 시스템은 러시아어 입력을 어떤 순서로 영어 문장으로 바꾸었는가?

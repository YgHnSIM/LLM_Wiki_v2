# 통계적 자연어 처리

> [!note] 학습 안내
> **난이도:** 심화<br>
> **선수 지식:** [[concept.조건부-확률|조건부 확률]], [[concept.말뭉치-기반-학습|말뭉치 기반 학습]]<br>
> **읽고 나면:** 자료에서 점수·확률·매개변수를 추정해 후보를 선택하는 공통 흐름과 생성·판별·상징 결합 모델의 차이를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 핵심 정의

[[통계적 자연어 처리]](Statistical NLP)는 언어 자료에서 확률·가중치·매개변수를 추정하고, 가능한 분석이나 출력 가운데 자료에 비추어 더 그럴듯한 것을 선택하는 접근법의 묶음이다. 하나의 알고리즘을 가리키는 말이 아니며, 언어 모델링·음성 인식·품사 태깅·파싱·기계 번역처럼 서로 다른 과제에서 서로 다른 시기에 발전했다.

## 2단계 — 작동 원리

### 핵심 원리

통계적 모델은 입력 $x$와 후보 출력 $y$의 관계를 $P(y\mid x)$, 결합 확률, 가능도 또는 이에 대응하는 점수로 나타낸다. 학습 자료에서 매개변수를 추정하고, 보지 못한 평가 자료에서 후보 선택이 얼마나 정확한지 측정한다. [[N-gram 모델]]은 앞선 단어가 주어졌을 때 다음 단어의 [[조건부 확률]]을 추정하고, [[은닉 마르코프 모델]]은 상태 전이와 관측 방출 확률로 시퀀스를 모델링한다.

확률은 모호성을 제거하지 않는다. 여러 품사열·구문 트리·번역문에 서로 다른 점수를 부여해 선택할 수 있게 한다. 가장 높은 확률의 후보가 실제 의미나 진리와 항상 일치하는 것은 아니며, 후보 공간·모델 가정·학습 분포가 잘못되면 체계적인 오류가 난다.

## 3단계 — 기술과 근거

### 역사적 범위

통계적 언어 처리의 토대는 1980년대 이전부터 존재했다. 섀넌은 1948년에 영어의 통계 구조를 분석했고, Jelinek는 1976년에 연속 음성 인식의 확률 모델·매개변수 추정·가설 탐색을 정리했다. 텍스트 NLP에서는 Church의 1988년 확률적 품사 태거, IBM 연구진의 1990년 예비 번역 실험과 1993년 Models 1–5 정식화가 구체적인 이정표다. [[022_IBM 통계적 기계 번역과 데이터 기반 전환]]은 이 [[통계적 기계 번역]] 연구를 단일한 1991년 발명으로 합치지 않고 논문별 기여로 구분한다.

Church와 Mercer는 1993년의 대규모 말뭉치 특집을 1950년대식 경험적·통계적 방법의 부활로 규정했다. 따라서 [[012_상징 규칙에서 통계 학습으로]]의 “1980년대 통계 혁명”은 편리한 시대 구분일 뿐 단일 발명 연도가 아니다. 같은 논문은 1993년에도 기계 번역에서 합리주의적 접근이 우세하고 논쟁이 진행 중이라고 기록한다.

### 생성 모델과 판별 모델

[[은닉 마르코프 모델]] 같은 생성 모델은 라벨 상태의 전이와 관측의 방출을 포함한 결합 구조를 모델링한다. 반면 [[최대 엔트로피 모델]]은 입력 문맥이 주어졌을 때 라벨의 조건부 확률을 직접 정규화하고, [[서포트 벡터 머신]]은 확률 분포 대신 클래스 사이의 최대 마진 경계를 학습한다. 모두 자료에서 매개변수를 추정한다는 점에서는 통계적이지만 필요한 가정과 출력의 의미는 다르다.

[[027_최대 엔트로피와 서포트 벡터 머신]]의 연표는 이 전환도 단일 사건이 아니었음을 보여 준다. MaxEnt의 NLP 적용은 1993–1994년에 나타났고, 1996년에는 원리의 체계화와 품사 태깅이 이어졌다. SVM의 1995년 원 논문은 필기 숫자 인식이었으며 대표적인 텍스트 분류 적용은 1998년, 청킹과 개체명 인식은 2001–2002년의 별도 연구다.

판별 모델은 입력 특징의 결합분포를 모두 설명하지 않고 예측 경계에 집중할 수 있지만, 입력 표현을 자동으로 결정하지는 않는다. Ratnaparkhi의 단어·접사·이전 품사 템플릿과 Joachims의 최소 빈도·불용어·IDF·길이 정규화는 [[특징 공학]]이 통계적 학습의 일부였음을 보여 준다. 후대 CRF는 라벨열 전체를 조건부로 정규화했고, 구조 SVM은 마진 학습을 구조 출력으로 확장했다. 지역 분류기와 이러한 순서열 확장을 같은 모델로 합치지 않는다.

### 상징 구조와의 결합

통계적 방법은 명시적 언어 구조를 반드시 버리지 않는다. HMM 품사 태거는 사람이 정의한 품사를 은닉 상태로 사용하고, 확률적 문법은 [[문맥자유문법]]의 규칙에 확률을 부여한다. Brill의 1992년 태거는 주석 자료에서 오류를 줄이는 변환 규칙을 학습해, 사람이 읽을 수 있는 상징 규칙과 데이터 기반 선택을 한 시스템 안에 결합했다.

이 때문에 상징적 NLP와 통계적 NLP를 “규칙이 있느냐 없느냐”로 나누면 부정확하다. 더 유용한 질문은 표현 단위를 누가 정의하는지, 매개변수를 어디서 얻는지, 후보를 어떤 기준으로 선택하는지다.

[[023_Penn Treebank와 통계적 구문 분석]]은 이 결합을 자료 차원에서 보여 준다. 사람이 품사·구성 성분·빈 요소·기능 태그를 정의하고 자동 분석 결과를 교정했으며, 통계 파서는 그 정답 구조의 분포를 학습했다. 공통 자료와 괄호 정밀도·재현율은 결과를 누적 비교하게 했지만, 주석 이론과 WSJ 영역을 모델의 능력 정의에 함께 새겼다.

[[017_Lesk 알고리즘과 단어 의미 중의성 해소]]가 다루는 [[Lesk 알고리즘]]은 이 경계를 보여 주는 사례다. Lesk(1986)의 [[단어 의미 중의성 해소]] 절차는 기계 판독형 사전에서 후보 의미의 정의와 문맥 단어들의 정의 사이에 정확히 일치하는 어휘를 세어 의미를 고르는 결정론적 지식 기반 방법이다. 문맥을 계산에 넣지만 학습 자료에서 확률이나 매개변수를 추정하는 통계 모델은 아니다.

따라서 규칙 기반 NLP에서 통계적 NLP로의 변화를 단선적인 교체로 설명하면, 사전처럼 사람이 편찬한 자원을 계산적으로 활용한 별도·중간 계열을 놓친다. Lesk는 문맥 활용이라는 문제의식을 공유하지만 현대 통계·신경 NLP 전체의 직접 조상으로 보지 않는다.

## 검증과 한계

### 한계

통계 모델은 학습 자료의 범위와 편향을 따른다. 희소한 표현, 새로운 장르, 다른 방언이나 시대에는 확률 추정이 불안정할 수 있다. 많은 자료를 더하는 것만으로 품질이 자동 개선되지는 않으며, 표집·주석·평가·목표 함수가 중요하다. 수작업 규칙의 [[지식 공학 병목]] 일부는 데이터와 주석을 설계하는 병목으로 이동한다.

현대의 자기회귀 [[대규모 언어 모델]]은 대규모 텍스트에서 다음 토큰의 분포를 학습한다는 넓은 통계적 전통과 연결된다. BERT 계열처럼 가려진 토큰 복원 등 다른 목표를 쓰는 언어 모델도 있다. HMM·n-gram·확률 문법과는 표현 구조와 학습 방식이 같지 않으며, LLM을 초기 통계 모델의 단순한 크기 확대판으로 설명하지 않는다.

# 통계적 자연어 처리

[[통계적 자연어 처리]](Statistical NLP)는 언어 자료에서 확률·가중치·매개변수를 추정하고, 가능한 분석이나 출력 가운데 자료에 비추어 더 그럴듯한 것을 선택하는 접근법의 묶음이다. 하나의 알고리즘을 가리키는 말이 아니며, 언어 모델링·음성 인식·품사 태깅·파싱·기계 번역처럼 서로 다른 과제에서 서로 다른 시기에 발전했다.

## 핵심 원리

통계적 모델은 입력 $x$와 후보 출력 $y$의 관계를 $P(y\mid x)$, 결합 확률, 가능도 또는 이에 대응하는 점수로 나타낸다. 학습 자료에서 매개변수를 추정하고, 보지 못한 평가 자료에서 후보 선택이 얼마나 정확한지 측정한다. [[N-gram 모델]]은 앞선 단어가 주어졌을 때 다음 단어의 [[조건부 확률]]을 추정하고, [[은닉 마르코프 모델]]은 상태 전이와 관측 방출 확률로 시퀀스를 모델링한다.

확률은 모호성을 제거하지 않는다. 여러 품사열·구문 트리·번역문에 서로 다른 점수를 부여해 선택할 수 있게 한다. 가장 높은 확률의 후보가 실제 의미나 진리와 항상 일치하는 것은 아니며, 후보 공간·모델 가정·학습 분포가 잘못되면 체계적인 오류가 난다.

## 역사적 범위

통계적 언어 처리의 토대는 1980년대 이전부터 존재했다. 섀넌은 1948년에 영어의 통계 구조를 분석했고, Jelinek는 1976년에 연속 음성 인식의 확률 모델·매개변수 추정·가설 탐색을 정리했다. 텍스트 NLP에서는 Church의 1988년 확률적 품사 태거와 IBM 연구진의 1990년 통계 기계 번역이 구체적인 이정표다.

Church와 Mercer는 1993년의 대규모 말뭉치 특집을 1950년대식 경험적·통계적 방법의 부활로 규정했다. 따라서 [[012_상징 규칙에서 통계 학습으로]]의 “1980년대 통계 혁명”은 편리한 시대 구분일 뿐 단일 발명 연도가 아니다. 같은 논문은 1993년에도 기계 번역에서 합리주의적 접근이 우세하고 논쟁이 진행 중이라고 기록한다.

## 상징 구조와의 결합

통계적 방법은 명시적 언어 구조를 반드시 버리지 않는다. HMM 품사 태거는 사람이 정의한 품사를 은닉 상태로 사용하고, 확률적 문법은 [[문맥자유문법]]의 규칙에 확률을 부여한다. Brill의 1992년 태거는 주석 자료에서 오류를 줄이는 변환 규칙을 학습해, 사람이 읽을 수 있는 상징 규칙과 데이터 기반 선택을 한 시스템 안에 결합했다.

이 때문에 상징적 NLP와 통계적 NLP를 “규칙이 있느냐 없느냐”로 나누면 부정확하다. 더 유용한 질문은 표현 단위를 누가 정의하는지, 매개변수를 어디서 얻는지, 후보를 어떤 기준으로 선택하는지다.

## 한계

통계 모델은 학습 자료의 범위와 편향을 따른다. 희소한 표현, 새로운 장르, 다른 방언이나 시대에는 확률 추정이 불안정할 수 있다. 많은 자료를 더하는 것만으로 품질이 자동 개선되지는 않으며, 표집·주석·평가·목표 함수가 중요하다. 수작업 규칙의 [[지식 공학 병목]] 일부는 데이터와 주석을 설계하는 병목으로 이동한다.

현대 [[대규모 언어 모델]]은 대규모 텍스트에서 다음 토큰의 분포를 학습한다는 넓은 통계적 전통과 연결된다. 다만 HMM·n-gram·확률 문법과 표현 구조와 학습 방식이 같지는 않으며, LLM을 초기 통계 모델의 단순한 크기 확대판으로 설명하지 않는다.

# 마스크드 언어 모델링

[[마스크드 언어 모델링]](Masked Language Modeling, MLM)은 입력 token 일부를 예측 대상으로 선택해 교란하고, 남은 좌우 문맥에서 원 token을 복원하도록 학습하는 사전 학습 목적이다. [[BERT]]는 깊은 양방향 Transformer 표현을 학습하기 위해 이 목적을 사용했다.

## 목적함수

원 sequence $x$에서 위치 집합 $M$을 뽑고 교란 함수로 $\tilde{x}$를 만든다. 모델은 선택 위치의 원 token만 예측한다.

$$
\mathcal{L}_{\mathrm{MLM}}(x)
=-\sum_{i\in M}\log p_\theta(x_i\mid\tilde{x}).
$$

causal mask가 없는 encoder에서는 $i$의 왼쪽과 오른쪽 token을 모두 조건으로 쓸 수 있다. 반면 자기회귀 다음 token 예측은 일반적으로 $p(x_i\mid x_{<i})$를 사용한다.

## BERT의 15%와 80/10/10

BERT는 WordPiece token 위치의 15%를 균일하게 선택했다.

- 선택 위치의 80%: `[MASK]`로 교체
- 10%: 무작위 vocabulary token으로 교체
- 10%: 원 token 유지

선택 위치는 세 경우 모두 원 token ID가 정답이다. 10% 원 token 사례에서도 모델은 그 위치가 손실 대상인지 입력만 보고 알 수 없다. 선택하지 않은 token은 문맥을 제공하지만 MLM loss의 직접 정답 항에는 들어가지 않는다.

## 장점과 불일치

MLM은 한 위치의 좌우 문맥을 동시에 사용하므로 분류·token labeling·span extraction에 유용한 표현을 제공한다. 모든 위치의 다음 token을 예측하는 자기회귀 목표보다 한 sequence에서 직접 채점하는 위치 수는 적어 수렴 효율이 다를 수 있다.

`[MASK]`는 실제 미세조정 입력에 거의 나타나지 않아 사전 학습–사용 불일치가 생긴다. BERT의 80/10/10 규칙은 이를 줄이지만 제거하지 않는다. ELECTRA의 replaced-token detection, XLNet의 permutation objective 등은 이 병목에 다른 답을 제안했다.

## masking 단위와 일정

BERT 원 절차는 WordPiece tokenization 뒤 개별 token 위치를 선택했고 partial word piece를 특별히 함께 가리지 않았다. 후대 whole-word masking은 한 단어의 모든 subword를 묶어 선택한다. RoBERTa의 dynamic masking은 epoch·노출마다 masking pattern을 바꿔 같은 sequence에 더 다양한 예측 위치를 제공한다.

이 변형들은 모두 ‘가려진 단어 맞히기’라는 표현 아래 있지만 선택 단위, 교란 분포, 재표집 일정과 학습 효율이 다르다.

## 생성 모델과의 차이

MLM은 입력 전체의 일부 빈칸을 채우는 조건부 복원 목적이다. 왼쪽에서 오른쪽으로 joint sequence probability를 표준적으로 분해하지 않으므로 그 자체가 causal text generator는 아니다. 반복 masking·Gibbs식 sampling 같은 생성 절차를 구성할 수 있어도 GPT식 next-token decoding과 동일하지 않다.

## 한계

- 선택 위치 비율과 교란 규칙이 실제 입력 분포와 다르다.
- 독립적으로 선택한 여러 masked token을 동시에 예측하면 선택 token 사이의 의존을 직접 조건화하지 못할 수 있다.
- token 복원 정확도가 추론·사실성·문서 이해를 자동 보장하지 않는다.
- subword masking 단위에 따라 형태·어휘 학습 신호가 달라진다.

# 통계적 기계 번역

통계적 기계 번역(Statistical Machine Translation, SMT)은 병렬 말뭉치에서 언어 간 대응의 확률을 추정하고, 원문에 대해 점수가 높은 번역문을 탐색하는 [[기계 번역]] 접근이다. 단어·구·구문 기반 등 여러 계열을 포함하며 하나의 단일 모델 이름은 아니다. [[022_IBM 통계적 기계 번역과 데이터 기반 전환]]은 IBM의 단어 기반 모형과 그 후속 전개를 1차 문헌으로 검증한다.

## 확률적 문제 설정

IBM의 대표적 잡음 채널 정식화는 원문 `f`에 대한 번역문 `e`의 조건부 확률을 목표 언어 모델과 번역 모델로 나눈다.

\[
\hat e = \arg\max_e P(e\mid f) = \arg\max_e P(e)P(f\mid e)
\]

`P(e)`는 목표 언어 문장의 가능성을, `P(f|e)`는 두 언어 사이의 대응을 평가한다. 디코딩은 이 점수를 최대화하는 문장 후보를 찾는 별도 탐색 문제다. 확률 분해는 유창성과 번역 대응을 따로 개선할 수 있게 하지만 의미 보존이나 문서 수준 일관성을 자동으로 보장하지 않는다.

## 병렬 말뭉치와 숨은 정렬

병렬 문장쌍만으로는 어느 단어가 어느 단어와 대응하는지 관측되지 않는다. IBM Models는 단어 정렬을 잠재 변수로 두고 EM으로 기대 계수를 계산해 어휘·위치·생성도·왜곡 확률을 갱신했다. Models 1·2는 가능한 정렬 전체를 정확히 합산할 수 있었고, Models 3 이상은 넓어진 정렬 공간에서 유력한 후보 주변을 탐색하는 근사를 사용했다.

자료의 양만큼 정렬·필터링·어휘 처리도 중요하다. Canadian Hansard에서 추출한 전체 후보 규모와 실제 매개변수 실험에 사용한 부분집합은 달랐으며, 희귀어 처리와 문장 길이 제한 같은 설계 선택도 학습 결과에 영향을 주었다. 이는 [[말뭉치 기반 학습]]이 사람의 설계를 없애기보다 설계 대상을 바꾼다는 사례다.

## IBM Models와 단어 기반 SMT

- Model 1은 어휘 번역 확률과 균일한 위치 선택을 사용한다.
- Model 2는 문장 길이와 두 단어 위치에 따른 정렬 확률을 더한다.
- Model 3은 생성도, NULL 생성과 단어 배치를 명시적으로 매개변수화한다.
- Model 4는 단어 부류와 상대 위치를 이용해 왜곡 모형을 정교화한다.
- Model 5는 빈 위치를 추적해 Models 3·4의 결손 분포와 유효하지 않은 배치 문제를 제거한다.

Models 1·2도 한 영어 단어에 여러 프랑스어 단어가 대응할 수 있다. Model 3의 차이는 다단어 대응을 처음 허용했다는 데 있지 않고 생성 수의 분포를 별도 매개변수로 둔 데 있다.

## Candide와 구 기반 SMT

1994년 Candide는 IBM 번역 모형과 언어 모형·디코더를 시스템으로 통합했지만 형태 처리와 이름·숫자 규칙 같은 설계 요소도 함께 사용했다. [[규칙 기반 기계 번역]]과 통계적 기계 번역은 역사상 언제나 완전히 분리된 두 상자였던 것이 아니라 혼합 구성으로 공존했다.

구 기반 SMT는 2003년 무렵 IBM·GIZA++ 정렬에서 일관된 다단어 구를 추출하고, 구 번역·언어·재배열 등 여러 특징을 결합하는 방식으로 발전했다. 2007년 Moses는 이 계열을 실험하고 배포할 수 있게 한 공개 툴킷이다. [[BLEU]]는 별도인 2002년 자동 평가 지표이며 초기 IBM Models의 구성 요소가 아니다. [[033_BLEU와 기계 번역 자동 평가]]는 BLEU의 수정 n-gram 정밀도·말뭉치 집계와 평가 한계를 검증한다.

## 신경망 번역과의 경계

[[신경망 기계 번역]]도 병렬 자료에서 `P(y|x)`를 학습하는 확률 모델이다. 신경망 seq2seq는 IBM식 어휘·정렬·왜곡 표를 하나씩 결합하는 대신 인코더와 디코더의 연속 표현으로 조건부 분포를 매개변수화했다. 신경망 어텐션은 입력–출력 대응을 나타낸다는 점에서 단어 정렬과 비교할 수 있지만, EM으로 추정하는 이산 잠재 변수와 현재 은닉 상태에서 계산하는 연속 가중치는 같은 연산이 아니다.

따라서 SMT에서 NMT로의 전환을 “확률 번역에서 비확률 번역으로의 이동”이라고 부르지 않는다. 직접 확인되는 공학적 연속성은 구 기반 SMT가 IBM 정렬을 사용한 경우이고, IBM 정렬에서 어텐션·Transformer가 곧바로 파생됐다는 역사적 인과에는 별도 근거가 필요하다.

## 강점과 한계

- 대규모 병렬 자료에서 번역 대응을 재현 가능한 확률 추정 문제로 만들었다.
- 언어 모델·번역 모델·정렬·탐색·평가를 분리해 구성 요소별 연구를 가능하게 했다.
- 단어 기반 모형은 관용 표현, 다단어 대응, 긴 문맥과 형태적으로 풍부한 언어를 다루는 데 한계가 있었다.
- 데이터가 적거나 영역이 바뀌면 [[데이터 희소성]]과 정렬 오류가 크게 작용한다.
- 1994년 Candide–SYSTRAN의 혼합 평가처럼, 초기 실험은 통계 방식의 모든 언어·영역·품질 차원에서의 보편적 우월성을 입증하지 않았다.

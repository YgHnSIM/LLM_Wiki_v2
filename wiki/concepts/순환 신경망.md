# 순환 신경망

[[순환 신경망]](Recurrent Neural Network, RNN)은 이전 시점의 상태를 현재 계산에 다시 입력하는 신경망 계열이다. 같은 상태 전이 매개변수를 시간 위치마다 공유해 가변 길이 순서열을 처리한다. `재귀 신경망`이라는 번역은 나무 구조에 같은 함수를 적용하는 recursive neural network와 혼동될 수 있어 이 문서에서는 사용하지 않는다.

## 순환 상태와 계산식

단순한 Elman형 RNN은 다음처럼 쓸 수 있다.

\[
h_t=\phi(W_{xh}x_t+W_{hh}h_{t-1}+b_h)
\]

\[
o_t=g(W_{ho}h_t+b_o)
\]

$h_t$는 이전 상태 $h_{t-1}$와 현재 입력 $x_t$의 학습된 함수다. 따라서 과거 입력은 현재 상태를 거쳐 뒤의 출력에 영향을 줄 수 있다. 출력 $o_t$는 선택적이며, 모든 시점에서 출력하거나 마지막 상태만 분류에 쓰는 등 과제에 따라 구성이 달라진다.

Jordan형 순환망은 출력 또는 별도 상태 단위를 되먹임했고, Elman의 단순 순환망은 은닉 활성을 한 시점 늦춰 context unit에 복사했다. 오늘날 `RNN`은 이런 역사적 구조 하나만의 고유 이름이 아니라 recurrent state를 가진 여러 모델의 상위 범주다.

## 시간축 공유와 펼치기

$W_{xh}$·$W_{hh}$·$W_{ho}$는 시간 $t$가 달라져도 같은 값이 사용된다. 이 시간축 매개변수 공유 덕분에 길이마다 별도 모델을 만들지 않고 같은 전이 규칙을 반복 적용할 수 있다. 한 시간 위치에서 학습한 변환을 다른 위치에도 재사용한다는 귀납 편향도 생긴다.

접힌 그림의 순환 간선을 길이 $T$의 입력에 대해 펼치면 $h_0\rightarrow h_1\rightarrow\cdots\rightarrow h_T$인 유한한 비순환 계산 그래프가 된다. 각 시점의 셀은 복사본처럼 보이지만 매개변수는 공유한다. $h_t$가 $h_{t-1}$에 의존하므로 한 순서열의 시간 위치를 모두 동시에 계산하기는 어렵지만, 배치·행렬 연산과 은닉 단위 수준의 병렬화는 가능하다.

## BPTT 학습

시간을 통한 역전파(backpropagation through time, BPTT)는 펼친 그래프에 일반 [[역전파]]를 적용한다. 손실이 여러 시점에 있으면 각 시점의 기여를 합하고, 같은 매개변수가 여러 시점에서 사용됐으면 그 사용 지점들의 그래디언트도 합산한다.

전체 이력을 펼치면 계산량과 중간 활성화 메모리가 길이에 따라 증가한다. Williams·Peng의 truncated BPTT는 일정 구간만 역전파해 비용을 낮추지만, 구간 밖의 먼 학습 신호를 직접 자르는 근사다. Williams·Zipser의 RTRL 미분은 가중치를 고정한 궤적에는 시간 의존성을 자르지 않은 정확한 도함수를 전방으로 계산한다. 그러나 이를 사용해 매 시점 가중치를 바꾸면 이후 상태 궤적도 달라져 전체 궤적 목적의 정확한 음의 그래디언트를 더는 따르지 않고, 작은 학습률에서 가까운 근사가 된다. BPTT와는 정확성의 조건, 계산 방향·비용이 다르다.

## 상태와 기억의 차이

은닉 상태를 `기억`이라고 부르는 것은 과거가 현재 계산에 영향을 준다는 비유다. $h_t$는 앞선 입력 전체의 복사본이나 데이터베이스가 아니라, 과제 손실에 맞춰 학습된 유한 차원 표현이다. 무엇을 유지할지는 모델 용량, 상태 전이, 활성화 함수, 데이터와 최적화에 달린다.

먼 과거에 수학적으로 의존할 수 있는 **표현 가능성**, 실제 훈련이 그 의존성을 발견하는 **학습 가능성**, 상태에서 입력 이력을 되살리는 **복원 가능성**은 서로 다르다. vanilla RNN의 상태 하나가 모든 관련 정보를 보존하거나 문법·의미를 자동으로 이해한다고 가정하지 않는다.

## 장기 의존성과 게이트 구조

긴 시간축의 그래디언트는 시점별 야코비안의 연속 곱을 포함한다. 관련 방향이 반복해서 작아지면 [[기울기 소실]]이, 커지면 폭주가 나타날 수 있다. 가중치 행렬의 고윳값 하나만이 아니라 비선형 활성화의 도함수와 실제 상태 궤적을 포함한 전체 곱이 결과를 결정한다.

[[장단기 메모리|LSTM]]은 셀 상태와 곱셈 게이트를 사용해 장기 오류 흐름과 선택적 갱신을 개선했고, GRU는 reset·update gate로 상태를 갱신하는 더 단순한 recurrent unit을 제시했다. 둘 다 RNN 계열의 구조적 변형이다. 이들이 vanilla RNN보다 긴 의존성을 학습하기 쉽게 만들 수는 있지만 모든 길이·데이터·최적화에서 정보 보존이나 안정적 학습을 보장하지 않는다.

## TDNN·attention·Transformer와의 차이

[[시간 지연 신경망]]은 고정된 시간 창에 공유 필터를 적용하는 순방향 구조로, 이전 은닉 상태를 다음 시간 단계로 되먹임하지 않는다. 수용 영역 안의 여러 위치를 병렬 계산할 수 있지만 한 출력이 볼 수 있는 입력 범위는 설계한 유한한 창과 층 구조로 정해진다.

초기 RNN encoder–decoder는 입력 전체를 마지막 encoder state 하나에 압축했다. [[신경망 기계 번역]]의 attention은 출력 시점마다 입력 위치별 은닉 표현을 가중 결합해 이 고정 벡터 병목을 완화했다. Transformer는 recurrence를 유지한 채 attention을 덧붙인 RNN이 아니라, 핵심 순서열 연산에서 순환을 제거하고 self-attention과 위치 표현을 사용하는 구조다.

GPT·BERT 같은 Transformer 언어 모델도 RNN식 단일 상태 갱신을 사용하지 않는다. RNN 언어 모델과 GPT가 자기회귀 조건부 확률 분해를 공유할 수 있다는 사실은 과업 수준의 공통점이며, [[대규모 언어 모델]]이 RNN 계산을 직접 상속했다는 뜻은 아니다.

# 학습된 세계 모델

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[Transformer]], [[멀티모달 대규모 언어 모델]]<br>
> **읽고 나면:** 학습된 세계 모델이라는 이름을 관측 표현, 행동 조건부 동역학, 계획·제어의 세 층으로 분해하고, V-JEPA 2와 V-JEPA 2-AC가 실제로 학습·평가한 범위를 일반 물리·인과 이해 주장과 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 한 문장 정의

**학습된 세계 모델(learned world model)**은 관측에서 과제에 유용한 상태 표현을 만들고, 필요하면 행동에 따른 다음 상태를 예측해 목표 달성을 위한 행동 선택에 쓰는 학습 모델 계열을 가리키는 우산 범주다. `세계 모델`이라는 더 넓은 말은 [[009_SHRDLU|SHRDLU]]처럼 설계자가 직접 만든 symbolic state representation에도 쓰일 수 있으므로, 이 문서는 data에서 표현·전이를 학습하는 계열에 범위를 둔다. 이 이름만으로 관측 표현, 행동 조건부 동역학, planner와 실제 제어기가 모두 하나의 신경망 안에 있다고 결론 내릴 수는 없다.

이 문서에서는 학습된 세계 모델 system을 다음 세 층으로 나누어 읽는다.

| 층 | 묻는 질문 | V-JEPA 2 사례 |
| --- | --- | --- |
| 관측 기반 표현 모델 | 영상에서 어떤 상태 정보를 보존하는가? | Action-free V-JEPA 2 encoder와 masked latent predictor |
| 행동 조건부 동역학 모델 | 현재 표현과 행동에서 다음 표현을 어떻게 예측하는가? | 동결 encoder 위에 post-training한 V-JEPA 2-AC predictor |
| Planner·control loop | 예측을 어떤 목표·탐색·실행·재계획 규칙으로 행동에 바꾸는가? | Image goal, L1 energy, cross-entropy method, receding-horizon MPC |

세 층은 함께 쓸 수 있지만 같은 것은 아니다. 관측 표현이 분류 probe에 유용하다는 사실은 행동의 효과를 예측했다는 뜻이 아니다. 행동 조건부 predictor가 다음 잠재 표현을 예측한다는 사실도 목표 함수, 행동 탐색, 로봇 실행과 feedback loop를 자체적으로 포함한다는 뜻이 아니다.

### 이름과 증거를 분리한다

V-JEPA 2 논문과 Meta 발표는 전체 접근을 세계 모델로 부른다. 이 저자 명명은 확인 가능한 사실이다. 그러나 명칭 자체가 model이 명시적인 물리 법칙, 인과 변수, 반사실 구조 또는 임의 환경의 완전한 simulator를 학습했다는 독립 증거는 아니다.

근거는 과제별로 읽어야 한다. V-JEPA 2의 관측 표현은 frozen encoder 위에 학습한 attentive probe와 언어 model alignment로 평가됐다. 행동의 효과를 이용한 robot planning은 별도 interaction data로 post-training한 V-JEPA 2-AC와 model-predictive control(MPC)의 결합에서 평가됐다. 이 두 경로를 합쳐 base encoder 하나가 곧 일반 물리·인과 이해와 자율 제어를 수행한다고 쓰지 않는다.

### 왜 중요한가

‘학습된 세계 모델’은 model family, 학습 목표, 전체 agent system을 한 단어로 압축하기 쉽다. 층을 분리하면 다음 질문에 답할 수 있다.

1. Video만 본 action-free pretraining이 실제로 최적화한 target은 무엇인가?
2. Action effect를 예측하는 component는 언제 어떤 interaction data로 추가됐는가?
3. 예측된 상태를 목표 행동으로 바꾼 주체는 learned predictor인가, 별도 planner·controller인가?
4. ‘Zero-shot’은 model 전체가 아무 robot data도 보지 않았다는 뜻인가, target lab·task에 맞춘 추가 수집과 training이 없었다는 뜻인가?

## 2단계 — 작동 원리

### 관측 층: 보이는 patch에서 가려진 잠재 표현을 예측한다

관측 영상 $o$를 patch token으로 나누고 일부 위치 $M$을 가린다고 하자. V-JEPA 2의 context encoder $E_\theta$는 남은 token을 표현하고, predictor $P_\phi$는 mask token과 위치 정보를 받아 가려진 부분의 target 표현을 예측한다.

$$
\hat z_M=P_\phi(E_\theta(o_{\setminus M}),m_M),
\qquad
\mathcal L_{\text{mask}}=\lVert \hat z_M-\operatorname{sg}(E_{\bar\theta}(o)_M)\rVert_1.
$$

$E_{\bar\theta}$는 context encoder weight의 지수 이동 평균으로 갱신되는 target encoder이고, $\operatorname{sg}$는 stop-gradient다. Loss는 가려진 patch의 표현에만 적용된다. 이 구조는 pixel 하나하나를 복원하는 대신 학습된 representation space의 예측 가능한 특징을 맞춘다.

여기에는 robot action이 입력되지 않는다. 또한 기본 pretraining target은 같은 clip에서 가려진 시공간 부분의 latent target이다. 따라서 base V-JEPA 2의 masked latent prediction을 곧바로 ‘임의 행동 뒤의 미래를 simulation하는 action-conditioned dynamics’라고 부르면 학습 문제를 바꾸게 된다.

### 동역학 층: 관측 표현에 행동과 상태를 조건으로 붙인다

V-JEPA 2-AC는 사전 학습한 video encoder를 동결하고 별도의 300M-parameter predictor를 robot trajectory로 post-training한다. Predictor는 과거 frame 표현, Cartesian control action, end-effector state를 시간 순서대로 받아 다음 frame의 latent representation을 autoregressive하게 예측한다.

$$
\hat z_{t+1:t+H}
=F_\psi(z_{\le t},a_{t:t+H-1},q_{\le t}).
$$

$z$는 동결 encoder의 영상 표현, $a$는 robot action, $q$는 end-effector state다. Training에는 teacher-forcing loss와 짧은 rollout loss가 함께 쓰인다. 이 단계가 있어야 후보 action sequence가 표현 공간의 미래 상태를 어떻게 바꿀지 비교할 수 있다.

Action-free pretraining과 action-conditioned post-training은 data와 목적이 다르다. 첫 단계는 대규모 image·video 관측을 쓰고, 둘째 단계는 DROID의 robot interaction video 약 62시간 미만을 쓴다. ‘관찰만으로 robot action effect까지 배웠다’고 축약하면 이 post-training 경계를 잃는다.

### 계획·제어 층: 예측을 목표 상태에 대한 행동 탐색으로 바꾼다

V-JEPA 2-AC를 robot에 쓰는 system은 goal image $o_g$를 encoder로 표현한 $z_g$와 후보 행동을 rollout한 미래 표현을 비교한다.

$$
a_{t:t+H-1}^{*}
=\arg\min_{a_{t:t+H-1}}
\left\lVert
F_\psi(z_{\le t},a_{t:t+H-1},q_{\le t})-z_g
\right\rVert_1.
$$

논문 구현은 cross-entropy method(CEM)로 후보 action sequence를 탐색한다. 선택한 sequence를 모두 고정 실행하지 않고 첫 action만 실행한 뒤 새 camera observation을 받아 다시 계획한다. 이 receding-horizon MPC loop는 predictor 바깥의 목표 표현, energy function, 탐색기, robot controller와 feedback을 포함한다.

따라서 robot 성공은 V-JEPA 2-AC predictor 단독의 metric이 아니라 다음 합성 system의 결과다.

$$
\text{robot planning system}
=
\text{frozen video encoder}
+\text{action-conditioned predictor}
+\text{goal energy}
+\text{CEM planner}
+\text{low-level controller}
+\text{camera feedback}.
$$

이 구분은 [[LLM 에이전트]]에서 model proposal과 orchestrator·executor를 나누는 것과 닮았다. 어느 경우든 전체 loop의 성능을 한 component의 내재 능력으로 환원하지 않는다.

## 3단계 — 기술과 근거

### V-JEPA 2와 V-JEPA 2-AC의 학습 경계

| 항목 | V-JEPA 2 | V-JEPA 2-AC |
| --- | --- | --- |
| 주된 역할 | Video representation pretraining | Action-conditioned latent dynamics |
| 입력 | Masked image·video patch | Frame representation, action, end-effector state |
| Target | EMA encoder가 만든 masked-patch latent | 다음 timestep의 frame latent |
| Data | 22M image·video sample, 1M시간 이상 video와 1M image | DROID robot trajectory 23K개, 약 62시간 미만 |
| Encoder | 300M·600M·1B ViT family를 학습 | V-JEPA 2 ViT-g encoder 동결 |
| Predictor | Mask-denoising predictor | 300M, 24-layer block-causal Transformer |
| 직접적인 action 조건 | 없음 | 있음 |
| 대표 사용 | Frozen-encoder probe, action anticipation probe, LLM-aligned VidQA | Goal-image 기반 robot MPC |

Meta 발표가 V-JEPA 2를 1.2B-parameter model로 소개하는 반면 논문과 공식 repository는 encoder를 최대 1B, V-JEPA 2-AC predictor를 300M으로 각각 기술한다. Parameter 수는 encoder·predictor·전체 system 가운데 무엇을 세었는지 경계를 붙여 인용해야 하며, 서로 다른 counting boundary를 임의로 같은 수치로 환산하지 않는다.

### ‘이해’ 평가는 downstream head를 포함한다

V-JEPA 2의 motion·appearance 분류는 encoder를 동결한 뒤 task-specific 4-layer attentive probe를 학습하는 protocol이다. ViT-g384는 Something-Something v2에서 top-1 77.3, Diving48에서 90.2를 기록했다. 이 결과는 representation이 probe가 분류에 사용할 정보를 보존한다는 근거다. Label 없이 encoder output만으로 class를 바로 산출했다는 뜻은 아니다.

Human action anticipation도 동결 encoder·predictor 위에 attentive probe를 학습해 EPIC-KITCHENS-100의 1초 anticipation을 평가했고, action mean-class recall@5 39.7을 보고했다. 이 수치는 정해진 kitchen action vocabulary와 metric에서의 예측 성능이다. 임의의 물리적 future, 장기 action sequence 또는 명시적 causal mechanism을 직접 측정하지 않는다.

Video question answering은 V-JEPA 2 encoder를 LLM에 alignment한 별도 multimodal system이다. 최종 8B setup은 Llama 3.1 backbone과 88.5M image·video-text alignment sample을 사용했다. PerceptionTest 84.0과 TempCompass 76.9 같은 결과를 ‘언어 supervision 없이 vision model 단독이 질문에 답했다’고 옮겨서는 안 된다. [[멀티모달 대규모 언어 모델]]의 encoder–projector–LLM 경계를 함께 기록해야 한다.

### Robot 계획 근거는 좁지만 실제 closed loop다

V-JEPA 2-AC는 DROID의 interaction data로 post-training한 뒤, 해당 data에 나타나지 않은 두 lab의 Franka arm에 같은 weight와 inference code를 배포했다. 논문이 말하는 zero-shot은 target lab robot에서 새 data를 수집하지 않았고 task-specific training·reward를 쓰지 않았다는 범위다. Robot interaction data 자체를 전혀 쓰지 않았다는 뜻은 아니다.

Reach·grasp·reach-with-object·pick-and-place는 monocular RGB camera와 image goal로 평가됐다. 각 lab에서 task별 10회 시행한 Table 2 평균에서 V-JEPA 2-AC는 reach 100%, grasp는 cup 65%·box 25%, pick-and-place는 cup 80%·box 65%를 기록했다. Table 3의 Lab 2 planning은 한 action을 고르는 데 RTX 4090에서 약 16초가 걸렸다. 이는 제한된 tabletop 조작에서 latent planning이 closed loop로 작동한 근거이지만 실시간 범용 robot control이나 안전-critical deployment의 근거는 아니다.

### 공개 구현은 재현 범위를 보여 준다

공식 repository는 2025-06-25 V-JEPA 2 release 기록과 300M·600M·1B encoder checkpoint, attentive probe, V-JEPA 2-AC checkpoint·training configuration을 제공한다. 이 공개성은 논문의 model family와 평가 경로를 재확인하는 데 유용하다.

같은 repository에는 2026년 공개된 V-JEPA 2.1도 함께 들어 있다. 2.1의 dense predictive loss·deep self-supervision·multimodal tokenizer와 checkpoint를 2025년 V-JEPA 2 결과에 소급해 섞지 않는다.

## 검증과 한계

### 확인된 사실

- V-JEPA 2 paper와 Meta 공식 발표 날짜는 2025-06-11이고, 공식 repository의 V-JEPA 2 release 기록은 2025-06-25다.
- Base V-JEPA 2는 action-free masked latent feature prediction으로 pretraining한다.
- V-JEPA 2-AC는 동결한 V-JEPA 2 encoder 위에 action-conditioned predictor를 별도 robot interaction data로 post-training한다.
- Robot planning은 goal image, latent L1 energy, CEM과 receding-horizon MPC를 결합한다.
- Probe classification, action anticipation, LLM-aligned VidQA와 robot planning은 서로 다른 downstream component와 평가 조건을 쓴다.

### 저자 명명과 편집상 해석

논문과 Meta는 V-JEPA 2 접근을 세계 모델이라고 명명하고 ‘이해·예측·계획’을 핵심 능력으로 제시한다. 이 문서의 세 층 분해는 그 pipeline을 검증 가능하게 읽기 위한 편집상 합성이다. 모든 세계 모델 연구가 반드시 같은 architecture나 세 층을 가져야 한다는 보편 분류를 주장하지 않는다.

`verification: partial`은 V-JEPA 2의 구조·수치가 불확실하다는 뜻이 아니다. 세 층 taxonomy와 ‘세계 모델’이라는 넓은 용어의 사용 경계를 한 연구 family의 1차 자료에서 합성했기 때문이다.

### 일반 물리·인과 이해로 확장할 수 없는 것

Masked latent prediction은 video의 예측 가능한 regularity를 학습할 수 있지만, 그 objective만으로 explicit law, object permanence, causal graph 또는 counterfactual intervention을 식별했다고 보장하지 않는다. Probe와 VQA benchmark도 정해진 dataset·head·alignment data 아래의 성능이다.

Meta 발표가 함께 소개한 CausalVQA는 counterfactual·anticipation·planning 질문에서 당시 large multimodal model과 human 사이의 격차가 남는다고 보고한다. 이 benchmark 발표 자체도 V-JEPA 2가 일반 causal reasoning을 해결했다는 증거가 아니다. ‘Physical reasoning’이라는 이름보다 실제 task, input, scoring과 비교 대상을 본다.

V-JEPA 2-AC의 action-conditioned prediction은 특정 Franka control space와 DROID data에 묶여 있다. 명시적인 camera calibration 없이 action coordinate를 암묵적으로 추정하며, 저자들은 잘 작동하는 camera 위치를 수동으로 탐색했다. Autoregressive rollout error가 누적되고 action search space는 horizon에 따라 커진다. 긴 pick-and-place에는 여러 image subgoal이 필요했고 natural-language goal은 future work였다.

### 흔한 오해

- **Base V-JEPA 2가 action-conditioned future를 직접 예측한다:** Action-conditioned autoregressive future prediction은 V-JEPA 2-AC post-training 단계다.
- **JEPA는 contrastive negative pair로 정답 future를 당긴다:** V-JEPA 2는 EMA target, stop-gradient와 L1 masked-latent regression을 사용한다.
- **Pixel future를 정확히 생성한다:** 핵심 target은 learned representation이며 pixel-level video generation과 다르다.
- **Zero-shot robot planning은 robot data가 없다는 뜻이다:** Target lab·task용 추가 training이 없다는 뜻이며 DROID interaction data post-training은 있다.
- **World model label이 일반 causal understanding을 증명한다:** 명칭, objective와 benchmark evidence는 별개다.
- **Planner도 V-JEPA 2-AC weight 안에 있다:** 논문 system은 외부 CEM·energy objective·MPC loop와 low-level controller를 결합한다.

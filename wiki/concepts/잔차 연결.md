# 잔차 연결

> [!note] 학습 안내
> **난이도:** 중급<br>
> **선수 지식:** [[벡터·행렬·텐서와 shape]]의 feature 축·성분별 덧셈, [[Degradation problem]]의 깊은 모델 최적화 문제<br>
> **읽고 나면:** 항등 shortcut과 투영 shortcut을 숫자로 계산하고, $I+J_F$가 직접 gradient 경로를 주는 이유와 그 보장 범위를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 이 개념이 필요해진 문제

층을 더 쌓으면 이론상 얕은 모델이 하던 일을 그대로 흉내 낼 수 있어야 한다. 새 층이 아무 변화도 만들지 않도록 만들면 되기 때문이다. 그러나 실제로는 매우 깊은 일반 신경망이 더 얕은 모델보다 훈련 오차조차 커지는 degradation problem이 관찰됐다. 이는 단순히 “모델이 너무 복잡해서 과적합했다”는 문제와 다르다.

[[잔차 연결]]은 새 층이 입력 전체를 처음부터 다시 만들게 하지 않고, 기존 입력을 옆길(shortcut)로 바로 전달한 뒤 학습된 변화량만 더하게 한다. 따라서 변환 branch가 아직 유용한 변화를 찾지 못해도, 최소한 입력을 통과시키는 경로를 만들기 쉬워진다.

### 먼저 알아야 할 기초 개념

- **항등 함수(identity)**: 입력을 바꾸지 않는 함수다. $I(x)=x$다.
- **목표 변환 $H(x)$**: 어떤 block이 궁극적으로 내고 싶은 출력이다.
- **잔차 $F(x)$**: 목표 출력에서 입력을 뺀 변화량이다. $F(x)=H(x)-x$로 쓸 수 있다.
- **shortcut**: 학습된 변환 branch를 지나지 않고 입력을 덧셈 지점까지 보내는 경로다.
- **Jacobian $J_F(x)$**: 벡터 함수 $F$의 각 출력 성분이 각 입력 성분에 얼마나 변하는지를 모은 미분 행렬이다.

잔차라는 말은 오류가 남았다는 일상적 의미가 아니라, “입력에 더해야 할 차이”라는 대수적 의미다. $F(x)$가 0이면 block은 실패한 것이 아니라 항등 변환을 정확히 수행한다.

덧셈은 두 항의 대응 feature 축이 같을 때만 성분별로 정의된다. 축·shape와 브로드캐스팅의 일반 규칙은 [[벡터·행렬·텐서와 shape]]에서, $W_sx$가 입력 폭을 출력 폭으로 바꾸는 가중합은 [[내적·행렬곱과 선형변환]]에서 확인한다. 이 문서는 그 두 결과를 shortcut과 gradient 경로로 연결한다.

### 핵심 아이디어

보통 block을 $H(x)$로 바로 쓰는 대신, 잔차 block은 다음처럼 쓴다.

$$
y=F(x)+x.
$$

$x$는 이미 있던 표현을 보존하는 경로이고, $F(x)$는 새 block이 배워야 하는 보정·변환이다. 덧셈이 가능하려면 두 벡터의 shape가 같아야 한다. 이 단순한 조건이 shortcut의 설계와 깊은 네트워크의 gradient 흐름을 함께 바꾼다.

## 2단계 — 작동 원리

### 가장 작은 구체적 예

입력과 변환 branch 출력이 모두 두 차원이라고 하자.

$$
x=(2,-1),\qquad F(x)=(0.3,0.2).
$$

잔차 연결의 출력은 성분별 덧셈이다.

$$
y=F(x)+x
=(0.3,0.2)+(2,-1)
=(2.3,-0.8).
$$

이 예에서 branch는 입력 전체를 다시 만들지 않고 첫 좌표에 $0.3$, 둘째 좌표에 $0.2$만 보정한다. 만약 학습 중 어떤 입력에서 $F(x)=(0,0)$이 되면 $y=x$다. 즉 identity mapping을 만들기 위해 branch가 입력을 복사하는 복잡한 계산을 학습할 필요가 없다. 숫자는 설명용 예이며 실제 ResNet이나 Transformer의 활성값이 아니다.

### 항등 shortcut과 투영 shortcut

입출력 차원이 같으면 항등 shortcut을 쓴다.

$$
y=F(x)+x.
$$

예를 들어 $x\in\mathbb R^{512}$이고 $F(x)\in\mathbb R^{512}$라면 두 벡터를 성분별로 더할 수 있다. 차원이 달라지면 입력을 출력 차원으로 맞추는 투영 shortcut을 쓴다.

$$
y=F(x)+W_sx.
$$

여기서 $x\in\mathbb R^{d_{\mathrm{in}}}$, $F(x)\in\mathbb R^{d_{\mathrm{out}}}$, $W_s\in\mathbb R^{d_{\mathrm{out}}\times d_{\mathrm{in}}}$다. $W_sx$도 길이 $d_{\mathrm{out}}$이므로 덧셈이 가능하다. CNN ResNet의 특정 구조에서는 zero-padding이나 subsampling으로 shape를 맞추기도 하지만, 어느 방법을 쓸지는 block의 채널 수·공간 해상도·계산 비용에 따른 설계 선택이다.

### 입력에서 출력까지

1. 입력 $x$가 shortcut과 변환 branch로 동시에 간다.
2. 변환 branch는 convolution·MLP·attention 같은 연산으로 $F(x)$를 계산한다.
3. shortcut은 $x$ 또는 shape를 맞춘 $W_sx$를 덧셈 지점까지 전달한다.
4. 두 결과를 더해 $y$를 만든다.
5. 다음 block은 $y$를 다시 입력으로 받아 추가 변화를 누적한다.

따라서 깊은 네트워크는 각 block이 “완전히 새 표현”을 독립적으로 만들기보다, 이미 있는 표현에 작은 변화를 계속 더하는 형태로 볼 수 있다. 그러나 실제 변화가 항상 작거나 좋은 방향이라는 뜻은 아니다. 그것은 데이터·손실함수·최적화가 결정한다.

## 3단계 — 기술과 근거

### 정식 용어와 기호

| 기호 | 현재 문서에서의 의미 | shape | 종류·출처 |
| --- | --- | --- | --- |
| $x$ | block 입력 표현 | $d_{\mathrm{in}}$차원 벡터 | 이전 block의 출력 |
| $F(x)$ | 학습된 변환 branch가 만든 변화량 | 보통 $d_{\mathrm{out}}$차원 벡터 | 학습된 층의 출력 |
| $H(x)$ | block이 구현하려는 전체 변환 | $d_{\mathrm{out}}$차원 벡터 | $F(x)$와 shortcut의 합 |
| $W_s$ | shortcut의 shape를 맞추는 투영 행렬 | $d_{\mathrm{out}}\times d_{\mathrm{in}}$ | 학습 매개변수일 수 있음 |
| $I$ | 항등 행렬 | 입력 차원에 맞는 정사각 행렬 | 미분에서 직접 경로를 나타냄 |
| $J_F(x)$ | $F$의 Jacobian | 입력·출력 차원에 맞는 행렬 | 현재 입력에서의 미분 |
| $\mathcal L$ | 학습이 줄이려는 손실 | 스칼라 | 모델 예측과 정답에서 계산 |

### 핵심 수식: 왜 gradient에 직접 경로가 생기는가

#### 수식이 답하려는 질문

잔차 연결이 깊은 네트워크 최적화에 도움을 준다는 말은, 순전파에서 입력을 더한다는 사실만으로 충분히 설명되지 않는다. 이 수식은 손실이 입력 쪽으로 미분될 때 shortcut이 어떤 경로를 추가하는지 보인다.

항등 shortcut에서는 다음이 성립한다.

$$
y=F(x)+x,\qquad
\frac{\partial y}{\partial x}=J_F(x)+I.
$$

손실의 gradient를 열벡터로 쓰면 연쇄 법칙은 다음과 같다.

$$
\nabla_x\mathcal L
=\bigl(J_F(x)+I\bigr)^{\mathsf T}\nabla_y\mathcal L.
$$

#### 한 항씩 만드는 과정

1. $F(x)$를 $x$로 미분하면 $J_F(x)$가 나온다. 변환 branch를 거친 변화 경로다.
2. $x$를 $x$로 미분하면 항등 행렬 $I$가 나온다. shortcut이 만든 직접 경로다.
3. 덧셈을 미분하면 각 항의 미분도 더해져 $J_F(x)+I$가 된다.
4. 손실 $\mathcal L$은 출력 $y$에 의존하므로, $\nabla_y\mathcal L$에 이 Jacobian의 전치를 곱해 입력 쪽 gradient를 얻는다.

$I$가 있다는 사실은 변환 branch의 Jacobian만 연속해서 곱하는 구조와 다른 경로를 제공한다. 특히 $F$가 항등에 가까운 변환을 배워야 하는 상황에서 shortcut은 그 목적을 직접 표현한다.

#### 무엇이 보장되고 무엇이 보장되지 않는가

$I$ 항이 있다고 해서 전체 gradient가 항상 정확히 1이 되거나 사라지지 않는다는 뜻은 아니다. $J_F(x)$의 값, activation·normalization의 위치, 여러 block의 곱, branch 사이의 상쇄가 gradient 크기와 방향을 바꾼다. identity shortcut은 유용한 경로를 제공하는 구조적 조건이지, 모든 깊이·초기화·학습률에서 안정 학습을 보장하는 정리는 아니다.

He 등의 identity-mapping 분석은 shortcut에 활성화나 곱셈 gate를 추가하면 직접 경로가 달라질 수 있음을 보였다. 따라서 잔차 구조는 단순히 “더하기 하나”가 아니라, 어느 경로가 항등으로 남는지까지 포함한 설계다.

### Transformer의 residual stream

Transformer는 attention과 위치별 feed-forward sublayer의 출력에 기존 표현을 더한다. 원 2017년 구조는 다음 Post-LN 형태였다.

$$
y=\operatorname{LayerNorm}\bigl(x+\operatorname{Sublayer}(x)\bigr).
$$

여기서 $x$와 $\operatorname{Sublayer}(x)$는 모두 $d_{\mathrm{model}}$차원이라 더할 수 있다. $\operatorname{Sublayer}$는 attention 또는 위치별 MLP이고, LayerNorm은 합친 표현의 feature별 통계를 사용해 정규화하는 별도 연산이다. 원 구조의 순서는 “더하기 뒤 정규화”인 Post-LN이다.

현대 대규모 모델에는 대체로 다음처럼 정규화를 branch 입력 쪽으로 옮긴 Pre-LN 변형도 쓰인다.

$$
y=x+\operatorname{Sublayer}\bigl(\operatorname{LayerNorm}(x)\bigr).
$$

두 식 모두 residual addition을 쓰지만, identity 경로가 정규화를 거치는지와 초기 gradient 조건이 다르다. CNN ResNet과 Transformer는 모두 기존 표현에 학습된 갱신을 더하지만, branch 내부 연산과 정규화 설계까지 같은 모델인 것은 아니다.

## 검증과 한계

### 확인된 사실

ResNet은 identity shortcut과 projection shortcut을 이용해 매우 깊은 CNN의 degradation 문제를 실험적으로 다뤘다. Transformer는 attention과 feed-forward sublayer 주위에 residual connection과 LayerNorm을 배치했다. 두 경우 모두 덧셈은 입력과 branch 출력의 shape가 맞아야 한다.

### 흔한 오해와 적용 범위

- 잔차 연결은 $F(x)$를 “오차”나 “실패”로 표시하지 않는다. 입력에 더할 변화량을 모델링하는 방식이다.
- $I$ 항은 직접 미분 경로를 제공하지만 gradient를 항상 보존한다는 보장은 아니다.
- projection shortcut은 차원이 다를 때 덧셈을 가능하게 하지만, 항등 shortcut처럼 추가 매개변수·계산이 없지는 않다.
- Transformer의 residual stream과 CNN ResNet은 같은 덧셈 원리를 공유하지만, attention·정규화·토큰 위치라는 다른 계산 맥락에서 쓰인다.
- Post-LN과 Pre-LN은 둘 다 잔차 연결을 쓰므로 같은 최적화 특성을 갖는다고 단정할 수 없다.

## 학습 확인

### 확인 질문과 답

1. $x=(2,-1)$, $F(x)=(0.3,0.2)$일 때 항등 shortcut block의 출력은 무엇인가?

   **답:** $y=F(x)+x=(2.3,-0.8)$다. branch는 입력 전체를 다시 만들지 않고 두 좌표에 변화량만 더한다.

2. projection shortcut이 필요한 경우와 행렬 $W_s$의 역할은 무엇인가?

   **답:** 입력과 branch 출력의 차원이 달라 바로 더할 수 없을 때 필요하다. $W_s$는 입력을 출력 차원으로 선형 변환해 두 항의 shape를 맞춘다.

3. $I+J_F(x)$의 $I$는 무엇을 보장하지 않는가?

   **답:** 변환 branch와 별도의 직접 gradient 경로를 제공하지만, 모든 층을 지난 gradient의 크기가 항상 1이거나 안정적이라는 보장은 하지 않는다.

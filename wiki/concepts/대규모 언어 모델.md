# 대규모 언어 모델

> [!note] 학습 안내
> **난이도:** 기초 → 중급<br>
> **선수 지식:** 없음 — token, 확률분포, 가중치, 학습과 생성의 차이를 이 문서 안에서 먼저 구분한다.<br>
> **읽고 나면:** LLM이 문맥에서 다음 token의 확률을 만들고, 음의 로그가능도로 가중치를 갱신하며, 생성 때는 왜 같은 가중치를 고정한 채 한 token씩 선택하는지 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 이 개념이 필요해진 문제

번역, 요약, 질의응답, 문장 완성처럼 겉으로는 서로 다른 언어 과제들도 모두 “지금까지 주어진 글을 보고 다음에 어떤 언어 조각이 자연스러운가?”라는 공통 질문을 품고 있다. 사람마다 정답 label을 붙여 각 과제용 모델을 따로 만들면 비용이 크고, 새 과제가 생길 때마다 다시 학습해야 한다.

대규모 언어 모델(Large Language Model, LLM)은 방대한 텍스트에서 이 공통 예측 문제를 먼저 학습한 신경망 언어 모델이다. 이후 지시문·예시·질문을 입력 문맥으로 주면, 같은 모델을 여러 언어 과제에 적용할 수 있다. 그렇다고 문맥에 그럴듯하게 이어질 확률을 계산하는 일이 사실 확인, 안전 판단, 사람의 의도 이해를 자동으로 해결하는 것은 아니다.

### 가장 짧은 정의

LLM은 문맥 $h$를 받아 후보 token마다 조건부확률 $p_\theta(w\mid h)$를 내는 함수라고 먼저 생각하면 된다. $w$는 다음 위치의 후보 token, $\theta$는 학습으로 바뀌는 수많은 가중치다. 고정된 문맥에서 모든 후보 $w$의 확률을 더하면 1이어야 한다.

여기서 **대규모**는 매개변수 수 하나에 정해진 경계값이 있다는 뜻이 아니다. 모델의 가중치 수, 학습 token 수, 학습·추론 계산량이 함께 큰 연구·공학적 범주를 가리킨다. 같은 100억 parameter라도 token화, 자료, 학습 시간, architecture와 평가 조건이 다르면 같은 능력이나 비용을 뜻하지 않는다.

### 먼저 알아야 할 기초 개념

- **token**: 모델이 한 번에 읽고 예측하는 텍스트 조각이다. 단어 하나일 수도, 단어의 일부나 문장 부호일 수도 있다. 글자 수나 단어 수와 token 수는 항상 같지 않다.
- **문맥 $h$**: 다음 token을 고를 때 이미 입력으로 주어진 token 열이다. 자기회귀 모델에서는 보통 앞선 token들만 문맥에 넣는다.
- **확률분포**: 가능한 후보마다 0 이상 1 이하의 값을 주고, 후보 전체의 합이 1이 되는 규칙이다. 가장 큰 확률의 후보가 유일한 답이라는 뜻은 아니다.
- **매개변수 $\theta$**: 모델이 자료에서 조정하는 수치 묶음이다. 추론 중에는 보통 고정하고, 학습 중에는 손실을 줄이는 방향으로 갱신한다.
- **학습과 생성**: 학습은 정답 token을 알고 가중치를 바꾸는 과정이고, 생성은 가중치를 바꾸지 않은 채 모델이 낸 분포에서 다음 token을 선택하는 과정이다.

### 이 문서의 범위

이 문서는 LLM을 하나의 고정 구조나 하나의 제품으로 정의하지 않는다. 확률적 언어 모델링, 학습 가능한 표현, 신경망 최적화, 대화 평가와 의미 논쟁이 현대 시스템에서 어떻게 만나는지를 본다. 자기회귀 생성은 중요한 한 갈래지만, BERT처럼 가려진 token을 복원하는 계열과 encoder–decoder 계열까지 모두 같은 생성 흐름으로 부르지는 않는다. 공통 문제를 곧바로 직접 역사 계보로 바꾸지도 않는다.

## 2단계 — 작동 원리

### 가장 작은 예: 문맥에서 후보 분포 만들기

설명용 문맥이 “오늘 비가”이고, 다음 위치의 후보를 세 개만 남겼다고 하자. 실제 LLM의 어휘는 훨씬 크지만, 확률분포의 뜻을 보이기에는 세 후보면 충분하다.

| 다음 후보 $w$ | 모델이 준 $p_\theta(w\mid h)$ | 읽는 법 |
| --- | ---: | --- |
| 온다 | 0.70 | 이 문맥 뒤에 “온다”가 올 확률을 70%로 둔다. |
| 그친다 | 0.20 | 두 번째 후보에도 20%를 남긴다. |
| 그 밖의 후보 | 0.10 | 나머지 모든 가능성을 합쳐 10%로 둔 단순화다. |

$0.70+0.20+0.10=1$이므로 표는 확률분포다. 실제 모델은 먼저 후보마다 확률이 아닌 정규화 전 점수(logit)를 만들고, [[소프트맥스]]로 양수이면서 합이 1인 분포로 바꾼다. 이 표의 수치는 작동 원리를 보이는 편집부 예이며, 특정 LLM의 출력 기록이 아니다.

### 학습: 실제 다음 token의 확률을 높이는 반복

사전학습 자료에 “오늘 비가 온다”라는 token 열이 있으면, 모델은 앞부분을 보고 실제 다음 token을 맞히는 여러 예를 얻는다. 예를 들어 “오늘” 뒤의 정답은 “비가”, “오늘 비가” 뒤의 정답은 “온다”다. 학습은 정답 token에 모델이 낮은 확률을 준 경우를 하나의 벌점으로 모으고, 그 벌점이 작아지도록 $\theta$를 바꾼다.

정답 token 하나에 준 확률을 0.8, 0.8, 0.5라고 가정한 세 위치의 설명용 예를 보자. 음의 자연로그 벌점은 각각 $-\ln0.8\approx0.2231$, $-\ln0.8\approx0.2231$, $-\ln0.5\approx0.6931$이다. 평균은 $(0.2231+0.2231+0.6931)/3\approx0.3798$이다. 0.5를 준 마지막 위치가 가장 큰 벌점을 내므로, 학습은 그런 정답 확률을 높이는 방향의 신호를 받는다.

실제 LLM의 가중치는 하나의 수가 아니라 거대한 벡터·행렬 묶음이다. [[역전파]]는 이 평균 벌점이 각 가중치에 대해 얼마나 변하는지를 계산하고, optimizer는 그 변화율과 학습률을 이용해 가중치를 실제로 갱신하는 절차다. 아래 3단계에서 왜 로그를 쓰고 평균을 내며 어떤 식으로 갱신을 표현하는지 정식 기호로 다시 설명한다.

### 생성: 가중치는 고정하고 문맥만 늘린다

생성에서는 새 정답을 미리 알 수 없다. 모델은 현재 문맥에서 분포를 계산하고, 가장 높은 확률을 고르거나 분포에서 표본을 뽑아 token 하나를 선택한다. 선택한 token을 문맥 뒤에 붙인 뒤 같은 과정을 반복한다.

따라서 학습 중에는 정답 이력을 보며 많은 위치의 벌점을 계산할 수 있지만, 일반적인 자기회귀 생성은 방금 고른 token이 다음 입력이 되므로 순차적이다. 같은 가중치 $\theta$를 쓰더라도 prompt, 이미 생성한 token, greedy 선택인지 sampling인지에 따라 출력이 달라진다. 이 생성 흐름의 상세한 조건은 [[자기회귀 생성]]에서, sampling 전에 온도·top-$k$·top-$p$로 현재 어휘 분포를 어떻게 바꾸는지는 [[표본추출·온도·top-k·top-p]]에서 이어서 다룬다.

## 3단계 — 기술과 근거

### 핵심 수식: 언어열 확률, 손실, 가중치 갱신

#### 수식이 답하려는 질문

자기회귀 LLM의 정식 질문은 “이미 앞선 token들을 보았을 때 실제 다음 token에 얼마의 확률을 주는가?”다. 학습에서는 실제 자료의 모든 위치에서 그 확률을 높이고 싶다. 그러나 긴 문장의 확률을 그대로 곱하면 수가 아주 작아지므로, 실제 구현은 로그를 취한 평균 벌점인 음의 로그가능도(negative log-likelihood, NLL)를 최소화한다.

#### 기호와 값의 종류

| 기호 | 현재 문서에서의 의미 | 종류·범위 | 어디서 오는가 |
| --- | --- | --- | --- |
| $x_{1:T}$ | 길이 $T$인 실제 학습 token 열 | token 열 | 말뭉치를 token화해 얻음 |
| $x_t$ | $t$번째 실제 정답 token | token | 관측 자료 |
| $x_{<t}$ | $t$보다 앞선 token들 | token 열 | 현재 문맥 |
| $t$ | 현재 위치를 세는 인덱스 | $1,\ldots,T$의 정수 | 합을 반복할 축 |
| $\theta$ | 모델의 모든 학습 가중치 | 고차원 실수 벡터·행렬 묶음 | 학습으로 갱신 |
| $q_t$ | 위치 $t$의 실제 정답 token 확률 | $0<q_t\le1$인 스칼라 | $p_\theta$가 계산 |
| $J(\theta)$ | token 하나당 평균 음의 로그확률 | 0 이상인 스칼라 | 학습이 줄일 손실 |
| $\eta$ | 한 번에 갱신하는 크기 | 양수 스칼라 | 사람이 정하는 학습률 |
| $\nabla_\theta J$ | 각 가중치별 손실 변화율 | $\theta$와 같은 shape | 역전파로 계산 |

현재 위치의 정답 확률은 짧게 $q_t$로 쓴다.

\[
q_t
=
p_\theta(x_t\mid x_{<t})
\]

$p_\theta$는 “가중치 $\theta$를 가진 모델이 계산한 확률분포”이고, 세로막대 뒤의 $x_{<t}$는 이미 알고 있는 문맥이다. 첫 token에서는 구현이 문장 시작 표지 같은 초기 문맥을 쓴다. 이 문서에서는 표기를 단순하게 유지하기 위해 그 표지를 $x_{<1}$ 안에 포함했다고 본다.

#### 왜 조건부확률을 곱하는가

문장 전체가 나올 확률은 각 위치의 조건부확률을 이어 붙여 얻는다.

\[
p_\theta(x_{1:T})
=
\prod_{t=1}^{T} q_t
\]

$\prod$는 $t=1$부터 $T$까지의 항을 모두 곱하라는 기호다. 이것은 token들이 서로 독립이라는 가정이 아니다. 결합확률을 앞선 token에 조건화한 확률들로 나누는 확률의 연쇄 법칙을 쓴 것이다. 앞 문맥이 바뀌면 다음 위치의 $q_t$도 바뀌므로, “오늘 비가” 뒤의 분포와 “오늘 날씨가” 뒤의 분포는 다를 수 있다.

#### 왜 음의 로그 평균을 최소화하는가

학습용 손실은 보통 다음처럼 쓴다.

\[
J(\theta)
=
-\frac{1}{T}
\sum_{t=1}^{T}\ln q_t
\]

각 연산에는 서로 다른 역할이 있다.

1. $\ln q_t$는 여러 확률의 곱을 합으로 바꾼다. $\ln(\prod_t q_t)=\sum_t\ln q_t$이므로 매우 작은 문장 확률을 직접 곱하지 않아도 된다.
2. $0<q_t\le1$이면 $\ln q_t\le0$이다. 앞의 마이너스 부호는 정답 확률이 작을수록 큰 양의 벌점을 만들고, 높은 확률에는 작은 벌점을 준다.
3. $1/T$는 문장 전체의 누적 벌점을 token 하나당 평균으로 바꾼다. 그래서 같은 token화·평가 규칙 안에서는 길이가 다른 열도 같은 단위로 비교할 수 있다.
4. $J$가 작아지는 것은 $\sum_t\ln q_t$, 곧 실제 token 열의 로그가능도가 커지는 것과 같다. 최대화 표기와 최소화 표기는 선호하는 $\theta$는 같고 부호만 다르다. 완전한 가능도·NLL 유도는 [[로그가능도]]에서 다룬다.

어느 위치에서든 $q_t=0$이면 $\ln q_t$가 유한한 수가 아니어서 이 식은 쓸 수 없다. 이론상 softmax는 모든 어휘 후보에 양의 확률을 주지만, 실제 구현에서는 수치 underflow와 어휘 밖 입력·전처리 규칙을 별도로 점검해야 한다. [[소프트맥스]]는 raw logit을 이 확률분포로 바꾸는 정확한 식을, [[수치 안정성과 log-sum-exp]]는 max shift·log-softmax·mask row의 finite-precision 경계를 설명한다.

#### 가중치는 왜 반대 방향으로 움직이는가

가장 단순한 경사하강법 표기는 다음과 같다.

\[
\theta'
=
\theta-\eta\nabla_\theta J(\theta)
\]

$\nabla_\theta J(\theta)$는 각 가중치를 아주 조금 올렸을 때 손실이 늘어나는지 줄어드는지를 모은 방향 벡터다. 손실을 줄이려면 증가 방향의 반대쪽으로 움직여야 하므로 마이너스를 쓴다. $\eta$가 너무 크면 좋은 지점을 지나칠 수 있고, 너무 작으면 학습이 매우 느려진다.

실제 LLM의 $\theta$는 수십억 개 이상의 수라 손으로 미분할 수 없다. $\nabla_\theta J$는 $\theta$와 같은 shape의 편미분 묶음이며, 이 표기와 국소 1차 해석은 [[미분·편미분·그래디언트]]에서 확인할 수 있다. [[역전파]]는 이 변화율을 효율적으로 계산하고, [[Adam 최적화기]] 같은 optimizer가 단순한 한 번의 경사하강법보다 더 복잡한 갱신 규칙을 적용한다. Adam의 $v_t$는 gradient variance가 아니라 squared gradient의 raw second moment 이동평균이다. 그래도 기본 목적은 “정답 token에 낮은 확률을 준 위치의 평균 벌점을 줄인다”는 위 식으로 읽을 수 있다.

한 개의 수만 가진 설명용 모형에서 $J(a)=a^2$, $a=3$, $\eta=0.1$이라고 하자. 변화율은 $dJ/da=2a=6$이므로 $a'=3-0.1\times6=2.4$가 된다. 손실은 $9$에서 $2.4^2=5.76$으로 줄어든다. 실제 LLM이 $a^2$를 학습한다는 뜻은 아니며, 마이너스 방향 갱신의 뜻만 보이는 계산이다.

#### 필연적인 부분과 설계 선택

- **확률의 귀결:** 결합확률을 조건부확률의 연쇄로 쓰면 각 위치의 확률을 곱해야 한다.
- **수학적 귀결:** 양의 확률에서는 로그가 엄격히 증가하므로, 전체 확률을 최대화하는 $\theta$와 로그확률을 최대화하는 $\theta$의 순서는 같다.
- **학습 목적의 선택:** 실제 token에 높은 확률을 주도록 NLL을 줄이는 것은 생성 언어 모델의 표준 목적이다. 사실성·유용성·안전성을 직접 최적화하는 유일한 목적은 아니다.
- **공학적 선택:** token 평균, batch 구성, optimizer, 학습률, token화와 문맥 길이는 안정성·비용·비교 단위를 위해 정하는 선택이다.

### N-gram과의 관계

N-gram 모델은 짧은 표면 문맥과 빈도표로 다음 항목을 예측한다. [[035_신경 확률 언어 모형과 분산 단어 표현]]은 2003년에 같은 조건부 예측을 고정 길이 [[단어 임베딩]]과 공유 MLP로 계산하고, 표현·확률 함수를 공동 학습한 중간 전환을 보여준다. 대규모 언어 모델은 더 긴 문맥, 문맥별 표현과 attention 같은 신경망 메커니즘을 사용한다. 자기회귀 LLM은 조건부 분포 예측과 lookup–문맥 함수–softmax라는 설계 연속성을 공유하지만, 2003년 고정 창이나 [[N-gram 모델]]의 단순한 규모 확장과 동일시해서는 안 된다.

### 모델·데이터·계산량의 공동 병목

[[066_신경 언어 모델의 스케일링 법칙]]에서 검증한 Kaplan 등의 경험식은 모델 크기 $N$, 데이터 token 수 $D$, 학습 compute $C$ 가운데 한 축과 손실의 관계를 읽을 때 나머지 두 축이 병목이 아니어야 한다고 전제한다. 따라서 모델만 키우고 데이터나 계산량을 고정하면 같은 단변량 power law를 계속 적용할 수 없다. 세 축을 함께 늘리거나, 고정 compute 안에서 모델 크기·batch·학습 step·처리 데이터를 배분해야 한다는 점이 [[언어 모델 스케일링 법칙]]의 핵심 조건이다.

### Total parameters와 active compute

[[069_전문가 혼합과 희소 활성 스케일링]]은 LLM의 ‘크기’를 total parameter 하나로 표현할 때 생기는 모호성을 드러낸다. Dense Transformer block은 token마다 거의 같은 dense weight 집합을 계산하지만, [[전문가 혼합]]은 일부 FFN을 여러 expert로 바꾸고 token마다 top-$k$만 실행할 수 있다. Total parameters는 크게 늘어도 한 token의 expert FLOPs는 더 천천히 늘 수 있다.

그러나 선택되지 않은 expert도 저장·학습해야 하며 expert parallelism에는 장치 간 token 통신이 필요하다. 따라서 total parameters, active parameters 또는 활성 expert 수, FLOPs, aggregate memory, communication, throughput·latency와 task quality를 따로 기록한다. Dense 175B와 sparse 1.6T를 parameter 수만으로 같은 척도에 놓지 않는다.

### GPT-3와 입력 문맥의 과제 적응

[[067_GPT-3와 문맥 내 학습]]은 125M부터 175B까지 여덟 자기회귀 모델을 모두 300B token으로 학습하고, task-specific gradient update 없이 zero-shot·one-shot·few-shot을 비교했다. [[문맥 내 학습]]에서는 instruction과 demonstration이 query 앞에 놓이며, 모델은 고정된 가중치로 그 입력에 조건화된 다음-token 분포를 계산한다.

규모가 커지며 여러 과제의 few-shot 성능이 향상됐지만 결과는 task마다 달랐다. SuperGLUE few-shot 71.8은 당시 fine-tuned 최고 89.0보다 낮았고, closed-book TriviaQA few-shot 71.2는 비교 가능한 기존 결과를 넘어섰다. 따라서 모델 규모, 평균 token loss, 특정 prompt의 downstream score를 하나의 ‘능력’ 척도로 합치지 않는다.

### PaLM: model 규모와 훈련 system을 함께 읽는다

[[083_PaLM과 Pathways 기반 대규모 언어 모델 확장]]은 540.35B dense decoder-only [[PaLM]]을 780B token으로 학습하고, 두 TPU v4 Pod의 6,144개 chip을 Pathways로 묶은 사례다. Pod 안의 model·fully sharded data parallelism과 Pod 사이 data parallelism은 이 규모의 training run을 가능하게 했지만, Pathways 자체가 새로운 추론 objective나 sparse attention은 아니다.

PaLM의 결과도 model 이름과 parameter 수만으로 읽지 않는다. 29개 English task의 28/29 우위는 Table 4의 당시 prior best few-shot result와의 비교이고, Table 5의 63.9/74.7은 별도 1-shot NLG/NLU aggregate다. GSM8K 58%도 8-shot CoT와 calculator를 결합한 조건이다. 100개가 넘는 언어가 corpus에 포함됐다는 사실, 특정 다국어 benchmark의 점수, 언어별 일반 품질도 서로 다른 주장이다. LLM의 규모는 architecture·학습 token·compute·prompt·adaptation·metric과 함께 기록해야 한다.

### 튜링 테스트와의 관계

두 번째 소스는 현대 LLM이 제한된 상황에서 인간과 구별하기 어려운 대화를 생성할 수 있기 때문에 [[튜링 테스트]] 논쟁을 다시 현실적인 문제로 만들었다고 설명한다. 그러나 인간처럼 말하는 능력은 이해, 의식, 장기적 일관성, 실제 세계에 대한 신뢰 가능한 추론을 곧바로 증명하지 않는다. 이 점에서 LLM 평가는 [[튜링 테스트와 LLM 평가]]처럼 인간 유사성과 과업별 신뢰성을 함께 보아야 한다.

### 중국어 방과 의미 논쟁

[[016_중국어 방 논증과 강한 AI 논쟁]]의 1980년 목표 논문은 현대 신경 LLM을 기술적 대상으로 분석하지 않았다. [[존 설]]이 겨냥한 것은 프로그램 구현 자체가 이해와 지향성에 충분하다는 [[강한 AI]]의 주장이다. 중국어 방을 LLM에 적용하는 것은 후대의 철학적 확장이며, 고전 규칙표와 학습된 분산 표현이 경험적으로 같은 시스템이라는 판정이 아니다.

많은 자기회귀 생성 LLM은 다음 토큰의 조건부 분포를 학습하지만, BERT 계열은 가려진 토큰 복원처럼 다른 목표를 사용한다. 따라서 모든 언어 모델을 다음 토큰 예측 하나로 정의하지 않는다. Bender와 Koller의 2020년 입장 논문은 의미를 언어 표현과 세계에 접지된 의사소통 의도 사이의 관계로 정의하고, 언어 형식만으로 학습한 시스템은 그 관계를 학습할 수 없다고 주장한다. 이 문헌은 한 견해를 제시하며 현대 LLM 전체의 이해 여부를 확정하는 합의나 실험 판정으로 사용하지 않는다.

유창성, 과업 정확성, 새로운 조합에서의 일반화, 감각·행동을 통한 환경 접지, 지향성과 의식은 서로 다른 평가 층위다. [[중국어 방 논증]]은 이 층위들을 구분하도록 돕지만 어느 하나의 벤치마크만으로 나머지를 판정하게 하지는 않는다.

### 기계 번역과의 관계

세 번째 소스는 [[기계 번역]]이 초기 NLP의 핵심 과업 중 하나였음을 보여준다. Georgetown-IBM 시스템은 사람이 만든 사전과 규칙으로 번역을 처리했지만, 현대 LLM은 대규모 말뭉치에서 학습한 표현을 바탕으로 번역을 생성 과업으로 수행한다. 이 변화는 [[지식 공학 병목]]을 줄이는 동시에, 평가와 해석 가능성이라는 새 문제를 남긴다.

### 퍼셉트론과의 관계

[[퍼셉트론]]은 오류에 따라 가중치를 조정하는 초기 선형 분류기다. 현대 LLM은 학습 가능한 선형 층을 포함한다는 넓은 신경망 계보를 공유하지만, 핵심 사전학습은 라벨 예시 중심의 퍼셉트론 학습 규칙과 다르다. 생성 사전학습, 마스크드 언어 모델링, 지도 미세조정, 선호 최적화 같은 단계를 구분해야 한다.

### 촘스키와의 관계

다섯 번째 소스는 [[노엄 촘스키]]가 언어를 표면 단어열이 아니라 [[통사 구조]], [[재귀]], [[합성성]]을 가진 체계로 보았음을 보여준다. 현대 LLM은 명시적 [[변형생성문법]]이나 [[보편문법]]을 내장하지 않고도 문법적으로 유창한 출력을 만들지만, 이 능력이 구조적 이해인지 통계적 모방인지에 대한 논쟁은 [[촘스키에서 LLM으로]] 이어지는 핵심 쟁점이다.

### MADALINE과의 관계

[[MADALINE]]은 학습 가능한 [[ADALINE]]과 고정 논리층을 결합한 초기 구조로 현대 LLM과 직접 같은 모델이 아니다. [[LMS 알고리즘]]은 선형 평균제곱오차에 대한 그래디언트 계열 학습의 역사적 사례지만, 이를 역전파나 LLM 훈련의 직접 원형으로 단정하지 않는다. [[적응 필터]]와 [[음성 활동 감지]]는 음성 인터페이스의 앞단에 쓰일 수 있으나 MADALINE의 대표 응용이라는 근거는 없다.

### 역전파와의 관계

현대 신경 언어 모델의 사전학습과 미세조정은 미분 가능한 손실의 그래디언트를 [[역전파]]로 계산하고, 최적화기가 그 값으로 매개변수를 갱신하는 방식을 널리 사용한다. 반면 일반적인 텍스트 생성 추론은 순전파로 출력을 계산하며 매 토큰마다 모델을 다시 학습하지 않는다.

Rumelhart·Hinton·Williams의 1986년 논문은 [[다층 퍼셉트론]]의 은닉 표상 학습을 널리 알린 이정표다. 그러나 이 논문은 Transformer 구조, 자기지도 사전학습 목표, 대규모 데이터와 병렬 하드웨어를 제시하지 않았다. 따라서 역전파를 현대 LLM의 핵심 훈련 도구라고 설명할 수는 있지만, 1986년 논문 하나를 모든 언어 AI의 직접 기원으로 두지는 않는다.

### CNN과의 관계

[[021_합성곱 신경망과 특징 학습]]이 다루는 [[합성곱 신경망]]은 문장과 문자 수준 NLP에도 직접 적용됐지만, 현대 LLM을 CNN의 단순한 후속 모델로 보지는 않는다. 두 계열은 데이터에서 계층적 표현을 학습하고 구조적 귀납 편향을 사용한다는 넓은 공통점이 있다. 그러나 CNN의 국소 공유 필터와 Transformer의 자기어텐션은 서로 다른 연산이다.

Vaswani 등의 2017년 Transformer는 [[순환 신경망|순환]]뿐 아니라 합성곱도 사용하지 않는 encoder–decoder 구조를 제시했고, 토큰 사이의 query–key 적합도로 어텐션 가중치를 계산했다. 그러므로 CNN 필터를 ‘암묵적 어텐션’이라고 동일시하거나 CNN에서 Word2Vec·GloVe·seq2seq·어텐션·Transformer가 직선적으로 파생됐다고 주장하지 않는다. 확인 가능한 연결은 특정 텍스트 CNN의 직접 사용과 더 넓은 표현 학습의 공통 문제의식이다.

### ELIZA와의 관계

일곱 번째 소스의 [[ELIZA]]는 사람이 작성한 [[패턴 매칭]] 규칙과 [[템플릿 기반 응답 생성|응답 템플릿]]으로 대화를 만들었다. 현대 LLM은 대규모 데이터에서 훨씬 복잡한 언어 패턴과 표현을 학습하지만, 자연스러운 대화가 실제 이해와 신뢰성을 곧바로 증명하지는 않는다는 문제는 이어진다. [[ELIZA 효과]]는 유창한 시스템에 사용자가 과도한 이해·공감·전문성을 귀속할 위험을 설명한다.

## 검증과 한계

### 무엇이 직접 확인되는가

등록한 1차·학술 근거는 다음 사실을 뒷받침한다. Shannon의 통신원 모형과 N-gram은 언어열을 확률적으로 다루는 선행 문제를 제공했고, Bengio 등의 2003년 신경 확률 언어 모형은 학습된 표현과 다음 단어 조건부확률을 함께 계산했다. Transformer, GPT 계열, 스케일링 연구와 PaLM은 서로 다른 architecture·자료·계산 조건에서 이 확률적 언어 모델링을 확장했다.

하지만 LLM이라는 이름이 하나의 모델 구조, 매개변수 수, 학습 자료, 능력 수준을 고정하지는 않는다. decoder-only 자기회귀 모델, 가려진 token 복원 모델, encoder–decoder 모델은 입력을 보고 확률을 쓰는 방식이 다르다. 특정 논문에서의 성능 수치는 그 논문의 자료·prompt·metric·비교 기준 안에서 읽어야 한다.

### 설명용 단순화와 수식의 경계

앞의 세 후보 분포, 세 위치의 정답 확률, $J(a)=a^2$ 갱신은 확률분포·NLL·경사하강법의 역할을 보이기 위한 편집부 계산이다. 실제 LLM은 수만 개 이상 token 후보, 긴 문맥, batch 평균, 고차원 parameter와 optimizer 상태를 함께 사용한다.

또한 $\theta'=\theta-\eta\nabla_\theta J(\theta)$는 기본 경사하강법의 방향을 보이는 식이다. 실제 대규모 학습은 [[Adam 최적화기|Adam류 optimizer]], 학습률 schedule, 분산 실행, 정밀도·메모리 관리처럼 추가 선택을 쓴다. 이 차이는 위 식이 틀렸다는 뜻이 아니라, 그 식 하나가 전체 학습 system을 완전히 기술하지 않는다는 뜻이다.

### 공통점과 직접 계보의 경계

초기 연구와 현대 LLM 사이에는 조건부 예측, 학습 가능한 가중치, 언어 구조, 대화 행동과 같은 공통 질문이 있다. 그러나 N-gram의 빈도표, 퍼셉트론의 선형 갱신, MADALINE의 고정 논리층, ELIZA의 규칙표, CNN의 국소 필터를 Transformer 기반 LLM의 동일한 내부 연산으로 취급하지 않는다.

유창한 출력과 낮은 예측 손실은 특정 수행을 보여 주지만 이해·의식·사실성·안전성을 함께 보장하지 않는다. 이 문서의 역사적 연결은 등록된 문헌이 확인하는 문제와 도구의 연속성을 설명하며, 모든 기술이 하나의 직선 계보로 이어졌다는 주장은 하지 않는다.

### 낮은 손실이 보장하지 않는 것

평균 NLL이 낮다는 것은 정한 token화와 평가열에서 실제 token에 높은 확률을 주었다는 뜻이다. 그 값만으로 최신 사실을 알고 있는지, 인용이 근거에 맞는지, 편향이 없는지, 긴 대화에서 일관되는지, 사용자의 목표를 안전하게 수행하는지를 결론낼 수 없다. 이들은 서로 다른 자료·목적함수·평가 절차가 필요한 질문이다.

## 학습 확인

### 확인 질문과 답

1. 자기회귀 LLM의 사전학습과 생성에서는 각각 무엇을 고정하고 무엇을 반복하는가?

   **답:** 사전학습은 실제 다음 token 확률의 평균 NLL을 계산하며 $\theta$를 갱신한다. 생성은 $\theta$를 고정하고, 이미 선택한 token을 문맥에 붙여 다음 분포 계산과 선택을 반복한다.

2. $J(\theta)=-\frac1T\sum_t\ln q_t$에서 로그, 마이너스 부호, $1/T$는 각각 왜 필요한가?

   **답:** 로그는 확률의 곱을 합으로 바꾸고, 마이너스는 낮은 정답 확률을 큰 벌점으로 바꾸며, $1/T$는 길이에 따른 누적 벌점을 token당 평균으로 바꾼다.

3. N-gram과 신경 확률 언어 모델, 현대 LLM이 조건부 예측을 공유해도 같은 모델이나 같은 능력이라고 할 수 없는 이유는 무엇인가?

   **답:** 조건부확률이라는 문제 형식은 같지만, 빈도표·고정 창 신경망·문맥별 Transformer 표현은 입력 처리, parameter 공유, 문맥 길이와 학습·계산 조건이 다르다.

# 조건부 확률

[[조건부 확률]]은 어떤 조건이 주어졌을 때 특정 사건이 일어날 확률이다. 언어 모델링에서는 앞선 문맥이 주어졌을 때 다음 단어 또는 토큰이 나타날 확률을 뜻한다.

[[N-gram 모델]]은 조건부 확률을 직접적인 형태로 사용한다. 예를 들어 trigram 모델은 앞의 두 단어가 주어졌을 때 다음 단어의 확률 분포를 말뭉치 빈도에서 추정한다. 이 단순한 설정은 자동완성, 음성 인식, 기계 번역 같은 여러 초기 자연어 처리 시스템의 기반이 되었다 [[001_섀넌의 N-gram 모델]].

## 언어 모델과의 관계

자기회귀 언어 모델은 가능한 이어짐들에 대한 조건부 확률 분포를 계산한다. 현대 [[대규모 언어 모델]] 가운데 BERT처럼 가려진 토큰을 복원하는 모델도 있으므로 모든 LLM을 다음 토큰 예측 하나로 정의하지 않는다. N-gram과 자기회귀 LLM은 조건부 예측 문제를 공유하지만 확률을 추정하는 표현과 학습 방식은 다르다.

# 튜링 테스트

[[튜링 테스트]](Turing Test)는 기계의 언어 행동을 인간 참가자의 행동과 비교하는 기계 지능 평가 사고실험이다. [[앨런 튜링]]은 1950년 논문에서 성별 [[모방 게임]]을 먼저 소개하고, 이어 기계가 참가자의 자리를 맡을 때 질문자의 판별이 어떻게 달라지는지를 물었다. 오늘날의 인간 대 기계 텍스트 판별 형식은 이 논의를 후대에 단순화한 표준형이다.

## 구성

현대 표준형에서는 평가자가 숨겨진 인간 참가자와 기계 참가자에게 텍스트로 질문한다. 다만 대화 시간, 비교군, 판정자 수, 허용 프롬프트가 달라지면 결과도 달라진다. 따라서 “통과” 여부는 하나의 보편적 판정이 아니라 명시된 시험 프로토콜의 결과다.

## 의미

튜링 테스트의 중요한 점은 의식이나 주관적 경험을 직접 측정하지 않는다는 데 있다. 내부 메커니즘보다 외부 수행을 평가하는 [[행동주의적 지능 기준|행동 기반 지능 기준]]이지만, 자극·반응·강화로 언어를 설명하는 Skinner식 행동주의와 동일한 이론은 아니다.

## 한계

튜링 테스트는 인간처럼 보이는 능력을 보상하기 때문에, 깊은 이해 없이도 표면적 언어 패턴이나 회피 전략으로 평가자를 속일 가능성을 남긴다. 이 문제는 [[중국어 방 논증]]처럼 기호 조작과 이해의 차이를 묻는 논쟁으로 이어진다. 또한 인간과 닮은 행동을 지능의 기준으로 삼는 인간중심적 편향도 가진다.

## ELIZA가 보여준 문제

[[ELIZA]]는 [[패턴 매칭]], 응답 템플릿, 반사 규칙만으로도 이해하는 듯한 인상을 만들었다. 이를 튜링 테스트의 최초 구현이나 튜링의 직접적 개발 계보로 부를 근거는 부족하지만, 평가자를 설득하는 대화 행동과 실제 의미 이해가 분리될 수 있음을 비교해서 보여준다.

## 현대적 위치

현대 [[대규모 언어 모델]]은 일부 명시된 프로토콜에서 인간과 구별하기 어려운 대화를 생성했다. 이 결과는 언어적 인간 유사성을 측정하지만 이해, 정확성, 안전성 또는 일반 지능 전체를 판정하지 않는다.

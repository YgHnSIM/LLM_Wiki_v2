# 메모리 네트워크

[[메모리 네트워크]]는 학습·추론 구성 요소와 읽고 쓸 수 있는 [[외부 메모리]]를 결합한 모델 틀이다. Weston·Chopra·Bordes가 2014년 공개한 일반 정의는 입력 (I), 메모리 갱신 (G), 메모리 기반 출력 (O), 응답 (R)을 분리했다.

## 원형의 네 구성 요소

입력 (x)는 (I(x))로 내부 특징이 되고, (G)가 이를 메모리에 저장하거나 기존 슬롯을 갱신한다. (O)는 현재 입력과 메모리에서 답에 필요한 정보를 찾고, (R)은 이를 텍스트나 행동으로 바꾼다.

원 텍스트 구현은 문장을 다음 빈 슬롯에 저장하고 bag-of-words 임베딩 점수로 최대 두 supporting facts를 `argmax` 선택했다. 훈련 때 supporting-fact 라벨과 답 라벨로 margin ranking loss를 사용했다. 이 원형을 모든 슬롯에 연속 가중치를 주는 soft attention 모델이라고 부르지 않는다.

## 후속 end-to-end 변형

2015년 End-To-End Memory Networks는 메모리 위의 recurrent soft attention과 여러 홉을 사용해 중간 supporting-fact 감독을 크게 줄였다. 원형과 후속 변형 모두 “Memory Network” 계열이지만 선택 연산, 감독 신호와 적용 범위가 다르다.

## 외부 지식 접근의 의미

메모리 슬롯은 특정 사실을 개별적으로 추가·선택할 수 있어 모든 지식을 모델 가중치에만 압축하는 방식과 구분된다. 그러나 새 항목 저장만으로 정확한 검색·추론이 보장되지는 않는다. 슬롯 단위, 표현, 후보 검색, 시간·관계 특징과 훈련 분포가 성능을 정한다.

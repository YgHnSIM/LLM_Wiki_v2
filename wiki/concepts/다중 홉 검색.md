# 다중 홉 검색

[[다중 홉 검색]]은 한 번의 검색 결과를 다음 검색 질의나 상태 갱신에 사용해 여러 관련 항목을 순차적으로 찾는 방식이다. 질문에 답하려면 서로 다른 사실을 연결해야 할 때 사용한다.

## Memory Network의 두 홉

2014년 MemNN은 질문과 가장 잘 맞는 첫 supporting memory를 고른 뒤, 질문과 첫 메모리를 함께 사용해 둘째 supporting memory를 골랐다. 예를 들어 물체를 누가 놓았는지와 그 사람이 어느 방에 있었는지를 이어 물체 위치를 답했다.

이 구조의 원 실험은 최대 두 hard `argmax` 선택과 supporting-fact 라벨을 사용했다. 2015년 End-To-End Memory Network는 soft attention 결과를 질문 표현에 더하고 다음 홉을 반복했다.

## 검색과 추론의 경계

여러 문서를 순서대로 찾았다는 사실만으로 논리적으로 올바른 추론을 보장하지 않는다. 각 홉의 후보 재현율, 질의 갱신, 관계 방향, 시간·부정·수량 조건과 최종 답의 충실성을 따로 평가해야 한다. “multi-hop reasoning”이라는 이름이 인간의 내적 사고 과정이나 명시적 논리 증명을 뜻하지도 않는다.

홉을 늘리면 더 긴 사슬을 찾을 가능성과 함께 오류 누적·계산 비용·무관한 경로도 늘어난다. 필요한 홉 수를 고정할지 동적으로 멈출지도 설계 문제다.

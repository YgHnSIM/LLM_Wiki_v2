# 자동 음성 인식

> [!note] 학습 안내
> **난이도:** 입문<br>
> **선수 지식:** 없음<br>
> **읽고 나면:** 음성 특징·음향 모델·발음 사전·언어 모델·디코더가 단어열을 만드는 흐름을 설명하고, 평가 조건과 의미 이해의 경계를 구분할 수 있다.

## 1단계 — 먼저 잡을 핵심

자동 음성 인식(automatic speech recognition, ASR)은 음성 신호를 단어·문자열 전사로 변환하는 과업이다. 음향 패턴을 구분하는 능력뿐 아니라 발음 변이, 단어 경계, 어휘, 언어 모델, 탐색과 평가가 함께 관여한다. 전사 정확성이 높다는 사실과 발화의 의미·의도·진위를 이해한다는 주장은 구분해야 한다.

## 2단계 — 작동 원리

### 전통적 모듈 구성

고전적인 대어휘 연속 음성 인식은 음향 특징, 음향 모델, 발음 사전, 언어 모델, 디코더를 결합했다. [[은닉 마르코프 모델]]은 시간에 따른 상태 전이와 정렬을 조직했고 GMM은 상태별 음향 관측 분포를 모델링했다. 2010년대 초 [[DNN-HMM]]은 이 가운데 GMM을 깊은 신경망 상태 분류기로 교체했다.

각 구성요소는 서로 다른 질문에 답한다.

| 구성요소 | 역할 |
| --- | --- |
| 특징 추출 | 파형을 프레임별 MFCC·filterbank 등으로 변환 |
| 음향 모델 | 특징이 어느 음소·문맥 의존 상태에 맞는지 점수화 |
| 발음 사전 | 단어와 가능한 음소열을 연결 |
| 언어 모델 | 단어열의 문맥 적합성을 점수화 |
| 디코더 | 여러 점수를 결합해 가장 좋은 전사 가설을 탐색 |

## 3단계 — 기술과 근거

### 평가 조건

대표 지표인 [[단어 오류율]]은 치환·삭제·삽입을 센다. 그러나 같은 WER도 자료의 화자, 잡음, 억양, 마이크, 어휘, 전사 규칙에 따라 의미가 다르다. 학습 자료와 시험 자료가 같은 대화 영역인지, 화자 독립인지, 외부 언어 모델과 사전을 사용했는지도 함께 기록해야 한다.

phone error rate, character error rate, sentence accuracy는 WER와 다른 단위다. 여러 논문의 최고 수치를 비교할 때 지표와 분모를 통일하지 않으면 기술의 효과를 과장할 수 있다.

### 심층 학습 전환과 후속 구조

2009–2012년 DNN 음향 모델은 깊은 완전 연결망으로 문맥 의존 HMM 상태를 예측해 GMM-HMM 기준선을 크게 개선했다. 이는 원시 파형부터 전사까지의 종단 간 구조가 아니라 기존 HMM 파이프라인 안의 음향 모델 전환이었다.

후대의 CTC, RNN-T, attention encoder–decoder, Transformer 계열은 프레임 정렬·발음 단위·언어 모델을 공동 학습하거나 단순화했다. 이 변화는 초기 DNN-HMM과 문제를 공유하지만 구조와 학습 범위가 다르다.

## 검증과 한계

### 한계

- 평균 WER은 고유명사·소수 방언·잡음 조건의 심각한 오류를 숨길 수 있다.
- 전사가 맞아도 문장 의미, 화자의 의도와 사실성은 별도 과제다.
- 실시간 시스템에서는 정확도뿐 아니라 지연·계산·메모리·개인정보 보호가 중요하다.
- 라벨이 적은 언어와 방언은 대규모 자원 언어보다 성능이 낮을 수 있다.
- 실제 대화에는 겹쳐 말하기, 머뭇거림, 비언어음, 화자 분리와 문장 부호 문제가 남는다.

## 학습 확인

## 개념

- [[N-gram 모델]] — 앞선 n-1개 단위의 빈도와 조건부 확률로 다음 항목을 예측하고 평활화로 미관측 조합을 다루는 언어 모델 (근거 3개)
- [[마르코프 가정]] — 다음 항목의 확률을 제한된 최근 문맥으로 근사하는 가정 (근거 3개)
- [[조건부 확률]] — 문맥이 주어졌을 때 다음 항목이 나타날 확률을 표현하는 수학적 개념 (근거 1개)
- [[데이터 희소성]] — 가능한 n-gram 조합에 비해 관측 자료가 부족해 0 확률과 불안정한 추정이 생기는 문제 (근거 3개)
- [[Smoothing]] — 관측 확률을 조정하고 미관측 사건에 질량을 배분하며 백오프와 보간을 구분하는 확률 추정 기법 (근거 2개)
- [[Perplexity]] — 평균 음의 로그확률을 지수화해 언어 모델을 평가하며 0 확률의 영향을 드러내는 지표 (근거 3개)
- [[대규모 언어 모델]] — 대규모 텍스트의 자기지도 목표로 문맥 표현을 학습하고 대화형 평가·번역·초기 신경망·언어 구조 문제와 연결되는 현대 언어 모델 (근거 13개)
- [[튜링 테스트]] — 텍스트 대화에서 인간과 기계를 구별할 수 있는지를 묻는 기계 지능 평가 사고실험 (근거 3개)
- [[모방 게임]] — 튜링 테스트의 원래 설정으로, 대화만으로 인간과 기계를 판별하게 하는 실험 구성 (근거 3개)
- [[행동주의적 지능 기준|행동 기반 지능 기준]] — 내면 상태보다 관찰 가능한 수행을 평가하되 Skinner식 행동주의와 구분하는 접근 (근거 4개)
- [[중국어 방 논증]] — 기호 조작과 의미 이해의 관계를 묻는 Searle의 논쟁적 사고실험 (근거 5개)
- [[강한 AI]] — 프로그램 실행 자체가 인지 상태를 구성하고 인간 인지를 설명한다는 설의 비판 대상 (근거 3개)
- [[기계 번역]] — 한 언어의 텍스트를 다른 언어로 자동 변환하는 NLP 과업 (근거 1개)
- [[규칙 기반 기계 번역]] — 사전과 통사 규칙을 사람이 설계해 번역을 수행하는 초기 접근 (근거 2개)
- [[지식 공학 병목]] — 규칙·지식·특징·구조를 수작업으로 설계해야 해서 확장성이 제한되는 문제 (근거 9개)
- [[신경망 기계 번역]] — 병렬 말뭉치에서 번역 대응을 학습하는 딥러닝 기반 번역 접근 (근거 2개)

- [[XOR 문제]] — 단층 퍼셉트론의 비선형 표현 한계와 다층 은닉 표상 학습을 보여주는 대표 문제 (근거 3개)

- [[재귀]] — 같은 종류의 구조가 구조 안에 다시 포함될 수 있는 성질 (근거 1개)
- [[합성성]] — 전체 의미가 부분들의 의미와 결합 방식에서 나온다는 원리 (근거 3개)
- [[인지 혁명]] — 마음을 내부 표상과 계산 과정으로 연구하게 된 전환 (근거 2개)
- [[ADALINE]] — 연속 선형 출력을 기준으로 LMS 학습을 수행하는 적응형 선형 유닛 (근거 2개)
- [[MADALINE]] — 여러 ADALINE과 고정 논리층을 결합한 초기 혼합 신경망 (근거 3개)
- [[LMS 알고리즘]] — 평균 제곱 오차를 줄이도록 가중치를 갱신하는 적응 학습 규칙 (근거 2개)
- [[경사하강법]] — 오류 함수가 감소하는 방향으로 매개변수를 반복 조정하며 역전파의 그래디언트 계산과 구분되는 최적화 방법 (근거 3개)
- [[적응 필터]] — 신호 환경의 변화에 맞춰 필터 계수를 자동으로 조정하는 시스템 (근거 2개)
- [[특징 공학]] — 원시 데이터에서 모델 입력 특징을 사람이 선택·계산하는 작업 (근거 4개)
- [[음성 활동 감지]] — 오디오 구간에서 사람의 음성과 잡음·침묵을 구분하는 과업 (근거 1개)
- [[ELIZA]] — 키워드·패턴·템플릿·반사 규칙으로 대화를 모사한 초기 프로그램 (근거 2개)
- [[DOCTOR 스크립트]] — 로저스식 심리치료사를 모사한 ELIZA의 대표 대화 스크립트 (근거 2개)
- [[패턴 매칭]] — 입력에서 미리 정의한 단어나 구조를 찾아 대응 규칙을 선택하는 방식 (근거 2개)
- [[템플릿 기반 응답 생성]] — 문장 틀에 사용자 표현을 삽입해 응답을 만드는 방식 (근거 2개)
- [[대화 복구]] — 처리하기 어려운 입력에서도 다음 발화를 유도해 상호작용을 이어가는 전략 (근거 2개)
- [[로저스식 심리치료]] — 반사와 비지시적 대화를 통해 내담자의 자기 탐색을 돕는 접근 (근거 1개)
- [[ELIZA 효과]] — 컴퓨터의 표면 행동에 인간과 같은 이해·의도·공감을 귀속하는 경향 (근거 2개)
- [[비터비 알고리즘]] — 유한상태 격자에서 상태별 최고 경로를 보존해 단일 최고 경로를 찾는 동적 계획법 (근거 3개)
- [[동적 계획법]] — 겹치는 하위 문제의 해를 저장·재사용해 다단계 문제의 전체 최적해를 구성하는 방법 (근거 2개)
- [[은닉 마르코프 모델]] — 은닉 상태 전이와 상태별 관측 분포로 순차 자료를 설명하는 확률 모델 (근거 7개)
- [[Baum–Welch 알고리즘]] — 순방향-역방향 기대 통계로 HMM 매개변수를 반복 재추정하는 학습 알고리즘 (근거 3개)
- [[SHRDLU]] — 자연어 명령과 질문을 블록 세계의 상태·추론·행동에 연결한 통합 프로그램 (근거 3개)
- [[블록 세계]] — 물체·공간 관계·가능한 행동을 명시해 언어 이해와 계획을 시험한 제한적 가상 환경 (근거 2개)
- [[마이크로월드]] — 여러 지능 기능을 통합 연구하도록 대상과 규칙을 좁게 제한한 실험 영역 (근거 3개)
- [[벡터 공간 모델]] — 문서와 질의를 같은 특성 공간에 놓고 유사도로 순위를 정하는 정보 검색 모델 (근거 3개)
- [[TF-IDF]] — 문서 안의 빈도와 문서 집합에서의 희소성을 결합한 용어 가중 방식 (근거 3개)
- [[코사인 유사도]] — 벡터 크기를 정규화해 방향의 유사성을 비교하는 척도 (근거 3개)
- [[개념 의존]] — 자연어 의미를 원시 ACT와 의존 관계의 정규 네트워크로 표현하려는 이론 (근거 4개)
- [[스크립트]] — 전형적인 사건·역할·기대를 이용해 이야기의 생략 정보를 보완하는 지식 구조 (근거 2개)
- [[통계적 자연어 처리]] — 말뭉치에서 확률과 매개변수를 추정해 언어 분석·출력 후보를 선택하는 접근 (근거 7개)
- [[말뭉치 기반 학습]] — 표집·주석된 실제 언어 자료에서 패턴과 모델 매개변수를 학습하는 접근 (근거 4개)
- [[증강 전이망]] — 재귀 전이망에 레지스터·조건·구조 구축 동작을 결합한 절차적 파싱 형식론 (근거 4개)
- [[몬태규 의미론]] — 자연언어의 통사 규칙과 내포 논리 번역·모형이론적 해석을 연결하는 형식 의미론 (근거 4개)
- [[Lesk 알고리즘]] — 사전 글로스의 정확한 어휘 중첩으로 문맥 속 후보 의미를 고르는 1986년 지식 기반 WSD 절차 (근거 5개)
- [[단어 의미 중의성 해소]] — 문맥 속 단어를 사전 의미 목록의 적절한 항목과 연결하는 자연어 처리 과제 (근거 6개)
- [[역전파]] — 계산 그래프를 역순으로 순회해 손실의 매개변수별 그래디언트를 구하는 역모드 미분 절차 (근거 6개)
- [[다층 퍼셉트론]] — 비선형 은닉층을 통해 입력을 단계적으로 다시 표현하는 순방향 신경망 (근거 6개)
- [[기울기 소실]] — 깊은 층이나 긴 시간 경로에서 역방향 그래디언트가 지나치게 작아지는 조건적 현상 (근거 4개)
- [[시간 지연 신경망]] — 지연된 국소 입력과 시간축 공유 가중치로 순차 특징을 학습하는 순방향 합성곱 신경망 (근거 5개)
- [[합성곱 신경망]] — 국소 연결과 위치별 가중치 공유로 공간·순서 패턴의 계층적 특징을 학습하는 신경망 (근거 10개)

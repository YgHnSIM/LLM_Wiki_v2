## 개념

- [[N-gram 모델]] — 연속된 n개 언어 단위의 빈도와 조건부 확률로 다음 항목을 예측하는 언어 모델 (소스 1개)
- [[마르코프 가정]] — 다음 항목의 확률을 제한된 최근 문맥으로 근사하는 가정 (소스 1개)
- [[조건부 확률]] — 문맥이 주어졌을 때 다음 항목이 나타날 확률을 표현하는 수학적 개념 (소스 1개)
- [[데이터 희소성]] — 가능한 n-gram 조합의 폭발로 미관측 조합이 많아지는 문제 (소스 1개)
- [[Smoothing]] — 미관측 사건에 0이 아닌 확률을 배분하는 확률 추정 기법 (소스 1개)
- [[Perplexity]] — 언어 모델의 다음 토큰 예측 성능을 평가하는 정보 이론 계열 지표 (소스 1개)
- [[대규모 언어 모델]] — 긴 문맥과 신경망 표현으로 다음 토큰 분포를 예측하고 대화형 지능 평가·번역·퍼셉트론 계보와도 연결되는 현대 언어 모델 (소스 4개)
- [[튜링 테스트]] — 텍스트 대화에서 인간과 기계를 구별할 수 있는지를 묻는 기계 지능 평가 사고실험 (소스 1개)
- [[모방 게임]] — 튜링 테스트의 원래 설정으로, 대화만으로 인간과 기계를 판별하게 하는 실험 구성 (소스 1개)
- [[행동주의적 지능 기준]] — 내면 상태보다 관찰 가능한 행동으로 지능을 평가하는 접근 (소스 1개)
- [[기계 번역]] — 한 언어의 텍스트를 다른 언어로 자동 변환하는 NLP 과업 (소스 1개)
- [[규칙 기반 기계 번역]] — 사전과 통사 규칙을 사람이 설계해 번역을 수행하는 초기 접근 (소스 1개)
- [[지식 공학 병목]] — 규칙과 지식을 수작업으로 구축해야 해서 확장성이 제한되는 문제 (소스 2개)
- [[신경망 기계 번역]] — 병렬 말뭉치에서 번역 대응을 학습하는 딥러닝 기반 번역 접근 (소스 2개)
- [[퍼셉트론]] — 입력의 가중합과 오류 수정으로 이진 분류를 학습하는 초기 인공 신경망 (소스 1개)
- [[선형 분류기]] — 선형 결정 경계로 데이터를 나누는 분류 모델 (소스 1개)

# 손실 곡선과 능력 곡선 사이

> [!note] 학습 안내
> **난이도:** 심화<br>
> **선수 지식:** [[언어 모델 스케일링 법칙]], [[문맥 내 학습]]<br>
> **읽고 나면:** 평균 token loss, downstream task score, ‘능력이 있다’는 threshold 판정을 서로 구분하고, 급격한 scaling curve가 내부의 질적 전환을 뜻하는지 검토할 수 있다.

## 1단계 — 먼저 잡을 핵심

### 비교 질문

[[065_신경 언어 모델의 스케일링 법칙]]은 모델·데이터·학습 compute가 커질 때 평균 token cross-entropy가 조건부 power law를 따라 매끄럽게 낮아지는 결과를 다룬다. [[066_GPT-3와 문맥 내 학습]]은 같은 시기 125M–175B의 여덟 모델에서 TriviaQA·SuperGLUE·산술처럼 서로 다른 downstream 곡선을 보여 준다.

두 관찰은 모순이 아니다. **손실 곡선과 능력 곡선은 같은 출력에서 시작할 수 있어도 같은 관측량이 아니기 때문이다.** 최소 세 층을 나눠야 한다.

| 측정 층 | 대표값 | 직접 답하는 질문 |
|---|---|---|
| 사전 학습 예측 | 평균 token cross-entropy·[[Perplexity]] | 다음 token 분포가 평균적으로 얼마나 좋아졌는가? |
| downstream 과제 점수 | exact match·accuracy·Brier score·edit distance | 특정 prompt·출력·scoring에서 얼마나 맞았는가? |
| 능력 판정 | 무작위 기준·실용 threshold 통과 여부 | 정한 기준에서 ‘할 수 있다’고 부를 것인가? |

Wei 등은 작은 모델에는 없고 큰 모델에는 있으며 작은 규모의 성능에서 단순 외삽하기 어려운 수행을 ‘창발 능력(emergent ability)’으로 정의했다. Schaeffer 등은 일부 급격한 곡선이 비선형·불연속 metric, 유한 평가 표본과 드문 model-size 관측에서 생길 수 있다고 반론했다.

안전한 결론은 두 주장 사이에 있다. 급격한 task score만으로 내부 계산의 질적 전환을 확정할 수 없지만, metric 효과가 확인됐다는 사실만으로 모든 창발 가능성을 부정할 수도 없다.

### 창발 주장의 최소 단위

창발을 모델 이름 하나의 영구 속성으로 쓰지 않는다. 적어도 다음 묶음에 붙는 검증 주장으로 기록한다.

$$
(\text{task},\ \text{metric},\ \text{model family},\ \text{prompt},\ \text{scale proxy},\ \text{sample}).
$$

task가 같아도 metric이 달라지면 곡선 모양이 달라질 수 있고, parameter 수가 같아도 data quality·training tokens·compute·architecture가 다르면 같은 scale이 아니다. 관측점 사이가 넓으면 실제 전이가 완만한지 급격한지도 식별하기 어렵다.

## 2단계 — 작동 원리

### 확률 분포에서 완전 일치로 가는 비선형 변환

길이 $L$인 정답에서 각 token을 맞힐 확률이 model scale $N$에 따라 매끄럽게 $p(N)$으로 증가한다고 가정하자. token 오류가 서로 독립이라는 단순 근사에서는 전체 문자열을 모두 맞힐 확률이 다음처럼 변한다.

$$
P(\text{exact match}\mid N)\approx p(N)^L.
$$

독립 가정은 실제 자기회귀 오류에 정확하지 않다. 그럼에도 작은 per-token 개선이 긴 문자열의 완전 일치에서는 거듭제곱으로 확대되거나, 작은 모델의 점수가 측정 해상도 아래에서 0처럼 보일 수 있다는 직관을 준다. 정답 token과의 추가·삭제·치환 거리를 부분점수로 쓰면 같은 출력 변화가 더 매끄럽게 보일 수 있다.

이것은 exact match가 나쁜 metric이라는 뜻이 아니다. 전체 답이 맞아야 쓸 수 있는 응용에서는 올바른 성공 기준이다. 다만 exact match의 급격한 곡선을 곧바로 내부 능력의 불연속으로 해석하려면 더 연속적인 진단 metric도 함께 봐야 한다.

### 선택 metric과 잠재 분포

다지선다 multiple-choice grade는 가장 높은 점수를 받은 선택지가 바뀌는 순간에만 0에서 1로 이동한다. 반면 Brier score는 각 선택지에 준 확률 질량을 연속적으로 반영한다. 두 metric은 같은 model output distribution을 서로 다른 해상도로 읽는다.

그래서 평가에는 두 종류의 질문이 함께 필요하다.

1. **사용 성공:** 정답 전체를 맞혔는가, 최고 확률 선택지가 맞았는가?
2. **진단 진행:** 오답이어도 정답 token·선택지에 주는 확률이 얼마나 개선됐는가?

첫째는 배포 threshold에 가깝고, 둘째는 scale에 따른 변화의 형태를 분석하는 데 유용하다. 어느 하나가 다른 하나의 ‘진짜’ metric이라고 자동 판정하지 않는다.

### 관측 간격과 표본 해상도

GPT-3 산술 곡선의 마지막 두 model size는 13B와 175B다. 약 13.5배 떨어진 두 관측점 사이에서 큰 점수 증가가 보였다는 사실은 확인할 수 있지만, 그 사이 어느 규모에서 어떤 모양으로 변했는지는 확인할 수 없다.

평가 문항도 유한하다. 실제 성공 확률이 매우 작으면 제한된 표본에서 정답이 한 번도 나오지 않아 관측 정확도가 0이 될 수 있다. Schaeffer 등은 더 많은 산술 평가 자료를 사용하자 분석한 GPT 계열 네 모델 모두에서 0보다 큰 정확도와 점진적 향상을 관측했다고 보고했다. 본문에 제시되지 않은 추가 표본 수를 추정해 쓰지는 않는다.

### scale 축에도 여러 변수가 겹친다

parameter 수, training FLOP, training token과 data quality는 함께 변할 때가 많다. Wei 등도 창발이 처음 관측되는 규모를 능력의 불변 상수로 보지 않았고, 하나의 scale proxy가 모든 차이를 포착하지 못한다고 밝혔다. 더 작은 model이 더 나은 자료·목적·prompt로 능력을 보일 수 있으므로 ‘몇 B에서 창발한다’는 문장은 model family와 학습 조건을 포함해야 한다.

## 3단계 — 기술과 근거

### Kaplan: 매끄러운 것은 평균 token loss다

Kaplan 등의 주 metric은 WebText2 등에서 1,024-token 문맥에 평균한 자기회귀 cross-entropy loss다. 모델 $N$, 데이터 $D$, compute $C$ 가운데 다른 축이 병목이 아닌 조건에서 loss가 power law로 감소했다.

이 결과는 모든 downstream 정확도가 같은 지수로 움직인다는 주장이 아니다. Appendix C도 법칙의 견고한 이론과 신뢰 가능한 외삽 범위를 체계적으로 알지 못한다고 제한한다. 따라서 ‘loss가 매끄럽다’에서 ‘모든 능력이 매끄럽다’로 바로 이동하지 않는다.

### Brown: 매끄러운 곡선과 큰 관측점 차이가 공존한다

Brown 등은 validation loss와 42개 accuracy benchmark 집계에서 model size가 커질수록 대체로 개선되는 경향을 보고했다. TriviaQA는 규모에 따라 비교적 매끄럽게 좋아졌고, 여러 NLI·독해 과제는 큰 model에서도 제한적이었다.

산술은 다른 모양을 보였다. 각 과제는 무작위 2,000문항을 사용하고 정답 문자열 전체가 맞아야 성공으로 셌다. few-shot에서 13B→175B 결과는 다음과 같다.

| 과제 | 13B | 175B |
|---|---:|---:|
| 4자리 덧셈 | 0.40% | 25.5% |
| 4자리 뺄셈 | 0.40% | 26.8% |
| 5자리 덧셈 | 0.05% | 9.3% |
| 5자리 뺄셈 | 0.00% | 9.9% |

이는 두 관측점 사이의 큰 증가를 보여 준다. 그러나 13B와 175B 사이 model이 없으므로 임계점의 위치나 수학적 불연속을 식별하지는 못한다. Brown 논문은 2022년의 엄격한 ‘창발 능력’ 정의를 핵심 용어로 사용하지 않았다.

### Wei: 창발을 별도의 조사 대상으로 정의한다

Wei 등은 작은 model이 무작위 수준에 머물다가 충분히 큰 model에서 유의미하게 무작위 수준을 넘는 곡선을 창발 사례로 정리했다. modified arithmetic, IPA transliteration, word unscrambling, Persian QA, TruthfulQA, grounded mappings, MMLU와 WiC 등 여러 model family의 결과를 모았다.

동시에 이 논문은 발생 scale이 data·parameter·compute 등 상관 변수에 좌우되며 고정된 임계 규모를 확정하는 것이 목적이 아니라고 밝혔다. Appendix A에서는 exact match·BLEU·accuracy가 작은 model의 진행을 가릴 가능성을 검토했고, 일부 BIG-Bench 과제에서 downstream score가 무작위 수준일 때도 cross-entropy가 개선됨을 보였다. 다만 조사한 생성 과제 일부에서는 여러 부분점수 metric에서도 창발형 곡선이 남았다고 보고했다.

### Schaeffer: 같은 출력도 metric과 표본으로 다르게 보인다

Schaeffer 등은 당시 조회 가능한 350M·1.3B·6.7B·175B GPT 계열 모델을 2-shot 두 자리 곱셈과 네 자리 덧셈에 적용했다. 고정된 model output에 accuracy 대신 token edit distance를 사용하면 저자들의 두 과제에서 더 매끄러운 곡선이 나타났다. 추가 평가 자료는 작은 model의 0처럼 보이던 정확도를 0보다 큰 값으로 분해했다.

이 반론의 범위도 제한된다. token edit distance는 오류 의존성과 과잉·과소 생성을 완전히 모델링하는 선형 진리가 아니라 근사적 진단이다. 연구진도 대규모 언어 모델이 창발 능력을 가질 수 없다고 주장하지 않았고, 기존 사례 일부가 연구자의 metric·표본 선택으로 생긴 신기루일 수 있다고 한정했다.

### 네 문헌을 함께 읽은 결론

| 문헌 | 직접 관측 | 이 분석에서 맡는 역할 |
|---|---|---|
| Kaplan 2020 | 조건부 token loss power law | 매끄러운 평균 예측 곡선 |
| Brown 2020 | GPT-3의 loss·task별 score | 같은 model family 안의 서로 다른 곡선 |
| Wei 2022 | 기존 창발 사례의 정의·조사 | ‘작은 model에 없고 큰 model에 있음’이라는 판정 틀 |
| Schaeffer 2023 | metric·표본을 바꾼 재평가 | 판정 틀이 평가 변환에 민감하다는 반론 |

네 결과를 합치면 scaling의 예측 가능성과 surprise를 하나로 선택할 필요가 없다. 평균 loss는 예측 가능하게 움직이면서도, 특정 task interface와 metric은 사용상 중요한 threshold를 급격히 넘을 수 있다. 다만 그 threshold가 내부 알고리즘의 상전이인지, 점진적 분포 변화를 비선형으로 읽은 결과인지는 별도 개입이 필요하다.

## 검증과 한계

### 확인된 사실

- Kaplan의 주 scaling metric은 downstream 정확도가 아니라 평균 token cross-entropy다.
- Brown의 GPT-3 산술은 정답 전체 exact match이며 13B와 175B 사이에 중간 관측점이 없다.
- Wei는 창발을 작은 model에서 없고 큰 model에서 나타나 단순 외삽하기 어려운 능력으로 정의했다.
- Schaeffer의 GPT 계열 재평가는 두 산술 과제·네 model size에 한정되며, 같은 출력의 metric과 평가 표본을 바꿔 곡선 모양을 비교했다.
- Schaeffer는 모든 창발 가능성을 부정하지 않았다.

### 비교를 통한 해석

- ‘능력이 없다’는 말은 latent output distribution, benchmark score, 사용 threshold 가운데 어느 층을 뜻하는지 밝혀야 한다.
- exact match와 multiple-choice grade는 실제 성공을 측정할 수 있지만 내부 변화의 해상도는 낮을 수 있다.
- 연속 부분점수는 점진적 진행을 드러낼 수 있지만 실제 응용의 완전 성공을 대신하지 않는다.
- 창발 주장은 task–metric–model family–prompt–scale proxy–sample을 함께 고정할 때 재검증 가능하다.

개별 수치와 metric 정의는 1차 문헌으로 확인했지만, 네 연구를 loss→task score→능력 판정의 세 층으로 묶은 결론은 이 문서의 합성 해석이므로 `verification: partial`을 유지한다.

### 아직 입증되지 않은 계보와 인과

이 자료만으로 다음을 확정할 수 없다.

- 모든 창발 능력은 평가 metric이 만든 환상이라는 결론
- 매끄러운 cross-entropy가 내부 알고리즘과 모든 행동의 연속성을 보장한다는 결론
- GPT-3가 정확히 175B에서 산술 알고리즘을 획득했다는 판정
- token edit distance가 model의 ‘진짜 능력’을 직접 측정한다는 판정
- 더 촘촘한 model size와 더 큰 평가 표본이면 모든 급격한 곡선이 사라진다는 예측
- parameter scale 하나가 data·compute·architecture·prompt를 넘어 창발의 유일 원인이라는 인과

‘창발’은 폐기할 단어도, 설명 없이 붙일 수 있는 라벨도 아니다. 예상 밖의 수행을 찾는 탐색 용어로는 유용하지만, 내부 질적 전환을 주장하려면 metric 대조, 촘촘한 scale, 충분한 표본, 고정된 prompt와 가능하면 model output 공개가 필요하다.

## 학습 확인

### 확인 질문

1. 평균 token cross-entropy와 산술 exact match는 각각 model output의 어느 층을 측정하는가?

# 010–019 비교 읽기: 표현·규칙·확률·학습

010부터 019까지의 열 편은 하나의 기술이 차례로 다음 기술을 낳았다는 연표가 아니다. 정보 검색, 의미 표현, 통사 분석, 음성 인식, 철학적 논증, 어휘 중의성 해소, 신경망 학습과 언어 모델 확률 추정처럼 서로 다른 층위를 다룬다. 이 비교 읽기의 목적은 각 자료가 무엇을 표현하고, 무엇을 사람이 설계하며, 무엇을 데이터에서 추정하고, 어떤 증거로 성과를 판단하는지 나란히 보는 데 있다.

표의 마지막 열은 방법의 중요도를 서열화하지 않는다. 형식 이론, 철학적 논증, 통제된 실험과 시스템 시연은 서로 다른 종류의 증거이므로 같은 숫자 축에 놓을 수 없다.

## 먼저 분리할 네 층

열 편을 함께 읽을 때 가장 흔한 오류는 표현, 추론, 학습, 평가를 하나로 합치는 것이다.

- 표현: [[벡터 공간 모델]], [[개념 의존]], [[은닉 마르코프 모델]], [[증강 전이망]], [[몬태규 의미론]]은 각각 문서, 사건, 상태열, 통사 절차, 형식 의미를 다른 단위로 나타낸다.
- 추론·예측: 문서 유사도 계산, 개념망 추론, HMM 디코딩, ATN 파싱, Lesk 중첩, Katz 확률 추정은 표현 위에서 수행하는 서로 다른 계산이다.
- 학습·추정: [[역전파]]는 미분 가능한 모델의 그래디언트를 계산하는 일반 도구이고, Katz 백오프는 n-gram 확률 추정법이다. 어느 쪽도 그 자체로 완전한 음성 인식기나 언어 이해 시스템은 아니다.
- 평가·비판: [[중국어 방 논증]]은 모델 구조나 벤치마크가 아니라 프로그램 구현과 이해의 관계를 묻는 철학적 논증이다. 실험 정확도 하나로 논증을 해결하거나 논증 하나로 모든 시스템의 성능을 부정할 수 없다.

이 층을 나누면 “역전파가 의미 표현을 만들었다”, “Katz가 음성 인식 전체를 발명했다”, “중국어 방이 특정 모델을 시험했다” 같은 범주 오류를 피할 수 있다.

## 규칙과 통계는 완전 교체 관계가 아니다

[[011_개념 의존]]과 [[014_증강 전이망과 절차적 자연어 파싱]]은 어휘 의미, 문법망, 레지스터 동작과 세계 지식을 사람이 명시적으로 설계하는 접근을 선명하게 보여 준다. [[015_몬태규 의미론과 합성적 자연언어 해석]]도 학습 시스템이라기보다 통사와 의미 사이의 형식 대응을 정의한다. 반면 [[013_은닉 마르코프 모델과 통계적 음성 인식]]과 [[019_Katz 백오프와 희소 데이터 확률 추정]]은 자료에서 확률을 추정한다.

그러나 통계 방법도 설계를 없애지 않는다. HMM 음성 인식은 음향 특징, 상태 구조, 발음 사전과 탐색을 정해야 했고, Katz 추정은 어휘, n-gram 차수, 할인 상한과 말뭉치 경계를 전제로 한다. [[017_Lesk 알고리즘과 단어 의미 중의성 해소]]는 사전이라는 수작업 지식 자원을 사용하지만 선택 절차는 단순한 중첩 계산이다. 따라서 [[012_상징 규칙에서 통계 학습으로]]가 보여 주는 변화는 “규칙이 사라지고 데이터가 대신했다”가 아니라 무엇을 사람이 정하고 무엇을 자료에서 추정하는지의 경계가 이동한 과정이다.

## 의미를 다룬다는 말의 네 가지 뜻

[[010_벡터 공간 모델과 TF-IDF]]의 유사도는 문서가 공유하는 가중 용어 패턴을 수치화한다. 관련 문서를 잘 찾는다는 사실만으로 문장의 지시 대상이나 진리조건을 이해했다고 결론 내릴 수 없다.

[[011_개념 의존]]은 서로 다른 표현을 정규화된 사건 구조로 바꾸고 추론하려 했고, [[015_몬태규 의미론과 합성적 자연언어 해석]]은 통사 구성에 형식 의미를 대응시켰다. [[017_Lesk 알고리즘과 단어 의미 중의성 해소]]는 훨씬 좁게, 문맥과 사전 풀이의 어휘 중첩으로 한 단어의 의미 후보를 고른다. 세 접근은 모두 의미를 언급하지만 목표 단위와 성공 조건이 다르다.

[[016_중국어 방 논증과 강한 AI 논쟁]]은 다시 다른 질문을 던진다. 올바른 기호 변환이나 유창한 출력이 프로그램 자체의 이해에 충분한지 묻는다. 이 철학적 충분조건 문제는 검색 관련성, 파싱 성공, 중의성 해소 정확도와 구분해 읽어야 한다.

## 순차 자료를 다루는 서로 다른 방식

[[013_은닉 마르코프 모델과 통계적 음성 인식]]은 시간에 따라 변하는 은닉 상태와 관측의 확률 관계를 모델링한다. [[019_Katz 백오프와 희소 데이터 확률 추정]]은 제한된 단어 이력에서 다음 단어의 조건부 확률을 추정한다. 둘 다 확률을 쓰지만 HMM의 상태열 추론과 n-gram의 문맥별 분포 추정은 같은 계산이 아니다.

[[014_증강 전이망과 절차적 자연어 파싱]]의 전이망은 입력 문장을 따라 통사 구조를 만드는 제어 형식이다. 시간 신호의 생성 모형과 동일하지 않다. [[018_역전파와 다층 신경망 학습]]의 역방향 이동도 시간 기억이 아니라 계산 그래프에서 미분을 누적하는 방향을 뜻한다. “순서대로 처리한다”는 표면적 공통점만으로 네 기술을 하나의 계보로 합치지 않는다.

## 희소성과 일반화의 서로 다른 병목

[[010_벡터 공간 모델과 TF-IDF]]는 문서 안에서 흔한 단어와 말뭉치에서 드문 단어를 구분해 검색 가중치를 만든다. [[019_Katz 백오프와 희소 데이터 확률 추정]]은 관측되지 않은 n-gram에 확률을 배분한다. 둘 다 빈도 정보를 쓰지만 TF-IDF의 목표는 검색 순위화이고 Katz의 목표는 정규화된 조건부 확률 추정이다.

[[018_역전파와 다층 신경망 학습]]은 손실 그래디언트를 효율적으로 계산하지만 적은 데이터, 잘못된 목표, 과적합이나 장거리 구조를 자동으로 해결하지 않는다. 마찬가지로 Katz 백오프는 0 확률을 완화하지만 n-gram의 짧은 문맥과 표면 토큰 표현을 없애지 않는다. 계산 도구가 가능하게 한 것과 남아 있는 모델 가정을 분리해야 한다.

## 평가 범위를 맞춰 읽기

열 편의 성과를 비교할 때는 먼저 증거의 종류를 맞춘다.

- 형식적 제안: 몬태규 의미론과 ATN의 계산 표현은 정의와 도출, 구현 가능 범위가 핵심이다.
- 제한된 시연: 개념 의존의 MARGIE·SAM·PAM과 LUNAR는 좁은 입력·지식 범위에서의 작동을 보여 준다.
- 통제된 실험: Lesk의 작은 표본, 1986년 역전파의 합성 과제, Katz의 100문장 평가는 설계와 표본 한계를 함께 읽어야 한다.
- 시스템 계보: HMM 음성 인식과 통계 NLP의 변화는 여러 시기·구성 요소·연구 집단을 하나의 발명으로 합치지 않는다.
- 철학적 논쟁: 중국어 방은 프로그램 실행이 이해에 충분한지를 묻고, 경험적 과업 점수와 다른 방식으로 논증된다.

작은 실험이 후대 연구에 중요할 수는 있지만, 그 중요성이 당시 실험 범위를 자동으로 넓혀 주지는 않는다.

## 두 가지 읽기 경로

표현과 의미에 관심이 있다면 다음 순서가 유용하다.

1. [[010_벡터 공간 모델과 TF-IDF]]에서 통계적 표면 표현과 검색 목적을 본다.
2. [[011_개념 의존]]과 [[014_증강 전이망과 절차적 자연어 파싱]]에서 사람이 만든 의미·통사 구조를 비교한다.
3. [[015_몬태규 의미론과 합성적 자연언어 해석]]에서 합성적 형식 의미를 읽는다.
4. [[017_Lesk 알고리즘과 단어 의미 중의성 해소]]에서 좁은 어휘 의미 선택 문제를 본다.
5. [[016_중국어 방 논증과 강한 AI 논쟁]]에서 계산 성공과 이해의 충분조건을 다시 묻는다.

학습과 확률에 관심이 있다면 다음 순서가 유용하다.

1. [[013_은닉 마르코프 모델과 통계적 음성 인식]]에서 사람이 정한 구조 안의 확률 추정을 본다.
2. [[019_Katz 백오프와 희소 데이터 확률 추정]]에서 미관측 사건과 정규화를 읽는다.
3. [[018_역전파와 다층 신경망 학습]]에서 확률표가 아닌 미분 가능한 가중치 학습의 계산 도구를 비교한다.
4. [[012_상징 규칙에서 통계 학습으로]]로 돌아가 이 변화가 단일 혁명이 아니라 과제별 재편이었는지 점검한다.

## 비교 질문

- 각 방법이 직접 표현하는 단위는 단어, 문서, 사건, 통사 구조, 논리식, 은닉 상태, 확률 분포, 신경망 가중치 가운데 무엇인가?
- 사람이 미리 정한 것은 무엇이며 데이터에서 추정하거나 학습한 것은 무엇인가?
- 같은 “문맥”이라는 말이 검색의 공기, 사전 글로스, n-gram 이력, 음향 상태열과 통사 구조에서 어떻게 다른가?
- 보고된 성과는 형식적 성질, 데모, 작은 실험, 시스템 평가, 철학적 논증 가운데 어디에 속하는가?
- 후대 기술과의 연결이 직접 인용·구현으로 확인되는가, 공통 문제나 수학적 유사성을 나중에 발견한 것인가?

## 핵심 정리

- 010–019는 상징에서 통계, 다시 신경망으로 곧게 이어지는 단일 사다리가 아니다.
- 표현, 추론, 학습, 확률 추정과 철학적 평가는 서로 다른 층이므로 기술 이름만으로 같은 종류의 해결책이라 묶지 않는다.
- 데이터 기반 방법에도 어휘·특징·상태·구조·목표 같은 설계가 남고, 규칙 기반 방법에도 계산과 제한된 경험적 평가가 존재한다.
- “의미”, “문맥”, “일반화”, “이해”는 자료마다 다른 조작적 뜻을 가지므로 먼저 성공 조건을 확인한다.
- 후대 영향은 당시 문헌의 직접 결과, 후속 적용, 문제 수준의 유사성을 나눠 기록한다.

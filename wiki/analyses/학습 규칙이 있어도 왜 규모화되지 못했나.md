# 학습 규칙이 있어도 왜 규모화되지 못했나

> [!note] 학습 안내
> **난이도:** 입문 → 중급<br>
> **선수 지식:** 없음 — 규칙 기반 처리, feature, weight, 선형 분리, loss와 update를 이 문서의 작은 예에서 정의한다.<br>
> **읽고 나면:** 초기 기계번역의 수작업 규칙과 퍼셉트론·ADALINE의 학습 규칙을 구분하고, 학습 가능한 weight가 생겼어도 data·표현·credit assignment·memory·연산·평가가 함께 확장되지 않으면 큰 학습 시스템이 되지 않는 이유를 설명할 수 있다.

## 1단계 — 먼저 잡을 핵심

### “학습한다”는 한 단어가 가리는 차이

1950년대의 machine이 새 입력을 처리했다고 해서 모두 data에서 규칙을 배운 것은 아니다. 1954년 [[003_Georgetown-IBM 기계 번역 시연]]은 사람이 만든 사전 정보와 6개 통사 연산으로 준비된 문장을 번역했다. 반면 [[004_퍼셉트론]]과 [[006_위드로-호프의 MADALINE]] 계열에서는 example과 정답의 차이에 따라 weight가 바뀌었다.

세 방식의 경계를 먼저 보자.

| 방식 | 사람이 고정한 것 | 자료에서 바뀌는 것 | 당시 확인한 결과 |
| --- | --- | --- | --- |
| Georgetown-IBM | 약 250개 러시아어 항목, 문법 정보, 6개 통사 연산 | 없음 | 준비된 60개 문장의 공개 번역 |
| Perceptron | input feature, 단일 선형 구조, threshold | 오분류 때의 weight | 조건을 만족하는 이진 분류 |
| ADALINE/LMS | input feature, 선형 구조, target과 step size | 연속 출력 오차에 따른 weight | 평균제곱오차를 줄이는 적응 |

첫 방식은 **programmed rule execution**, 뒤의 두 방식은 **parameter learning**이다. 그러나 학습 가능한 parameter가 있다는 사실만으로 넓은 언어·시각 문제에서 더 많은 data와 compute를 넣을수록 계속 좋아지는 **scalable learning system**이 완성되지는 않는다.

### 규모화에는 여섯 조건이 함께 필요하다

학습 규칙은 “한 example을 보고 weight를 어떻게 바꾸는가”에 답한다. 큰 학습 시스템은 그 밖에도 다음 질문에 답해야 한다.

1. **자료:** 어떤 input–target pair를 얼마나 모으고 어떻게 저장·읽는가?
2. **표현:** raw text·image를 어떤 feature vector로 바꾸는가?
3. **모형:** 필요한 pattern을 표현할 충분한 depth·width·nonlinearity가 있는가?
4. **credit assignment:** 여러 layer와 parameter 가운데 어느 값이 error에 얼마나 기여했는가?
5. **실행:** update를 반복할 memory 용량·연산률·data 이동 경로가 있는가?
6. **평가:** training example 암기가 아니라 새 input의 성능을 어떻게 재는가?

초기 연구는 이 조건 가운데 일부를 중요한 방식으로 해결했다. “못했다”는 표현은 연구가 실패했다는 뜻이 아니라, 오늘의 대규모 학습을 위한 전체 묶음이 한 시점에 준비되지 않았다는 뜻이다.

### 가장 작은 구체적 예: 같은 선형 점수, 다른 학습 신호

Input $x=(1,2)$, 초기 weight $w=(0.2,-0.1)$, bias $b=0$이면 선형 점수는

$$
a=w^\top x+b=0.2\cdot1-0.1\cdot2=0
$$

이다. 목표 $d=1$, step size $\eta=0.1$이라고 하자.

Perceptron은 threshold를 지난 class $\hat y$가 틀렸는지 본다. 예를 들어 $a\le0$을 class 0으로 정했다면 $\hat y=0$이고 다음처럼 수정할 수 있다.

$$
w'=w+\eta(d-\hat y)x=(0.2,-0.1)+0.1(1)(1,2)=(0.3,0.1)
$$

ADALINE은 threshold 전 연속값 $a=0$과 target의 오차 $e=d-a=1$을 사용한다.

$$
w'=w+\eta ex=(0.3,0.1),\qquad b'=b+\eta e=0.1
$$

이 한 step에서는 두 weight가 우연히 같다. 그러나 $a=0.4$처럼 class는 맞고 연속 오차가 남으면 perceptron은 수정하지 않을 수 있지만 ADALINE은 $e=0.6$을 이용해 계속 바꾼다. 같은 선형 unit이라도 **어느 출력에서 error를 재는가**가 학습 경로를 바꾼다.

## 2단계 — 작동 원리

### 규칙 기반 번역은 적용 범위를 사람이 먼저 쓴다

Georgetown-IBM system은 Russian word의 사전 정보와 문법 표지를 읽고 정한 operation으로 English 대응과 어순을 만들었다. 성공 범위는 미리 준비한 lexicon·rule·sentence에 묶였다.

어휘를 250개에서 25,000개로 늘린다고 생각해 보자. 저장 공간만 늘어나는 것이 아니다. 한 word가 여러 뜻을 가질 때 context rule을 추가하고, 서로 충돌하는 rule의 우선순위를 정하고, 새로운 domain의 표현을 검증해야 한다. Coverage가 커질수록 사람의 작성·디버깅·검산 비용이 커진다.

이 방식에도 훌륭한 computation이 있다. 다만 system이 example에서 번역 rule 자체를 추정한 것은 아니다. Prepared demo의 성공과 learning capability를 구분해야 한다.

### Perceptron은 결정 경계를 example로 옮긴다

[[퍼셉트론]]은 feature vector $x\in\mathbb{R}^d$에 weight $w\in\mathbb{R}^d$를 곱해 score를 만들고 threshold로 둘 중 하나를 고른다.

$$
\hat y=\mathbf{1}[w^\top x+b>0]
$$

Prediction이 틀렸을 때 input 방향으로 weight를 수정하므로 사람이 모든 판정 rule을 직접 나열하지 않아도 된다. Training data가 선형 분리 가능하면 유한한 mistake 뒤 분리 경계를 찾는다는 수렴 결과도 있다.

하지만 조건이 곧 한계다. XOR처럼 하나의 line이나 hyperplane으로 나눌 수 없는 label pattern은 weight를 더 오래 update해도 단일 perceptron이 표현할 수 없다. **Optimization이 실패한 것**과 **model 안에 정답 함수가 없는 것**을 구분해야 한다.

### ADALINE은 error의 크기를 연속값에서 잰다

[[ADALINE]]은 이진 결정을 내리기 전 선형 출력 $a=w^\top x+b$와 target $d$의 차이를 이용한다. 한 example의 제곱오차를

$$
L=\frac12(d-a)^2
$$

로 두면 weight에 대한 gradient는

$$
\nabla_wL=-(d-a)x
$$

가 된다. 따라서 $w\leftarrow w-\eta\nabla_wL=w+\eta(d-a)x$로 loss를 줄이는 방향을 계산할 수 있다. [[LMS 알고리즘]]은 noisy signal에서도 평균제곱오차를 줄이는 실용적 적응으로 발전했다.

이 진전은 중요하지만 단일 ADALINE은 여전히 선형 결합기다. 여러 ADALINE을 놓은 초기 MADALINE은 더 다양한 구조를 만들었지만 모든 층을 한 objective로 공동 학습하는 현대 deep network와 같지 않았다.

### 여러 layer에서는 “누가 틀렸는가”가 어려워진다

Output 하나가 틀렸을 때 마지막 weight는 target과 직접 비교할 수 있다. Hidden unit은 직접 target이 없다. 각 hidden output이 최종 error에 얼마나 기여했는지 chain rule로 나누어 전달하는 credit assignment가 필요하다.

초기 local rule과 고정 logic layer는 이 문제를 제한된 구조에서 우회하거나 사람이 결합을 설계했다. 후대 [[역전파]]는 differentiable composition 전체에서 parameter별 gradient를 계산했고, [[경사하강법]]은 그 gradient로 update했다. 역전파만 있어도 data·hardware·좋은 initialization·objective가 자동으로 생기는 것은 아니다.

### Feature가 고정되면 학습 범위도 고정된다

Perceptron과 ADALINE에 넣는 $x$는 현실의 object 자체가 아니다. 연구자가 sensor 값을 골라 scaling하거나 text에서 count·dictionary feature를 만든 결과다. Model은 주어진 coordinate 안에서 weight를 배운다.

Modern deep learning의 큰 변화 가운데 하나는 여러 layer가 task에 유용한 intermediate representation도 함께 학습한다는 점이다. 그러나 raw data를 넣었다는 이유만으로 의미 있는 representation이 보장되지는 않는다. Architecture, objective와 data distribution이 무엇을 학습할지 계속 제한한다.

## 3단계 — 기술과 근거

### 1954년 시연: 실행은 됐지만 학습 평가는 아니었다

1963년 Macdonald 보고서가 회고한 Georgetown-IBM experiment는 IBM 701에서 화학 분야의 준비된 60개 Russian sentence를 English로 번역했다. 약 250개 vocabulary item과 6개 syntactic operation이 사용됐다.

이 수치는 system이 수행한 task의 경계를 보여 준다. 60/60 같은 demo 성공률을 무작위로 고른 일반 문장에 대한 accuracy로 읽을 수 없다. Training set, held-out test set과 domain shift를 나눈 modern evaluation도 아니었다.

### 1958년 Perceptron: 학습 가능한 연결과 조건부 보장

Rosenblatt의 1958년 논문은 perceptron을 정보 저장·조직을 위한 probabilistic model로 제안하고 학습 절차와 실험을 다뤘다. 후대의 간결한 선형 classifier 표기는 핵심 계산을 배우기 위한 정리이지 원문의 모든 구조를 그대로 복제한 것은 아니다.

Novikoff의 1963년 분석은 margin을 가진 선형 분리 자료에서 mistake bound를 제시했다. 이는 “충분히 오래 학습하면 모든 pattern을 배운다”가 아니다. Input norm, separating margin과 선형 분리 가능성이라는 전제가 있는 결과다.

### 1960년 ADALINE/LMS: 학습 규칙과 physical implementation

Widrow와 Hoff의 Adaptive Switching Circuits는 ADALINE과 least mean square 적응을 switching 문제에 연결했다. [[퍼셉트론에서 MADALINE으로]]이 자세히 비교하듯, perceptron의 binary error correction과 ADALINE의 continuous error는 같은 update rule이 아니다.

Widrow와 Lehr의 1990년 회고는 perceptron, ADALINE·MADALINE, hardware 구현과 후대 backpropagation을 30년 범위에서 구분한다. 초기 적용에는 pattern·speech recognition, weather prediction과 adaptive control이 있었지만, 후대 adaptive noise cancellation의 성과를 모두 MADALINE 자체의 배치 성능으로 돌릴 수는 없다.

### Parameter 수보다 먼저 봐야 할 반복 비용

$d$차원 input에서 output 하나를 만드는 선형 unit은 bias를 포함해 $d+1$개 parameter를 가진다. Output $k$개를 모두 dense하게 연결하면

$$
P=k(d+1)
$$

이다. Example $N$개를 한 번 훑는 단순 dense 계산은 대략 $O(Nkd)$ multiply-add를 요구한다. 실제 비용에는 input을 읽고 weight를 저장·갱신하는 memory traffic, analog·digital hardware의 precision과 synchronization도 들어간다.

Parameter $P$만 늘리면 표현력 일부는 늘 수 있지만 training example·update step·memory와 validation 비용도 함께 커진다. 더구나 선형 layer를 넓히기만 해서는 depth와 nonlinearity가 주는 composition을 얻지 못한다.

### 이 본편의 측정 장부

| 항목 | 기록 |
| --- | --- |
| 작업 | 준비된 Russian–English rule 실행, labeled pattern의 이진 분류, 연속 target에 대한 선형 적응 |
| 규모 | vocabulary·rule·sentence 수, input dimension $d$, output $k$, parameter $P$, example $N$, update 횟수 |
| 결과 계약 | 준비 범위의 translation, 선형 분리 자료의 correct classification, 정한 분포에서 mean squared error 감소 |
| 시스템 경계 | 사전·rule 작성과 IBM 701 실행, feature 추출·학습 unit·threshold, ADALINE hardware·trainer·평가 자료를 분리 |
| 고정 조건 | domain·lexicon·rule, feature와 label, initial weight·step size, model class와 train/test 분할 |
| 지표 | coverage·오류 유형, mistake 수·margin, MSE·convergence, memory word·operation·wall-clock과 새 자료 성능 |

서로 다른 system의 “성공”을 한 accuracy 열에 놓을 수 없다. Prepared translation demo, separable classification과 noisy adaptive filtering은 input sampling과 result contract가 다르다.

### LLM과 비교하면 무엇이 추가됐나

Modern [[대규모 언어 모델]]도 parameter update라는 점에서는 초기 learning machine과 넓은 공통점을 가진다. 그러나 규모화는 다음 결합 위에서 일어났다.

- 사람이 고른 소수 feature 대신 token과 다층 representation을 함께 학습한다.
- [[역전파]]로 모든 differentiable layer의 credit를 계산한다.
- 대규모 corpus를 반복해 읽고 optimizer state와 checkpoint를 저장한다.
- 행렬곱을 accelerator에서 batch·병렬 실행한다.
- held-out loss와 여러 downstream evaluation으로 training 밖의 성능을 확인한다.

이 목록은 Perceptron이 Transformer를 직접 낳았다는 계보가 아니다. 초기 연구가 분명히 만든 것은 **data가 parameter를 바꾸는 실행 계약**이다. 이후의 발전은 표현·optimization·data pipeline·hardware와 평가가 함께 바뀐 결과다.

## 검증과 한계

- **직접 영향:** Widrow–Hoff의 ADALINE/LMS 연구와 후대 adaptive system 계보, perceptron·MADALINE·backpropagation을 비교한 Widrow–Lehr의 회고는 문헌으로 확인된다. Georgetown demo에서 perceptron으로 직접 이어진 기술 이전은 이 문서가 주장하지 않는다.
- **가능 조건:** 더 큰 memory·연산률, digital data와 reusable software는 더 많은 example·parameter update를 실행할 여지를 넓혔다. Hardware 증가만으로 좋은 representation·objective·generalization이 생기지는 않는다.
- **병행 맥락:** 1950–1960년대 rule-based translation과 learning machine은 “기계가 지적 작업을 수행할 수 있는가”라는 넓은 관심을 공유했지만 input·output·학습 여부가 달랐다.
- **후대 유추:** Data·model·compute·evaluation의 여섯 조건으로 초기 system을 감사하는 것은 현대 scaling 관점의 분석이다. 당시 연구자가 오늘의 foundation model roadmap을 갖고 있었다는 뜻이 아니다.

“규모화되지 못했다”는 판단은 parameter count가 작았다는 사실만으로 내리지 않는다. 공개 자료가 모든 hardware operation rate·memory capacity·training time을 같은 단위로 제공하지 않으므로, 이 문서는 서로 다른 실험의 속도 순위를 만들지 않는다.

Minsky와 Papert가 분석한 단층 perceptron의 표현 한계는 중요하지만, XOR 하나가 neural network 연구 침체를 단독으로 일으켰다는 설명은 채택하지 않는다. 연구 방향은 funding, hardware, data, algorithm과 기대가 함께 바뀐 결과다.

## 학습 확인

1. Georgetown-IBM demo와 Perceptron·ADALINE 가운데 무엇이 rule execution이고 무엇이 parameter learning인지, 고정되는 값과 바뀌는 값으로 설명하라.
2. 선형 분리되지 않는 자료에서 Perceptron이 수렴하지 않을 때 optimization failure와 representation failure를 어떻게 구분할 수 있는가?
3. 새 learning system에 update 식이 제시됐다면 data·표현·credit assignment·실행·평가에서 추가로 확인할 질문을 하나씩 적어라.

다음에는 corpus count와 확률 추정이 N-gram·HMM·speech recognition에서 어떻게 production computation이 됐는지, model sparsity·search와 당시 CPU·storage 조건을 함께 살핀다.
